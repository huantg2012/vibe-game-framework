必须成立

  • 实体 / 寻路 / 巡逻速度走 AISystem，禁止另写一套移动。
  • 贴图与出击共用 generatePlaceholderTextures。
  • 新敌人角色：data/enemies.csv → 给 GYM_LOOPS 补环。
  • 方案 1：加厚工业像素 + 灯尘。侧影加厚、配色略暖。
  • 出击 Player 已接同一套外形（DEC-068）。
  • 北墙渗透体 / 改写体是出击同一套像素，只站住对照尺寸。
  • 固定观察院子，不是裂隙生成岛。
  • 玩家走出击 Player，无敌。WASD 移动，空格挥击。
  • 甲走出击 AISystem / CombatSystem。乙丙丁走出击 ContaminationHostSystem（含伤害与混乱）。
  • 侧栏按污染句法维度配表，点生成刷当前配置。
  • 拖动画布平移，滚轮缩放。画布钉在右侧窗格，不跟侧栏一起被撑走。
  • 击杀后约 0.8 秒按当前侧栏配置再刷。打不死不会被击杀，需再点生成。
  • 止损从连续性 × 覆盖深度查表，不是接触词素。场=挥击打不动但仍踩踏/进体积吃混乱；菌落=多颗核，打一颗其余还在；渗透核露、覆盖核埋。
  • 不开视野迷雾。不接遭遇识别旁白。侧栏止损行是开发说明，不是头上名字。
  • 一次只进一个厅（孔谱 × 基体）。拖动画布或画布外侧空白平移。滚轮上下看，Shift+滚轮左右看，Ctrl 或 Cmd+滚轮缩放。
  • 只 attach 生产方案 D。不刷玩家、不创建 Enemy / 宿主。
  • 开发标签走 DOM，头上无字。表名与档位分行。
  • 点格选中。双击或侧栏「检视」看活标本、四朝向与信号相。关闭回到厅。
  • 打开就是三格并排：A 更扁更贴地 / B 更亮膜感 / C 更汇流。
  • 同一颗种子、同一改写档、油膜。不要点生成，不要翻句法课侧栏。
  • 拖动画布平移，滚轮缩放。开发课，不是陈列馆目录。
  • 布局走出击同一套 generateRiftLayout，禁止另写生成器。
  • 地表走 RiftSurfacePainter。不开 VisibilitySystem。
  • 乙 / 丙 / 丁走出击同一套 ContaminationHostSystem。
  • 不接遭遇识别旁白。
  • 不刷会走的甲。色块只标甲路点。
  • 色块是布点标记，不是实体。拖动画布平移，滚轮缩放。
  • 布局 / 地表 / 玩家 / 相机 / 视野全是出击同一套；只有遮罩渲染模式可切。
  • 数字键 1–4 切模式：1 现状（三档+棋盘）/ 2 细分带 / 3 光场 / 4 抖动坡。
  • T 切 teal 渗透：关 → 硬内缘（现状）→ 软内缘。强度固定 0.6 供对照。
  • R 换种子重生成，当前模式保持。WASD 移动，边走边看肩膀与边界。
  • 这是抽卡对照课：模式只活在 VisibilitySystem 的 spike 分支里，出击默认仍是 1。
