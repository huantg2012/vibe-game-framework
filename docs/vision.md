## Elevator Pitch

后克苏鲁世界的单机搜打撤：在注定崩塌的时空中，穿越裂隙猎取薪柴，以毒攻毒，维持最后一点净土的存续。

## 核心体验

> 在一个注定崩塌的世界里，独自维持最后一点光亮——每次穿越裂隙都是赌命，赌的不是能不能赢，而是能不能多撑一天。

## 体验支柱

1. **绝望边缘的紧绷** — 资源永远不够，净化点永远在被侵蚀，玩家永远处于"再不出击就要崩了"的状态。不是突发的恐惧，是持续的、低频的焦虑。
2. **贪婪与撤退的博弈** — 裂隙里每多待一秒都有代价（混乱值），但搜刮越多回去越好过。核心决策不是"打不打得过"，而是"还敢不敢再多拿一点"。
3. **孤独的仪式感** — 没有同伴、没有NPC喊你英雄。点燃薪柴、强化净化点、准备下一次出击——这些重复动作本身就是"活着"的证明。西西弗斯推石头上山的节奏。

## 世界观骨架

- **背景**：后克苏鲁。灾难已发生，星球被污染殆尽，时空破碎。
- **净化点**：玩家仅存的据点/基地，孤立地对抗周围的污染。时刻处于被侵蚀的状态。
- **裂隙**：临时产生的时空通道，连接到其他被污染的时空。玩家通过裂隙出击。
- **薪柴**：其他时空被污染过程中产生的渣滓。因不同时空的污染源互相冲突，可用于抵抗玩家所在时空的污染。是游戏的通用货币。
- **污染体**：各时空中被污染扭曲的存在。猎杀/收集的对象。
- **混乱值**：玩家身处异时空时累积的外来污染。超过阈值后触发逐步加码的惩罚（软限制）。

## 核心循环

```
进入裂隙（推进冲击计数器）
    → 在污染时空中潜行/观察/选择性交战
    → 收集薪柴 + 物品
    → 混乱值匀速上升 + 行为加速
    → 超过阈值后惩罚逐步加码（软限制，不是硬截止）
    → 玩家自行决定何时撤离（越晚走代价越大）
    → 撤离后：薪柴分配到净化点各模块 / 自身强化
    → 每 N 次出击，净化点遭受污染冲击（分区结算）
    → 受损模块影响下次出击条件
    → 资源缺口驱动下一次出击
```

## 关键机制

1. **混乱值系统**：基础随时间匀速增长 + 特定行为（被发现/战斗/接触高污染区）额外累加。超过阈值不强制撤离，而是惩罚逐步加码（视野缩小/移速降低/等）。— 支撑支柱 1, 2
2. **潜行/观察系统**：敌人有巡逻路径和感知范围。玩家核心动作是观察、等待、选择路线。— 支撑支柱 2, 3
3. **战斗系统**：[具体方式待 Foundation 确定] 定位为"可选手段，有代价但可控"。不是主要交互方式，是决策选项之一。— 支撑支柱 1, 2
4. **净化点分区防御系统**：净化点分为多个功能模块，冲击前玩家将薪柴分配至各模块作为防御。冲击攻击力在模块间不均匀分布（部分可预测）。防御不足的模块受损并影响后续出击条件。— 支撑支柱 1, 3
5. **薪柴经济**：唯一通用货币，同时服务三个出口（净化点各模块防御 + 自身强化）。来源是裂隙内的搜刮/战斗。设计方向为"永远不够用，顾此失彼"。— 支撑支柱 1, 3
6. **物品系统**：[MVP 阶段精简为 0-1 种，后续迭代扩充] 预期丰富度高。物品是"选项空间"的载体。— 支撑支柱 2

## 净化点冲击结算详细设计

**分区防御 + 资源分配模型：**

- 净化点有 2-3 个功能模块（MVP 阶段 2 个即可，后续可扩展）
- 每个模块有功能效果，影响玩家出击条件（如：屏障影响混乱值基础增速、储藏影响携带上限、净化器影响初始状态等）
- 冲击前：玩家将薪柴储备分配到各模块作为防御投入
- 冲击时：攻击力在模块间不均匀分布，分布方向部分可预测（给提示但不给精确数值）
- 结算规则：
  - 防御足够 → 模块安全，投入薪柴消耗一部分（维护成本）
  - 防御不足 → 模块受损（功能降级），投入薪柴全部消耗
  - 防御为零 → 模块严重受损，需额外薪柴修复
- 冲击强度随游戏进程递增

**设计意图**：每次冲击都是资源分配决策——在多个模块间权衡优先级。多数情况下薪柴会吃紧，但并非绝对不可能全防住（优秀的出击表现应该被奖励）。模块受损的后果反馈到下次出击，形成"出击表现 → 冲击结算 → 出击条件变化"的连环影响。整体循环的核心价值在于：资源分配的纠结感 + 受损后果的连锁反应 + 冲击递增带来的持续压力。

## 短期/中期/长期循环

- **Moment-to-Moment（10-30秒）**：观察环境 → 评估自身状态与敌人分布 → 选择路径（绕行/潜行/交战/搜刮）
- **Session（15-30分钟）**：一次完整裂隙探索。从进入到撤离，伴随混乱值从 0 逐步逼近并可能超过阈值的全程压力曲线。撤离后进行薪柴分配决策。
- **Meta（跨 Session）**：维持净化点各模块存续（分区防御决策链） + 逐步拼凑世界真相（叙事碎片，辅线）。冲击强度递增制造持续的规模压力。

## 成长曲线设计方向

**"勉强维持的紧绷感"** — 玩家变强的同时威胁同步升级（冲击强度递增）。永远不会到达"安全"的状态。进度不是"从弱变强"，而是"在更大的规模上维持同一条崩溃边缘线"。

元进度的价值感来源：A（生存紧迫："活着回来了，赶紧加固"）为主，B（理解驱动："又拼上一块拼图"）为辅。

## 游戏形式

- **类型**：单机搜打撤 + 潜行/资源生存
- **单机**：当前只考虑单机模式
- **视角**：俯视角 2D（Darkwood 式）
- **画面风格**：AI 生成美术，倾向像素风或 low-fi 风格（AI 出图最稳定的方向）
- **平台**：Web 浏览器

## 目标玩家

**喜欢在压迫感中做决策的单机玩家。**

他们玩过 Darkest Dungeon / Darkwood / Rain World / This War of Mine 中的至少一两个，能接受"不爽快"的游戏节奏，享受"活着回来"比"杀光全场"更有成就感的体验。不追求操作竞技，追求每个选择都有重量。

具体画像：
- 能接受失败和损失作为常态（非轻度休闲玩家）
- 喜欢氛围/叙事但不介意碎片化呈现
- 享受"资源紧缺下的精打细算"
- 对克苏鲁/宇宙恐怖/后末日题材有兴趣

## 参考与差异化

### 核心参考

- **Darkwood**：学有限视野 + 环境压迫氛围 + 白天/夜晚双循环结构；避无时间压力的自由探索节奏
- **Rain World**：学脆弱感 + 生态系统设计 + 知识即进步；避极端无引导 + 操作选项过少
- **Escape from Tarkov**：学出击前经济决策 + 装备恐惧心理 + 撤离点多样性；避依赖PvP制造紧张 + 后期经济膨胀
- **Darkest Dungeon**：学渐进压力系统（Stress）+ "贪一步"后果设计 + 仪式感叙述；避高RNG决定成败
- **Signalis**：学物品栏限制作为决策 + 碎片化叙事 + 低保真美术的恐怖力量；避战斗故意难玩 + 线性一次性体验
- **Alien: Isolation**：学动态AI不可预测性 + 工具多样性 + 不完美信息工具；避单一威胁导致疲劳 + 无成长反馈
- **This War of Mine**：学"勉强维持"的多线资源消耗 + 出击前决策权重 + 安静时刻的力量；避搜刮操作过简 + 中后期可能稳定
- **Subnautica**：学安全空间vs危险空间的情感对比（净化点作为情感锚点）；避成长消除恐惧

### 差异化定位

> 一个以"搜打撤"经济循环驱动的、单人潜行生存游戏，核心体验不是"变强翻盘"而是"维持崩溃边缘的紧绷"。

市场空白分析：
- 搜打撤游戏 = 多人 + 射击 + 成长导向（无单机潜行生存方向）
- 潜行生存恐怖 = 无搜打撤经济循环结构
- "勉强维持"生存游戏（This War of Mine）= 核心玩法不在出击环节
- 压力/混乱系统（Darkest Dungeon）= 管理者视角，非当事人视角

本项目占据的交叉点目前无现存游戏精确覆盖。

## MVP 范围

### 设计原则

MVP 要具备一定程度的可玩性，不能过度阉割。目标是"能完整体验核心循环并验证三根体验支柱是否成立"的最小完整体验。

### Must-have

**裂隙内（核心玩法层）：**
1. 俯视角移动 + 有限视野（锥形或圆形光源式，视野外黑暗）
2. 程序化地图生成（Voronoi 碎片区域 + Cellular Automata 有机地形 + 空间裂口连接，支持视线遮挡和路线选择）
3. 一种基础敌人（巡逻路径 + 感知范围 + 状态机：巡逻/警觉/追击）
4. 基础战斗（简化版，验证"可选、有代价、可控"的定位）
5. 薪柴收集（地图散布，部分安全/部分被看守）
6. 混乱值系统（匀速上涨 + 行为加速 + UI 显示 + 至少一种超阈值惩罚）
7. 撤离机制（地图上有撤离点，到达即撤离）

**净化点（元循环层）：**
8. 净化点分区防御界面（2 个功能模块 + 薪柴分配 + 冲击结算）
9. 模块受损反馈（受损模块影响下次出击条件）
10. 冲击强度递增（每轮冲击比上一轮更强）
11. 完整循环跳转（冲击结算后可进入下一轮裂隙）

**基础设施：**

12. 游戏状态管理（session 内数据持续）
13. 基本 UI（血量/混乱值/薪柴/物品栏显示）
14. 第二种敌人类型（不同感知/行为模式）
15. 1-2 种功能物品（干扰物/回复品）
16. 音效（环境音 + 关键交互反馈音）
17. 持久存档（跨 session 保存）
18. 净化点视觉状态变化（模块健康/受损在画面上有视觉反馈）
19. 多语言支持（简体中文 + 英文）
20. 净化点可行走空间 + 边界黑暗氛围系统（外部周期性渲染模糊内容制造压迫感）

### Nice-to-have（有余量时纳入）

- 净化点第三个功能模块
- 撤离点多样性（多个位置/不同条件）
- 混乱值多级惩罚（阶梯式加码）

### 明确不做（Out-of-scope）

- 叙事碎片 / 世界观文本 / B线内容
- "虚假希望"终局设计
- 丰富物品系统（3种以上）
- 多种裂隙环境/生物群落
- 玩家自身升级/技能树
- NPC 互动
- 教程/新手引导
- 完整音乐/音景设计
- 手机端适配
- 多存档
- 成就系统
