# 完整悬海试玩入口

提供单趟训练与净化点连续旅程两种入口，仅开发服务器启用。单趟16组真实搜撤和连续五趟供奉链已验证，2026-09-13用户“验证ok，提交吧”验收本轮整体体验。它使用正式RiftScene、武器与技能、视线、物件账本、翻找及撤离，换入已登记的悬海内容和三维呈现。与旧M长路线、local、冻结Vista分别保留，不用新内容覆盖旧样本。

## 可选内容

两张布局是“开阔潮沟”和“折返岸脊”，分别组织落水低道/高岸旁路与满载折返。四配置为白板无技能、短窗近战、轻装静默、稳步绕行；装备由现有共享训练初始化一次授予，途中不提供换装、补充耐久或保护。

可重现地址参数为`scene`、`loadout`、`seed`，具体ID见[悬海内容](../content/suspended-sea.md)。本页默认短入场先建立声音与画面，Enter可跳过；结束入场后才交给WASD、Space、Q/F、E和Tab。动作键在入场期间按住时，交控不会误触，须松开再按。

- WASD移动及转向，Space挥击；Q/F沿实际装备释放主动技能。
- 按住E翻堆；揭晓后使用既有拾获交互，Tab整理本趟收获，世界继续。
- Esc暂停和继续；同一水流、壳片、技能与入场时钟同时冻结。
- 撤离点仍是进入岸。正常撤离/死亡使用正式库存结算，之后返回本页配置；中止单独记录，不伪装成死亡或撤离。

## 世界中的操作

合拢的壳片位于落水边缘。汇流至水退尽之前，撬棍可以从干地击偏薄唇；一次有效命中消耗1点耐久。被改道的是侧水，垂直核心仍危险。已经接地的侧水最多再持续0.6秒，随后流入天井；自然水先退完则更早结束。原片在水退后回摆，下一轮还会重新合拢。无需打壳片也能通过等待或绕岸离开。

内容、布局、来源掉落和水流参数以`data/suspended-sea-*.csv`与`data/contaminant-sources.csv`为源。修改后运行`npm run codegen`，未知显式ID/不支持组合不能静默回退成旧图书馆或其它敌人。四配置组装在`data/build-lab-loadouts.csv`，物件定义与数值仍由原物品表拥有。

## 记录与存储边界

本页用隔离内存库存，正式浏览器存档不加载、不保存、不删除。重开产生新的一趟，刷新清空本页训练库存与尚未下载记录；这不是正式游戏的中断损失政策。记录包含配置、实际地图编排/seed/版本/水相位、初始及最终库存、操作时钟、真实事件及结果；下载JSON保存本次观察。

`window.__suspendedSea`仅用于只读状态/记录和测试观测。验收只能通过正常键鼠动作，不能用DEV修改入口瞬移、补次、清敌人或快进水流。[迭代22 QA](../qa/iteration-22.md)区分机制检查、正常画面、有限路线诊断和用户体验判断。

## 从净化点开始的连续旅程

入口为`/suspended-sea-journey.html?resume=1`。从正式初始白板撬棍开始，实际翻找、携回、在原供奉台经历冲击成熟，再到净化点入口的备行槽装配武器与技能。每次回基地沿用原修复/供奉/潮汐规则，不在裂隙内提供换装。侧栏只在净化点允许选择下一趟的布局和种子。

- 该地址使用独立悬海纪录，刷新或关闭后续同一趟；离线不推进，不赠送收益或返还消耗。原游戏存档保留。
- 裂隙Esc打开现有场景菜单，可继续，或明确确认放弃本趟。放弃失去全部随身物、不获携回奖励，回基地结算一次既有冲击。正常死亡规则仍成立。
- 保存失败时行动冻结，画面提示“重试保存”；重试成功才继续。损坏/不匹配纪录保留并拒绝加载，当前没有坏包抢救界面。
- 净化点Tab打开存续报告；裂隙Tab仅整理拾获、世界不停。E交互、Q/F主动技能、Space挥击；真实终局后R回净化点。
- 去掉`resume=1`得到同页内存旅程，用于可丢弃的测试，关闭后结束。两种模式不能混作同一种持久性承诺。

恢复目前只为本入口的两种原生悬海布局注册，默认游戏其他旧世界未接入。实现细节及证据见[恢复记录](../design-notes/rift-interruption-recovery.md)与[迭代22 QA](../qa/iteration-22.md)。

下一步仍是第二世界/构筑与共享能力，然后四A连续供给验证，再允许四B扩产。五趟真实成熟与使用链只能证明循环接通，不能替代正常耗尽、连续失败重组及武器/技能供奉竞争的供给验证。
