## 历史样本：绘制式生命地貌（DEC-168 / R8）

[打开归档样本](http://127.0.0.1:3011/living-landmass-stage.html)。启动：`npm run dev -- --host 127.0.0.1 --port 3011 --strictPort`。

**WASD / 方向键行走，M静音。** 第一次移动解锁声音。入口沿宽坡前行，主壳两侧可以绕行并在后方合流；东侧经倒伏体旁的低洼与外坡形成第二条回环。路面是一整块自然地貌，不是拉宽的路线线条。当前0个内洞、13个观察/转折节点、14邻接段、5条节点链、2个独立回环；这些是当前布局统计，不是地形设计目标。

相机32°长焦透视、焦面跨度960，前望350，跟随行走。逻辑960×640，Three内部1920×1280 MSAA。实际3D坡面提供角色高度与身体碰撞；地表绘画按实际边界映射一次。主壳和倒伏体是固定−32°绘制景物，有独立不可走足迹与投影代理，不是可以旋转观察/攀登的完整三维物体。画中细层缘不是独立台阶。DEV机位`?camera=28|32|36`仅研究。

六张原生资产分别为`ground-atlas-r8.png`独立地表构图、`carapace-r8.png`主壳、`fallen-r8.png`倒伏体、`middle-carapace-r8.png`远处悬挑体、`vista-r8.png`最远空间及`cutface-r8.png`专用切面；石体与地表不共用纹理。前景保留铁赭沉积、矿化层片和紫灰阴面，中景同族画法，远景降低对比与细节；撤掉原晴空积云意象。资产和同名`.generation.json`保留内置imagegen的完整prompt及来源，位于`public/assets/dev/living-landmass/`。

中景悬挑画片与真实下承体围绕固定受力端缓慢变形，共用26秒声画时钟；脚下走面静止。reduced-motion停止装饰运动并保留静态底音。单一可走高程，下承体不授予通行；无敌人、搜撤、危险、战术视野或存档读写，刷新回入口。完整第二世界仍冻结。

九份vista CSV独立拥有轮廓、孔洞、区域、路线节点、连接、地层、断面、石体和绘制景物落地足迹。`node tools/living-landmass/check-vista-terrain.mjs`验证实际三角网、整身通路与边界，不以图论数字代替场景判断。实际画面、普通输入路线、音轨和限制见[QA §15](../qa/iteration-23.md)及[方向 §17](../art/living-landmass-direction.md)。完整基线与最终受影响区域复测已完成，透视角色遮挡和倒伏体触点已修正；整体美术、人的空间记忆、声音听感与真实OS失焦仍未获验收。

## 冻结：首包受力鳍面（DEC-159/160）

[打开冻结样本](http://127.0.0.1:3007/living-landmass.html)。用户已于2026-09-13否决其视觉表达；保留页面用于复盘。随后A/B/C生成静帧也被用户否决（DEC-161），不再等待选图或AI短动画。以下操作只属于旧页。此页不加入正式主菜单和构建入口；独立内存训练，不读写正式记录，刷新后不保留本趟。

点击“开始 / 中止当前并重开”。WASD移动与转向，空格挥击，按住E翻找；在入口按E撤离。Tab查看本趟拾获，世界继续；Esc暂停，结束后R返回配置。页面可选白板、近战、轻装、岸边配置，均使用已有正式物件和真实有限次数。首轮建议普通白板。

从入口往前，左侧厚脊始终可绕行；右侧鳍面有周期性受力。走到右路下端，转身观察下层承托面、连接与前方搭接硬边。普通起伏不伤人，中段夹合会伤人；可等待、绕行，或在连接绷紧时用撬棍击中近处卡结。这会消耗一次有效命中耐久，让当前支路经过传力延迟逐渐卸力；下层生命仍承托其它支路。

四处翻堆中有薪柴和污染物，远端有一只沿用正式行为的听觉虫。拾获物仍须归来供奉，不能当场装备；普通白板无需撬卡结也可经左侧搜寻并原路撤离。这里验证当地空间/动作与已有玩法能否成立，训练给装不计为持续供给。

当前范围为`living-landmass/living-borne-fin@1`、43×35格、35°固定尺度三维舞台、真实前视224/环身80。地表、足点与物件共用同一8px三角高度格；固定XY、连续Z，没有水平移动平台、跳跃或完整三维碰撞。种子影响既有掉落与外形支流，不改这张局部的布局；不以此宣称大量环境已完成。

策划入口为`data/living-landmass-{scenes,supports,tension,placements}.csv`，修改后执行`npm run codegen`和`npm run check:living-landmass`。局部设计见[内容合同](../content/living-landmass.md)，美术方向见[承重生命](../art/living-landmass-direction.md)，验证和未验项见[迭代23 QA](../qa/iteration-23.md)。
