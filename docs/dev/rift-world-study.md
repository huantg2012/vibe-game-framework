## 入口与操作

入口：`/rift-worlds.html`。世界控件从 `WORLD_PROFILES` 生成，空间控件从 `SPACE_PROFILES` 生成；两份列表独立，新增记录不需要新增世界 ID 绘制分支。控件直接读取编译后的数据。

- `world`：世界配方 ID；当前示例为 `ash-strata`、`crystal-fibre`、`ivory-basin`。
- `space`：空间配方 ID；当前示例为 `open-scars`、`fracture-fields`。旧 `topology=loops|channels` 保留为这两项的兼容别名，不再代表旧环岛/平行长带算法。
- `seed=0..4294967295`、`view=overview|walk`、`field=1|0`。默认步行并开启视野；关闭遮蔽仅供检查材料。URL解析、两份空间切换以及切换材料保留地形/位置已过浏览器验证。
- 数字键切世界；R 换种子；顶部可输入种子和选择空间。相同 seed 与空间参数保持同一几何，便于比较材料组合。
- WASD / 方向键移动；Space 回到角色；拖拽观察，滚轮缩放。基础移动复用正式常量：80px/s、起步0.08s、停步0.10s，斜向归一化；Shift没有加速。默认步行镜头1.5倍。未模拟负重/混乱等速度修正。

原版角色32帧不变。空洞是缺失空间：不透明纯黑、不可通行、遮挡视线，没有受光顶面或立面。材质浅浮雕属于可跨过的陆地表面，不新增实体阻挡类型。

样板使用 `fieldVisibilityAt` 与32级强度，并用本图连续形状裁剪视线，尚未接入完整生产 `VisibilitySystem`。当前照明仍按四向角色方向驱动；正式玩法的八向目标与连续转向未迁入。正式视野的侧向射程收缩、暖色加法灯光合成以及混乱/技能修正也未完整对齐。本轮只改地图构型和地表层次，不把这些差异写成已经修复。

## 空间生成能力

`data/rift-world-spaces.csv` → `tools/map-preview/codegen-world-spaces.mjs` → `src/generated/rift-world-space-data.ts` → `space-profile.ts`。

`SpaceProfile` 独立控制：

- `voidFraction`：局部侵蚀占原始支撑陆地的面积目标。
- `crackFraction`：短裂口相对团状蚀坑的候选比例。
- `holeScale`：空洞尺寸倍率。
- `directionality`：局部裂口沿共同方向组织的程度。
- `clustering`：侵蚀的空间聚集程度；高值从有界侵蚀盆地内取样，避免排斥间距把候选重新摊匀。

合法输入范围由 `SPACE_LIMITS` 与 `validateSpaceProfile` 定义；字段必须改变可观测几何，不能仅改变随机散列。单字段合法也不承诺所有联合参数一定能通过空间质量要求。

`layout.ts` 保留 `generateWorldSample(profileOrId, topologyId, seed)`，并接收可选第四参 `SpaceProfile`。第一参可直接传未命名组合的 `WorldProfile` 对象；显式空间参数确定几何时，旧拓扑别名不参与重新选算法。输出继续保留 `land`、`walls`、`formations`、出生/出口、流向及沉积字段，渲染和碰撞接口不变。

生成从连续宽地面出发，由 `open-space.ts` 添加局部侵蚀。尺度、裂口占比、方向及聚集来自通用参数；没有按世界 ID、特定 seed 或截图坐标修洞。原四条平行长裂带已移除。

`space-quality.ts` 在运行时检查全地面连通、宽地面比例、多方向开放区域、内陆局部窗口、宽通行核心连通及双轴横穿、空洞夹出的长通道，并对出生→出口宽路径以共享 `shape.ts` 进行半径6、九探针、2px间隔的连续扫掠。海岸的单侧窄边不直接算成内部夹道。质量失败在同参数、同种子的确定性随机支流内有界重抽；当前上限由 `MAX_SPACE_ATTEMPTS` 定义为12，仍失败则明确拒绝，不退回某张特定种子的预制图。

## 通用材料层

`data/rift-world-profiles.csv` → `tools/map-preview/codegen-world-profiles.mjs` → `src/generated/rift-world-profile-data.ts`。世界记录提供色板及 `SurfaceRecipe`，名称和 ID 用于选择/展示，不决定绘制算法。旧 `material` 字段保留兼容，绘制由 `surface.substrate/coating` 决定。

`SurfaceRecipe` 包含 `substrate`、`coating`、`coverage`、`wear`、`deposits`、`scale`、`relief`、`contrast`：底材与覆盖材料各自选择层岩、晶体或釉三种绘制基元，其余参数调节覆盖、磨损露底、沉积、尺度、浅浮雕和明暗强度。基元可作为底材或覆盖层交叉组合；三份具名世界只是数据样本。新增已有能力内的组合修改 CSV 并验证即可；新增基元仍需实现和验收。

- `material-field.ts`：读取布局的沉积历史与流向。
- `surface-field.ts`：生成覆盖、磨损、沉积、露底与方向场；各过程使用独立信号，又通过露底和边缘响应发生关联，不再全部共用一条浓淡分布。
- `ground-material.ts`：底材→覆盖→磨损露底→薄层接触边→沉积与碎屑。两种材料共享通用组合流程。
- `material-forms.ts`：局部层片、晶簇和釉片在受支持地面取样，扩展到宽阔地面内部；仍受覆盖/磨损/沉积控制，不靠沿每个洞口重复摆装饰。
- `surface.ts` / `shape.ts`：静态烘焙、可见轮廓与碰撞共享形状；最终所有空洞像素回写纯黑。
- `material-response.ts` / `material-light.ts`：记录所绘材料的反射点并按灯的位置响应，最后经过同一视野遮罩。后绘碎屑和形体按实际写入移除被覆盖的旧反射，同色覆盖也生效。没有新增光源或照亮洞内。
- `src/entities/player-sprite-dense.ts` / `movement.ts`：正式角色同源像素和基础启停数学，环境配方不能换色角色或改速度。

## 上批反馈与落地记录

2026-09-17 的四条反馈均已落实：恢复正式角色；将原石板障碍改为空洞；晶体有独立切面和外轮廓；地面加入三尺度材料场及局部碎片。釉原保留亮釉色调并增加开片与剥落；灰层加强定向沉积；晶化床用埋入地表的碎面和低矮晶簇。形体均在陆地，空洞内部不绘立面或材质。
