# 世界观设定

## 一句话基调

一切已经结束了。剩下的只是还没停止运转的残骸，和一个拒绝熄灭的光点。

## 世界状态概述

灾变没有过程。没有预兆、抵抗、失败的记录。对这个时空的居民而言，污染从"不存在"到"已经完成"之间没有中间态。星球表面被彻底改写——物质结构、因果律、空间拓扑全部被外来模式覆盖。原有的一切（文明、生态、物理常数）只作为被覆盖层的残影存在。

时空本身在灾变中碎裂。本时空与无数其他被污染的时空之间产生了不稳定的连接（裂隙）。每个时空都被不同的污染源改写，彼此的污染模式互不兼容。

在本时空的污染覆盖中，存在一个异常——一个极小范围内污染未能完全渗透的区域。这就是净化点。原因不明。它不在扩大，只在被缓慢侵蚀。

## 核心设定规则（影响机制）

- **污染是改写，不是破坏**：外来存在不"摧毁"事物，而是用自身的模式"覆盖"现实。被污染的区域仍在运作，只是运作方式不再属于原来的物理法则。 → 机制影响：污染体不是"损坏的东西"，而是"按另一套规则正常运作的东西"。它们有稳定的行为模式（AI巡逻/感知），不是随机疯狂的怪物。
- **不同污染源互相排斥**：每个外来存在的改写模式是排他的。当两种模式接触时互相干扰、抵消。一种污染的残留物对另一种污染有天然的抵抗性。 → 机制影响：薪柴（其他时空的污染残渣）能抵抗本时空的污染。这是净化点防御系统的物理基础。
- **裂隙是碎裂的伤口，不是门**：裂隙不是被制造的通道，是时空结构破损后的自然渗漏。它们不稳定、临时、不可控制。 → 机制影响：玩家不能选择目的地，裂隙通向哪里是随机/程序化的。撤离点的位置也不固定。
- **混乱是异时空的污染渗透**：进入其他时空意味着暴露在该时空的污染模式下。停留越久，外来模式对玩家的渗透越深。 → 机制影响：混乱值随时间增长是物理过程，不是诅咒或惩罚。超阈值后的效果（视野缩小、移速降低）是外来模式开始覆盖玩家自身的表现。
- **净化点的存续需要持续输入**：净化点不是自持的。它在被本时空的污染缓慢侵蚀，需要外来的对抗性物质（薪柴）来维持边界。 → 机制影响：冲击系统存在的理由——不是敌人来攻击，是本时空的污染在持续压迫净化点边界。薪柴分配到模块 = 用异源污染加固各处边界。

## 时空结构

### 多时空的运作模型

每个时空碎片是一个独立的"被改写区域"，由不同的外来存在（污染源）各自覆盖。它们之间的关系：

- **互不通信**：各时空的污染源之间没有协作或意识到彼此的关系。
- **模式冲突**：两种改写模式在接触界面产生干涉。这种干涉不会消灭任何一方，但会在交界处产生"两边都不是"的残渣。
- **裂隙成因**：时空碎裂后的结构性不稳定。裂隙在净化点附近出现频率更高（待验证假设：可能因为净化点的"未被完全覆盖"状态在结构上是薄弱点）。

### 为什么薪柴有效

薪柴 = 两种污染模式冲突后的残渣。它携带一种模式对另一种模式的"否定性"。当薪柴被投入净化点边界时，其携带的否定性能短暂抵消本时空污染的推进。

这解释了：
- 为什么要去别的时空取：本时空的污染残渣对本时空的污染无效（同源不冲突）。
- 为什么薪柴会被消耗：否定性在对抗过程中耗尽。
- 为什么不同裂隙的薪柴等价：虽来自不同污染源，但对本时空污染的否定性在数值上可归一化处理（游戏简化：一种货币，不区分来源）。

## 玩家身份

玩家没有名字、没有背景故事、没有被选中的叙事。

**已知事实**：
- 玩家存在于净化点内——这意味着他们没有被完全覆盖。
- 玩家能穿越裂隙并在异时空短暂存活——这意味着他们对污染有高于零的基础抗性。
- 玩家穿越裂隙后会累积混乱值——这意味着抗性是有限的、可被消耗的。
- 玩家回到净化点后混乱值会清除——这意味着净化点的环境能"重置"外来模式的渗透。

**不解释的部分**（设计决策：保持空白）：
- 为什么玩家有抗性。
- 净化点为什么存在。
- 玩家是否是唯一的幸存者。
- 灾变前的世界是什么样的。

**对玩家的叙事定位**：不是英雄、不是救世主。是一个在维持生存的个体。动机是"继续存在"，不是"拯救世界"。世界已经不存在了。

## 污染体分类方向

污染体是被外来模式覆盖的"原有存在"。它们按覆盖程度和原有基体分为以下方向（用于美术风格区分和敌人行为设计）：

### 按覆盖程度分级

| 等级 | 名称 | 视觉特征 | 行为特征 |
| ---- | ---- | -------- | -------- |
| 低度 | 渗透体 | 原有形态基本可辨，表面有异常纹理/生长物 | 保留原有行为模式的残余，动作僵硬或不协调 |
| 中度 | 改写体 | 原有形态与外来结构各半，几何失调 | 新旧行为模式混合，不可预测的切换 |
| 高度 | 覆盖体 | 原有形态几乎不可辨，完全按外来模式重构 | 行为完全服从外来逻辑，稳定但非人类可理解 |

### 按原有基体分类（影响体型和移动方式）

- **有机基体**：原为生物体。覆盖后保留运动能力但运动方式异变。
- **无机基体**：原为建筑/地形/物体。覆盖后可能获得自主性。通常体积大、移动慢或不移动。
- **概念基体**：原为非物质存在（声音、光线、空间关系）。覆盖后成为环境型危险而非实体敌人。

### 对内容设计的约束

- 每个具体时空的污染体应有统一的视觉"模式"（该时空的污染源特征）。
- 同一时空内不同污染体的差异来自"基体"不同，不是"污染"不同。
- MVP 阶段只需一种时空风格的污染体（程序化地图共用一套视觉主题）。

## 空间结构

### 净化点（玩家据点）

- 物理上是一个小范围区域，被污染包围。
- 内部划分功能模块——每个模块对应一种"维持生存"的功能。
- 视觉上应与外界有明确的边界感（内侧：有序/暗淡但可辨认；外侧：被改写的混沌）。
- 氛围：不是安全的天堂，是一个随时可能熄灭的微弱光源。安静、空旷、功能性。

### 裂隙内部（出击区域）

- 每次进入裂隙 = 进入一个其他时空的碎片。
- 空间结构不遵循常规建筑逻辑（房间和走廊存在，但比例、连接方式、重力方向可以不正常）。
- 程序化生成的依据：时空碎片本身是不稳定的片段，没有理由保持完整的空间一致性。
- 环境中有可辨认的"原有事物残影"被污染模式包裹/穿透。

### 空间的层级关系

```
本时空（完全被污染覆盖）
  └── 净化点（微小未覆盖区域）
        └── 裂隙入口（在净化点边界附近产生）
              └── 异时空碎片（另一个完全被覆盖的时空的局部片段）
```

## 术语表

| 游戏术语 | 含义 | 使用场景 |
| -------- | ---- | -------- |
| 净化点 | 玩家的据点。唯一未被完全覆盖的区域 | UI（基地界面标题）、系统名 |
| 裂隙 | 时空碎裂产生的不稳定通道。连接到异时空 | UI（出击入口）、系统名 |
| 薪柴 | 异源污染冲突的残渣。通用资源/货币 | UI（资源显示）、系统名 |
| 混乱值 | 玩家在异时空累积的外来污染渗透程度 | UI（状态条）、系统名 |
| 污染体 | 被外来模式覆盖的存在。敌人的统称 | UI（图鉴/提示）、内容设计 |
| 冲击 | 本时空污染对净化点边界的周期性压迫 | UI（冲击预警/结算界面）、系统名 |
| 模块 | 净化点内的功能分区 | UI（分配界面） |
| 撤离点 | 裂隙内供玩家返回净化点的出口位置 | UI（地图标记） |
| 覆盖 | 外来模式替换原有现实的过程 | 叙事文本、描述文本 |
| 渗透 | 覆盖的早期/轻微阶段 | 叙事文本、混乱值相关提示 |

## 对美术的约束

### 材质倾向

- **净化点**：金属、混凝土、功能性工业材质。磨损但有人维护的痕迹。灯光微弱但存在。
- **裂隙内部**：有机与无机的强制融合。原有材质（砖墙/木头/土壤）被异常纹理穿透或包裹。表面可能有不属于原材质的光泽/脉动/几何图案。
- **污染体**：基体材质被外来模式"升级"——保留原始轮廓但材质属性异变（软变硬、不透明变半透明、静止变脉动）。

### 色彩倾向

- **净化点**：低饱和、偏冷灰。唯一的暖色是功能性光源（灯/火/能量指示）。整体暗但不黑。
- **裂隙环境**：以该时空污染源的"主题色"为主调。主题色应该是不自然的、刺眼的或者反常的（比如在本应黑暗的地方有过度饱和的颜色渗出）。
- **污染体**：与所在时空环境同色系，但在关键部位（感知器官/核心/接缝处）有高对比的发光/颜色。
- **整体原则**：黑暗是底色，颜色是入侵——有颜色的地方就是被污染的地方。净化点的"干净"体现为颜色的缺席。

### 视觉禁忌

无硬性禁忌。以下为风格偏好（非强制）：
- 偏好几何异变 > 生物恶心（不追求内脏/血浆/虫卵式的恐怖）
- 偏好"错误的秩序" > "混乱无序"（污染体有自己的规律，只是不是人类的规律）
- 偏好暗示 > 展示（看不清比看清更有效）

### 氛围关键词

净化点：孤立、微光、功能性、空旷、安静、勉强维持
裂隙内部：窒息、不适、错位、监视感、危险的美感
污染体：异质秩序、不可理解的合理、无表情的威胁

## 对机制的约束

### 允许

- 薪柴作为唯一通用货币的简化（世界观支持：所有异源残渣的否定性可归一化）
- 混乱值回到净化点后清零（世界观支持：净化点环境能重置外来渗透）
- 污染体有稳定可学习的行为模式（世界观支持：覆盖后的存在按新规则"正常运作"）
- 净化点分模块受损（世界观支持：边界不同区段抵抗力可独立变化）
- 程序化生成的关卡不需要空间逻辑一致性（世界观支持：异时空碎片本身是不完整的片段）

### 禁止

- 玩家不应获得"净化"或"治愈"污染的能力（世界观规则：覆盖不可逆。只能用另一种污染对抗）
- 不存在"安全区域"的持续扩大机制（世界观规则：净化点只能维持，不能扩张。扩张意味着需要指数增长的薪柴投入，不经济）——当前阶段约束，未来可能被打破
- 不存在与污染体交流/招降的可能（世界观规则：被完全覆盖的存在不保留原有意识。它们不是"被控制的人"，是"看起来像人的另一种东西"）——当前阶段约束，未来可能被打破
- 混乱值不能通过裂隙内的任何手段降低（世界观规则：身处异时空 = 持续暴露。没有"异时空内的净化手段"这种东西）

### 叙事理由备忘

- **为什么要出击而不是躲着**：净化点在被侵蚀。不出击获取薪柴 = 等死。
- **为什么不能长期待在裂隙里**：混乱值。异时空的污染最终会覆盖玩家。
- **为什么冲击会越来越强**：本时空的污染在持续渗透。净化点的存在对周围污染来说是一个"异常"，它会被逐步修正。（待验证假设：是否需要在游戏内向玩家传达这一点）
- **为什么薪柴会被消耗**：否定性在对抗中耗尽。防御不是建墙，是持续烧燃料。

## 叙事语调（约束所有游戏内文本）

本章节定义游戏中所有面向玩家的文本的写作规则。

- **语气**：冷峻克制。陈述事实，不渲染情绪。干燥、简短、精确。像设备日志或现场勘察报告，不像小说。
- **人称**：无人称或旁白体。不使用"你"。描述事物状态，不描述玩家感受。
- **时态**：现在时。
- **单条文本长度**：
  - tooltip/简述：不超过 15 字
  - 详细描述：不超过 40 字
  - 教学提示：不超过 25 字
- **禁忌**：
  - 禁止诗意化/文学化措辞（不写"黑暗吞噬了一切"，写"全域覆盖已完成"）
  - 禁止打破第四面墙
  - 禁止现代俚语/网络用语
  - 禁止感叹号
  - 禁止修辞性疑问
- **命名风格**：
  - 物品命名规则：功能描述式，中文直译风格。如"干扰发生器"、"感知屏蔽剂"，而非"混沌之眼"、"寂灭符"。
  - 敌人命名规则：[覆盖程度/行为特征] + [基体类型]。如"巡视渗透体"、"固定覆盖体"，而非"暗影猎手"、"深渊守望者"。
  - 地点命名规则：[状态/特征] + [原有空间类型]。如"坍缩走廊"、"过饱和储藏区"，而非"永夜回廊"、"深渊之心"。
- **示例**（标杆语感）：
  - 好的物品描述：`异源残渣压缩物。燃烧时释放否定性。` （薪柴的描述）
  - 好的敌人描述：`有机基体，中度覆盖。视觉感知范围约 6 米，巡逻路径固定。`
  - 好的环境提示：`前方区域污染密度上升。建议绕行。`
  - 好的冲击预警：`边界压力上升。预计冲击强度：高。东侧模块承压集中。`

## 待验证假设

- [ ] 裂隙在净化点附近高频出现的原因是否需要向玩家解释（当前倾向：不解释，当作"就是这样"）
- [ ] 冲击强度递增是否需要叙事理由的游戏内呈现（当前设定有理由，但是否做成可见文本待定）
- [ ] 是否需要暗示"其他幸存者"的存在来丰富世界感（当前倾向：不需要，孤独感是体验支柱）
- [ ] 异时空的"主题"多样性上限——MVP 一种主题，后续需要几种才不重复（内容 Slice 时决定）
- [ ] 概念基体的污染体（环境型危险）是否纳入 MVP（当前倾向：不纳入，优先实体敌人）
