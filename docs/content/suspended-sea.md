# 悬海：首个完整出击内容合同

> **TL;DR**：两种海床编排围绕同一个可观察关系组织搜撤：上方汇流落入贴地壳面，合拢的壳片将水挤向岸道；玩家能等待、绕行，或用撬棍错开薄唇，让侧溢沿退水沟流入天井。垂直落水不受这次操作关闭。四种配置使用现有五族技能，掉落采用来源明确的既有物件；通过实际操作证明不同路线与携带成本。

## 1. 已锁定、实施边界与待验证项

已锁定：

- 悬海是首包方向；固定35°三维像素舞台及当前人物尺度继续，正俯视冻结。
- `RiftScene`是唯一游玩模拟，正式移动、有限视野、攻击、受伤、翻找、装备消费及撤离照常工作。隔离记录不写玩家长期存档。
- 开敞天井不可跨越但允许视线穿过；实际可见空气揭开海层，记忆不能凭空穿透海体。海面的自然开口不改变脚下通行。
- 两种布局、至少一个当地危险源、正式拾获、音景、简短入场；不扩武器种类、全敌人目录或新技能库。
- 先完成此包，再接基地获得→供奉→再装配。长期记录前解决中断政策。阶段四A持续供给验证仍未开始，四B仍锁定。

Director已采纳本次实施方向：可击偏的壳片、共用正式撬棍命中预算、既有技能不默认控制海、第四配置组合现有能力。以下尺寸、时间和收益是可回归的首轮数据，不冒充用户对最终体验的通过。

待验证：玩家能否从壳片与退水沟读出改流；600ms余水能否看清；满载时短路是否仍值得走；四配置的实际成本是否拉开。失败时先改局部几何、预兆或来源，不用追加物件掩盖问题。

## 2. 这个世界的局部关系

海水的原生承载方向与玩家熟悉的方向不同。海床上方维持着有厚度的水体，海床仍保存沉积、冲刷和分流留下的低矮结构。污染覆盖后，局部水量周期性汇向少数位置，脱离海体落下；壳片在水压中合拢，侧向排水反复冲刷同一段岸道。

陌生的是水体与空间的关系；可以学习的是局部因果。玩家应能按顺序看见汇流、下落、接地、侧溢、断供、尾水、排空。不能把整片海解释成可被玩家关闭的机关，也不需要说明污染源的意志。

现有低污染虫仍是裂口带来的外来污染体：一只听觉型、一只视线型。保留当前实际形态，不改名冒充当地物种。壳片与水流承担本地危险身份；它不是第三种AI，也没有假血条或杀死整片海的奖励。

视觉与音景的规格由Art在[悬海美术合同](../art/suspended-sea-direction.md)补齐；本文件只锁定画面必须讲清的物理关系、状态和信息。

## 3. 两种布局与完整一趟

两图使用约57×35格（32世界px/格）的同级别空间预算；若尺寸调整，必须保持人物尺度与取景边界，不能缩人把全图塞入镜头。出击只有一个撤离点，位于本次进入的安全岸；不是做两个出口。

### A · 开阔潮沟（`sea-open-channel`）

入口在西南低岸。沿西岸到安全观察面，可从侧面看见一轮完整落水及朝中央低道的侧溢。低道连接近岸与远岸，是短路线；退水沟直接通往相邻天井，薄唇可从干地敲到。北侧高岸形成始终可走的旁路，不是必须打壳片才能开的门。

路线骨架：入口 → 近岸薪柴 → 观察面 →〔等水/错开薄唇走低道，或沿北岸绕行〕→ 外来残堆与听觉虫 → 远岸可选沉积物 → 视线虫所在回岸 → 原入口撤离。地图能成环；不要直接镜像M的两个空洞加一条南侧落水。

- 主要判断是“这轮水能不能过，还是现在绕路”。观察面距离最大侧溢边界至少一具完整身体加16px，能原地转向观察而不被无声擦中。
- 低道上被侧溢截住的沿行走方向长度不超过96px；完整身体走过后有至少64×64px干地落脚。
- 旁路比短路多约240–400px可走路程，首轮目标是多花约4–7秒正常行走；实际应按真身体路径与负重测量，不按地图直线算。
- 听觉虫巡逻在可选残堆附近，不能在最初观察面自动发现玩家；击壳声可能引来它。回声空壳必须能落在一处干地岔口并令它朝真实落点调查。
- 视线虫只控制一段可选收益/回岸视线；在它经过时停留或绕开有普通解法，不能把唯一出口变成必打房。

### B · 折返岸脊（`sea-folded-ridge`）

入口在南侧裂开的岸脊。近路沿中央低鞍部折回，远路绕过一段向北伸出的脊端。玩家从斜对岸先看见远处残堆和退水去向，再在折返处找到可击薄唇。主体是“出发时能走的低道，装载后返程还要重新判断”，不是A的镜像。

路线骨架：入口 → 近岸薪柴 → 西侧干脊与听觉虫 → 上游观察台 → 远端两处收益 →〔等待/敲开低鞍部回程，或绕脊端走长岸〕→ 下游可选残堆 → 原入口撤离。

- 短路与旁路从远端观察点同时可理解；完整危险不能同时切断两条路。
- 低道受水长度仍不超过96px，旁路额外路程约320–480px。不能把折返设计成只容单体的窄桥加卡位敌人。
- 视线虫在远端收益处提供朝向判断；听觉虫与第一张的位置职责错开，在返程相邻岸段能对敲壳/翻找声作真实反应。
- 从远端满载返回时必须再经过同一真实周期，不能收完物资后自动停水。已错开只保持本轮，不是永久解锁捷径。

### 两图共同的空间与节奏硬约束

- 干地站位到薄唇命中点24–32px；撬棍正式距离40px、120°，不扩大攻击范围迁就场景。此站位不在落水核心或侧溢内。
- 壳片是海床嵌入结构，主体齐地、薄唇最高约8世界px，不新增WALL/独立阻行体/视线遮挡。真正阻止跨越的是原天井。图像不能画成胸高箱体再让玩家穿过。
- 所有翻堆脚底与全部可领取地面物在真实FLOOR上，搜索半径48px、按E 1200ms照旧。危险边界外给一处可完成整理的干地，但整理不暂停也不免敌人发现。
- 将所有可能活动的水接触区按真实身体占地扩张后移除，入口、旁路、可安全放弃收益后的回程仍连通；最大负重和高混乱最低速度下也不能困死。
- 路径必须按碰撞后的连续足迹核对；不能只用格心连通宣称玩家能过。
- 首轮熟悉路线目标约90–150秒，首次观察约2–4分钟；是此有限首包的诊断窗口，不改全游戏出击时长目标，也不用硬倒计时逼回程。

## 4. 当地可交互危险：合拢的壳片

内容ID为`folding-shell`，玩家可见描述用“合拢的壳片”。每图一处。它承受从海落下的水，原有薄片沿折线受压合拢；撬棍把薄片击偏，卸压后原片慢慢回摆。不是打碎、下轮无因重生。

### 自然时钟

沿用已验证水的起始参数，数据最终进入本世界CSV：

| 字段 | 首轮值 | 含义 |
| --- | ---: | --- |
| `quiet_ms` | 4400 | 无供水的静息段 |
| `warning_ms` | 1900 | 汇流与前缘下落 |
| `active_ms` | 2500 | 持续供水段 |
| `retract_ms` | 1700 | 断供和尾水下落，不表现为水倒吸 |
| `fall_travel_ms` | 780 | 源口至地面的飞行时间 |
| `contact_extension` | 0.96 | 现有接触窗的阈值 |
| `damage` | 12 | 一次实际水接触生命伤害 |
| `hit_interval_ms` | 800 | 尝试伤害的间隔，仍经过玩家无敌窗 |
| `divert_ms` | 600 | 命中到侧溢余水排尽的时间 |
| `return_ms` | 650 | 最后水落地后原壳片回摆的时间 |

实际接地起止用`WaterFlowCycle.contactStart/contactEnd`；它与现有`sampleWaterCurtain`的逆smoothstep阈值是同一规则。不能把`warning_ms`结束错误当作第一次接地，也不能把停止供水当作立刻无害。

### 近战、改流与恢复

1. 一个壳片实例在每轮**`[warningStart, contactEnd)`**内、尚未错开时，进入近战合法目标集。静息、已错开、回摆和排空后均不接受新有效命中。
2. 使用正式`CombatSystem.registerMeleeTargets`。与虫体一起按同一挥击弧、视线、按弧先后、最多两个目标、首次有效命中先保存扣1耐久，再施加效果。环境不得成为免费第三目标。目标不伪装AI，不发`ENEMY_DAMAGED/ENEMY_KILLED`，不掉击杀薪柴；击中仍发正式命中声、击停与160px警觉噪声。
3. 不设HP或累计伤害门槛。任意正伤害的合法撬棍命中即可错开一次；更高品质不改变此结构的操作方式。未击中、射程/实墙阻挡、时窗外、已错开不扣耐久。保存失败不改壳片、不关危险；末点耐久仍完成该次错开及整挥恢复。
4. 命中时刻记为`hitAt`。在**自然已接地**的前提下，`[hitAt, hitAt+600ms)`仍保持原侧溢完整危险，水流可以开始转向，但不能用变淡画面暗示已安全；旧湿边与余水仍盖住危险区。达到600ms后，侧溢接触区关闭，流向天井的排水继续可见。汇流早期还未接地时，即使壳片已处于`diverting`，也不能提前画地面危险或判伤；图形必须同时读`spillActive`。**垂直落水核心在整个过程中保持原有伤害窗。**
5. 命中不重置、延后或快进自然周期。若600ms尚未走完自然水已排空，危险随自然排空结束；不会因改流补一次伤害。接地终点精确瞬时已不能命中，也不能吞掉1耐久。
6. 本轮`contactEnd`到达后，壳片沿原折线在650ms内回摆。回摆本身没有伤害；下一轮只有完成原有汇流与飞行预兆后才再次侧溢。不得复位即开伤。
7. 核心和侧溢是同一处水源的两个命中区，重叠只算一次伤害尝试，共用一个间隔。接触采用唯一权威当帧多边形；动效、湿边和伤害读同一状态，不能渲染小一圈、暗中伤大一圈。
8. 暂停、结束、销毁按正式生命周期：先准备本帧时钟与目标资格，再解算Combat，最后根据实际命中后的状态结算水接触；不会在同帧用上一帧资格扣耐久。暂停和结束冻结，重开清掉旧壳片、旧危险和目标注册。

### 可以影响什么

- 直接命中只改变贴地薄唇及侧溢去向；海体、自然开口、飞行前沿、落水核心、地面碰撞不变。
- 退水沟的终点在真实天井内；沿沟的水不是新增可走桥、踏脚板或可拾物。导走图形必须与剩余核心水连着，不能只删掉一块伤害蒙层。
- 首包不把水变成敌人：它没有寻敌、听觉、移动、眩晕、诱饵调查或战斗死亡。不支持技能应保持失败免费或只影响真正合格对象。

品质权重仍用`contaminant-loot.csv`的safe/contested/deep：60/25/12/3、40/35/20/5、20/35/32/13。撬棍副掉落在允许节点沿用`weapon-loot.csv`，第一把发现保障仍由原`weapon-first-discovery.csv`决定，但**来源不允许武器的节点不能被保障越权塞入武器**。本批不提高品质、成熟速度或次数来弥补收益不足。

薪柴仍是异源模式冲突的残渣。所谓近岸沉积来源，指外来残留被水冲到局部接界后的积存，不把普通海水或任意石头都改成可燃资源。三个节点均需有少量异源夹入物的痕迹；反复落水不生产新薪柴。

首轮理论全收薪柴7（既有储藏倍率另记），污染物8.0重；每把实际副掉落武器再加真实2.7/3.0/3.3重。白板可带回较多物件；9.0装备配置全取污染物已达17.0，必有取舍。轻装7.0可容4件污染物到15.0，额外武器会触发取舍。以上是容量关系，不是掉落保证；只按最终实际携回计收益。

开包不暂停。不得将地面已揭晓物强行删掉；留、换、丢、再取都保留实例与来源。壳片操控不掉资源，循环水不刷节点，不会形成无成本原地刷供给。

## 7. 数据schema与种子合同（CSV → 生成 → 校验）

这是需新增的内容数据，不允许在TS手写这两张图再反导CSV。沿用既有空间样板管线扩展所需字段，不建立通用流体/维度引擎。

### 文件与字段

1. **`data/suspended-sea-scenes.csv`**：`id,name,world_id,recipe_version,cols,rows,floors,walls,voids,spawn,extract,sea_front_y,sea_bottom_height,sea_top_height,reef_col,reef_row,reef_height`。两行id分别为`sea-open-channel`、`sea-folded-ridge`；world_id固定`suspended-sea`，version首版1。坐标与矩形语法沿现有SpatialFixtureDefinition。未使用的reef须有明确空值支持，不能为了满足旧字段塞入一根库房石柱。
2. **`data/suspended-sea-ground.csv`**：`scene_id,id,kind,x,y,radius_x,radius_y,angle,height`。kind沿现有GroundHeightField；内容为低沉积面/退水沟/少量岸脊，不复用library名称或以凸起木板冒充海床。
3. **`data/suspended-sea-openings.csv`**：`scene_id,id,x,y,radius_x,radius_y,drift_x,drift_y,phase,angle`。自然海孔沿现有模型；与足下天井分离。
4. **`data/suspended-sea-water.csv`**：`scene_id,id,x,y,width,depth,outline,spill_outline,drain_path,quiet_ms,warning_ms,active_ms,retract_ms,damage,hit_interval_ms,contact_extension,fall_travel_ms,shell_x,shell_y,shell_hit_x,shell_hit_y,divert_ms,return_ms`。每图一行；outline是核心接触多边形，spill_outline是闭合壳片造成的额外侧溢多边形，均用相对x/y的`x:y|…`语法。drain_path为相同基准的泄水折线，终点进天井；shell坐标为世界px，hit点在低矮薄唇。两多边形可接界/局部交叠，共用伤害计时。width/depth只界定包围/显示尺度，不另拿椭圆做隐藏判伤。
5. **`data/suspended-sea-placements.csv`**：`scene_id,id,kind,col,row,tier,loot_pool_id,allow_weapon,substrate,coverage,motion,sense,rhythm,contact,facing,patrol,variant_group,variant`。kind只允许enemy/kindling/contaminant；loot_pool仅污染物节点用；allow_weapon仅薪柴节点用。敌人两种仍固定`insect_remnant/infiltrate/monolith/jia/floor`及现有合法词素，恰好1只sense_hear映射rewriter、1只sense_cone映射infiltrator。不得放开未做的污染档。
6. **`data/contaminant-sources.csv`**：`pool_id,type,weight`。只登记上面的7行来源权重；必须是活跃族、正有限权重、同pool+type不重复、池不为空。默认未指定池的旧地图保持13族等概率，不反向改变旧掉落。
7. **`data/build-lab-loadouts.csv`**增加`shore`一行：普通撬棍、kindle、stitch、muffle，pair=`light`；名字“稳步绕行”。Stage新世界入口允许bare/melee/light/shore，旧M入口支持范围可原样保留。

### 有限变化与登记

- 两种布局是两份拓扑编排，不是种子换颜色。每种布局内部至少提供一个真实内容变体组：听觉巡逻端点与邻近外来残堆成对变化，保持同样普通解法；不得让种子只改变海面噪声。
- `variant_group`相同的行作为一个原子选择；`variant`从明确整数0开始。用`mix32(seed,'suspended-sea:'+sceneId+':placement:'+group)`独立选择，同组所有关联行使用同一变体，不把敌人与其配套路线拆散抽。空group为固定行。
- 水相位可按另一个种子支流选择0/600/1200/1800ms相位偏移；它不改变持续时间和安全旁路。入场镜头冻结模拟，正式接管的第一帧开始计此相位。若偏移会使出生可视近处突然已伤人，必须有安全距离而不能靠出生无敌掩盖。
- 地图形状、种子、配方版本、所选variant、危险初始相位、来源池、装备授予、firstWeaponDiscovered状态均写入本趟记录。掉落继续独立fork族/品质，不被战斗、渲染、开包顺序推进。
- 进入前要求完整注册：world ID、scene ID、实际海床材质、翻堆、危险、敌人支持、音景、数据版本。不能继续把完整悬海报成`frag-library`或查不到时回退旧图书馆。

### 对齐已落盘的运行时类型

窄接口正文为`src/worlds/suspended-sea/types.ts`，CSV适配时一次性转换坐标，不让渲染器重复解析或拥有计时：

- `ShellDefinition.position`映射`shell_hit_x/shell_hit_y`，是实际命中点；`shell_x/shell_y`另供低矮结构的显示锚点，不混用。`spillOutline`、`drainPath`为CSV相对坐标加水源x/y后的绝对世界坐标。`divert_ms`→`diversionDelayMs`，`return_ms`→`returnMs`；伤害/间隔沿同一水源值。
- `ShellCycleTiming`的`periodMs,warningStartMs,contactStartMs,contactEndMs`派生自同一自然水定义，不能单独再填一张冲突的时间表。
- `ShellView`只借读`mode: closed/diverting/diverted/returning`、`canHit`、`spillActive`、两进度、真实`hitSequence/hitAtMs`及尝试/落地伤害计数。正常自然阶段仍由水帧提供，不另造“猜测受击”。异步记录必须复制。
- 壳片与核心用玩家同一世界位置判接触，沿当前水对玩家中心的合同，不借此次内容变更扩大为身体外接矩形。地图安全性校验仍要为完整身体留下通行余量；这是布点保守量，不是另一个隐藏伤害范围。
- `SeaEntryView`仅描述入场显示；暂停/结束与正式模拟接管由场景拥有，不让镜头组件自行修改游戏时间。

## 8. 系统接口变更建议与实现清单

这些建议由Code/Director落实到已有系统spec；Design本次不直接改其他spec、CSV或src。

- **地图/场景**：现`SpatialSliceData`可承接scene/ground/openings和单水源。新增字段全部显式注入；旧local与M默认保持。扩展node定义的可选`lootPoolId`/`allowWeapon`，新世界必须显式提供，旧图缺省沿旧规则。世界身份与fragment视觉来源分清，首包能注册而不自动进入长期存档的正式随机池。
- **战斗**：复用`MeleeTarget`与`registerMeleeTargets/unregisterMeleeTargets`。向DEV runtime context开放窄注册接口；新增本帧战斗前准备钩子仅刷新环境时钟/目标资格，不提前判伤。shell的`isAlive`表示实例存续；`canHit`决定当前合法性，错开不以死亡冒充。消费失败、末次、同挥2目标沿原链。
- **环境状态**：world拥有壳片姿态、hitAt、divertReadyAt、复位进度及核心/侧溢接触区。显示只借读；beforeCombat准备→Combat真实命中→advance接触→presentation，同一elapsed不得重复推进。水命中沿`applyHazardHit('environment:'+id,12)`，PLAYER_DAMAGED/完整度/无敌窗/死亡/附着空壳均使用现有链。
- **工具**：不注册shell为ToolSystem的敌人或Host，不让范围控制碰巧控水。shore沿五件已支持展示，无新技能分支。
- **拾获**：`rollContaminantNodeDrop`接可选poolId，并从CSV有序权重确定族；品质仍调用旧函数。未知显式pool须失败，不能回全局池。`rollWeaponDrop`在第一把保障判断之前检查本节点allowWeapon。揭晓物source填写真实`fragmentId`，runId/nodeId继续由InventoryStore写入；复试不重抽，失败不换ID。
- **音频/入场**：替换/扩展实际注册音源，按AudioManager播。自然汇流预兆、接地、改流与排空由真实水/壳状态驱动，不用循环音轨碰运气。入场目标1.2秒、硬上限1.5秒，先听见世界再建立上水/下岸/玩家位置，最后交控；镜头阶段不暗耗耐久、混乱或受到攻击。可跳过直接同一准备态接管。该入场是隔离入口能力，不决定主菜单/基地出击政策。
- **记录/生命周期**：记录两种接触区、实际壳命中与耐久、改流窗口、目标数、合法足迹、掉落来源/品质/去向；暂停/Tab/结算/死亡/重开/退出销毁含目标注销和声音清理。长期恢复不在本批冒认已完成。

对应spec建议原地补：system-map-generation（注册/节点与种子）；system-combat（环境目标与共同预算）；system-chaos-scavenge-extract（节点来源显式入参）；system-growth-tide（来源族池，Stage允许配置范围）；system-audio（世界音景/状态声）。system-player-weapons与system-field-inventory须澄清：已登记、确实可改变状态的壳片属于合法命中；旧文“不可杀场体不耗耐久”指没有有效命中资格的场体，不能据此把可交互壳片变成免费目标。供奉阈值、消费先保存、每挥最多1耐久和负重公式不改，不新开第二套账本。

## 9. 验收合同

### 数据与机制自动检查

1. 所有显式ID完整/唯一，CSV生成可复现；未知图/来源/配置/未支持形态进入前拒绝。
2. 两图×全部编排变体：完整身体可走、天井不可跨、真墙挡视线；自然满水状态旁路连通。观察点、挥击点、干地退路和全部拾获点有效。
3. 壳片窗的前1ms/边界/后1ms、600ms排流、contactEnd、650ms回摆；暂停、低帧跨边界、同elapsed重复调用和结束冻结。
4. 壳片+虫同挥只占原预算；第三目标拒绝；1耐久/末次/存储失败/已错开/无效攻击全覆盖。核心与侧溢重叠不双伤，转流不清玩家无敌窗。
5. 五技能资格逐项；壳片/水不误入声诱饵、线/石、余烬/砂砾资格。真实虫受控后恢复；真实水伤可触发附着空壳但不减物理伤害。
6. 族池与风险品质独立；海沉积节点无武器；外来节点第一发现保障/普通概率正确。相同seed+node+source重复揭晓、保存失败、取丢重取不重抽；阶段未供奉、重/品质/来源保留。
7. 两图的seed变化实际改变至少一组已登记部署；未变化时生成检查失败，不拿美术噪点算关卡变化。

### 四配置×两种子的首轮操作诊断

首轮8趟：四配置分别跑**A seed7、B seed42**。这是两张编排各一个固定样本，不称为两图各两种子。全部用真实移动、转向、攻击、Q/F、E、Tab；配置授予只在开始，途中不补物、跳时钟或瞬移。标准对照将`firstWeaponDiscovered`初始状态固定并记录，不能有的配置吃首次奖励有的不吃。

每趟保存：输入/连续录像、配方/种子/变体、起止装备与余次/耐久、路径、等待、交战、受到的真实伤害、壳片是否用及何时、核心/侧溢命中、混乱、负重、已揭晓/实际携回/留下/丢弃物件、撤离或失败、帧时间。失败尝试保留，不以重开覆盖。

在冻结调参版本后，使用未参与调参的**A seed73、B seed211**再跑四配置；如发现问题修参数，原结果保留并另选新种子复验。此有限样本只检验路线与能力依赖，不宣称统计平衡或发行性能证明。

另做专项：满载高混乱返程、主动留一件使light/shore产生容量差异、目标末次/无效目标、同挥壳片与虫、壳片刚错开时故意踩余水、错开后踩核心、自然复位后再进入、真伤及死亡、活动技能/水/壳片下暂停和撤离。声音实听与正常帧画面由Art/QA复核，不能只看状态值。

### 通过与回退

- 白板两图都能用观察/等待/绕行完成正常携回；无需精确到一帧的水窗，无隐形卡路。
- 至少两种配置有可解释且不同的实际优势，保留其损耗和失败成本；light/shore的2.0重量差与一份细线不能成为纯装饰差别。
- 普通玩家从正常镜头能看清“上方落水仍在、被改的是侧水、回摆后下轮会再来”；无渲染/判伤分离，无看似地面但踩不到的新结构。
- 完整世界注册、两种编排、当地危险、来源拾获、音景、入场均交付且有证据，才称第二工作包已交；“有新图”不能代替。
