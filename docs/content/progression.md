# 当前成长节奏与扩展边界

规则唯一正文：[成长与潮汐](../specs/system-growth-tide.md)；设计因果、逐步效果与验证：[净化点与成长更新](../design-notes/purification-growth-renewal.md)。次序、目标级、每步价格、两处经历条件及短文案唯一来源为 `data/growth-route.csv`；`data/upgrades.csv` 提供效果与总级数，不再保存价格。本文组织节奏，不另写一份可执行路线，也不承诺固定游戏时长。R3实施与有界验证以本轮QA为准，文档同步不提升验收状态。

## 从立足到整备、承压

- **立足，第1–7步，累计71薪柴**：先生命与亲和，第3步供奉从1格到2格，累计26薪柴；第5步在真正承受过冲击后读准强度，第7步第一次加厚。第二格让工具与武器不必完全轮候，但没有额外物件赠送。首归仍免冲击，不登记受冲击经历或充供奉进度。
- **整备，第8–14步，本段118、累计189薪柴**：亲和第2层支持后续投入；第9步读准重点，第10步供奉到3格，开始按重点安排防御与维修；第12步以18薪柴增加第三主动位，累计149，仍计重并保留唯一被动位。第14步第二次加厚。没有三件主动的玩家可以延迟推进，但不能跳过本步购买后项；平滑价格不等于库存即时有用。
- **承压，第15–22步，本段237、累计426薪柴**：第17步在经历有限潮峰进入退潮后读出三模块供奉前压力，第18步供奉到4格，累计290；随后生命、自然时间减缓与加厚收满。最后四步共136，是有限数值收口，不制造新的技能或无限未来池。

只展示当前下一项和只读已获能力；当前级/总级及完成步数/22可直接读清。两个未满足经历分别用“承受冲击”“抵达退潮”，已满足就收起；薪柴支出独立展示。事实可以提前自然获得，到达节点不重做。供奉完成和工具揭晓保留记录，不再作为线性门禁，不要求特定随机物件。

## 温和指数与唯一价格源

本批22步（含三档加厚）按 `cost(n)=round(8×1.077^(n−1))` 独立四舍五入：首价8、末价38、总426；不使用上一项取整后的价格递推。允许第2–3步同为9、第6–7步同为12两段短平台，全路线不下降；同类各等级严格递增。

实际价格直接写在 `data/growth-route.csv` 的 `cost` 列。生成的 `GROWTH_ROUTE_DATA.cost` 为公共来源；既有 `UPGRADE_DATA.costs` 接口从相同路线行按单位/等级派生，加厚也按 `unit=thicken` 与目标等级读同源价格。不保留 `upgrades.csv` 的 `cost_N` 或 `constants.ts` 中的加厚价阶。公式解释本次曲线，CSV显式值是后续维护入口。

## 固定路线下的资源取舍

玩家决定“现在推进下一项，还是先修复维持”，不再决定先买亲和或生命等轴间顺序。当前项缺乏即时收益时，可以继续出击、搜取和准备，但须承受整条路线暂缓；界面不能假装存在绕行分支。空技能位、空供奉位都可出击；基地无就绪武器仍有白板替补，不因唯一供奉位占用而断掉循环。

加厚只提高上限、不回血。三个模块的功效统一按完整度100为基准并封顶，净化器不再把扩容后的上限用作功效分母；同hp在上限100/115/130/145下起始混乱相同。首次100/100变100/115时起始混乱仍为0；hp70在各档均为15。无修复额度时三模块填满新增空间另需12薪柴，得到的是额外受损缓冲，不是恢复被扩容削弱的功效；现有耐久不增加，必要注入成本仍在当前项首屏显示。第三主动位同样只增加装配选择，不赠工具、不增加被动位或负重容量。

预兆的价值必须由统一信息边界保证。远近HUD、裂隙就近提示、备行相关读数与存续报告同读当前等级的公开预兆；入口不再直接另显潮汐真实倍率。粗略潮汐阶段与世界反馈仍可观察，成长只是读清既有事实，不重抽下次冲击。

渗透抗性保留现行自然时间减缓：每级4%、最高20%，在自然时间通道应用既有倍率。它不加入武器/工具的广谱污染抗性百分点，不减少离散污染或起始混乱。把成长改为统一广谱抗性未获本轮授权，本文不再将其写成既定收益。

旧档按成长schemaVersion=2保留旧容量权益：缺版本旧供奉0/1级迁新2/3级，对应原3/4格。已购后项继续生效，下一项取最早缺级；不补齐中间、重复收费、丢物或发稳定度。R3调价对旧已购不补扣、不追溯退款；新购买按对应原路线节点的现价，不按已购总数错移价位。界面进度按已达到目标级计，继承能力不被描述成刚花薪柴买到。

## 难度与尚未证明的部分

潮汐沿原五潮三阶段，最终潮持续高潮；未新增终局，稳定度100仍只是状态记录。22步包含12次身体数值成长和3次加厚，主要功能变化是三层信息、并行供奉与第三主动。它们并不证明毕业后的持续新内容或无限潮平衡已经成立。

待验证重点是：1格阶段维修是否吃尽积累；取得第二格的实际时间；第三主动位是否因自然工具不足而成为暂时无收益的强制投入；信息第2/3层是否改变真实维修；强制加厚后的新增容积能否被注入并实际缓冲损伤；三主动/四供奉的自然补给能否周转。中段价格平滑后支出移向尾段，最后四步136的等待与收口感也未验证。

亲和算例继续按真实取整公式，但固定节点数、成功带回的毛收益不能推断自然净收入。新路线不再存在“亲和优先/容错优先”的购买策略对照；应比较路线节点前后的净可投入余量、维修暂停频率、失败损失及下一趟可用能力。顺序、价格和收益的调整需各有归因，不同时改掉所有变量。

迭代28扩大采样、长期平衡和动态美术继续挂起。**净化点美术已标记为迭代30待独立审核/迭代，尚未开始**；本轮价格与功效修复不代签审美，也不启动该独立工作。本轮不解除终局/后续供给扩产边界；新增内容须先说明真实能力、玩家决定与代价，再接入CSV、旧档和证据，不能只加等级与价格延长路线。
