# 当前成长节奏与扩展边界

规则唯一正文：[成长与潮汐](../specs/system-growth-tide.md)；本轮设计意图与受控比较：[净化点与成长更新](../design-notes/purification-growth-renewal.md)。本文组织当前玩家问题，不假定游戏时长或声明终局已实现。

## 从维持到准备

- **初入**：学习搜取与带回，薪柴在修复、三种身体基础与加厚之间选择。第一次归来有报告但免冲击，不登记受冲击经历，不推进供奉。
- **承受真实冲击后**：展开预兆第一层，准确读强度；维修开始考虑下一轮压力。已有完整度仍决定下一趟条件。
- **完成一次供奉后**：展开供奉扩容与预兆第二层。第四槽增加防御/培养吞吐；明确重点后，可优先修复最受压装置。鉴定为无能力物也证明已完成供奉。
- **揭晓可用工具后**：展开出击扩容，第三主动与携带重量一起进入准备。额外位置不赠送工具，唯一被动位仍在视距、容量及其他作用之间取舍。
- **离开有限高潮后**：预兆第三层显示各模块供奉作用前压力。经历无需完美无损，不与稳定度“完整度守住”奖励混淆。

事实可交错积累，已购能力不会因旧档缺少事实而失效。首归、死亡、放弃与菜单重入分别按实际归来账本处理，不把打开菜单或周目数字当成功经验。

## 池与成本的真实规模

当前仍为6条、17次永久成长购买，总薪柴334；另有3档加厚共64。价格/名称/各级条件在 `data/upgrades.csv`，加厚用既有系统常量。展开条件与分组不会增加池深度；本轮实质新增是三层确定信息及其准备决定。基础/扩槽的数值与含义保持，出击扩容旧被动错位已修。

阶段一仍可先修复再改造；库存没有第三主动时不必买出击扩容；已有足够防御且模块健康时信息能力可能晚买。加厚不免费回血，净化效率会暂时下降，须一并预算购买与后续补满成本。

## 难度与尚未证明的部分

潮汐沿原五潮三阶段，第36次冲击起进入第五潮无限高潮；未新增终局或声称新目录足以承受无限循环。稳定100仍只是状态记录。各阶段时长、失败恢复、获取足够工具的自然频率及长期最优购买顺序未被本轮短测试证实。

亲和在受控安全短撤/标准搜撤/深搜均有较高回报，但这些计算假设固定堆数与成功带回，不能推出普遍必买。暂不凭公式降数值。后续若重启长期验证，应比较亲和优先、容错优先与维护优先的真实损失和下一趟可用资源，再决定调价/改收益。

迭代28扩大采样、长期平衡和动态美术继续挂起。后续新成长需先写一句话能力、增加的决定与不值得优先的反例，再扩CSV、消费链、资格、旧档与证据；不以每项追加等级替代功能变化。
