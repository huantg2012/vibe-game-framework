# 当前成长节奏与扩展边界

规则唯一正文：[成长与潮汐](../specs/system-growth-tide.md)；设计因果、逐步效果与验证：[净化点与成长更新](../design-notes/purification-growth-renewal.md)。次序、目标级、两处经历条件及短文案唯一来源为 `data/growth-route.csv`，费用/效果/总级数由 `data/upgrades.csv` 与既有加厚常量提供。本文组织节奏，不另写一份可执行路线，也不承诺固定游戏时长。

## 从立足到整备、承压

- **立足，第1–7步，累计68薪柴**：先生命与亲和，第3步供奉从1格到2格，累计26薪柴；第5步在真正承受过冲击后读准强度，第7步第一次加厚。第二格让工具与武器不必完全轮候，但没有额外物件赠送。首归仍免冲击，不登记受冲击经历或充供奉进度。
- **整备，第8–14步，累计210薪柴**：亲和第2层支持较大支出；第9步读准重点，第10步供奉到3格，开始按重点安排防御与维修；第12步第三主动位扩大应对组合，仍计重并保留唯一被动位。第14步第二次加厚。40薪柴的第三主动位是最高单笔费用，没有三件主动的玩家可以延迟推进，但不能跳过本步购买后项。
- **承压，第15–22步，累计428薪柴**：第17步在经历有限潮峰进入退潮后读出三模块供奉前压力，第18步供奉到4格；随后生命、抗性与加厚收满。最后四步是有限数值收口，不制造新的技能或无限未来池。

只展示当前下一项和只读已获能力；当前级/总级及完成步数/22可直接读清。两个未满足经历分别用“承受冲击”“抵达退潮”，已满足就收起；薪柴支出独立展示。事实可以提前自然获得，到达节点不重做。供奉完成和工具揭晓保留记录，不再作为线性门禁，不要求特定随机物件。

## 固定路线下的资源取舍

六轴19次刻入共364薪柴，加厚3档共64，总22步428；身体12次199、预兆3次60、出击扩容1次40、供奉扩容3次65。修复支出不计入此总价，单看毛收入不能推算几趟毕业。

玩家决定“现在推进下一项，还是先修复维持”，不再决定先买亲和或生命等轴间顺序。当前项缺乏即时收益时，可以继续出击、搜取和准备，但须承受整条路线暂缓；界面不能假装存在绕行分支。空技能位、空供奉位都可出击；基地无就绪武器仍有白板替补，不因唯一供奉位占用而断掉循环。

加厚只提高上限、不回血，净化器需要额外补满才能恢复原起始混乱。首档100/100变100/115，起始混乱0→7；无修复额度时三模块补满另需12薪柴。此代价在当前项首屏显示。第三主动位同样只增加装配选择，不赠工具、不增加被动位或负重容量。

旧档按成长schemaVersion=2保留旧容量权益：缺版本旧供奉0/1级迁新2/3级，对应原3/4格。已购后项继续生效，下一项取最早缺级；不补齐中间、重复收费、丢物或发稳定度。界面进度按已达到目标级计，继承能力不被描述成刚花薪柴买到。

## 难度与尚未证明的部分

潮汐沿原五潮三阶段，最终潮持续高潮；未新增终局，稳定度100仍只是状态记录。22步包含12次身体数值成长和3次加厚，主要功能变化是三层信息、并行供奉与第三主动。它们并不证明毕业后的持续新内容或无限潮平衡已经成立。

待验证重点是：1格阶段维修是否吃尽积累；取得第二格的实际时间；第12步40薪柴是否长期成为无用的强制投入；信息第2/3层是否改变真实维修；强制加厚的短期代价能否被理解；三主动/四供奉的自然补给能否周转。

亲和算例继续按真实取整公式，但固定节点数、成功带回的毛收益不能推断自然净收入。新路线不再存在“亲和优先/容错优先”的购买策略对照；应比较路线节点前后的净可投入余量、维修暂停频率、失败损失及下一趟可用能力。顺序、价格和收益的调整需各有归因，不同时改掉所有变量。

迭代28扩大采样、长期平衡和动态美术继续挂起。本轮完成当前范围的设计、实现及有界验证，不解除终局/后续供给扩产边界；新增内容须先说明真实能力、玩家决定与代价，再接入CSV、旧档和证据，不能只加等级与价格延长路线。
