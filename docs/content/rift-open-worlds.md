# 当前开放 Rift 世界与重构记录

更新：2026-10-20 · DEC-220 · COH-F011 / F044 / F039 / F007 / F054

正式游戏只开放 **余烬脊、晶化林床、破膜盆地**。低、中、重污染均使用这三个世界；其余105个世界暂停开放，包括已有新版构型的吸光釉原。完整108世界的数据和开发图册保留。

用户明确其他世界的旧进行中存档按废局处理：继续记录时沿现有弃行结算回到净化点，遗失随身物与本趟收获，不计成功撤离，不删除基地进度。更早且不属于这三个世界的有效旧局同样处理；已经结算的记录正常完成返程。这三个世界的有效进行中存档仍正常续玩。

开放权威为 [rift-native-worlds.csv](../../data/rift-native-worlds.csv) 的 `enabled` 字段。以下记录的是已接入工作；后续重新开放其他世界必须另行更新开放范围。

## 三图共同完成的重构

- **地图构型**：r13 从矩形拼合的世界碎片出发，加入错位主地块、次级宽臂、参差岸线与自由断缘。地面、空间空洞和实体障碍在构造阶段共同组织，保留身体通路；空洞阻行且遮视，实体按既有规则阻行及近战。
- **固定认可骨架，变化出击内容**：中重污染保留认可的中档物理母体；2026-10-20起新低污染使用各自的紧凑地床、孔洞与实体安排，保留同一世界材料和几何种子 `20261012`。实际出发种子继续决定内容、撤离候选及怪物个体；撤离不固定在出生点附近或地图对端。这不是每次重生一份新外轮廓，出生位置也未改为随机。低档破膜入口移到北侧孔洞之间的宽地，使出发干路能先遇到遮蔽。
- **低污染短程补给**（2026-10-20）：三图可通行面积相对旧低档分别减少18.86%／20.44%／24.24%；逻辑画布尺寸不变。新低档为6处薪柴、2处污染物，其中两处近程薪柴不参与武器替换。旧在途配方按原貌恢复；长期自然搜撤平衡待体验。
- **翻找物融入场景**：以母体断落、表层剥离或开放积留解释来源，使用当地材料与同一灯场，翻找后留下残迹。沿用已接入的环境残骸机制，奖励与交互规则保持。
- **玩家角色 A**：正式使用净化点 Last Light 同源「短摆工装」，保留头盔、肩灯、骨架和材质关系，补偿侧身低光暗部。已接原装备持具、挥击和受击反馈，原20px身体与战斗规则保持。覆盖三档新出发及有效续玩；2026-10-20将Rift人物及手持物、灯锚和接地缩至原展示的0.8倍，净化点与玩法身体保持。
- **连续吞光视野**（2026-10-20）：新污染／持久同化协议使用实际肩灯光场。污染连续收缩视距并吞噬近远处光线，留下断续污绿反应；同化只恢复阴冷的辨认范围，不恢复干净照明。工具、Host、暂停及冷续与真实状态联动；旧150混乱协议保留旧表现。角色混合同化与净化点主观视觉已按下项接入。

- **持久同化形象**（2026-10-20）：实际A与跨世界来源谱驱动全身材料、胸背前屈/头探/肩差及晶脊/厚膜，攻击/收步/坐姿仍用真实动作时钟。晶化/破膜贡献可混合并带回净化点，疗愈同比消退；余烬脊没有已获批的本土人形组织模板，用通用姿态与当地solid材料，不复制其他世界的专属组织。新形体后台按完整动作库准备，首次/换源可能短暂保留基础/上一形体；材质即时变化，A0即时恢复。正式限定证据见[同化形象QA](../qa/assimilation-production-2026-10-20.md)。

## 余烬脊 · `cinder-ridge`

- 中重档为错位主地块与两处次级宽臂，16个孔、7件从属障碍及完整主体组；新低档缩短外围探索域，12个孔、5件从属障碍及主体组。
- 保留锈红颗粒／冷灰夹层的世界材料身份；翻找物采用压实颗粒形态 `packed-granules`。
- 已接上述构型、翻找物和 A 角色；**尚未接入此次类人／菌毯怪物本土化**，怪物沿原分支。

## 晶化林床 · `crystal-fibre`

- 中重档为错位拼合与两处次级宽臂，16个孔、7件从属障碍及完整纤维主体组；新低档保留四块主地床，12个孔、5件从属障碍及纤维主体组。
- 保留钴蓝晶纤／金色脉络；翻找物采用断裂纤维形态 `fractured-fibres`。
- 已接实际类人 `human_remnant` 与地面菌毯 `fungal_mat`，使用本世界纤维材料、真实 AI／Host 和现有类型行为；数量职责沿原合同。
- 已接 A 角色及全部共同重构。

## 破膜盆地 · `ruptured-film`

- 中重档为错位拼合与一处次级宽臂，14个孔、6件从属障碍及完整膜体组；认可母体整体等比缩至0.8。新低档重排外围地床和共同出发路径，11个孔、4件从属障碍及膜体组，主体额外使用0.9倍率。
- 保留酒红／玫红薄膜与冷灰蓝夹层；翻找物采用撕裂薄膜形态 `torn-membrane`。
- 已接实际类人 `human_remnant` 与地面菌毯 `fungal_mat`，沿本世界膜材料表现及现有类型行为。
- 已接 A 角色及全部共同重构。

孔／障碍数字是作者构造对象数，主体组可包含多个实体，不能当作最终碰撞块数量。三图配色和主体材料是已有身份的保留与统一受光，并非本轮重新制作全部材质。
