# 迭代19：撬棍、统一库存与出击闭环

## 当前范围

只做撬棍，开局一把普通白板，不可升级；类型决定攻击方式，同类品质决定主要价值，同品质只微调重量和抗性。四品质十成品采用污染侵蚀、结构改写和少量污染色，用户否决的科技升阶与旧八功能撬棍不再实施。当前机制和素材由DEC-138“开始实施吧”授权投产，具体平衡仍需试玩。

武器与污染物统一库存，负重16.0、污染物2.0，出击前装配；裂隙背包不暂停世界，不热切已装配物。死亡丢本次全部携入装备和收获，基地保留。退出/刷新/崩溃不擅自套用死亡规则，处理政策待用户明确。
