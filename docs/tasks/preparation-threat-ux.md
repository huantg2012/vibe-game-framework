## 3. 背景与声音方案

载体仍是裂隙边的备行交互；本次氛围的承载面是覆盖在实景上的整层半透明 UI 遮罩，挂载在固定 960×640 的 `#dom-ui-root`。沿当前像素实景、无框排字与连续暗场，Signalis 取主从与克制文字，Darkwood 取人物在场与暗处准备，Hyper Light Drifter 取直接选择与短标记；不移植其皮肤。

**世界底图三档完全相同。** 人物、裂口、建筑、机位、既有光照和真实遮挡不随选级改变。层位从后到前是世界底图、基础阅读暗场、整层氛围视效、文字。氛围层可以横跨当前遮罩，通过半透明形状的疏密、方向、围合，以及主流与异步局部运动传达压力；不再借世界远景、裂口内层或深度空隙承载这些差异。

- **低：相对从容，但污染在场。** 至少两处污流在正常文字存在时仍能辨认，具有可追踪的主流与局部异步卷折。保留较多间隔和人物附近清楚空间，不把“相对安全”做成无氛围或只有微不可见的变化。
- **中：有压力，仍能掌握。** 主流之外出现局部伸入、横拉和残痕；不同方向的运动发生冲突，卷折、拉扯、回退不同时起落。狂野程度来自空间关系与局部节奏，不只是把整层匀速流动调快；正文清楚，不以阅读困难制造压力。
- **重：明显危险，运动更难预测。** 方向冲突更强，局部卷折、伸入、横拉及残痕相互接续，主层／薄层有错速和错拍；收紧留白，但仍能追踪局部变化。人物和文字始终固定保护，不靠全屏晃动、突然闪帧、单纯加黑／泛绿或整体提速替代狂野感。


人物及肩灯周围采用同一稳定的屏幕空间保护区域，三档不收缩、不漂移，不把它伪装成机制中的安全范围。文字、选中标记和输入命中区位于效果上方，始终原位，不参与扭曲；效果在阅读区的亮暗／细节上限由最坏帧实看决定。所谓“整层”是效果的构图范围，不要求每个像素同等密度，也不允许吞掉小人。P1 的表现区／保护区图据此标示遮罩层、人物保护区和稳定读字区，不再规定真实远景深度保护。

静态三档首先在遮罩的大形、间隔和围合上可分；同一实景、相位和基础阅读暗场下，隐藏文字、静音、停动验证。动态在静态关系之上建立主流、局部异步卷折、伸入、横拉与残痕；中重以方向冲突和非齐步的局部节奏增强狂野，不能全档只有缓慢平稳的输运。仍不以闪帧、突然扑面、可辨敌人／路径／奖励剪影或基地受损反馈制造威胁。它不改变碰撞、视野、装置完整度，不预生成目的世界。此前远层折面样例和“只在背景深处变化”的审查限制已被用户纠正，不作为本轮素材或规则基线。

声音为辅助，归属于裂口方向的选级表现层，保留净化点原有主床与功能声身份。先审听已有素材；仅在不适配时限定制作一条环境层。同一音色家族内调整事件间隔、纹理密度和摩擦质感，响度只辅助，不持续攀升。选档连续衔接，不调用真实混乱/受击/追击层，不让整座基地变调。允许有界交叉尾音，过渡结束仅剩当前目标；P2 记录过渡峰值和稳态实例数，不以含糊的“8轨”代替资源合同。

## 4. A / B 文案与信息编排

### A：规则说明

内容顺序为危险判断 → 危险原因 → 应对 → 深处资源。各档用同样的字段与位置，可直接比较。选中档名 18px、危险判断 16px、事实 12px、标签 11px；风险判断从属于当前档，不复制第二个大档名，不用更亮/更重的文字抢主标题。收益留在次级位置，避免高档首先读成奖励升级。

候选文案仅用于方案审查，实施时迁入对应 CSV 并由 codegen 消费，本文件不成为运行文案的第二真源：

- **低污染／威胁较低**：混乱增长较慢，污染体较少。应对：观察路线，逐步搜取。深处资源：较少。
- **中污染／威胁升高**：混乱增长更快，受侵占的区域更多。应对：留意绕行机会，提前考虑撤退。深处资源：较多。
- **重度污染／高度危险**：混乱增长很快，且更早加速。地面与空气大范围受侵占。应对：准备脱身手段，为返程留出余量。深处资源：最多。

用户已要求删除选级页重复的“入口附近的收获不随档位增加”说明，现随本批标题／B 组选择一并从独立样例删除。删除的是此处重复呈现，不改变机制。“深处资源”仍比较场景部署的可搜资源，不能换成“本趟所得”“收益倍率”或保证带回的数量。所有新文案先候选后选择，不在视觉修订中顺手替换运行文本。

事实逐项对照 `rift-pollution-grades.csv` 与 `rift-expedition-grades.csv`；“更早加速”对照当前 90/60/40 秒起点，不显示保证成功的停留时长。没有装备评分、推荐战力、必备物检查或精确掉落预告。`威胁较低`是相对其他档的判断。

新稿改用角色第一人称，以 Darkest Dungeon 为语感参考，重点是凝练、有分量的自述；不直接仿写或借入全知旁白。减少套路化意象堆叠、刻意文学转折与 AI 式修辞，用角色当下的判断或具体感受形成气氛，不虚构 NPC、灾变解释或世界预知。每档最多 40 字、两行，不靠大量轮播稀释判断。用户已明确选择 B 组；下列为本批采纳的选择记录，独立样例运行文案归 `docs/art/demos/preparation-threat-sample/copy.csv`，本文件不形成第二个运行数据源：

- 重：我的腿不肯往前。它们比我明白。

B 沿现有低语 13px 衬线族、正常字重，与 A 的无衬线事实说明分开；不加引号框、打字机或大面积斜体，不进入人物保护区。无需增加“A/B”“氛围提示”等玩家标签。未来新增句必须符合实际背景，不能描述未画出的场景事件；正文不得借诗意承诺路、出口或安全窗口。

固定版位候选沿现有 960×640：选项列 x344–490，详情列 x534–928，footer y526–588。详情内危险判断 y214–238（24px 行高），事实 y248–311（至多三行，21px 行高），应对 y324–366（至多两行，21px 行高），深处资源 y380–402；旧入口说明所占 y410–446 已随本批删除而留白，不用新信息补满。B 独占 y466–510 两行区（22px 行高），标题“裂隙彼端”与已选第一人称 B 组须以实际长度核对。出现/消失不推移控件，B 至 footer 保留至少 16px。P1 用重档最长文案、真实字体与键盘焦点核对，超长先精简稿件，不能缩小正文字号、截掉风险或塞进 footer；坐标只在实景核后写回 Kit。

**B 的状态联动设计（未实施）：** 从已知事实资格筛选后，优先回应近期成长/成熟，再看当前行装与上一趟经历，最后用档位语气兜底。新物未成熟不算战力；仓库好物只能用“带上它”的意向，已装且可用才能谈手中底气；成长区分身体、收益、基地。重污染即使配上鼓动句，A 和背景也保留原威胁。

**节奏与避重：** 复用共享 CSV 句池的无放回轮换；不靠计时轮播制造多样性。旧计划“关开即恢复机会”撤销：同次准备行程保留预算，配装往返只在真正状态变化时有限补一次，不得 A→B→A 刷句。选档停稳、六秒候选显示、暂停与关闭的细则、近期事件失效及存储边界只维护在[旁白规格](../specs/system-atmosphere-narration.md#备行选级计划中)。本页不复制第二套运行规则。

**本轮只读与审查结论：** Explorer 已追踪生产库存/成长/归来链；Design 审查指出必须区分物品可用性与新获得、关闭视图与准备预算、文本新鲜与事实资格。已采纳有限状态变化补句及无合资格内容时兜底/留白。无新增运行 CSV、代码或页面变化；文案候选只在本轮回复供选择。备行没有跨趟残血、最近升级没有持久时间、连续胜负没有记录，这三类内容不能通过猜测补齐。

### 行装承接

标题附近保留“所选档／危险判断”短摘要，低于当前物件；出发动作旁保留等级身份。两处消费同一选档值，重复是防止长时间配装后误发，不能重复整段风险文案。行装页背景保留静态档位差异，动态和声音收敛以免干扰阅读；不能暗示准备后危险已经下降。

两处摘要均沿辅助层级，不继承选择页 18/16px 的标题权重；当前物品名和主要动作保持视觉主次，装备页不再新增 B 或风险段落。

## 5. 状态与资源归属

P1 即接通真实 panel → presenter → 净化点场景路径，传递只读的已接受档位、pollution/equipment/closed 阶段、active/paused/disposed 生命周期。档位只取现有业务选择；不以 DOM 查询或 DEV 自建 grade 驱动另一套状态。备行呈现控制器持有屏幕遮罩与 B 会话／计时，场景持有局部声音资源；它们只观察已接受的备行状态。空档位/旧入口明确恢复中性基线，不能继承上一会话的重档。

氛围使用 UI 屏幕空间遮罩，置于基础阅读暗场之上、文字之下；世界合成图保持同一输入和输出，不修改 far/middle/near、光场、深度或正式资产。人物保护区在备行固定构图中稳定锚定；实现不得让选档改变它的位置和范围。P1 用同相位对照验证世界底图相同、人物清楚、文字稳定，不能只量全屏亮度便判定三档压力成立。

声音使用局部控制器与固定实例身份，复用既有音量、解锁与暂停。选级态跟随最新档，行装态转安静目标；paused 冻结/静音，手动恢复时只追最新状态；closed/disposed 释放自身资源。取消不能用全局 `haltNonBgm` 清掉净化点原床，不写 Rift 战斗层目标。晚到加载回调校验会话代次；资源缺失或解锁失败不阻塞选择和出发。准备取消、进入实际 Rift 与场景销毁均有明确收尾。

**P2 连续视觉与声音样板｜Art/Audio 定规格，Code 实现。依赖 P1 静态内部核与预算冻结。** 沿同一状态桥加入档位过渡、B 时序、遮罩动势与局部声音包络。规格必须记录每个效果的触发、目标层、幅度上限、周期/时长、曲线、打断及恢复；记录声音最大过渡重叠、安静目标与释放窗口。背景从当前值追随最新输入，不排队、不锁操作；行装只收敛运动，不退回低档构图。包含快速切档、返回、关闭、静音、减少动态与失焦。先一版，最多一次针对实际缺陷的修订；仍不成立则保留失败并回到原因，不无限调参。成本中到高，素材适配未审听前不作精确工期承诺。

## 7. 验证问题与停止条件

- **辨认强弱**：世界底图完全相同时，只看三档稳定遮罩、不放档名和 B，能否给出低→中→重的压力顺序；再恢复正常 UI 检查 A 是否准确解释原因。隐藏文字仅为表达诊断，正式玩家始终看完整信息。知情代理不能冒充盲测。
- **读懂并保留信心**：正常页面上能否说清至少一个真实差异；中档是否既有压力又仍愿意尝试；重档是否促使认真检查行装而不是误以为被禁止进入。真正心理效果由用户描述，不能由颜色/字号测试代签。
- **误读反例**：玩家是否以为背景正在损伤基地、计时惩罚已经开始、目的地已确定、整张地图必定是这一形状或重档必掉好物。若成立，先修表现归属和措辞，不能靠追加大段免责声明补救。
- **阅读与舒适**：默认尺寸和实际显示比例下三档关键信息可读；正文（含 B）/关键非文字标记合成背景对比分别保持 4.5:1 / 3:1，覆盖动效最暗/最亮阶段并留抽样时间。静音、减少动态保留层级；持续配装不靠晃字、突闪、响度攀升制造压力。连续录像检查闪帧，不能用最暗静帧代签。
- **行为回归**：第一步不能出发；普通 Enter/Space、Shift+Enter、返回/退出沿既有语义；长库后段装配、4/5槽、空工具与无武器、未成熟物、旧入口兼容均保持；三档各至少一次正式出发核冻结等级一致。
- **低语限频**：注入取句计数，快速三次切档仅最终可见档消费；250ms 候选下 249ms 关闭/失焦不消费；回到已读档不新抽；已显示的暂停仅恢复余时；关闭重开不刷新准备行程预算；真实状态改变的额外机会及A→B→A防刷按旁白规格核对。自动低语不得叠句。旁白历史与业务记录分别检查。
- **隔离与清理**：纯选档/切页步骤不改变库存、设施、生成身份或世界历史；主动装配是合法变更，不把整趟首尾库存全等当闸门。旧句/旧音/旧特效不在下一页或场景残留；生成/世界历史在选级时零调用，只于真实出发一次。快速切档、关闭中切换、失焦/手动恢复、准备取消、拒写重试、场景 shutdown/destroy 是不同样本。复用现有 DEV 的 import 前 Storage 隔离和业务内存记录，native Storage 零调用检查继续保留。
- **声音验证**：先单听选级层，再在同监听音量下听实际低/中/重混音、重→低、快速往返和持续配装；查接缝、点击、提示遮蔽及疲劳。取消后净化点原床还在，关闭后的异步完成不产声，进入真正 Rift 后备行实例为零。计数不能代替试听。
- **性能范围**：同设备同场景比较帧时间/长任务与资源数；暖机后跑 20 次有界切档/开关，关闭且等声明的尾音窗口结束后，对照监听器、纹理、控制器及声音残留。用 P1 冻结的增量预算判定，不将过渡中总 voice 数当泄漏，也不扩成整库/弱设备重新验收。用户已豁免其他真实设备，本计划不重新打开该待办。

以上仍是正式接入后的验收计划。当前独立样例仅用于屏幕遮罩的静态／动态候选和排字审看，不满足真实状态链、正式动态生命周期或声音验收。实帧结论按本轮记录单列，不能沿用纠偏前截图／E200；方案审查与样例浏览均不能提升发布结论。
