# 余烬脊空间结构原型

2026-10-10。用户授权：先做一个代表世界，用去雾全图检查结构并展示。状态：DEV 样本完成有限结构与浏览器检查，未推广正式世界库，等待用户看图。详见[QA](../qa/cinder-spatial-prototype-2026-10-10.md)。

绑定能力：COH-F011 地图生成、COH-F012 地表、COH-F013 空间支撑、COH-F049 隔离审阅。保留原生产世界、保存身份、污染档位及收益规则。

## 本轮交付

- 复用余烬脊的材料与原生实体渲染；新空间参数来自 `data/rift-spatial-prototype*.csv`。
- 扩大完整身体可达空间，目标约旧余烬脊的四倍，记录实际比值；外轮廓用大凹口、伸出地块和收束连接改变路线。
- 以成组 `solid` 脊群分隔宽地块；浅浮雕不算阻挡。提供完整身体可走网格上的路线，不拿装饰线替代真实路径。
- 出生和唯一撤离按种子选择近侧候选区域，保留搜取后归返。该原型不引入穿越全图才能撤离的新规则。
- 独立入口 `rift-spatial-prototype.html`，提供无标记去雾图、路线地点、真实实体占地与原始像素查看；不读取或写入玩家记录。

## 表现依据

世界内实体是余烬材料挤压堆积成的脊，不是人为修建的围墙。沿用已锁 `granular-ridge` 三维表面投影、材质图、外观色阶、面法线和接地关系；允许长短不同的连续脊群和破裂堆积体，排除规则棋盘墙、另造围栏与仅在图片上遮黑的假缺地。支撑、碰撞、烘焙读取同一个地形。

本轮参照为正式余烬脊的材质与体积、现有 R100 真实缺地的表面终止、正式 20px 身体尺度。放大的是探索空间，不缩小角色与障碍来伪造地图变大。审阅按钮和路线文字属于 DEV 元界面，不新增游戏 HUD 或改变视觉规范。

## 验证与边界

比较同世界旧种子的完整身体可达面积、外轮廓占比、出生/撤离可达性和至少一组真实替代路径。另用不同种子验证入口区位变化，同种子复现。截图采用实际原生材质渲染，不用概念图代替结果。

普通实体的碰撞不等同于挡视线，不将绕行命名为已验证安全路线。这个空间样本不证明敌人布置、搜撤时长、扩图后的内容密度、长期收益、全种子生成质量或用户认可。完整战斗与经济布置留到空间方向确认之后。
