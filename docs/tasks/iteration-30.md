# 迭代30：净化点空间、模型与成长获得感重构

## 当前状态

**当前方向已转为侧视上下层的封闭场所，双层检修舱为具体待评审提案；正式场景未改变。** 原俯视三候选被用户新要求取代，保留为[历史探索页](../reading/purification-spatial-directions.html)。S01–S03/GR-06历史问题仍需解决。

[当前完整设计](../design-notes/purification-spatial-directions.md)与[侧视剖面阅读页](../reading/purification-cutaway.html)提出：下层储藏/核心/净化器/裂隙，上层蜕变/供奉，两端短阶；实体壳体、既有抗侵蚀和外部改写分开设计。前墙是镜头剖切，世界内仍闭合。原角色身份保持，需补侧视动作；Rift保持俯视。

本轮只完成设计与阅读页检查；[本次边界](../qa/i30-cutaway-design.md)不代表真实碰撞、原速路线、美术或声音通过。两层、短阶与具体模型还待评审。成长反馈原有范围保留，不被空间改造遗漏。

## 独立审查范围

- 使用game-review审查净化点整体场所构图、六交互对象的剪影/材质/职责、正常尺度与交互镜头下的主次。
- 重点检查身体成长和装置建设的结果对应：一次投入能否读出作用对象，恢复操作后能否找到持久变化。
- 复核修复、供奉、成长、受损在运动与音色上的区别；先取得原速动作和实际听感证据，不能以截图判仪式感通过。
- 覆盖新档、受损、早/中/后段成长、空/满供奉，检查长期补件和当前损伤是否互相覆盖。
- 审核后形成优先级与最小表现样板，再据样板反馈决定制作范围；不预设全面提亮、低饱和、换角色、22套模型或长阻断仪式。
