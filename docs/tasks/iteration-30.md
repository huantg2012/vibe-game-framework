# 迭代30：净化点空间、模型与成长获得感重构

## 当前状态

**三方向设计已就绪，未选型，未改正式场景。** 用户指出闭合膜边界像蛋、地面连接不改变行走空间，要求整体重构。已恢复S01–S03/GR-06的历史范围，并由design与art独立推敲空间和六功能载体。

三方向为残墙工作院、错层断崖站、剖开的巨械。见[完整设计](../design-notes/purification-spatial-directions.md)、[可检查通路的阅读页](../reading/purification-spatial-directions.html)。阅读页是抽象示意，没有替代真实碰撞灰盒或最终美术。原六锚点与旧模型形体不再作为候选重构限制；原角色、2D和游戏机制保留。

本轮只完成方案设计与阅读载体验证；[限定检查](../qa/i30-spatial-directions.md)不代表场景实现、人审或动态听感通过。成长反馈原有范围保留，不能被空间改造遗漏。

## 独立审查范围

- 使用game-review审查净化点整体场所构图、六交互对象的剪影/材质/职责、正常尺度与交互镜头下的主次。
- 重点检查身体成长和装置建设的结果对应：一次投入能否读出作用对象，恢复操作后能否找到持久变化。
- 复核修复、供奉、成长、受损在运动与音色上的区别；先取得原速动作和实际听感证据，不能以截图判仪式感通过。
- 覆盖新档、受损、早/中/后段成长、空/满供奉，检查长期补件和当前损伤是否互相覆盖。
- 审核后形成优先级与最小表现样板，再据样板反馈决定制作范围；不预设全面提亮、低饱和、换角色、22套模型或长阻断仪式。
