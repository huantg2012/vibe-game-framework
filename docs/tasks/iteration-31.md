## 有界验收

1. 亲和0/1/3、储藏HP 0/70/99/100/115与修复前后示例，覆盖互换/共振/一次额度。HP70→99未跨档时不能显示虚假产出提升；HP100以上修复明确增加承压余量。阈值是当前状态一次所需总费，不重复计算额度，不因储备不足误称无台阶。
2. 至少一组通过正式共享翻找结算核对实际整数所得；若用隔离状态/固定基值须明确，不冒称自然获得或长期经济通过。实际修改三模块的预览与新出击修正相同，拒写完整回滚。
3. 被动验证至少覆盖无被动、一种catalog整趟被动、最后一趟、正常结束/死亡、刷新恢复以及旧事件计数。回执能在绑定清理后保留，旧缺字段记录不补造历史，不要求自然取得48件目录。
4. 受损纪录包括无法解析与可解析但不兼容两类；只存在无效字节也需确认。取消/Esc、重复输入及保存失败不造成默许替换；真正无纪录正常新开，已有合法纪录继续保持原流程。
5. 修复页在960×640固定逻辑画面内保持260px宽投入列，三横列“份量示例”不挡装置、人物与动作行；最长阈值和资金不足提示可读，0/足额/不足、鼠标/方向键、Enter/重复/退出正常。正式备行在装备下/筛选上添加48px静默条件行，只在prepare模式出现；三列标签与数值分开，列表至少保留两条完整可见项且可滚动，详情动作及出发footer固定。catalog/rift模式不加该行。归来仍以真正所得或损失为主，被动伴随为从属事实；不新增阻断弹窗。
