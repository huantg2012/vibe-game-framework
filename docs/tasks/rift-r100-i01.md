## 本轮玩家价值与范围

先使旧在途世界能按原算法恢复，防止新物质/地形制作破坏续局；把世界身份与低/中/重污染分开，让后续风险、画面、准备和收益的差异可以精确验证。现有五个世界是回归样本，不直接计入108；本轮计数目标为0世界、0等级资格格。新分级选择、压力周期和奖励规则仍待I03实施。

## 实施批次与责任

- **B01 旧局保护**（code / r100_legacy）：冻结基线生成依赖闭包，接入旧恢复路径；v1/v2与无配方路径金样、跨进程恢复和拒绝损坏身份。新出击仍为当前v2，不改变玩法。
- **B02 最小包合同**（code / r100_package）：CSV驱动世界包与独立等级声明，绑定算法/能力版本及来源哈希，未知能力与伪造资格拒绝。仅登记五个legacy/dev样本及未实施的三级，不制造108空壳。
- **B03 测量与资格方法**（director）：自然出击采样与定向边界分开；测量生成/恢复、有限原生运行基线，锁定预算、硬件边界与后续样本规则；保持可重复命令和原始结果。
- **B04 I02制作任务包**（art / r100_art_baseline）：审查真实原生画法，确定板、束、壳三构造的同源三级母版、几何/受光/遮挡/动态方法及反例。交付具体制作稿，实际母版在I02执行。

每批实现后由非作者进行专项复核；root统一更新现行spec、architecture、game-state和版本台账，不用规划文案替代实际接入。新增图形先保持开发入口，不影响现行出击池。

1. 可执行旧算法封存且回归通过；签名拒绝不是旧局保护的替代品。
2. 最小CSV编译和包校验实际可运行；来源/能力/三级状态可辨，旧五样本不虚报合格。

4. 世界×等级、随机流、实体几何、备行/压力/收益/暂停恢复的合同影响清楚；未实施机制仍标待实施。

## 下一代运行合同的实施顺序（已裁定、尚未接入）

**实体几何先于部署。** I02建立版本化形体实例：世界地面锚点、实体占地、多面顶点/面法线/材质区域、孔腔、受控运动端点。地面支撑、实体阻挡、视线遮挡、光线遮挡、表面投影分别派生，不能把同一张黑白mask当成五种语义。生成次序为地表→实体几何→20px身体连通与视线→遭遇→资源与语义路线→绘制；后置高物体不能堵住已验收通道。支撑保留8px，Host语义保留32px，无可走第二层。版本/字段随I02真实实现原地写入地图spec。

**身份承诺在生成前冻结。** I03的出发意图先包含worldPackageId、package/dependency hash、pollutionGrade、gradeRulesVersion、generationAlgorithmVersion和请求seed，再进行确定性重试。命名随机流继续分开地貌、材质、部署、遭遇、压力与奖励；改纹理不能重抽奖励。重试只换候选seed，不换世界/等级/包；耗尽保留错误且不消费已取消的准备。新字段用显式新版本，不塞进历史v2。

**进入选择归备行。** 裂隙交互→认识风险档与时间承诺→整备→确认→生成准入→原子beginRun。取消不扣资源，不生成可预览刷奖的内容；重度需玩家主动选择，常规随机不得替选。具体世界仍随机，低/中不因增加重度而失去存续价值。受影响：PurificationScene/InventoryPanel/session/RunController及现行相关spec；I03改UI前执行in-game-ux，I01没有新玩家UI。

**压力时钟归世界，费用归既有系统。** 地图压力保存累计有效时间、阶段、局部区域与阶段seed；advance仅消费有效模拟delta。暂停/失焦/退出期间不推进，恢复不能重抽安全窗口。预兆/高压/回落读同一状态，材料仅决定表现方式；危险按真实局部接触/暴露映射到Host与混乱抗性，避免叠加收费。混乱仍独立保存；新等级不额外提高初始混乱。受影响：RiftScene、HostRuntime、chaos-system与rift-checkpoint/recovery-state。

**收益先验机会与净值。** I03等级配方用CSV表达节点预算及现有功能级机会，不改变“品质不等于功能级”的合同；使用原Inventory/RunController结算，只有成功带回可兑现。至少两条现有装备/技巧准备路线；对照空装、自然可得准备与充分准备，记录消耗、用时、带回、失败损失及恢复趟数。不可仅以成功者最高收益证明重度合理。I06与I13扩大自然供给、多趟选择测试，不把相关测试挪给挂起的I28。

**冻结与原子性负例。** I03必须拒绝未知grade/version/hash，测试重试/刷新同级、压力峰前保存恢复、暂停长于一周期、离线长时间恢复、保存失败重试、死亡/弃局/撤离一次结算、任意档退出后的下一趟选择。当前I01仅旧身份与DEV包负例实际通过；这些新运行负例未实施，不标通过。


## 冻结的测量与资格预算 v1

参考机为本轮实际 M4 Pro / 14逻辑核 / 48GiB，浏览器原生逻辑960×640；具体视口/DPR与版本随证据保存。Windows集显/低端CPU/高DPR均未验证；至少另一档较弱硬件是I14发布前置，不能凭本机通过替代。视觉阈值只守可读下限，不能代签审美。

- **交互主线程**：新增生成、验图、表面预烤不允许连续阻塞>50ms；正式接入前须worker或可中断分片，错误/取消不吞用户存档。I01自然出击测出秒级同步长尾，当前未达标，作为I03正式接入阻断跟踪。
- **离线与载入**：参考机普通自然样本生成p95目标≤5s、冷恢复p95≤5s；单个离线worker硬超时60s，超时保留失败而非补抽换种。目标不能靠放宽路线/身体硬准入实现。I01生成8.31s/恢复8.33s的样本p95不达目标；优化与预编译在接正式新代生成前补证。
- **原生运行**：完整固定镜头路线采样≥60s，帧间隔p95≤20ms、p99≤33.4ms、>50ms帧占比≤0.5%；CPU提交p95≤12ms，以留合成/GPU余量。I01只做每世界12s出生区静止基线，没有60s移动/压力峰资格；暂停/后台片段排除并计数。I02新实体新增CPU提交p95预算≤3ms；超过即改缓存/可见区域，不降原生像素密度掩盖。
- **内存与生命周期**：先锁结构性预算：只有当前世界持有可变纹理/几何/声音，包目录不常驻108份资源；单世界新GPU缓冲估算≤64MiB，新CPU驻留缓存≤64MiB。连续10次进入/离开后资源计数回到同一稳定值，GC后测得的保留内存较初始增长≤10MiB；现有4份layout缓存单列，不当泄漏。浏览器heap读数不是GPU内存，也不能证明GC回收。I01此项未测，I02/I05开始补证。
- **资格种子**：每世界每级先32个固定、预先登记的均匀seed，完整保留失败分母；再8个定向边界（参数端点、紧通道、长退路、压力相位、恢复等）另列。修改后复跑失败种子及受影响闭包；每批另留8个此前未供作者调参的seed，封存后才揭示，不能用补抽消除失败。技术过关仍需至少两次原生完整搜撤/替代路线实证及独立美术/体验审查。
- **成本与拆批**：(32+8)×324=12,960例（另加保留样本）。按I01自然样本均值估算，参考机单串只生成约9.23h；生成+冷恢复约18.00h，加每例双进程装载/指纹约22.48h。只是现算法测量估算，不是新几何或108世界的工期承诺。资格工厂按最多4世界/12格分批，允许有界并行但每进程超时独立；不能因此抽薄重度或跳过美术。
