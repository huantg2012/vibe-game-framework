## 目标与制作对象

交付三个具有实质材料/空间差异的构造能力 × 低/中/重，共九个可连续行走、转灯、观察压力与回落的原生完整地段。旧板/束/壳名称可用于追踪原验证维度，但旧外形不获得保留权，“三条层位”不再是制作指令。九格齐全仍计 0 合格世界，完整准备/风险/收益/搜撤资格在 I03；不据母版直接扩到 108 世界。

画面质量以[集中标准](../art-direction.md#rift-r100-standard)与[重做制作单](../art/rift-r100-masters.md)为准。最新用户裁决覆盖其中尚未清理的旧示例。先做足连续地表与材料描绘，景观从材料形成关系中产生，不能在薄灰底上陈列三个体积模型。

保持原 Rift 960×640 逻辑画布、1.5 相机、32px 原生角色、80px/s 移动、20px 身体、8px 支撑与有限视野；不暗换净化点相机/高精角色、不扩大光圈掩盖问题。借鉴净化点构造/材料/光同源的表现能力，以及实际查看的 Darkwood/HLD 地表组织，不能照搬其配色、题材或斜视立面。

## 实施批次与验收递进

1. **纠正语义并验证。** 普通景观显式区分 `solid`/可走 `relief`；侵蚀吞光由独立作者区域声明。材质阴影只影响受光，不使普通实体/地面从权威视野消失；真实虚空、范围/FOV、实体攻击阻挡各守原有职责。普通障碍透视后不可隔物攻击。先以可查诊断与实际原生转灯验证，不能只调曝光。
2. **完成地表画法。** 连续基材→材料形成事件→成组露面/接边/沉积共同决定描绘与受光。R20 实际采用原始材料母片提供面内描绘、CSV 目视选区与几何/地面事件选择取材、确定性构造生成高度/法向/AO；素材亮度不反推实体或侵蚀。先把小范围画到成品密度，嵌入完整原生视口，再铺展；具体形体/像素加工见制作单。平底色贴斑、闭合石片铺装、平滑波纹或满地颗粒均不作为终稿。
3. **完成第一个完整地段。** 原生角色、安静通路、材料接点、与地床相连的景观、转角/绕行与搜取物同场；进入、贴近、回望都成立。关污染仅作诊断时普通世界仍有材质与地点感。共享几何服务真实厚度/腔体/碰撞，不强制所有绘画效果三维化。
4. **完成同一地段三级。** 低档普通关系可读，中档改变贯穿材料/接点，重档从静态尺度与临界关系形成压力，再加蓄压→传播→短峰→回落。吞光有来源，静区/退路与正常材料保留辨识。此轮表现相位如未接真实危险须明确标注，不能用假伤害暗示机制完成。
5. **完成其余两种能力及九格内部审核。** 迁移已验证的绘画与显隐方法，重新设计各自材料形成/接合，不将同一体块换皮。每格保留正式尺寸截图、连续观察和独立可见判断；低档不能故意简陋，重档不能只更黑更绿更多。发现共性失败回到负责该问题的生成关系修正，不靠轮廓增量拖延。
6. **补运行与声景证据，送人审。** 按 I01 预算测连续原生运行与资源释放；材料/压力声音必须实际审听。内部技术、艺术、动作/公平结论齐备才整理成品供用户审查。人类认可保持待审，不能预填通过，也不能要求用户降低标准替代修复。

每批是持续实施顺序，不是每批结束就停下来重新索要授权。未达到前批质量时先修，不以时间或九格数量抵消失败；也不能以“先做一个”作为本轮只交一个的理由。
