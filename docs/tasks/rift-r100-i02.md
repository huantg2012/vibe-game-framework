# I02：三构造、三级原生美术母版

承接I01的真实兼容底座与预算。制作依据只有[集中美术标准](../art-direction.md#rift-r100-standard)及[九格制作单](../art/rift-r100-masters.md)，不另造平行画风。用户已授权继续；I02母版的人审保留，未经其确认不把方法扩到108世界。

**先做什么：** 折叠板低/中/重形成第一组完整可看、可移动、可验光的小范围，再迁移到纤维结和厚壳腔。场景复用原生Rift角色、80px/s移动、20px身体、8px支撑和有限视野。严格顶视地面不压缩，厚度通过斜切面、卷曲面、端部退台与腔内斜壁可见；不暗换净化点相机或高精角色。

**制作方法：** 同一几何编译实体可见面、实际占地、光学遮挡与法线/材质/高度buffer；独立区分物质存在、可走与透光。静态buffer缓存，动态灯只在局部表面求值。板、束、壳分别使用其受力和生长规则；不得共用立方体贴三种纹理。像素材料先解决大形/中尺度组织，细节服从面和断口。

**入口与范围：** 新`rift-r100-masters.html`是DEV美术局，CSV声明九格配置，生成和几何先于出生/交互座位。直接给RiftDevFixture一个如实标识的作者layout，不伪造正式WorldProductionMap准入。不启用新出击池、等级奖励、压力伤害或v3保存。此轮九格齐全仍计0合格世界，完整玩法资格在I03。

**分工：** r100_native_volumes拥有pure mesh/G-buffer/占地与灯光模块及专项；r100_master_stage拥有CSV、代码生成、作者布局和原生入口、动效；r100_art_baseline独立看图审查，root集成、真实浏览器检查、现行spec/架构/进度与提交。没有独立实际音频验证不签声音通过。

**审核顺序：** 正常960×640逻辑视野静帧→沿同一结构移动→转灯与阴影→关细节/关动态检查体积→三级同源对照→跨材料区别→性能与资源释放。先看图后看作者解释；灰盒、噪点填充、统一绿黑、黑洞假腔、开灯不影响邻面、角色穿插任一成立就退回。交付保留配置/seed/版本/时间相位、原生截图和连续观察，审核意见留[本轮记录](../art/rift-r100-i02-review.md)。

I01发现的主线程生成长尾仍阻断I03正式接入；不能把DEV母版跑起来当成问题已解决。复杂度预算沿[I01任务](rift-r100-i01.md)。
