## 裁决及其依据

- 玩家选择低、中、重污染，具体世界仍随机。重污染提供充分准备后短时深入的机会；不能用强制解锁、某件钥匙或必死倒计时替代选择。
- 沿用母版已验收的材料、实体边界、绿色侵蚀和正常照明。将真实敌人、翻找、污染物、撤离与完整存档接进去，不能把仅有一堆薪柴的 DEV 地段说成完整远征。
- 地图等级改变已有混乱增长曲线、真实地面/空气污染的数量与面积、路线及收益分布。周期危险由实际 Host 的聚集、释放和消散表达；材料的形变、闪动和声音本身不造成数值伤害。不要再使用“污染接点”“承压短峰”等自造词。
- 高等级的增量收益放到必须深入的位置。每档入口附近同为一份 safe 薪柴基础值 1，不给安全堆乘倍率。低污染保留完整收益路线和装备供给，中污染承担日常积累，不能让它们在有装备后失去作用。

## 两种可实际准备的路线

普通品质两主动工具、无额外被动是配装对照基准，不要求靠第三个主动工具完成。普通撬棍／100生命是原起步基准，不是重度必须在无成长状态通过的要求。充分准备可以使用真实连续游玩取得的永久成长、武器和据点状态，同组比较保留完全相同的原始存档，不赠生命、耐久或成长。当前真实低档30趟来源为145生命、抗性3、亲和2、精良撬棍40；原G槽空白相框保留但不允许G输入，被动槽为空，两个既有防御供奉原样保留。“普通”只描述新增两件QA工具的品质，不概括整份成熟装备。以下是验证配置，不是强制入场模板；真实玩家可以空槽踏入和及时撤回。

1. **抗污与压制**：`salted_vial` 盐封药瓶，30 秒增加 20 抗污、普通 3 次；`cold_ash_pipe` 冷灰烟斗，128px 内可见且无遮挡的活动 Host 压制 3 秒、普通 3 次。前者降低正向混乱，不减旧值；后者短时打开真实污染区域的穿越/搜取机会，不冻结实体攻击。两者合计重量 4，撬棍重量 3；不要求第三槽。
2. **B1：消声后引开**（2026-10-04修订，有限实测范围另记）：`gray_felt_glove` 灰毡手套，5秒行动消声、普通5次；`split_tongue_bell` 裂舌铜铃，96px合法投点、实际声路与遮挡决定听见、持续4秒、普通5次。先观察目标与侧路，在接近／翻找前消声，投铃让尚未锁定的听觉目标调查别处，再利用短窗口；手套覆盖移动听觉和正式翻找／挥击发声回调，但不遮视觉、不停止污染、不取消已有CHASE或被击中的直接仇恨。两者合计重量4，不要求第三槽。

**B0历史假设保留。** 原盲针罗盘（128px可走路径、6秒静态快照、普通3次）＋铜铃适合信息取得与前置诱导，但不解决玩家随后移动／翻找再次发声。普通及真实成长壳体实测中，目标曾向早投的铃偏移，接近后重新锁定；靠近战清掉追兵后取得东西不能证明组合完成潜行。本轮不再把B0当作所有强听觉重度环境的完整准备承诺，也不抹去原36／固定样本与手动失败。B1是依据机制和实景明确修订的独立假设，须另留三母版固定单次、普通两工具实际有效并深搜归返的证据；不能给旧B0结果改名。

实际有效使用才记录能力效果和余次。用掉一份普通工具的一次能力不能算获得免费常驻抗性；临时效果不得在暂停、恢复或地图切换后重置时长。正式闭环至少从真实翻得、带回、供奉到成熟配入走一遍；赠送成熟装备仅能用于受控对照，不能证明自然供给足够。

## 36 趟正式运行对照

矩阵为 **3 世界 × 3 等级 × 2 种子 × 2 套普通准备 = 36 趟**。两种子在运行前固定：一个代表通常路线，一个覆盖更长绕行/更差初始巡逻或多处污染的合法候选；不得跑坏后换掉。每个世界/等级同一种子两配装共用同一开局净化点状态，以减少配装之外的差异。

每趟从正式备行链进入；按正常角色与视野行走、真实 E 搜取和撤离/失败，不改节点状态、不传送、不清敌、不改 HP/混乱或暂停作弊。受控初始化普通成熟行装与种子要明确标识，不能混入自然养成统计。QA可自动按键，必须保存输入、状态和原生运行证据；机器可达性另算，不算36趟。

记录：选择及实际包/等级/种子；开始/结束混乱及90/120秒若实际经历的读数；时间、位移、Host接触、发现/交战、工具施用/拒绝/余次、实际搜取和带回、留下物品、生命、结果、归来冲击、真实维修支出。原36趟为B0探路／引开对照，保留原分母，不称重跑成B1。当前功能验证必须观察到A的有效抗污／压制，以及另列B1消声后引开并利用窗口；没有触发则只说明带了装备，不能证明准备有价值。失败占一个真实样本，不能删掉再只报成功。

比较的是“同图下花什么代价取回多少”，不要求两套清空全图，也不强求相同成功率。重度至少每世界两套各一趟带回有意义的深区收益；若同一套只能用无效技能但凭满状态硬取，须回查准备与地形／敌人感知的匹配、目标部署及实际操作，不能将硬取包装为能力有效。低档要能以低接触/低消耗走完较安静路线；中档实际积累应比低档更有效但风险增加；重档收益必须来自真正深入，安全速刷不能优于低档。

**额外、不得塞入36分母**：每世界一次基础合法行装的重度察看后退回；至少一次实际失败后仅用存留库存重新准备；暂停/冷恢复跨 Host 阶段、工具剩余时间与混乱加速区间；入口取消/拒写；出生和撤离不被全部活动范围封死。自然搜得→供奉→带入能力另留一条连续记录。
