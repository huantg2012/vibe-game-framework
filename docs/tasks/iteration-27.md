# 迭代27 · 全游戏补审整改

用户授权：2026-09-18「全修复」。依据[冻结评审](../qa/game-wide-review-2026-09-18.md)全部整改项实施；确认缺陷、待定位症状、设计/美术改善和验证缺口分别收口，不把未测项当不存在。此文是本轮防遗漏清单，跨会话继续从未完成项接续。

## 范围与不变量

- 正式俯视2D入口及共享系统；原角色、速度、光照/遮蔽核心规则不变。空洞仍不可照亮，不以显示未知出口/敌人来修导航。
- 世界观优先；低饱和不是新世界系统统一要求。地表改进是共享绘制能力，不写单seed特供；不自动推广I26新地图至正式随机池。
- 不重开三维；不以新增武器/异物数量解决周转。四B不解锁。24/25占位不消耗。
- 同一系统spec原地维护，数据CSV→code。既存CLAUDE框架改动不碰；本轮不自动commit/push。
- 视觉方向延续已锁角色/装置/界面，使用in-game-ux和pixel-models；无需再抽已锁样式。人的最终审美与机器验证分开记录。

## 制作决策

1. 成长与准备显示以真实运行值统一：生命+15/级；亲和每级使每堆基础薪柴+1，再受储藏倍率影响，最终 `max(1, floor((base + affinity) * storageModifier))`，显示与实际公式一致。
2. 稳定度采用当前已校准常量1/1/3/5/−1，并补缺失事件/一次性结算；首趟教学免冲击按真实出发cycle修正。不是把所有数值回退旧spec。
3. 正式2D续原局沿用现有完整恢复能力和明确放弃政策；不默认刷新死亡，不丢累计据点。旧active无完整世界包必须有明确且事务安全的退出路径。
4. 导航只增强已经看过的路径/撤离线索及可读操作，不揭未探索信息。暂停的载入措辞与物理回程区分。
5. 先验证现有物件的代表战术与周转，再决定必要供给调节；不为让统计好看给自然链补装。
