# 验证问题（人看地图课 / 练习场时回答；再看出击）

1. **四张碎片在画面上是否可分？** 靠渍色 / 纹理 / 划痕 / 脏污 / 结构，不要求底色落到不同暖格，不要求第一层众数互不相同。不要求「好看」，要求能感到是四个世界。图书馆不得读成户外换了个名字。
2. **崩坏簇在户外 / 地铁的新生与标准档，是否能读出青绿？** 旧图书馆同样不得零着色交差。
3. **污染是否仍只在青绿里，没有替碎片做身份（户外绿青 / 医院白青 / 地铁蓝青那种分工）？**
4. **敌人（甲）叠在新地面上，是否仍读得出是污染、没有淹没、没有整只发光？**
5. **暗地占比 / 「极度压暗」是否仍成立？** 本迭代否决了整体提高地板亮度；本问仍要答，确认局部变亮没有把暗地毁了。
6. **地图课走一圈，路是否仍通？** 四张都要抽到。连通不是配色问题，但本迭代碰了烤漆管线与旧图书馆，必须问。

建议打开：`http://localhost:3000/gym.html?lesson=map`（无迷雾，看出击同一套生成 + 烤地），再看句法课 / 陈列馆敌人叠在院子碎片上。裂隙试玩仍算迭代 3 的迷雾问，不要用它代勾本迭代，也不要代勾迭代 3。
