# 验证问题（人看练习场时回答；I5-J 前不看出击）

1. **同一基体的三档覆盖，是否读成结构违规的阶梯，而不是漆更浓、洞更多？**
2. **同一基体同一覆盖档，厅里 8 个采样种子并排，能不能看出是不同个体？** 不靠肩宽 2 像素。
3. **甲的七个骨架语法是否可分？** 街具残骸不要再跟门框是同一根竖杆；三种生物的体轴 / 肢数必须一眼可分；灯柱 / 栏柱 / 标牌杆只作为街具残骸的变体，不要读成三个基体。
4. **污染是否读得出是污染，并与该碎片底色够对比？** 不要求五张碎片靠污染色互相可分。若迭代 6 地面尚未可读，本问标「延后」，不要用坏地面代勾。
5. **疯了之后是否仍是一块身体？** 飘着的构件读作程序错误，不读作疯。
6. **碰撞是否仍是 20？** 在句法课里走两步即可，不靠截图像素量。
7. **生物残余是否仍读成「原物坏了」，而不是污染本身长成了软组织 / 黏液 / 内脏？** 对照 I5-A 定稿的禁忌边界。
