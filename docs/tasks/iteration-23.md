### 优化正文

1. **材质分化。** 裸露岩体/矿化硬壳表现完整大面、硬断口和沿自身结构发展的纹理；松散沉积表现细碎、低反差、凹处和石根的厚薄变化；剥落层片表现翘边/搭接/缺口/薄壳厚度；崖壁表现内部层理、新旧断裂及顺断面的方向。岩石主体有独立质地和尺度，根部才与周围沉积接续。风格统一由色彩关系、笔触和光照建立，不再把共享同一map当成统一的合同。
2. **分布有形成原因。** 凸脊/高处露硬壳，凹槽/背风侧/石根积屑，弯折处定向褶皱与拉裂，搭接处磨损和挤碎物，断缘露内部组织。独立材质层配明确分布遮罩与接触过渡；分布形状需要设计，不用随机噪声铺满。参考[官方地形层混合文档](https://dev.epicgames.com/documentation/unreal-engine/landscape-materials-in-unreal-engine)，后续在现有技术栈适配，不迁引擎、不冒称参考引擎已接入。
3. **补自然地貌的中间尺度。** 在平台和小石头之间补露岩脊、半埋大壳体、浅洼、剥落带和堆积坡；可走空间从结构之间形成。石块有成组/孤立/嵌入/崩落关系，疏密明显变化。保留必要路线连通性，允许重新组织宽窄、坡向与边缘，减少圆台接步道的感觉；不能把现有轮廓冻结成自然造型的限制。
4. **五区具不同地表体验。** 入口肩台沉积较厚、半埋壳片露出；矿化脊大片裸露硬壳、裂隙/凸脊/块状断口；高位冠台较完整大壳面，变化集中接缝和风化边缘，保留壮阔留白；纤维台定向沟槽与局部裸露纤维，顺受力展开；回折台褶皱/搭接/摩擦碎屑与凹处沉积集中。跨区渐变，避免五块整齐分色的主题地板。
5. **绘制感与材质辨识并存。** 保留克制画法，同时各类材料具有独立边缘、明暗和细节尺度。清楚的行走区少细节，但仍有坡面、大块裸露与沉积边界；不靠全屏模糊、整体去纹理或只加滤镜。
