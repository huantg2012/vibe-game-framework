# 当前20世界的视觉区分度重构

用户已依据[专项诊断](../reviews/2026-10-05-r100-world-identity.md)授权“开始吧 / 继续吧”。本批是I07扩产之前的质量修正，覆盖当前20世界；不增加世界数量、不重开无关成长经济，也不据本批宣称完整I07结束。

目标：同一画法与正常潜行视野内，各世界的材料本色、地表纹理节奏、巨构轮廓及通路关系能够被直接辨认。保护获认可的材料层次、断面、碰撞边缘、翻找物来源和污染绿含义。

## 执行顺序与职责

1. 封存修订3生成/校验/表面烘焙及旧资产依据，留下改前20世界正常镜头。`identity_pipeline`负责兼容与材质管线。
2. 新的CSV外观配方覆盖20世界，分别描述地面、表皮、断面及次材料色，保留源图笔触，控制中尺度组织及静区。`world_loot_pixels`负责美术配方与集中制作记录。
3. 用显式构造版本深化已有六材料族的轮廓和空间关系，17派生世界重排尺度、形状和通路；地形、实体与碰撞同源。`identity_shapes`负责几何与原生世界CSV。
4. 根协调者整合、制作正常画面对照、检查邻近世界、运行准入/移动/翻找/恢复/性能专项，修复发现问题，再更新spec/架构/看板/现状索引并本地提交。

## 可验收产物

- 正式生产管线可玩的当前20世界，不以独立画廊实现冒充接入。
- 同种子、相同正常镜头与键盘路线的改前/改后实帧；另一种子和三污染档检查。几何改变后路径结果可能不同，不声称像素级同场景实验。
- 旧修订3及更早存档保持原身份和规则；新包显式新修订，外观配方冻结入合同。
- 生成部署有界、完整身体可走；不可通行处可见。普通实体不获得吞光资格，污染数量/增长/经济保持。
- 内部技术、美术实图及操作范围分别记录；不伪造用户认可、所有随机种子、弱设备或长期体验通过。
