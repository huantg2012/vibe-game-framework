# 范围锁

本包做的是：**占墙、占漆（铺地的漆）、占空（走廊体积场）的外形怎么长出来。** 同一条诊断：现行画法把「手写旋钮 / 核大小 / 云更实」当成天花板，覆盖档不改身份。修法方向沿用已拍板的三层管线概念（骨架或拓扑 → 共享构件或共享漆法 → 覆盖档违规预算；污染漆最后刷），但**落地按孔谱另写**，见下节。

| 孔谱 | 现行失败（设计正文 / HOW 已写） | 本包要锁的方向 |
| ---- | -------------------------------- | -------------- |
| 占漆 | 基体只选长宽比；油膜与灰幕是同一扁带；覆盖档是破洞 / 呼吸幅度滑块 | 基体选拓扑：菌毯 = 团（嵌套瓣）、油膜 = 树（分支脉络）、灰幕 = 环（带孔覆层）。覆盖档 = 拓扑违反自身（子团顶破外沿 / 树闭成回路 / 环里再嵌环）。呼吸仍走 DEC-070 / DEC-071 整团胀缩，不另写第二套 |
| 占墙 | 缝核 1–4px + 覆盖档加厚；身份几乎等于「更粗的核」 | 第一批先写清：在 1–4px、钉缝、不进走廊碰撞的合同里，三层管线如何成立。禁止把占地那套「茎数翻倍」直接套进来把核画进走廊 |
| 占空 | 概念三类云已可分；覆盖档主要是云更实、核更亮 | 第一批先写清：覆盖档如何改**云的结构**（余响圈数 / 脉的折裂 / 错位量），而不是只调 alpha。depth 仍 40，必须低于视野蒙层 |
