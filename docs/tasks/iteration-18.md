# 迭代18：污染句法的完整敌人系统

## 用户目标与边界

让污染句法能够在不同地图中生成大量质量可靠的敌人。数量、模型、动作、行动定位一起验收；不把参数排列数或换色数量当成可玩的敌人数量。发布质量是本轮目标，不是开工即获得的状态。

保留世界观：遇见的是原物遭污染后的实体；污染越深，原物的结构与秩序越少。沿用用户禁止旧审美经验污染的要求，不读取旧审美skill/HOW作为设计依据。虫与人形已认可的模型及动作是当前生产基线，新增家族独立设计，不复制它们的轮廓。

## 工作批次

1. **事实盘点**：生成池与实际地图抽样；词素到AI/危险/表现消费；生产模型与动作覆盖。输出可复现证据，区分缺陷与尚未测试的风险。
2. **生成与行为合同**：把家族的运动能力、有效词素、地图权重和组合合法性变成可检查的数据；兑现有真实应对差异的规则。策划数据CSV→code。
3. **模型与动作批次**：按生物/固着物/环境宿主分别升级；每个家族有独立结构、三档污染递进和符合定位的动作，使用正式危险时钟。低污染可辨基底，中污染明显改写，高污染保留少量线索。
4. **正式遭遇与规模**：地图身份、组合多样性、同屏识别、近身空间、出击分布、资源/性能和生命周期；不靠每张地图塞满敌人来冒充内容丰富。
5. **完整验证**：实际生成种子、动作与伤害同步、遮挡与攻击范围、死亡/重进清理、模型帧边界、构建和针对性机制测试。形成可直接玩的验收入口。

### R4-B 已批准的设计方向（数值与运行合同随实施补齐）

1. **气团**：浑浊、紧聚的体积；以向内挤压→短促外胀区分活动。低污染是被困住的烟气，中污染内部流与外层逆行，高污染收缩的部位出现更大的内部深度。原物线索保留在气体翻滚里，不长脸或拟人肢体。危险候选为有预告的压力脉冲，边缘变化应与真实作用范围一致。
2. **雾团**：悬浮薄层、丝缕和能穿透看见后景的空隙；缓慢分流和重聚。低污染保持湿雾质感，中污染分层互相穿过，高污染折回自身但整体仍可追踪。与铺地灰幕分开：有离地高度和垂落边缘，不涂整块地板。危险候选为缓慢侵占通路，并保留可观察的穿行窗口。
3. **尘絮群**：灰尘、纤维、纸屑等离散物组成悬群；旋聚→偏移→散开。低污染随风聚散，中污染局部逆流/迟滞，高污染颗粒仿佛沿看不见的内部结构循环，仍不画几何框架。不同地图改变残余材料，群体行为保留一致。危险候选为凝聚后短距扫过，不做另一只雾团。

孢子群可作第三项备选，但需避免与菌毯同质、也不替换成清晰昆虫群。以上三档、行为仅用于讨论；具体时序、命中/混乱通道、核心可杀性与数值在方向确定后再形成实施合同。
