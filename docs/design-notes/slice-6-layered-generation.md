# Slice 6 分层生成（草案合同）

看图：`docs/art/demos/slice-6-outline/spatial-drafts/index.html`（十风格一岛）。

生成：`npx tsx --tsconfig tsconfig.json tools/map-preview/render-recipe-drafts.ts`  
闸门：`npx tsx --tsconfig tsconfig.json tools/map-preview/check-recipe-drafts.ts`

**FATAL：连通性。** 陆地一块；墙后地板四连通分量必须恰好 1；装饰层不得拆连通。记忆：`.cursor/rules/map-generation-connectivity.mdc`。规格：`docs/specs/system-map-generation.md` 规则 C。

---

## 人要的两件事

1. **分层出细节。** 在已认可的野外走法上叠装饰、植被、残骸、光影、粒子、波动。
2. **参考点衍生极大样本。** 10 张样例是风格锚，不是地图上限。新图 = 抽一个锚 + 新种子，在邻域里抖参数，不在两个骨架之间插值。

本批不接 `RiftScene`、不放出生/撤离。粒子在静帧里是盖章；天空巨影在预览里用 8 帧循环证明「同一份场只改 `phase`」。裂隙场景仍走旧图，进游戏还不会动。

## 分层栈

结构层才挡路。漆与氛围场绝不写 `walls[]`。

| 层 | 名字 | 挡路 | 闸门 |
| -- | ---- | ---- | ---- |
| 0 | 陆地外轮廓（现成 C1） | 虚空不可走 | 最大四连通块 |
| 1 | 走法骨架 | 墙挡路、挡视线 | 墙后地板分量 == 1 |
| **1b** | **掩护 + 生物性** | 见下 | 墙后仍一块；空洞不得把陆地切成两块 |
| 2 | 残片材质（CSV `frag-*`） | 否 | 不准再写墙 |
| 3 | 风化（只删墙） | 仍是墙 | 风化后再测连通 |
| 4 | 程序化地表 | 否 | 漆 |
| 5 | 植被点 | 否 | 只落已连通地板 |
| 6 | 碎屑漆 | 否 | 不是碰撞 |
| **7–9** | **氛围场** | 否 | 见下。不是几个具名 FX case |

### 1b 掩护体量

挡路、挡视线。切开空地，不封第三边。

**现实现会出迷宫，下一手必须改。** `bisectYard` 沿院子几乎整边劈 1 宽墙、`cuts` 12–18、不够再 extra 细条直到 `sight≤14`——这是走廊工厂，不是掩护。合同旧句「短脊 1×3–5」若漂在院心当篱笆，同样读成迷宫。改完之前的配额见下「墙剪影 / 反迷宫」。

生物性身份叠在这些体量上：

| | 挡路 | 挡视线 | 数量 |
| -- | -- | -- | -- |
| 巨大的树 | 是 | 是 | 0–2（户外/木/宅基；诊所地铁为 0）。见下「桩语法」 |
| 不明生物残骸 | 是 | 是 | 2–4 格团块或短脊 |
| 不明空洞 | 虚空坑 | 否 | 1–3，直径 3–5，必须能绕 |

潜行目标：最大空矩形 ≤ 48，最长轴对齐空直线 ≤ 10。墙+掩护合计不超过约 18%。

层 6 的碎屑漆 ≠ 挡路残骸。漆不挡视线。

### 1b 桩语法

俯视读成**砍断的树桩 + 根**，不是立着的树，也不是青绿树冠。

| 件 | 几何 | 漆 | 规则 |
| -- | ---- | -- | ---- |
| 桩 | 恰好 2×2 | `stump`，深色木头，中心略凹（切面） | 必须能放下。配方 `trees ≥ 1` 时闸门要求至少 1 个桩 |
| 根 | 3–4 条四向臂，各长 2–4 | `root`，比桩更暗、顶沿更弱 | 根之间留角缝可走。长不出根时只落桩，不算失败 |
| 选点 | 优先最大空地，其次离岛缘远 | — | 两棵树曼哈顿距离 ≥ 10 |
| 邻接 | — | — | 桩/根四邻不得是石墙。后续掩护不得贴上去（`reserved`） |

色只走已锁板：`#2a2018` / `#2a1f1c` / `#1a1e18`。禁止用 `#8a5c2a` 当树的暖光（那是玩家设备光）。禁止再画树冠圆团。

### 7–9 氛围场（完整合同）

这是一层**生成**，不是按配方塞几个 `FxKind`。碎片身份仍是 L1 + 骨架（spec 规则 A / 约束 3）。本层不替代障碍语法，只让同一块岛活起来。

**输入**（`AtmosphereSpec`，锚锁定，新图只抖 ±30%）：

| 标量 | 0 | 1 |
| ---- | - | - |
| `skyShadow` | 无天空遮挡 | 巨大体量划过岛的大部分 |
| `fog` | 地干燥 | 缘 / 空洞 / 空地按权重灌满 |
| `motes` | 0 个尘点 | 个数预算（不是 0–1）；实际按雾²加权落下 |
| `seep` | 污染格不渗 | 强 teal 伤口光 + 局部雾 |
| `poolRim` / `poolHollow` / `poolOpen` | 该项不积雾 | 该项主导积雾（归一化） |

**过程**（顺序固定，同种子同图）：

1. 抽共享**风向**（单位向量）。天空体、雾输运、尘点漂移共用这一根轴。
2. **天空巨影**：1–2 个**有限胶囊**（不是无限条带，也不是极坐标膜）。`restCx/Cy` 是 phase 0.5 的静止位；预览/以后动画只改 `phase`，沿风向平移 `slideSpan`，不重跑拓扑。`travel` 做沿轴运动模糊。`skyShadow > 0.48` 时加一颗落后的碎块。影子盖陆地和虚空。
3. **地雾**：按拓扑播种（外缘虚空、内部空洞、离墙远的空地）× 三项权重 × `fog`。墙上压到 28%。污染格按 `seep` 局部加雾。两遍四邻模糊（池化），再沿风向平流一格半。
4. **尘点**：从地板雾²加权抽样，沿风向偏半格。不是均匀撒。
5. **渗光**：每个污染格一枚 teal glow，强度随 `seep`。学净化点伤口渗色，不抄呼吸环。

**输出**（`AtmosphereField`）：`phase`、`slideSpan`、`windX/Y`、`occluders[]`、每格 `fog`、`motes`（含 seep glow）。十锚静帧各烤一份随机 `phase`。动态预览（`atmo-ridge-soil-*` / `atmo-ridge-clinic-*`）同一份场扫 8 个 phase。裂隙场景未接，进游戏还不会动。尘点沿风位移以后再做。

**方言（十锚怎么配，不是 case 分支）**：

- 户外：雾重，缘或空地主导；影中等偏强。
- 沿缘：`poolRim` 主导。
- 撕缝：`poolHollow` 主导。
- 诊所：影很重、雾很轻、`poolOpen` 主导（无菌顶光，不是林雾）。
- 地铁：`seep` 最高，雾轻。
- 图书馆 / 宅基：尘雾中等。

**闸门**：场必须在；`skyShadow > 0.04` 时陆地平均遮挡 ∈ [0.04, 0.88]（测的是落地阴影，不是标量大小序——诊所「更干」不等于「更暗」）；`fog > 0.35` 时陆地雾极差 ≥ 0.06（禁止整图洗一层灰）。漆不得写 `walls[]`。`generateRecipeDraft` 在 `trees ≥ 1` 却放不下 2×2 桩时重试，不静默出无桩图。

本批**已交预览**的机器刹车仍是空矩形 ≤ 80、视线 ≤ 14。人已确认这条视线闸门在倒逼迷宫（见下「墙剪影」）。潜行目标 48 / 10 / 墙约 18% **不要**当下一手的生产循环；48/10 当硬闸门只会更密。波动（`ripple`/`band`）本批未做。

出生 / 撤离 / 薪柴是以后的层 10。本批已交机器闸门：墙后地板 == 1；预览空矩形 ≤ 80；轴对齐视线 ≤ 14（**诊断为过时生产目标**）。空洞不挡视线。木格不得与石墙四邻相接。`trees ≥ 1` 必须至少 1 个 2×2 桩。下一手形状闸门见「墙剪影 / 反迷宫」，未改机器。

父本是 `wilderness-draft` 的三种走法。`masses.ts` 的围院语言不进这条栈。

## 参考点 → 样本空间

一个 `MapRecipe` 锁死：骨架语法 + `fragmentTypeId` + 覆盖方言。禁止「同一褶脊只换 `l1Key`」当新身份。

新图只抖：岛形、脊厚/缺口/段数、污染年龄、残破度、覆盖密度 ±30%。不插值「半褶脊半撕缝」。

可读变体量级约 **10⁶**（10 锚 × 年龄 × 残破 × 岛形 × 骨架参数）。不声称无限群系。

种子：`outline` 用画廊种子本身（十张同一块已认可的岛，比的是配方不是陆地）。结构 / 散射 / 氛围按 `recipeId` 具名分流。同 `(seed, recipeId)` 必须同图。

## 墙剪影 / 反迷宫（2026-08-18）

人看十锚预览：长条墙太多太长，第一反应是迷宫。设计 + 美术独立看图后再互批（DEC-058）。

### 已锁诊断

真实废墟**会**有长墙（院墙、站台），但不会被十几条同样细的正交长条织满。迷宫不是「墙多」，是**墙与路的宽度反了**：1 格墙夹出 1–2 格槽，槽比墙更像主体。暗色板 + 南落影把细墙描成双线，地雾灌进槽，走廊更实。换色救不了。

| 来源 | 做什么 | 迷宫贡献 |
| ---- | ------ | -------- |
| 层 1 | 脊 / 断层 / 平行板 / 双梁 / 空心壳 | `orthoRidge` 6–10 格肋、`plates` 5–6 条长 8–14、贯穿 1 宽 shear、`twinRidge` 等宽巷、`shellOf` 描房间——骨架已是平面图 |
| 层 1b | 掩护 | **主工厂**：`bisectYard` 整边劈、`bisectSightline` 横切最长视线、`cuts` 12–18、最多 16 次 extra stub，直到 `sight≤14` |
| 闸门 | 预览 80/14 | 上帝视角消灭每条 >14 的空直线。实机前向视野 **7 格**、敌锥约 **5.6 格**。`sight≤14` 是生产目标不是安全网 |

只改 1b、或只把 `sight` 放到 18–22，静帧仍是疏迷宫。潜行目标 48/10 当硬闸门会更迷宫。Darkwood 式潜行的单位是「走到体量后面」，不是「全图不存在长空直线」。空地是要过的危险，不是要用篱笆填掉的缺陷。

### 无论密度选哪条，下一手都必须做

未改生成器。改的时候这些是硬条件，不再分叉：

1. 停掉「切到看不见」：最长空直线不再当生产循环目标。
2. 拆 1b 工厂：禁止整边劈院子，禁止 extra 细条，`cuts` 收到 0–4。
3. 层 1 的贯穿 1 格骨架一起改（诊所肋、平行板、双梁、空心壳）。
4. 形状闸门（眼可判，机器也要能判）：
   - 1 格宽直行 ≤6
   - 墙格至少一半属于 2 厚或坨（含桩）
   - 间距 1–2 格、轴向重叠 ≥4 的平行窄槽 = **0**
   - 禁止三向 1 宽巷（2 厚建筑转角仍允许）
   - 至少一块 6×6 空地，内部无细墙，**边缘**有厚掩护
   - 墙占比约 18% **只当顶**，不当「填到接近 18%」
   - 禁 2–4 格宽且长 >8 的巷
5. 坨用实心，不用空心壳。缺边必须整边开口，禁止 1 格门洞。
6. 连通、不封房间、失败不换算法——不动。

断头测的是**墙段尽端停在空地**，不是单入口口袋（口袋仍禁止）。

## 禁令

- 装饰升级成墙；缺口里长草封死。树/残骸是掩护层，不是层 5–9 的漆。
- 用几个具名 FX case 顶替氛围场。
- 空洞把陆地切成两块。
- 围合语法爬回农舍院子 / 闭合房间。
- 用 1 格宽长条织走廊网交差（反迷宫，DEC-058）。
- 换皮当衍生。
- 波动抄净化点极坐标膜。
- 坏连通仍出图。失败只在本栈挖通或重试，不换算法。
