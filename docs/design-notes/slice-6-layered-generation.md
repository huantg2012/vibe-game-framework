## Agent 入口（找策略 / 扩空间）

人说「地图策略 / 空间草案 / 把裂隙再丰富一点 / 加一种身份」：先读本文件，再动手。画廊 PNG 是风格锚的样例，不是要搬进游戏的地图库。

| 角色 | 路径 |
| ---- | ---- |
| 合同正文（本文件） | `docs/design-notes/slice-6-layered-generation.md` |
| 十锚 + 邻域抖动 | `src/generation/recipes.ts` → `PREVIEW_RECIPES`、`jitterRecipe` |
| 出击抽锚生成 | `src/generation/rift-layout.ts` → `pickRecipe`、`generateRiftLayout` |
| 分层栈 | `outline-mask.ts` → `structure-grammars.ts` → `cover.ts` → `stealth-density.ts` → `atmosphere.ts` → `draft-pipeline.ts` |
| 「曾经是什么」底色 | `data/rift-fragments.csv`（正式抽取只开 `enabled: true`） |
| 漆 | `src/generation/preview-paint.ts`；裂隙地面烤一次，天空走低分辨率叠层（`RiftSurfacePainter`）。**DEC-104 / I8-R：** 生产不再铺氛围崩坏簇；看得见的成片青绿是有主占漆。活层技术保留，应用改为占漆宿主 |
| 样例画廊 | `docs/art/demos/slice-6-outline/spatial-drafts/index.html` |
| 再生样例 / 闸门 | `npm run preview:recipes`；`npm run check:recipes`；`npm run check:layout` |

**新图怎么来：** 抽一个锚 + 新种子 + 在邻域抖参数。禁止两种骨架对半插值。游戏必须每次用这套策略生成并烤图，禁止接静帧当成品。

**扩的三种粒度（人点名选一种，不要混）：**

1. **邻域更大 / 更小** — 只改 `jitterRecipe`。语法、`fragmentTypeId`、墙厚、「有没有树」继续锁死；密度 / 掩护计数 / 散射 / 雾影现为 ±30%。
2. **新风格锚** — 在 `PREVIEW_RECIPES` 加一行：锁死骨架语法 + 碎片种类 + 覆盖方言。新身份 ≠ 只换底色。出画廊、过 `check:recipes` 与 `check:layout`。该 `fragmentTypeId` 已 `enabled` 则裂隙会抽到。
3. **新碎片种类** — 改 `data/rift-fragments.csv`（新行，或把 `frag-library` / `frag-residential` 的 `enabled` 改 true），并至少配一个锚用该 id。色只走已锁板。改完跑 `npm run codegen`。

**还没乘进生成器的轴：** 污染年龄 × 残破度（下文样本空间 10⁶ 的后两轴）。要扩这两轴仍走本栈，不要另起生成器。

**禁止：** 把画廊 PNG 拷进游戏当地图；只改着色器 / 底色假装新身份；装饰挡路；坏图换另一套算法；两种骨架插值。

## 分层栈

结构层才挡路。漆与氛围场绝不写 `walls[]`。

| 层 | 名字 | 挡路 | 闸门 |
| -- | ---- | ---- | ---- |
| 0 | 陆地外轮廓（现成 C1） | 虚空不可走 | 最大四连通块 |
| 1 | 走法骨架 | 墙挡路、挡视线 | 墙后地板分量 == 1 |
| **1b** | **掩护 + 生物性** | 见下 | 墙后仍一块；空洞不得把陆地切成两块 |
| 2 | 残片材质（CSV `frag-*`） | 否 | 不准再写墙 |
| 3 | 风化（只删墙） | 仍是墙 | 风化后再测连通 |
| 4 | 程序化地表 | 否 | 漆 |
| 5 | 植被点 | 否 | 只落已连通地板 |
| 6 | 碎屑漆 | 否 | 不是碰撞 |
| **7–9** | **氛围场** | 否 | 见下。不是几个具名 FX case |

### 1b 掩护体量

挡路、挡视线。切开空地，不封第三边。

**已改（方向 1）。** 不再 `bisectYard`、不再 extra 细条、不再切到 `sight≤14`。`cuts` 0–4，只加团块 / 2 厚短板，贴着已有残块。旧句「短脊 1×3–5」若漂在院心当篱笆，仍读成迷宫，禁止。形状闸门见「墙剪影 / 反迷宫」。

生物性身份叠在这些体量上：

| | 挡路 | 挡视线 | 数量 |
| -- | -- | -- | -- |
| 巨大的树 | 是 | 是 | 0–2（户外/木/宅基；诊所地铁为 0）。见下「桩语法」 |
| 不明生物残骸 | 是 | 是 | 2–4 格团块或短脊 |
| 不明空洞 | 虚空坑 | 否 | 1–3，直径 3–5，必须能绕 |

潜行目标：最大空矩形 ≤ 48，最长轴对齐空直线 ≤ 10。墙+掩护合计不超过约 18%。

层 6 的碎屑漆 ≠ 挡路残骸。漆不挡视线。

### 1b 桩语法

俯视读成**砍断的树桩 + 根**，不是立着的树，也不是青绿树冠。

| 件 | 几何 | 漆 | 规则 |
| -- | ---- | -- | ---- |
| 桩 | 恰好 2×2 | `stump`，深色木头，中心略凹（切面） | 必须能放下。配方 `trees ≥ 1` 时闸门要求至少 1 个桩 |
| 根 | 3–4 条四向臂，各长 2–4 | `root`，比桩更暗、顶沿更弱 | 根之间留角缝可走。长不出根时只落桩，不算失败 |
| 选点 | 优先最大空地，其次离岛缘远 | — | 两棵树曼哈顿距离 ≥ 10 |
| 邻接 | — | — | 桩/根四邻不得是石墙。后续掩护不得贴上去（`reserved`） |

色只走已锁板：`#2a2018` / `#2a1f1c` / `#1a1e18`。禁止用 `#8a5c2a` 当树的暖光（那是玩家设备光）。禁止再画树冠圆团。

### 7–9 氛围场（完整合同）

这是一层**生成**，不是按配方塞几个 `FxKind`。碎片身份仍是 L1 + 骨架（spec 规则 A / 约束 3）。本层不替代障碍语法，只让同一块岛活起来。

**输入**（`AtmosphereSpec`，锚锁定，新图只抖 ±30%）：

| 标量 | 0 | 1 |
| ---- | - | - |
| `skyShadow` | 无天空遮挡 | 巨大体量划过岛的大部分 |
| `fog` | 地干燥 | 缘 / 空洞 / 空地按权重灌满 |
| `motes` | 0 个尘点 | 个数预算（不是 0–1）；实际按雾²加权落下 |
| `seep` | 污染格不渗 | 强 teal 伤口光 + 局部雾 |
| `poolRim` / `poolHollow` / `poolOpen` | 该项不积雾 | 该项主导积雾（归一化） |

**过程**（顺序固定，同种子同图）：

1. 抽共享**风向**（单位向量）。天空体、雾输运、尘点漂移共用这一根轴。
2. **天空巨影**：1–2 个**有限胶囊**（不是无限条带，也不是极坐标膜）。`restCx/Cy` 是 phase 0.5 的静止位；预览/以后动画只改 `phase`，沿风向平移 `slideSpan`，不重跑拓扑。`travel` 做沿轴运动模糊。`skyShadow > 0.48` 时加一颗落后的碎块。影子盖陆地和虚空。
3. **地雾**：按拓扑播种（外缘虚空、内部空洞、离墙远的空地）× 三项权重 × `fog`。墙上压到 28%。污染格按 `seep` 局部加雾。两遍四邻模糊（池化），再沿风向平流一格半。
4. **尘点**：从地板雾²加权抽样，沿风向偏半格。不是均匀撒。
5. **渗光**：每个污染格一枚 teal glow，强度随 `seep`。学净化点伤口渗色，不抄呼吸环。

**输出**（`AtmosphereField`）：`phase`、`slideSpan`、`windX/Y`、`occluders[]`、每格 `fog`、`motes`（含 seep glow）。十锚静帧各烤一份随机 `phase`。动态预览与裂隙出击同一份场扫 phase：雾池烤死，天空胶囊沿风向平移。尘点出击中沿本趟 `windX/Y` 随 `phase` 漂（与天空同一根风轴），仍是漆、不挡路；禁止整图 CPU `compositePaint`。视觉死约束见 `docs/art/rift-fragment-surfaces.md`「尘点」。

**方言（十锚怎么配，不是 case 分支）**：

- 户外：雾重，缘或空地主导；影中等偏强。
- 沿缘：`poolRim` 主导。
- 撕缝：`poolHollow` 主导。
- 诊所：影很重、雾很轻、`poolOpen` 主导（无菌顶光，不是林雾）。
- 地铁：`seep` 最高，雾轻。
- 图书馆 / 宅基：尘雾中等。

**闸门**：场必须在；`skyShadow > 0.04` 时陆地平均遮挡 ∈ [0.04, 0.88]（测的是落地阴影，不是标量大小序——诊所「更干」不等于「更暗」）；`fog > 0.35` 时陆地雾极差 ≥ 0.06（禁止整图洗一层灰）。漆不得写 `walls[]`。`generateRecipeDraft` 在 `trees ≥ 1` 却放不下 2×2 桩时重试，不静默出无桩图。

本批预览的机器刹车是形状闸门 + 连通 + 掩护距离（DEC-060：P90≤8，远块≤48）。禁止把 `sight≤14` / 空矩形 48 当生产循环。波动（`ripple`/`band`）未做。

出生 / 撤离 / 薪柴是以后的层 10。墙后地板 == 1。空洞原不挡视线；**DEC-106（2026-08-29）起虚空挡视线（虚空吞光）**。木格不得与石墙四邻相接。`trees ≥ 1` 必须至少 1 个 2×2 桩。形状闸门见「墙剪影 / 反迷宫」。

父本是 `wilderness-draft` 的三种走法。`masses.ts` 的围院语言不进这条栈。

## 参考点 → 样本空间

一个 `MapRecipe` 锁死：骨架语法 + `fragmentTypeId` + 覆盖方言。禁止「同一褶脊只换 `l1Key`」当新身份。

新图只抖：岛形、脊厚/缺口/段数、污染年龄、残破度、覆盖密度 ±30%。不插值「半褶脊半撕缝」。

可读变体量级约 **10⁶**（10 锚 × 年龄 × 残破 × 岛形 × 骨架参数）。不声称无限群系。

种子：`outline` 用画廊种子本身（十张同一块已认可的岛，比的是配方不是陆地）。结构 / 散射 / 氛围按 `recipeId` 具名分流。同 `(seed, recipeId)` 必须同图。

## 墙剪影 / 反迷宫（2026-08-18）

人看十锚预览：长条墙太多太长，第一反应是迷宫。设计 + 美术独立看图后再互批（DEC-058）。

### 已锁诊断

真实废墟**会**有长墙（院墙、站台），但不会被十几条同样细的正交长条织满。迷宫不是「墙多」，是**墙与路的宽度反了**：1 格墙夹出 1–2 格槽，槽比墙更像主体。暗色板 + 南落影把细墙描成双线，地雾灌进槽，走廊更实。换色救不了。

| 来源 | 做什么 | 迷宫贡献 |
| ---- | ------ | -------- |
| 层 1 | 脊 / 断层 / 平行板 / 双梁 / 空心壳 | `orthoRidge` 6–10 格肋、`plates` 5–6 条长 8–14、贯穿 1 宽 shear、`twinRidge` 等宽巷、`shellOf` 描房间——骨架已是平面图 |
| 层 1b | 掩护 | **主工厂**：`bisectYard` 整边劈、`bisectSightline` 横切最长视线、`cuts` 12–18、最多 16 次 extra stub，直到 `sight≤14` |
| 闸门 | 预览 80/14 | 上帝视角消灭每条 >14 的空直线。实机前向视野 **7 格**、敌锥约 **5.6 格**。`sight≤14` 是生产目标不是安全网 |

只改 1b、或只把 `sight` 放到 18–22，静帧仍是疏迷宫。潜行目标 48/10 当硬闸门会更迷宫。Darkwood 式潜行的单位是「走到体量后面」，不是「全图不存在长空直线」。空地是要过的危险，不是要用篱笆填掉的缺陷。

### 无论密度选哪条，下一手都必须做

这些是硬条件，生成器按此改（2026-08-18 人锁密度方向 1 + 正交 B 后落地）：

1. 停掉「切到看不见」：最长空直线不再当生产循环目标。
2. 拆 1b 工厂：禁止整边劈院子，禁止 extra 细条，`cuts` 收到 0–4。
3. 层 1 的贯穿 1 格骨架一起改（诊所肋、平行板、双梁、空心壳）。
4. 形状闸门（眼可判，机器也要能判）：
   - 1 格宽直行 ≤6
   - 墙格至少一半属于 2 厚或坨（含桩）
   - 间距 1–2 格、轴向重叠 ≥4 的平行窄槽 = **0**
   - 禁止三向 1 宽巷（2 厚建筑转角仍允许）
   - 至少一块 6×6 空地，内部无细墙，**边缘**有厚掩护
   - 墙占比约 18% **只当顶**，不当「填到接近 18%」
   - 禁 2–4 格宽且长 >8 的巷
5. 坨用实心，不用空心壳。缺边必须整边开口，禁止 1 格门洞。
6. 连通、不封房间、失败不换算法——不动。

断头测的是**墙段尽端停在空地**，不是单入口口袋（口袋仍禁止）。

### 已锁：密度方向 1 + 正交 B（2026-08-18 人拍）

**厚短残块铺开。** 十锚靠形状分，不靠细线拉满岛。掩护贴在已有残块旁边，不在院心拉篱笆。

**诊所 / 地铁也收成短板 / 坨。** 全图最多一把 L（无菌折脊用这一把，臂 4–6、厚 2、开口泻空地）。禁止再织 T/+ 正交网。直角不是禁令，1 宽贯穿肋才是。

| 锚 | 落地剪影 |
| -- | ---- |
| `ridge-soil` | 一根 2 厚弯脊，长 6–10，中有缺口，脊上可粘 1–2 坨 |
| `shear-soil` / `shear-clinic` / `shear-metro` | 2–3 段厚唇，唇长 4–7、厚 2，唇间距 ≥3，错开，禁止平移 2 格描巷 |
| `hunks-soil` | 3–5 块实心 2×3～4×4 |
| `rim-soil` | 贴岛皮 2 厚、2–3 段，岛心空 |
| `ridge-clinic` | **一把** 2 厚 L |
| `hunks-metro` | 最多 3 条板，厚 2、长 5–8，条间距 ≥4 |
| `ridge-library` | 两截短梁，厚 2、长 5–6，间距 3，两端开口 |
| `hunks-residential` | 1、最多 2 个三边框，开口整边，框墙厚 2 |

层 1b：`cuts` 0–4，只加团块 / 2 厚短板，贴着已有墙；禁止 `bisectYard`、禁止 extra 细条、禁止院心 1×N。

机器闸门改打形状（见上），`sight≤14` 不再 FATAL。墙占比 18% 是顶。连通仍 FATAL。

落地后空地过大（DEC-059）。人看五案后授权结合（DEC-060）：D 当尺，A 落点，B 缝宽/停手，C 只给适合的锚切盆地，E 法兰上限。人随后要求空地再收约 20%：先切最大空地再长法兰，空矩形目标约 96、顶 112（沿缘岛心除外）。实现：`src/generation/stealth-density.ts`，接在 1b 之后。种子 101 实测墙约 18%、空矩形 72–99、掩护 P90 5–7。禁止把视线工厂请回来。十锚图待人认。

## 禁令

- 装饰升级成墙；缺口里长草封死。树/残骸是掩护层，不是层 5–9 的漆。
- 用几个具名 FX case 顶替氛围场。
- 空洞把陆地切成两块。
- 围合语法爬回农舍院子 / 闭合房间。
- 用 1 格宽长条织走廊网交差（反迷宫，DEC-058）。
- 换皮当衍生。
- 波动抄净化点极坐标膜。
- 坏连通仍出图。失败只在本栈挖通或重试，不换算法。
