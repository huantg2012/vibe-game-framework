### 世界观硬约束（直接引用，不改写）

来自 `docs/world.md`：

- **不同污染源互相排斥。** 每个外来存在的改写模式是排他的；两种模式接触时互相干扰、抵消。**一种污染的残留物对另一种污染有天然的抵抗性。这是净化点防御系统的物理基础。**
- **冲击不是敌人来攻击**，是本时空的污染在持续压迫净化点边界。
- 残渣 = 两种改写模式在接触界面干涉后产生的、「两边都不是」的东西。
- 净化点不自持，它在被缓慢侵蚀，需要外来的对抗性物质来维持边界。

推论（这台装置存在的物理理由）：**把异源残渣支在压力里，本时空的污染压过来会被它顶住。残渣在顶的过程中被改写，顶够三次就不再是残渣，成了工具。**

## 2. 已锁身份（人 2026-09-04）

**一台同时起收容、控制、暴露三种作用的装置。**

原文：「不能简单画成个【架子】，它应该是一个起着收容、控制、暴露多种用途的【装置】。」

三种作用同时成立，这就是它的张力所在：

| 作用 | 它对残渣做什么 | 为什么必须有 |
| ---- | -------------- | ------------ |
| **收容** | 把异源残渣扣在里面，不让它散到净化点里 | 残渣是别的时空的污染物，不能随便放着 |
| **控制** | 用人造手段把它按住、固定住 | 它不配合；人得把它锁死才能用它 |
| **暴露** | **故意朝外开一面**，让本时空的污染压力打在它身上 | 这是防御生效的物理条件；不暴露就顶不住 |

装置本身不出力、不加工、不点火。转化是**冲击**做的，不是它做的。它只负责把东西扣住、并且把它摆在压力里。

「供奉」是这个动作在玩家侧的名字（你把捡回来的东西交出去挨打），不是宗教献祭。

### 必须共同服从的读法

1. 读出**里面扣着东西**，而且是异源的（污染侧 teal，不是薪柴、不是工具、不是战利品）。
2. 读出**有人造手段在按住它**（夹 / 围 / 浇，人的活儿，磨损但有维护）。
3. 读出**朝外那一面是敞的**，压力从那儿进来。

### 与储藏的关系（这条最要紧，别做成同一台）

储藏锁的是「收容体」——**只关，不开**。供奉台是**关住 + 按死 + 故意开一面**。两台都收容，区别在**有没有那个朝外的敞面**，以及**为什么开**：储藏开缝是为了让你看见；供奉台开面是为了让它挨打。

### 外观不显槽数（人拍板）

原文：「从外观不需要看出明确的槽位数量。」

所以**不画可数的槽位**。你看到的是一台扣住异源物质的装置，里面的东西不可数。这同时解掉了「基础 3 槽、改造后 4 槽，贴图不能画死」的矛盾——第 5.2 节三个解法全部作废，改为：**装置结构钉死，里面那点 teal 是活层，不对应具体槽位。**

### 禁止读成（每一条都有具体的撞车对象）

| 禁止读成 | 为什么 |
| -------- | ------ |
| 祭坛 / 神龛 / 香炉 / 火盆 | **核心 v6-B 已经是「石构神龛、在烧东西」**（DEC-111），西边 3.5 tile 还有一台正式叫「改造祭坛」。三个祭坛并排就废了。**具体禁令：青绿绝不许溢出口沿往上飘**——那一下就成香炉 |
| 收纳柜 / 箱子 / 板条箱 | 剪影误读清单「宽矮的块 + 顶面亮带 = 箱子 / 板条箱」那条。要加高、破对称、长进地里 |
| 储藏 C1 的翻版 | 见上「与储藏的关系」。必须有朝外的敞面 |
| 武器架 / 战利品陈列 | 架上的东西不是你的装备，是拿去挨打的耗材 |
| 熔炉 / 加工台 | 转化是冲击做的，它不出力 |
| 第五台承血模块 | 它没有完整度、不吃薪柴注入、不进 `PurificationModuleEntity` |
| 界面图标 / 读数盘 | 它是世界内装置 |

## 3. 可分维度（抽卡时只许拆这些）

**换过一次（人 2026-09-04，第一轮之后）。**

第一轮拆的是「用什么手段收容与控制」（夹 / 围 / 浇）+「朝外那一面怎么开」+「在挨压怎么读」。
结果三张全是同一句形体——`iso_prism` 实心方块 + 前左面开一个洞，只有块的高矮与表面纹理在换。
人的原话：「三个卡本质上是同一个方向只是调整了大小，区分度非常低。」

**教训：手段（夹 / 围 / 浇）是表面处理，不是形体。在 32×32 的剪影上，它只值几像素的纹理差；
真正决定「第一眼是不是另一个东西」的是体积怎么占空间。** 所以第一轴换成形体类：

1. **形体类**（第一眼的剪影归类，一张卡一类，不许两张同类）：
   - 方块——竖立的实心块，开口在某个可见面上（第一轮 A / B / C 都在这里）
   - 横向外伸——重心与体量偏向一侧，长臂把残渣送出装置本体之外（卡 D）
   - 竖向细高——细柱贯到顶，残渣被中段的箍咬住（卡 E）
   - 贴地矮宽——几乎不往上长，横向铺开，开口朝上（卡 F）
2. **朝外那一面怎么开**（敞口 / 断条 / 留洞 / 指缝 / 月牙；开在哪个可见面上）
3. **「在挨压」怎么被读出**（活层：里面的东西在顶，以及受力的痕迹）

禁止把外观 × 槽数 × 动效排成碎片。每张卡是完整组合。
