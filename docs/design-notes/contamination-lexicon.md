## 1. 背景

### 1.1 问题（人提出）

两种敌人、每种一个形态，玩家体验单调，且与程序生成式的裂隙关卡不相称。目标：构建可以生成海量敌人形态的系统。

现有对照（实现真相，不是要删掉的遗产）：

- 一份五态：巡逻 / 警觉 / 警戒 / 追击 / 归位。
- 两种剖面：渗透体以视锥为主；改写体以听觉为主、视锥更窄；每图恰好 1 个改写体。
- 基体在世界观里已按有机 / 无机 / 概念分类，但出击里两种都还是「会走路的污染体」。
- 覆盖体（高度覆盖）未做。`world.md` 写它「原有形态几乎不可辨」。

### 1.2 符文之语的启发（人明确：不是抄）

人提起《暗黑破坏神 2》的符文之语，不是要做镶孔装备或词缀伤害表，而是要一种启发：**用有限维度、每维有限取值，组合出海量内容。**

真正能借的结构不是「传奇词缀列表」，而是：

| 暗黑 | 污染词法要借的 |
| ---- | ---------------- |
| 白装底子 | 基体 × 覆盖深度（它曾经是什么、改写到哪一步） |
| 孔数与孔型 | 连续性 × 占位（它在这张生成岛上怎么存在） |
| 符文 | 词素（运动 / 感知 / 节律 / 接触），只能从该孔的合法字母表抽 |
| 合法顺序 | 本趟裂隙风格锚的方言：同一张图一种污染源，不是动物园 |
| 符文之语 | 成句：少数具名遭遇 |
| 未成句的孔里货 | 无名变体：大量日常污染体，没有传奇名，但六件套仍由规则填满 |

笛卡尔积负责**样本空间**；语法负责**不像随机时装**。若有 m 个维度、每维 n 个取值，样本空间是 **n 的 m 次方**（不是 m 的 n 次方）。可玩集合是这个空间上的合法子集。

战斗纪律不跟着暗黑走。`system-combat.md` 的成功标准仍是：「如果试玩者开始享受战斗，本系统就失败了。」词素改的是绕 / 冲 / 杀的价目表（时间、路线、混乱、暴露），不是 DPS 堆。

### 1.3 爆炸思考：先拆维度，再砍

对话里先做了维度爆炸，明确要求敌人原形不拘泥于人类：可以是生物、某种物质、非生命事物、不可名状之物。炸开过的族如下。**未写入「人点名保留」的族，不是第一版词法的独立骰子。**

| 族 | 想过什么 | 第一版怎么处理 |
| -- | -------- | -------------- |
| 基体 | 有机残影、物件、建筑切片、物质、过程/痕迹、空间关系、不可名状 | **保留为底材。** 第一版封闭六种可画基体。不可名状必须先寄生在某一层占位上，否则不是对象 |
| 覆盖深度 | 渗透 / 改写 / 覆盖 / 交界残渣 | **保留。** 三档与世界用语对齐。交界残渣不当自由取值 |
| 连续性 | 单核、裂片、菌落、场、诱饵体 | **保留孔谱半边。** 诱饵体不作为自由连续性，只作成句 |
| 占位 | 占地、占墙、占漆、占空、占声、占相位 | **保留孔谱半边。** 占相位并入节律，避免与占空/占漆抢定义。占声不进第一版主课 |
| 运动语法 | 巡路、沿壁、簇间跳、凝聚、转面、拖尾、固着、随风 | **衍生槽：运动词素** |
| 感知通道 | 视、听、触地、嗅混乱、反视、嗜薪/工具/静止 | **衍生槽：感知词素** |
| 注意节律 | 常开、脉冲、潮汐/天空相、睡眠、记忆长短、一次性升级 | **衍生槽：节律词素** |
| 接触与止损 | 三刀、挥击无效、踩踏混乱、重组、广播 | **衍生槽：接触词素** |
| 尺度 | 霉斑 / 人高 / 走廊 / 天空巨影 | 不独立。走廊尺度走占空场；巨影继续当氛围，落地的是占空的一小截 |
| 器官错位 | 亮核、裂缝眼、工作面、声从别处来 | 不独立。可读核由占位 + 外观合同保证 |
| 与生成器挂钩 | 钉簇、钉墙缝、钉喉、钉风 | 不独立。出生规则写在孔谱与抽卡配额里 |
| 关系 / 小生态 | 共享警觉、模式互斥、器官分离 | 第一版不做自由维。广播是接触词素之一；双占位是第二批成句 |

硬筛（爆炸时就写下的，词法必须遵守）：

- 改不了「绕 / 停 / 打 / 走哪一层」的维，降为皮肤，不进形态枚举。
- 一份五态。差异进剖面 / 占位 / 刺激，不进第二套 AI。
- 可追击的个体仍守玩家视距优势、撤退可行（现有 I1–I6）。不追击的孔谱改写不变量，不许偷偷打破。
- 同图污染方言要统一。海量来自基体 × 词素，不来自每只一个宇宙。

### 1.4 人点名保留的轴（设计输入）

人挑选后要求跟进适配、设计真正的组合制度：

1. **基体 / 覆盖深度** — 必要核心。
2. **连续性 / 占位** — 决定污染体底层逻辑（外观、行为、攻击、感知都与此挂钩）。占位尤其被点名为关键：它决定能否移动、感知与攻击如何定义，进而决定玩家是绕、硬冲，还是击杀。
3. **运动语法 / 感知通道 / 注意节律 / 接触与止损** — 在 1 与 2 上**自然衍生**，不是再掷一套独立骰子。

人补充的落地硬约束：空间内的元素必须能落到游戏对象上——无论如何要有明确的 **外观、生命期、移动、感知、攻击、死亡效果**。

人确认符文之语的映射可以当出发点。

### 1.5 制度怎么从这些输入收束

八个名字不是八个并列开关。

- **底材** = 基体 × 覆盖深度。暗黑里的白装。
- **孔谱** = 连续性 × 占位。暗黑里的孔数与孔型。决定画在哪一层、挡不挡路、追不追、血怎么计。
- **词素** = 运动 / 感知 / 节律 / 接触各填一个。只能从该孔谱字母表与本图方言的交集里抽。
- **成句** = 少数具名配方。语法允许，但不随机拼出来。

渗透体与改写体不再解释成「两个物种」，而解释成 **同一孔谱（单核 × 占地）的两种填法**。覆盖体不以第三种人形出场，而以非人形成句（缝、场、体积）第一次出现。

## 2. 六件套：不允许存在「概念生物」

凡合法出生的个体，生成器必须一次写完：

| 件 | 由谁决定 | 落地成什么 |
| -- | -------- | ---------- |
| 外观 | 基体给剪影与残余；覆盖深度给材质改写程度；占位给画在哪一层；连续性给几块、有没有中心 | 程序像素，或地面 / 墙缝 / 雾团体积上的漆。不是一句设定 |
| 生命期 | 节律给「何时是活的」；出击结束必回收；死亡可留残骸，残骸也是一个更短的六件套 | 睡眠 → 醒来 → 死亡 → 残骸 → 消失，每段有钟 |
| 移动 | 占位先砍掉非法走法，再填运动词素 | 路点、沿墙图、簇间、转面、固着、随风。没有「抽象游荡」 |
| 感知 | 占位决定探测器钉在哪；连续性决定一个还是多个；再填感知词素 | 仍写入同一份察觉度 0–1。追击锁定须满足该孔谱规则 |
| 攻击 | 接触词素给意图，占位给实现 | 近战扇形、邻格抽打、踩踏收混乱、场内加速混乱。没有「精神攻击」空包 |
| 死亡 | 占位给默认残骸层；接触词素可改写（干净消失 / 留下漆 / 打散重组） | 必有可见结束。禁止只从名单里删掉 |

连通硬约束写进语法：**菌落与场不得变成额外的墙。** 只有单核、裂片可以「占地且挡走」。否则程序地图的可走区会被污染体切开。

## 3. 底材

### 3.1 基体（第一版封闭六种）

基体不取「不可名状」当自由取值。不可名状若要落地，必须先有一层可画的占位。

| 基体 | 残余动词（低度覆盖时必须可读） | 合法占位 | 合法连续性 |
| ---- | ------------------------------ | -------- | ---------- |
| 有机残影 | 走、转头、咬 | 占地 | 单核、裂片 |
| 灯柱 | 亮、扫 | 占地（默认固着） | 单核 |
| 门框 | 开、合、夹 | 占墙，或占地但固着挡门洞 | 单核 |
| 墙锈 | 渗、刮 | 占墙 | 单核、菌落 |
| 菌毯 | 铺、胀 | 占漆 | 菌落、场 |
| 油膜 | 流、沾 | 占漆，或占空（DEC-076：否则孔谱丁没有合法基体） | 单核、菌落、场 |

同一裂隙仍遵守世界规则：差异来自基体，污染方言来自这张图的风格锚。青绿量化、年龄滑动跟地表合同走，不另发明色板。

### 3.2 覆盖深度（开孔，不是第三种人形）

| 深度 | 世界用语 | 开孔 | 残余动词 | 成句资格 |
| ---- | -------- | ---- | -------- | -------- |
| 渗透 | 低度 | 感知只开一条主通道；运动被残余动词锁死一半 | 强（灯还想亮，门还想关） | 通常不成句 |
| 改写 | 中度 | 感知可双通道；运动可偏离残余 | 半在 | 可成句 |
| 覆盖 | 高度 | 残余关闭，字母表开到该孔谱上限 | 无（原形几乎不可辨） | 成句主要发生在这里 |

## 4. 孔谱

### 4.1 占位五层

都是这引擎里已有、或可长在已有层上的东西：

- **占地**：实体层，可挡走（仅单核 / 裂片）
- **占墙**：钉墙缝，不封走廊
- **占漆**：钉崩坏簇 / 可走地板污染，跟已有烤漆与整团胀缩活层
- **占空**：挡视线或不挡走的体积，深度在实体与视野蒙层之间
- **占声**：几乎不挡，改听觉半径或把噪声当皮肤

**占相位不单独占一层**，并入节律词素（随天空巨影的相、随簇呼吸）。

**诱饵体不作为自由连续性。** 「眼在缝里、脚在油里」强制两个占位、两套六件套绑成一个注意，只作成句。

### 4.2 合法矩阵（空格 = 生成器丢弃）

|  | 占地 | 占墙 | 占漆 | 占空 | 占声 |
| -- | -- | -- | -- | -- | -- |
| 单核 | 可挡走，可追击 | 沿缝，抽打邻格 | 一滩有核 | 一团有核的雾 | 一个声源核 |
| 裂片 | 可挡走，共享注意 | 多缝一心 | 多斑一心 | 非法（雾切成片难读） | 多扬声器一心 |
| 菌落 | **非法挡走** | 许多墙斑，不挡路 | 簇上铺开 | 非法（满图雾不可学） | 非法（满图响不可学） |
| 场 | **非法**（会变成移动的墙） | 非法（整面墙是敌人 = 封图） | 整片簇场 | 一段走廊的错体积 | 一段窄喉的声场 |

每一格孔谱的四条衍生槽字母表是砍出来的，不是再枚举一次全世界。

### 4.3 第一版四张主孔谱

海量来自填词；记忆来自孔谱。玩家先学四句。占声不进第一版主课（与改写体听觉主轴抢教学）。裂片占地可晚做（甲的血条写法变体）。

写入本稿时，人要求落文档，未另选「用占声换掉占空」。默认锁定甲乙丙丁。实现前若要换一张，须新决策。

#### 孔谱甲：「会走路的东西」（单核 × 占地）

现状住在这里。对照用，不许删。

| 件 | 默认落地 |
| -- | -------- |
| 外观 | 32×32 或 32×48 程序像素，碰撞约 20。剪影来自有机残影或灯柱 |
| 生命期 | 常开或睡眠；打死进尸体清理；出击结束回收 |
| 移动 | 巡路 / 转面 / 凝聚。追击 = 地板寻路。速度仍受「玩家更快、撤退可行」约束 |
| 感知 | 视锥或听觉为主，写入察觉度。看见才锁定追击 |
| 攻击 | 贴身扇形，前摇可躲，默认三刀账 |
| 死亡 | 实体消失；渗透深度可残一点基体轮廓 |

玩家对齐：等它走过去（绕）最便宜；硬冲吃前摇；击杀付混乱 + 噪声。

现有两种填法（实现已在，词法承认它们）：

- 渗透体：有机残影 × 渗透 × 单核占地 × 视锥 × 常开 × 三刀近战
- 改写体：有机残影 × 改写 × 单核占地 × 听觉为主 × 常开 × 三刀近战

#### 孔谱乙：「缝在看路」（单核 × 占墙）

| 件 | 默认落地 |
| -- | -------- |
| 外观 | 钉在墙缘的锈 / 门缝 / 亮核，不占走廊碰撞 |
| 生命期 | 固着或沿墙图滑动；死则缝合上或留下墙斑 |
| 移动 | 沿壁渗、转面、固着。禁止穿开阔地追击。追 = 沿墙滑到离玩家最近的邻接缝 |
| 感知 | 探测器在缝上，视 / 听 / 触只扫邻接的可走格。走廊中央 ≠ 安全；贴墙才是它的嘴 |
| 攻击 | 邻格抽打（有前摇的地格危险）。挥击必须打到缝上的核 |
| 死亡 | 核灭，抽打停；可留不挡路的墙锈 |

玩家对齐：走路中、别贴墙；冲 = 穿过正在抽打的邻格；杀 = 找缝里的亮核。

门框低度覆盖时，残余动词锁成「开合」：门洞这一格周期性变成抽打格。

#### 孔谱丙：「地在呼吸」（菌落或场 × 占漆）

与程序关卡、崩坏簇活层咬合最紧。簇已经在胀缩；这张孔谱让「那团漆」有生命期。

| 件 | 默认落地 |
| -- | -------- |
| 外观 | 不另做小人。用已烤的簇核 + 活层中间 / 外圈。菌落 = 多团；场 = 这一片污染方言 |
| 生命期 | 跟簇呼吸或常开；被踩 / 被打改变强度；出击结束随地表回收 |
| 移动 | 簇间跳、胀缩、固着。没有地板寻路。核可以慢慢迁到邻簇 |
| 感知 | 主通道是触地。嗅混乱可作辅通道。无追击锁定 |
| 攻击 | 踩踏收混乱，或在胀满相位提高踩踏价。默认不挥刀打玩家的血。可打核降低场强 |
| 死亡 | 核灭则该团不再伤人，漆可留作无害纹样；场则整片休眠 |

玩家对齐：绕开污染斑、等它缩；冲 = 付混乱抄近路（「还敢不敢再多拿一点」）；杀 = 清核，通常比绕贵。

连通：漆不改碰撞。

#### 孔谱丁：「这段路本身在工作」（场或单核 × 占空）

| 件 | 默认落地 |
| -- | -------- |
| 外观 | 走廊尺度的错体积：挡视线的雾、假墙、或宽度错了的暗带。单核有可打的核；场只有强度 |
| 生命期 | 脉冲或随天空相；相没了就不是实体，相来了才挡眼、才可打 |
| 移动 | 固着或随风慢漂。不寻路追人 |
| 感知 | 领域察觉，或反视（玩家视野扫到核它才醒） |
| 攻击 | 在体积内加速混乱或缩短视野，不默认同款近战。打 = 打核驱散 |
| 死亡 | 体积散；短暂看得见出口 |

玩家对齐：改道绕开整段；冲 = 盲穿付视野 / 混乱；杀 = 驱散核。节律让「等相过去」成为第四种绕。

呼吸层与占空体积必须低于裂隙视野黑暗蒙层。迷雾下亮度等人终审，本文不写好看。

## 5. 填词

四槽各抽一个词素。抽之前与孔谱字母表、本图方言、覆盖深度求交。交为空则重抽，不许拿最近的非法值凑。

每个词素必须能改六件套里至少一件，否则逐出字母表（那是皮肤）。

**运动：** 巡路、沿壁、簇栖、转面、固着、随风、拖尾、凝聚  
**感知：** 视锥、窄视、听噪、触地、反视、嗅混乱、领域  
**节律：** 常开、脉冲、睡眠、随簇呼吸、随天空相  
**接触：** 三刀近战、邻格抽打、踩踏混乱、场内加速混乱、打散重组、驱散才死、广播

自动改写：

- 接触抽到「三刀近战」但孔谱是占墙 → 改写为邻格抽打。
- 接触抽到「三刀」但孔谱是占漆 / 占空 → 改写为打核驱散 / 降强度。
- 运动抽到「巡路」但占墙 → 巡的是墙图，不是地板路点。
- 感知抽到「视锥」但占漆 → 视锥降为辅，主通道仍是触地。

无名变体的六件套 = 孔谱默认表 ∪ 四个词素的覆盖规则。生成器不许输出「待美术决定」。

覆盖深度调节开哪些槽、残余动词锁死哪一槽，不另乘一套完全独立的表。粗算第一版四张主孔谱、每槽约 3 个合法词：大约 \(4 \times 3^4 = 324\) 个无名填法。玩家要学的是四句孔谱 + 十来个词素，不是 324 个名字。

## 6. 成句（第一版四句）

成句是内容高峰，不是另一套生成器。各教一张孔谱的极限，并让覆盖体以非人形出场。

1. **门还想关** — 渗透 · 门框 · 单核占墙 · 固着 · 脉冲 · 邻格抽打。门洞这一格按节律开合。
2. **缝里的眼** — 覆盖 · 墙锈 · 单核占墙 · 窄视 · 常开。核在缝里。贴墙等于走进视锥。
3. **簇的肺** — 改写 · 菌毯 · 场占漆 · 随簇呼吸 · 踩踏混乱。与已锁崩坏簇整团胀缩是同一口气。
4. **走廊在看你** — 覆盖 · 场占空 · 反视 · 随天空相。视野探进那段错体积，它才醒来。

「眼在缝、脚在油」列为第二批成句。第一版不做。

上列四句是**内部配方名**，禁止印在 HUD / 遭遇识别旁白上（传奇口吻，且 `world.md` 禁暗黑式称号）。游戏内怎么认出遭遇了什么、成句短标记怎么上屏、限频怎么挡刷——同一套体系的识别面见 **§7**。规则合同 `docs/specs/system-contamination-lexicon.md`；表面合同 `docs/specs/ui-encounter-narration.md`（DEC-074 / DEC-075）。

## 7. 遭遇识别旁白（同一套体系的识别面）

污染词法生成形态；遭遇识别旁白是同一套体系里玩家认出「刚才遭遇了什么」的那一面。不是第二套玩法，不是独立 HUD 产品。读者只读本文件应能同时理解「形态怎么生成」和「玩家怎么认出遭遇了什么」。限频与身份键的规则合同见 `docs/specs/system-contamination-lexicon.md`；载体、参考锚点、视觉规格、U1–U12 见 `docs/specs/ui-encounter-narration.md`。

### 7.1 为什么需要识别面

世界可读仍是第一课。缝里的核、簇的胀缩、体积的相，必须先能在世界上读到。没有这一课，字再准也只是说明书：玩家会盯着一行记录，而不是盯着走廊。

污染词法第一版大约有三百多个无名填法。玩家要学的是四张孔谱加十来个词素，不是三百个名字。海量填法会让「刚才碰上的是哪一种」在识别当下滑走——尤其是非人形占位（墙缝、漆、体积）不像会走路的身体那样自带「这是一只敌人」的旧习惯。识别当下需要一次强化，让组合项在那一拍被读成一种东西，然后闭嘴。

头上挂名字会把裂隙变成 RPG 名牌场：迷雾里的身体被标签挡住，绕 / 冲 / 杀变成读牌而不是读世界。遭遇识别旁白用随身罩一行现场记录，在第一次可识别时把组合项报出来。它强化识别，不替代身体。

### 7.2 教什么

一行记录只强化已经写进词法的课，不另发明身份。孔谱四句仍是玩家先学的记忆：占地是会走路的东西，占墙是缝在看路，占漆是地在呼吸，占空是这段路本身在工作。覆盖深度、基体、占位分节点上屏；占地再加主感知节点，用来分开甲上已有的两种填法。成句用短行为标记从无名变体里跳出来，不是传奇名。

| 节点 | 教什么 |
| ---- | ------ |
| 覆盖深度 | 改写走到哪一步（渗透 / 改写 / 覆盖） |
| 基体 | 它曾经是什么（有机残影、门框、菌毯……） |
| 占位 | 它钉在哪一层——孔谱四句的半边：占地 / 占墙 / 占漆 / 占空 |
| 占地主感知 | 只给占地：视锥还是听噪等 |
| 成句短标记 | 少数具名遭遇：开合 / 缝视 / 呼吸 / 反视 |

### 7.3 与世界可读的关系

遭遇识别旁白是强化，不是替代。缝核、簇胀缩、体积相必须先能在世界上读到。旁白不得让实现把缝 / 簇 / 体积画成不可辨的色块再靠字救命。世界读得懂时，这一行是确认；世界读不懂时，这一行不合格——回去改孔谱落地，不加大字号、不加图鉴。

### 7.4 文案骨架

设备打字，不是小说。骨架固定为：

```
识别。[覆盖深度] [基体] [占位]
```

占地加主感知节点：`识别。[覆盖深度] [基体] [占位] [视锥|听噪|…]`

节点分开。禁止粘成会被读成复合传奇名的一句（例如「渗透门框墙缝体」）。「识别。」是随身罩记录仪的设备骨架，不是第四个身份词。节点之间用空格或已有 HUD 间隔，不用间隔号堆成暗黑词缀串，不用「体」当后缀硬粘。整行（含「识别。」）按详细描述计不超过 40 字。无人称。禁止「你」、感叹号、软件词。

### 7.5 成句短标记

内部配方名禁止上屏。游戏内只加一个短行为标记节点，用已锁污染侧 teal 与 1px 错位强调，字号不放大。

| 内部配方（禁止上屏） | 上屏短标记 |
| -------------------- | ---------- |
| 门还想关 | 开合 |
| 缝里的眼 | 缝视 |
| 簇的肺 | 呼吸 |
| 走廊在看你 | 反视 |

### 7.6 限频

身份键只给限频用，不给玩家看。

- 成句：`utteranceId`
- 无名变体：`coverage + substrate + occupancy + continuity`；占地再加主感知词素（否则渗透体与改写体撞键）。不把运动 / 节律 / 接触四槽全编进键，否则几乎永不「相同」。

同身份键本趟 60s 冷却（从该行开始显示起算）。任意身份两条记录间隔 ≥ 2.5s（含上一条淡出）。同时只允许 1 行。与混乱阈值重叠时阈值优先，这次作废、不补打。出击结束清空冷却表，不进存档。

持续留在可识别里（一直看着同一只）= 同一次遭遇。必须先掉出可识别再进来，才可能是下一次，且仍吃冷却。

触发：甲乙看见身体；丙踩漆或扫到簇核；丁进体积或扫到核。数字与条件的规则合同见 `docs/specs/system-contamination-lexicon.md`。

### 7.7 禁止项

- 每个个体头上挂名字、血条名、传奇飘字
- 图鉴弹窗、回顾列表、「新怪物解锁」
- OS toast / 成就解锁框 / 挂 `document.body`
- 抄混乱阈值那种全屏居中文学旁白腔
- 「你」、感叹号、软件词（提交 / 确认 / 知道了 / 图鉴已更新）
- 把污染词法画成后台配装板或词缀检视仪

## 8. 一趟裂隙怎么抽

风格锚先给本图方言字母表。然后配额，不动物园：

1. **甲 2–3**：保留现有巡逻压力。
2. **乙或丁 1**：改一条路怎么走。
3. **丙 0–1**：绑本图最显眼的簇；没有簇则抽空。
4. 改写体名额变成：甲里恰好一个听觉填法，或乙的一条听缝。仍是「每图一个听觉主轴」，不是两种 AI。

出生钉层：

- 占地挡走 → 现有路点契约（可走、从出生可达）。
- 占墙 → 生成出来的墙缘折线；抽打只进邻接地板。
- 占漆 → `bakeGround` 记下的簇核；禁墙 / 虚空。
- 占空 → 一段走廊包围盒；深度低于视野黑暗蒙层。
