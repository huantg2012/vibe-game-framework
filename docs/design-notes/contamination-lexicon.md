## 1. 背景

### 1.1 问题（人提出）

两种敌人、每种一个形态，玩家体验单调，且与程序生成式的裂隙关卡不相称。目标：构建可以生成海量敌人形态的系统。

现有对照（实现真相，不是要删掉的遗产）：

- 一份五态：巡逻 / 警觉 / 警戒 / 追击 / 归位。
- 两种剖面：渗透体以视锥为主；改写体以听觉为主、视锥更窄；每图恰好 1 个改写体。
- 基体在世界观里已按有机 / 无机 / 概念分类，但出击里两种都还是「会走路的污染体」。
- 覆盖体（高度覆盖）未做。`world.md` 写它「原有形态几乎不可辨」。

### 1.2 符文之语的启发（人明确：不是抄）

人提起《暗黑破坏神 2》的符文之语，不是要做镶孔装备或词缀伤害表，而是要一种启发：**用有限维度、每维有限取值，组合出海量内容。**

真正能借的结构不是「传奇词缀列表」，而是：

| 暗黑 | 污染句法要借的 |
| ---- | ---------------- |
| 白装底子 | 基体 × 覆盖深度（它曾经是什么、改写到哪一步） |
| 孔数与孔型 | 连续性 × 占位（它在这张生成岛上怎么存在） |
| 符文 | 词素（运动 / 感知 / 节律 / 接触），只能从该孔的合法字母表抽 |
| 合法顺序 | 本趟裂隙风格锚的方言：同一张图一种污染源，不是动物园 |
| 符文之语 | 成句：少数具名遭遇 |
| 未成句的孔里货 | 无名变体：大量日常污染体，没有传奇名，但六件套仍由规则填满 |

笛卡尔积负责**样本空间**；语法负责**不像随机时装**。若有 m 个维度、每维 n 个取值，样本空间是 **n 的 m 次方**（不是 m 的 n 次方）。可玩集合是这个空间上的合法子集。

战斗纪律不跟着暗黑走。`system-combat.md` 的成功标准仍是：「如果试玩者开始享受战斗，本系统就失败了。」词素改的是绕 / 冲 / 杀的价目表（时间、路线、混乱、暴露），不是 DPS 堆。

### 1.3 爆炸思考：先拆维度，再砍

对话里先做了维度爆炸，明确要求敌人原形不拘泥于人类：可以是生物、某种物质、非生命事物、不可名状之物。炸开过的族如下。**未写入「人点名保留」的族，不是第一版句法的独立骰子。**

| 族 | 想过什么 | 第一版怎么处理 |
| -- | -------- | -------------- |
| 基体 | 有机残影、物件、建筑切片、物质、过程/痕迹、空间关系、不可名状 | **保留为底材。** 表以 CSV 为准（出击白名单仍是旧六种；第二轮加占地/占漆/概念占空）。不可名状必须先寄生在某一层占位上，否则不是对象 |
| 覆盖深度 | 渗透 / 改写 / 覆盖 / 交界残渣 | **保留。** 三档与世界用语对齐。交界残渣不当自由取值 |
| 连续性 | 单核、裂片、菌落、场、诱饵体 | **保留孔谱半边。** 诱饵体不作为自由连续性，只作成句 |
| 占位 | 占地、占墙、占漆、占空、占声、占相位 | **保留孔谱半边。** 占相位并入节律，避免与占空/占漆抢定义。占声不进第一版主课 |
| 运动语法 | 巡路、沿壁、簇间跳、凝聚、转面、拖尾、固着、随风 | **衍生槽：运动词素** |
| 感知通道 | 视、听、触地、嗅混乱、反视、嗜薪/工具/静止 | **衍生槽：感知词素** |
| 注意节律 | 常开、脉冲、潮汐/天空相、睡眠、记忆长短、一次性升级 | **衍生槽：节律词素** |
| 接触与止损 | 三刀、挥击无效、踩踏混乱、重组、广播 | **拆成两面。接触词素只管「它怎么伤你」（仍是衍生槽）。止损（玩家怎么终结这次遭遇）从连续性 × 覆盖深度查表衍生，不是第五骰子，也不再占用接触字母表。打核驱散不是词素。** |
| 尺度 | 霉斑 / 人高 / 走廊 / 天空巨影 | 不独立。走廊尺度走占空场；巨影继续当氛围，落地的是占空的一小截 |
| 器官错位 | 亮核、裂缝眼、工作面、声从别处来 | 不独立。可读核由占位 + 外观合同保证 |
| 与生成器挂钩 | 钉簇、钉墙缝、钉喉、钉风 | 不独立。出生规则写在孔谱与抽卡配额里 |
| 关系 / 小生态 | 共享警觉、模式互斥、器官分离 | 第一版不做自由维。广播是接触词素之一；双占位是第二批成句 |

硬筛（爆炸时就写下的，句法必须遵守）：

- 改不了「绕 / 停 / 打 / 走哪一层」的维，降为皮肤，不进形态枚举。
- 一份五态。差异进剖面 / 占位 / 刺激，不进第二套 AI。
- 可追击的个体仍守玩家视距优势、撤退可行（现有 I1–I6）。不追击的孔谱改写不变量，不许偷偷打破。
- 同图污染方言要统一。海量来自基体 × 词素，不来自每只一个宇宙。

### 1.4 人点名保留的轴（设计输入）

人挑选后要求跟进适配、设计真正的组合制度：

1. **基体 / 覆盖深度** — 必要核心。
2. **连续性 / 占位** — 决定污染体底层逻辑（外观、行为、攻击、感知都与此挂钩）。占位尤其被点名为关键：它决定能否移动、感知与攻击如何定义，进而决定玩家是绕、硬冲，还是击杀。
3. **运动语法 / 感知通道 / 注意节律 / 接触** — 在 1 与 2 上**自然衍生**，不是再掷一套独立骰子。爆炸思考里的「接触与止损」是同一族的两面：接触填「它怎么伤你」；止损不另抽，由孔谱连续性 × 覆盖深度查表（DEC-083）。

人补充的落地硬约束：空间内的元素必须能落到游戏对象上——无论如何要有明确的 **外观、生命期、移动、感知、攻击、死亡效果**。

人确认符文之语的映射可以当出发点。

### 1.5 制度怎么从这些输入收束

八个名字不是八个并列开关。

- **底材** = 基体 × 覆盖深度。暗黑里的白装。
- **孔谱** = 连续性 × 占位。暗黑里的孔数与孔型。决定画在哪一层、挡不挡路、追不追、血怎么计。
- **词素** = 运动 / 感知 / 节律 / 接触各填一个。只能从该孔谱字母表与本图方言的交集里抽。接触只填攻击通道。
- **止损** = 怎么终结这次遭遇。不是词素，不抽第五槽。查 `continuity × coverage`（表在 `data/contamination-stop-loss.csv`）。
- **成句** = 少数具名配方。语法允许，但不随机拼出来。

渗透体与改写体不再解释成「两个物种」，而解释成 **同一孔谱（单核 × 占地）的两种填法**。覆盖体不以第三种人形出场，而以非人形成句（缝、场、体积）第一次出现。

## 2. 六件套：不允许存在「概念生物」

**概念基体 ≠ 概念生物。** DEC-080 启用的声音 / 光线 / 空间关系是**底材上的基体种类**，不是第三类「没有身体的抽象敌人」。它们必须：

- 钉在**占空**上（孔谱丁）。不新开占声主孔谱；占声仍不进第一版主课。
- 一次写完六件套（外观 / 生命期 / 移动 / 感知 / 攻击 / 死亡）。外观是缓慢形变的体积云，不是一句设定、也不是无法落地的场外叙事。
- 攻击仍走体积场（混乱 + 视野），不发明「精神攻击」空包，不给丁开打血通道。

禁止输出没有占位的纯过程。不可名状若要落地，必须先有一层可画的占位。

凡合法出生的个体，生成器必须一次写完：

| 件 | 由谁决定 | 落地成什么 |
| -- | -------- | ---------- |
| 外观 | 基体给剪影与残余；覆盖深度给材质改写程度；占位给画在哪一层；连续性给几块、有没有中心 | 程序像素，或地面 / 墙缝 / 雾团体积上的漆。不是一句设定 |
| 生命期 | 节律给「何时是活的」；出击结束必回收；死亡可留残骸，残骸也是一个更短的六件套 | 睡眠 → 醒来 → 死亡 → 残骸 → 消失，每段有钟 |
| 移动 | 占位先砍掉非法走法，再填运动词素 | 路点、沿墙图、簇间、转面、固着、随风。没有「抽象游荡」 |
| 感知 | 占位决定探测器钉在哪；连续性决定一个还是多个；再填感知词素 | 仍写入同一份察觉度 0–1。追击锁定须满足该孔谱规则 |
| 攻击 | 接触词素给通道，占位给实现 | 近战扇形、邻格抽打、踩踏收混乱、场内加速混乱。必须非空。没有「精神攻击」空包。禁止用「仅驱散核」冒充攻击 |
| 死亡 | 占位给残骸落在哪一层；止损查表填写怎么结束（打核 / 打散重组 / 打不死） | 打不死也必须在世界上可读（没有可打核）。禁止只从名单里删掉。接触词素不再改死亡 |

连通硬约束写进语法：**菌落与场不得变成额外的墙。** 只有单核、裂片可以「占地且挡走」。否则程序地图的可走区会被污染体切开。

### 3.2 覆盖深度（开孔，不是第三种人形）

| 深度 | 世界用语 | 开孔 | 残余动词 | 成句资格 |

## 4. 孔谱

### 4.1 占位五层

都是这引擎里已有、或可长在已有层上的东西：

- **占地**：实体层，可挡走（仅单核 / 裂片）
- **占墙**：钉墙缝，不封走廊
- **占漆**：钉可走地板上有主的漆（油膜三变体为生产外观）。氛围崩坏簇已下线（DEC-104）。活层技术（DEC-070 / DEC-071）跟该宿主自己走，不跟整图烤地走
- **占空**：挡视线或不挡走的体积，深度在实体与视野蒙层之间
- **占声**：几乎不挡，改听觉半径或把噪声当皮肤

**占相位不单独占一层**，并入节律词素（随天空巨影的相、随占漆宿主呼吸）。

**诱饵体不作为自由连续性。** 「眼在缝里、脚在油里」强制两个占位、两套六件套绑成一个注意，只作成句。

### 4.2 合法矩阵（空格 = 生成器丢弃）

| -- | -- | -- | -- | -- | -- |
| 单核 | 可挡走，可追击 | 沿缝，抽打邻格 | 一滩有核 | 一团有核的雾 | 一个声源核 |
| 裂片 | 可挡走，共享注意 | 多缝一心 | 多斑一心 | 非法（雾切成片难读） | 多扬声器一心 |
| 菌落 | **非法挡走** | 许多墙斑，不挡路 | 簇上铺开 | 非法（满图雾不可学） | 非法（满图响不可学） |
| 场 | **非法**（会变成移动的墙） | 非法（整面墙是敌人 = 封图） | 整片簇场 | 一段走廊的错体积 | 一段窄喉的声场 |

## 5. 填词

四槽各抽一个词素。抽之前与孔谱字母表、本图方言、覆盖深度求交。交为空则重抽，不许拿最近的非法值凑。

每个词素必须能改六件套里至少一件，否则逐出字母表（那是皮肤）。接触词素必须改**攻击**。止损不是词素，不走这条；死亡件由止损查表填写。

**运动：** 巡路、沿壁、簇栖、转面、固着、随风、拖尾、凝聚  
**感知：** 视锥、窄视、听噪、触地、反视、嗅混乱、领域  
**节律：** 常开、脉冲、睡眠、随漆呼吸、随天空相  
**接触（只伤你）：** 三刀近战、邻格抽打、踩踏混乱、场内加速混乱  

第一版每张主孔谱接触合法词就是该孔默认通道（甲三刀 / 乙抽打 / 丙踩踏 / 丁体积）。广播不进第一版。打散重组、驱散才死、挥击无效都不进接触字母表：重组与打不死归止损；挥击必须打到核是占位几何，不是词素。

自动改写：

- 接触抽到「三刀近战」但孔谱是占墙 → 改写为邻格抽打。
- 接触抽到「三刀」但孔谱是占漆 → 改写为踩踏混乱。
- 接触抽到「三刀」但孔谱是占空 → 改写为场内加速混乱。
- 运动抽到「巡路」但占墙 → 巡的是墙图，不是地板路点。
- 感知抽到「视锥」但占漆 → 视锥降为辅，主通道仍是触地。

禁止再改写成「打核驱散」。打核是止损，不是接触。

### 5.1 止损（DEC-083）：查表，不抽第五槽

人要的差异是组合（打不死 / 更硬 / 更脆 / 打散重组），不是接触槽里互斥的五个选项。若再开第五词素槽，组合空间爆炸，也违反「运动 / 感知 / 节律 / 接触在底材与孔谱上自然衍生」。

取值从已有两维来，表在 `data/contamination-stop-loss.csv`（不是抽卡表）：

| 连续性 | 止损族 | 玩家在遭遇里做什么 |
| ------ | ------ | ------------------ |
| 单核 | 打核 | 找到唯一可打核，按孔谱价目打完（甲三刀 75 HP；乙丙丁核 50 = 两刀） |
| 菌落 | 打散重组 | 多核。杀一个，该团停，其余仍伤人。本趟死核不回来 |
| 场 | 打不死 | 没有可打核。只能绕、冲着付代价，或等节律把场暂时关掉 |
| 裂片 | （延后） | 第一版主课无裂片。不写进 CSV，避免 code 猜「更硬 = 多段 HP」 |

覆盖深度只调**同一族里核好不好认、残骸干不干净**，禁止改刀数、禁止改核 HP：

| 覆盖 | core_policy | 读成 |
| ---- | ----------- | ---- |
| 渗透 | 更脆（exposed） | 核暴露、死亡干净。仍是原价目的刀数。杀仍贵过绕 |
| 改写 | 默认（standard） | 现在这套核 |
| 覆盖 | 更硬（obscured） | 核藏在覆盖里更难看。打完痕迹多留一会儿，仍不挡路、不再伤人 |

「更脆 = 少打一刀」否决：乙丙丁核 HP 锁 50，甲三刀账不变。更脆是好认 + 干净结束，不是打折。

合法孔谱：

- 打核：甲（占地单核）、乙（占墙单核）、丙单核占漆、丁单核占空。
- 打散重组：丙菌落占漆（乙墙斑菌落第一版主课未开）。核 2–3 个，各 50 HP。
- 打不死：丙场占漆、丁场占空。禁止占地挡走，禁止占墙整面封图。

世界可读合同：有稳定可打核 ⟺ 不是打不死。多颗可打核 ⟺ 打散重组。没有可打核的一片漆 / 一段体积 ⟺ 打不死。旁白不上屏「打不死 / 更硬 / 更脆」这些设计词。

无名变体的六件套 = 孔谱默认表 ∪ 四个词素的覆盖规则 ∪ 止损查表。生成器不许输出「待美术决定」。

覆盖深度调节开哪些槽、残余动词锁死哪一槽，不另乘一套完全独立的表。接触第一版不乘组合（每孔一个通道）。粗算运动 / 感知 / 节律每槽约 3 个合法词：大约 \(4 \times 3^3 = 108\) 个无名填法，再乘基体与覆盖深度。玩家要学的是四句孔谱 + 核的个数/有无，不是一张止损词缀表。

## 6. 成句（第一版四句）

成句是内容高峰，不是另一套生成器。各教一张孔谱的极限，并让覆盖体以非人形出场。

1. **门还想关** — 渗透 · 门框 · 单核占墙 · 固着 · 脉冲 · 邻格抽打。门洞这一格按节律开合。
2. **缝里的眼** — 覆盖 · 墙锈 · 单核占墙 · 窄视 · 常开。核在缝里。贴墙等于走进视锥。
3. **簇的肺** — 改写 · 菌毯 · 场占漆 · 随该宿主活层呼吸 · 踩踏混乱。止损 = 打不死（教「这段地只能绕或等它缩」）。与该占漆宿主自己的整团胀缩是同一口气，不跟已下线的氛围簇。
4. **走廊在看你** — 覆盖 · 间距 · 场占空 · 反视 · 随天空相。止损 = 打不死。视野探进那段错体积，它才醒来。不绑油膜。

「眼在缝、脚在油」列为第二批成句。第一版不做。

上列四句是**内部配方名**，禁止印在 HUD / 遭遇识别旁白上（传奇口吻，且 `world.md` 禁暗黑式称号）。游戏内怎么认出遭遇了什么、成句短标记怎么上屏、限频怎么挡刷——同一套体系的识别面见 **§7**。规则合同 `docs/specs/system-contamination-lexicon.md`；表面合同 `docs/specs/ui-encounter-narration.md`（DEC-074 / DEC-075）。

## 7. 遭遇识别旁白（同一套体系的识别面）

污染句法生成形态；遭遇识别旁白是同一套体系里玩家认出「刚才遭遇了什么」的那一面。不是第二套玩法，不是独立 HUD 产品。读者只读本文件应能同时理解「形态怎么生成」和「玩家怎么认出遭遇了什么」。限频与身份键的规则合同见 `docs/specs/system-contamination-lexicon.md`；载体、参考锚点、视觉规格、U1–U12 见 `docs/specs/ui-encounter-narration.md`。

### 7.1 为什么需要识别面

世界可读仍是第一课。缝里的核、占漆的胀缩、体积的相，必须先能在世界上读到。没有这一课，字再准也只是说明书：玩家会盯着一行记录，而不是盯着走廊。

污染句法第一版大约有一百多个无名填法（接触不乘组合），再乘基体与覆盖深度。玩家要学的是四张孔谱加核的个数/有无，不是三百个名字。海量填法会让「刚才碰上的是哪一种」在识别当下滑走——尤其是非人形占位（墙缝、漆、体积）不像会走路的身体那样自带「这是一只敌人」的旧习惯。识别当下需要一次强化，让组合项在那一拍被读成一种东西，然后闭嘴。

头上挂名字会把裂隙变成 RPG 名牌场：迷雾里的身体被标签挡住，绕 / 冲 / 杀变成读牌而不是读世界。遭遇识别旁白用随身罩印出一行角色低语，在第一次可识别时把「面对这类要注意什么」隐晦说出来。它强化识别，不替代身体。

### 7.2 教什么

一行低语只强化已经写进句法的课，不另发明身份。孔谱四句仍是玩家先学的记忆：会走路的东西、缝在看路、地在呼吸、这段路本身在工作。**I8-R / DEC-104：** 不再逐节点报覆盖深度 + 基体 + 占位（那是精确定位，已否决）。**I8-R2：** 改成角色低语的完整自然句，隐晦提示面对此类要注意什么。不上「识别。」。世界用语「渗透 / 改写 / 覆盖」不上屏，化进语气（渗透更像残余还在、话说到一半；改写与覆盖更像原形关死、更发麻）。基体名不上屏。内部层名不上屏。

选行键（给 I8-N 抄，不上屏；**键结构不改**，每键一个句池 ≥2 行）：

| 条件 | 句池 | 隐晦提示的注意事项 |
| ---- | ---- | ------------------ |
| 占地 + 视锥或窄视 | 甲·看 | 别被他发现 |
| 占地 + 听噪 | 甲·听 | 别出声，他听得见 |
| 占墙 + 渗透 | 乙·渗透 | 离缝远点 |
| 占墙 + 改写或覆盖 | 乙·改写覆盖 | 离缝远点 |
| 占漆 + 渗透 | 丙·渗透 | 别靠近 / 别从那上面过 |
| 占漆 + 改写或覆盖 | 丙·改写覆盖 | 别靠近 / 别从那上面过 |
| 占空 + 渗透 | 丁·渗透 | 换条路 |
| 占空 + 改写或覆盖 | 丁·改写覆盖 | 换条路 |
| 命中成句 | 该成句整句替换上表（各 1 行） | 同一孔谱的极限课 |

完整成品句见 `docs/specs/ui-encounter-narration.md` 文案合同；CSV 由 I8-N 落地，本文不改数据文件。同一次遭遇按宿主种子从该池抽 1 行；限频仍按身份键，不按抽到哪一句。

### 7.3 与世界可读的关系

遭遇识别旁白是强化，不是替代。缝核、占漆外沿与呼吸、体积相必须先能在世界上读到。**止损也走这一课：** 有几颗可打核、有没有可打核，必须在遭遇当下从身体读出。旁白不得印「打不死 / 更硬 / 更脆 / 打散重组」，也不得印「危险 / 敌人 / 注意」这类说明书词。提示化在句子里（「别被他看见」「我还是不要……」）。旁白不得让实现把缝 / 漆 / 体积画成不可辨的色块再靠字救命。世界读得懂时，这一行是确认；世界读不懂时，这一行不合格——回去改孔谱落地，不加大字号、不加图鉴。

**占漆：** 看见的成片青绿都有主（§4.3）。旁白在视野扫到该宿主漆格或踩上之后才来，只确认，不代替油膜外沿。同图多只占漆若身份键相同，只报第一口，其余吃冷却静默——这是特性，不是漏报。

### 7.4 文案骨架（I8-R2）

I8-R 的「识别。+ 电报式观察句」已被人否（「游戏内的文案就别用缩写了，ai 味儿太浓」）。口吻标杆（人原话，不上屏当唯一成品，只定语音）：

- 甲·看：`慢一点，慢一点，别被他发现了`
- 丙：`这增生物令人发麻，我们还是不要...`

本表面写**完整自然句**：第一人称自语（零主语，或需要主语时用「我」）、有情绪、允许重复拖长、允许话说到一半。禁止「我们」。禁止压缩电报腔（「路当中那具还在转头」就是那种缩写）。人拍板后落地口吻：「我还是不要……」。

**前缀：去掉「识别。」。** 整行就是那一句低语。不再加「记录。」或任何分类头。成句命中时整句换成该成句专用句，并可另加一个短标记节点（已锁污染侧 teal、同一字号、1px 错位）。

载荷节点 kind 只有两种：`observe`（观察句）/ `utterance_mark`（成句短标记）。不再发 `device` 节点。

观察句是一个 span，不要再拆成覆盖 / 基体 / 占位。整行按详细描述计不超过 40 字（标杆都在 20 字内，成品应对齐这个长度感）。允许「我」与「他 / 它」、零主语。禁止「我们」、禁止「你」、感叹号、软件词、说明书词（危险 / 敌人 / 注意）。

DEC-104 的「文学性」= 角色低语里的隐晦提示，不是 `world.md` 禁止的诗意渲染，也不是勘察报告。

**载体 fiction：** 载体仍是 A（裂隙随身罩）。罩上那台勉强还在转的记录仪印出来的不是勘察日志，是角色压在嗓子里的第一人称自语。视觉仍是底栏上方一行 Courier（Kit 已锁），不改成对话框、不改成全屏旁白。记录仪在拾音，不是在分类。与 `art-direction.md` §6 不冲突。

### 7.6 限频

身份键只给限频用，不给玩家看。键结构**不改**（改键会让同图复制的占漆互相不踩冷却）。

- 成句：`utteranceId`
- 无名变体：`coverage + substrate + occupancy + continuity`；占地再加主感知词素（否则渗透体与改写体撞键）。不把运动 / 节律 / 接触四槽全编进键。止损不另进键。旁白不上屏止损术语。

持续留在可识别里（一直看着同一只）= 同一次遭遇。必须先掉出可识别再进来，才可能是下一次，且仍吃冷却。

## 8. 一趟裂隙怎么抽

风格锚先给本图方言字母表。然后配额，不动物园：

1. **甲**：保留现有巡逻压力。出击条数仍跟地图巡逻（3–4），禁止用本条砍路点。
2. **乙或丁 1**：改一条路怎么走。
3. **丙（占漆，DEC-104 / I8-R2）：** 读本图 `contaminationAge`，不读簇只数 C（簇已下线）。每档一个闭区间，生成时按种子在区间内均匀取整：

| `contaminationAge` | 区间（含端） | 理由 |
| ------------------ | ------------ | ---- |
| 新生 `new` | **3–5** | 下限锁 3（DEC-104）；年轻图外来模式刚在场，税口少。三档取值，不再钉死 3 |
| 标准 `standard` | **6–8** | 与新生不重叠（新生最高 5）；旧钉死 5 太硬，整段抬到 6 起 |
| 古老 `ancient` | **9–12** | 与标准不重叠；旧钉死 8，上限收到 12 而不是 14，以免短薪柴路径上被迫均匀撒点 |

全轴跨度 3→12（旧阶梯 3→8）。档间区分度靠**不重叠**：看只数能倒推大概哪一档。

**N 只由年龄区间掷，不读图面积、不读薪柴路径长度。** 面积 / 路径已经通过「同样 N 钉在或长或短的贪婪路上」改变密度；再乘一层会让大号新生图看起来像小号古老图，冲掉年龄轴。禁止菜单式系数。

掷法：`N = lo + floor(rng × (hi − lo + 1))`，种子 `mix32(layout.seed, 'paint-count')`（或 lexicon fork 的下一掷）。必须是整数。抽**一份** form，复制 N 只。油膜三变体仍按**个体**种子采样。钉在**贪婪薪柴路径**上的可走地板，偏咽喉。间距：首选 Chebyshev ≥ 6；**当 N ≥ 9 时第一步改从 ≥ 5 起**（古老档在短路径上从 6 起会无谓失败），不够 ≥ 4，再不够 ≥ 3。禁止钉墙 / 虚空 / 出生与撤离 Chebyshev ≤ 3 / 薪柴所在格。禁止 N 只叠在同一钉点。放不下先降间距、再把候选扩到路径 Chebyshev 2 的可走格、再扩到出生可达的全部可走地板；**仍不足掷出的 N** 则本图重试（与连通同一纪律：交不出满额的出击图）。禁止交不足该档下限的图，也禁止悄悄把 N 钳到「放得下就算」。同图一种污染方言。同身份 60s 互踩旁白是特性，不改秒数。
4. 改写体名额变成：甲里恰好一个听觉填法，或乙的一条听缝。仍是「每图一个听觉主轴」，不是两种 AI。

**为什么污染度用 `contaminationAge`，不用混乱档：** 年龄是本图已经抽好的布局事实（新生 / 标准 / 古老），出击全程不变；混乱档是玩家状态，会在一趟里自己涨，不能当「这张图有多脏」。残破轴管材质糊不糊，不管有主的漆有几滩。不新开第四轴。区间跨度 3→12，比 I8-R 钉死的 3→8 大，也比 I8-D 的 0→3 大。

**钉点与绕 / 冲 / 杀：** 贪婪薪柴路径 = 出生走到争夺档与深档薪柴的最短可走链（实现可并上撤离方向的主干，但薪柴税必须压在「还敢不敢再拿一点」的路上）。漆压在这条路上，绕 = 离开便宜路付时间混乱；冲 = 留在路上付踩踏 +2/+4；杀 = 仅当本图这份 form 是菌落（清核通常仍贵过绕）。分散覆盖若离开贪婪路，冲的价目表会变空——禁止以「图上均匀撒点」交差。连通 FATAL 不变：漆不挡路。
