# 培养藏三卡

身份锁见 `docs/design-notes/growth-console-identity.md`：**一具能装下人体的圆柱培养藏。舱里是冒泡的半透明液体。**

机制不动。本文件只声明三张完整组合，不推荐。上一轮九张（操作件占空间）整支作废，不参考。

画布：卡 A **40×42**（加粗、压矮）；卡 B / C 仍 **32×36**。相机 **45° 等距**。8 帧、6fps。锚点脚底。
卡 A 热修（2026-09-05，人点名加粗并减少高度）：中段舱液约全高 70%；紧贴地面；影子按核心从东侧打、往西偏。**已翻生产（DEC-116）。**
生成器 `docs/art/review-2026-08-28/gen/growth_console_cards.py`（单卡闸门 + 跨卡形体类 + 禁拱/钳/环 + 谎称测试，退出码非 0 即不合格。对供奉台 G/H/I 只打印画布占用 IoU 作备注，不当闸门——同相机同画幅的居中实心块会假红）。

## 三张，一张一类

第一轴 = 圆柱腔怎么占空间。腔的语法是圆柱，占空间的方式不同。舱液都在腔里冒泡。腔心必须填满，不许挖成透明。

| 键 | 卡 | 形体类 | 一句话读法 | 舱液怎么动 | 科技 / 刻痕 |
| -- | -- | ------ | ---------- | ---------- | ----------- |
| 1 | A 立缸 | 立缸 | 人能站进去的立缸，前脸看见舱液 | 气泡从舱底往上冒 | 两道长短不齐的箍；一侧事后刻痕 |
| 2 | B 横棺 | 横卧 | 人能躺进去的横管，侧窗看见舱液 | 气泡沿管腔缓移 | 管身法兰；端盖上不对称刻痕 |
| 3 | C 沉井 | 沉井 | 人往下沉的井口，顶上看进舱液 | 液面鼓泡 | 井圈螺栓不齐；圈沿一段刻痕 |

三张共用同一份身份锁、同一套色板、同一组闸门。对照课 `gym.html?lesson=growth-card`，键 1–3，底是出击同一份净化点混凝土。**这里换卡不改生产默认。**

## 可分维度（已声明）

1. **圆柱腔怎么占空间**（第一轴，本轮在抽）
2. **舱液怎么动**（绑在卡上，三张都是冒泡）
3. **待处理高亮**（声明可分，本轮不拆成卡）

禁止再按黄铜 / 石 / 木拆一轮。禁止再按操作件拆一轮。

## 卡 A 立缸热修闸门（生成器必须绿）

- 画布 40×42
- 舱液高度 / 物体高度在 62–78%
- 缸贴地：本体与影子之间没有空行
- 接地影重心在缸西侧（核心在东）
- 中段左右 38% 带宽，右面亮度 > 左面 +4
- 顶盖与缸底仍是材质（两端 14% 带里舱液 < 22%）
- 近黑三色不上外沿（接地 3 行除外）

## 谎称测试（生成器必须红）

- 把任一张谎称成拱 / 钳 / 环 → 红
- 把卡 A 立缸谎称成沉井 → 红
- 把卡 B 横棺谎称成立缸 → 红
- 把卡 C 沉井谎称成横卧 → 红

## 本文件不推荐

不写「建议抽哪张」。给人的材料是读法 + 对照课地址 + 决策问题：哪一张第一眼是「把人放进去改」，而且不是供奉台。
