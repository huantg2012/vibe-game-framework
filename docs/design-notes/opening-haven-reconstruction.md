## 1. 方向与成立条件

**开场是一处仍有人停留的破碎建筑。人靠炉火维持体温，异常的核心维持着这里的秩序，建筑之外还有不可度量的世界。** 点击进入后，玩家接管刚才看见的那个人。

这是一个观看顺序：先注意到人的处境，继而意识到庇护来自不安的力量，最后把这处地方当作可以行动的空间。标题不承担功能目录，也不在一张图里解释全部世界观。

审美目标是克制、沉重、暂时可栖身：有温度，但不舒适；有秩序，但不安全；人物有生活尺度，环境仍大到无法掌控。原画的深渊、重残构、细密塑形与有限暖点，是必须保住的品质基准。

**主方案采用同一场所的两次取景：单独制作开场镜头，以匹配剪辑衔接正式游玩镜头。** “同空间”锁定物件和建筑关系，不要求在技术上实现一镜到底。

理由：当前炉席背后是大块可行走地坪，核心在它右前方。把正式画面直接放大，会放大地板与核心，压缩深渊。降低开场俯角并单独构图，可以减少地坪在画面上的铺展，增强断面和竖向落差；切回游戏俯角则恢复导航可读性。两种镜头各自完成观看与行动的任务。

这里也修正上一轮口头建议的一个不严谨点：“核心进入中景”不能成为移动核心或伪造深度的理由。核心保持当前世界坐标和朝向，它在开场中仍可能是右侧近景；通过完整的局部结构、出画关系和投光控制其叙事分量。

尚需样片证明的假设：较低俯角下，真实炉席和核心能同时形成好的构图；新开场能保住原画的深渊感。当前证据不允许提前宣称二者已成立。若失败，先调整开场相机和可见外景，不能挪动已认可的净化点布局来迁就海报。

## 2. 场景构图：每一块空间承担什么

### 2.1 镜头与画框

- 固定 960×640 游戏逻辑画框。单独定义开场正交相机，保持现有观察方位，优先降低俯角，不做广角透视或夸张镜头畸变。
- 现相机 direction 为 `[19,24,30]`，俯角约 34°。开场先在 `[19,17…21,30]`（约 26°–31°）搜索取景；这是内部构图搜索范围，不是已验证的最终参数。
- 标题沿用左侧既有安静位置。用相机 origin / target / scale 安排画面，不拉伸既有 PNG；最终参数由完整关键帧确定。
- 人物放在偏右的炉席小组，保留一个能直接读到断沿与下坠空间的侧面。人物不必位于原画同一屏幕坐标，但进入游戏时应是同一世界位置和朝向。

**为什么：** 低一些的俯角把“平面的面积”转换为“建筑的厚度和下方的深度”。保持方位降低物件轮廓突然翻面的陌生感。正交投影同样能表达纪念碑尺度，依靠的是真实巨大构件、遮挡和跨画框延伸，不需要广角特效。

### 2.2 左侧：自然形成的安静暗部

标题周围保留低对比暗区；暗区右缘由大残柱、空洞或阴影构成不规则的软硬交界。标题之外仍需看到深渊的空间，不能把左半边全刷成没有信息的黑板。

**为什么：** 文字要容易读，世界也要继续存在。明确、稳定的暗部能容纳文字；少量被遮住的轮廓让暗部有距离和体积。高反差碎片或能量亮点进入文字区，会造成两个阅读任务互相争抢。

### 2.3 右下：炉、残墙、人的生活单元

使用当前炉子、可坐建筑残骸、人物和附近独特断沿。平台从右侧建筑依托伸入画面，只展示局部，不展示完整岛形轮廓。座席保持建筑构件的厚断面、旧接合痕迹及被坐磨的上缘；炉口、朝人的受热面、脚边小范围煤灰形成位置明确的使用关系。

角色保持现有头盔、背包、肩灯和衣服身份，以站立静息为初始姿态：重心落地，膝和肩不僵直，背包有重量。不会因为标题需要“生活感”就强制新档已经坐下或增加起身脚本。人物靠近可坐处，玩家接管后自行决定是否停留。

**为什么：** 生活感来自身体与物件之间发生过的关系。被磨过的坐面、火光照到的衣服和近手边的石沿，比新增一排箱罐更有说服力。只展示一段平台，会让地方继续伸向画外，保留“身在建筑残骸中”的感觉。

### 2.4 右侧：有来源、有约束的异样光

核心保持正式位置、朝向、比例与能量体定义。允许部分出画，但至少读得出“约束构件围住一团有体积的发光内质”。优先裁外壳的延伸或底座，不把核心裁成一截不明绿色灯条；不完整展示台座到顶冠的产品式全貌。

**为什么：** 完整、居中的巨型核心会把人降为比例尺；完全藏起它又会使冷光没有来源。可辨的局部结构让人意识到这是一件危险且重要的东西，同时保留进入游戏后靠近观察的空间。具体露出比例必须以成片决定，不以“切到边上就解决”替代构图。

### 2.5 外景：重构观看关系，保护真实建筑关系

- 近层：与据点实际相连的梁、承托和残墙；轮廓较硬，接合、厚度和承重可读，不相对平台滑动。
- 中层：少量尺寸显著更大的书架或建筑残体，通过遮挡、转面和下坠跨度建立距离。优先保留一个跨出画框的大体块，不排成可数清的小浮岛队列。
- 远层：更低对比、更少材质频率的轮廓，消失在深暗介质中；偶发异动只改变局部遮挡，不制造完整怪物登场。
- 外景与右侧建筑依托沿用同一个世界源。若标题需要扩展画外内容，补充遮挡后真实存在的几何；新增且可能被两个镜头看见的结构应从两边检查，不专为标题拼一份互相矛盾的世界。

**为什么：** 深度依赖“什么挡住什么、什么继续向下、远处失去哪些信息”。整体提亮或整体提蓝不会自动产生距离；均匀撒碎块也只会产生密度。原画最强的压迫感应来自大尺度秩序崩塌，小人物只提供比较基准。

## 3. 光与色：保留冲突，建立因果

仍然只有三类来源：肩灯淡暖白、炉内橙火、污染灰冷绿。核心保持净化点最强光源和全向辐射。标题不另加一盏无来源的“电影补光”。

| 处理 | 如何做 | 为什么成立 / 怎样发现失败 |
| --- | --- | --- |
| 人与炉席可读 | 炉光落到邻近衣物、手边石沿和地面，肩灯形成更小的暖白落点；人物背光面保留冷暗本色 | 暖区的连贯关系把身体和栖身处联系起来。若仅剩橙光斑而看不清人的姿态，关系未成立。 |
| 核心最强，但画面有人的焦点 | 不降低其世界功率；用取景、有限可见发光面积、真实距离与遮挡控制它占据的画面 | 光源功率、可见亮面面积和注意力不是同一件事。若只能大幅压暗核心才能看见人，须重排镜头。 |
| 混光有体积 | 同一构造决定法线、背光、接触与投影；橙火和灰绿在真实接收面上交汇 | 同一物件的冷暖转面能表达它位于两种力量之间。整块地坪混成青黄灰，会同时损失温度与材料本色。 |
| 深暗有层次 | 近面保留中尺度转面，中景减少细节和局部对比，远景先失去纹理再失去轮廓 | 使人能感觉黑暗里还有空间；不是把所有物体都勉强照亮。 |
| 污染绿色有语义 | 普通石木保留本色；只有污染本体及其真实受光范围带明显灰冷绿 | 绿色表示侵蚀与异源能量，不是废墟装饰。大范围统一染绿会使源与受光失去区别。 |

不在本方案中虚构一组已锁定色号。沿用当前母版材料与源色，在新取景的实际混光下校准。需要大胆发光的核心内质仍可有很亮的苍白高能区，但保留密度、暗隙和透射，不能变成白灯泡。

## 4. 画法与细节：让对象经得起看

继续使用已取得正面效果的确定性构型与像素渲染：对象几何 → 可见面与深度 → 世界尺度材料 → 遮挡与受光 → 能量/空气合成。开场在目标网格重新绘制；放大旧全景不会生成新细节。

- 石与混凝土：大形是楼板与承重腹部，中形是砌层、错台、断口和切面，微细节是骨料、磨损和少量沉积。裂纹应影响边缘或结构，不是均匀贴在线条底板上。
- 木架与书册：按承重、倾斜、缺板和书册成组组织明暗。纤维服从板面方向；远处不逐本描清，以免碎纹抢过人物。
- 机器金属：折边、孔腔、夹持和受力部件决定高光带的位置与宽度。转面不只是三块固定面色，污斑不能代替形体。
- 角色：沿用正式角色的构造与比例，按开场相机重绘静息资源。近景增加有因果的轮廓和受光信息，不重新设计服装或另造“封面主角”。Rift 低精度角色保持。
- 空气：源附近有限散射，受不透明几何阻挡；远景以不同尺度的消隐表达介质。前景与人物保持像素轮廓，不对整张图做模糊。

**为什么：** 充分描绘不等于每处都有高频纹理。近处材质经得起看，远处让出信息，人的眼睛才有距离和停顿。若删除锈斑、划痕后物件就变成平色纸盒，应该修形体与受光，不能继续加装饰。

## 5. 动态：让世界持续存在，不让它表演

| 对象 | 动态方式 | 理由与限制 |
| --- | --- | --- |
| 人物 | 独立静息呼吸、细微重心与背包响应；双脚稳定；肩灯随同一个锚点 | 让人有身体重量，避免网格整体漂移和用移动帧充当待机。 |
| 炉火 | 火口变化先发生，相邻受光跟随变化；短而不齐的节奏 | 证明暖光来自火。不会只让橙色像素闪烁而地面不响应。 |
| 核心 | 沿用慢扩张、快压缩及内部涌动；内质、透射和环境贡献共享相位 | 使约束在持续工作，保留能量体的体积。不能只整体缩放一个发光贴片。 |
| 尘与侵蚀 | 小范围、稀疏、依附光域与材料；不同时起伏 | 不把场景变成所有层都在呼吸的壁纸。 |
| 深处异物 | 极低频，先短暂遮住一点已有轮廓或光，再消失 | 让未知来自“也许看错”，不承诺剧情事件、战斗或新的怪物机制。 |

菜单待机时相机稳定，不随鼠标摆动整片建筑。不同深度的远景不是可随意滑动的贴纸。减动模式保留识别所必需的源光与可选静帧，取消相机运动及非必要远景异动；动态细节以实际资源和可达性规格落地。

声音沿用既有提前接入的机制。优先维持炉声/机械底声的连续性，使剪辑前后声源身份一致；不添加入场轰鸣、传送声或抒情高潮。当前音频未实际试听，具体音量、频率与混音必须另做带声样片，不据代码宣布好听。

## 6. 从观看到操作：短交接与首屏

以当前约 2.1 秒新档、1.1 秒继续、0.5 秒减动作为初始预算。不是先加长过场再找内容填充；具体时间随实际样片校准。

1. 点击后菜单先退，存档/继续事务沿现有可靠流程执行。短暂让画面本身成立；不新增确认页、世界观字幕或章节卡。
2. 人物脚点是剪辑的硬锚；炉门暖点、残墙端头和断沿是相邻地标。开场画面暗下去，在既有遮断窗口切入正式场景。不同俯角用清楚的匹配剪辑，不用长叠化叠出双轮廓，不谎称无缝变形。
3. 正式画面初始取景围绕同一角色与炉席；随后轻微拉回/平移到现有精确游玩镜头。角色仍在真实出生位置，镜头承担变化，不移动平台、核心或人物去凑屏幕坐标。
4. 入场末端恢复既有 HUD 与控制。脚下通路、角色轮廓、可坐残墙先读清；“坐下”保持可选，无恢复资源或强制教学。关于潮汐/预报是否延后显示，留为最小新手验证项，不凭本方案直接改已锁 HUD。

继续记录优先尊重保存位置及当前场景；不能为复用标题表演把角色搬回炉席。继续与减动采用短淡变，必要时放弃严格的脚点匹配。保持存档失败、重复确认、失焦暂停、切场清理和输入残留保护。

**为什么：** 连续性首先来自角色和地标身份，镜头运动只是传达手段。首次进入值得给出短暂的“落脚”；反复继续更看重迅速恢复操作。强制重复坐下/起身会把情绪变成等待。

## 7. 制作与技术路线

事实边界：作者源有完整三角几何与可变正交 Camera；正式运行时是固定取景的 G-buffer / 分层 PNG / 角色图集经过 WebGL2 合成，并不是可任意环绕的实时 3D 场景。Phaser 的 zoom / scroll 只能改变现有画面的取景，不能揭示新侧面。

主路线：

1. 从当前 `docs/art/demos/purification-forecourt-options/option-a.ts` 的 `buildOption()` 与 Last Light 几何、材料、源光建立独立 opening Camera；正式 CAMERA 与平台/交互/导航数据不变。不能回用旧 `buildHaven()`，它缺少当前断口与裂隙修订。
2. 以新 Camera 重渲开场静态整景，并重导该取景实际用到的深度、遮挡、光贡献与透明层；旧屏幕空间数据不能复用到新角度。复用的是模型、材质、光的世界坐标与能量函数。
3. 人物按同源骨架与新相机制作一个真实朝向的 8 相位站立静息；无须为菜单重导整套步行图集。肩灯从人物真实锚点投影。角色局部不能直接抠旧标题人物伸缩。
4. 主方案采用固定镜头的离线受光动画：静态底层，加人物/炉火/核心动态以及匹配的投光贡献。每个 idle 相位先按同源场景求出真实变化，再裁出变化像素并集；包括人物影子与肩灯受光，不只是身体的包围盒。核心仍用当前八帧、4.8 秒周期的生成函数在新相机下重积分。若人物遮挡核心，应重烘相应透射；不能默认各层永不重叠。
5. 最小开场包不需要复制正式四层视差、整套 G-buffer 或 1035 帧人物。若离线 patch 影响区过大，可保留 8 张基底帧并核实内存/解码，再决定压缩方式；不用复杂压缩牺牲阴影正确性。未来若确需复用正式动态合成，须先参数化硬编码相机与视口假定，不能把旧 shader 直接套到新底图。
6. 主菜单保有自己的完整资源生命周期；只有第一眼与交接被更新。正式移动、碰撞、经济、交互与 Rift 不因开场制作而改写。

拟新增单独导出入口 `tools/last-light/export-opening.mjs`，输出 `public/assets/opening/`：`opening-base.png`、独立核心/炉火贡献、核心能量与透射八帧、idle 变化 patch 及 `opening-manifest.json`。manifest 记录相机、脚点/肩灯/炉门锚点、相位、patch 范围、来源指纹与剪辑接点。这些路径是规划，不是已存在的资产。

跨场状态也要同源：首次进入用新档实际的 70/100 装置状态配光，不能标题按满状态渲染、入场突然变暗（当前正式核心初始增益约 0.775）。剪辑传递或对齐人物呼吸、核心和炉火相位。继续记录按保存状态恢复，不为匹配固定标题画面改变记录或位置。相机变化后旧远景异物的屏幕坐标、空气分布、深度阈值与固定像素光晕均需重新校准，不能照抄旧数据。

主要入口：`docs/art/demos/purification-last-light/model.ts`、`render.ts`、`actor.ts`、`energy.ts`、`export.mjs`；当前 A 变体构造与正式运行组件按现有依赖引用。接入点为 `src/scenes/main-menu-scene.ts`、`main-menu-actor.ts`、`main-menu-atmosphere.ts`、`menu-entry-transition.ts` 及净化点入场分支。以上是拟涉及的职责，不是本轮已修改文件。

## 8. 分段推进与失败处理

| 阶段 | 交付 | 必须回答的问题 | 未成立时做什么 |
| --- | --- | --- | --- |
| ① 同源取景 | 新开场完整关键帧＋正式首帧并置；内部相机搜索 | 真实炉席、核心、断沿是否容得下原画级的深渊与人物处境？ | 只调整相机和可见范围。低成本裁切只有达到同一审美目标时才采用；不挪功能布局。 |
| ② 美术母版 | 目标尺寸整景，含完成度足够的石木金属、人物、核心与混光 | 近看有材料，缩小有主次；比原画更接得上游戏，同时情绪不退步？ | 回查大中形、边缘显隐和真实受光。不能用更多噪点/光晕补救。 |
| ③ 动态与交接 | 菜单待机循环＋一次真实点击进入的带声样片 | 光与形体是否共同变化，画面是否平静但活着，切入是否认得出同一处？ | 修共用相位/锚点和剪辑；不加长过场遮掩问题。 |
| ④ 正式接入 | 根游戏新档/继续/减动及异常路径，集中设计与规格同步 | 新入口是否稳定，继续位置和存档是否保持，操作是否及时交还？ | 按具体故障修复；艺术验收和功能验证分别记录。 |

先做一个完成度足够的完整构图样片；不向用户交付粗糙线稿作为后续美术基准，不重复制作多个仅换色的候选，不因做了计划就自动开始游戏改造。工作量集中于独立相机的资产包与交接，属于中等以上美术/技术美术工作；不做没有样片依据的小时承诺。

## 9. 最终验收：审美理由如何落到画面

- **首先读到一个有人停留的地方。** 缩到四分之一检查大形，再回到正常尺寸看人物与炉席的具体关系；缩图不要求读清手指或装置细节。若只读到“绿色大门＋橙色光点”，人物关系失败。
- **深渊仍比基地更大。** 与旧标题同画框并置，至少有明确的长距离下坠空间与跨出画框的大构件；平台不是完整摆在黑底上的商品。
- **核心的光有来源、有路径、有约束。** 关掉核心环境贡献，应能识别哪些地面/结构失去了照明；开回后没有无因漂浮光斑。正常版本中不靠压低设定功率换取构图。
- **删去表面装饰仍有重量。** 骨架、转面、孔壁、接触、投影共同说明对象如何建成；磨损只是补充。
- **两次取景之间能认回角色与炉火。** 不需文案解释地理关系，不要求逐像素重叠。不要在验收时预先把地标答案告诉首次观看者。
- **新作同时赢得空间对应与情绪表达。** “更像实际地图”单独成立不够。若孤独、纵深、材料质量或停留欲明显降低，就不能替换旧标题。
- **静态、连续动态、声音与真实操作各自有证据。** 技术正确不代替画面终审；新手反应需未参与制作的人验证。原 I13/I14 验收保留历史范围，本提案不冒领通过。

此方案把设计因果明确到可制作、可反驳的程度；新镜头的最终艺术表现仍由完整样片证明。
