# Slice 3 出击工具设计：污染物转化后的裂隙用具

> 每种污染物在净化点承受 3 次冲击后，被本世界侵蚀转化为"本世界污染物"——可在裂隙中有限次使用的主动/被动工具。用完破碎。

---

## 分档总览

| 等级 | 数量 | 使用次数 | 定位 |
| ---- | ---- | -------- | ---- |
| 普通 | 4 | 4-5 次 | 实用型基础工具，稳定可靠 |
| 精良 | 3 | 3 次 | 改变单次遭遇的处理方式 |
| 稀有 | 3 | 2 次 | 逆转一次危机或创造重大优势 |

玩家每次出击携带 3 件。类型分布：7 主动 + 3 被动。

---

## 普通级

### 1. 凝锁（固化残渣 → 转化）

**类型**：主动

**效果**：指定视野内一个敌人，将其冻结在原地 4 秒。冻结期间敌人无法移动、转向或感知，但不受伤害。冻结结束后敌人立刻进入 alert 状态。

**使用次数**：5

**决策点**：用在巡逻挡路的敌人身上直接穿过，还是留给被追击时甩掉追兵？冻结后敌人会 alert——如果你没走远就等于白冻。

**信息反馈**：被冻结的敌人身上出现明显的白色晶格覆盖纹理，4 秒倒计时以晶格逐渐碎裂表现。

---

### 2. 反刍之口（反刍残渣 → 转化）

**类型**：主动

**效果**：对当前脚下的地面"咬一口"——消化周围 3 格内的一个已拾取过的空节点，重新生成 1 薪柴（不受 STORAGE 加成）。只能消化已拾取的节点，不能凭空创造。

**使用次数**：4

**决策点**：在回程路上对已拾取的 safe 节点使用（顺手额外 +1），还是留到深入 deep 区域后对高价值空节点使用？注意：每个空节点只能被消化一次。

**信息反馈**：使用时脚下出现短暂的吞噬动画（暗色漩涡 0.5s），薪柴计数 +1 闪现。已消化的节点位置留下一个暗色疤痕（区分已消化 vs 未消化的空节点）。

---

### 3. 碎影（散射残渣 → 转化）

**类型**：被动（装了即生效）

**效果**：当敌人进入 suspicious 状态时（感知条开始填充），你的位置信息被"碎片化"——敌人的感知填充速度降低 30%。等于给你多了约 1.5 秒的反应窗口来离开感知范围。

**使用次数**：本局持续生效，但每次触发后进入 15 秒冷却（冷却期间不生效）。累计触发 5 次后破碎。

**决策点**：被动生效不需要操作决策。真正的决策在出击前：带碎影意味着放弃一个主动 slot——在敌人密集区有巨大价值，在开阔区浪费。

**信息反馈**：当碎影生效时（敌人感知被减缓），屏幕边缘对应方向出现一个短暂的灰色闪烁脉冲（"有东西在看你，但它看不清"）。冷却状态在 HUD 显示为工具图标变暗。

---

### 4. 残响标记（回溯残渣 → 转化）

**类型**：主动

**效果**：标记一个视野内的敌人。被标记的敌人在离开你视野后，其位置仍以一个"残像"显示 12 秒（灰色半透明轮廓，每 2 秒更新一次位置）。同时标记期间该敌人的巡逻路线以虚线显示在地面上。

**使用次数**：4

**决策点**：标记挡路的巡逻兵（看清路线找窗口穿过），还是标记追击者（转角后知道它往哪去了）？12 秒够不够你做完想做的事？

**信息反馈**：标记瞬间目标敌人闪一下淡蓝色光；之后残像以半透明灰色渲染，每次位置更新时有轻微"鬼影"过渡动画。巡逻路线虚线用与敌人状态指示相同的 teal 色。

---

## 精良级

### 5. 时裂（延时残渣 → 转化）

**类型**：主动

**效果**：在当前位置放置一个时间裂隙装置（持续 8 秒）。半径 2 格内所有敌人的感知系统冻结——它们在装置存续期间不更新检测状态（不会从 suspicious 升级到 alert，不会从 alert 升级到 chase）。已经在 chase 的敌人不受影响。

**使用次数**：3

**决策点**：放在你准备穿越的巡逻覆盖区（预设安全通道），还是在被多个敌人发现时放在脚下争取逃跑时间？对 chase 状态无效意味着它不是万能脱身工具——必须在升级到 chase 之前使用。

**信息反馈**：装置放置时有一个淡蓝色涟漪扩散效果表示范围。范围内的敌人状态指示点停止闪烁（冻结在当前状态）。8 秒倒计时通过涟漪逐渐收缩表现。

---

### 6. 寄生引流（虹吸残渣 → 转化）

**类型**：被动（装了即生效）

**效果**：每次击杀敌人时，从敌人身上吸取 2 薪柴价值（不受 STORAGE 加成）。另外，击杀后 5 秒内混乱值增速 -50%（短暂的"安全窗口"）。

**使用次数**：累计触发 3 次击杀后破碎。

**决策点**：被动触发无操作决策。出击前的决策：带寄生引流意味着你打算这次出击主动清除 2-3 个敌人（进攻路线）。如果你打算全程潜行不开打，这件工具就是浪费一个 slot。

**信息反馈**：击杀瞬间，敌人死亡位置有一个明显的绿色能量涌向玩家的吸取动画。薪柴 +2 闪现。混乱值条短暂变为绿色边框表示减速生效中（5 秒）。

---

### 7. 虚化步（膨胀残渣 → 转化）

**类型**：主动

**效果**：激活后 3 秒内，你的物理存在"稀释"——可以穿越一层墙壁/障碍物（直线穿越，最多 2 格厚度）。穿越期间不能被敌人感知（完全隐身），但穿越结束后有 1 秒的"实体化"硬直（不能移动）。

**使用次数**：3

**决策点**：用来穿墙抄近路到达 deep 节点（节省大量时间和混乱值），还是留给紧急时刻穿墙逃离追击？1 秒硬直意味着穿到另一边时必须确认那边没有敌人。

**信息反馈**：激活时玩家 sprite 变为半透明 + 轻微闪烁。穿墙过程中有"穿越维度"的视觉扭曲（轻微波纹）。实体化硬直时 sprite 快速闪烁回实体。

---

## 稀有级

### 8. 共振链接（共振残渣 → 转化）

**类型**：主动

**效果**：选择视野内的 2 个点（可以是敌人、薪柴节点、或空地），在它们之间创建一条"共振弦"持续 10 秒。任何穿越共振弦的敌人立刻被弹回 3 格 + 进入 2 秒眩晕（感知/移动停止）。共振弦对玩家无效。

**使用次数**：2

**决策点**：用来封锁一条走廊（安全采集窗口），还是在被追击时放在身后作为"绊线"？两个锚点的选择决定了弦的位置和覆盖——需要空间判断力。

**信息反馈**：两个锚点间显示明显的白色能量线（细微脉冲动画表示活跃）。敌人触线时有明显的弹开 + 闪白 + 短暂屏幕微震。10 秒后弦消散（逐渐变淡）。

---

### 9. 规则覆写（覆写残渣 → 转化）

**类型**：主动

**效果**：对视野内一个敌人使用——"覆写"其行为规则 15 秒。覆写效果：目标敌人的巡逻路线反转（朝远离你的方向行走），且感知范围缩小 50%。如果目标正在 chase 你，覆写使其立刻降级为 return 状态。

**使用次数**：2

**决策点**：用在正在追你的敌人身上（立刻脱离追击），还是用在挡路的巡逻兵上（让它 15 秒内走开）？只有 2 次——你必须判断哪两次遭遇是"非用不可"的。

**信息反馈**：使用时目标敌人的状态指示颜色短暂变为紫色（被覆写状态）。其行为变化本身就是可观测的反馈（开始往反方向走/停止追击）。15 秒结束时指示颜色恢复。

---

### 10. 侵蚀领域（侵蚀残渣 → 转化）

**类型**：主动

**效果**：在当前位置释放一片侵蚀场（半径 4 格），持续 12 秒。领域内效果：所有敌人移速 -40%、感知范围 -30%、chase 状态的追击速度降至 patrol 级别。玩家自身不受影响。

**使用次数**：2

**决策点**：放在需要长时间停留采集的 contested/deep 区域（安全作业窗口），还是在被多敌追击时放在必经之路上（大幅削弱追兵）？12 秒很长——但你需要在领域范围内才能受益，走出去就没了。

**信息反馈**：释放时地面出现明显的暗红色/深紫色脉动圈。领域内的敌人行动明显变慢（视觉可确认）。12 秒后圈逐渐收缩消失。

## 设计总结

### 类型分布

| 类型 | 数量 | 工具 |
| ---- | ---- | ---- |
| 主动 | 7 | 凝锁、反刍之口、残响标记、时裂、虚化步、共振链接、规则覆写、侵蚀领域 |
| 被动 | 2 | 碎影、寄生引流 |

（注：反刍之口虽然需要按键，但本质是"在已拾取节点附近按一下额外拿 1"，操作极简。）

### 策略风格对应

| 出击策略 | 推荐 loadout | 核心体验 |
| -------- | ------------ | -------- |
| 纯潜行 | 碎影 + 时裂 + 残响标记 | 信息优势 + 感知冻结 + 从不正面交锋 |
| 精确清除 | 寄生引流 + 凝锁 + 规则覆写 | 主动出击获取额外薪柴 + 控制遭遇节奏 |
| 贪婪深入 | 虚化步 + 侵蚀领域 + 反刍之口 | 穿墙抄近路 + 安全采集区 + 二次榨取 |
| 探索优先 | 残响标记 + 碎影 + 时裂 | 情报收集 + 减缓被发现 + 通道安全 |

### 信息类反馈设计原则

所有工具的反馈遵循"实时间接提示"原则：
- **主动工具**：使用瞬间有明确视觉特效（玩家主动触发，反馈即时确认"生效了"）
- **被动工具**：触发时有方向性/时间性的屏幕边缘信号（"刚才有事情因为你的装备而改变了"）
- **持续效果**：受影响的敌人/区域有持续的视觉标记（颜色变化、减速表现），让玩家可以观察效果是否还在

### 关于操作复杂度

所有主动工具的操作模式只有三种：
1. **按键即触发**（凝锁、反刍之口、虚化步、侵蚀领域）— 按键后对"最近的合适目标"或"自身位置"生效
2. **按键 + 自动选择目标**（残响标记、规则覆写）— 按键后对视野内最近/最具威胁的敌人生效
3. **按键 + 放置点选择**（时裂、共振链接）— 按键后显示放置预览，再按确认

没有任何工具需要精确瞄准、连续输入或反应速度。
