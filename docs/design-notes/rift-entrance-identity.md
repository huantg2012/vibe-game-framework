# 裂隙入口身份

对照句：储藏锁的是「储藏是收容体」，不是「储藏长什么样」。本文件要锁的是「北侧这台交互物在世界里是什么」，不是它怎么画。

身份已锁。抽卡只抽表现。生产默认保持现有呼吸圆点，直到人抽卡并登记决策。

本包只谈净化点北侧这一台世界内交互物。不是出击关卡本身，不是地面，不是四个交互点一起做。防御点、改造祭坛、加厚本包不动。不开迭代 11。不塞进迭代 5 / 迭代 9 / 迭代 10。活指针仍在迭代 5。Findings P2–P7 仍挂起。

## 审核稿越权用语（先标冲突，再谈身份）

`docs/world.md` 核心设定写死：**裂隙是碎裂的伤口，不是门。** 裂隙不是被制造的通道；它们不稳定、临时、不可控制。

Findings P2 与给人看的审核报告把北侧这台东西写成「空间裂缝 / 传送门 / 门」。这是**越权画法**，与伤口设定冲突。本文件不沿用「它是门」当身份，也不把「空间裂缝 / 传送门」原样列为选项。

上一轮三张（撕裂 / 多层 / 崩塌）是没锁身份就开画的失败路径。人评「表现不咋地」。它们不是成品，不拿来微调交差，也不改写成身份选项。身份从世界观推，不从旧卡反推。

`docs/vision.md` 里「裂隙是临时产生的时空通道」、术语表里「裂隙是不稳定通道」，说的是核心循环里「从这里进入另一块碎片」这件事成立，不是授权把入口做成门。功能上能过去，身份上仍服从伤口设定。

### 世界观硬约束（直接引用，不改写成门）

来自 `docs/world.md`，本文件不改写：

- **裂隙是碎裂的伤口，不是门。** 不是被制造的通道。是时空结构破损后的自然渗漏。不稳定、临时、不可控制。
- 玩家不能选择目的地。
- 空间层级：本时空（完全被覆盖）→ 净化点（微小未覆盖区域）→ **裂隙入口（在净化点边界附近产生）** → 异时空碎片。
- 净化器专责在裂隙入口处压低外来模式残留。入口是踏入发生的地方；净化器是旁边那台剥离装置。
- 进入其他时空 = 暴露在该时空的污染模式下。停留越久，渗透越深。这是混乱值存在的物理理由。
- 「裂隙在净化点附近出现频率更高，是因为未覆盖区在结构上是薄弱点」是 **待验证假设**。是否向玩家解释：当前倾向不解释，当作就是这样。

来自 `docs/vision.md`，本文件不改体验支柱，只作身份后果的锚：

- 核心循环从「进入裂隙」开始。
- 每次穿越裂隙都是赌命：赌的不是能不能赢，而是能不能多撑一天。
- 支柱仍是绝望边缘的紧绷、贪婪与撤退、孤独的仪式感。北侧这台东西是仪式里「再出去一次」发生的地方。

## 2. 已锁身份（人 2026-09-01「开始」）

**伤口渗漏，不是门。**

入口是这条伤口在净化点这一侧的现形；裂隙是那条伤本身。北侧是场景摆放，不写进身份。「未覆盖区是薄弱点」仍是待验证假设，不向玩家解释。

三张视觉卡必须共同服从：读出「这里正在漏」，并且读出「可以从这里去别处」。禁止读成门 / 传送门 / 地板破洞 / 第四台机器 / 界面图标。

可分维度（杂交时只能拆这些）：伤口如何占住场地 · 「另一边」如何被读出 · 不稳定如何被读出。
