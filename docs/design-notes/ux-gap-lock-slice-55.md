## 分区（给 code 的 DOM 合同）

对照 `menu-crt-_layout.md` 的上/中/下。壳、扫描线、底键行、680×468 **不动**。禁止把 P1 和库存塞进同一个 `.scroll-area`。

共享骨架（六个 `.game-panel` 都这样排）：

```
.game-panel          column flex；overflow:hidden
  标题（若有）         flex: 0 0 auto
  .panel-fixed × N    flex: 0 0 auto   ← 决策区，永不滚
  .scroll-area        至多一块         ← 只有合同点名的那区
  .inspect-dock       flex: 0 0 auto；高度固定（约 5–6 行 / min-height 110px）
                      库存变长时禁止被挤矮、禁止进滚动区
  .key-hint-bar       flex: 0 0 auto
```

`.scroll-area` 已有（`flex:1; overflow-y:auto`）。本轮新增结构类 **`.panel-fixed`**（`flex: 0 0 auto`），不新造视觉语言。无库存的表面 **不要**包一层空的 `.scroll-area`。

**原则**：决策用的身份 / 数值 / 机会成本 / 槽上 P1 / 三项属性 / 残留 / 检视 **不得进滚动区**。只有库存列表可滚。蜕变：六卡应尽量不滚；仅当 3×2 在读数玻璃里放不下时，才让卡区成为那一块 `.scroll-area`。

术语跟 `ux-copy-lock-slice-55.md`：表名用 **混乱增速**，不要写回混乱率 / 混乱抗。蜕变底栏是 **刻入**，不是购买。存续分组是残渣 / 工具 / 已碎，不要「库存」。

## 提示队列

通道仍是 IA §S14 的 **B**。函数仍是 `showToastInline`。不要新通道、不要居中弹窗、不要改成 `showToastStamp`。

| 规则 | 值 |
| ---- | -- |
| 同时可见 | 最多 **2** 条 |
| 超出 | 后来的排队；轮到再出现 |
| 空间 | 不重叠同一像素（第二条相对第一条让开高度 + 间隙） |
| 默认时长 | **2s**（现实现默认 3s 改为 2s） |
| 挂载 | 仍 `#dom-ui-root` |

**不进这条队列**（通道 A 即时局部，保持 800ms）：

- 拾取闪 `+N`（贴薪柴数）
- 被动槽短闪「名 生效」（贴工具行；去掉 `·` 粘句——名与「生效」分节点，仍 800ms）

这两条可继续走 `showToastInline`，但必须带「不入队」标记（或等价：不占 2 条名额、不改成 2s）。其余所有 `showToastInline` 调用（防御残留开局、新工具、稳定度里程碑等）进队列。稳定度里程碑若仍 `top:50%;left:50%` 居中，本轮改到通道 B 既有贴边位置，禁止继续居中盖净化点——这不是新通道，是同一条 B 不再占画面中心。

多条防御残留开局：不要用一个 toast 里 `<br>` 叠成一块挡视野；拆成队列条目，同时最多 2 条可见。

## 工具剩余时间

裂隙 HUD **生效中**（左上装置板内，已有 `effectsEl`）：

- **防御残留限时**（混乱增速 ±N% 与秒、移速、视野等）**保持已有行**，表名/数值/时长分节点（混乱增速写法见文案合同）。
- **每条进行中的限时工具**：独立一行 = CSV `displayNameTool`（中文名，独立节点）+ 剩余**整数秒**（独立节点，`ceil(remainingMs/1000)`）。禁止粘成「凝锁4秒」一个复合词。
- **瞬时工具不上这行**：CSV `tool_duration_ms === 0`（反刍之口、消声步常驻）。消声步的余量仍只在工具槽。
- **冷却不上这行**：碎影触发后的 15s 是冷却，不是「效果还在改世界」。怀疑填充正在减速的那一小段若系统已有 remainingMs，可以报；不要把 CD 画成生效。
- 同一工具多名实例：合并一行，剩余秒取最大值。
- 溶解动画（玩法效果已结束、只剩表现）不上。

code：`tool-system` **只读**暴露进行中效果列表（类型 + `remainingMs`）。不改效果、不改时长公式。`rift-scene` 每帧把该列表与已有防御残留行合并进 `RiftHud.setActiveEffects`（或等价），不要用工具行把残留行冲掉。

深渊之眼：10 秒透视走工具行；使用后混乱增速 +50% 若已作为残留/临时增速行存在，保持那一行，不要把两件事写成一句。
