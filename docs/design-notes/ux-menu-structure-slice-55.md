# UX 主菜单结构合同（Slice 5.5）

> **TL;DR**：标题屏永远三组——身份 / 纪录读数 / 动作。摘要是读数，贴动作组上方，不是第三种按钮。游标只属动作行：未选中无可见前缀，已选中 `▸`。覆盖确认同一套分组，读数组只留警告句。

本文是给 art / code 的**结构合同**，不是新系统 spec。文案词仍以 `ux-copy-lock-slice-55.md` / DEC-050 为准，**不要改这些词**。分组权威：本文 > 文案合同里「旁或正上方」的两可句。视觉（字级/色阶/具体空隙 px）归 art，回写 Kit §A5-1。

## 1. 三组是什么

垂直三块，**不是**同一列表里的连续行。组名是结构名，不上屏。

### 身份

始终在。根菜单与覆盖确认屏都保留（场景字已在，确认态不要拆掉）。

| 可见行 | 词（DEC-050，勿改） |
| ------ | ------------------- |
| 标题 | 存续 |
| 副题 | 边界仍在，光尚未熄 |

### 纪录读数

只读。回答「上次到哪 / 清掉会丢什么」。**禁止**游标、禁止 `>` / `▸`、禁止做成可点项。

**根菜单 · 有可读纪录**（三行，表名 / 值 / 档位分节点，禁止 `·` 粘句）：

| 可见行 | 表名 | 值 | 档位 |
| ------ | ---- | -- | ---- |
| 1 | 潮汐 | 第 N 潮 | 涨潮 / 潮峰 / 退潮 |
| 2 | 出击 | M | （无） |
| 3 | 稳定度 | N% | 未完成 / 已完成 |

**根菜单 · 无纪录**：本组不画。不要空表、不要灰行、不要「无纪录」占位句。

**覆盖确认屏**：本组**不画**上述三行。改留一行后果陈述（仍是本组结构槽：非动作、不可点、贴动作上方）：

| 可见行 | 词（DEC-050，勿改） |
| ------ | ------------------- |
| 警告 | 将清除第 {tideNumber} 潮的全部记录 |

警告句 = 纪录读数组在确认态的唯一内容。不是身份，不是第三条动作。

### 动作

唯一可激活组。游标只在这里移动。

| 画面 | 可见行（词勿改） | 默认游标 |
| ---- | ---------------- | -------- |
| 根 · 无纪录 | 进入净化点（仅此一行） | 该行 |
| 根 · 有纪录 | 沿旧路返回；新的纪录 | 沿旧路返回 |
| 覆盖确认 | 清除后进入；沿旧路返回 | 沿旧路返回 |

不要加「存档 / 读取 / 确认 / OK / Continue」。无纪录不要灰掉的第二项。

## 2. 组间距原则

- **组间空隙必须明显大于组内行距。** 身份↔读数、读数↔动作（确认态：警告↔动作）是组间；标题↔副题、三行读数之间、两条动作之间是组内。
- 三组可以仍居中同一竖轴，但必须读成**三块**，不能读成一条匀进行列。
- 读数与动作若空隙≈组内行距，就是本次人反馈的结构失败。
- 具体 px 由 art 给。design 不锁数字。

---

## 3. 摘要贴哪

- 贴**动作组正上方**，属于纪录读数组。
- 不是第三种按钮，不与动作行抢同一视觉角色。
- 无纪录不画空摘要。
- 覆盖确认不要摘要三行（只留警告句，见上）。
- 收紧文案合同「旁或正上方」：结构上**只允许正上方**。「旁」会让读数像按钮标签。词本身不改。

读数与动作的主次：读数是事实，动作是路。art 必须让两簇不可互换（字级或色阶，由 art 核）。design 只锁：读数无游标；动作有游标。

---

## 4. 游标只属于动作行

**选定结构（一种，勿并行）：**

- `>` / `▸` **只出现在可激活的动作行**。
- 纪录读数行、警告句、身份行：**禁止**带 `>` / `▸`。
- **未选中动作行：无可见前缀。**
- **已选中动作行：左侧 `▸`。**
- 未选中可用等宽空位对齐，避免切游标时字跳；空位里**不得**再画 `>` 或第二套符号。

**理由：** 现状静默 `>` + 已选中 `▸` 同列同时出现，形状同类、重量不同，会被读成两种按钮，而不是「同一列表里的游标」。废掉静默 `>` 之后，屏上只剩一枚 `▸`，它才能被读成游标。不废除 `▸`，不改动作文案词。

**对 Kit §A5-1：** 原文「静默 `>`、已选中 `▸`」在**本屏动作列表**上改为「静默无可见前缀、已选中 `▸`」。这是结构澄清，不是新玩法。净化点底栏单行 `>` 提示不是列表游标，**本轮不要求底栏同步改**。art 回写 Kit §A5-1 本屏条目。

**建议 DEC-052 写明：** 游标只属动作行；主菜单列表静默不再用 `>`。

交互保持：`↑ ↓` 只在动作组内移动，`Enter` / 空格激活当前动作行，确认态 `Esc` 回根菜单。

---

## 5. 覆盖确认怎么分组

与根菜单同一套三组，不要另起第四种画面语言。

```
身份     存续
         边界仍在，光尚未熄
         （组间）
读数     将清除第 N 潮的全部记录     ← 仅警告，无摘要三行，无游标
         （组间）
动作     清除后进入                   ← 未选中：无前缀
         ▸ 沿旧路返回                ← 默认游标
```

默认游标仍在「沿旧路返回」（安全项）。警告是读数组，不是动作。不要加「确认」。
