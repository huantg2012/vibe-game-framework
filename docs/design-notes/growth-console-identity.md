人给的新方向（本文件锁死，不再问）：**本质设定为一个圆柱形的人体培养藏，里面是冒泡的半透明液体。整个装置透着科技与神秘学结合的味道。**

### 世界观硬约束（直接引用，不改写）

来自 `docs/world.md`：

- 薪柴 = 异源污染冲突的残渣，携带对另一种模式的否定性。投入时否定性耗尽。
- **刻入** = 用薪柴换永久改造。不是治疗，不是净化。
- 净化点：守点的人自己造的，手头有什么用什么；磨损但有人维护；灯光微弱；**有颜色的地方就是被污染的地方。**
- 污染体可「不透明变半透明」——培养液是同一条语法用在容器里，不是地上的黏液。

推论（这台装置存在的物理理由）：**人要把薪柴的否定性写进自己的身体。所以场上有一具能装下一个人体的圆柱培养藏；舱里的半透明液体就是那份否定性在工作。刻进去就抽不出来。**

「科技与神秘学结合」落到本作，不是通用法阵、也不是飞船培养舱：

- **科技** = 守点的人焊得起来的东西：压力箍、螺栓、混凝土座、长短不齐的法兰。够用，不是精加工。
- **神秘学** = 这世界里颜色即污染。舱液是青绿的外来介质；缸壁上有事后刻上去的、不对称的痕——像有人想把否定性写进金属，不是出厂铭牌。

禁止读成：全息 UI、LED 屏、机械臂、香炉、祭坛、供奉台那种空心圈。

## 2. 已锁身份

**一具能装下人体的圆柱培养藏。舱里是冒泡的半透明液体。科技箍着它，外来介质在里面改人。**

一眼必须读出两件事：

1. **改的是人**——体量够装一个身体；舱里有活着的介质，不是旋钮台面。
2. **圆柱培养藏**——腔体是圆柱，液体在腔里。不是拱门、不是钳子、不是空心环。

### 本质作为过滤器（划成立范围）

- **要求：** 有一个圆柱腔；腔被液体填满（半透明 = 能看见深浅和气泡，不是看穿到画布）；液体在动（冒泡）；体量暗示装得下人；科技零件 + 事后刻痕同时在。
- **排除：** 操作台 / 旋钮案（上一轮）；祭坛 / 香炉；电脑 / 屏幕 / 灯条 / 机械臂；供奉台的拱 / 钳 / 空心环（西南已经是卡 I 环，本台再出开口三类 = 雷同）；储藏那种只关不开的井；黄铜整台 / 木整台当身份。
- **于是哪些形体成立？** 圆柱腔怎么占空间——通常不止一个。用三个手法找：

  1. **分量主导：** 「装得下人」主导 → 立着的缸（人站进去）；「躺进去改」主导 → 横卧的棺管；「沉下去改」主导 → 地面上的井口。
  2. **换体量分布：** 竖高 / 横卧 / 贴地。
  3. **不换载体平面：** 三张都立在混凝土地上，相机同一套。沉井仍有短壁，不是地面贴花。

  候选：立缸 / 横棺 / 沉井。三个都还是圆柱腔 + 舱液，落在成立范围里。

**圆柱是腔的语法，不是抽卡的唯一取值。** 三张必须是三个不同的占空间方式。禁止三张都画成「立着的玻璃罐换窗的位置」。

### 必须共同服从的读法

1. 读出**圆柱腔**，腔内是介质，不是空。
2. 读出**液体在冒泡**（结构钉死，只动液面 / 气泡 / 舱内暗团）。
3. 读出**科技箍 + 事后刻痕**，不是出厂培养舱，也不是法阵。
4. 舱液青绿只在腔里。半透明靠舱内分档（深 / 中 / 亮泡），禁止把腔心挖成透明——那会读成供奉台的环。

### 禁止读成

| 禁止读成 | 为什么 |
| -------- | ------ |
| 供奉台 G 拱 / H 钳 / I 环 | 人点名高度雷同。本台闸门直接禁这三类 |
| 机械操作台 / 旋钮案 | 上一轮整支作废：看不出改的是人 |
| 祭坛 / 神龛 / 香炉 | 核心已经是神龛。青绿绝不许溢出口沿往上飘 |
| 电脑 / 屏幕 / LED | 审核红线「不能太现代」仍在；整齐亮矩形 = 屏幕 |
| 空心圈 / 舷窗门环 | 腔必须被液体填满 |
| 一只眼 | 舱内暗团不得是光滑对称椭圆 |
| 花盆 / 底座 | 沉井禁止底部填实深色椭圆当座 |
| 黏液滩 | 液体在腔里，不淌到地上 |

| 装置 | 一句话 | 玩家给它什么 | 它做什么 |

## 3. 可分维度（抽卡时只许拆这些）

**第一轴 = 圆柱腔怎么占空间。一张一类。**

| 形体类 | 第一眼 | 机器判据 |
| ------ | ------ | -------- |
| 立缸 | 人能站进去的立着的缸 | `aspect ≤ 0.78` 且 `rise ≥ 0.55` 且 `enclosed = 0` 且 `apex_two < 2` 且 `mid_runs = 1` |
| 横卧 | 人能躺进去的横管 | `0.90 ≤ aspect ≤ 1.70` 且 `0.40 ≤ rise < 0.55` 且 `enclosed = 0` 且 `apex_two < 2` |
| 沉井 | 人往下沉的井口，顶上看进去 | `aspect ≥ 1.15` 且 `rise < 0.40` 且 `enclosed = 0` 且 `apex_two < 2` |

`rise` = 材质包围盒高 / 画布高（去接地两行、去近黑地裂）。`enclosed = 0` 是硬条件：腔心必须被液体填住，不许再出现供奉台那种封闭内孔。

**本台禁止落进：** 拱 / 钳 / 环（判据与供奉台同一套）。任何一张撞上这三类 = 不合格。曾试过画布对齐占用 IoU，同相机同画幅的中央实心块会稳定偏高，测的不是「长得像拱/钳/环」——那件事由开口三类拓扑闸门抓。

**第二轴（绑在形体上，不独立排）：** 舱液怎么动（气泡上浮）。三张都冒泡。

**第三轴（声明可分、本回合不拆成卡）：** 待处理高亮（可刻入 vs 闲置）。三张都只播舱液在动。生产若翻，高亮跟现有「可刻入」逻辑走，不另画一套屏幕。

禁止再按黄铜 / 石 / 木拆，禁止再按「旋钮还是拉杆」拆。

## 4b. 净化点打光（卡 A 热修锁死）

场上两盏会照到这台装置的灯：

| 灯 | 位置 | 色 | 行为 | 半径 |
| -- | ---- | -- | ---- | ---- |
| **核心** | 净化点正中。本台在它**正西** 3.5 tile（同高） | teal（烧薪柴，光与污染同源） | 固定。地面光池 + 本体自发光。代码写明「应当是净化点内的主要光源」 | 光池半径约 56px × 1.25；艺术方向 3–4 tile 有效 |
| **玩家灯** | 跟玩家走。出生在核心南 2 tile；走近本台时人多半从东侧过来 | warm-dim | 净化点里半强度、全向、不开手电 | 贴身 2–3 tile |

**烤进贴图的主光源 = 核心。** 贴图不能跟玩家走，只能烤一盏固定灯。核心永远在本台东侧（屏幕右），所以：

- 缸的**右面亮、左面暗**
- 接地影往**西**偏（屏幕左），贴着缸底，不是缸底下再画一条悬空横杠
- 玩家灯是走近时的暖补光，最多一格 `warm-dim` 指示落在东侧棱上；禁止把玩家灯方向烤成第二套影子

缸**紧贴地面**：没有垫高的座；缸壁落到接地点。深色只许是往西偏的接地斑，禁止填实椭圆座（花盆误读）。

人抓回「中段透明约全高 70%」：舱液占物体高度 62–78%。腔仍须被液体填满（`enclosed = 0`），不是挖空看穿画布。中段是整圈舱液，前脸不许留一圈金属当窗框；箍只咬屏幕左右剪影。

「不压全身」测的是顶盖 / 缸底仍是材质（物体两端 14% 带里舱液 < 22%），不是全身面积帽。旧的面积 < 58% 会和「中段整圈 70%」打架——测的量从窗变成整圈中段之后定义冲突，不是把阈值抬绿。
