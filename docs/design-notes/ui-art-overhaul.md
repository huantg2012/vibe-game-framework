#### `purification-hud` 载体裁定（专门说明）

Slice 5 的 code agent 让它自成一套"无文字标签、位置+颜色+形状即语言"的符号网格，不套 `.game-panel`。裁定为**保留**，理由：

1. **它符合载体分工的逻辑，不是偷懒**：`.game-panel` 是"世界内终端"（B 类，唤出后才看的一块屏幕），而 `purification-hud` 承载的是 P0 常驻信息（薪柴/稳定度/潮汐/冲击预告）——这本应是"世界内装置"（A 类）的活儿。给一个 A 类装置强行套 B 类终端的边框面板样式，才是真正的不一致。
2. **与裂隙 HUD 分工对称**：裂隙 HUD（#2）同样是无边框符号层，两个场景的"常驻读数层"用同一套语言（无边框、符号先行、颜色+位置编码），这才是 U11"同一台设备"的正确达成方式——不是所有东西都套同一个 CSS class，而是"同类载体用同类语言"。
3. **需要修的不是载体，是内容完整度**：现状问题是裂隙 HUD 的符号语言比 `purification-hud` 简陋得多（没有第二重编码、没有身份标签），§A5 会把裂隙 HUD 补齐到同等语言水平，而不是把 `purification-hud` 拉低到套用面板边框。

### A1. 可读性硬规则（优先级高于装饰，做不到位整个 Slice 不合格）

#### 技术根因：角锚必须跟画布走同一根

DOM 面板与裂隙 HUD 的字号都是 CSS px。屏幕空间 overlay 挂 `#dom-ui-root`，由 `bindDomUiRootToGame()` 按 canvas 实际显示框做 `translate + scale(canvasWidth/960)`。**1 声明 CSS px ⇔ 1 逻辑画布 px（960×640）。**

裂隙 HUD **已是 DOM**（`rift-hud.ts`）。禁止再用 Phaser `scrollFactor(0)` 画角锚——`camera.zoom ≠ 1` 会把四角甩出视口。`hud.ts` **已删除**。下列「Phaser HUD ×1.5」换算 **作废**，不得当验收基准。

主菜单仍是 Phaser Text（元界面、zoom=1）；CJK 须 `setPadding` 顶边，见 `ux-menu-text-clip-slice-55.md`。

统一最小字号（**DOM 声明值**）：

| 层级 | DOM（CSS px） | 用途 |
| ---- | ------------- | ---- |
| 标题/关键数值 | ≥ 16px | 面板标题、结算数字、临界警告 |
| 正文/数值 | ≥ 13px | 描述文字、状态数值、工具名 |
| 标签/次要 | ≥ 12px | 槽位标签、提示行、耗尽态 |

#### 最小对比度

正文文字与其背景的对比度 **≥ 4.5:1**（WCAG AA 文本标准，用相对亮度公式估算，作为内部设计基准，不
要求正式认证但计算方法一致）；纯装饰性边框/分隔线不强制，但若边框本身承载状态含义（如"已选中"边框）
建议 ≥ 3:1。

#### 关键数值的第二重编码（禁止单靠颜色）

任何"安全/危险""可用/不可用""高/低"的判断，必须至少有一种非颜色编码同时存在：形状（pip/方块计数）、
位置（刻度线）、符号（图标/字符）、离散数量（●●●○○）。混乱值条有刻度线；完整度条必须同时有标签+条+数字
（禁止只靠颜色脉动）。玩家表名是「完整度」，禁止上屏 HP / 生命值。

### A3. 排版

#### 字体族（不变，但补充"哪台机器打出来的字"的分工）

- **主字体**：`"Courier New", monospace`，系统回退 monospace。
- **世界内装置/终端（A/B 类，#2-15）**：字体族固定不变——这是"设备/终端打印出来的字"，任何场合

## B. 角色美术方案

### B1. 玩家（32px 俯视角，Phaser Graphics 程序化绘制）

#### 设计方向

工业防护服轮廓 + 背包 + 肩灯暖光点。从正上方看是一个略扁的六边形躯干 + 圆形头部 + 短腿影。整体色调融入净化点环境（冷灰），只有肩灯是暖色。

#### 形状构成（32x32 画布，实际内容约 20x28）

```
        ●●           ← 头部：4x4px 圆角矩形，#3a3d42
      ●●●●●●         ← 肩部：8px 宽，#2c2e33
     ●●●●●●●●        ← 躯干：10x8px 六边形轮廓，#2c2e33
     ●●████●●        ← 背包：中间 6x4px 凸起，#2a2a2e
      ●●●●●●         ← 腰部收窄
       ●● ●●         ← 腿部阴影：2x3px x2，#151a1e
```

#### 方向辨识

- 朝向通过**头部偏移** + **肩灯位置**表达：
  - 朝下（默认）：头部居中，肩灯在左上角
  - 朝上：头部居中偏上，肩灯在左下角
  - 朝左/右：头部偏移 2px + 肩灯在对应肩部
- 肩灯：1x1px `#c4873a` 亮点（唯一暖色，方向指示器）

#### 色彩

| 部位 | 色值 |
|------|------|
| 头部/面罩 | `#3a3d42` |
| 躯干/外套 | `#2c2e33` |
| 背包 | `#2a2a2e` |
| 腿部阴影 | `#151a1e` |
| 肩灯 | `#c4873a`（1px） |
| 轮廓暗边 | `#151a1e`（底部/右侧 1px 阴影线） |

#### Phaser Graphics 实现要点

```typescript
// 伪代码 - 玩家绘制
const g = scene.add.graphics();
// 躯干
g.fillStyle(0x2c2e33);
g.fillRect(-5, -4, 10, 8);
// 头部
g.fillStyle(0x3a3d42);
g.fillRect(-2, -8, 4, 4);
// 背包凸起
g.fillStyle(0x2a2a2e);
g.fillRect(-3, 0, 6, 4);
// 肩灯（方向性）
g.fillStyle(0xc4873a);
g.fillRect(-5, -4, 1, 1);
// 腿部阴影
g.fillStyle(0x151a1e);
g.fillRect(-3, 4, 2, 3);
g.fillRect(1, 4, 2, 3);
```

#### 动画方案（代码实现）

- 待机：躯干整体每 250ms 上移 1px 再回来（呼吸感）
- 移动：腿部影像交替闪烁（左右各 2 帧），8fps
- 受伤：整体 fillStyle 切白色 (#c8cdd4) 1 帧，然后恢复

### B2. 敌人（差异化方向 + 状态表达）

#### 渗透体（32x32）

**设计方向**：几乎是人形剪影，但比例错误——手臂过长 2px，肩膀不对称（一高一低），头部偏小。表面有 3-5 个 teal 散点像素（"坏像素"签名）。

| 部位 | 色值 |
|------|------|
| 基体轮廓 | `#2e2d30`（极暗，与环境低对比） |
| 坏像素散点 | `#1aad96`（3-5 个 1px 点） |
| 感知区高亮 | `#2ae6c8`（头部 1px，警觉时亮度增加） |

**状态表达**：
- 巡逻：匀速移动，坏像素静态
- 警觉：停顿，头部 teal 点从 `#1aad96` 变为 `#2ae6c8`（亮度跳升）
- 追击：移速加快，整体每 4 帧抖动 1px（不协调的突进）

#### 改写体（32x48）

**设计方向**：半人半崩坏。左半身保持人形轮廓，右半身溶解为矩形 teal 色块簇。整体重心偏移，前倾。体积比渗透体大 50%。

| 部位 | 色值 |
|------|------|
| 完整半身 | `#2e2d30` |
| 崩坏半身 | `#0e4a3f` 基底 + `#1aad96` 色块簇（15-20px 面积） |
| 核心亮点 | `#2ae6c8`（胸部中心 2x2px） |
| 边缘飘散 | `#1a6b5c` 半透明粒子（代码动态层） |

**状态表达**：
- 巡逻：崩坏侧缓慢脉动（alpha 0.8-1.0，2s 周期）
- 警觉：核心亮点闪烁加速
- 追击：位置每 8 帧跳动 1-2px（"渲染位置错误"）

#### 覆盖体（48x48）

**设计方向**：完全非人形。抽象几何体——多重偏移矩形叠加，像一个坏掉的 sprite 被多次错误渲染在不同位置。全体自发光 teal，中心有白热核心。

| 部位 | 色值 |
|------|------|
| 外层偏移矩形 | `#1a6b5c` @ 60% alpha |
| 中层主体 | `#1aad96` |
| 内层核心 | `#2ae6c8` 中心 + `#7fffee` 核心点 (2x2px) |
| 环境光池 | `#1aad96` @ 20% alpha，半径 3-4 tile（代码实现） |

**状态表达**：
- 匀速滑行（不步行），无帧动画——整体平移
- 外层矩形每 1s 偏移位置循环（"多次渲染"感）
- 投射面积光池随移动跟随

### B4. 节点视觉升级

#### 薪柴（16x16）

**当前**：占位 teal 色块。
**升级方向**：不规则多面体残渣（4-6 个像素组成的非对称形状）+ 微弱 teal 余晖。

**当前**：白色脉动。
