# 界面与世界表现

## A. 当前全游戏界面设计

本轮设计输入只有真实游戏场景、世界观及用户最新反馈。此前的CRT/墙机/像素字体/固定字号处方不构成本轮约束。实现保持960×640逻辑画布对齐，是技术坐标约定。

### 意图

人只是黑暗中维持存在的个体。界面应像视野边缘的低声记述，读数需要时找得到，观看场景时不抢夺注意。交互时才允许展开较完整的信息；结束操作后还给世界。恐怖感由世界、留白与未知支撑，不堆符文、金属装饰或“克苏鲁主题”图标。

### 文字与视觉分量

- 正文12px/20–21px，辅助11px/18px，快捷键10px。使用常规中文无衬线字体保证小字号清晰；场景交互与菜单标题16px/24px与正文同用无衬线字体，字距1px；详情标题亦同。取消COH Pixel整套大字限制，中文不强制点阵字。
- 灰绿文字与低饱和灰色标题；暖灰褐用于薪柴与消耗，低饱和灰绿用于污染及器具。不用大片亮白、艳青或粗色边框。
- 六点交互、报告、暂停与结算均无矩形底板；渐隐暗场在整个视野上连续过渡，文字区域不叠颗粒或独立纹理。详细构图见下文R5/R6；固定逻辑画布不变。
- 焦点用局部微亮底色/短边线，暂停列表只用小短划与字色；文字不叠噪点、不降低整体透明度。关键操作可点击，底栏固定。颜色和词语共同说明状态。

### 常驻与瞬时信息

- 净化点HUD右上，字体11px，无底板，整体低对比；薪柴、潮汐、归来预告保持轻量读数。闲置操作提示置底边，进一步减弱。
- 裂隙完整度与混乱归左上，两个144px细条，厚2px；生命y24、混乱y66。中央上沿留空。数字11px，标签/阶段10px，危险状态仍用原机制触发。
- 薪柴右上、器具左下、地图右下，均无实体罩。翻找/撤离底中，进度120px×2px；低语在其上方，采用13px衬线文字。时序与资格不变。

### 决策编排

- 供奉/装配：上部横向槽位，下部双列库存，右侧单件详情。常规完整示例库存（18种器具；17件可供奉）无须滚动；更多重复藏品自然滚动。槽位只保留名称、次数或充能，长效果与类别归详情。
- 装配的下次踏入条件归右栏下部，不插在库存中间。“踏入裂隙”底部按钮与Shift+Enter始终保留；普通Enter用于当前装填/取下。库存左右±1、上下±2，符合两列位置。
- 蜕变：七项单列完整展开，右侧显示效果、成本和剩余薪柴。无需滚动找最后一项。
- 分配：当前完整度→投入→修复/效果→剩余薪柴。取消与当前修复无关的其他装置耐久、最便宜蜕变价格重复披露；这些仍在对应报告/蜕变页。完整度与投入区保持独立间隔。
- 报告四页保留机制分类，以低分量文字、窄装置列表与详情呈现；残渣超长列表支持稳定滚动。
- 撤离/阵亡和冲击结果采用同一排字，唯一关键收获/损伤突出到18px；次要记录12px，损伤图仅细条，不形成巨幅红条。
- 主菜单沿用本作宣传图，标题36px，使用与游戏交互一致的无衬线字；菜单操作13px。暂停和失焦提示收小。

### 滚动行为

选择变化保留列表DOM，仅替换详情与底栏；pointermove改变当前对象，滚轮导致条目移到鼠标下方不重建。完整数据刷新保存各滚动区的位置。只有键盘浏览主动显露选项；鼠标滚动不跟随旧焦点回顶。切报告页才重置滚动。

实现为 `panel-render-state.ts`，供奉、装配、蜕变、报告共用。此处描述真实行为，不以隐藏滚动条代替修复。

### 当前验证

2026-09-06：供奉/装配/蜕变完整示例无滚动；长库存（5份全部品类）装填后位置驻留、网格键盘导航已实测。新一轮画面证据使用r2前缀。上一轮r1截图只保留历史；人已明确否决。R2人审：HUD95分PASS并锁定；交互80分，布局非常好，材质与标题待改。R3仅修改面板材质和标题字体，当前画面r3前缀，待复评。

## B. 角色美术方案

### B1. 玩家（32px 俯视角，Phaser Graphics 程序化绘制）

#### 设计方向

工业防护服轮廓 + 背包 + 肩灯暖光点。从正上方看是一个略扁的六边形躯干 + 圆形头部 + 短腿影。整体色调融入净化点环境（冷灰），只有肩灯是暖色。

#### 形状构成（32x32 画布，实际内容约 20x28）

```
        ●●           ← 头部：4x4px 圆角矩形，#3a3d42
      ●●●●●●         ← 肩部：8px 宽，#2c2e33
     ●●●●●●●●        ← 躯干：10x8px 六边形轮廓，#2c2e33
     ●●████●●        ← 背包：中间 6x4px 凸起，#2a2a2e
      ●●●●●●         ← 腰部收窄
       ●● ●●         ← 腿部阴影：2x3px x2，#151a1e
```

#### 方向辨识

- 朝向通过**头部偏移** + **肩灯位置**表达：
  - 朝下（默认）：头部居中，肩灯在左上角
  - 朝上：头部居中偏上，肩灯在左下角
  - 朝左/右：头部偏移 2px + 肩灯在对应肩部
- 肩灯：1x1px `#c4873a` 亮点（唯一暖色，方向指示器）

#### 色彩

| 部位 | 色值 |
|------|------|
| 头部/面罩 | `#3a3d42` |
| 躯干/外套 | `#2c2e33` |
| 背包 | `#2a2a2e` |
| 腿部阴影 | `#151a1e` |
| 肩灯 | `#c4873a`（1px） |
| 轮廓暗边 | `#151a1e`（底部/右侧 1px 阴影线） |

#### Phaser Graphics 实现要点

```typescript
// 伪代码 - 玩家绘制
const g = scene.add.graphics();
// 躯干
g.fillStyle(0x2c2e33);
g.fillRect(-5, -4, 10, 8);
// 头部
g.fillStyle(0x3a3d42);
g.fillRect(-2, -8, 4, 4);
// 背包凸起
g.fillStyle(0x2a2a2e);
g.fillRect(-3, 0, 6, 4);
// 肩灯（方向性）
g.fillStyle(0xc4873a);
g.fillRect(-5, -4, 1, 1);
// 腿部阴影
g.fillStyle(0x151a1e);
g.fillRect(-3, 4, 2, 3);
g.fillRect(1, 4, 2, 3);
```

#### 动画方案（代码实现）

- 待机：躯干整体每 250ms 上移 1px 再回来（呼吸感）
- 移动：腿部影像交替闪烁（左右各 2 帧），8fps
- 受伤：整体 fillStyle 切白色 (#c8cdd4) 1 帧，然后恢复

### B2. 敌人（差异化方向 + 状态表达）

#### 渗透体（32x32）

**设计方向**：几乎是人形剪影，但比例错误——手臂过长 2px，肩膀不对称（一高一低），头部偏小。表面有 3-5 个 teal 散点像素（"坏像素"签名）。

| 部位 | 色值 |
|------|------|
| 基体轮廓 | `#2e2d30`（极暗，与环境低对比） |
| 坏像素散点 | `#1aad96`（3-5 个 1px 点） |
| 感知区高亮 | `#2ae6c8`（头部 1px，警觉时亮度增加） |

**状态表达**：
- 巡逻：匀速移动，坏像素静态
- 警觉：停顿，头部 teal 点从 `#1aad96` 变为 `#2ae6c8`（亮度跳升）
- 追击：移速加快，整体每 4 帧抖动 1px（不协调的突进）

#### 改写体（32×48，俯视 4 向）

**设计方向**：半人半崩坏。**身体右侧**溶散为矩形 teal 簇，完整侧保留爪 / 前倾（与渗透体同家族）。覆盖 ~50%。成品走程序像素，死约束：`docs/art/rewriter-sprite.md`（DEC-066）。禁止一张图旋转、禁止紫粉史莱姆、禁止眼睛。

| 部位 | 色值 |
|------|------|
| 完整半身 | `#2e2d30` |
| 崩坏半身 | `#0e4a3f` 基底 + `#1aad96` 簇 **17 px** |
| 簇心 | `#2ae6c8`（2 px） |
| 边缘飘散 | `#1a6b5c`（baked 喷点 + 可选粒子） |

**状态表达**（无新色）：
- 巡逻：崩坏侧 alpha 0.80–1.00，周期 2000 ms
- 搜寻：簇内再 4 px 改 `#2ae6c8`，3.0 Hz 亮/暗 1.00/0.55
- 追击：簇几乎全改 `#2ae6c8`；残影间隔 55 ms；每 8 帧沿身体右侧抖 1 px

#### 覆盖体（48x48）

**设计方向**：完全非人形。抽象几何体——多重偏移矩形叠加，像一个坏掉的 sprite 被多次错误渲染在不同位置。全体自发光 teal，中心有白热核心。

| 部位 | 色值 |
|------|------|
| 外层偏移矩形 | `#1a6b5c` @ 60% alpha |
| 中层主体 | `#1aad96` |
| 内层核心 | `#2ae6c8` 中心 + `#7fffee` 核心点 (2x2px) |
| 环境光池 | `#1aad96` @ 20% alpha，半径 3-4 tile（代码实现） |

**状态表达**：
- 匀速滑行（不步行），无帧动画——整体平移
- 外层矩形每 1s 偏移位置循环（"多次渲染"感）
- 投射面积光池随移动跟随

### B4. 节点视觉升级

#### 薪柴（16x16）

**当前**：占位 teal 色块。
**升级方向**：不规则多面体残渣（4-6 个像素组成的非对称形状）+ 微弱 teal 余晖。

| 部位 | 色值 |
|------|------|
| 主体 | `#1a6b5c`（暗 teal 固体） |
| 高光面 | `#1aad96`（顶部 1-2px） |
| 余晖 | `#1aad96` @ 30% alpha（周围 1px 光晕，代码实现） |

**动画**：2 帧，高光面位置微移（200ms 周期，模拟微弱脉动）。

#### 撤离点（32x32）

**当前**：白色脉动。
**升级方向**：垂直裂缝形态——中心白热线 + teal 边缘辐射。

| 部位 | 色值 |
|------|------|
| 裂缝中心线 | `#b0fff5`（近白，2px 宽 x 16px 高） |
| 边缘辐射 | `#2ae6c8`（中心两侧各 2-3px 渐淡） |
| 外围微光 | `#1aad96` @ 15% alpha |

**动画**：4 帧脉动——中心线宽度 2px->3px->2px->1px，800ms 周期。靠近时周期缩短至 400ms。

#### 污染物/战利品（16x16）

**设计方向**：比薪柴更"活"的感觉——不规则球形 + 中心高亮 + 缓慢旋转感。

| 部位 | 色值 |
|------|------|
| 外壳 | `#0e4a3f` |
| 活性面 | `#1aad96`（随机 3-4px 表面高亮） |
| 核心 | `#2ae6c8` 1px 中心点 |
