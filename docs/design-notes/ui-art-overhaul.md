# UI Design Kit + 角色美术方案

> 目标：从"调试信息 + 后台管理系统 + 原型几何体"升级为符合 art-direction.md 的游戏内体验。
> 约束：像素风 32px、pixelArt:true、palette.json 锁定色板、程序化绘制（Phaser Graphics）优先。

---

## A. UI Design Kit 规范

### A1. 色彩系统

#### 三层级基础色

| 层级 | 用途 | 色值 | 备注 |
|------|------|------|------|
| 背景层 | 面板/条形底色 | `#0f1114` @ 88% opacity | 半透明，不完全遮挡游戏画面 |
| 边框层 | 面板边框/分割线 | `#2a2d32` | 1px 实线，无圆角 |
| 文字层-主 | 关键数值/标题 | `#c8cdd4` | 唯一高亮文字色 |
| 文字层-次 | 标签/正文 | `#8a8f96` | 常规阅读色 |
| 文字层-弱 | 次要信息/禁用 | `#8a8f96` @ 50% | 极弱存在感 |

#### 语义色（5 种）

| 语义 | 色值 | 用途 |
|------|------|------|
| 薪柴 | `#c4873a` | 薪柴计数、分配面板暖色调 |
| 混乱 | `#1aad96` | 混乱值条填充、混乱相关提示 |
| 生命 | `#cc3333` | 生命条低血量脉动 |
| 稳定度 | `#44aa66` | 净化点稳定度指示 |
| 危险 | `#cc3333` @ 脉动 | 临界警告（生命<25%、混乱>75%） |

#### 条形填充色（渐变方案）

| 数值条 | 正常填充 | 低值填充 | 背景槽 |
|--------|----------|----------|--------|
| 生命 | `#8a8f96` 50% alpha | `#cc3333` 脉动 | `#151a1e` |
| 混乱 | `#1aad96` | `#2ae6c8` 高亮脉动（>75%） | `#151a1e` |
| 稳定度 | `#44aa66` | `#66cc88`（>75%）| `#151a1e` |

### A2. 排版

#### 字体

- **主字体**：`"Courier New", monospace`（等宽像素感；后续可替换为自定义像素字体如 Press Start 2P）
- **回退**：系统 monospace

#### 字号层级（4 级）

| 级别 | 大小 | 用途 | 行高 |
|------|------|------|------|
| H1 | 14px | 面板标题、结算标题 | 20px |
| H2 | 11px | 数值标签、模块名 | 16px |
| Body | 10px | 正文内容、描述文字 | 14px |
| Caption | 9px | 次要信息、提示 | 12px |

#### 间距系统

- 基础单位：4px
- 面板内边距：12px（3 单位）
- 元素间距：8px（2 单位）
- 段落间距：12px（3 单位）
- 条形高度：4px（紧凑模式）/ 6px（标准模式）

---

### A3. 面板组件

#### 外框

```
┌─────────────────────────┐  ← 1px #2a2d32 实线
│  padding: 12px          │  ← 背景 #0f1114 @ 88%
│                         │
│                         │
└─────────────────────────┘  ← 无圆角，无阴影，无发光
```

- 无 border-radius（工业直角）
- 无 box-shadow（CRT 监视器不发光）
- 嵌套面板：用 1px 水平分割线隔开，不用嵌套边框

#### 按钮 4 态

| 状态 | 边框 | 背景 | 文字 |
|------|------|------|------|
| Default | `#2a2d32` 1px | `#0f1114` | `#8a8f96` |
| Hover | `#3a3d44` 1px | `#151a1e` | `#c8cdd4` |
| Active | `#4a4e55` 1px | `#1a1d22` | `#c8cdd4` |
| Disabled | `#2a2d32` 1px @ 40% | `#0f1114` @ 40% | `#8a8f96` @ 40% |

- 尺寸：最小高度 24px，水平内边距 12px
- 无圆角、无阴影
- Hover 态过渡：100ms ease-out

#### 分割线

- 水平：1px solid `#2a2d32`，左右各缩进 0px（全宽）
- 用于面板内分区，代替嵌套边框

#### 进度条

```
┌──────────────────────────────┐  ← 无边框
│████████████░░░░░░░░░░░░░░░░░│  ← 高 4px
└──────────────────────────────┘
  填充色（语义色）     槽色 #151a1e
```

- 高度：4px（HUD 紧凑）/ 6px（面板内标准）
- 无圆角端头
- 临界状态：填充色切换 + 0.3s 周期 alpha 脉动（0.6-1.0）
- 刻度线：1px 宽 `#ffffff` @ 30%，仅混乱值条在 50%/75% 处标记

| 动效 | 触发 | 参数 |
|------|------|------|
| 面板开启 | 打开面板/菜单 | opacity 0->1, 150ms ease-out |

## B. 角色美术方案

### B1. 玩家（32px 俯视角，Phaser Graphics 程序化绘制）

#### 设计方向

工业防护服轮廓 + 背包 + 肩灯暖光点。从正上方看是一个略扁的六边形躯干 + 圆形头部 + 短腿影。整体色调融入净化点环境（冷灰），只有肩灯是暖色。

#### 形状构成（32x32 画布，实际内容约 20x28）

```
        ●●           ← 头部：4x4px 圆角矩形，#3a3d42
      ●●●●●●         ← 肩部：8px 宽，#2c2e33
     ●●●●●●●●        ← 躯干：10x8px 六边形轮廓，#2c2e33
     ●●████●●        ← 背包：中间 6x4px 凸起，#2a2a2e
      ●●●●●●         ← 腰部收窄
       ●● ●●         ← 腿部阴影：2x3px x2，#151a1e
```

#### 方向辨识

- 朝向通过**头部偏移** + **肩灯位置**表达：
  - 朝下（默认）：头部居中，肩灯在左上角
  - 朝上：头部居中偏上，肩灯在左下角
  - 朝左/右：头部偏移 2px + 肩灯在对应肩部
- 肩灯：1x1px `#c4873a` 亮点（唯一暖色，方向指示器）

#### 色彩

| 部位 | 色值 |
|------|------|
| 头部/面罩 | `#3a3d42` |
| 躯干/外套 | `#2c2e33` |
| 背包 | `#2a2a2e` |
| 腿部阴影 | `#151a1e` |
| 肩灯 | `#c4873a`（1px） |
| 轮廓暗边 | `#151a1e`（底部/右侧 1px 阴影线） |

#### Phaser Graphics 实现要点

```typescript
// 伪代码 - 玩家绘制
const g = scene.add.graphics();
// 躯干
g.fillStyle(0x2c2e33);
g.fillRect(-5, -4, 10, 8);
// 头部
g.fillStyle(0x3a3d42);
g.fillRect(-2, -8, 4, 4);
// 背包凸起
g.fillStyle(0x2a2a2e);
g.fillRect(-3, 0, 6, 4);
// 肩灯（方向性）
g.fillStyle(0xc4873a);
g.fillRect(-5, -4, 1, 1);
// 腿部阴影
g.fillStyle(0x151a1e);
g.fillRect(-3, 4, 2, 3);
g.fillRect(1, 4, 2, 3);
```

#### 动画方案（代码实现）

- 待机：躯干整体每 250ms 上移 1px 再回来（呼吸感）
- 移动：腿部影像交替闪烁（左右各 2 帧），8fps
- 受伤：整体 fillStyle 切白色 (#c8cdd4) 1 帧，然后恢复

### B2. 敌人（差异化方向 + 状态表达）

#### 渗透体（32x32）

**设计方向**：几乎是人形剪影，但比例错误——手臂过长 2px，肩膀不对称（一高一低），头部偏小。表面有 3-5 个 teal 散点像素（"坏像素"签名）。

| 部位 | 色值 |
|------|------|
| 基体轮廓 | `#2e2d30`（极暗，与环境低对比） |
| 坏像素散点 | `#1aad96`（3-5 个 1px 点） |
| 感知区高亮 | `#2ae6c8`（头部 1px，警觉时亮度增加） |

**状态表达**：
- 巡逻：匀速移动，坏像素静态
- 警觉：停顿，头部 teal 点从 `#1aad96` 变为 `#2ae6c8`（亮度跳升）
- 追击：移速加快，整体每 4 帧抖动 1px（不协调的突进）

#### 改写体（32x48）

**设计方向**：半人半崩坏。左半身保持人形轮廓，右半身溶解为矩形 teal 色块簇。整体重心偏移，前倾。体积比渗透体大 50%。

| 部位 | 色值 |
|------|------|
| 完整半身 | `#2e2d30` |
| 崩坏半身 | `#0e4a3f` 基底 + `#1aad96` 色块簇（15-20px 面积） |
| 核心亮点 | `#2ae6c8`（胸部中心 2x2px） |
| 边缘飘散 | `#1a6b5c` 半透明粒子（代码动态层） |

**状态表达**：
- 巡逻：崩坏侧缓慢脉动（alpha 0.8-1.0，2s 周期）
- 警觉：核心亮点闪烁加速
- 追击：位置每 8 帧跳动 1-2px（"渲染位置错误"）

#### 覆盖体（48x48）

**设计方向**：完全非人形。抽象几何体——多重偏移矩形叠加，像一个坏掉的 sprite 被多次错误渲染在不同位置。全体自发光 teal，中心有白热核心。

| 部位 | 色值 |
|------|------|
| 外层偏移矩形 | `#1a6b5c` @ 60% alpha |
| 中层主体 | `#1aad96` |
| 内层核心 | `#2ae6c8` 中心 + `#7fffee` 核心点 (2x2px) |
| 环境光池 | `#1aad96` @ 20% alpha，半径 3-4 tile（代码实现） |

**状态表达**：
- 匀速滑行（不步行），无帧动画——整体平移
- 外层矩形每 1s 偏移位置循环（"多次渲染"感）
- 投射面积光池随移动跟随

### B3. 净化点模块（替代几何体）

**设计方向**：工业设备感。金属框架 + 管线 + 功能指示灯。不是科幻全息台，是粗糙的、焊接起来的维生设备。

#### 屏障模块（64x64）

```
┌────────────────────────┐
│  ██  ┃┃┃┃┃┃┃┃  ██    │  ← 顶部金属支架
│  ██  ┃ 竖管线 ┃  ██    │
│  ██  ┃        ┃  ██    │  ← 中部管线区
│  ██  ┃   ●    ┃  ██    │  ← 指示灯（1px）
│  ██  ┃┃┃┃┃┃┃┃  ██    │
│ ═══════════════════════ │  ← 底座横管
└────────────────────────┘
```

| 部位 | 色值 |
|------|------|
| 金属框架 | `#4a4e55` |
| 框架暗面 | `#3a3d42` |
| 管线 | `#2c2e33` |
| 底座 | `#5a5f66`（最亮金属面） |
| 指示灯-健康 | `#44aa66` 1px |
| 指示灯-受损 | `#b89040` 1px 闪烁 |
| 指示灯-严重受损 | 熄灭（`#2a2d32`）+ 边缘 teal 渗入 `#1aad96` |

#### 储藏模块（64x64）

箱体结构：矩形金属壳 + 前面板铆钉细节 + 顶部小窗口。

| 部位 | 色值 |
|------|------|
| 壳体主色 | `#3a3d42` |
| 壳体暗面 | `#2c2e33` |
| 铆钉 | `#5a5f66` 1px 点阵（4 个角） |
| 观察窗 | `#151a1e`（深黑色） |
| 指示灯 | 同屏障模块规则 |

#### 三态表达（程序化实现）

| 状态 | 视觉变化 |
|------|----------|
| 健康 | 正常绘制 + 指示灯 `#44aa66` 常亮 |
| 受损 | 框架增加 2-3 条 1px 裂缝线（`#151a1e`）+ 指示灯 `#b89040` 每 500ms 闪烁 |
| 严重受损 | 框架裂缝加宽 + 指示灯熄灭 + 边缘出现 2-3px teal 渗入点 `#1aad96` |

### B4. 节点视觉升级

#### 薪柴（16x16）

**当前**：占位 teal 色块。
**升级方向**：不规则多面体残渣（4-6 个像素组成的非对称形状）+ 微弱 teal 余晖。

| 部位 | 色值 |
|------|------|
| 主体 | `#1a6b5c`（暗 teal 固体） |
| 高光面 | `#1aad96`（顶部 1-2px） |
| 余晖 | `#1aad96` @ 30% alpha（周围 1px 光晕，代码实现） |

**动画**：2 帧，高光面位置微移（200ms 周期，模拟微弱脉动）。

#### 撤离点（32x32）

**当前**：白色脉动。
**升级方向**：垂直裂缝形态——中心白热线 + teal 边缘辐射。

| 部位 | 色值 |
|------|------|
| 裂缝中心线 | `#b0fff5`（近白，2px 宽 x 16px 高） |
| 边缘辐射 | `#2ae6c8`（中心两侧各 2-3px 渐淡） |
| 外围微光 | `#1aad96` @ 15% alpha |

**动画**：4 帧脉动——中心线宽度 2px->3px->2px->1px，800ms 周期。靠近时周期缩短至 400ms。

#### 污染物/战利品（16x16）

**设计方向**：比薪柴更"活"的感觉——不规则球形 + 中心高亮 + 缓慢旋转感。

| 部位 | 色值 |
|------|------|
| 外壳 | `#0e4a3f` |
| 活性面 | `#1aad96`（随机 3-4px 表面高亮） |
| 核心 | `#2ae6c8` 1px 中心点 |

## 实施优先级

1. **HUD 重设计**（条形缩减、色彩修正、结算面板 DOM 化）
2. **玩家程序化绘制**（替换白色矩形）
3. **渗透体程序化绘制**（替换红色圆形）
4. **净化点模块**（替换色块）
5. **薪柴/撤离点视觉升级**
6. **面板组件统一**（scanline 纹理、按钮态）
7. **改写体/覆盖体**（Slice 2+ 敌人出现时再做）
