### A1. 可读性硬规则（优先级高于装饰，做不到位整个 Slice 不合格）

#### 技术根因：角锚必须跟画布走同一根

DOM 面板与裂隙 HUD 的字号都是 CSS px。屏幕空间 overlay 挂 `#dom-ui-root`，由 `bindDomUiRootToGame()` 按 canvas 实际显示框做 `translate + scale(canvasWidth/960)`。**1 声明 CSS px ⇔ 1 逻辑画布 px（960×640）。**

裂隙 HUD **已是 DOM**（`rift-hud.ts`）。禁止再用 Phaser `scrollFactor(0)` 画角锚——`camera.zoom ≠ 1` 会把四角甩出视口。`hud.ts` **已删除**。下列「Phaser HUD ×1.5」换算 **作废**，不得当验收基准。

主菜单仍是 Phaser Text（元界面、zoom=1）；CJK 须 `setPadding` 顶边，见 `ux-menu-text-clip-slice-55.md`。

统一最小字号（**DOM 声明值**）：

| 层级 | DOM（CSS px） | 用途 |
| ---- | ------------- | ---- |
| 标题/关键数值 | ≥ 16px | 面板标题、结算数字、临界警告 |
| 正文/数值 | ≥ 13px | 描述文字、状态数值、工具名 |
| 标签/次要 | ≥ 12px | 槽位标签、提示行、耗尽态 |

#### 最小对比度

正文文字与其背景的对比度 **≥ 4.5:1**（WCAG AA 文本标准，用相对亮度公式估算，作为内部设计基准，不
要求正式认证但计算方法一致）；纯装饰性边框/分隔线不强制，但若边框本身承载状态含义（如"已选中"边框）
建议 ≥ 3:1。

#### 关键数值的第二重编码（禁止单靠颜色）

任何"安全/危险""可用/不可用""高/低"的判断，必须至少有一种非颜色编码同时存在：形状（pip/方块计数）、
位置（刻度线）、符号（图标/字符）、离散数量（●●●○○）。混乱值条有刻度线；完整度条必须同时有标签+条+数字
（禁止只靠颜色脉动）。玩家表名是「完整度」，禁止上屏 HP / 生命值。

#### A5-13. 世界内检视信息层（新组件，替代 `title` tooltip）

**问题**：`title="..."` 是浏览器原生 tooltip——系统字体、鼠标悬停 600ms+ 延迟才出现、无法键盘触达，
直接违反 U7。

**设计**：不做浮动气泡（那是网页范式），改成**面板内固定的"详情条"**——物品格列表下方（或旁侧，
视面板布局而定）永远保留一条固定高度的详情区域，显示"当前键盘/鼠标焦点所在物品格"的完整描述。
焦点移动时详情区内容跟着切换，**没有延迟、没有弹出动画抢注意力**（内容 300ms 内切换即可，参见
§A6）。默认（无焦点）时详情区显示提示文字"移动光标查看详情"或直接留空。

```
┌──────────── 物品格网格 ──────────────┐
│ [固化★] [反刍★★] [散射★] [虹吸★★★] │  ← 当前焦点：反刍（边框高亮）
└────────────────────────────────────┘
┌──────────── 详情条（固定区域）────────┐
│ 反刍之口：持续侵蚀目标感知范围。       │  ← 键盘/鼠标焦点变化即时更新
└────────────────────────────────────┘
```

- **载体**：世界内终端子区域（跟随宿主面板，不是独立浮层）。
- **触发**：键盘方向键移动物品格焦点（已有的 Tab/方向键导航体系，若面板当前无此能力需 code agent
  补齐——这是本组件成立的前提）；鼠标悬停作为**附加**便利，不作为唯一触达方式。
- **排版**：Body 层级，`ui-text #8a8f96`，最多两行，超出截断（详情文本本身已受 `world.md`
  "tooltip/简述不超过 15 字，详细描述不超过 40 字"约束，不会超）。
- **复用声明**：新增基元，进 `panel-styles.ts` 命名为 `.inspect-dock`，供 #8-12 五个面板共用。

#### A8.1 净化点 HUD（P5）

**玩家这一屏必须回答：** 还剩多少薪柴？现在潮汐到哪一相？下次归来打谁、多重？（后一项默认不抢视线。）

**容器（必须有）：**

- 元素：`#purif-hud`，建议 class `device-plate`（与裂隙 HUD 同类语言）。**禁止** class `game-panel`。
- 锚：`top:10px; right:12px;`。`pointer-events:none`。`flex-wrap:nowrap`。
- 背景：`rgba(15, 17, 20, 0.82)`（混凝土上比裂隙随身罩 0.72 略不透明，因为净化点地面更亮）。
- 边：`1px solid #2a2d32`，**直角**，`border-radius:0`。物理原因：读数板在混凝土上的暗凹槽；不是装饰描边、不是墙机「无外框靠扫描线分开」那套。
- 内边距：`8px 12px`。
- 禁止：`box-shadow`、彩色外发光、圆角、渐变底、扫描线加厚到墙机那档（HUD 是板，不是 CRT；`.device-plate::after` 那条暗扫描可留，当作板面磨损，不要再叠 teal 扫描）。
- 已有 `text-shadow:0 0 2px rgba(0,0,0,0.8)` 保留（可读性暗晕）。

**分组（必须有）：** 容器内 **两行**，中间 1px `#2a2d32` 分隔。

```
┌─ #purif-hud 贴顶靠右 ──────────────────────────┐
│ 薪柴  12                                        │  ← 资源组（独占上行）
│────────────────────────────────────────────────│
│ 潮汐  第 1 潮  涨潮     下次归来  核心  中等    │  ← 状态组
└────────────────────────────────────────────────┘
```

- 资源组：只放薪柴。`display:flex; gap:4px; align-items:baseline;`
- 状态组：潮汐槽 + 下次归来槽（+ 可选消声槽「再下一轮」）。槽间 `gap:24px`。消声槽若出现，放在状态组**最左**，整槽 `opacity:0.85`，字一律 `#8a8f96`，无脉动（A1 V2）。
- 这不是「改成左上竖表」：仍然贴顶靠右、仍然一槽三节点。只是薪柴不再跟潮汐同一视觉权。

**字号档：**

| 节点 | 远离入口（静默） | 靠近裂隙入口（满显） |
| ---- | ---------------- | -------------------- |
| 表名「薪柴」 | 12px `#8a8f96` | 同左 |
| 薪柴整数 | **16px** `#c4873a`（本层最大） | 同左 |
| 表名「潮汐」/ 相位 | 12px `#8a8f96` | 同左 |
| 「第 N 潮」 | 13px `#1aad96` | 同左 |
| 「下次归来」整槽 | 表名/目标/档位 **全 12px `#8a8f96`**，无脉动 | 表名 12px `#8a8f96`；目标 13px 按 §A5-3 目标色；档位 12px 轻微/中等 `#8a8f96`、剧烈/极端 `#cc3333`；仅极端走 `hud-critical-pulse` |

「弱」的通道是**去掉强调色 + 降到 12px**，不是 opacity 0.4（会跌破 A1 对比度）。靠近入口 = 现有 `InteractionTarget.type === 'rift'` 的 overlap，不改交互半径。

**余光：** 薪柴靠 16px 暖色整数。本层**不画条**——薪柴无上限，潮汐是离散相，预告是档位词。审查图里的迷你条是「分组后余光可扫」的方向，不要把完整度 / 污染条搬进本层（稳定度已不在本层；模块完整度在装置脚下与打开的面板里）。

#### A8.3 面板语言（P7 视觉，不是信息架构）

机身仍 §A5-5：`680×468`，`top:52px; left:140px`，玻璃 `rgba(15,17,20,0.88)`，无金属面壳、无 1px 外框、无圆角、无 HTML 主按钮。Q2 已拍：**主-从 + 渐进披露**，不是只加框。

**竖切四带（从上到下，固定视口，空白由详情填满）：**

**单一焦点怎么画：**

#### A8.5 三问书面预答（这一版规格打算让人在 `#purif` 里看见什么）

审美 / 读作游戏 / 风格适配待人终审。下面不是结论句，是对照时看哪一帧。

**问 1 · 好不好看。** 进 `#purif`，右上应是一块暗直角读数板：上行只有薪柴 16px 暖色整数，下行潮汐与「下次归来」分开；字是灰的（`#8a8f96` / `#c8cdd4`），不是纯白字贴近黑底。底栏应是一条同样暗边的短板，不是裸字。打开存续报告，四周仍漏混凝土与装置；屏上是等宽灰字 + 克制扫描线，没有圆角卡、没有青色块填的 Tab。把这一帧跟 `ui-hud.png` / `ui-hint.png` / `ui-status.png` 并排：对齐的是「有容器、有分组、有三级字」，不对齐审查图里的底右条、圆角、完整度条。非平直表现的物理原因：板的 1px 暗边 = 混凝土上的凹槽；`text-shadow` = 抗亮地；墙机扫描线 = 磷光屏材质，不是滤镜秀。

**问 2 · 读不读作游戏 UI。** 走过去：无目标时底栏半透明一行 Tab/Esc；走进培养藏或核心，150ms 内底栏满显，第一行是 `[E]` + 动作，第二行是完整度或缺口，不必先开面板。按 Tab：顶上三模块条固定，其下是顶 Tab，一次一项，详情填满，底有键印。走近核心开分配：唯一带 1px 亮边框的是「投入」那一行；底部「出击预估」是三个分节点的已有修正，没有「生存」徽章。空库存时详情里是虚线 40 框 + 两行原因 + 键印下一步，不是一句「尚无残渣」贴在大块黑上。键鼠同一通道：选中即填检视层。

**问 3 · 跟场上已锁装置并排是否同一世界。** 打开面板时，漏景里仍是核心 v6-B、净化器 B1、储藏 C1、入口卡 5、供奉台卡 I、培养藏卡 A。这块屏应读作墙上那台磨损 CRT，而不是另一套软件盖上去：同一 Courier、同一冷灰、暖色只出现在薪柴数字、HUD 板比墙机更扁更不透明、没有跟 B1 观察窗或培养藏立缸抢饱和 teal 的 UI 描边。提示条不再画 ◈▣ 几何符，避免和已锁外形抢身份。把这块 UI 挪到另一款暗色科幻游戏里若完全成立，就是世界观没喂进去——本规格用「薪柴暖 / 结构灰 / 净化器 teal」和「板 vs 墙机」把净化点自己的设备差留下。

证据帧（落地后给人）：① 独处右上 HUD（含远离入口的弱「下次归来」）；② 走近入口后的同一 HUD；③ 无目标底栏；④ 走近培养藏的两行提示条；⑤ 存续报告顶 Tab + 漏景；⑥ 分配屏投入焦点 + 出击预估三节点；⑦ 空状态三槽。

## B. 角色美术方案

### B1. 玩家（32px 俯视角，Phaser Graphics 程序化绘制）

#### 设计方向

工业防护服轮廓 + 背包 + 肩灯暖光点。从正上方看是一个略扁的六边形躯干 + 圆形头部 + 短腿影。整体色调融入净化点环境（冷灰），只有肩灯是暖色。

#### 形状构成（32x32 画布，实际内容约 20x28）

```
        ●●           ← 头部：4x4px 圆角矩形，#3a3d42
      ●●●●●●         ← 肩部：8px 宽，#2c2e33
     ●●●●●●●●        ← 躯干：10x8px 六边形轮廓，#2c2e33
     ●●████●●        ← 背包：中间 6x4px 凸起，#2a2a2e
      ●●●●●●         ← 腰部收窄
       ●● ●●         ← 腿部阴影：2x3px x2，#151a1e
```

#### 方向辨识

- 朝向通过**头部偏移** + **肩灯位置**表达：
  - 朝下（默认）：头部居中，肩灯在左上角
  - 朝上：头部居中偏上，肩灯在左下角
  - 朝左/右：头部偏移 2px + 肩灯在对应肩部
- 肩灯：1x1px `#c4873a` 亮点（唯一暖色，方向指示器）

#### 色彩

| 部位 | 色值 |
|------|------|
| 头部/面罩 | `#3a3d42` |
| 躯干/外套 | `#2c2e33` |
| 背包 | `#2a2a2e` |
| 腿部阴影 | `#151a1e` |
| 肩灯 | `#c4873a`（1px） |
| 轮廓暗边 | `#151a1e`（底部/右侧 1px 阴影线） |

#### Phaser Graphics 实现要点

```typescript
// 伪代码 - 玩家绘制
const g = scene.add.graphics();
// 躯干
g.fillStyle(0x2c2e33);
g.fillRect(-5, -4, 10, 8);
// 头部
g.fillStyle(0x3a3d42);
g.fillRect(-2, -8, 4, 4);
// 背包凸起
g.fillStyle(0x2a2a2e);

// 肩灯（方向性）

```

#### 动画方案（代码实现）

- 待机：躯干整体每 250ms 上移 1px 再回来（呼吸感）
- 移动：腿部影像交替闪烁（左右各 2 帧），8fps
- 受伤：整体 fillStyle 切白色 (#c8cdd4) 1 帧，然后恢复

#### 渗透体（32x32）

### B4. 节点视觉升级

#### 薪柴（16x16）

**当前**：占位 teal 色块。
**升级方向**：不规则多面体残渣（4-6 个像素组成的非对称形状）+ 微弱 teal 余晖。

| 部位 | 色值 |
|------|------|
| 主体 | `#1a6b5c`（暗 teal 固体） |
| 高光面 | `#1aad96`（顶部 1-2px） |
| 余晖 | `#1aad96` @ 30% alpha（周围 1px 光晕，代码实现） |

**动画**：2 帧，高光面位置微移（200ms 周期，模拟微弱脉动）。

#### 撤离点（32x32）

**当前**：白色脉动。
**升级方向**：垂直裂缝形态——中心白热线 + teal 边缘辐射。

| 部位 | 色值 |
|------|------|
| 裂缝中心线 | `#b0fff5`（近白，2px 宽 x 16px 高） |
| 边缘辐射 | `#2ae6c8`（中心两侧各 2-3px 渐淡） |
| 外围微光 | `#1aad96` @ 15% alpha |

**动画**：4 帧脉动——中心线宽度 2px->3px->2px->1px，800ms 周期。靠近时周期缩短至 400ms。

#### 污染物/战利品（16x16）

**设计方向**：比薪柴更"活"的感觉——不规则球形 + 中心高亮 + 缓慢旋转感。

| 部位 | 色值 |
|------|------|
| 外壳 | `#0e4a3f` |
| 活性面 | `#1aad96`（随机 3-4px 表面高亮） |
| 核心 | `#2ae6c8` 1px 中心点 |
