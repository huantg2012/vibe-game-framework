# Slice 6 体验方案（请拍这一套，不要拍算法菜单）

## 「五套记忆」是什么（上次没说清）

不是新造的黑话。美术方向里早就写了：裂隙是从别的现实撕下来的一块，这块地**曾经是什么**会留下极弱的色温和材质残影。已经点名的五类是：

| 曾经是 | 你会感到 |
| ------ | -------- |
| 旧图书馆 / 木结构 | 暗、暖、旧木头 |
| 医院 / 实验室 | 冷、灰白、无菌 |
| 地铁 / 工业 | 锈、机械、衰败 |
| 居民区 / 公寓 | 暗黄、曾有人住 |
| 户外 / 土壤 / 公园 | 深橄榄、被吞没的自然 |

现在游戏里**只有最后一种**，而且每趟都是它。你要的「不同世界碎片」= 每一次踏入，这块地换一种「曾经是什么」。不是丛林/冰原/岩浆那种新题材。

**五类是词表起点，不是成品上限。** 成品要靠两件事堆出大量差异，而不是再手写 30 套互不相干的世界：

1. **扩展**：CSV 里加新的「曾经是什么」（新地点类型 + 对应色温/材质，须走美术论证，禁止代码里偷加色）。
2. **组合**：同一种「曾经是什么」再叠污染深浅、残破程度、障碍语法变体。医院×新生偏蓝 和 医院×古老偏绿 应能分清；地铁+隔断残和地铁+长柱列也应能分清。后面还可以一张图拼两种（接缝处色温跳），本 Slice 先不做。

本 Slice 先把这根管子接通，并做出三种对比最强的（户外 / 医院 / 地铁）。加第四种应是加一行数据 + 一段美术，而不是重写生成器。

---

## 建议就做这一套

**1. 陆地长什么样**  
从几个点长出来，再把细边咬掉，留下最大的一块岛。外轮廓不会是长方形。  
你点名好奇的就是这条。预览图已经跑出来了（对照图是现在这种满框矩形）。

**2. 岛上有什么**  
不让你选组合。专业侧锁死：先放下 2–3 段能叫出名字的残墙（L / 脊 / 缺一边的院子），再按「曾经是什么」换墙的形状（医院是隔断，地铁是柱列，户外是土脊）。禁止再撒胡椒粒小石子。

**3. 本 Slice 几种地方**  
先做三种、对比拉满：户外（已经有）、医院、地铁。图书馆和居民区后补。每一次踏入抽一种。一张图不混两种。

**4. 阵亡**  
失败。回净化点。不能按 R 立刻再打这一次（现在可以，等于没失败）。这一次薪柴带不回来；这次出击仍要走归来和冲击——相对现在「死了按 R 原地再来」，这就是那点惩罚。不另扣稳定度。

**5. 撤离**  
仍是一个口，走近按 E。位置由生成器给，不会还在现在那个格子。
