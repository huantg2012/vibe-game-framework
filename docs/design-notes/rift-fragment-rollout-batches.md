# 矩形碎片推广：作者批次

规则唯一正文为[地图生成规格](../specs/system-map-generation.md#rectangle-fragment-authoring)，实际资格归[推广任务](../tasks/rift-spatial-rollout.md)。本记录解释逐世界宽地、破坏与实体关系，不用内容行数代替质量。余烬脊的认可作者源和共享 `rectilinear-fragment-v1` 不在本轮修改范围内。

## 范围与批次方法

原库108世界，余烬脊已有正式代表；剩余107按主材料为层板18、纤束17、壳20、颗粒13、膜22、胶17。这里的六族用于核对材料覆盖，不能当成六个通用地图模板。construction v1/v2尚余19项，v3/v4共88项；8项v2混合材质也有已认可的主次关系，不能因版本较早便当作任意撒点。

推广分开处理两层：每个世界显式编排自己的矩形地床与缺地；已有人审的材料、原生形体、role、主次材和接合关系继续来自原库。断缘seed只变化局部边角，不代表新布局。旋转、镜像、换色、统一抖动均不算独立构型。

首批为下列5项，与余烬脊一起覆盖六种主材料。随后优先验证 `monolith-sill` 与 `woven-quarters` 的独有关系，再按材料族分解剩余条目，每作者批不超过5项，逐批留下原始剪影、实际材质全图和正常镜头证据。先导成功不会替剩余条目自动签收；后续作者批连续推进，不重复请求已获得的推广授权。

## B01：跨类型先导（有限内部完成）

### ash-strata · 无彩层原

`ash-crossfall-field-v1`：横向错落的宽床为主体，西北与西侧断层成组，中南留下可自由转向的连续宽面；东伸厚肩和南垂短床打破长方形外岸。长层片位于完整中床的不同高低带，短片靠近其断开端，避免在每个孔旁摆一堵墙。

本图沿用成群层片的repeat能力与材料比例，显式编排18件solid、3件relief。数量只是当前作者结果。主层片与中等板段承担移动绕行；西北及西侧的真VOID承担观察中断，二者分别检查。初轮旋转足迹检查发现7件靠孔或岸线过近，已移动/收小；第二轮材料比例放大暴露实体22一个角，按root裁决最后局部修正为(390,821)、180×70。没有改孔或断缘算法补救。

### pale-sail · 苍帆夹道

`pale-offset-sheet-field-v1`：西/中北的厚床占主导，东侧为较低的短厚肩，南岸大幅退开、仅西南留短垂足。双幕仍为两件独立大膜体，错位相对，允许内路换侧及外路绕行。缺失在北带、西南和幕间有不同尺度的聚集，不能把整个双幕外面包成完整矩形场。

初稿因填孔外岸仍读成厚矩形盘、内部孔过于均衡，被独立art退回。一次布局级修订撤去东北/东南的大块原地床并重排宽面；右幕随新厚肩局部调整，保留两件solid的source-once身份。旧初稿机器准入不作为新构型通过证据。

### splayed-fibres · 纤维扇流

`splayed-fan-field-v1`：西北根床收小、向内退入，主宽面落在中东与下部；东北另留较高的短厚残床，二者之间的大段北岸下退，西岸上半也大幅内撤。缺地从中东向东南展开为错开的折裂，西部仅留一组较大的断缺；穿过束间或绕过裂带后仍进入宽地，不走连续门洞。

稀疏长束的方向有主次，较大束体与较小断束分组，14件solid和3块relief为本图作者结果；不继承灰层的平行板片或余烬脊的小堆排列。材料和母形来源保持，显式作者长宽不再二次乘通用材料比例。

首稿虽通过三档有限技术检查，但实际材质全图暴露北岸长直线、西岸立边与东南小台阶仍围成矩形盘，art/root明确退回。上述一次布局级修订是大面积撤床和重心迁移；部分束体随新地床换位，孔不替旧实例让路。修订后先交纯剪影复核，再重做技术检查，原30例保持attempt1历史范围。

### shell-chain · 壳缘阶串

`shell-stepped-basin-field-v1`：宽床重心偏南，北面两块错台与西侧破带共同截断原有连续面。四个开口不同向的壳仍作为一个关系组位于中南宽地；北侧和西侧缺失形成观察断口，东侧留一块较完整厚岸。不能用环孔围起每件壳，也不能将开壳实体当成吞光空洞。

采用source-once，原1块relief+4件solid各一次。以原母版(512,384)为源、(1250,1100)为目标作1.2倍统一平面变换，保留相对位置、原方向和长宽比例。不是把先前重复的20个壳挤入变小地床；本次恢复可指认的四壳关系，是否足够阻行由真实绕行检查决定。

### gel-fibre · 凝胶裹纤维

`gel-crossed-floodplain-field-v1`：西北整角与左岸上半撤去，西侧只保留较低的短厚肩；连续主床偏到中东，东北保留高短台、南面留下偏置垂足。西侧流前沿的成组缺失与东北较安静宽面形成不对称关系。中央池面跨束和露出的两根硬束仍为场所焦点，东端缺地截断视线而不在池边造一圈沟。

采用source-once，原1块gel relief、2件fibre solid、1件gel solid各一次。以原母版(512,384)为源、(1200,900)为目标作1.3倍统一平面变换，保留两种材料、池面跨束、露出的次束及原方向。孔不切穿这组可指认的接合关系；也不为保旧位置回填地形，作者先调整整个关系组和缺失区域。

首稿因四岸仍包住满幅矩形、左上出现薄唇而在正式图审中被退回。一次宏形修订去掉整块西北地床和原侧岸，中央四实例所有作者数值保持；不是在旧矩形上加噪声或切小角。与Splayed同批先做纯剪影复核，原技术PASS不迁移到新宏形。

五图已完成两seed三档最终有效组合、三档独立完整生产/恢复、实际图与普通输入及限定运行预算检查；Pale/Splayed/Gel首稿退回与修正保留。[本批QA](../qa/rift-fragment-expansion-2026-10-12.md)列出源与边界，不代用户正式终验。现共6个正式fragment世界，尚余102。

## 后续优先关系与全库队列

- **B02 · 独有主体**：`monolith-sill`、`woven-quarters`。前者保留唯一分足巨体和单侧宽静床，远侧集中破坏，不能复制主柱；后者保留3relief+3solid、短长纤接合与四角关系，不能把六件各自随机安放。生产表仍待B01阶段结果后写入。
- **B03 · 连体/低床/混合压力样本**：`sentinel-mass`、`cleft-tableland`、`clamped-shore`、`bladder-weave`。分别保护高低连体双肩、低床真断口、壳夹凝胶、膜与锚束关系。数量/位置从各自原生CSV取，不由一个族模板替代。
- **余下96项**：在B01五个先导与B02/B03六个特殊样本（合计11个新增世界）完成后，分材料作者批继续：层板14、纤束16、壳18、颗粒13、膜19、胶16。每批最多5项，混合世界同批对照其纯材近邻；作者登记其宽地主次位置、破坏方向和实体与空地关系中至少两个非颜色差别。此计数是排产余额，不是已制作/已通过状态。

## 作者到生产的单向链

1. 在 `rift-spatial-fragment-layouts.csv` 与 `rift-spatial-fragment-rectangles.csv` 写明确尺寸和矩形来源，再在 `rift-spatial-fragment-worlds.csv` 绑定独立layout。共享编译器及cinder认可输入不变。
2. fragment策略要求 `authored-sectors`、不镜像；同步更新spatial-worlds/sectors/sector-layouts/sector-anchors。旧authored-group转移时须删除该world旧group行，避免两个作者源争夺真相。
3. source-once按role重新索引但原实例各出现一次；保留material/family/shapeProfile/role/构造与主次关系，变换后重新检查接合。repeat仅供原本可复用的成群材料，不能吞掉唯一地标。
4. 原始地床上的旋转足迹与出生留量只是作者预检，不代替断缘后8px支撑、20px身体、真实材质alpha、VOID视线和完整内容准入。code统一生成产物；审查冻结期间作者暂停共享CSV变更。

## 闸门与停止条件

机器负责：CSV完整/唯一、同seed确定性、同世界三档骨架一致、边角打磨不并孔/断路、原生身份映射完整、旧冻结局不读新CSV、最终20px身体/8px支撑、探索式唯一撤离候选和完整Host/敌人/资源配额。继承当前真实绕行、身体可达及撤离门，不能为本批降低门槛。近距VOID见证必须在当前肩灯视距内，并通过移除VOID的反事实排除纯距离遮蔽。

作者和art负责：填孔外岸不是近矩形厚盘；宽面主导而非房间走廊；集中破坏与完整区并存；加回实体后不沿每孔布墙；同族近邻不能只换颜色或旋转。孔数、顶点数、solid数量、面积占比均保留诊断，不单独签品质。全库可做归一化/D4剪影相似度检查以指出疑似复制，但不把一个相似度阈值当审美标准。

每图最多两轮作者自检修正；重复失败给root具体实例/点、输入和失败证据，由root决定作者层还是能力层问题。原始失败、图审退回和限定成功分别保留，禁止刷seed挑成功或悄悄删失败。自然未知搜撤、全库全seed稳定性以及用户正式体验终验仍须按任务实际证据标注，不由小批技术检查代替。
