# 裂隙入口卡面

身份锁见 `docs/design-notes/rift-entrance-identity.md`：**伤口渗漏，不是门。**

机制不动（规则 2 / 3 / 31 / 40）：位置中心正北 4.0 tile、走近 32 像素按 E 开出击装配、永不高亮、提示条优先级最低、是安全区钳制源之一。抽卡只抽外形。

## 结案（DEC-113，2026-09-04）

**生产默认 = 卡 4 地缝**（地面裂缝贴花）。**卡 5 击裂**留作对照（`?entrance=5` 或净化点内键 4 / 5）。

## 可分维度（杂交只许拆这些）

1. **伤口如何占住场地**
2. **「另一边」如何被读出**
3. **不稳定如何被读出**

禁止把外观 × 进度 × 动效排成碎片。每张卡都是完整组合。

载体：**A 世界内现形**（伤口在净化点北侧的现形）。不是装置外壳，不是世界内终端，不是元界面。青绿 = 另一边往这边渗的外来模式，不是装饰光。

## 已废掉的那六张（只留记录，图集与生成器已删）

| 批次 | 卡 | 为什么废 |
| ---- | -- | -------- |
| 墙上第一批 | 壁裂幕 / 错层剪 / 膜破回缩 | 人评「太像水池」「灾难」「不要真门框」。中途两次描边热修，第一次把墨黑换成深灰交差，人评**不诚实** |
| 墙上第二批 | 挤入 / 蚀腔 / 层叠 | 画法闸门全绿、外沿全是面色，人仍评「都是狗屎」 |
| 地面版落选 | 囚笼（被人造装置禁锢的竖立虫洞） | 人在三张里留下卡 4 / 卡 5 |

**六张的共同病根：载体平面选错**——把「时空的伤」画成「一段墙被弄坏」。而入口所在的位置（压在椭圆北沿）根本没有墙：净化点的边界是变暗带 → 力场膜 → 虚空。凭空造一段内壁 = 发明场景里不存在的建筑。过程教训已沉淀进 `.cursor/skills/pixel-models/SKILL.md`（因果链「本质 → 形体剪影」+ 开工闸门「声明载体平面，再声明相机」+「剪影误读清单」）与该 skill 的 `exemplars.md`。

# 地面版：卡 4 地缝（生产默认）/ 卡 5 击裂（对照）

人给的结论与方向：

> 裂隙入口应该在**地面上**而不是墙上。可以是地面上的一道中间粗两边细的裂缝，
> 或者是一些由中心点向周围辐射的裂缝（就像钢化玻璃上受击后出现的东西），
> 或者是竖立在地面上的一个被人造装置禁锢住的、在缓慢挣扎变化着的虫洞入口。
> 不需要显式的呈现【裂隙那边是什么】。

所以本批只执行这三个方向，不另发明第四种。生成器：`gen/rift_entrance_ground.py`（现只留卡 4 / 卡 5）。

## 为什么在地面上（推导，不是口味）

1. **伤在空间上，不在材料上。** `world.md`：裂隙是时空结构破损后的自然渗漏，不是被制造的通道。画成「一段墙被弄坏了」等于把它降级成建筑损坏。
2. **那个位置没有墙。** 入口在中心正北 4.0 tile，加 1.0 安全区正好压在椭圆北沿。净化点的边界不是砌体，是变暗带 → 力场膜 → 虚空。凭空造一段内壁 = 发明场景里不存在的建筑。
3. **去向不可选**，所以不画「那边是一个具体地方」。缝里 / 口里只有深与青绿的丝。人已明令不必显式呈现那边是什么。
4. **它不是第四台机器。** 净化器才是装置，它对着入口干活。入口永不高亮、提示优先级最低——它不需要被操作。

## 相机（地面平面内，显式声明，不许默默混用）

两张都在**地面平面内**（与净化点混凝土同一平面，顶视）。地面上的缝只能画在地面平面里；按向下俯视 10° 画会被压成几乎看不见——一格进深只换来 0.17 行。已锁三台装置仍是 45° 等距，本批不动它们。

**接线后果（DEC-ARCH-019）：** 两张都是地面贴花，锚点取中心（`ENTRANCE_ORIGIN_Y = 0.5`）、层压在地板之上玩家之下（`ENTRANCE_DEPTH = 1`），玩家能踩过去。交互不变：32 像素半径 → 按 E 开出击装配。

## 两张共用的画法

落地底 = 净化点混凝土（主色 `concrete-mid #3a3d42` 明度 60.7、暗部 `concrete-dark #2c2e33` 明度 46.0）。所以：

| 角色 | 色板名 | hex | 明度 |
| -- | -- | -- | -- |
| 缝最深 | void-black | `#080a0c` | 9.6 |
| 缝中段 | ambient-black | `#0d1114` | 16.1 |
| 缝口 | shadow-grey | `#151a1e` | 25.0 |
| 新断口 | metal-grey | `#4a4e55` | 77.6 |
| 断口受光棱 | metal-light | `#5a5f66` | 94.3 |
| 崩渣 | concrete-mid / concrete-dark / debris-earth / bone-grey | — | — |
| 缝里那点亮 | contam-deep → contam-glow | `#0e4a3f` … `#2ae6c8` | — |

**缝要有三档深度。** 一档就读成一条涂上去的线。**断口亮棱要断续。** 两侧铺满就成了勾边（DEC-110：断口新鲜面比风化践踏的地面新、亮）。

**青绿只许在缝里 / 口里**，一贴到背景就读成涂上去的荧光线。面积压在 22% 以下——它是渗，不是霓虹。

## 卡 4 地缝

| 项 | 取值 |
| -- | ---- |
| 一句话读法 | 地面上一道中间粗两边细的裂缝，缝深处一条丝在慢慢走 |
| 载体 | A 世界内现形（地面贴花） |
| 伤口如何占住场地 | 横贯的一道缝，中段半宽到 3.2 像素、两端收到 0。上缘比下缘收一点，另有四条支缝岔出去——上下对称的纺锤会读成一只眼 |
| 「另一边」如何被读出 | 不显式呈现。只有缝深处那条丝说明「下面不是土」 |
| 不稳定如何被读出 | 丝上几格在走。缝、断口、崩渣逐帧钉死 |

## 卡 5 击裂（对照）

| 项 | 取值 |
| -- | ---- |
| 一句话读法 | 地面被从一点击穿，裂缝像钢化玻璃那样辐射出去，青绿从受击点往外淡 |
| 载体 | A 世界内现形（地面贴花） |
| 伤口如何占住场地 | 九条不等角、不等长的放射缝 + 五条分叉 + 一条环向短弧。全部 1 像素宽。受击点只有两三格被压碎——团一大就成墨点 |
| 「另一边」如何被读出 | 不显式呈现。缝越靠受击点越深，说明是从那一点被穿透的 |
| 不稳定如何被读出 | 青绿的可达半径随帧呼吸（5.0 ± 2.2 像素），靠中心亮、往外淡。缝本身逐帧钉死 |

## 机器闸门（生成器内置，退出码非 0 即不合格）

按对象类别分两套，因为判据不通用。

**三张共用：**

| 闸门 | 判据 |
| ---- | ---- |
| 色全在锁定色板 | 每个不透明 RGB 都能在 `palette.json` 找到 |
| 变化只在声明的活层里 | 逐帧差集必须落在该卡声明的活层区域内（两张都是缝里的格） |
| 单一主体色 < 45% | 防一块平色 |
| 材质层 ≥ 3 档各 ≥ 8% | 防只有一档 |
| 对混凝土有黑有亮 | 最暗 ≤ 20、最亮 ≥ 70、暗色 ≥ 15%、亮色 ≥ 5%。落地底明度 46–61，两头都要够 |
| 青绿只在缝里 / 口里 | 青绿不得有透明的四邻 |
| 青绿不压全身 < 22% | 渗，不是霓虹 |

**地面贴花（卡 4 / 5）：**

| 闸门 | 判据 |
| ---- | ---- |
| 躺在地面平面里 | 包围盒宽 ≥ 高。防画成立着的东西 |
| 亮断口断续、不勾边 < 70% | 亮断口像素 / 缝像素 < 70% |
| 缝有三档深度 | `#151a1e` / `#0d1114` / `#080a0c` 三档都在 |

**为什么闸门要按对象类别分套：** 「主导外沿是面色 / 体内中位数」那套是给整块实体写的。曾出过的卡 6 是骨架式对象——三根 3 像素宽的桩，要做出圆度就必然有一列背光，那是形体明暗、不是勾边，会被那套判据误报到 45%。当时改查更硬的一条「禁锢件上不许出现近黑」。方法论已沉淀进 `.cursor/skills/pixel-models/SKILL.md`。

## 对比课

`gym.html?lesson=rift-entrance-card`。两卡并排：卡 4 地缝（生产默认）/ 卡 5 击裂（对照）。键 4 / 5 高亮。

底是出击同一份净化点混凝土（`createPurificationFloorTexture`，与卡面同样放大 4×）。纯黑会把任何不透明外沿都看成描边。

净化点实地：`#purif` 默认就是卡 4；`?entrance=5` 或场景内键 4 / 5 切对照。练习场与实地换卡都不改生产默认。
