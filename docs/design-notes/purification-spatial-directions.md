# 净化点整体空间重构：三个方向

> **TL;DR**：以残墙院落、连续错层地形、剖开巨械三种不同骨架重构净化点。每个方向同时定义真实阻挡、短通路、六功能载体和内外边界；目前是设计选项，不是已实现或已验收的关卡。

阅读入口：[三方向空间图与比较](../reading/purification-spatial-directions.html)。图是拓扑与体量示意，不代表最终像素美术、生产碰撞或已测得的行走时长。

## 1. 这次要改变什么

- 用户反馈：当前外边界像包着膜的蛋；装置之间虽然画了连接，角色仍在一整块互通平面上行动。
- 原因：绘制的联系没有成为空间结构。表面管线、补板和磨损不能代替真实墙体、落差或机体。
- 本轮重构范围包括地形、通路、阻挡、六装置形体及安装关系；旧六锚点坐标和旧模型形体可以改变。
- 保留的是已成立的游戏功能和短循环，不是旧椭圆底盘、放射摆放或闭合发光边框。
- 历史依据：[原场景审查](../reviews/purification-growth-review-2026-09-20.md)、[成长样板复评](../reviews/growth-sample-review-2026-09-21.md)。旧审查不是对新方案的验收。

## 2. 三个方向共享的约束

### 世界与机制

- 净化点是仍未被完全改写的小区域；它不扩大，不把本次重构解释为修复外部世界。
- 内侧可辨、外侧失序的边界必须清楚；`world.md` 不要求用完整膜壳表现边界。
- 保留核心、储藏、净化器、蜕变、供奉、裂隙六功能；不增加货币、成长项目、强制操作或基地危险。
- 净化器仍按已有规则影响踏入状态；玩家不必先走进净化器、按键净化才能出击。
- 保留原玩家、俯视 2D、既有基本移动和交互机制。空间高差不引入跳跃、攀爬、掉落或平台动作。
- 受损、修复、供奉和永久成长仍读取原系统事实；场景不能用摆件暗示不存在的新功能或库存数量。

### 尺度、镜头与信息

- 旧逻辑空间为 14×12 格、每格 32 px，移动速度 80 px/s；这些仅作旧基线，不是新方案尺寸合同或路线实测。
- 六操作区各有明确进入面与站立空间；镜头聚焦时，角色、装置关键结构和现有读数都必须可读。
- 走道宽度、门洞和坡道按角色碰撞体测量，不能只用精灵外观估算；不会以改变移速掩盖冗长路线。
- 三卡均需允许“归来后直接再次出击”；需要维修、供奉或蜕变才走向对应区域，不设固定参观顺序。
- 既有通过的蜕变信息层级继续复用。本轮设计世界内载体与操作空间，不另起一套菜单样式。

## 3. A｜残墙工作院

**一句话读法：一个被持续修补、仍有人使用的工作场所。**

### 空间骨架与主要体验

两间错位的残存工作间、一个开放维修院和一处出击外缘，组成不完整的建筑片段。L 形承重墙是真实体积，工作间的两处开口提供短环路。玩家记住“墙后那间”和“穿过侧口”，而不只是左边升级、右边储藏。

载体为残存建筑与后来装上的设备；不是完整房屋，也不是六个独立亭子。缺失的大块墙面让污染压力仍可进入视线，院内留出安静的空白。

### 六功能邻接与模型体系

- **核心**：安装于两段承重残墙交汇的维修端；支架接入墙脚与地基，重要性由结构关系而非中心大光圈表达。
- **储藏**：沿维修院低墙设置低而厚的收存槽，开口朝院内；前壁、容积和清理过的站立面先于小零件细节。
- **蜕变**：内工作间的改造腔，身体进入位置、支承与约束件可读；保留原玩家，不靠换角色模型表达成长。
- **供奉**：相邻但分隔的封存凹室，夹持与隔离结构包住未知物；形态不提前泄露供奉后身份。
- **净化器**：出击侧维修口的剥离装置，结构朝向裂隙一侧；与通路相邻但不构成强制通行闸机。
- **裂隙**：外缘地坪和残墙错开的地面伤口，附近地面跟着错位；不画成有门框的传送门。

共用墙脚、固定件与维护磨损，装置剪影仍有差异。每件设备同时设计接地、操作面和维护余量，避免六件展品落在同一张地毯上。

### 真实移动与阻挡

- 归来落点靠院口；可以沿外侧短路去裂隙，也可以进入院内维护。
- 工作间近口接维修院，侧口接出击侧；两口之间的实墙阻止任意斜穿，形成可见也可走的短回路。
- 维修院保留一块可自由走动的开敞面，但开敞面不会连接所有操作点的直线。
- 墙体底部占地、门洞和设备主体进入同一碰撞图；线缆与薄地板盖不承担假阻挡。

### 边界、镜头与 2D 遮挡

- 外边界由残墙、断坪与向外失去原有结构的地表组成，取消连续闭合膜轮廓。
- 不画完整屋顶；靠镜头的高墙采用固定剖断/低墙构图，不把路线藏在一整面前墙后。
- 高设备按脚点排序，操作面朝向可读方向；不以新屋顶淡出系统作为本方向成立的前提。
- 普通镜头能看清院口和出击侧；交互镜头不能被隔壁墙体或未操作设备塞满。

### 参考、成本与风险

- 参考研究目标：[Darkwood 官方 press kit](https://www.darkwoodgame.com/presskit/)中的俯视生存场所资料，用于研究居留空间与行动边界；不移植昼夜守屋、封门或敌袭流程。
- 参考研究目标：[SIGNALIS 官方资料](https://rose-engine.org/signalis/)中的设施与物件资料，用于研究设备如何属于房间；不移植钥匙门链、解谜节奏或其角色设定。
- 成本：**中**。墙角、破口、地脚可模块化；需重做碰撞、装置安装关系与交互镜头检查。
- 风险：整齐四方房间会变通用地堡；墙太多则变成办事走廊。残缺外壳与两条短路必须同时成立。

## 4. B｜错层断崖站

**一句话读法：设备安置在一段尚未被改写的厚重地层上，场所真正有上下与内外。**

### 空间骨架与主要体验

一块连续地层分成**上下两级**，中段厚断面横切空间，左右各有一条宽坡道。上层承载较安静的维护/改造空间，下层保留归来与出击的直接联系。不是多个浮岛搭桥，也不是完整平面上画几条等高线。

载体是地形与嵌入式设施。玩家从下层看到被支撑的上层，绕过断面走坡道；高差的存在改变路线，但不要求新增垂直运动能力。

### 六功能邻接与模型体系

- **核心**：嵌入上层内侧厚地层，承力支脚跨接基坑与岩/混凝土断层，形成稳定视觉支点。
- **储藏**：下层归来面附近的半沉槽，使用低前壁与厚边缘表达容积，方便短停后继续行动。
- **蜕变**：上层内凹操作区的半沉式改造腔，保留看得见的进入面，腔体与地层共同构成体积。
- **供奉**：上层另一侧的封存凹口，以夹具和隔离口区别于蜕变；操作空间不与坡道混用。
- **净化器**：下层外缘的剥离机构，与出击面相邻，玩家无需为了再次出击先走上层。
- **裂隙**：下层外缘的一处断层伤口，裂口与地层方向有关，但不把所有地层裂纹都误读成出口。

模型不是在台阶上重新摆一排旧物件：沉槽、支撑、露出的管段和压住断面的构件共同表达设备如何占据地形。

### 真实移动与阻挡

- 下层归来点至出击点有直接短路；维护、蜕变与供奉通过两侧坡道到达。
- 断面为不可横穿体积；只有两条清晰坡道连通上下层。两条坡道及上下层走带构成回路。
- 坡道宽度允许稳定行走和转向，不能成为需要精确对准的小桥；操作点不占坡道口。
- 两层在俯视平面上分区，不做上下重叠通道、桥下穿行或梯子；坡面使用既有移动规则。

### 边界、镜头与 2D 遮挡

- 内侧用厚地层与支撑表达仍然成立的物质；外侧断面逐渐被改写结构吞没，无连续发光包边。
- 上层地面、断面和下层地面在画面中都占实际空间；可走掩码与断面轮廓共同设计。
- 上层后置、下层前置；避免用一块高前景断面盖住下层玩家。装置按脚点排序，坡面不能遮掉脚部。
- 不靠缩小角色获得壮阔感；层次主要来自厚度、遮挡、明暗面和清晰的坡道接口。

### 参考、成本与风险

- 参考研究目标：[Hyper Light Drifter 官方资料](https://www.heartmachine.com/hyper-light-drifter)中的像素场景资料，用于研究可读地形层次、路径与大体量背景；不移植冲刺门槛或其完整色彩方案。
- 参考研究目标：[Rain World 官方资料](https://www.rainworldgame.com/)中的工业遗存与环境关系，用于研究结构尺度和残存功能；不移植横版平台移动、攀爬或生态系统。
- 成本：**中高**。断面、坡道和设备嵌地需要共同制作，碰撞与绘制排序比 A 更敏感。
- 风险：高差变装饰、角色横穿断面，或上层过远导致维护像爬山。先做走图与断面灰盒，再讨论细材质。

## 5. C｜剖开的巨械

**一句话读法：玩家住在一个庞大残存结构的内部，用其中尚能工作的部分维持生存。**

### 空间骨架与主要体验

一条斜向延伸、局部剖开的机体占据中央，两侧形成维修带。前端、中部破口、后端三处横通连接两侧，构成两个紧凑回路。大结构延伸出局部画面，六装置是它内部的独立功能部件与后来加装物。

载体为残存巨构及持续维护的附属设备；不为它新增确定的灾前用途或解释净化点起源。玩家记住“内侧改造腔”和“从破口穿到外侧”，空间身份来自主体积与内部关系。

### 六功能邻接与模型体系

- **核心**：中央可见腔体内仍运转的独立组件，由肋架支撑；不能把整台巨械混称为核心或暗示它有新机制。
- **储藏**：归来端的装卸槽，槽口朝向内侧维修带；容积和开口清楚，避免用散落物数量表示并不存在的库存。
- **蜕变**：内侧展开的改造腔，身体支承与进入位置面向通路；机壳提供空间尺度，装置自身保持可识别。
- **供奉**：外侧后来加装的封存夹架，封存方向与主体结构有关，但有独立操作面及未知物遮护。
- **净化器**：靠出击端加装的剥离机构，不封住整条通路，也不变成必须操作的检查站。
- **裂隙**：机体与地层共同错位处的伤口；断裂结构围绕裂口让开，而非整齐地给它造一扇门。

机壳、肋架、检修盖提供共同语法，各装置通过不同占位与开口区分。不能把六功能降成巨械上的六盏灯或六个按钮。

### 真实移动与阻挡

- 中央机体不可穿越；左右维修带保持连续，只有三处真实开口能够换侧。
- 归来至出击保留一侧的短路线；进入另一侧维护时可从中部破口穿过，无需绕完整台机器。
- 中部横通位于破损敞开段，不要求玩家从未画出的桥洞、机壳下层或暗道中穿行。
- 设备操作面退出主走带，避免玩家沿维修带移动时连续吸附多个交互对象。

### 边界、镜头与 2D 遮挡

- 安全区域表现为仍被维护的一小段结构；外围由机壳残影、地坪缺失与改写吞没衔接，不画完整岛形轮廓。
- 对靠镜头一侧的壳体预先剖开，使内部路径常态可读；关键操作面不依赖临时透明才能发现。
- 大机体分前后遮挡片并按实际脚点关系排序；三处横通保持敞开，不引入多楼层穿越。
- 普通镜头首先读到两侧维修带和中部开口；聚焦镜头再读装置，不靠扩大亮度把它从暗块里抢出来。

### 参考、成本与风险

- 参考研究目标：[Rain World 官方资料](https://www.rainworldgame.com/)中的工业遗存尺度，用于研究个体如何存在于远大于自身的残存结构中；不移植其横版拓扑和平台挑战。
- 参考研究目标：[SIGNALIS 官方资料](https://rose-engine.org/signalis/)中的设施与机械物件资料，用于研究安装、开口及操作面的关系；不移植世界设定、解谜或复古屏幕界面。
- 成本：**高前期、可模块化复用**。主机体是关键资产；肋架、壳板、接口可复用，但不能靠放大旧精灵解决。
- 风险：巨械抢走六功能的识别，或成为画面中央一大坨暗色。主通路、操作面与中部空洞须先以大形建立可读性。

## 6. 灰盒验证与淘汰条件

1. 关闭纹理，仅保留可走地面、实体阻挡和六操作区，仍能分辨 A 的院落、B 的两级地层、C 的两侧维修带。
2. 每卡至少一组高频功能之间有两条真实可走路线；墙、断面、机体不能被任意斜穿，图上开口也不能是假的。
3. 分别记录当前与候选的“归来→核心→出击 / 归来→蜕变→出击 / 归来→供奉→出击”路线与原速时长。
4. **相对当前不增长超过约 20%**仅是首轮灰盒的待验证预算；尚未测量，不宣称任何卡已达标，必要时缩短空间与移动锚点。
5. 归来直接再出击不经过强制操作；转角不夹脚，装置操作区不相互争抢，交互镜头不遮住玩家或关键读数。
6. 六模型分别核查：功能形体、安装/承重、操作面、常态与受损的可辨差异；原速感受和审美仍由用户终审。
7. 回归反例：椭圆底盘加几处小障碍、装饰坡道、六点等距围中心、单线串联办事流程，均不能算完成本轮目标。

## 7. 可组合范围与下一步

- **已锁定**：问题是整体空间；允许重做地形与模型，保留原角色、2D、六功能及既有机制。
- **待用户判断**：更希望归来处是一处被维护的院落、一段厚重错层地形，还是巨构内部的生存空间；本轮不代选。
- 可借用材料、修补语言、装置局部开口做法；不可将三个主地形、通路与阻挡骨架直接拼在一起。
- 选定骨架后，先以原角色与原速制作真实碰撞灰盒；通过短循环验证，再做场景与装置共用的美术样板。
- 文中的布局、参考研究目标和成本均为设计判断；没有新增运行证据，不替代旧系统 spec 或生产场景。
