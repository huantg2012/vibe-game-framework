# 从生成之初组织空洞、实体与开放地面

**结论：将“完整旧地图 → 查缺 → 增补”替换为“世界身份与空间目标 → 联合生成地面、内孔和实体 → 完整内容部署 → 整图准入”。** 空洞与实体不是完成地图后的补丁。每份候选从开始就承担足够结构、约二比一的内孔与实体、没有巨大空白、可作多方向绕行四项责任；任何一项失败都不能靠另一项高分抵扣。

这是针对 r11 的知情设计审查和后继方案，不是盲测或已经证明的最优密度。2026-10-14 用户已批准实施（DEC-209）；下文数值继续作为需实测的初始合同，不能由批准推定通过。实施与校准结果见[本轮 QA](../qa/native-spatial-2026-10-14.md)。生产规则仍以[地图生成 spec](../specs/system-map-generation.md)为准；r11 的有限证据仍保持原范围。

## 1. 已锁定的体验与本轮边界

现有五图已经说明“比例合格”和“空间合格”是两件事。协调者读取本轮保留缓存的[五图统计](../reviews/artifacts/native-generation-2026-10-13/baseline-counts.json)：split-rib-causeway / gel-rafts / sloughed-court / ash-strata / black-lacuna 的独立内孔分别为4 / 4 / 5 / 8 / 4，solid实例分别为7 / 9 / 7 / 18 / 2，最终WALL四连通团为6 / 9 / 7 / 14 / 2。最后一图已经是4孔/2实体却仍有空白；灰层有18个实例，直接补到36孔显然不是合理答案。实例、WALL连通团与下文最终可辨空间组不是同一口径，当前有效认知组尚未标注，不能直接拿这列数签署新比例通过。

这五图最终身体站位面积约为157.6 / 124.1 / 131.0 / 132.5 / 163.1万px²，世界规模接近而结构数量相差很大。下一版应重新求整体数量、尺寸与位置，而非保留过多实体再用更多孔追比例。上述为当前实现的静态数据，不是玩家体验测量。

用户已确定：从基础生成得到合适数量；玩家遇到的空间空洞约为可视实体两倍；不得出现巨大空白；仍是漂泊的开放世界碎片，保持矩形拼合、自由断缘，不能退回地下城、地洞、窄走廊串房间或整张矩形底板。寻找未知唯一撤离仍是核心挑战，不能预设出生与撤离两端。

世界观给出的空间依据是被覆盖、撕裂、拼合的物质残留，而非为玩家修造的路线。因此用厚地块之间的偏置搭接、缺失和同族残块组织空间；路线从这份空间涌现。地形不围着一条已知出生→出口的线铺设，普通实体不为提供掩护而偷偷改成挡视线。

保留当前机制：20×20 px 身体、8 px 支撑、普通 solid 阻行及近战但不挡 LOS；真实 VOID 阻行、阻视、不能被照亮。可走 relief、裂纹、阴影、翻找残骸、敌人均不能拿来凑地形障碍数量。老在途配方按原算法恢复。新生成器需要新部署修订与冻结输入，不在 r11 名下替换逻辑。

## 2. 从潜行行为推导尺度，不把密度当潜行成立

行动链是：**发现局部形体和威胁 → 选择观察位置 → 等待/绕行/穿过暴露地 → 在下一处取得新信息 → 决定继续搜取或撤退**。空洞提供隔岸未知和断视换位；实体提供路径拐折、接近方式和场所记忆。因两者功能不同，二比一不是可互换的总障碍配额。

当前常态步速为 80 px/s，前向视距 224 px，周身 80 px。敌人核心视距通常 180 px，窄视词素可达 207 px；玩家先见优势只有约 0.55 / 0.21 秒行程。视觉察觉可能在不足一秒内完成。因此下文“结构之间 2–4 秒的移动”**只说明空间节奏，绝不叫安全穿越窗口**。VOID 也不静音，听觉墙系数为 0.6。

用常态 80/224 建立地图尺度；恶化态作为失败压力复核。不能按最高混乱前向约 89.6 px 和最低速度 33.6 px/s 将全图塞满，以抵消本来存在的出行代价。常态数据来源为 `src/config/constants.ts`、`data/enemies.csv` 及移动/混乱/AI spec，由协调者同时核对当前实现。

初始尺度假设如下，**均为首轮待校准参数，不是理论最优或当前已实现值**：

- 结构中心典型间距 `s = 320 px`；首轮比较 288 / 320 / 352 三档。中心距不是通道宽，实际形体会占去一部分间距。
- 主体之间常见开放过渡约 120–240 px，即常态 1.5–3 秒纯步行；局部可长可短，由后述最大空白门限制极端值。
- 有效内孔通常跨 112–240 px，厚处至少 64 px；可见从属实体通常跨 80–200 px。独有大型母体不压成这个尺寸，也不复制成若干小版。
- 地形换位、等待与敌人绕行时间必须分别记录。不能由上述尺寸直接推出成功潜行率、免伤率或脱追时间。

研究只支持方法，没有为本项目给出密度定额：[Xu 等的潜行关卡生成研究](https://www.sable.mcgill.ca/~clump/papers/xu-14-procedural.pdf)和[相关 AIIDE 研究](https://ojs.aaai.org/index.php/AIIDE/article/view/12591)支持将几何、敌人运动和视野共同评价；前者的有限原型并不等于本作真人验证。[Tremblay 等的风险测量研究](https://www.sable.mcgill.ca/~clump/papers/tremblay-14-measuring.pdf)在有限人类相对风险判断中发现，沿可走路线到敌人的距离有价值，不能只看简单 LOS；不是“某距离普遍安全”的定理。[PCG 评价综述](https://arxiv.org/abs/2404.18657)亦不能提供普适的最佳密度。这些来源由本轮协调者核读；本稿据此限定推论，不借论文给自行设定的数值背书。

## 3. 先统一“一个”的口径

**内孔 `H`：** 最终真实支撑中的独立、闭合、可从出生主连通域接近的 VOID 连通分量。矩形数量、轮廓角数量和分支数不参与计数。三矩形拼成的一个叉形孔仍是一个；两个孔在断缘后相连即为一个；仅由一条不可容完整身体的细地条分开的孔，在统计上合为一个空间组，避免伪造多次绕行。

进入主比例的孔还须有效：至少含一个可容半径32px圆的真实VOID厚核，且存在真实的局部断视/换位见证——双方在同一身体可达域，距离位于常态参考视距内，VOID 确实阻断视线，绕端换位后方可看见。若孔太小或藏在不可达残地中，不计有效内孔；它仍消耗真实地面和几何预算，不能免费保留一圈装饰孔。大孔及其多个支叉只有一个身份，可以服务多处观察点，但不能反复刷数量。

**实体 `S`：** 有真实 solid 足迹、可接近、可辨为一组的独立物质结构。一个连体肋架、四足母体、同一破壳的多个 mesh 只算一个组；一个 unique-source 的美术组不因导出实例拆分就变成多件。物理相连或仅留不可容身体间隙的同源部件合组。只有彼此可独立绕行、独立落地且并非一个组合物的从属残块，才分别计数。候选编号及 CSV 行数不能充当结果计数。

有效实体初值为真实足迹面积至少 `4×身体宽² = 1600 px²`、最长跨度至少 `4×身体宽 = 80 px`，并能提供完整身体绕行而非只有贴花；尺寸阈值需要用六材料族校准。计数组先消费冻结的作者 assembly 身份：同一具名四足母体即使地面足迹分离，仍是一组，不能因物理未连而报错。不同 assembly 的真实阻挡相连或仅留不可容身体的缝时，必须合并为一个机械空间组，不能拆计。由此产生作者身份与机械组的对应表，并报告组内足迹分量数、最大跨度和分量间身体可达距离。只有已定义的母体构造能声明多足/多片同组；不允许求解器临时把遍布全图的独立物件赋同一assembly，或为比例拆开母体。超出作者构造允许跨度/相接关系的，按该构造非法拒绝。现有108世界需完成这一语义标注，不能根据当前实例数自动宣称计数完成。

**岸湾 `B`：** 与外海连通的凹入 VOID。它可以制造真实断视和绕行，但单列，不进入 `H:S` 主比例；整片外海也不是“一个巨大空洞”。这样二比一主要体现在玩家深入世界时不断遇到的内孔，不能靠外围多挖几口完成数量。主体内的材质凹孔若有真实底面、仍是 solid，并非 VOID。

## 4. 数量从可用面积与尺度推导，面积占比作诊断

每个世界先从其内容身份给出目标**可行走面积** `A_target`、范围和一份唯一母体身份组；不把旧图的固定 `voidRects + placements` 作为已经完成的基础结果。目标面积是新版作者数据中的标量要求，不是每次先生成旧地图再量它。现有作者资料可用一次离线迁移提取尺寸参照；这不保留旧孔/旧从属物的坐标或数量。

给定间距 `s`，初估总有效结构数：

```text
N0 = round(A_target / (0.866 × s²))
S0 = nearest feasible integer to N0 / 3
H0 = N0 − S0
```

`0.866×s²` 是等间距二维点分布的面积估计，只用于推导初始容量，**不铺六角格、不规定每块地必须有三件套**。边界损耗、混合尺寸和异形母体会让估计偏离，最终以全域硬门为准。在 `N0` 的约 ±20% 有限整数范围中求可行数对，优先最接近二比一且总物件较少的解；每次枚举的是整份分布，不能从已完成地图递增加物件直到凑数。若需要超出此域，说明间距/尺寸/面积合同不相容，应作为失败样本反馈，不能运行时无上限扩数。

最终全图接受 `|H − 2S| ≤ max(1, 0.2S)`，同时要求 `S≥1` 且 `H>S`；小计数受整数误差影响，直接报告 H/S，不假装精确二比一，也不因舍入接受1孔/1实体。例如目标可行走面积为 1,000,000 px²、s=320 时，初估 N≈11，可先求 7 孔/4 实体或 8 孔/4 实体；这只是公式示例，并非给每个世界固定 8/4。实际 unique 母体已经计入 S，不能再另加一整份实体配额。

联合求解必须同时满足 `A_walk` 在目标面积的初始 ±10% 窗内。不能通过挖掉大半地面使分母变小、数量变少、空白指标变好。外框尺寸和现有光栅预算保持；若既定物件尺度、通路和可行走面积装不下，整个合同不准入，不悄悄缩地图。

空洞面积、实体真实足迹面积、剩余地面面积分别报告；二比一**是遭遇对象数量的方向，不是挖走地面两倍于实体占地**。不再继承 r11“新增面积各 ≤8%”的后补预算，因为这里没有应该被保留的旧成品；也不盲定全库某个面积百分比。前期校准用分布发现极端个体和过密反例，若需面积上限再据此入表。

## 5. 候选准入与代表验证分别承担责任

G1–G4是提议的逐候选自动门（其中明确标为摘要/校准目标者不冒充硬门）；既有完整内容准入继续适用于每份结果。G5的动态部分是代表阶段发布验证，当前尚未确定全种子的自动判定器，不能由本稿声称每张图都已有安全潜行解。

### G1：全图没有巨大无结构空白

在最终8px支撑及真实solid足迹上，对原有全部合法身体中心分开求两种距离：`d_internal`为到最近合格H/S边界的距离；`r_open=min(实际solid投影距离,全部实际VOID边界距离)`为实际地面内不含阻行实体的空圆半径。全部VOID包括内部H、B、外海及frame外侧；浅浮雕、贴花和敌人不参与。外岸/B只限制物理空圆，不计H/S、不提供q，也不替代持续无结构区检测。

初值同时要求：

- `max(r_open+4√2)≤160px`：不能存在超过原阈值的实际可走敞空圆；保留原8px单元保守上界，不另做一次20px身体侵蚀或加新margin。旧`max(d_internal+4√2)`及最坏点、边界来源继续作为内部结构覆盖诊断报告，不再将它误称为完整落在地面内的空圆。160px不是安全掩护距离。
- 对 `d_internal+4√2>112px` 的深空白区，以原完整身体能在该区内部移动的关系分组，单组最长轴向跨度仍不得超过448px。只有几像素的细缝不将两块空白误连为一块。该门仍检测细长无结构带，不因贴外岸/B而取得低距离；原深区侵蚀、连接、bbox与均值内部距离口径不改，不把两次BFS近似直径当严格上界。

两个门都对**最坏区域**成立，不能拿均值/P90或全图多数合格抵扣一处失败；不能仅每32px抽一点便宣称连续地面无漏检。G2、G3、G4、计数、配额、面积域和预算不随本次max换源改变。

**2026-10-14 Root决定及证据边界。** Root基于上述物理空圆定义及[实际三图同源双测](../qa/artifacts/native-spatial-2026-10-14/open-radius-calibration-round1/summary.md)批准max-only接线：c25仍161.429px失败，c27保持158.334px，原坏c3仍由max/deep/G3拒绝；实际三图全部非max指标同值。四个合成夹具合同并未全过：短岸角和有结构长带的104×16名义S正式有效面积不足，失去有效结构资格，两项正控证明未完成，失败保留且不再调夹具。该决定不冒称全部校准通过、正式生成通过或用户体验终验；代码接线与完整生成另记。规划max使用固定实际外海/B与可移动H/S，deep/均值仍只消费内部距离，不能仅改最终门而继续按旧internal max排站位。

### G2：空洞确实提供信息分隔，且没有整片缺席

为每个有效内孔登记实际遮视站位：遮断点 q、换位后的观察点 v、威胁参照点 t。三点都在主体可达域；q→t 被该孔阻断、v→t LOS畅通且在224px内；q→v有完整身体路径，初值80–240px。归因必须做单孔对照：仅在对照LOS掩码中移除该内孔的遮挡，保持其余几何和q/t不变，q→t须恢复可见，否则不得把该断视见证归于此孔；身体及路径始终使用未消融原图，不能走过临时“填回”的孔。t是方向参照，不假扮实际敌人；不能由邻近VOID边缘直接推断安全。

初始分布门：在冻结的32px站位采样域中，以固定方向/候选次序枚举并保留**所有通过见证的遮断点q**，而非每孔任取一个。只将q作为覆盖站位集合，已显露的v和威胁参照t不进入集合；同一大孔的不同有效侧可贡献多个q，但H仍只计一孔。全部合法身体中心至此q集合的真实最短行走距离不超过320px，不穿孔量直距。采样没有找到q不能直接解释为实际无掩护，要保留采样分辨率及失败原因供反例核对。此门只证明“附近可找到一个能隔断特定方向的观察关系”，不保证能在当前敌人发现前赶到、能遮住任意方向或避开听觉。反过来，普通实体再多也不能抵扣此门。

### G3：仍是宽面上的绕行，不是窄道迷宫

以真实两类障碍共同计算净空。20px身体可站且可连续扫掠为基本门；再在最终几何上建立中心距阻行边界至少48px的宽地核，**不与旧图比较保留百分比**。初值：宽地核覆盖至少55%的合法身体中心，且其最大连通分量至少覆盖全部宽地核的80%。这只是宽面积筛查：112px走廊仍有宽核，不能因此声称排除了大厅串廊。

路线另测**实际横向开口**，不再仅凭中心距48px判断窄段。使用G4固定且经身体平滑的路径，每8px取点，用前后32px路径确定局部运动轴，沿其法向两侧查到第一处真实VOID/solid边界（每侧最多224px），两侧实际距离之和为该位置的横向开口；非末端单侧超出量测范围时只记有界下限，不伪造闭合截面。折返点/尖角邻域标记不确定，不能当作宽段重置持续长度，须以连续身体轨迹复核。

横向开口小于160px仍记窄段。单段不得超过224px；窄段行程占比20%改为诊断，保留全部路线原值。局部短收口与搜取凹位允许，长期走廊及全域宽地不足仍由持续长度与G3拒绝。构型是否像地下城仍需剪影/正常视口检查，不能由自动门代签。

这里的48px是中心净空，不能直接宣称任何弯折穿口都恰好96px宽。距离场筛查后仍消费真实20px身体扫掠。原生土地只有一个外轮廓、矩形错搭和自由断缘的机制保持；以上机械门仍不能替代全图剪影及正常视口审美。

### G4：二比一在玩家路线中也能遇到

全图计数之外，固定生成后审查路径族：出生→撤离；出生→每个真实翻找站位→撤离（所有节点，而非只挑好看的几处）；以及到各主要可达地段的探索路径。探索目标由最终身体域包围范围的4×3等分评测区域产生，每个非空区选离区内身体中心质心最近的合法点（平局按y、x），不选“孔最多”点。这份区域网格仅用于覆盖评价，不用于摆地形，也不能反推房间网格。

所有路径使用完整身体图，固定8邻居次序、距离量化、等成本结点y/x次序及身体可行的平滑次序，写入算法版本；不能为比例改变平局路线。交互目标取真实合法站位的最低路程，平局同样固定。路径族枚举顺序冻结为直接撤离、节点ID排序、评测区域行列排序。冻结从出生到目标再到撤离的**完整出行路线**，主计数按整趟首次遇见去重；去/回单腿仅另作诊断，同孔跨去回再见不是两孔。

沿路线进入某结构边界112px内，且玩家可观察到其面对自己的有效地面侧，记一次结构遇见。每条完整出行按最终空间组ID去重；不能沿着同一孔的十个支叉反复记十次。同一观察位置同时满足多个身份时按真实身份各记一件，但合组规则先执行。岸湾另列 B，不能改写 H:S。

**G4 整体路线机会与局部差异（2026-10-14，用户要求纠正过度开销后收缩验收）。** 路径族、最短路/平滑、真实48px操作站位、112px首遇和每条完整路线按身份去重保持。全路径族汇总首遇H与S，使用现CSV的`.60≤ΣH/(ΣH+ΣS)≤.75`检查整体空洞机会；同一结构跨不同路线可重复计入，故这是路线机会频次，不冒充独立物件数量，独立H约2S仍由几何门另验。至少一条路线满足原224px/6件资格，否则证据不足而拒绝。所有节点/出口必须真实可达，实际连续窄段不得超过224px。逐路线比例、连续六件窗口和窄段占比20%改为独立`qualityDiagnostics`，原始数值与失败位置完整保留，不触发重排或拒绝。局部路线允许偏孔或偏实体；不能为了让每条路相同而继续进行约束求解。区域等权摘要继续仅作诊断。G1最坏空白、G2真实遮视覆盖、G3宽地连通、有效身份/数量、完整内容与60秒预算不变。这是工程验收范围修正，不是美术或玩家终审。

先前逐路线整数相位校准与固定probe试验保留在QA历史中；不再作为正常生成的硬验收合同。当前整体统计不使用相位补偿，不挑选有利路线。

全图分布摘要不重复累计公共主干：路径几何先按无向身体图边ID合并，将每个遇见事件归到其首次发生的评测区域，按`区域ID＋结构组ID`去重；每个有足量遇见的区域等权，不能因某区资源节点多而放大该区的票数。区域不足6件只报告、从摘要分母排除，必须同时报告被排除区域数，禁止选择性隐藏；暂以有足量区域的平均内孔份额0.64–0.70为**校准目标**，不将一个缺少足量区域的摘要作为自动通过。全局数量、全路线机会汇总、每条路线诊断及区域摘要分别呈现，不压成一个加权分。优先以整候选重排处理，不能在出生路边事后补孔。

这些是路线**机会分布**，不冒充真人实际探索轨迹。极短支路、不同玩家绕法和返回复见的体验仍须实走；不得将所有可能无限循环路线都纳入强制二比一。

### G5：原完整内容准入＋代表场景动态发布验证

准入保留真实出生/未知撤离规则、完整薪柴/污染物配额、48px交互站位、原风险档及巡逻窗口；不减内容、不把守卫改静止、不把深资源挪到入口，不为新密度降低风险。

动态检查在几何通过后针对真实敌人位置、移动轨迹、朝向、视距、察觉积累、听觉和等待执行。最小对照为同一遭遇的“直接穿越 / 等待后穿越 / 经孔绕行”；至少一条替代动作在实际机制下改变暴露或风险，且撤回路线成立。用现有AI/感知能力验证，不能另写简化潜行AI给自己证明成功。

报告敌人沿身体可走路径到玩家观察位/退路的距离和时间，以及每个有限巡逻相位中的持续视觉暴露时间；视觉断了而敌人三步可绕到，不能称作可靠退路。静态q/v/t与一条最短路通过仅证明几何机会，不能证明这条动态门。先做有限真实场景校准，再决定哪些动态量值得提升为自动准入，不凭当前设计稿承诺全部种子已经有成功潜行策略。

## 6. 可执行的基础生成流程

不需要先建一套大规模全局AI搜索。首版采用**带类型的空间分布＋有限约束求解**，复用已有轻量真实地形编译、8px/身体/LOS能力：

1. **冻结意图而非旧成品。** 输入为world身份、材料族、唯一母体及其允许变换、目标面积、矩形骨架语法、结构尺度/比例、独立种子。旧固定 placements/voidRects 不再是必须保留的成品。保留独有母体各一次及可辨关系；从属物、孔、板片都可重新安排。若某母体原坐标和尺寸必须原封不动才能成立，需显式标其约束及可生成范围，不用隐藏按worldId例外。
2. **共同采样一份完整布置。** 从面积和间距估计N及H/S整数，使用不等间距采样产生有类型的结构站点；方向来自世界的共同物质组织轴但带有限偏差。站点不是地图格子、不是房间中心。同一站点不总复制“孔＋石块”组合；大中小尺度和组合关系可变化。正向厚地板片、内孔负矩形组、实体实际足迹一起存在于约束状态中。
3. **在未完成状态内求解。** 合法操作为整组移位、转向、尺寸在授权范围内变化、站点类型交换、重新选择有限H/S数对及重新安排板片。位点互斥按真实footprint加宽地留量；空白热点可驱动重排，但不得只在已有成品上追加对象。若旧独有主体阻碍布局，可以按其允许变换共同让位，不能永远保护一大片空地。
4. **一次编译最终几何，再验G1–G3。** 同一矩形并/差及已锁v1断缘生成真实支撑；从结果重新计数H/S，并用真实mesh足迹、支持/LOS检查。装饰断缘可能让孔合并、通路断裂或计数变化，此时拒绝该候选，不把输入矩形数当成功。光栅、材质、碰撞、视线共用这一输出，不能分别修补。
5. **选择出生/撤离并完整部署。** 不预设两端，不预设这局一定选择哪个孔附近为出口。之后执行原完整准入及G4，记录实际布局、路线与拒绝原因。失败回到同一冻结身份下下一完整候选，不在已准入地图上补物。2026-10-14 Root批准尚未准入plan保留首个失败完整候选的实际出撤／节点目标为固定route probe，以真实失败类型事件和窄段截面导出既有有界整物件交换／移位；每份重编译候选仍先过G1/G2/G3，再复用原G4精确路径、站位与首遇评价。固定目标失效或原合格路线降资格不能算改善，探索探针仍全量；逐路线实际违规向量驱动比较，mean可暂差但几何门不得退步。探针不建完整世界／Host或重部署内容，实际几何仍计原72-work与60秒；probe全过后才消费原剩余第二full，正常资源初次部署及最终全部G4仍独立准入。资源早筛暂不在本批实施；后续如接线，须保留全部真实站位的最低成本风险定价，不能用换贵站位、删资源、重抽出口或换seed隐藏失败。实施接口与有界反例见[路线处置合同](../qa/artifacts/native-spatial-2026-10-14/native-route-design-review.md#3-root认可的最小实现合同)，唯一规则以地图spec为准；当前为实施待验，不宣称c27或fresh已通过。
6. **烘焙及冻结。** 仅对正式可接受的整图执行材质/翻找表现准备，保存输入、算法版本、几何/结果指纹及诊断；恢复不消费今日CSV。存档和Worker事务沿用当前安全边界。

求解预算先按**真实轻量几何评价总次数**计，不将“候选数×每候选调整数”藏成数千次编译：每个几何attempt最多72次真实编译与测量（每次重排后复测也占一次），最多2份进入完整内容部署；外层仍是既有8个确定性attempt及60秒截止。整次请求最坏为576次轻量评价、16次完整部署。首次成本试验必须测真实G1–G4及完整部署，不能由r11同为72次便推断耗时相同或一定成功；若超时/接受率低，要减少搜索成本或改善联合采样，不能移除硬门。重排/平局次序及所有支流确定，耗时不影响选择结果。计算耗尽而未满足G1–G4时明确生成失败，不能输出“可达但空旷”的基底或静默调用r11兜底。

所有策略初值与材料族形体范围由CSV单向生成；2026-10-14用户批准实施后，首批作者数据已落盘，见第9节，尚不代表几何、性能或体验通过。几何预算（当前32 solid/48总实例、fragment矩形/顶点、光栅容量等）若与目标数对冲突，输出不可行合同原因，另做容量与性能论证；禁止把密度悄悄截断到容量上限。

## 7. 怎么校准，以及什么会推翻这个方案

**阶段A：几何可行性。** 调参集固定本文五图的请求种子20261012与0；gel-rafts请求20261012对应的历史有效种子3991160799另作恢复/回归记录，不能把它混写成同一请求seed。补足六材料族的样本在跑前登记世界ID，不临时挑容易过的图。留出集固定请求种子730201、730217，本轮不用于调参或择优；到留出验证时连同失败整批公开。288/320/352三档间距保持同一世界、种子、面积和完整内容配额，比较所有失败、接受率与G1–G4。先排作者能力/编译错误，再评设计约束，不能把不兼容profile误作空间无解。跨世界、跨尺度、三污染档的进一步覆盖由试验结果决定，不以四个seed冒充全库统计保证。

**阶段B：正常镜头行动。** 在数值合法样本中专选最大残余空地、最窄、孔最多、实体最多、强母体占地最大和未知种子。观察遮断前→绕端→观察→退回的连续画面；同一敌人做三种行动对照，含至少常态与一档恶化状态。各自记录实际听见/看见、等待、被发现、改道与撤离寻找，不用去雾图代替潜行体验。

**阶段C：有限调参。** 优先调整s、有效对象尺度及G1最大空白阈值三者的关系；不要一次同时调十多个阈值。每轮仅提出一个可反驳的因果修改，最多两轮内部校准后交付变化证据和剩余问题，再决定推广。不能在少数图上把所有阈值调绿后声称全108地图已最优。

明确反例：

- 一张图统计12孔/6实体，但孔都挤在角落：G4失败；总数不能通过。
- 一孔分八叉或一母体八条腿：仍各一组；若故意用细地条拆孔也不能灌数。
- 只在周边挖深湾、内部空白：H不足且G1/G2失败。
- 遍地微孔、小碎屑使最近障碍距离很小：有效结构资格失败，不能逃过G1。
- 巨大可见母体撑住全部实体配额、另一侧空白：G1失败，即使H:S和面积统计合格。
- 112px宽、448px长的廊道：即使48px宽核连通，实际横向开口/持续窄段门仍应失败；另做沿宽面贴障路线的反例，确保不会误罚。十个短颈串大厅不宣称必被本版自动门排除，保留构型审查。
- 多孔组成一条绝对安全外环，直接绕图避开全部遭遇：静态分隔成立，但动态/路线价值不成立；优先重组空间和部署，不把孔LOS偷偷关掉。
- 每张图三角点阵、同形孔石等距交替：数据可能合格，但世界身份/美术失败；随机抖几个角不能为机械铺排辩护。
- 从属实体变成独有主物件的缩小复制：玩法统计不能代替美术质量，退回材料族形体组织。

### 9.1 冻结面积与土地组合

五图`target_walk_area_px2`来自第1节基线的最终20px身体可达站位数乘8px格面积，而非地板投影面积：split 1575616、gel 1241088、sloughed 1310016、ash 1324992、black 1630848。它们在三污染档共用；不会因候选挖孔较多而跟着缩小。该量是一次离线迁移的尺度参照，运行时不读取旧地图，也不继承旧`voidRects/placements`。

土地语法为`offset-overlap-v1`：共4–7块轴向矩形偏置搭接。2026-10-14 B对照后启用§9.6的有界core/shoulder作者分层，旧每世界片长/厚范围保留为core域，肩片使用显式新字段；并未增加总板片数。`span`为矩形长侧，`thickness`为短侧；方向只允许0/90度，不能把整个轴向骨架任意旋转成斜矩形。每加入片与其合法父片须有实际二维面重叠，两轴均至少320px，不能只搭角或以细桥连接；最终单外轮廓、宽面与身体通路仍由真实编译结果验证。候选共同求土地、内孔、实体，片数和范围不是先铺成固定矩形板后再掏洞的许可。

土地片中心不在固定格点，伸出与退缩不能四边同步；禁止用等边距内缩替代矩形错搭。`material_axis_rad`供材料组织和实体朝向使用，不改变矩形布尔骨架的轴向规则。表内板片范围只是首轮搜索域，目标面积/G1–G4优先；不可行时拒绝并报告，而非放宽门。外岸和内孔统一消费已锁定的共享v1自由断缘；本次不新增固定圆角或另一套边缘算法。

### 9.2 单孔语法与大小分布

一个孔由2–4个相互重叠的负矩形联合，使用同一个孔身份，组合后再参与整图布尔与共享断缘。矩形角仍是基底语言，分段切损和自由断缘是局部打磨；不得替换为椭圆、任意多边形洞或每孔同一个十字。

初始小/中/大权重为35/50/15：小孔最长跨度112–144px，中孔152–192px，大孔200–240px；它们的短厚范围分别80–104、88–120、96–136px。权重用所选H作最大余数分配，平局按profile ID，之后确定性打散身份次序；不是固定每图有几孔。大孔15%是本轮尺寸组织初值，不冒充体验最优。最终每孔面积上限分别14000/22000/30000px²，最大跨度作用于**整个矩形联合及最终断缘轮廓**，不能按每根枝分别放大。

`min/max_overlap_ratio`约束新矩形与其接续矩形在接合方向上的重叠长度，相对两者该向较短边；`min/max_offset_ratio`约束接续矩形的横向中心错位，相对两者较短厚度。先选接续边和偏移符号，再在范围内采样，不对每根枝复用同一偏移。每次接续必须保持正面积连接；超出联合总跨度、面积或核心条件便拒绝该孔样本，不能将矩形裁成细丝继续计数。2–3片的小/中孔强调偏移阶口，3–4片的大孔允许一处次分支；旋转/镜像只是变化来源之一，不是唯一变化。

表内最小厚度留有断缘余量，但**最终真实VOID内必须存在半径32px厚核**，不以输入厚度代验。孔间合并、接上海岸、被细地条伪分、失去q/v/t见证，均按第3/5节重新计数；不得补写一个ID维持H。小孔也承担实际遮视，不能变成视觉噪点。128负/正矩形总预算共用，求解器在采样前按H与profile片数预检预算；超限整候选不可用，不丢弃末尾孔蒙混过关。

### 9.3 独有母体和从属物的身份

`source_instance_ids/attached_relief_ids`均指向按污染档生成的**原生definition实例ID**，不是空间placement ID，也不是按solid/relief过滤后的下标。组从源中心的相对位移、局部转角和构造参数一起复制一次；solid的最终三维统一尺度=`source_scale × sampled(min_scale,max_scale)`，旋转偏移整体作用于组，不允许每片分别摆。2026-10-14实施澄清：附着relief是贴地材质低面，保留作者height/thickness，仅XY位置、长宽及相对位移跟随母体变换；不把6px贴地高度放大后夹回6，也不放宽settled低面上限。这里0.95–1.05的窄尺度域只容纳联合排布，不能把母体缩成小残块。

- **gel-rafts**：源3和源6为两个独立落地的夹岸组，分别挂接relief 1/2与4/5，不能把二者远距离合成一组刷比例。基础尺度1.25。原7–12同形扩写不继承。

### 9.6 core/shoulder 有界作者域校准
