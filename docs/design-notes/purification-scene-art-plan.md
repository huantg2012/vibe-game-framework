## 完整画面与功能范围

以原画的断裂书库、旧混凝土厚断面、木架和书册、铁机器、微暖炉光、下坠残构与深暗空洞为整体目标。构图同时容纳上下两层、两条坡道和六处既有功能：核心、储藏、净化器、供奉、蜕变、裂隙；各物须有独立构造、可接近站位和互不混淆的身份。核心保持被夹件约束的污染暗物质，采用低饱和灰绿，不改画成普通能源灯。

保留原角色身份与实际尺度，暖棕角色须在整景中可读。双坡和操作站位先做几何校核，随后正式阶段另验真实碰撞与行走；样景查看器中的模型点击仅用于检查图片，不构成正式游戏交互。

## 推进顺序与回看节点

1. **完整环境与六物同时成形。** 平台断面、墙体、书架与远近残构应共同支撑整体构图，核心等六物保留功能身份；不再沿 C 局部候选补丁式扩充。
2. **校核空间和正常尺度画面。** 上下层、两坡与六站位应有连续可接近表面。以原角色同框检视轮廓、遮挡、物体厚度、材料区别及明暗层次；几何结果与美术判断分别记录。
3. **导出与查看。** 保存分层像素资产与复现入口，核对查看页的整景、原画和六模型视图、图片载入与错误记录。技术检查仅验证产物可复现和入口可用。
4. **根据用户画面反馈收敛。** 对照启动页原画检查完整场所，而非只列已增加多少细节。当前候选在获得确认前保持 HUMAN-REVIEW-PENDING。
5. **后续正式接入另行记录。** 接入真实碰撞、操作、角色排序、装置状态与人物驱动三层视差时，再验证六点行走、双坡往返、切场、暂停与生命周期。离线深度和 AO 不能替代这些运行证据。

本轮只推进艺术样景，不扩展 Rift、成长经济、物品设计、游戏 UI 体系或长期平衡。确定性 3D 辅助构型服务像素制作，并未恢复已终止的三维游戏路线。
