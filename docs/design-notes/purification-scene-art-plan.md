## 后续顺序

1. **扩展前景和室内。** 将已成立的样板画法扩至据点建筑、两层地面、通道及六处装置的环境接口。构图沿用 C，重点是承托、断面、接触、遮挡和细节疏密；在原人物实际位置检查可见性与连续通行。
2. **完成外景三层和全场光影。** 近层与据点混乱相连，中景隐约形成尺度落点，远景大部分不可见。先让完整静帧具备纵深、材料区别与氛围，保持 C 的内外占比和观看路径；远层偶发存在留给动态阶段。
3. **接入正式场景与动态。** 保留已经成立的画面，接上正式碰撞、操作点、前后遮挡、相机和装置状态。玩家真实移动驱动不同距离的三层视差；核对接根、画幅边界、暂停及减少动态。资产显示链路从样板阶段就验证，不把所有技术风险拖到这里。
4. **整景验收与收尾。** 同视口对照 C、成品静帧与实机，检查一整段连续走动和停留、六处操作及上下层往返。分别记录画面判断与功能证据。用户认可整体画面后再标艺术完成。
