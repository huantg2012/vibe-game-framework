## Slice 1 范围推导（依据 guides/10-slice-model.md）

规则："Slice 1 = 核心循环的最小可交互版本"，问"最少需要什么才能让一个人体验到这个循环一次"。

vision 的完整核心循环 = 裂隙出击（前半段）+ 净化点分配/冲击（后半段）。完整闭环对单个 Slice 过大（预估 >7 天），因此**提案将循环拆为两个 Slice**：
- **Slice 1（本提案）= 裂隙前半段**：验证 moment-to-moment 的潜行 + 资源博弈手感（体验支柱 1「绝望边缘的紧绷」+ 支柱 2「贪婪与撤退的博弈」）。这是全游戏最核心、风险最高、最该早验证的部分——若这一层不成立，后面的元循环无意义。
- **Slice 2 = 净化点闭环**：撤离 → 薪柴分配 → 冲击结算 → 受损后果反馈（见 roadmap）。

### 提案纳入 Slice 1 的最小范围（来自 vision MVP · 裂隙层）

1. 俯视角移动 + 有限视野（Raycasting 视野遮罩，视野外黑暗）— 核心体验支撑，不可省
2. 一张可玩的裂隙地图（含障碍布局，支持视线遮挡 + 路线选择）
3. 一种基础敌人（巡逻路径 + 感知范围 + FSM：巡逻/警觉/追击）
4. 薪柴搜刮（地图散布，部分安全 / 部分被敌人看守 → 制造博弈）
5. 混乱值系统（匀速上涨 + UI 显示 + 至少一种超阈值惩罚，如视野缩小）
6. 撤离机制（地图上有撤离点，到达即结束本次出击）
7. 占位资产（按 art-direction.md §12 占位策略：色块 + 代码绘制的视野/光照，不等正式 AI 资产）

### 提案暂不纳入（推迟到后续 Slice，保持 Slice 1 可验证且够小）

- 净化点 / 冲击结算（→ Slice 2）
- 战斗系统（见设计取舍 #2）
- 第二种敌人、功能物品、音频资产、跨 session 存档、多语言接入（→ backlog / 后续 Slice）

## 设计取舍（需人决策，PROPOSED）

| # | 决策点 | 提案倾向 | 理由 / 风险 |
| - | ------ | -------- | ----------- |
| 1 | **地图生成**：Slice 1 用完整 Voronoi+CA 程序生成，还是先用简化/手工布局验证手感？ | 倾向**先手工/简化布局**（保证有障碍+路线选择即可） | 程序生成（DEC-005）预估 6-10h 且调参风险高；潜行手感的验证不必依赖程序生成。程序地图可作为独立 Slice 或 Slice 1 后半。但若人认为"随机性是紧绷感的一部分"，也可纳入。 |
| 2 | **战斗是否纳入 Slice 1？** | 倾向**不纳入** | vision 将战斗定位为"可选、有代价、可控"的决策选项，非主要交互。Slice 1 用"绕行/等待/潜行"即可验证博弈手感；纳入战斗会扩大范围并模糊验证焦点。若人认为"没有战斗无法判断敢不敢拿"，可纳入简化版。 |
| 3 | **Slice 边界**：裂隙前半段单独成 Slice，还是把最小闭环（含净化点）压进一个更大 Slice？ | 倾向**拆成 Slice 1 + Slice 2** | 拆开每个 Slice 都能在 3-7 天完成且可独立验证；合并则单 Slice 过大、验证焦点分散。 |

### A-G3 合成测试步骤分解（agent 驱动，人只碰生图+审美）

| 步 | 做什么 | 谁做 |
| - | ------ | ---- |
| 1 | 列出合成测试所需 tile/decal 清单（地面变体×N、墙、数据错误块、裂缝 decal） | art agent |
| 2 | 为每块 tile/decal 写生成 prompt（固定前缀 + 本块描述） | art agent |
| 3 | 用 prompt 在外部模型生成单块原图 | 🙋 人（唯一：外部生图） |
| 4 | 逐块过 `npm run art:postprocess` + `art:verify` 处理为合规资产 | code agent |
| 5 | 搭最小合成场景：真实 tilemap 渲染 + 覆盖层 decal + 有限视野光照，输出截图 | code agent |
| 6 | 结构性自检（重复感 / 边界马赛克 / 色板合规）+ 截图与参考图并排 | code/art agent |
| 7 | 看合成效果拍板"氛围 vs 逐像素"、是否回炉 | 🙋 人（唯一：最终审美） |

> 人肉参与仅第 3、7 步；其余全部 agent 执行、Director 编排（对应 director.md 的"人肉手工唯二例外"）。第 5 步的合成场景不是一次性玩具——它就是 Slice 1 真实渲染路径（TilemapRenderer + VisibilitySystem）的提早落地，因此 A-G3 天然是 Slice 1 实现的**第一段**，而非独立于 Slice 之外的前置工序。
