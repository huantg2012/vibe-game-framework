## 验证问题

玩家不看文档，连续踏入裂隙两次，能否同时感到这四件事：

1. **布局不是上一趟那张。** 墙、可走区域、出生点、撤离点都是这一次踏入时生成的；这一次出击结束前地图不再变。
2. **可走区域的外轮廓不是规则矩形。** 不能靠「这是一张长方形纸」预判探索方向。
3. **障碍读得出「这曾是什么」。** 不是细碎随机石块；要有情景（一段墙、一条脊、一块像院子/站台/林缘的残留）。
4. **两次出击的氛围能分清。** 不只是形状不同；色温、地表、障碍语言要让人觉得进了另一块世界碎片。

核心玩法仍是：还会不会为了多拿一点而改路。本 Slice **不**验证「选哪个出口」。

## 三条体验约束（本 Slice 的技术难点，规格必须先拆解）

人点名：这是高难度环节；每个问题都可能有多个解；准备知识/审美/参考，不要只抱一条路。

### 约束 1 — 不规则外轮廓

现状：整张图是规则矩形，四边一圈墙。玩家对「往哪探」有稳定预期，随机生成的优势被吃掉。

技术事实：引擎里 tile 数组几乎总是矩形缓冲。不规则指的是 **可走 / 不可走的外轮廓**，不是「数组本身变成多边形」。矩形缓冲里的界外格当作虚空/不可走，是合法实现，不能拿它当「边界仍是矩形」的借口——玩家看到的可走陆地轮廓必须不规则。

规格至少要并列评估（可增，不可只留第一条）：

- 若干大幅相交矩形的并集外轮廓（人给的参考，**不是唯一思路**）
- 极坐标压力团 / 隐式曲面（净化点已有类似边界形态，只作参考不是照搬）
- 只保留宏观碎片的并集，外围碎片丢掉，外轮廓=碎片拼合的锯齿
- 从种子生长再腐蚀，取最大连通块当陆地
- 手绘/预制轮廓章旋转缩放后当掩膜
- 其他 design 调研后补的路

禁止：生成一张矩形可走区再在边上啃几个缺口充数。

### 约束 2 — 障碍要有情景

现状：手写图已是 L/T/C 和小簇（2–12 格），人仍读成细碎随机，没有「我在探索一块世界碎片」。

世界观：裂隙是被强行拼合的现实残片；原有材质（砖/木/土/金属）应仍可辨。DEC-005 反对的是「方正房间+走廊像建筑游戏」，**不是**反对「这段墙曾是一栋房子」。

规格至少要并列评估：

- 先放 2–3 个可读地标（一段街、一个院子、一道脊），再填缝
- 按碎片类型用不同障碍语法（书架墙 / 站台柱列 / 林缘土脊），不是同一套胡椒粒
- 提高最小特征尺度（禁止大量 1–2 格孤岛）
- 预制残块印章 + 污染侵蚀
- 其他

禁止：只靠 CA 胡椒粒墙交差。CA 可以当风化，不能当唯一结构来源。

### 约束 3 — 不同出击，不同氛围

现状：`procedural-surface.ts` 写死户外灰绿（`frag-outdoor`）。美术方向 **已经锁了五套碎片记忆色**（旧图书馆 / 医院实验室 / 地铁工业 / 居民区 / 户外），从未按「每一次踏入换一套」用起来。

`vision.md` 把「多种裂隙环境/生物群落」写在明确不做；`world.md` 写过 MVP 共用一套视觉主题。**人本 Slice 的指令覆盖这两句。** 本 Slice 做的是「有限种碎片氛围」，不是无限生物群落，也不是丛林/冰原/岩浆那种新题材。

规格至少要并列评估：

- 每一次踏入抽一种已锁的 L1 碎片记忆，地表 + 障碍语法跟着变（实现已有色板，优先评估）
- 同一种记忆再叠污染年龄/浓度（偏蓝新生 vs 正 teal vs 暖绿古老）
- 只做 2–3 种本 Slice 能做完的，其余记忆留给后面
- 只改雾/亮度/污染密度、不改障碍语法（标出「可能不够」的风险）

禁止：所有生成结果共用现在这一套户外灰绿。禁止为了「不一样」引入未论证的新色值。新色必须走美术方向已有论证路径。

策划数据：碎片类型若有策划向字段，进 `data/*.csv`，禁止在代码里手写一套再反向导出。
