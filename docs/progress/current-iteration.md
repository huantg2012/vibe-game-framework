## 验证问题（人浏览陈列馆时回答）

1. **能不能按孔谱 → 基体找到想看的外形，而不是在一张大网格里找？**
2. **每个标本的参数能不能看懂？** 表名与档位是否分开，有没有读成一句复合名词？
3. **去重说明是否让你相信「视觉不同的都在这儿」？** 缺的是真的「看起来一样被合并」，还是漏了？
4. **浏览时浏览器是否可接受？** 不卡死、丙丁不互删、丁不在镜头底下乱冒浊点。

建议打开：`http://localhost:3000/gym.html?lesson=lexicon-gallery`（Cursor Simple Browser）。I4-B 之后就可以先看厅结构；I4-C 之后再看动作。
