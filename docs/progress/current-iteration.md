| 项 | 约定 |
| -- | ---- |
| 触发 | 人点名模块并说开始，或 `/director` 带具体任务 |
| 显示名 | `迭代 1`、`迭代 2`…（阿拉伯数字，从 1 起算，从下一手人点名的任务开始） |
| 粒度 | 一次迭代 = 人这一次点名的那包工作；禁止把多个无关模块塞进同一迭代 |
