## 验证问题（人试玩裂隙时回答；FV-04）

本次验证依赖人在**真裂隙**里试玩（练习场不开迷雾、不开旁白）。建议参考 Playtest 方法：自己玩 10+ 次完整循环，记录结构化反馈。详见 `guides/02-ideation-workflow.md` Step 4。

1. **迷雾下四张孔谱是否仍可读？** 甲的簇、乙的墙缝核、丙的呼吸、丁的云——在可见区内能否看成「那里有一口」？丁是否仍低于视野蒙层？
2. **新基体上屏的旁白是否读成一句复合名词？** 残茎 / 栏柱 / 灰幕 / 余响 / 散光 / 间距是否分节点？成句短标记是否像传奇全名？
3. **打不死的场是否让你选择绕，而不是烦到想清场？** 绕是否仍比杀便宜？有没有开始享受战斗？
4. **乙沿墙游荡、丁云飘移时，危险区是否跟得上？** 会不会挡路或把走廊切开？
5. **第一次踏入是否明显卡顿？** 方案 D 每只都要烘焙画布；整座生成岛 + 迷雾 + 甲 2–4 只 + 宿主，首次是否可接受？

不要标迭代 3 COMPLETE，除非人回答过以上问题（或明确要求按「实现完成，体验未验证」收尾）。agent 不得代勾。
