1. 已确定的方向与边界

用户明确接受三档自由进入；撤销早期“完成一次中污染搜撤才开放重度”的候选条件。低档目标为相对安全、可从容；中档有压力但仍有信心；重档危险明显、需要谨慎决定。相对安全不承诺无伤、无敌或稳赚。

选择界面的整体背景视觉是第一层表达，不能只改档名颜色或裂口的一点闪光。文案分 A（简洁准确的机制说明）与 B（符合世界观的文学化氛围低语）；两者必须在职责与排字上可分。

继续保留先选污染 → 配置行装 → 踏入的顺序、单列背包及其键鼠行为、返回时的装备/选择/滚动记忆、具体目的世界未知。这里优化出发决策的信息与感受，不改敌人、混乱、掉落、消耗、准入和保存规则。

尚属制作候选：背景的具体形状、各档明暗与动效幅度、音色与混音、文案逐字稿、淡入时长。用户认可方向不等于这些细节或最终实景已获认可；本计划不要求再选一遍方向。

2. 玩家经过的体验

靠近裂隙打开备行，第一眼通过整幅背景感知所选档的压力；随后读档名和风险，再读必要的应对及收益。选档只改变表现与公开说明。前往行装后，背景动势收敛，所选档与简短危险判断保留；装备成为阅读焦点。返回可立即比较其他档。取消恢复净化点原表现。

一个当前选择、一份说明、一个前进动作。等级名称维持低污染／中污染／重度污染；“轻”只用于沟通，不增加第二套玩家术语。

3. 背景与声音方案

载体是实际裂隙边的世界内交互读数；背景是这次辨认暴露条件的表现层。沿当前像素实景、无框排字与连续暗场，挂载仍为固定 960×640 的现有场景/overlay。Signalis 取主从与克制文字，Darkwood 取人物在场与暗处准备，Hyper Light Drifter 取直接选择与短标记；不移植其皮肤。

同一机位、人物、裂口和建筑身份贯穿三档；采用远层遮蔽、裂口内侧异样层次和局部明暗节律的组合，构图先于动效。场景本身不改碰撞、视野、装置完整度，也不预先生成或展示某个将进入的世界。

  • 低：空间舒展。 人物脚下、裂口边缘与几处原有空间层次可辨；暗部有间隔，异样局限在远处。稳定静帧成立，声音稀疏且留有较长安静段。
  • 中：围合增强但仍能掌握。 远层暗部在两侧形成更明确的包围，裂口内部有缓慢的遮蔽/明暗变化；人物及脚下仍保有清晰的空间。节奏大体可辨，声音增加克制的受压质感。
  • 重：环境占据更大分量。 大片有内部层次的暗形与局部错位关系压缩背景留白；少数稳定的场景边缘与肩灯构成人的立足点。缓慢变化的方向与停顿不完全同步，声音低沉紧绷。不能把黑色遮罩加深、全屏泛绿、放大音量作为主要差别。

新增异常只作用于背景层/裂口内部的表现，不让脚下地坪断裂、装置闪出损伤状态、人物扭曲或相机摇晃；也不出现类似可走路径、敌人或奖励的剪影。保护的是人物轮廓、脚边实际地坪和装置实体身份，不是把整个左侧世界区冻结。现行右半屏已被阅读暗场大幅遮蔽，效果不能全藏在其下。P1 必须先交付表现区/保护区示意：哪些可见远层轮廓、暗隙、裂口内层参与变化，哪些前景实体与读字底保持原样。

三档首先区别于可见的大形和空隙：低档远层之间有分开的暗隙；中档同组远层形成局部围合，仍留清晰间隔；重档让远层与裂口暗形产生更强的接续/对向关系，收紧视觉留白。以上是待试构图，不是改变实体位置或可走区域。保持同一机位、曝光设置和阅读暗场，在隐藏文字、静音、停动时验证差异。重档不能只剩一片黑。素材与已有世界像素共用画法，不叠通用烟雾、CRT噪点或惊吓跳帧。

声音为辅助，归属于裂口方向的选级表现层，保留净化点原有主床与功能声身份。先审听已有素材；仅在不适配时限定制作一条环境层。同一音色家族内调整事件间隔、纹理密度和摩擦质感，响度只辅助，不持续攀升。选档连续衔接，不调用真实混乱/受击/追击层，不让整座基地变调。允许有界交叉尾音，过渡结束仅剩当前目标；P2 记录过渡峰值和稳态实例数，不以含糊的“8轨”代替资源合同。

静音和减少动态时，静态构图与文字仍完整。减少动态直接采用 P1 每档设计好的稳定构图，不截取随机动帧、不统一退成低档。现有 Canvas 兼容路径与减少动态是两件事：本计划承诺兼容路径保留 A/B、档位、输入与清理，暂不承诺等效的三档背景压力；P1 只评估同源静态层能否有限补足，不能为此另建动态渲染器。实际限制在验收记录中明确。

三问开工核：审美靠空间层次、人物尺度与单一阅读焦点；游戏感靠真实裂口旁的辨认—备行行为；同世界靠既有材质、受光、像素与克制自语。三问是制作依据，效果仍待实景验证，不能写成人审 PASS。

4. A / B 文案与信息编排

A：规则说明

内容顺序为危险判断 → 危险原因 → 应对 → 深处资源。各档用同样的字段与位置，可直接比较。选中档名 18px、危险判断 16px、事实 12px、标签 11px；风险判断从属于当前档，不复制第二个大档名，不用更亮/更重的文字抢主标题。收益留在次级位置，避免高档首先读成奖励升级。

候选文案仅用于方案审查，实施时迁入对应 CSV 并由 codegen 消费，本文件不成为运行文案的第二真源：

  • 低污染／威胁较低：混乱增长较慢，污染体较少。应对：观察路线，逐步搜取。深处资源：较少。
  • 中污染／威胁升高：混乱增长更快，受侵占的区域更多。应对：留意绕行机会，提前考虑撤退。深处资源：较多。
  • 重度污染／高度危险：混乱增长很快，且更早加速。地面与空气大范围受侵占。应对：准备脱身手段，为返程留出余量。深处资源：最多。

三档共用一条次级说明：入口附近的收获不随档位增加。 “深处资源”比较的是场景部署的可搜资源，不能换成“本趟所得”“收益倍率”或保证带回的数量。共用规则在同一位置只写一次，不在档内和页脚反复堆叠。

事实逐项对照 rift-pollution-grades.csv 与 rift-expedition-grades.csv；“更早加速”对照当前 90/60/40 秒起点，不显示保证成功的停留时长。没有装备评分、推荐战力、必备物检查或精确掉落预告。威胁较低是相对其他档的判断。

B：氛围低语

从角色当下的灯、鞋尖、石面、背带、手心出发；用观察和身体反应烘托气氛，不替玩家宣布绝望/勇敢，不虚构 NPC、灾变解释或世界预知。每档先一条主稿，最多 40 字、两行，不靠大量轮播稀释判断。

  • 低：灯照着鞋尖，石面的细纹还看得清。
  • 中：背带又收紧了一格。裂口边上的光，怎么也接不到另一头。
  • 重：裂口很窄，里面却没有近处。还没迈步，手心已经湿了。

B 沿现有低语 13px 衬线族、正常字重，与 A 的无衬线事实说明分开；不加引号框、打字机或大面积斜体，不进入左侧人物/世界保护区。无需增加“A/B”“氛围提示”等玩家标签。未来新增句必须符合实际背景，不能描述未画出的场景事件；正文不得借诗意承诺路、出口或安全窗口。

固定版位候选沿现有 960×640：选项列 x344–490，详情列 x534–928，footer y526–588。详情内危险判断 y214–238（24px 行高），事实 y248–311（至多三行，21px 行高），应对 y324–366（至多两行，21px 行高），深处资源 y380–402，共用入口说明 y410–446（11px 字号、至多两行、18px 行高）；B 独占 y466–510 两行区（22px 行高）。出现/消失不推移控件，B 至 footer 保留至少 16px。P1 用重档最长文案、真实字体与键盘焦点核对，超长先精简稿件，不能缩小正文字号、截掉风险或塞进 footer；坐标只在实景核后写回 Kit。

B 的局部呈现合同已裁定，数值仍待样板调校：

  • 一次打开到真正关闭为一个会话；进入行装再返回仍是同一会话。每档每会话最多一次有效呈现。
  • 档位、短划与 A 立即响应；连续停稳 250ms 且页面实际可见才调用专属池并标记该档已呈现。快速改选、进入行装、关闭或失焦撤销待呈现回调，不提前抽句/消费预算。失焦前尚未呈现的机会，手动恢复且仍在选级页后重新计停稳时间。
  • 有效呈现候选总长 6 秒（含渐入渐出，以场景时钟计），之后留白，停留不轮播。改选或进入行装立即结束该句；回来不重播、不另抽，预留区仍在。B 不承载必要的决策事实，所以留白不损失机制信息。
  • 已显示时失焦，隐藏同一句并冻结余时；玩家按现有暂停流程主动恢复且仍在原档选级页，继续余时，不重抽、不重播渐入。若期间关闭/换档/进入行装则结束；不自动恢复游戏。
  • 关闭销毁会话；下次打开各档重新获得一次机会，新有效呈现仍按共享池的避重规则取句。这里只定义备行的触发资格，不修改全游戏的池轮换规则。一般净化点自动低语继续让位，不同屏叠句。

此规则在旁白规格中标为计划中；P1/P2 可以据实际阅读结果调整时长，但不得自行换成返回刷句或后台预抽。

行装承接

标题附近保留“所选档／危险判断”短摘要，低于当前物件；出发动作旁保留等级身份。两处消费同一选档值，重复是防止长时间配装后误发，不能重复整段风险文案。行装页背景保留静态档位差异，动态和声音收敛以免干扰阅读；不能暗示准备后危险已经下降。

两处摘要均沿辅助层级，不继承选择页 18/16px 的标题权重；当前物品名和主要动作保持视觉主次，装备页不再新增 B 或风险段落。

5. 状态与资源归属

P1 即接通真实 panel → presenter → 净化点场景路径，传递只读的已接受档位、pollution/equipment/closed 阶段、active/paused/disposed 生命周期。档位只取现有业务选择；不以 DOM 查询或 DEV 自建 grade 驱动另一套状态。场景持有背景和局部声音资源，备行呈现状态持有 B 会话及计时。空档位/旧入口明确恢复中性基线，不能继承上一会话的重档。

背景使用已有 far/middle/near、深度与光场，优先扩展现有环境层参数及语义掩膜；不能对最终合成图整体 tint 冒充局部变化，也不重烘整景。保护区依据实际投影/遮挡定义，P1 用锁定同相位的前后区域对照检查。

声音使用局部控制器与固定实例身份，复用既有音量、解锁与暂停。选级态跟随最新档，行装态转安静目标；paused 冻结/静音，手动恢复时只追最新状态；closed/disposed 释放自身资源。取消不能用全局 haltNonBgm 清掉净化点原床，不写 Rift 战斗层目标。晚到加载回调校验会话代次；资源缺失或解锁失败不阻塞选择和出发。准备取消、进入实际 Rift 与场景销毁均有明确收尾。

6. 实施分批与依赖

P0 方案收口（本次）｜Director 主责，Design/Art/QA 分审。 保存已确认方向、候选方案、机制边界与审查修改；更新归属 spec/Kit 的“计划中”链接、P49 与现状索引。交付仅为方案，不创建游戏源码或数值改动。完成条件为三份独立意见及逐项处置可追溯。

P1 三档静态实景样板｜Art 主责，Code 协助。依赖 P0。 先一次技术核：确认现有层可操作范围、真实状态桥、主渲染/兼容路径和基线，列出有限改动清单。接通第 5 节合同，在既有隔离备行入口复用真实场景与组件；生产默认暂不启用，不能另造一套 DEV 行为。交付表现区/保护区图、三档固定构图、A/B 排字和行装承接；同场景/独立记录/尺寸输出每档正常文字及隐藏文字帧。静态样板一版加一次针对问题的修订，仍不能形成有意义差异则封存原因，停止进入 P2。实测无新增层基线后，冻结允许的帧时间/资源增量及超限时先降运动/纹理复杂度的策略，不能无基线捏造精确预算。成本中；允许最小掩膜或同源静态层，整景重烘/第二套渲染器不在本批。

P2 连续视觉与声音样板｜Art/Audio 定规格，Code 实现。依赖 P1 静态内部核与预算冻结。 沿同一状态桥加入档位过渡、B 时序、环境动势与局部声音包络。规格必须记录每个效果的触发、目标层、幅度上限、周期/时长、曲线、打断及恢复；记录声音最大过渡重叠、安静目标与释放窗口。背景从当前值追随最新输入，不排队、不锁操作；行装只收敛运动，不退回低档构图。包含快速切档、返回、关闭、静音、减少动态与失焦。先一版，最多一次针对实际缺陷的修订；仍不成立则保留失败并回到原因，不无限调参。成本中到高，素材适配未审听前不作精确工期承诺。

P3 正式启用与生命周期回归｜Code 主责，QA 独核。依赖 P2。 将已走真实调用链的表现默认启用，清理落选运行分支；这是整合，不是首次接状态桥。A 使用现有等级 CSV 增补公开字段；B 使用 atmosphere-lines.csv 的备行专属池并由 codegen 导出，样板起即按这条管线消费候选稿。视觉/音频预设与业务等级分离，表现不消费生成 RNG、不写出击状态。执行 codegen 一致性、构建及针对性两环节/声音/存储/失败路径回归；独立 fixture 分别强制初始兼容渲染、运行中降级一次。更新 architecture 中实际模块和资源归属。成本中。

P4 体验验收与收口｜QA 取证，Art/Design 判读，用户终审。依赖 P3。 交付可直接体验的选级→行装→返回/出发过程、三档静帧及连续视听记录。独立区分机器检查、知情专家意见和用户感受；用户未审则停在待复看，不关闭 P49/I14。将最终规格与 CSV 收口，候选值/失败样板保留在对应证据，移除落选运行分支。成本低到中，返工按实际问题重新限定。

7. 验证问题与停止条件

  • 辨认强弱：只看三档稳定背景、不放档名和 B，能否给出低→中→重的压力顺序；再恢复正常 UI 检查 A 是否准确解释原因。隐藏文字仅为表达诊断，正式玩家始终看完整信息。知情代理不能冒充盲测。
  • 读懂并保留信心：正常页面上能否说清至少一个真实差异；中档是否既有压力又仍愿意尝试；重档是否促使认真检查行装而不是误以为被禁止进入。真正心理效果由用户描述，不能由颜色/字号测试代签。
  • 误读反例：玩家是否以为背景正在损伤基地、计时惩罚已经开始、目的地已确定、整张地图必定是这一形状或重档必掉好物。若成立，先修表现归属和措辞，不能靠追加大段免责声明补救。
  • 阅读与舒适：默认尺寸和实际显示比例下三档关键信息可读；正文（含 B）/关键非文字标记合成背景对比分别保持 4.5:1 / 3:1，覆盖动效最暗/最亮阶段并留抽样时间。静音、减少动态保留层级；持续配装不靠晃字、突闪、响度攀升制造压力。连续录像检查闪帧，不能用最暗静帧代签。

  • 低语限频：注入取句计数，快速三次切档仅最终可见档消费；250ms 候选下 249ms 关闭/失焦不消费；回到已读档不新抽；已显示的暂停仅恢复余时；新会话可抽。自动低语不得叠句。旁白历史与业务记录分别检查。
  • 隔离与清理：纯选档/切页步骤不改变库存、设施、生成身份或世界历史；主动装配是合法变更，不把整趟首尾库存全等当闸门。旧句/旧音/旧特效不在下一页或场景残留；生成/世界历史在选级时零调用，只于真实出发一次。快速切档、关闭中切换、失焦/手动恢复、准备取消、拒写重试、场景 shutdown/destroy 是不同样本。复用现有 DEV 的 import 前 Storage 隔离和业务内存记录，native Storage 零调用检查继续保留。
