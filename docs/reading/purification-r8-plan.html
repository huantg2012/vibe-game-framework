01 / SPACE

先把空间组织起来

上层可重组，为核心暗龛留下足够空间。左右辅助湾大小不同，双坡连成可选环路；下层保留停留、转身和维护的完整空地。三种墙体分别承担支撑、错位与坠落的构造叙事。

负形使核心成为焦点

核心背后留近暗腔，前方留工作带。建筑负责庄重，受控活腔负责活动；不添加神像、祭坛或宗教正史。

大构造决定墙的破坏

先读出完整壳体，再理解局部失稳。保留长直边、粗断芯和承力件；小缺口不再承担整体轮廓。

移位须通过路径预算

出生→核心、核心→储藏、供奉→入口，任一路不应超过现版基线约 10%。未过不进细化；调整仍不满足，就把核心留在主层，以靠墙暗龛建立仪式感。预算待实测。

02 / RESPONSE

七项反馈，对应七处设计改变

  1. 01

    裂隙入口明显退步

    恢复沿不等距地缝传播的动作，重新做地面咬合、暗芯与局部反光。入口是空间伤口，不应收缩成一颗星状坑。

    源码定位：I30 首次重构丢失旧 8 帧沿缝传播，现状为星状坑与 8 像素透明度变化。接入新材料与光照，不直接贴回旧图。实际 RiftScene 的“未改”目前仅为静态核对，未通过实机排除全部回归。
  2. 02

    完整度条的颜色、
    切边与严格范围

    观察范围与 E 交互解耦；加入进退距离差和时间缓冲。换侧先退后现，不横穿人物；遮挡立即避让。常态灰青、受损赭金、危险铁锈红，零值保留有色端帽。

    具体初值见第 04 节；距离与时序均待实景调整。
  3. 03

    三处墙缘像鼠啃

    分别重构为厚墙肩、大错位侧墙、垂落楼板断面。每处有自己的连续大形与受力来由，少数成片失稳取代等密度碎齿。

    重点是构型和体量，不是在原轮廓上多加骨料、裂纹和钢筋。
  4. 04

    核心缺少仪式感

    允许移动与放大，优先尝试上后部暗龛。约束体与建筑连接，活腔前留工作站位；玩家反复投入、装置抵抗再归稳，形成求生动作的庄重。

    比例必须连原人物一起看；位置必须通过常用动线验证。
  5. 05

    核心动态光与偶发颤动

    光随活腔局部活动影响支架与邻近受光面；夹持处有偶发承力颤动，主体不持续抖动。注入成功出现一次清楚的反作用和归稳。

    动态来自装置实际部位，不让整圈光池统一涨缩，也不循环伪造修复成功。
  6. 06

    六交互物都要有身份动效

    每件装置用不同动词、运动方向和事件节奏说话。静置、操作、受损与转化分别消费真实状态，避免全场同频呼吸。

    只有三模块有模块完整度；不给液缸、供奉和地缝凭空新增耐久。
  7. 07

    外景粗糙、缺少纵深

    近层交代边界与材料，中层交代大残构的遮挡和错位，远层只留尺度不明的层影。视差、反差和活动幅度逐层递减。

    外景仍在运作，但不抢核心焦点；不靠左右复制护栏或满屏漂浮粒子填满。
03 / MOTION

六物，六种动作身份

主体有重量，活动有接触点。完整度下降应改变控制质量、密封或流路，不能只靠亮暗表达。修复后回到可维持的秩序，磨损痕迹仍在。

核心 / 受控活腔

收束 → 承力 → 归稳

活腔不同部位错开节律。受损时缺拍与泄漏增多；真实注入后先抵抗再恢复受控幅度。

储藏 / 深收容

压存 → 沉降 → 封住

深口内物质缓慢沉落，压板追随负载。受损时密封间歇失守；修复后压板落定、逸散收回。

净化器 / 过滤腔

摄入 → 剥离 → 回吐

流动有入口与出口，前后不同相。受损时断续和滞留；修复后流路连贯，出击响应只跟现有操作。

成长 / 人体液缸

悬浮 → 偏移 → 悬住

人体先可读，管线约束微小位移。刻入完成时有一次明确介质传递；静置不重复表演“正在改造”。

供奉 / 承压立环

暴露 → 受压 → 锁住

环有重量，残渣和锁具传递力量。占槽数不是充能进度；空槽保持空，充能、成熟与转化只消费真实状态和事件。

入口 / 地面裂隙

错位 → 传播 → 复位

沿不等距地缝分段传播，两侧地面短暂失配。动作贴地，有暗芯与断续反光；不抬起成传送门。

全景同一时刻只保留一处强动作，其余弱动或间歇静止。环境节律不泄露尚未公开的冲击目标、强度或目的地。

  • 不横穿人物：换侧用退场、落位、入场，禁止整条滑过身体。

实景需联检：靠近、擦边、快速折返、跨侧、持具遮挡、近看与普通镜头。这里展示时序，不模拟已完成的交互。

状态按固定 100 效能基准：hp ≥ 100 稳定，25 ≤ hp < 100 受损，hp < 25 危险，0 为失效。条长仍为 hp / max；100 / 115 不显示效能受损。

主体活动与光强也用同一效能语义：真实加厚过程 100 / 100 → 100 / 115，不能让装置运行变弱。容量欠满另行表达。

候选色：灰青 #9eaaa8、赭金 #bf965b、铁锈红 #bd685e。零值端帽不表示剩余生命。颜色与实景对比仍待标定，详细语义以方案正文为准。

05 / PRODUCTION

作者整景，再拆成可运行资产

制作方法用于获得结果，不能代替结果。先判断完整场景是否成立，再投入单体精修。3D 只辅助统一体量、透视与光照，不要求替换现有 2D 游戏或原人物。

A / 基线与整体样稿

先画整景，先量路径

保留入口与现版证据，测三条常用路径。产出含原人物、三处墙和三层外景的灰度构图与色稿。

画面或路径预算不过，不进入细化。

B / 完整画面核心样板

一张整景，一次注入

作者整景拆为可遮挡、可受光的像素资产，先完成核心及其所在空间。3D 仅辅助体量与投影。

用完整画面判断，孤立单体特写不够。

C / 全场装置与外景

扩展六物与三层深度

按身份拆主体与活层；接回地缝传播。近中远外景按材质、遮挡和活动幅度分别制作。

动作消费真实事件，仍须兼容原人物。

D / 完整度体验 · 可并行

范围、节奏与状态同义

实现观察距离、出现退出、换侧避让和零值端帽。主体、光与读数共用固定 100 效能语义。

最终随新轮廓与相机一起核验。

E / 整体验收

运行、驻留、往返复看

实走双坡与六处交互，检查遮挡、动态光和 Rift 往返。长时间停留复看节律与材料。

运行证据和人审结论分别记录。

首个可判断样本：原角色处于双坡之间的完整房间，带核心一次注入与右侧三层外景。若整体仍像灰色展台，回到空间大形；增加细碎纹理不能替代重构。
