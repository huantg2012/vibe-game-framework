# 可见背身短接近：有限实玩样本

原90趟与独立低档30趟继续各自冻结输入政策。本目录只记录另起分母的三个真实输入样本，不是自然供给追加数，也不是熟练玩家完整评审。版本、原始存档来源及政策在 `policy-freeze.json`，精确结果在 `summary.json`。

旧政策只要175px内有可见敌人，就几乎总请求重规划；观察到敌人没有靠近也重规划，缺少背向走开后继续接近的分支。它仍会间歇移动，不是绝对原地等待。新分支仅在实际可见的敌人背向、未靠近、未出招，且28px短走廊全身体可走、全段距离至少66px、不穿敌人当前正面时，准许一次接近；350ms后重新观察。没有读取AI状态、检测值或未来巡路。

- **原冒险第5趟存档复走**：恢复该趟出发前实际存档和同一世界身份，保留原有5次回卷尺，没有新增装备。完整撤回3薪、HP100、混乱122.77。155次可见观察中没有满足该严格背向条件的时刻，实际许可0次，不能声称分支改善了这趟表现。
- **灰层重档20261004，普通探路＋声诱 fixture**：真实声诱1次、背向接近许可6次；仅带回入口1薪，HP85、混乱96.75。接近深处时触发测试政策75混乱返回阈值。这是保留的低收益结果。
- **同灰层重档，普通抗污＋压制 fixture**：真实盐瓶2次、烟斗3次，背向接近许可7次；50.16秒搜得第一堆深层薪柴，携带从3增加至8，64.15秒完整撤回、实际入账8，HP100、混乱96.38。深层薪柴确实可以带回，但消耗全部烟斗余次，未证明持续供给与维护有盈余。

最后两项是明确的普通成熟工具初始fixture，首趟归来免冲击，不能用其入账减零维修费宣称净经营利润。世界种子一致，但实际观察/路径/工具时序不同；样本量不足以归因单一变量或给出成功率。

所有策略仍按身体可走地图做宏观路径，局部避让主要针对看见的敌人。没有把所有已看见的绿色地面侵蚀加入绕路成本；混乱75截止及单次观察判断也限制深入程度。因此低收益既不能藏掉，也不能直接当关卡不可能高收益的证明。

初次声诱样本误把形体ID `folded-slab` 当成世界ID，被生成入口拒绝，尚未出发。该调用保留在 `prepared-lure/`，改用正确世界ID `ash-strata` 的独立目录运行；不计入三次实际旅程。
