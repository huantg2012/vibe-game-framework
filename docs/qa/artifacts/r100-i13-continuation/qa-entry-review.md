## 建议的最小真实反例搜索

先从同一真实健康祖先分别开低／中／重三支；源存档的现金、设施、成长、装备、供奉、潮段、已见历史须逐项相同。固定同一个预登记世界／seed可用于等级诊断，但应明确它不是正常随机重复访问的频率证据。高档和低档的生成部署不同，不称严格单因素时间实验。

开跑前锁定一个三档共用的**可观察近处速返规则**：按已见对象与合法身体路径选最近对象、固定最大搜索数／额外路程或时间上限，完成后直接撤离；没有合格目标则真实空返。不能使用节点kind／tier／value选目标，不能因找到污染物而追加一堆直到拿到钱，不为成功重抽。完局后才按原件区分到底搜到了safe、contested或deep。具体距离上限由正式合同确定，QA不把源码的40%换成伪造的玩家策略。

单次三档对照只能回答这三个实际案例。若要判断“重复速返可滚动成长／供给”，最小增量是**每支再从真实末态续一次**，共6趟，观察相同潮段下现金／设施债是否延续、祖先在槽物是否耗尽、第一趟新物是否进入成熟链；不能每次重置到健康祖先来重复计算净收益。第二趟的世界选择是否固定或自然必须预先声明，结论只落在对应范围。若只批准三趟，则报告明确“单返已测、重复经营未测”。

逐趟最小收据：

1. 四份真实存档与SHA、cycle／run ID／world／grade／实际输入、正常视野目标选择依据，场内时间与操作者备行／基地墙钟分开。
2. 每堆真实kind、tier、base／modifier／亲和、实际落袋，附带武器与污染物实例；空返、死亡、失败和未能靠近都保留。
3. 实际冲击前后每台HP、目标／强度、供奉防御及本次成熟来源，原51／100／51服务债与原51／102／51资本债固定，不以新段开局欠修作新低标准。
4. 真正支付的维修／成长、余款、主动／被动／武器消耗，基地供奉槽与消耗旧库存的变化；一次结算不得重复入账。

通过“没有等级入口加价”须正式逐堆结算匹配相同基值规则且实际高档未得到未说明的safe奖励。通过“这个有限速返策略未表现为可持续套利”须同时记录现金和服务／资本侵蚀及有限库存来源；净现金为正但欠修或消耗祖先库存，不够签套利，也不够签长期净利。若真实连续速返恢复同服务及等效准备后还能稳定支付成长，保留为机制反例并定位原因；不可仅因结果不合预期把它归为执行无效。

### 入口静态边界

[源码模型](qa-entry-bound.json)复用同修订6、同seed的旧三档完整几何，再按当前A12真实状态计算，不是本批实跑。三档320px内都仅有safe薪柴／safe污染物各1，因此两次翻找现金上界为6；模型不会把这些隐藏分类提供给行动选择器。当前槽位2件35%减伤污染物＋2件武器（武器不减伤），final crest强度3、CORE重点原伤59／16／15，经正式防御引擎得到25／7／6；预计归返模块28／94／48，恢复51／100／51至少9薪。当前一次性修复额度0、供奉返薪0；最多6−9＝−3维护余量。新的真实入场仍须校对同一圈内对象集合，真实归返／维修仍须另审。

条件性的重复边界也可定位：若每趟仍只能取得这个入口圈的1件新污染物（及可能附带武器），final crest每次归来会让所有在槽物达到成熟阈值；新catalog供奉最强45%，不返薪、不赠修复额度。每件最多省90×45%＝40.5HP，多件同趟相乘有递减边际。把每台取整最多0.5HP计入最有利误差，维持同服务的长期平均实际损伤仍至少48HP／趟，即维修至少12薪／趟，大于入口6薪上界。有限原现金、额外HP、旧供奉、修复额度不能每次复制输入；消费这些资本形成的短期余款不是持续套利。

上述是针对这一固定入口预算、final crest与固定服务条件的机制边界，不推广到其他世界／圈半径／早期潮汐，也不证明所有玩家经济策略都平衡。最终每档两次真实归返用于核实实际经营；结论不扩成无限世界定理。
