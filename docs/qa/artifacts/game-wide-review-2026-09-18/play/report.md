# 全游戏玩法独立评审 · C/D 综合判断

日期：2026-09-18。对象：冻结的正式 production，`http://127.0.0.1:3013/`，协调者登记源码 HEAD `1d7f309`。本报告只综合，未改游戏、数据或既有 A/B 记录。

## 结论

**当前最有价值的体验，是把一次小额搜获想成下一趟的生存办法。** A 中捡到「冷却的余烬」后，我开始想把它带回供奉；混乱进入「渗透」后，旁边还有一个翻堆，又发生了一次“既然就在这里，再拿一个”的选择。B 的有限预算进一步把核心修复、净化器修复、永久生命与供奉安排连了起来。这些都是实际发生的决策，值得保留。

**最妨碍这条体验的跨系统瓶颈，是选择尚不能可靠地兑现为下一趟。** 独立首玩没有形成可用的归途认知，未完成自然返回；已买生命成长在实战无收益，由独立按键与技术核对交叉确认；协调者还确认正式出行中途刷新后没有正常 UI 续局或明确弃局的通路。三者证据强度不同，但共同压在“把东西带回去，并相信这次投入”的关键位置。

**下一笔制作投入应先修复成长兑现和正式中断恢复，再做一个聚焦首次归途与遭遇理解的完整样板。** 暂不优先扩充武器数量、异物族数或更多地形。当前已有足够材料检验两趟之间是否真的出现新计划；本轮没有证据证明数量是限制因素。

整体判断：已有可辨认的玩法核心，基地交互及局内资源压力提供了有效片段；**尚不能交付“完整循环、持续构筑与长期经济已验证”的结论**。这不是把未测等同于失败，也不是用模块回归通过代替整体体验。

## 2. 作者意图与实际观察分栏记录

以下逐项分为“作者意图”与“实际观察”，避免披露后的解释替代首次理解。

### 2.1 贪婪与主动撤退

**作者意图：** vision 把“还敢不敢再多拿一点”设为主要决策。撤离 spec 希望出口成为导航锚点；现行小地图只显示局部窗口内的撤离竖缝，不提供全图或放大键。世界允许随机、错位空间，但要求局部行动因果可观察。

**实际观察：** A 在混乱 53 后仍翻了附近第三堆，这是一次真实的小贪心；其后主要问题变成“出口在哪、这片暗处能不能走”，没有形成“我知道回程大致代价，因此决定多拿”的完整博弈。按 M 没有开图符合当前合同，不判按键失效。我的局部观察没有证明出口缺失或地图不可达。

**判断：** 归途知识是核心博弈的前提。当前样本提示它可能建立得太晚或太不稳定，优先做真人连续操作的小样本验证；不能直接决定加全图箭头或泄露隐藏地图。

### 2.2 以异源污染维持净土

**作者意图：** world 的因果是不同污染互相排斥，维持边界需要外来输入；异物先参与供奉防御，再成熟为有限工具。净化点强调孤独、功能性与勉强维持。

**实际观察：** 核心零薪柴提示明确教会我“去裂隙带燃料回来”。翻堆后的余烬说明同时展示防御、成熟进度、未来技能，我产生了带回目的。B 凝滞石的 1/3 供奉进度和未来停滞效果可理解。真正的冲击、防御结算、成熟完成和下趟再使用未在独立链发生。

**判断：** 世界观已经为道具生命周期提供有辨识度的理由；首次期待已成立，等待成本与兑现快感仍缺连续证据。

### 2.3 单一预算中的短期与永久投入

**作者意图：** 薪柴在修复与成长间分配，受损模块影响下次出行；生命每级 +15 且后续出行持续生效。潮汐应缓解单向下行压力。

**实际观察：** 24 薪柴中，我花 5 修核心、10 修净化器、8 买生命，剩 1。修复预览、即时反馈和差额清楚。下一趟 Q 与武器装备正确，生命却仍 100/100；受伤后 85/100、70/100。没有实际跨越潮峰/退潮。

**判断：** 分配界面能承载选择，但生命选择没有兑现。技术组还确认薪柴亲和未接入拾取收益。应先排除这两项断线，再讨论成长“数值太弱”或修复“永远吞掉收入”。

### 2.4 可观察、可应对的威胁

**作者意图：** 污染体有稳定行为而非随机疯狂；留影玻璃需要敌人实际看见诱饵，已经确认玩家的追击不会被强行清除；旧布只拦截听觉，视觉和真实伤害仍成立。

**实际观察：** A 的低语促使我绕开膨胀地表。B 接近威胁→近战受伤→用 Q 尝试脱离→退到墙边→转身再战，空间与消耗产生联系。Q 次数和剩余时间清楚；敌人是否看见诱饵、是否改变目标未能确认。旧布始终 5 次，没有可确认的有效听觉遭遇。

**判断：** B 不能作为“诱饵无效”或“被动坏了”的证据；披露规则后，我原先把诱饵当紧急脱战工具的预期过宽。值得验证的是正常玩家能否从描述、现场行为与反馈学习这个边界。按了 Q、扣了次还不足以说明战术收益可读。

### 2.5 克制的世界与界面

**作者意图：** UI skill 要求世界留在场景中、读数安静但有层级；pixel skill 用本质、空间与世界材料限定物体身份。世界强调颜色有意义，并非把一切一律画成低饱和。用户已澄清世界观是约束，低饱和不构成本轮统一输出要求。

**实际观察：** 净化点装置旁展开选择，修复后有在场反馈，能支撑整备仪式。主菜单的空间纵深和细节明显强于实际 Rift 的几何块面，这是连续观感上的落差。Rift 中主角、危险地表、可走区域与视野遮挡的读法对本次操作造成了辨认负担。声音没有证据。

**判断：** 不建议以全面提亮、降饱和或统一套面板解决。优先让一处完整遭遇中的通行面、遮挡边、危险前兆和退路在现有世界语言中可区分；总体美术六轴裁决由独立美术专项负责。

## 3. 六领域当前判断

### G1 净化点与整备：局部可用，仪式的后半段待证

核心、净化器、供奉、成长和入口都能通过正常行走与 UI 使用。修复效果和余额对账成立；空装备位可出发，零资源不造成伪可用按钮。初见装置功能需要靠近才能确认，但在本轮没有阻断出发。未验证真实归来后连续处理、潮汐空间变化以及重复多趟操作负担。

### G2 物件与构筑：生命周期有吸引力，深度不能按数量认定

自然揭晓让未来能力与眼前负重相连；B 成熟/未成熟/守护中的区别、武器数值比较与槽位限制可用。技术清单的 10 武器共用同一撬棍攻击模式，品质主要改变数值；13 族×4 品质也不能等同于 52 种打法。独立实玩只覆盖一件自然未成熟余烬、预置凝滞石供奉、一个主动镜像、一个未确认触发的被动、白板与优良撬棍。没有宣称全部能力、品质、组合、末次消费或可持续补给通过。

### G3 潜行与战斗：已有有代价的应对，学习链不完整

低语、局部视野、危险地表与墙边战斗提供了因果片段。近战能造成耐久消耗并与受伤同场发生，不能由静帧确定杀敌数或评价连击手感。没有完成同一遭遇的绕行/诱导/交战对照，也没有确认视觉/听觉敌人的区别。下一步重点是玩家能否说出“为什么这次被发现、道具为什么有/没有帮助”。

### G4 成长与经济：选择表面明确，收益信任受损

生命失效是独立实机与 TECH-02 的交叉事实。TECH-01 亲和失效、TECH-03 保存失败未回滚来自技术核对，不能说成我亲自复现。初始混乱 0 经 TECH-06 解释为初值未同步，之后实际压力生效，不能把它并入净化器修复无效。长期物件吞吐、潮汐账单、加厚价值和稳定度节奏仍未验证。

### G5 完整循环：独立新手链缺口仍在

“获得→想带回”与“预置资源→修复/装配→实战消耗”分别有证据；“自然携回→冲击成熟→再次发挥”和“死亡→替代打法→恢复构筑”没有完成。不能把两个 context 拼成一条自然循环，也不能把协调者的全图知情路线算入我的导航学习。仅凭本次证据，我愿意继续检验一次完整归来，但尚不能给出稳定复玩欲的肯定结论。

### G6 连续运行与视听：正式恢复是高影响缺口

独立过程中暂停和恢复能够使用，面板主要键盘动作可达。TECH-07 与协调者实机证明正式 active 出行刷新后旧 bytes 保留，却没有正常 UI 继续或明确弃局路线；新纪录会替换累计进度。此问题直接损害多趟游戏的可靠性，应优先修复。音频、性能长跑、全部输入切换及连续多局稳定性不作通过结论。

协调者与美术组还各报告了连续准备后出发停滞；新 context 的相应副本可以出发，不能判成所有装备或存档必现。由于它实际截断供奉成熟后的使用验证，应与恢复问题同批保留最小历史/随机条件诊断，不能凭一次副本正常出发宣布排除。

## 4. 制作优先级与最小验证

### P0 · 兑现已支付的成长，并给在途纪录正常出口

**收益：** 保护玩家对“这次投入能改变下趟”和“可以稍后继续”的信任。生命失效已经有独立实机交叉，恢复阻断有正式入口复现，优先级高于主观打磨。

**动作边界：** 生命与亲和接入实际战斗/拾取消费方，统一 HUD、报告与保存校验；按已锁中断政策实现正常续局及明确弃局，不能用覆盖存档掩盖问题；成长/加厚存储失败事务另补回滚或可重试锁。

**成本/风险估计：** 成长接线相对低至中；完整出行恢复中至高，因为涉及库存与世界同一提交，不能只修菜单文案。具体排期由实现者估计。

**最小验证：** 相同初始条件正常 UI 买一级，对账余额、最大生命及同档节点收益；再做出行受伤/用工具/搜获→暂停→刷新→续局→归来，核对不补物、不重抽、不重复冲击。该验证优先于扩大量化样本。

### P1 · 做一次陌生玩家能理解的归途与遭遇样板

**收益：** 让“再拿一点”变成有代价但可判断的决定，减少把路线困惑误当生存压力。

**当前把握：** 单个 AI 专家两次局部重复观察，受离散输入影响，低于确认 Bug。先验证，再决定改法。

**最小实验：** 让 3–5 位未读设计的人连续操作正式首趟，不提示出口位置；记录首次明确想回去的时刻、其依据、预测归途和实际结果，观察是否能用已见信息形成路线。此样本用于找误解，不估算人群成功率。另让玩家在一个代表遭遇中尝试绕行、近战或镜像，事后复述敌人的反应。

**候选投入：** 首次看见撤离信号的学习、已走路径/路口的可辨认性、视野边界与实体障碍的区别，以及工具有效条件和结果反馈。哪一项进入生产由实验决定。保持隐藏空间和未知翻堆；不先默认全图指路。

**成本/风险估计：** 先做一处端到端样板，中等成本；直接全面重画地图或补长教程成本更高，且可能消除原本需要的未知感。

### P2 · 用真实周转检验现有道具与经济，再决定扩产

**收益：** 判断“得到—防御—成熟—使用—补充”是否能在普通成功、低收益和一次失败后持续提供选择。

**最小实验：** 在 P0 修复后，用正常正式档连续记录一次成熟后使用和一次损失后重整；保留未成熟库存、槽占用、携入消耗、带回收入与基地账单。另用同起点副本比较偏修复和偏成长两种合理选择，不强迫全清，也不预置补回消耗。到首个明确断点即可诊断，不用无限趟数凑通过。

**风险提示：** 技术模型中指定族的等待、供奉吞吐与后期裸修复成本值得关注，但模型假设理想搜获，不能直接判经济失败。数量扩张可能稀释指定族供给，新增内容前先知道替代打法是否可用。

## 5. 独立判断的保留条件

- 保留 A/B 当时的误解，不用作者设定将其抹成“本来就懂”。
- 不把生命异常、初始混乱错显、路径认知和工具用途误解合成一个“UI 不好”的大问题；它们需要不同修复与验证。
- 不把青绿地表视为一定危险或缺素材。首次误读是体验事实；技术层解释另见专项，不据颜色单独判机制。
- 本轮未测项仍未测：完整自然成功/死亡闭环、F、被动实效、全部能力等价类、满仓/超重交换、成熟耗尽后的供给、潮汐全过程、长期成长、声音及人群留存。
- 世界观为设计约束；克制、暗色或低饱和不是免除可读性验证的理由，也不是本轮要求所有后续输出遵循的单一色彩方案。

本报告的肯定是：短时搜获和基地资源选择已产生可解释的玩家动机。下一阶段要证明的，是这个动机能经由可靠归来、真实成长与有限物件周转，连续改变下一趟的行动。
