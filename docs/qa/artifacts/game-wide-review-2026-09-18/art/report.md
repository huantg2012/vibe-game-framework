# 全游戏美术复评 · A/B 观察与 C/D 对照

2026-09-18；正式静态入口 3013，协调者冻结版本 `1d7f309`。独立 AI 美术／技术美术判断；不是招募玩家测试，也不是严格零先验盲测。结论限本轮样本，不撤销旧验收，不代替整游戏循环裁决。

## 结论

**最有价值的表达，是小人物携带的一点暖光，以及把维持生存落实到身边装置的安静仪式。** 首页的构图最完整；实际游玩中，现场聚焦、投入预览与净化器真实修复的连接最有说服力。净化器 20→60 时，数值、装置发光及逸出颗粒变化共同确认投入，不应归纳成“全靠文字”。

**最弱的是可玩环境的空间／材料解释，以及它与首页的形体完成度差距。** 两段短出行里，近黑几何、均质颗粒和少量物件承担大部分世界表达；不通的边界往往需先撞到才理解。首页具体、有重量、有纵深的世界，在这些样本中变成较抽象的行动底图。限制视野确实制造孤立感，但当前可见区域本身给出的线索不够稳定，妨碍潜行路线预判，也削弱地方记忆。

**下一笔美术投入应先做一段正式路线的完整场景样板：让可见边界、材料组织、人物／敌人动作在正常尺寸共同成立，再决定扩展。** 先处理运行阻断属于技术前置；不建议先批量加物件、重画主角，或全场增亮、统一降饱和。

## 六轴归类：作品实际使用了什么语言

### 1. 空间与投影

首页是有斜俯视纵深的废墟插画；实际世界是俯视平面地面加直立小物、人物和局部等距装置。净化点交互会放大并移动真实场景，与右侧读数形成两侧构图。出行更多通过灯照范围与黑暗遮挡划出可见地面，而非可辨建筑大形解释空间。此混合成立的潜力在于“小人对大暗面”，弱点是体积与地方记忆在可玩段骤减。

### 2. 画法与细节尺度

主导语言是硬边像素簇、少量色阶和粗粝地面短线／散点。首页虽也颗粒化，却用密集细节、薄边与复杂明暗构成近写实重量。次级语言是平滑、低分量、无框排字。三者共享暗背景和小色光，但细节密度、轮廓精度与体量的衔接仍不充分。像素风本身不要求低完成度，也不要求首页与游戏逐像素相同。

### 3. 造型与材质

角色宽帽／大躯干／短腿，暖灯与持物形成记号，观感比首页人物轻巧；这不是要求更改原角色的依据。装置有罐、柜、缸、环与地裂等不同大形，玻璃缸最容易直接读材质。镜面亮边、旧布团块、石块碎面支持小物区分。供奉、成熟、品质仍主要由文字解释；这是合理分工，不能要求一个小图标独立解释所有机制。场地和青绿平矩形的材料语法明显弱于这些物件。

### 4. 色光与构图

大面积近黑托住灰褐／灰绿，中间点缀青绿和极小暖光。首页焦点最稳；据点空旷、装置疏散，打开面板后实际对象仍占有位置；Rift 的微光与大量黑暗产生脆弱感。缺口是近距对象重叠、边界缺解释，而不是“黑色太多”这一单变量。提亮一切会抹去已经有效的对比；需要局部大形、明暗组织和材质区分。

### 5. 母题与情感

共同母题为残存、容器、微光、伤口与孤立个体。首页“一个曾运转的世界留下的残骸”最强；据点开始建立“我维护这些东西”的关系，出行目前更多是抽象异域。世界观允许非人场所、陌生自然秩序，故不要求所有场景补成建筑废墟。真正需要的是每个地点可记住的组织方式，以及可观察的局部因果。

### 6. 动作、特效与时间

有限像素步态、短弧挥击、镜头聚焦、细读条、局部发光与残影共同构成克制表达。B 的实体修复和留影反证了“没有世界动作”。留影固定在施放点并与行走人物分离，物件名与效果有联系；诱敌成功未获证据。近距敌我重叠后，我能确认掉血，却不能稳定归因到一次可辨攻击；全屏压力变色可宣告阶段，但不足以承担局部受伤方向与时机。

**综合归类：低照度的硬边像素潜行／生存世界为主，高细节颗粒废墟插画与平滑克制排版为辅。情绪方向和局部记号清楚；可玩环境及压力下动作的整体完成度仍脆弱。**

## 各层裁决及必须保留的反例

- **环境：最弱层。** A15–23、B24–33 两次路线试探支持可见边界解释不足；A27–32 的直边青绿平块加剧材料层次薄弱。样本不是全地图全集，也不是新地图材料审查。不能推断每张地图都同样差。
- **角色：辨识成立，衔接待加强。** 移动后暖灯与轮廓可认；据点近景中角色遮住核心／净化器部分特征。A06、B03 可见。先调正常交互站位或构图避让，保持原角色，成本比重画低。
- **装置与物件：用途差异和状态链局部成立。** B01 展示三装置不同健康档，但不能当同一装置三态的严格对照。B02–04 只直接证明净化器严重受损 20→受损 60 的改变，未覆盖同一物件完整健康态。供奉环不能自行讲明成熟规则并非缺陷；说明正确补全规则即可。
- **界面：现场关系是强项，生产长文案仍有瑕疵。** B07–08 “普通”分裂为两行，名称、品质、效果争一行；B11–13 详细装配操作需要滚动进入视野。实际操作成功，不能写成无法装配；也不能用自动滚动后的截图声称首屏已齐。优先核对固定逻辑画布上的真实长名称、普通／成熟／守护中状态。
- **特效／战斗：已见功能性反馈，手感尚不能整体通过。** B34–36 证明 Space 短弧动作存在；B37–42 是实际敌人和玩家 100→85 的伤害结果。普通撬棍耐久始终 60，按活 spec 只在有效命中扣耐久，故本段尤其不能当成功命中、击杀或完整受击表现验收。

## C/D：意图、实际结果与技术解释分开

### 地面平矩形：排除 fallback，保留艺术与语义问题

[ground-origin-report.md](../tech/ground-origin-report.md) 确認是正式程序烤地：vegetation 角色整格着色，再经色板量化产生纯青绿矩形；占位 Tilemap 隐藏，未见贴图漏载。其运行时内部证据来自技术诊断环境，不冒称本代理在正式盲玩读取了隐藏状态。

这排除了 A 的“可能显示缺层”解释。美术方向和地表合同又把“看得见的成片青绿”分给有主占漆，并排除整格平涂。因此现象同时构成**地面材料表达不足和当前合同偏离**。它是否令普通玩家把安全地面当危险仍未验证；A 只证实评审者无法预判语义，不擅自扩为普遍误导。

### 首页衔接：意图合理，执行缺口仍存在

世界观的孤立、微光、功能性，与 A 的独立归类相合；当前 UI 设计明确要求界面让出场景，B 的修复交互也实现了这一点。世界观同时允许非人世界、非建筑组织，故 A 的“具体废墟未延续”应在最终结论中收窄为**空间具体性、材料组织和叙事重量未接续**，而非规定后续每处都画书架或墙体。历史已验收不能消除此次艺术观感，艺术观感也不自动宣布违约。

### 留影与受伤：表达存在，效果裁决受证据限制

工具合同规定留影玻璃复制施放姿态、固定位置，敌人需实际看见它，已确认玩家的追击不强制清除。B22–23 支持前两项，B42 不足以证明诱敌成功。不要因撤退时敌人未立即改追就判工具失效。近距视觉因果不足仍值得验证，但没有本段真实命中证据，就不能断言生产命中特效缺失。

### 出发停帧：独立列为技术未定项

B24 第一次正常出发后 HUD 消失、据点固定；现场未挂 console/pageerror，无法补造异常栈。原样存档已留存。技术验证初始 fixture 合法且离开事务已提交；[一次等价准备状态复核](../tech/b24-transition-review.md) 正常进入 Rift，无异常，未重演此前修复／供奉／刻入／面板历史。因此停帧仍是高影响观察，原因和复现条件未定，不归因于某件装备或“fixture 太高级”。

随后 reload 的 active 存档不能继续属于技术组已确认的恢复阻断；它不是第二次同类场景创建失败。本美术报告不重复给技术根因定级，交整合报告处理。

## 按风险排序的制作方向

### 前置：可重复进入与继续（技术）

先完成正式入口与 active 恢复的技术收口；保留 B24 历史相关停帧作为单独未定项。收益是后续长线审查不被运行中断截断。不要靠修改物件状态隐藏问题。

### 1. 可见地面的空间与材料规则（高优先，约中等成本）

收益：降低试撞导航，保护可学习的潜行规划，同时提升作品身份。先处理正式烤地整格青绿的成因，建立它与危险占漆的可辨关系；一段真实路线同时审可走面、实墙／缺失空间、地表材料和可交互小堆。

**最小实验：** 固定同一路线，在正常视野及跨 50 压力状态连续走到一次翻找和一次敌人遭遇；观察者操作前指出可前进方向与风险依据，记录预测和实际结果。保留未知区域，不用揭全图验证。以更少错误预测和更稳定材料辨识为目标，不以“更亮、更细”当结果。

风险：过多标线会把探索变成导视；过多颗粒会淹没小物；全面提亮会损失微光焦点。

### 2. 近距动作因果（高验证优先，中等制作成本，现结论暂定）

收益：让玩家看懂接近、挥击、接触、受伤、脱离，避免所有后果都落在左上数字。

**最小实验：** 同一正式敌人，分别做一次空挥、一次有效命中、一次躲开前摇、一次真实受伤；只用正常输入，保留连续片段并核对耐久／完整度。首次审看后复述“谁在何时对谁产生何种后果”，再定位具体缺失的姿态、接触点、方向或恢复段。优先调整重叠处轮廓与时序，不直接增加全屏闪光或新范围圈。

风险：过强特效遮挡后续攻击，或错误暗示击退／打断。现有小样没有证明命中特效不存在，不能先按缺失重做。

### 3. 标题—据点—出行的整体完成度（中高优先，中等成本）

收益：兑现首页吸引力，形成可记忆的可玩世界。保持原角色和已成立的光色关系，选一组跨三处重复的结构、材料边缘与尺度线索；它可以是非人自然组织，不必全为建筑。

**最小实验：** 在同一正式路线做一个完整场景候选，正常观看首页、据点、出行连续段，比较体积、材质与人物重量是否共同成立，以及能否记住路线里的某个地方。只做一套可玩的完整样板后再决定扩产。风险是用装饰填满黑暗，把统一误解为每处长得一样。

### 4. 物件与交互的局部完成度（中优先，较低成本）

先修真实长名称／品质断行与必要动作的显示，再做角色遮挡装置的常规交互站位检查。强化刻入／供奉可感知的材料动作可以是后续候选，但应先核对实际成熟和带回流程；**不得以“增加反馈”为由抹除已存在的净化器修复回应**。同一装置三态还需补齐，不能用三个不同装置代替。

最小验证使用 0／可支付两种资源、一个长名、一件未成熟与一件成熟物，键鼠各一次；在固定逻辑画布审名称、状态、下一步和退出。成本低、收益明确，不需要改整套 HUD 风格。
