## 结论边界与保留观察

1. 108 张中档证明的是这些固定生成结果的宏形与材质组织。同族有整肋、断肋、低台、薄片、厚胶与散裂端，未被统一成一个大腹轮廓；宽地与 VOID 的分隔可以并存。没有声称所有世界都必须拥有相同深湾。
2. Cleft / Sentinel 的较紧凑外轮廓是明确记录的关注项。根审复看完整图后保留，理由是阶肩、宽腹错位与低台／独柱身份仍成立，未构成矩形盘、地下城房间链或环形窄道。后续人审可再次否决。
3. Curled / Notched 的局部窄岸不依靠缩图判死。已有正式三档 20×20 身体支撑的专项证据：[Curled](../b21-attempt1/curled-south-lip-production.json)、[Notched](../b24-attempt1/notched-south-lip-production.json)。该证据只覆盖点名岸段。
4. 八样本的核心、散料、翻后残迹在所见镜头中可区分，并随环境灯光变化；未见浮起底板、空洞越界或靠整堆压暗替代后态。但远处最暗条件、陌生玩家是否自然发现、所有种子下的背景对比都未穷尽。
5. 八例 turned-away 大都仍在近身全向视野，visibility 仍为 1；Pleated 的 before 为 0.6。**不能拿这些图宣称已完成远处 1→0 遮蔽验证。** 根另有 sight-final-retry 专项证据，本页不把他人的运行结果冒充本轮亲测。
6. 本审不重跑生产、不改 src/data，不将内部无新阻断登记为用户视觉验收。
