### 已证实的行为

- HUD 无同化值、第三行同化提示、“跨趟保留”或“污染已满，同化加深”。帮助默认收起，点击展开，Enter 收起且没有增加攻击序号；右上真实入口名称为“随身”。
- 鼠标入口和 Tab 都打开正式随身。新协议 A0 仍显示完整两列两行四事实；数字、标签、基础参照为分开的节点。面板显见“世界仍在继续”。
- A0 → `0.0% / +0.0% / 基础55.0% / 基础100.0%`；A60 → `60.0% / +30.0% / 基础76.0% / 基础64.0%`；A100 → `100.0% / +50.0% / 基础90.0% / 基础40.0%`。逐项对照实际 `assimilation-system` 派生函数，未在 QA 重写公式。
- 正式新出发为 `persistent-v1`；注入污染增量后实际 P 封顶 100。打开面板期间真实模拟时钟从 5953.364ms 推进到 10969.824ms，A 从 0.0353331 到 0.0854977，显示从 `0.0%` 跨到 `0.1%`。首个 DOM 变化观察到 A=0.0501658 时已显示 `0.1%`；没有重新实现或直接触发 UI 更新来冒充场景接线。
- 同化跨精度时，列表和选中行仍是同一 DOM 对象，选中 `QA_HUD_5`，scrollTop 始终 107；列表实际 clientHeight=205、scrollHeight=312，确有六件内容和滚动压力。
- Tab 收起、Esc 收起均不打开暂停层。W/A/S/D 都收起并交回真实移动，分别移动约 12–13 world px；攻击序号未增加。独立 Esc 仍打开暂停菜单，菜单用词为“随身”。
- 备行使用真实生产路径，无身体小节。独立 catalog 使用相同生产面板及六件实际内容投影，无身体小节，End 可选末项。展开凝滞的石块真实完整说明后，内容在 377px 详情区内完整可见，无需滚动，底部操作仍可见。
- 独立生产 `RiftHud` 在 legacy/null 夹具显示“混乱 150”，不出现 `/100`；同一生产随身 null 投影隐藏身体小节，Tab 可收起。**这只证明投影兼容，未加载历史完整存档。**
- 主复验及完成的独立组件运行均为 0 page error、0 console error，来源哈希前后一致。

### 夹具、重试和原始失败分类

1. `rift-hud-polish-2026-10-19/browser-2026-10-19T03-02-02-069Z`：首次运行直接把六件物件加进 active 库存，触发完整世界检查点的交叉校验，正式保护路径停住场景。领域 add 返回成功不能证明完整在途快照合法。此轮后续输入/legacy结果无效；保留错误、截图与原始日志，不记产品 Bug。
2. `browser-2026-10-19T03-05-39-931Z`：改为只读生产面板快照中的六件实际 CSV 内容投影，**不修改库存所有权或存档**。身体/输入/时间/对比度主要范围完成。额外暂停恢复检查在开启后仅 120ms 再按 Esc，落在 `pause-menu.ts:285` 既有 200ms 防误触窗口内；脚本期望立即恢复有误。随后已有暂停层挡住 legacy 点击，使本轮最后一个组件步骤超时。这不否定已完成的库存 Esc 退出检查；不宣称正常延迟下恢复已实测。
3. `browser-2026-10-19T03-08-11-340Z`：组件页无 Phaser canvas，通用截图 helper 等待不存在的 canvas 超时；legacy150/null 断言已通过，后续未执行。已补无 canvas 的截图范围。
4. `browser-2026-10-19T03-08-58-106Z`：legacy/catalog 组件补测完成。长说明全部装入可见高度（scrollTop=0、clientHeight=scrollHeight=377），脚本错误地要求必须出现滚动而标 fail。记录事实是“完整可见、不需要滚动”，不是滚动被截断。

未再开启第三次正式新出发，未重做自然全趟或跨世界平衡。两次正式入口运行包括一次被无效夹具中断的尝试、一次限定复验；额外两次均是轻量空白文档生产组件夹具。

### 对比度与实景判断

- 新入口“随身”最低 **7.36:1**；身体 A0 与 A60 的节名、全部标签、基础参照及数值最低均为 **5.26:1**，本次取样高于 4.5:1。
- 方法：面板淡入完成后短暂停住引擎帧，截取可见文本图；只把采样文字颜色设为透明（保留布局、实际 Rift、HUD 污染层与场景渐暗），再截背景图。按 DOM Range 的文字矩形对每个背景像素计算 sRGB WCAG 对比度，前景使用实际计算后的不透明字色；取矩形内最差值。采样数据/最差坐标/RGB/配对图全部保留在主实录。这是固定场景和位置的背景取样，不是所有场景背景的保证，也不把抗锯齿边缘当作字色。
- 可见画面：身体事实在原右侧阅读区内，小字号、无新增卡片边框；实际六件列表仍有约四项可见，当前物件详情与操作保留。场景留在左侧和阅读区背后，沿原灰绿和渐暗。实景证据支持“没有出现新的后台卡片结构”；“好看 / 像游戏 / 与已锁装置同世界”的终审归人，Art 可据此复核。
