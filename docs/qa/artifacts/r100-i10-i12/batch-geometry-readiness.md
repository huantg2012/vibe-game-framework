# I10–I12 几何作者准备

本表记录制作依赖，不代表候选世界通过。B01 的连续母面、倒束、曲壳和卷皮在 3103 已获内部有限三档画面通过；B02 才开始精确作者数据。后批均保持每批最多 4 个、图审放行后再追加。旧 52、B01 及后续已过批次的共享画法不得为新卡回改。

## 当前关键路径

- **B02 / I10 第二批**：`braided-seam`、`scalloped-reach`、`offset-pan`、`thin-delta`。已有临时 CSV 和四组真实缺地多边形，使用现有 v4；核两次错颈、外湾与内陆返路、横床串联、袋路与南回环。四项断沿取已验证的 8px 宽；12px 的两项初稿超过 2048 三角预算，失败保留，不提高预算。精确 20px 身体结果另存本批报告。
- **B03 / I10 第三批**：`shard-switchback`、`hollow-wreckage`、`knotted-run`、`rolled-fragments`。设计就绪，尚无作者 CSV。短楔的三次换侧、倒伏与立壳共享裂场、三处局部扭结交路、五段卷皮弧序分别编排。扭结需由真实交接的短粗束与断尾建立主次，检查交叠是否形成完整母体；若正常视野仍只是交叉杆，则该卡返工，不能拿改名或转角作为身份。
- **B04 / I10 第四批**：`fibre-choke`、`buried-lamellae`、`pressed-rim`、`wedged-hide`。设计就绪。用现有倒束/曲唇/低母面/卷皮形成实体相接：断束夹壳、层片逐段入粒床、胶头压出双低尾、楔间撕皮。数据需写清 solid 与 relief；小路必须穿实际低段或缺口。
- **B05 / I10 第五批**：`quiet-spur`、`split-fall`、`three-shelves`、`frayed-outwash`。设计就绪。缺地塑出静长岬，短密倒片接大静床，三段壳岸围偏心庭，断纤从密根到疏尾。重点验证密短路与静长路的不同路径长度和完整身体连通，不增加装饰碰撞针。

I10 后三批不依赖短纤/孔髓新母版，可沿当前四种已修构造连续推进。精确坐标、每级身体路线和正常画面仍逐批生成，未提前填写通过结论。

## 后续九批的实现依赖

- **B06 / I11 第一批**：`short-fibre-mat`、`marrow-break`、`felt-wedges`、`pore-bank`。唯一优先的新几何能力准入批：压短纤的厚楔/不等层口，以及有坡壁和封底的真实孔髓断端。隔离草稿在 `i11-geometry-preparation/eight-directions-v2/`，64 个八向几何/身体样本、最多 270 三角、孔底最少 2 原生像素。未接生产构造枚举，未追加世界；短纤厚压团是否仍像薄折片、孔与吞光的灯下辨识均待正常视野，不能以隔离图代签。
- **B07 / I11 第二批**：`staggered-cups`、`split-tows`、`curled-flats`、`pitch-forks`。设计就绪，拟复用曲壳、倒束、卷皮和厚胶结构。四个局部嘴必须是独立可穿开的半壳关系；厚胶头的内袋必须明确封底。布局若不能兑现嘴/袋的实际轮廓，先调整该卡组织，不把四段曲唇的摆放自动称为四个空腔。
- **B08 / I11 第三批**：`grain-weld`、`silk-catch`、`resin-sleeve`、`shell-threads`。设计就绪。两缝一高一低、断肩挂皮、胶覆半壳、低壳穿断束，使用现有构造的真实材料接触。交接处检查可见内缝、足印和主体来源；半套不得靠贴色假造。
- **B09 / I11 第四批**：`chalk-divide`、`red-vault-fragments`、`blue-fault`、`pale-pressure`。设计就绪。四段厚岸三口、主弧背加倒片、单斜裂跨口、低平到密褶，均可从现有构造和显式缺地制作。长弧不得误称桥下可穿；白面不得弱化脚边或实际视野。
- **B10 / I11 第五批**：`notched-backwater`、`crossed-casings`、`fibre-stumpfield`、`sloughed-court`。设计就绪。三湾只有一条穿口、连体折壳双朝向、短粗断头偏聚、低皮剥庭带真裂伤。连体壳需重做相接/双口证明；纤桩不能只把长束沿 Z 拉高而没有粗断头读法。
- **B11 / I12 第一批**：`crushed-seam`、`husk-reef`、`fibre-scree`、`gel-rafts`。设计就绪。两低母层夹短厚片、数薄背配宽倒皮、两团反向断束、两组低脂片配各一高头。无需新材料；只在大组之间和明确端口承担路线选择。
- **B12 / I12 第二批**：`double-return`、`offset-basins`、`pinched-fan`、`spliced-reaches`。设计就绪。左右裂地双返路、两浅湾共用外床、双夹膜扇中央露床、两长床由短斜床相接。用真实地面连通和构件接触定义差别；不以相同双颈改色重复 B02。
- **B13 / I12 第三批**：`white-scarfield`、`black-lacuna`、`ochre-folds`、`violet-marrows`。前三可沿已合格画法制作；最后一项依赖 B06 孔髓。两浅床夹暗短体、偏心缺湾单厚头、三个离散折口反复返回大床、两不等横剖髓芯分别验证。
- **B14 / I12 第四批**：`fractured-estuary`、`woven-quarters`、`shell-patchwork`、`last-shelf`。除 `woven-quarters` 依赖 B06 短纤外，均可复用已有构造；双床汇颈再分、四角低毡与长束交会、壳/膜厚薄拼裂、外岸三缺余两台。最后筛查需与近邻正常路线及连续抽取证据一起判断，不能按数量保留重复卡。
