# I10 首批构造 4：作者技术合同

本批 feature 为 COH-F052，基线 d194be4c；仅首4作者定义进入候选库。其余13批由 art 集中设计，不提前加入候选或启用。旧构造1/2/3形状函数保持原样，修订5执行器另由 pipeline 封存。

本质锁：裂台是断开而仅局部回连的物质地床，要求真实缺地与厚断端，排除地板上画黑线；倒伏脊段是同向材料断件，要求粗断肩与渐细尾部，排除完整高梳背；夹壳岸是厚壳对低软层的夹挤接触，要求接触、薄尾和裸床同时成立，排除两个互不关联的彩色物件；撕底浅庭是低皮断散后的静床与短卷边，要求真实破边与稀密变化，排除两片高幕。成立范围为不等平床、错列短体、单侧厚唇、断散低皮；不引入新生物或建筑设定。

全部位于原生XY地面，Z仅受光/体积而非可攀层。20px角色、80px/s、正常肩灯/FOV保持；1024×768原生世界承载960×640观察。中尺度实体约100–260px长、35–100px宽、18–58px高，低皮/地板为2–6px高可走relief；较高、不可走体均显式solid并有完整下沿。

构造4沿用数值字段与材质族。`fracture-fan` 用少量不等宽平面片组成真实断床，`fallen-bundle` 用不等截面与渐细断束，`clamp-bank` 用宽曲面与单侧厚唇，`torn-sheet` 用二维撕口和高低卷边。配置驱动；禁止按worldId分支。材质来自实际family与逐世界appearance；外沿是实际面色，没有额外深色描圈。普通原生景物不会新增伤害或吞光对象。

参考：已锁 ash-strata 的母平面/真实剖面（不复制三块布局）；已锁 splayed-fibres 的长向受力/断束（不复制完整大束）；已锁 refined bleached-court 的局部终止与真实退缺（不复制双层长岸）。地底分别由 art 的本批appearance配置；最终以同地底正常肩灯实走判断，不以灰模或数字判断美术通过。

新增作者列 `erosion_polygons`：仅构造4允许非空。空列保持原按grade母版默认侵蚀；非空绝对XY简单多边形列表完整替换默认侵蚀。语法 `x:y;x:y;…|…`；1–12多边形，每3–32点，坐标限定地图0–1024/0–768，单片面积至少64平方像素，禁止重复点、退化边、自交、片间接触/覆盖。它表示实际缺失的地面（既有VOID与光照截止），与污染Host不同。旧52只加空列，不改旧字段或编译后的定义。
