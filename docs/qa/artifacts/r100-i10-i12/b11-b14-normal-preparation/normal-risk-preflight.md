# 后16世界正常图预审盯点

只读风险清单：48三档当前定义与原实际身体报告完全一致；6世界10低层仍为torn-sheet/fracture-fan且blocking0/H≤6。无新测试，无数据修改，不据此判失败。原坐标、精确朝向、补点、来源SHA见JSON和已有checklist。

- **B11 crushed-seam**：两片低fallen-bundle可踩母面仍可能呈长直封边；02/03必须辨中央两处真相接、04/05辨上下离断。只有物3一件裂叉，避免把整世界误读为旧六箭头。 原机位：01(500,516)→(450,420)、02(476,420)→(566,360)、03(500,540)→(585,473)、05(436,588)→(542,608)

- **B11 husk-reef**：物1/2/3/5是四个clamp实体，物4同母形低皮；看西侧三背是否读成不等残背而非等形弯盆，03低皮须有柔缓贴床关系，不能与solid同样高亮封圈。 原机位：01(484,324)→(375,325)、03(740,540)→(765,435)、04(236,492)→(335,535)

- **B11 fibre-scree**：六个fallen实体应合成两粗团，而不是六根同形单杆；低7/8只为可踩屑。01/02接触目标127/158px，若在灯外只签团界，不能宣称内部交接可读。 原机位：01(244,332)→(371,331)、02(716,588)→(716,430)、03(548,508)→(550,400)、04(756,588)→(650,608)

- **B11 gel-rafts**：六件全clamp：低1/2/4/5与高3/6必须有面积/厚薄/断尾差，不能读成同一种壳唇仅换成胶色。02/05专看薄片落床，01/04专看厚端。 原机位：01(548,332)→(439,314)、02(332,580)→(350,475)、04(780,484)→(709,565)、05(836,484)→(742,430)

- **B12 double-return**：大低fallen母床避免长黑边；物2裂肩、物3钝束、物4压楔已不同profile，普通灯下仍须能读出两个不同短断肩而非三同叉。01/02看物4短缝与真实横隙，04不能证明北颈。 原机位：01(580,628)→(515,542)、02(556,596)→(553,487)、03(604,404)→(525,331)、04(716,636)→(740,530)

- **B12 offset-basins**：两clamp实体虽同源，要靠错位开口/共享西床与不等厚唇成立，不能只两张同轮廓壳。没有低torn/fan命中；02短接与04外床仍需分别可读。 原机位：01(516,412)→(475,311)、02(508,468)→(594,404)、03(628,644)→(694,559)、04(484,500)→(392,444)

- **B12 pinched-fan**：低物1/2均torn-sheet H5/4、blocking0：重点看01/03/04是否出现长直黑边、尖角封圈或贴地三角。两高torn仅5/6，重复计数未达3但应真卷起；绿色必须从夹点内膜根露出，不能只看颗粒肩。 原机位：01(276,348)→(410,345)、02(572,556)→(572,451)、03(836,484)→(739,388)、04(876,508)→(787,447)

- **B12 spliced-reaches**：三低fallen长度550/535/410，虽不是命中profile仍防长直色带/高桥误读。01/04看长床薄边，02/03看短斜接与两实体断束；不得只靠颜色宣布已经换床。 原机位：01(388,620)→(341,522)、02(620,388)→(512,382)、03(508,468)→(615,453)、04(732,364)→(726,255)

- **B13 white-scarfield**：低物1/2均fracture-fan H5/4、长度555/570：01/04优先查跨床黑直线/大三角和等宽亮边。高3/4/5均fallen，须读成粗粒中列而非三个箭杆；02/03与大白低床面积反差才是近邻差别。 原机位：01(404,484)→(354,389)、02(436,316)→(544,314)、03(508,452)→(610,486)、04(788,548)→(814,443)

- **B13 black-lacuna**：低物1 fracture-fan H4、560×320是主要贴片风险；03/04主要看薄clamp唇与尾，不一定覆盖物1整个外沿，不能以它们代签大母床。墨紫受光材质、浅裸床与真VOID必须三者区分。 原机位：01(348,508)→(446,460)、03(852,244)→(826,349)、04(612,588)→(700,523)

- **B13 ochre-folds**：三件pleated-tear不是三torn-sheet；每件有两折片，仍需01/02/04比较轮廓，不能仅比例/转角重复。03宽床与三离散折口不同于五卷弧。原4站没有直瞄joint，使用既有near-joint补帧只证明第3件短缝。 原机位：01(444,372)→(377,289)、02(596,452)→(664,370)、03(556,452)→(641,516)、04(684,644)→(760,568)

- **B13 violet-marrows**：物3低fracture-fan H5是04的贴片/裂叉风险；完整外皮意图允许少量真切缘，但不能读成三叉板。01/02应见真实孔壁/封底和不等两芯，不把浅粉孔当绿色/VOID。 原机位：01(468,468)→(410,377)、02(676,348)→(690,455)、03(644,348)→(567,424)、04(700,348)→(729,244)

- **B14 fractured-estuary**：低物1/2/3都是fracture-fan H5/4/5，三同裂叉集中，01/02及原南床补点优先看母床汇合是否读成三块箭头拼板/长直黑缝。03/04胶肩相接须真实，不能用胶色遮母床问题。 原机位：01(292,228)→(400,238)、02(500,316)→(572,396)、03(556,372)→(593,271)、04(748,564)→(662,499)

- **B14 woven-quarters**：低1/3/4与高2均compressed-wedge，须辨唯一厚毡与大片可踩短纤，5/6长束不能只是另一色相同粗块。当前组织仍short-fibre，未切short-fibre-loose；旧源拒绝记录不能由另外两世界新源通过继承。 原机位：01(468,372)→(400,289)、02(652,332)→(558,282)、03(644,636)→(573,554)、04(772,452)→(780,560)

- **B14 last-shelf**：低1fallen 540×450占主面积，03仍防大硬板；物2仅一短fracture、物3完整压楔应有断端差。02物3真缝不能由01亮裂肩替代，04只证下台，上外沿依原948,268补点。 原机位：01(764,348)→(786,242)、02(724,532)→(817,476)、03(756,308)→(684,388)、04(820,564)→(922,532)
