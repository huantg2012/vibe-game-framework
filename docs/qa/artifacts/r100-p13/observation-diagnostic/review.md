# 重档观察位置与铜铃落点：六个固定地图的只读诊断

范围：当前revision3的灰层、纤维、壳体，20261004／20261005，未改生产。`report.json`保存签名、坐标、时间、身体路径及源码SHA；壳05签名7fe1508e与手动实际身份相同。分析使用生成后已知深区位置，不传给真实游玩策略挑隐藏奖励。

六图共24个深处残骸均找到“未警觉巡路某一时刻，能够站在身体合法的干燥地面观察至少一名邻近守卫，且能向侧方投出可被其听见的铜铃”的几何候选。该结果反驳“所有深区根本没有任何合法观察位／声诱落点”的强断言；不证明玩家实际接近时仍未惊动，也不证明声诱已制造搜索窗口。不能把CPU候选写成24次成功潜行。

实际检查：8px身体图、20px身体、准确多边形位移；正式VOID视线；正式96px投掷落点；正式按物理地面连通传播的声路和遮挡衰减。观察位用16px采样、距一个干搜索站位48—192px身体路径、至所有敌人>40px、肩灯半径90%内可见且不处于其视锥。时间从出生起按正式巡速／转向／到点暂停模拟，500ms采样，最长60s；排除了比出生以80px/s走到该位置加1秒更早的候选。铜铃投16种方向，落点须比目标守卫距残骸更远至少32px。

限制：不模拟玩家抵达观察位沿途的声音和警戒，不证明持续观察安全；邻近守卫之一听到不等于所有守卫同时离开；不模拟声诱后追踪、搜索96px噪声、受击和撤离；0.9灯半径是保守空间筛选，不替代真实像素可见度。坐标是开发诊断，不能给已声称只看画面的手动玩家提供未探索路线。

实景另见壳B033—039：玩家已经被跟随时走进西北残骸袋、停下尝试近战，四名敌人聚拢；其后原东侧／南侧能撤出。这里可确认错误接近会被包围，但不能确认未警觉时四名敌人永久守袋。壳A的成长复核沿已见东路带回深区污染物，进一步说明原死亡含走入死路的成本。当前没有足够依据因此削减敌人数、赠生命或改冻结地图。

铜铃的实际语义：它不抹掉CHASE、受伤或战斗高优先声。改写体听距150，移动mult2作用于感知增长速率，绝不是300px听距；当其感知≥0.70且持续听到玩家移动，听觉警戒分支先于铜铃的怀疑级脉冲。铜铃每秒重发一次，所以“尚未CHASE”也不保证能边跑边稳定引开。应在未被锁定、可见合法侧向落点下记录转头／走离和利用空隙的真实动作；只扣次、最后靠近战取胜均不能替代这一证据。

设计裁决：保持现地图与追逐危险，本批不凭失败后敌群汇聚盲改。生成目前只验证2.4秒干搜索站位，尚未保证观察—接近—搜取全过程，这是真实已知覆盖边界；本次六图有几何候选，未证明“确无机会”的新部署阻断。若正确时机的固定真实复核仍失败，下一步定向检查该处的非主守卫巡路端点、观察位到搜索位暴露和声诱侧路；避免将四敌直接缩为两敌或把声诱改成清除追逐。
