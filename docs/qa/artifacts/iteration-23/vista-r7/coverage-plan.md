## 五条用户反馈的证据分工

1. 惨白/缺重量：正常角色镜头记录主干、薄鞍、根侧沉积、断面；给art比较明暗/色彩重量和足下辨认。可读不以整体压黑、亮度阈值或贴图数量判定。
2. 中景画风不同：同帧核前/中/远片层、束及受力转折，局部动作接点沿周期可追踪；运行分层/资源检查不替代同一画法判断。
3. 白云不合基调：以world.md残骸仍运转、黑暗底色与危险美感为语境，DEC145允许陌生自然而非晴空仙境；新远景实帧核无日轮/天气积云等旧意象。不能把一切气体都判禁用或编正史。
4. 网状与立体空间：新合同至少6个大小形状不均真孔、分叉合流、多独立环；code提供outline/holes/regions/connector与route CSV，ROOT确认精确数量/图关系/路线。按连通图核components=1、cycle rank及junction数，按实际孔多边形面积比辅助核不等尺寸；几何数值不代表自然视觉。上下层遮挡不冒称双层均可走。
5. 模型/地形同体系：实际高度支持、主干截面与变细、薄鞍/断裂/沉积的可见接续；根部碰撞和绕行保持。图、脚底和真实路线共同证明，不以面数增加替代内容。

## 控制证据大小

- initialGeometry只保存一次，initialState保存一次静态合同/渲染背景说明。
- 普通采样只存player位置/足点/支持/速度/投影，镜头位置，实际局部形变/相位、音频时钟/空间参数、渲染计数；不再携带每帧长说明、材料配置或地图数组。
- 输入前后只记[x,y,height]，不重复完整player结构。
- 相同检查归并为规则与samples/failed；失败保留完整标签、时刻及细节，另存assertions总数。结果minified JSON，仍有可读摘要与README。
- 原帧/视频/被动实际音轨保留，声音输出证据不等于Agent有听觉。
