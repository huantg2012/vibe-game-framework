建议routeNodes为{id,x,y,region?}[]、recommendedRoute为节点ID[]，每两个相邻节点有足够身体宽度的直达走线；全路覆盖6连接且返回出生。connectors给nodeIds或实际端点；boundary/obstacle测试给安全接近节点及方向，避免QA凭空构造路线。
