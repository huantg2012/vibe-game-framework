## 明确未验证项与失败说明

1. **真实失焦未验证。** 开始即关闭Playwright默认forced-focus，实际最小化浏览器窗口后document.hasFocus仍true、hidden仍false。没有注入blur/focus事件冒充系统失焦，未将继续移动判为产品Bug。
2. **CDP销毁观测失败。** 完整路线后实际reload与导航about:blank已执行，但CDP没有发送contextWillBeDestroyed。观察目标随导航撤销，缺事件不能证明close没发生或证明close已完成；保留原断言失败和事件明细。ROOT接管单独短close观察，若有补证由其文档引用，不覆盖本次evidence。
3. **后续CUA尝试中断。** 仅调用`cua.getApp("Finder")`请求激活API，工具未返回并在459.4秒后被ROOT中断；尚未执行Finder激活、短测Chrome或任何产品操作。按ROOT要求不再重试CUA、不做第三轮失焦，不新增补测成功记录。
4. **声音未审听、视觉未人审。** 录音已真实留存；本会话不具备音频感知能力。原型方向认可不能转写为R4成品认可。
5. 没有Firefox/Safari、长期内存泄漏或独立GPU基准；没有用本样场证明正式搜撤、战术视野、收益、伤害或持续供给。
