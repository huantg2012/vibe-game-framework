## 方法与实测

服务器为关闭 HMR 的 `http://127.0.0.1:3046`。真实 Chrome，原生 960×640，固定正常有限视野，不改曝光、不移除敌人、不禁用伤害、不替换碰撞规则。种子固定 `20261002`。

每个受测方向先重建场景，选择通过 `bodyHasSupport(grid, point, 10, 10)` 的起点，再以真实键盘选定朝向。开始测量前仅用已有 DEV 接口放回该合法起点；之后持续按键约 1.8 秒，每 150ms 记录一次身体支持、位置、速度、碰撞标志、生命和敌人状态。此方法证明局部接近行为，**不是从出生点自然走完整趟的证明**。

- 第一批：折板三档×8方向，其余六个构造／等级×4方向，共48项。43项存在所测64px偏移起点；其中40项最终停止，3项受阻后沿边滑动。所有43项发生碰撞标志，516个采样均有完整身体支持。
- 第二批：将5个缺失方向改用40px起点重试，并补折板三档的东南／西南近照。纤维中污染东侧补测成功，实际移动18px后停止。六个折板近侧斜向实际移动20–26px后停止；84个采样均有完整身体支持，7项均HP100。
- 合计：44个独立方向，另有6次近照重复方向；共50次按键接近、600个采样。所有受测目标边界在接近前的原生可见度查询均为1。这证明边界在视野里，**不自动证明美术可读性通过**。
- 3项沿边滑动：折板低污染西北、重污染东北、重污染西北。没有把“某轴受阻但仍沿边行走”谎称为完全停止。
- 4项仍未覆盖：折板重污染正西、纤维低污染正东、纤维重污染正东、厚壳重污染正北。在所测64px／40px固定方向直线起点下，未找到不先接触VOID的合法接近方式。**这是测试站位缺失，不是整个方向无路的证明。**
- 4项存在战斗干扰：折板低污染东北、折板重污染正东／东北、厚壳低污染正北，HP100→85。原始状态与图片保留；不将其截图当成没有敌人影响的纯材质实验。

低污染折板、纤维、厚壳的第一个构造为可通行低矮表面，本次物理边界测试选择各图第一个真正标为 `solid` 的对象；没有把可行走表面误判成应阻挡的实体。

近照采集首轮遇到 Playwright 的元素稳定等待超时，随后改为按读取到的固定960×640画布边界截图重跑。没有改动游戏或暂停模拟；最终两批完整输出均无页面错误。
