# C 阶段：作者意图与范围披露

本材料仅在 A/B 记录封存后提供。它是项目现行文档的意图摘录，不是体验结论；不得据此改写首次接触记录。历史评价、旧截图和既有检查结果不在本披露包内。

## 作品意图

世界已经被外来规律改写，玩家是在维持自身与微小净化点的存续。裂隙连接不同的被改写时空；取景可以来自自然、陌生生命、非人文明或不同物质状态，不必像人类建筑。原生秩序与后来覆盖它的外来规律，在设计上应有区别。陌生不应消除局部行动的可理解因果。

世界生成的长期意图是：先产生具有物质、形成过程、空间组织、改写规律与表现方式的世界配方，再在其中产生可玩的地图。世界间可以有可预测的倾向和罕见组合；更换色板或种子不自动等于不同世界。该完整系统仍为提案。

## 当前被审版本的范围

本入口是独立可移动地图与材料样板，没有接入正式敌人、资源交互、风险收益、撤离结算及存档。它用于检查空间、材料与受限视野下的行走体验，不能代替完整游戏出行循环。正式游戏的存在不证明这些新地图已经适配正式机制。

当前希望表达：连续开放的承重地面，局部空间侵蚀造成空洞；多方向绕行与地面变化应帮助构成可探索的空间。三个具名世界和两种空间选项是数据示例，不是最终目录上限。

## 视觉与行动约束

- 保留正式玩家角色造型与基础移动。环境画法可以探索，不以旧项目锁色或旧画法作为本次及格线。
- 黑色障碍是缺失空间，不可行走、不可被照亮，并遮断视线。黑色内部没有需要表现的石头顶面或洞壁。
- 可见的片状、晶化、沉积和釉壳形体目前均是可跨越的低矮地表结构，不具有新实体障碍的语义。
- 材料希望通过底材、覆盖、磨损露底、接触关系、沉积与局部形体构成；宏观区块、中尺度结构、细部应有层次与静区。
- 受限视野是正式玩法的重要条件。当前入口只复用了部分正式视野计算；正式光照与角色方向处理尚未全部对齐。具体实现与差异在 D 阶段核实。
- 一切改进应成为跨配方、跨空间和跨种子的系统能力，不接受只修一张截图或为具名世界编写专属补丁。
