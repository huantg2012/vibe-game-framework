# QA：原生空间生成的结构性求解审查

日期：2026-10-14。范围：只读代码、有效 spec / 设计和已有收据；本审查没有运行地图、局部算子、fresh 或其它重型测试，没有修改 src/data。

依据为 `docs/specs/system-map-generation.md`「原生联合生成」及 `docs/design-notes/world-fragment-native-generation-2026-10-13.md` §4–6、§9.5–9.6。后续完整地图仍由原 G1–G4、身体/身份/面积和部署合同验收，55% 等阈值不变。

**当前不是旧成图之后追加物件：L/B/H/S 确实最终一次合编，内容也尚未部署。但其求解过程仍明显分层：先决定 L/B，再在固定地面上贪心放置 H/S，之后只调整 H/S 位置。批准设计中的全部变量共同受反馈约束，尚未实现。**

以下最多三项。代码缺口与它们是否足以解释全部失败分开；没有将有限搜索失败认定为合同数学无解。

## 1. 宽地面积已进入约束分数，但实际宽地反馈没有进入这一分数

**性质：确定的反馈缺口；优先做最小修正验证。**

`native-spatial-wide-domain.ts` 的 `measure/evaluate` 已返回真实 8px VOID 平移掩码下的 `wideCount` 与 `largestWideRatio`。但 `native-spatial-layout.ts:123` 只消费后者，面积项仍由 16px raw 场点比例加上一个原图常数校正生成。单物件回调也只返回 `largestWideRatio`。因此，移动后海岸/孔边缘之间 48px 禁宽带的交叠变化，精评分仍可能被旧 raw 近似误排；有实际格数却没有用到。

另一个方向遗漏是 G3-only 状态仍选择 `worstEmptyPoint` 或 `worstDeepPoint`：layout 的 witness 选择只有 empty/deep，joint 在 `native-spatial-joint-refinement.ts:195` 取离该点最近的三件，并向该点移动。G3-only 的“该释放哪块宽地”不等同于“该给最大空白再补一个物件”。这不是说任何这类移动都不能提高宽地比例，而是尚无对应 G3 面积缺口的因果目标。

已有最近反例为历史 c27：G1 最大空白 157.9723、deep 336 通过；独立正式 G2 也通过，只有实际 wide **0.5405753542292829 < 0.55** 失败。此状态已不需要继续以修复 G1 为主目的。本审查没有运行一次新 c27 refinement，因此尚不能给出新方法改善率。

### 最小正确接线

先复用现有 single scan，**不必新增 witnessKind，也不扩候选集**：

- 将 `siteFor` 的回调由单个 largest ratio 改为一次返回 `wideCount/largestWideRatio`；同一精评只调用一次宽域测量。`completePlanningScore` 采用相同口径。
- 有实际缓存时，精评分的面积预测使用 `wideCount / base.supportedBodySeats`，停止对此项叠加 raw16 常数修正。raw16 可以继续承担现有粗排及独立诊断。无缓存的 fresh 仍保留“未证实”，不伪造实际宽域结果。
- 基准 supported count 必须为该缓存来源几何的正整数；先核对原位预测与原实际比例一致。c27 的基准为 **18,632**，应对应 **10,072** 个 wide centres，比值精确回到 **0.5405753542292829**。这里的格数是由保存的实际比例/分母得到的预期，尚未在本审查中重新构造 cache 测量。
- 这是**固定身体分母的平移预测**，不是最终身体域比例的证明。整物件、8px 相位及 72px 对象间隔使相互阻挡面积一般保持分离；但 raw 岸距 24px 不保证受伤后的实际岸线及 20px 身体侵蚀始终不重叠。先前 c3 的 raw 24→actual 14.34 反例已说明这一限制，不能断言所有移动的 supported count 恒定。最终重新断缘后仍必须用新真实分母验门。若要求预测本身也精确统计移动身体域，须另维护身体占用计数，这超出上述最小接线。

**一次可证伪测试（未执行）：** 固定已保存 c27、计数、形体、land/B、seed 和现有 single 候选生成方式，只替换完整精评分的 wide 面积项。先核对原位 count；执行一轮原 single scan（每物件至多 12 精评，不是整轮共 12），最终只真实重编所选完整结果一次。报告实际 G1/G3、G2及 supported count 变化。若预测改善未转化为实际 wide 改善，或把已过 G1 改坏，则不能宣称此接线解决 c27；不借失败扩大位移域或降低 55%。

## 2. L/B 的选择目标没有覆盖和宽地容量，且进入局部求解后不可调整

**性质：确定的联合求解范围遗漏；是否导致某个 land 无解尚未证明。**

证据：

- `native-spatial-land.ts:58`–`60` 仅从母体粗面积、H/S 计数、固定损耗和 B 估计产生 land 面积目标；实际 H/S 形体及站点此时尚未加入评分。
- land 的 core 排名（`:112`）和 shoulder 排名（`:143`）主要是新增面积偏差、保留既有岸线和少量随机扰动。没有 G1 的 H/S 覆盖能力、可放置完整对象的站位容量或 G3 的 48px 宽地消耗项。
- `createNativeSpatialLayout` 先得到 land / joins / B / ground，再放对象；reuse 分支直接复制 `previous.layout.plan.land/landPlates/bays/landJoins`，单移位和双移位只改 `objects[index].site`。因此，失败反馈不可能把一块不合适的肩部重新接合、调整岸湾落点或重新分配该计划的宽面。

G1 特意不把海岸/B 算作结构，要求沿岸地面也接近 H/S；G3 同时因同一岸线消耗 48px 宽地边带。保留更多凹凸岸段、再靠对象覆盖每段岸边，会同时消耗对象容量和宽地面积。这是必须在 land 选择阶段看见的负担，面积相同并不代表可布置性相同。

新 fresh 确实能重新抽 land，但这是整份重采样，不能代替同一未完成计划内的 land↔H/S 反馈。批准 §6.2–6.3 明确把板片、内孔、实体一起置于约束状态，并允许重排板片；当前局部状态只实现了其中 H/S 平移。

**最小方向：** 不先加入更多对象或搜索次数。先让 fresh 的现有 land 选项接收完整 H/S roster 的粗可放置/宽地负担反馈，至少保留一个可以替换原选择的有限 land 备选；或以一项有界板片调整替代一次既有 H/S refinement。两者择一验证，不能一起改后把改善归给“联合”。正式面积窗、板片范围、320px 搭接、B 身份和全部 G 门保留。

**一次可证伪测试（未执行）：** 在同一个保存失败计划上冻结 H/S roster、形体、计数及预算，只对一个已授权范围内的 core/shoulder 搭接选项作预先登记的二选一对照；两版均使用同一对象分配规则及每件 12 精评上限。真实重编后比较 G1/G3、身体面积和轮廓合同。若改善只来自越过面积窗、制造窄道或放宽门，则假设未得到支持；两版均无改善也不能推出所有板片安排无解。

## 3. 初始 placement 只为已放前缀优化全图，未给剩余形体保留可行站位

**性质：确定的初始化策略缺口；有晚件域收缩证据，但不是已证明的数量不可行。**

代码先把母体加入 objects，随后将 H 与从属 S 随机混排。全部形体虽然已产生，`for i ... siteFor(object, ground, placed, ...)` 评分只看到当前 object 与 `placed` 前缀；剩余对象没有暂定站点、占位或容量约束。全域最大空白/deep 最终目标却已用于这一不完整前缀。于是先放几件时，“未来会由其它对象承担的地区”也被当成当前几件必须解决的最大缺口；早期中心化布置和 relief 保护可能压缩晚到大孔的合法域。

已有固定 c3 证据：最后一件是 224×136 的大孔；在 L−B 完整地面支撑下，同一有限 field 有 **3,727** 个合法站点，加入前 14 件、间距和 relief 后只剩 **13**。原 185 个随机/邻位候选恰好没采中；这是当时已经确认并修好的直接漏采原因，不能改写成“14 件把空间完全占满”。资格修正后的同一前缀最终得到 10H5S，但实际 max **251.258**、deep **696**、wide **0.534375** 仍失败。剩余小口能放下最后一件，并不意味着这份前缀能覆盖全图。

**最小方向：** 先在原有限站点域里给未放的大 footprint 保留合法站位，或用可行域大小/完整支撑 footprint 决定初始分配次序；只替换一次原前缀贪心选择。不要把新增几千随机点或第 13 个精评当作解决方案。完整图放齐后再比较最终 G1/G3，保留母体完整、H/S 比例和每物件原预算。

**一次可证伪测试（未执行）：** 冻结保存 c3 的 land/B 和已采出的所有形体，登记唯一一次“受约束大形体先分配、保留同一有限站点域”的初始化对照。记录每件放置后剩余物件的合法站位数，并以相同每件 12 精评预算完成图，最后真实验门。若只是晚件可放而全域 G1/G3 未改善，则只能证明避免放置饥饿，不能声称解开生成问题。

## 不成立的推论与下一步顺序

六次或后续 fresh 的零完整通过，只证明当前策略尚未找到完整结果，不证明现有数值不相容。历史 c27 已提供 G1/G2 同时通过、G3 仅差约 0.9425 个百分点的真实几何；这不足以证明联合可行，也不足以支持直接下调 55%。

建议先做第 1 项可隔离的小接线实验；其结果作为第 2/3 项联合初始化方案的证据。当前不再机械扩展 c39 的双移位次数、位移档位或第三件物体。本报告也没有认定某个边角数学上必然无法覆盖；证明那一点需要该固定形体/站位域的不可行证据，而不是多次未搜到。
