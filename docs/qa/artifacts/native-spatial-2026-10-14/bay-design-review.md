# B 岸湾缺项：联合构造合同根审

> 2026-10-14 · Design 独立静态审查。关联 COH-F011 / F007 / F013 / F052，DEC-208 / DEC-209。仅此报告变更；未改 src、CSV、主 spec，未运行或中断正式生成。以下是给 Director / Code 的可执行修正建议，新增数值明确属于首轮校准域，不能冒称已经批准或实测通过。

**结论：先补齐原合同已经定义的 B 原生外岸负空间，再检验厚板域是否足以表达认可构型。不能继续把“正向大板排列”当成参考的完整生成机制，也不能把一次 B 切口当成已解决所有外形问题。** B 属于宏观岸线组织，H 属于内部信息分隔，两种身份从采样开始分开；B 不替代 H 数量、G1 结构覆盖或 G2 掩护站位。

## 2. 修正边界与两个层次

**本次最小实施：** 保留当前 4–7 厚板、尺寸域、320 搭接、H/S 数对、目标身体面积和所有 G 门，增加独立 B 语法与来源，并让它参与整份候选的面积预估、合法站位、布尔、重排和冻结。B 的采样位置利用真实外露岸链及肩部，不在已有完整部署之后切地。

**需要留住的第二层风险：** 即使有 B，单一厚板尺寸层也可能继续读成整板加槽。如果有 B 的代表候选仍被 Art 判厚板，下一步应显式分层正向土地作者 profile，而不是第三、第四轮盲增 B 数量/深度。见 §8。此层尚未授权修改 CSV，不暗中实施。

不改：G1 的 160/112/448，G2 的真实 H 见证及 320 行走覆盖，G3 的 48/55%/80% 和实际路径窄段，H:S、唯一母体、撤离规则、内容配额、预算、旧修订恢复与失败关闭。

## 3. B 的独立身份、空间角色与测量口径

每个 B 在 fresh plan 内即有 `bayId、profileId、sourceShore、rects`。`sourceShore` 是**当前正向土地并集的一段连续外露岸链及朝外方向**，可跨一处阶肩，不是固定地图右边或固定四边槽位。ID 不能从最终“某孔失败了”反推。

一个 B 是从这段外岸向内缺失的 1–3 个轴向重叠负矩形；允许一片，参考本身就是一片。矩形的联合应向同一局部岸段开口，后续片可使内端或一侧错台，不做等宽长管、交叉隧道和末端膨大的房间。仍使用共享 `fragment-shape-v1` 断缘。多矩形只是形体，不刷 B 数。

最终 B 必须同时满足：

1. 真正删去一块正向土地，且该删去域通过真实 VOID 接外海；全在外海中的矩形没有 B 成果。
2. 有保留下来的足够宽的外海开口，不能靠一个 8px 格或一次对角接触取得“通海”名义。建议首轮要求实际 VOID 通路具有 **64px 最窄厚度**，仅作 B 身份的稳定性验证，不进入 H 有效性或 G2。
3. 来源及最终身份不变：预定 H 触海、与 B 相接或被 B 消掉，仍是 H 资格失败，拒绝完整候选；不能改名 B。预定 B 被封成闭孔，也拒绝；不能赠送一个 H。
4. 它只属于外海的一段局部岸湾；最终外海全部连成一个分量**不意味着所有 B 合为一个对象**。两份 B 只有在正向土地内部删去域相接、成为同一局部开口构造时才合并核对；若与计划身份不符则拒绝，不用两个 source ID 拆计同一槽。
5. 纯正向搭接自然形成的凹岸可记录为外形诊断，不伪装成一个作者负矩形 B。普通外海、自然凹岸和 B 对 G1/G2 都没有抵扣权。

**B 面积**记录 `area(union(B rects) ∩ union(land rects))`，以及断缘后实际变化范围的测量。前者是精确原始删地成本，不把伸进外海的空白面积算“强烈破坏”。最终归属不得取整个 exterior label 的包围盒/面积；须以原始 B 身份及已知断缘影响包络定位其局部地内 VOID，再验证与外海的连通、开口与跨度。若同一局部细节不能确定归属，记失败/不确定，不能拿整片外海给 B 制造厚度或面积。

G1 的最近结构仍只构建通过资格的 H/S；G2 的 q 集仍仅归于 H。B 的 LOS 遮挡正常存在于真实世界和单 H 消融对照中，因此一个其实由 B 挡住的 q→t 不能计作 H 见证。G3 的真实 VOID、身体连通、宽面和窄段测量自然包含 B。G4 可单列 B 遇见诊断，但 B 不进入 H/S 分子分母。

## 4. 最少需要增加的冻结输入

建议新增一份 `rift-native-spatial-bay-profiles.csv`，与既有五表同向 codegen，进入总 sourceHash；恢复从 recipe 读取，不读今日 CSV。新增字段不能仅藏在运行时代码常数或按 worldId 分支。

世界输入增加：

- `bay_grammar`：明确的语法名，例如 `shore-rect-cut-v1`。
- `bay_profile_ids`：可用 profile ID 列表，首轮五图可共享一个，但必须显式引用。
- `bay_count_options`：首轮有限域 `0|1|2`。这是搜索能力上限，不是“每图必须挖两口”的配额。0 是保留正向构型能力及本轮因果对照；不能让 0 的旧厚板自动获得 Art 通过。

B profile 至少冻结：`id、min/max_rect_count、min/max_depth_px、min/max_mouth_px、min/max_offset_ratio、min/max_overlap_ratio、max_union_span_px、min/max_removed_land_area_px2、min_final_throat_px、min_backland_px`。

首轮可实施采样域，**均为待校准假设，不是参考给出的普适门限**：

- 1–3 片；内切深度 128–480 px；朝源岸法向测量，实际包含在正向土地内的深度才有效。
- 口部投影宽度 96–192 px；跨阶岸的开口按其局部岸链投影测量，不要求岸链是一根直线。最终 64px VOID 通路保护与原始口宽是两个量。
- 后续片的接合方向重叠比例 0.35–0.80，横向错移比例 0.15–0.45；使用方向分支而非每片同号同位移。整体允许只一片，无需为矩形数量凑枝。
- 整个负矩形组跨度上限 576 px（包含有限伸海外段）；删去正向土地的面积 8,192–61,440 px²。上下限用来排除微耳/整侧刨空，不借一个任意总面积百分比承诺美术成立。参考 22,400 px² 落在此域。
- 后方厚面预留 320 px，见下节。它继承既有宽搭接尺度；不是把 H/S 间距偷偷扩大为 320。

配方/布局结果另冻结派生 provenance：每份 B 的源岸坐标/外法向、矩形组、实际删地范围、最终局部 VOID 对应、断缘 seed；原始 land/H/S 与 B 的身份分别保存。源岸不是世界 ID 隐藏偏好。新增语法应显式版本化，不能让同名算法/版本对相同冻结输入产生另一种世界；Code 决定未发布 r12 的精确版本升级方式，旧 r11 闭包绝不补字段升级。

## 5. 共同预算与宽面保护

数量 N0 仍只由固定 `A_target` 和 s 得到 H/S 数对。B 既不减少 N0，也不消费 H 配额。每次完整 plan 从起点选择 `(H,S,B)`；B 的数目、profile、源岸和形体与正板、母体一起承担真实几何预算。

正向土地粗面积目标需要显式容纳预估 B 删地量，不允许切完湾再把 A_target 改小。实际身体面积仍须通过原 ±10% 门；不能用 B 删除空白热点、缩小分母而保留同一残缺成品。目标面积预估只是采样器引导，实际最终面积从身体域量。

每份 B 同时付出：

- 真正删掉的地面面积；
- 1–3 个共享 128 矩形预算；
- 自由断缘顶点及 recipe 容量；
- 占用一处岸段及其内侧空间，可能迫使 H、母体或地板共同换位；
- G3 的宽核损失、路线变化和原内容部署的真实代价。

不另外设置“B 越多/越深得分越高”。在通过同一组硬门的提案中，较少重复切口、较少删地和较低剩余代价可用于稳定平局；不能以此压过外形辨识。无 Art 合格构型库时，求解器不能自行宣布最省 B 的厚板已经艺术合格。

宽面保护分两层：

1. **提案层的局部实体关系。** 为厚板附着记录确实 ≥320×320 的连接区域，B 不穿过这些主宽搭接。对 B 内端沿其入射方向，检查在 `union(land) − union(B)` 中到对面外海仍留至少 320px 连续地面；这里暂不把 H/S 当作地板外岸，否则会和 G1 所需的近邻结构产生矛盾。这是避免切穿主体、切出细条的提案约束，不证明最终通路已经宽。
2. **最终真实场景。** 仍重算完整 20px 身体、单主体可达域、G1/G2/G3、物件及 attached relief 的真实支撑。H/S 与 B 共同造成的局部窄颈由最终 G3 和真实路线检验，不能由前项“留了 320”代验。最终板片变成细颈房间串或机械梳齿时，Art 仍拒绝。

选择源岸优先看“偏置肩旁的长连续岸被哪一个局部缺失打断”，而非离几何 G1 最坏点最近就切哪里。可以将待切岸长、肩部交接和重复方向作为诊断/提案排序；不把未校准的 bbox 填充率或四向湾数量升为新硬门。禁止固定两侧对称切口、每一板一个槽、每次出生对面一个湾。

## 6. 有限、确定性的求解接入

1. Fresh plan 同时冻结 H/S 数对、B 个数、各形体 profile 与全部随机子流。首轮给 0/1/2 的完整构型各分配明确且有限的初始提案机会，不能因为 B=0 先得到一个数值最好值，就从未生成过有 B 的构型。
2. 在同一未完成约束状态中建立正板及 B 岸链/负矩形，计算净地床 `L0=union(land)−union(B)`；母体、H、从属的规划支撑和 shoreline distance 都消费 L0，而不是继续把 B 位置视作完整土地。B 没有 H/S 的 coverage primitive。
3. 原 H/S 类型数量在对象落点之前已经决定。对 B/正板做局部变换时，允许其他组在该完整 plan 中同步重新安排；不保留母体/孔的旧绝对坐标作为永久禁区。任何一次重测仍计入原预算。
4. 一次共享布尔编译所有 land/B/H，再测真实 identity、profile、面积、G1–G3；通过后才定出撤并完整部署、运行 G4。不能先生成、部署，再“雕岸收尾”。
5. 失败归因区分 `bay-no-source-shore、bay-no-real-land-loss、bay-sealed、bay-mouth-too-thin、bay-cut-wide-join、bay-profile-size、H-connected-to-exterior、area/G1/G2/G3`。不能将这些失败统一吞成“无合法站位”，更不能将 H-connected-to-exterior 移出孔失败列表。
6. 仍每 attempt ≤72 次真实轻量评价、≤2 次完整部署，外层8次/60秒失败关闭。新增 B 分支和调整不另开隐藏预算，不烘焙每次中间图；时间不参与候选择优。所有平局用稳定身份/位置排序，奖励、敌人流独立。

当前 best-first archive 的下一阶段 refinement 应保存整份 land/B/H/S plan；B 数/profile/源岸的变化属于新完整构型分支，不能把旧 gate 与新 plan 错配。支持在明确的新 proposal 内改一处 B 并联动重排，但不得把旧 H 的失败几何改标签重用。

## 7. 最小验收证据和反例

正式候选前先做独立几何夹具：

- 同一凹口真实连海时是 B；封口后是失败，不变 H；计划 H 连海也失败，不变 B。
- 一组矩形全部伸在海上，实际删地为零，应拒绝；不能从 rect 面积误报。
- 两个独立 B 经外海相通仍保留各自局部来源；二者在土地内并成一个槽时不能拆成两份贡献。
- 通海仅靠 8px 或对角接触应拒绝；共享断缘封口/缩口会被最终几何发现。
- B 在离结构很远的边上真实存在，G1 最近结构距离仍不将 B 当近邻；G2 单 H 消融不得借 B 冒领见证。
- 正向地板完整但 B 切断宽搭接/生成长窄条，即使剩余身体可通，也不通过相应保护或最终 G3。
- B 改变后关联 relief 支撑、H final profile、唯一母体和完整内容全部重验；不能缩减配额过关。
- B+H+land 达到容量边界、超限与冻结后改 CSV，分别验证明确拒绝和精确恢复。

首轮源稳定诊断须成套保留**同一 seed 和 H/S 数对**的 0/1/2 B 完整提案，包括无合法源岸及布局失败，报告 `positiveArea、B 原始/实际删地、B口宽/厚面、最终 bodyArea、G1/G2/G3、H/S/B 身份表`。这组只隔离 B 作用，不是生产选择最漂亮种子的理由。Art 同时看去除内孔/实体后的真实外轮廓与完整剪影，避免内孔密度掩盖整板问题。

若有 B 的几何准入图可得，才进入正式全量部署、正常材质和 G5 动态对照。B 的几何可行不等于敌人潜行通过，更不等于全库推广通过。现有两轮被拒绝证据保留；本报告没有关闭 AR-N01。

## 8. 如果 B 修正后仍是厚板，下一层应该改什么

不能将参考十片尺度直接复制到新图：参考面积更大，部分肩片很薄，也未满足当前宽地合同。需要继承的是**少数承重宽体 + 较小的偏置肩**，不是某个矩形坐标或片数。

可讨论的最小下一层是将现有单一 land 尺寸域拆为 `core / shoulder` 两个作者 profile；总数仍4–7，主体至少3片，肩片至多2片，并从原总数中分配、不额外增加。core 沿用当前每世界域；shoulder 的可行初始域可从长边512–896、短边384–512开始，保留真实320双向搭接，不借140px细片制造走廊。肩片不能再次作为新肩片的父节点，避免树状房间。数字需要与真实目标面积和材料母体联合校准，**本报告不授权落入数据**。

这个修正更直接地恢复正向形体层级，但会改变已冻结的作者搜索域，因此应在 B 的独立证据之后由 Director 明确记入合同，再一次性由 CSV实施。不是建议同时增加肩片、B、H、阈值五条轴后只看一张“终于好看”的图。

## 9. 已锁定、未锁定与交接

已锁定：用户的开放世界碎片、矩形拼合和自由断缘；原生联合生成；H约为S两倍；巨大空白拒绝；既有 B 不入 H:S；普通 solid 不遮视；未知撤离与完整内容保持。
