# COH-F011：原生路线的地域偏科与岸边窄道

2026-10-14，Design静态审查。关联F013/F007/F006。范围为r12当前源码与已保存c27，geometryRuns=0、fresh=0、full=0；没有改源码、CSV、地图或旧失败收据。Root已认可下述未准入plan路线反馈策略，实施及验证待Code。本报告不是新的系统spec或用户验收。

**结论：保留当前全部G4门。将G4实际失败反馈接回同一未准入完整plan，使用现有预算作有根据的整物件移位／站位交换；以重编译后的真实完整路线评价改善。资源初次部署同源路线早筛作为后续备选，本批暂不实施。不能再只调整H/S先后、追任意P的覆盖距离，或将全图最小间隔统一抬到160px。**

## 1. 证据与原因

已读项目入口、Design定义、game-state技能及COH-F011依赖、vision/world、唯一地图spec、批准原生设计稿和`global-generation-design-review.md`§11–14；亲自查看保存的[全图](c27-spatial-art/readable/c27-overview.png)及[岸道局部](c27-spatial-art/readable/c27-deep-resource-local.png)。本轮game-state check退出2，存在既有来源漂移和未登记工具；未刷新基线或提升历史验证，登记归Root。

c27实际hash `9faebdbd40a92649`：11H/5S，G1/G2/G3通过；短比例校准后仍有3项类型、2项窄路失败。东北实际完整路线6H/0S、另一条5H/1S，中下另有3H/3S；五个S位于中下偏左。H6—岸及H8—岸的实测截面约40.07/40.41px。深污染资源的出入最短路有328px连续窄／转折不确定段。事实来自[图审](c27-spatial-art/review.md)、[完整内容捕获](complete-candidate-c27-capture-round2/summary.md)及[校准后原路复测](route-share-production-round1/summary.md)，不是本次新测。

源码给出四处具体原因：

1. [`native-spatial-layout.ts:367–415`](../../../../src/generation/world-study/native-spatial-layout.ts)先放独有母体，再按打乱序列放H和从属S；`siteFor`与`completePlanningScore`对任意H/S共用覆盖距离，完全没有类型相遇目标。母体承载域大，且relief只禁止H挖掉支撑、允许S共享其地面，容易形成中央S、外围H的偏置。偏置有机制来源，不证明每个种子必然如此。S全部前置已在固定c11因后孔无合法域失败，本轮不重复该顺序轴。
2. 同文件`siteFor`的承托岸距为24px，物件间阻行足迹留量为`48×1.5=72px`；这些是局部合法性，不是160px横向开口及224px持续长度。全域55%宽核、最大宽核80%连通仍允许少量细岸带，G3通过不保证每个目标的实际完整出行通过。
3. [`r100-expedition.ts:118–170`](../../../../src/generation/world-study/r100-expedition.ts)把20px身体可达、48px操作圈最低额外路程、污染邻近和节点间距作为资源资格，评分另偏好风险档中点、分散、来源及固定seed微差；没有实际窄段或H/S路线项。深处岸端可以同时满足这些条件。它并未故意指定岸道，但没有区分“路程深”与“长夹道里的路程深”。已有Host／巡逻窗口全部通过也不补足这一项。
4. [`r100-production-map.ts:50`](../../../../src/generation/world-study/r100-production-map.ts)把失败作为`next(feedback)`送回，然而[`native-spatial-generation.ts:239–254`](../../../../src/generation/world-study/native-spatial-generation.ts)在geometry通过后清空archive，且`yield`没有接收返回值。G4失败目前只被记录，没有成为下一完整plan的评分目标。该处符合此前分阶段隔离写法，但没有落实原生联合生成对路线关系的反馈。

## 2. 通路与六窗的设计判断

**所有几何点都须160px通路过强。** 当前160px是完整路线的横向窄段分类，不是每个站位的半径，也不是所有H/S与岸的最小gap。原门明确允许窄段≤20%、连续窄／不确定段≤224px，因此局部搜取凹位和短收口可以存在。将48px中心宽域覆盖全部端点也错误：保存例spawn净空30.463px、exit44px、目标20px/12px，不能由它们不在48px核内判定没有可用接近。

**资源必须保有原规则认可的完整接近—操作—归途；局部短接近可窄。** 单独有一片宽地或一条脱离真实操作站位的宽路不够。当前硬门仍审查确定性最短完整路线，不以“另有绕路”豁免。已有探针找到explore:11同端点的宽绕行，只多8.15%且横截面合格；深污染资源四条有限绕路仍有336–344px连续窄／不确定段。前者说明最短路和被迫窄道不是同一性质，后者不证明所有宽路都不存在。未来若改为有代价上界的可选宽路，需要独立合同；本次不改路径选择或门。

**六遭遇至少3H有合理动机，没有客观最优证明。** 它防止较长出行局部只遇普通不挡视S，而不是要求每六件精确4H/2S。六件是两个理想周期的观察窗，不能直接换算潜行时间；首次身份去重、同时可见事件和不同形体跨度都会改变它的体验含义。此窗本身容许6H/0S，也容许3H/3S：前两者在c27是由完整路线比例拒绝。校准后的c27没有六窗拒因，因此放宽六窗不能解决当前问题；新增“每六件最多5H”也没有当前证据授权。本轮沿现窗口及比例整数校准，不把计数门说成实际潜行通过。

## 3. Root认可的最小实现合同

### 固定探针与职责

首个完整候选被G4拒绝时，保留`sourceGeometryHash`、实际spawn/exit、全部节点ID/kind/tier/position、原合格路线ID、完整events与横截面作为**本attempt未准入plan的route probe**。这不是可交付地图，不向其追加物件；下一次仍是一整份L/B/H/S候选。fresh新plan不得继承旧probe，正常新图不复用c27坐标。原形体、母体／relief关系、数量与类型身份保持；源plan和旧失败收据不可覆写。

Complete负责generation／routes／production-map：提取共用route评价入口，不写第二套路径或相遇算法。Main负责layout的有限完整对象候选。两者共享原几何工作账本、截止与候选身份；不增加流程工具或隐藏重试。

### 真实失败如何导出候选

仅对实际G1/G2/G3已过、路线仍失败的完整plan开启一次有界关系候选域，替代既有joint机会。同一首G4拒绝触发的probe闭环共用48个tuple机会，后继实际几何不刷新额度，不与原48域相乘；从当前基底扫描到首个合法tuple，前序合法性拒绝也消费机会，已试tuple不得重复取得机会。72工作／2full／60秒同时生效。

- **类型偏科（c17有限域反例后的校正）：** 从全部官方比例失败路线中提取超额类型的实际首遇完整对象，不再两端各截前三；缺失类型保留全部完整对象，反向偏科的真实事件作为优先证据而非排除过滤。完整交换按预测类型纠偏、反向事件、含relief的足迹尺寸适配和距离作稳定排序，并按对象身份轮次均衡机会；这些只排序，不做隐藏的合法性预筛。完整entries跨路线去重，类型与窄段提案交替进入同48域。原第一次生产域22次全非法；替代域保存c17的同48次里得到3项合法，仅证明规划可放，不证明G1–G4改善。H仍是原H、S仍是原S，不改kind/profile，不拆母体。六窗失败只用该实际六窗的超额S，不用最近对象代替事件窗。
- **岸边窄道：** 在实际最长窄／不确定run中取最窄的已闭合横截面，重用同源射线核对两侧边界归属。H—外海时，岸不动，整H向远离外海的法向移`ceil8(max(8,160−width))`及再加8px两档；两侧均可移动H/S时允许单侧让位及两侧各半。最终以原站位域、完整承托／间隔和真实重编译为准，法向预测不证明开口已扩大。不确定转折自身不生成伪造宽度；没有可归因闭合截面则记录本轴无候选。
- 共同移除旧足迹后试放完整新足迹，含附着relief。若某提案恰由一个完整对象阻挡，可复用既有双对象同向释放；不连锁第三件。不合法就拒绝，不扩大frame、改孔数、缩母体、补地或抬预算。窄段候选按失败route ID、事件／截面位置、对象ID、位移档确定性排序，与类型候选共同去重、轮转后截于原总额；每次真正足迹合法性检查先消费额度。

### 精确评分，不让G1-only比较把路线改进退回原位

每份进入实际评价的候选先编译同源最终几何并跑原G1/G3及G2。任何原几何硬门失败，不能作为路线改善进入full。通过后，用冻结probe重算**原确定性身体最短路、所有48px合法站位中的最低完整路程、LOS、112px首遇去重、逐腿平滑与横截面**；不冻结旧折线。探索目标仍按当前最终身体域的原4×3规则全部重算，不能删除探索失败；区域消失须单列，不能记作进步。

固定spawn/exit失去身体支持、任一节点无合法操作站位、原合格路线降至不足6件／原长度资格，或baseline非空探索区域消失，均拒绝该探针比较，不能靠少见结构变绿。向量轴固定为direct、节点ID序、explore:0–11，每条四轴；新出现区域照常计入实际门。helper按官方±32px运动轴恢复横截面，两侧owner不唯一或仅有不确定转折时不猜归属、不生成让位候选。逐路线保存实际违规向量：

1. `shareDelta = min(|H−k|)/N`，k枚举当前N下由现生产`classifyNativeRouteHoleShare`接受的整数；不用P距离或理想比例的连续近似。
2. `windowDelta = max_window(max(0,minWindowHoles−Hw))/minWindowHoles`。
3. `narrowExcess = max(0,narrowRatio/maxNarrowRatio−1)`。
4. `runExcess = max(0,maxNarrowOrUncertainRun/maxNarrowRun−1)`。

保持每条路线的各项实际向量及非支配状态，沿现有“最大规范违规→合计规范违规”比较；平均内部覆盖距离仅作末位平局，可暂时变差，不能否决真实route改善。几何门必须仍全部通过。任何候选最终出图仍须所有门为零违规，不能用北侧改善抵掉南侧新增失败；局部评分改善本身不等于准入。

探针只计算geometry＋routes，不构造Master/Host，不重部署资源／敌人、不烘焙；每次真实几何仍占原72 work，路径计算也受同一60秒截止。只有probe全部accepted且G1/G2/G3通过，才再调用正常完整部署，消费该attempt原剩余的第二个full。最终实际资源初次布置可不同于探针，必须重新跑全部正式G4及原完整内容准入。旧probe不替代最终门；第二full失败或预算耗尽仍失败，不开第三full、不重抽好种子。

### 资源初次部署早筛（待实施，本批不接线）

在`r100-expedition`原`allowed`内、第一次选择节点前复用同源单目标route评价，丢弃正式完整路线必拒的候选；同一目标的路线结果可缓存，避免每slot重复算。safe/contested/deep原额外路程、污染邻近、配额、间距、来源与seed排序保持。风险定价仍取**全部真实合法操作站位的最低成本**，不能先删窄站位再挑更贵宽站位把浅资源算deep。任何档无足量候选就整份失败，不删配额或事后搬已选节点。早筛不替代explore与最终全路族G4。

## 4. 有界验证与停止线

先静态核对控制流确实消费`yield`反馈、probe字段冻结、full不被探针重置、Main候选有真实事件来源。反例至少覆盖：目标丧失支持、旧合格路线被降资格、只让P更近但真实首遇不变、mean变差而真实route改善、probe过而最终新部署G4失败。使用既有测试／捕获入口，不新建一组诊断流程。

原拟固定c27的有界因果验证（本批暂不执行新几何搜索）：冻结本hash的L/B、全部局部H/S形体、原spawn/exit及8节点位置，沿同一账本比较原路族和有限重排后的真实路族；保留所有失败。旧配额、各H身份、完整母体／relief与G1/G2/G3须保持。清除全部五项失败、原通过路线无新增失败，才可称固定完整探针通过；只减少某项违规则只报告局部改善。候选域无合法项、无实测改善或预算耗尽即停，不追加顺序实验／扩大tuple／换目标。

Root当前执行顺序为：代码统一冻结后完成必要纯逻辑／保存快照回归，只运行gel medium请求seed `20261012`的一次正常fresh完整链；seed `0`与固定c27新几何搜索等待该次结果再决定。原后续验证计划中，在运行前锁同一源码与预算，连同失败报告。单次或后续有限样本都不是接受率证明；分别记录到G1/G2/G3、probe、实际full、最终准入的计数和耗时，才能看是否减少真正生成失败。不得使用留出730201/730217调参或删掉失败seed。正常镜头、实际搜撤／动态潜行和旧配方恢复仍独立验证。

## 5. 本轮另获授权的G1文档收口

Root已依据真实物理空圆定义及实际c25/c27/c3同源双测，批准max改为`max(min(actualSolidDistance,allActualVoidDistance)+4√2)≤160`，旧内部H/S max保留诊断；deep仍是内部距离加原误差>112、跨度448，其他门不动。本代理据此更新唯一spec与批准design-note，未改生产接线。

这不是“四夹具校准全部通过”：104×16名义S正式有效面积不足，使短岸角及有结构长带两项正控未完成；[原失败记录](open-radius-calibration-round1/summary.md)保留、不再调夹具。实际三图全部非max同值，c25新max仍161.429失败；此决定不能洗掉c27的五项G4拒因。

**已锁定：** 用户原生联合生成、全局H:S方向、未知撤离、完整配额；现G4所有门；Root本轮max-only定义与有界route-probe实施策略。

**待验证：** 上述候选域能否产生实际route改善及完整新图；成本是否在原预算内；六窗／160px节奏的正常镜头体验；可选宽绕行的代价边界。无新增必须由用户先回答的问题，不因本报告提升全库、I14/P49或用户终验。
