# 迭代18：污染句法完整敌人系统验证

本轮由用户授权系统审查与完善。发行质量是目标；程序检查、离线烤图和本机试玩均不代替人的美术/体验终审。不引用旧审美skill/HOW，保留此前虫、人已认可的造型和动作基线。框架与存档不改，未提交或推送。

## 核心问题与本轮处理

1. **参数数目冒充敌人种类**：字母表存在未兑现词素；相同通用AI和模型反复换名字。改为家族能力、地图方言、职责分配与行为参数CSV共同约束；不合法的候选抽样前排除，成句不能绕过能力。
2. **职责与身体不一致**：撤离守卫固定有机体、近半占地名额实际不巡游。守卫改为地图可选的低档常开巡游体；原听觉槽可由墙承担，占地余位最多一只静止哨点。固定门框/街具不能巡游。
3. **薄弱六家族**：兽、蠕虫、有机残余、残茎、门框、街具各三种主形，三档污染、四方向、六动作。中档改承重/连接关系，高档进一步改写原物，不能只加青绿装饰。虫、人沿用已认可主体。门框侧面复核后加真实厚度与铰接板，最薄站立体块14px。
4. **假步态与假攻击**：生产通过统一模型注册与适配器，读取真实位移、攻击时钟、承诺朝向、活动状态。八身体profile同时驱动速度、蓄势、范围、扇角和冷却；窄扑和宽扫有不同承重动作。睡眠/脉冲真正控制行为，并可从实体收拢、醒转看到窗口。
5. **感官未兑现**：窄视为70°/207px，不比玩家224px先见；墙窄视、墙听觉和反视体积均有运行时消费。反视300ms激活、移开600ms退去；域影响与表现取同一状态。近距消声对休眠体与墙宿主共用装备倍率和扣次入口，显式战斗声保持原规则。
6. **近身空间与环境危险**：静止/同心敌人参与地形合法分离；真实移动与纠正分开。地面预告读真实扇区或危险格；镜像目标、隔墙打核、不可杀核吞挥击、死亡同帧反打等边界已修。玩家与占地模型按接地点排序，状态标记/闪白仍在上方，雾层不变。
7. **资源与练习场分歧**：每实体一张动态GPU纹理、最多64张CPU帧，隐藏时不烤图/上传、死亡与重入清理；丁慢云限20Hz烤图。练习场走正式分发，非油膜漆不再偷偷显示另一实现。
