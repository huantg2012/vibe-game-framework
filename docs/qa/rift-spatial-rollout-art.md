## 静态审查待复核项

1. **单主体与混合关系被槽位抹平。** `createR100SpatialDefinition` 为每个世界使用同一组织的约二十个 solid 槽，并循环原 `sources`。`monolith-sill` 原定义只有一处 `monolith-buttress`，其单主体关系会变为多处同类复制；`woven-quarters` 的膜/纤维原相对位置也不会继承。保留 `family` / `shapeProfile` / 高度字段，不能单独证明主体数量、次材依托及接合关系保留。后续 `pale-sail`、`hollow-wreckage`、`marrow-break` 真实全图已进一步证实这是共因，不是仅两个名称特殊。当前不能据此宣称108个原空间身份保持。
2. **原 v4 地床切口被宏观 erosion 替代。** `definition.erosion` 只取空间 policy，原世界切口未参与。扩图本来允许新轮廓，因此不要求复制旧坐标；但以地床撕裂/孔洞间隔构成身份的世界，需要重新建立相应关系，不能仅保留独一 `groundEdgeWidth` 就视作地床身份未变。
3. **物理与视线角色分离仍有源码支持。** `r100-master-world.ts` 先生成 matter，再以 solid 标记 WALL；`sight.isOpaque` 依据缺地，而非普通实体。两幅真实 receiver 图也显示普通 solid 的表面。此处为静态链与限定画面核对，身体实际行走和视线回归由 QA 独立记录。

## 单主体与牵接材料的纠偏交接

以下为交 Code 的特殊组织方案，不是另开视觉方向。依据分别为 [单柱旷地原意图及真实侧出口](../art/rift-r100-i07-i09.md) 与 [压纤四角原意图](../art/rift-r100-i10-i12.md)。主代理已认可问题成立并安排专用布局。数值是本轮可验证的设计目标，不应反向以它们抹平已锁的主次关系。

**单柱旷地：一件高体 + 两种回绕。** 2304×1792 内保留一件偏东的分足高体，西侧是宽静床；允许整体镜像，不能据此指定出生或撤离。原高度105、厚度18、fold 0.56、opening 0.88保留（初稿混淆后两字段，已按原CSV纠正），初始平面占有建议约650×520，不循环复制小柱。第一绕行组由巨体的外侧长路与前口→侧出口构成；第二组是静床偏西南的一段约420×100的错位、细长缺地，将近侧窄颈与远侧宽路分开。两组间保留连续静床，不连成一道横断全图的墙。

验证重点：可识别高体恰好一件；分足口供20px身体真正穿到侧出口；分别从两组两侧取可达点，应各有两条内部不共边的路线，临时封闭其中一条局部颈口后另一条仍连通；建议各组绕行最短路/直距至少1.25、额外路程至少120px，以排除只加一个几乎无影响的小孔。正常肩灯应可依次读到西静床、实体前足和侧出口。该世界不以17–27%的通用实体占比逼迫增殖主体。

**压纤四角：四片低床和两条搭接的长纤。** 保留四块不等短纤床，其中三块低而可走、一块翻起为solid；两条铜色长纤分别搭在北组和南组的蓝灰短毡交界，必须看得见压住或穿过边缘的关系。不能把膜高边和长纤拆成二十个互不相干的岛。第一绕行组为翻起边＋北长纤，第二组为南长纤＋对角短裂地；两条地裂位于板片对角接缝，保留外圈可走。初始平面关系可按1.6–1.8倍展开，保持原高度/厚度和纹理世界尺度。

验证重点：4块膜床中3 relief/1 solid，另有2 fibre solid；两束各与两片床/边搭接，AABB只筛查不代替实图接触；每组有接缝近路与宽外绕，可按上一例的双路及绕行增量检查。两组间至少约300px行程，使玩家在有限视野中能先后辨认，不挤为一团。采图须补蓝灰短毡与铜长束接触、翻起边和真实短裂地的正常视野近帧。
