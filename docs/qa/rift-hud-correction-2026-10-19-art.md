# Rift 同化次级常驻读数 · 美术短核

日期：2026-10-19。范围：COH-F032 / COH-F035 / COH-F054。用户纠正优先于前轮 DEC-222 呈现：同化必须常驻但降为次级；同化不改变净化点冲击强度。

本记录为本轮处方与限定观察，不是新 UI Kit；规则正文及状态传播由主任务原地更新。Art 不修改游戏逻辑，不代替用户作最终审美判断。

## 开工依据与处方

已显式读取 Art 定义、in-game-ux skill 与 exemplars / aesthetics / like-a-game、项目规则、game-state 入口与协议、当前 Kit、world 美术约束、art-direction UI 节及 U1–U12；看过前轮正式余烬脊的静默 HUD 实景。

- 载体仍是世界内随身读数，以屏幕空间 DOM 挂 `#dom-ui-root`，960×640 逻辑画布。没有新造实体或镜头动作。
- 沿既有参考：Darkwood 取行动画面与阅读留白，不移植库存皮；Signalis 取当前对象与辅助读数的主从，不移植 CRT；Hyper Light Drifter 取短标记与直接操作，不移植鲜色或纯符号谜语。
- 左上生命、污染两条保持。同化在右上「Tab 随身」下方独立一行，建议右距24px、上距80px；位置把它归到长期随身状态，仍能随时找到。
- 「同化」10px/14px辅助灰绿，数值11px/16px等宽、保留一位小数，间距8px；使用现有色格，不叠整体透明度。新文本对实际背景下限4.5:1。主从靠分组、位置和无条形表达，不靠把必要信息压到不可读。
- 新协议0.0%也显示，旧150协议不显示。无第三条进度、无机制段落、无常驻闪烁、无整块底板。打开随身或系统菜单时随入口让位，避免旧 HUD 重复压到正文。
- 左侧操作帮助保持原位置；它与右上新行没有空间冲突，无须为一条次级读数重排左侧。
- 随身「身体」移除归返冲击增幅，保留同化、满污染时视距、未激怒敌人感知距离。建议三行完整事实，标签与数字分节点，沿11px/12px层级，不让原四宫格留下伪空位。
- 培养藏也不再描述同化提高冲击；正常疗愈周期仍发生的冲击成本须按实际机制展示，不借视觉文案重新引入倍率。

## 三问

1. **主次：** 左上两根细条服务即时生存；右上短行服务持续身体状态，缺少进度条、危险脉动和解释段落，视觉分量低于即时组。随身展开后才说明实际影响。最终须以实帧确认这行可见、又不成为新的焦点。
2. **行为：** 玩家无需打开菜单即可确认同化，详细影响沿一次 Tab 查询。新行只读，不伪装成按钮，不增加按键与悬停条件；身体状态可更新而物件列表不应重排。
3. **世界连续性：** 原场景、镜头、灰绿小字及无框结构保持。没有外来卡片、怪异图标和新装饰材质；同化身体状态也不再被误说成改变净化点外部潮汐压迫。

## U1–U12 相关短核

- U1：沿同一屏幕空间根；新行不能由世界相机缩放决定位置。
- U2：无新增卡片、边框、发光、渐变按钮或通用图标。此项不能替代审美。
- U3：用现有灰绿色格；同化不借薪柴暖色或新增污染等级色。
- U4：HUD10/11px、查询11/12px，沿 Kit 字体与层级。
- U5：短标签「同化」，去掉归返冲击增幅及其错误说明。
- U6：右上页边短行；避开行动中心、右下地图和左侧帮助。查询时让位正文。
- U7：无新增输入或 hover 依赖；Tab 与原入口的真实行为需 Code/QA 回归。
- U8：0值仍有位置；旧协议隐藏，不用假0值冒充其已具备同化机制。
- U9：标签、数值分开，数字精度固定；实帧文字可辨，背景对比取样边界见下节。
- U10：实际值变化应在400ms内可见，不新增警报动画；刷新时序由 Code/QA 验证。
- U11：新样式限定 Rift HUD，查询沿原结构，不能改变基地/备行。
- U12：既有三项具名参考与当前样本均已读取；此修正不扩新参考方向。
