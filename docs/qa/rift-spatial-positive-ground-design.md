# 余烬脊：先生成地床，再组织破坏

用户否决前轮整体边界仍近矩形，指出生成意图有误。本轮撤销上一份 brief 中“沿四岸浅挖 80–240px、为容纳既有席位局部恢复岸线”的生成方式。该办法仍预设了一张完整矩形纸面，局部锯齿、削角和空洞都没有改变其宏观轮廓。

## 已锁定与本轮实施假设

- 已锁定：被破坏的开放空间；8 处内部空洞的**数量**获用户认可；实体按上轮减少至 22 件的基线控制，不能因地床收窄又变得拥挤；撤离须探索，不能固定在对岸、最远点或出生旁。
- 本轮实施假设：三块不等宽地床以宽面叠合，形成东北较长的厚腹、西南错位的宽脚和西北短肩。东南方向整片缺席；没有连接房间的细桥，也不靠外海深湾把地面切成洞室。
- 正向宏形首稿曾用四片围中心补齐，内部美术审查仍读为近凸厚盘，已弃用。当前三片大形获 Root/Art 内部方向放行，仅允许进入作者数据与生产验证，不等于玩家已通过。

## 数据与生成顺序

`data/rift-spatial-land-plates.csv` 使用 `world_id,id,points` 声明正向有地板片，每行是宽厚的简单多边形。先做严格并集，要求得到单一、无内部孔的地床外圈；不从画框逐边削出它，也不添加隐藏补地来容纳旧坐标。矩形仅作为 2304×1792 的存储画布。

当前三个源片总并集为 2,436,431.36px²，17 个非闭合外圈顶点；扣除保持形尺度的八孔，连续几何有地约占画布 48.70%。面积较旧版减少必须明确报告，不能因为外轮廓通过就忽略有效探索空间或相对障碍密度。此面积是作者几何诊断，不能替代 8px 光栅、真实身体和玩家判读。

顺序固定为：正向宏形 → 八个独立内部缺地 → 实体/低床 → 合法出生候选 → 原有完整内容部署。旧孔、实体和出生点都可随新地床迁位。禁止为了保护绝对坐标将东南缺席处重新补回。

当前 `sector-cuts` 的余烬行只保留八个内部孔。七孔使用平移，西北长孔绕参考中心旋转 -0.45rad 后迁入短肩；孔形与尺度职责保留，坐标仅有千分像素记录误差。不能将孔接到外海或合并成一个大口后仍声称保留八孔。

`sector-layouts` 保留 22 个实体的 ID/source_index、三条主脊和八块短碎体的尺度。中型体分别收长宽并重新选位，目的在于避免地床面积减少约四分之一后，相同数量再次形成上轮被否决的拥挤。它们没有统一缩放；三条主脊仍承担构图主次，普通实体仍只挡行进/近战。四块 relief 保留可走身份，不计实体密度。

出生候选同时分布于外侧宽地与内场，按新真实足印修正。它们与撤离不固定配对，原全图路程层/空间区抽选继续有效。

## 验证顺序与停手边界

1. 先隐藏实体并填平内部孔，缩至小剪影读宏形。若仍可直接概括为削角矩形、等向厚盘或三个房间加桥，本轮失败；不能再加小齿或孔来遮掩。
2. 恢复真实孔与材质，查看去雾完整生产图及正常相机尺度。检查宽地的跨区联系、孔前后的未知区域、实体轻重和东南方向的缺席是否仍可读；不得用简图代成品。
3. 分开报告有地面积、真实实体并集占有地比例、完整身体可站面积、出生连通率及路程分布。上轮约 29% 的实体/有地比仅是密度比较参照，不是自动通过线。也不能以 97% 连通率掩盖整张图变小。
4. 身体保持 20×20、支撑 8px、速度 80px/s、前向视距 224px。真实身体可达席位至少 97%；三档内容/巡逻/Host 配额与探索式唯一撤离保持。实例网格必须使用实际 `seed ^ Math.imul(id,104729)`，不能用长宽矩形、椭圆或请求种子的单体预检代签最终准入种子。
5. 八孔必须为地床内八个互不连通的真实 VOID。正常视野仍以隔洞不可见、绕端显露与退回再阻断分别核查；实体不可冒充视线障碍。多个种子检查撤离相对方位与路程层，不把宏观主轴变成“另一头就是出口”。
6. 旧冻结配方保持原貌，其他 107 世界不因本代表而取得通过。材质、物理、光学规则与奖励配额本轮不改；正向地床表示的运行时与存档校验由 Code 负责。

首稿作者位置不代表真实足印相容。只对生产检查指出的具体越界、封路或重复堆叠做定点校正，不填孔、不补东南、不统一缩小全部对象。最终通过仍由玩家复看实际地图决定。
