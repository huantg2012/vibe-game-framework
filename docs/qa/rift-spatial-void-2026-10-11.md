# 裂隙空间质量整改：VOID 首批代表

2026-10-11。COH-F007 + F011/F012/F013/F014；关联 F006/F039/F044/F052。用户否决原规则轮廓和弱化空间空洞后重开。本文是整改与实际证据记录，不是 108 世界完成或用户验收。

## 修正的方向

原问题不是吞光代码失效，而是内容与验收遗漏：地图面积扩大 5.25 倍，旧主体仅整体放大 2.56 倍面积；外围大块通路可绕开中央构图。只要求两组身体绕行，普通实体即可满足，不能证明空间空洞对信息的阻隔。

首批正式生产代表为裂台、苍帆、余烬脊。作者输入改由四张 sector CSV 保存，重新组织深湾、内部缺地和实体接近角度，保留材料、构造与 solid/relief 角色。旧 84 作者组、19 通用世界、2 特殊世界的数据值保持；此批不复制成全库模板。源实例与唯一岸沿 owner 合同继续验证。

普通实体仍只阻挡身体/近战；缺失地面 VOID 同时不可走、不可照、截断视线。没有用透明实体冒充挡视线，也没有添加装饰黑片。出生/撤离沿用多区域、多距离层随机选择，不指定对岸、两端或最远点。

## 专项验收边界

三处独立 VOID 的可达观察点→目标→揭示点只是机械见证。旧三图也能通过这一数量，故不能把新增门槛当作质量改善结论。新证据同时记录内部缺地与外部黑区、近邻有地之间 LOS 阻隔、外围长直通路；数值是诊断，不能替代全图及正常视野的图审。

正常视野旅程使用生产 RiftScene、正常灯距/朝向/伤害/时间以及真实键盘位移。全图仅作知情测试导航；目标是原地图的有地位置，不虚构为实际资源。目标处于当前朝向和视距内时，隔 VOID 不可见，绕端可见，返回再次不可见；同时读取不计 LOS 的反事实光学值排除纯超距。此过程不是盲测，也未证明自然搜撤趣味或长期平衡。

## 保留的失败与返修

- 首轮视线脚本在未 hydrate 的 native 上取 sight 失败，记录 sight-baseline.json；修复工具后另写 v2，不覆盖失败。
- 初稿裂台岸壁超过 16,384 三角；保留失败，测量后将大图拒绝预算调至 20,480，小图 2,048 不变。实际细分、采样、UV、排序与生成算法未变，已准入旧图输出保持。最终资源和参考机运行单独取证。
- 裂台初稿机械视线门通过，但上下仍有 1,456/1,448px 长直外围通路，图审拒绝；最终增加偏轴深切，没有靠微锯齿掩盖。
- 苍帆初稿把主体缩小为两组相距很远的叶片，图审拒绝，要求恢复至少一件完整长高幕与对向关系，保持 VOID 骨架。
- 余烬脊首次正常旅程在 35ms 朝向输入后反事实也为 0。转向速率为 1,080°/s，180° 需要约 167ms；工具改为 220ms 并记录真实位置/灯向后重测通过。原失败是取证朝向不成立，不记为遮蔽功能失败。

- 苍帆最终版中央孔的首条普通输入见证失败：到达正确揭示点后，220ms 转向同时向右移动约17px，再次进入遮挡区；真实反事实光学值为1、实际LOS为0，故这次旅程保留为失败。没有放宽可见断言；另选预先计算的西南独立孔见证，以正常输入完成。中央孔连续揭示的取证仍未通过，不能把离线点查询冒充实走。

## 最终限定证据

- `production-final.json`：3世界×3档，seed20261010，共9份完整正式生产图，通过内容配额、身体支持/连通、巡逻站位与真实双侧绕行。全部首候选成功，最低可达率99.9758%。这不是全种子成功率。
- `authored-identities-final.json`：252份旧完整作者组定义及9份新sector定义，保源角色/构造/唯一岸沿owner通过。`representative-scope-pale-reframe.json`证明其余105世界空间值未变。
- `sight-cleft-final-three-grades.json`、`sight-pale-final-three-grades.json`及先前未改cinder的`sight-representatives-three-grades.json`：三档各3个相互独立的VOID观察见证。`sight-alternate-seed-final.json`补20261011三中档；裂台首候选，苍帆和余烬各标准重试一次成功，effectiveSeed3617560835。详细诊断在`qa-final-sight-report.md`。
- 实际去雾全图/正常出生图：`browser-final`裂台和苍帆、`browser-first`余烬。`cinder-source-bridge.json`核对最终配方参数、材料、出撤位置及执行差异，界定旧捕图适用范围。三个出生时撤离均未知且不可见。取自生产worker+RiftScene的实际材质canvas，不是独立原型重画。
- 普通键盘、当前视域三帧：`sight-browser-cleft-final`、`sight-browser-pale-southwest`、`sight-browser-cinder-turn`，各1个孔取得实际0→1→0、反事实始终>0的遮蔽/绕行/返回证据。目标距约135–177px，实际前向灯距224px，三例均100HP。每图只实走1孔，另2孔仍是离线机制证据；没有自然未知搜撤或完整高幕夹道体验结论。
- `frozen-before.json`与最终manifest重生后的`frozen-final.json`（中间复验另存`frozen-after.json`）：3份旧r7配方在旧执行源码与新实现中，完整布局/native栅格/几何与identity精确相同。新作者内容不追改已保存旧局。
- 最终`npm run build`、包依赖80项来源校验、CSV codegen/离线岸线并集检查通过。构建仍有既有大包提示，不冒称已做包体优化。没有配置独立lint脚本。

独立美术最终结论：三张全图可交用户复看，无新增必须修项；裂台东侧1328px局部通路、苍帆南侧1160px开放段仍存在，但已经不组成绕开全部内部结构的宽外围通环。保留局部静区和替代路线，未用统一最长直线阈值把地图切碎。主体夹道的正常连续读法与玩家趣味仍不由全图代签。
