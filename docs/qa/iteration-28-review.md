# 迭代 28 独立代码与集成审查

## 结论

本次独立审查发现的 **3 个 P1、2 个 P2 均已修复并完成对应复核**。本报告覆盖的路径没有遗留已确认缺陷。该结论不表示整个 I28 已完成，也不代替内容平衡、首次玩家测试或美术人审。

关键结果：未成功持久化的鉴定不会向玩家发布真名、能力、报告或揭晓音效；重试保存相同结算候选，不再次冲击或鉴定；合法的已保存掉落和来源片区按原结果恢复，不按当前权重重抽。

## 发现与修复

### P1 · 归返拒写仍提前揭晓 — 已关闭

原 `PurificationScene.create` 在 `commitWorldTransaction` 返回失败后仍直接展示结果报告。报告已有真名、图标及能力，刷新却会回到未鉴定的旧存档。

现将报告、音效和后续提示统一放入 `publishArrival`，只在保存成功或同一候选重试成功后发布。待保存期间禁止移动和基地交互。浏览器连续两次拒写没有报告或真名，第三次成功才揭晓；三次尝试的候选字节完全相同。

### P1 · 恢复时按当前内容重抽固定掉落 — 已关闭

原准入校验调用当前生成器重建计划，再比较校验值；当前权重或内容扩充可能使合法的既有世界无法继续。

现保存实际物品结果以及全部翻堆节点的来源片区与提示；恢复验证版本、地图节点、风险档、合法引用与跨所有者关联。定向测试替换一个未翻找节点的合法定义及保存片区，使它们不同于当前重新抽样结果，仍可恢复且不改写；遗漏薪柴片区或条目标签冲突会被拒绝。

### P1 · 保存重试按钮无法实际点击 — 已关闭

首次浏览器回归中，按钮可见但继承 overlay 根的 `pointer-events: none`，真实鼠标点击被 canvas 接收，保存恢复流程无法继续。

现用既有装置面板容器承载按钮，明确启用指针事件，保留按钮焦点和键盘入口。回归使用实际鼠标点击，拒写重试与成功重试均通过，没有采用脚本调用 `onclick` 绕过交互。

### P2 · 提前合上报告后被入场回调重新锁住 — 已关闭

原入场结束回调按静态 `impactResult.skipped` 判定输入资格；若报告已被合上，后执行的回调仍可能把角色锁住。

现按实时报告是否打开、是否待保存和菜单入场状态控制输入。定向回归在动画结束前重试并合上报告，确认稍后可正常移动，报告、音效、揭晓提示各一次。

### P2 · 首次揭晓缺少装配类型、实际余量与重量 — 已关闭

原报告仅显示真名、图标和一句效果。现从相同公开投影补入独立字段，首次揭晓可读到：

- 主动：琥珀甲虫显示“主动 / 5 / 次 / 重量 / 2”。
- 被动：铜框单镜显示“被动 / 2 / 趟 / 重量 / 2”。
- 无能力：双孔票牌只显示重量，不出现主动/被动、虚假次数或“可装配”提示。

三类均使用真正的供奉完成结算与报告；后两类是明确标注的同壳定向身份变体，未冒充自然掉落。

随后 root 的真实首屏复核发现揭晓块曾被模块明细挤到滚动区下方。现有转化时把同一揭晓块提到最大损伤摘要之后，未转化时保持原有顺序；无能力说明合并为一句。最终浏览器回归**没有执行滚动或 `scrollIntoView`**，断言三类的真名、已加载真图标和余量/重量整行的 bounding box 完整落在报告可视区内，且 `scrollTop` 为 0。证据截图均已刷新为这个未滚动首屏。

## 验证边界

1. 本报告的供奉用例是**定向边界测试**。在实际采集的 `03-carry.storage.json` 副本中准备最后一轮供奉和待归返状态；没有用它证明真实等待节奏、补给充足、30 次自然探索或新手理解。
2. 存储拒绝通过当前隔离浏览器的主存档 `setItem` 抛错模拟。验证覆盖持久字节不变、候选锁定、交互锁定与重试；不代表浏览器崩溃、电源故障及所有第三方存储实现均已模拟。
3. 拒写时进程内保留冻结结算候选供重试，旧持久存档不变且玩家无法使用未保存结果；这是本次实际验证的行为，不应误述为所有内存对象立刻回滚。
4. 本轮只有当前 `contaminant-v1` 与既有兼容路径。未来改变旧参数或增加版本时仍需保留对应冻结 resolver/版本实现，不能以本次“不重抽”证明未来所有版本都已支持。
5. 未独立覆盖所有低帧设备、所有障碍几何和每个能力的长期收益。短冲等专项通过与否以对应运行测试为准。首屏几何断言覆盖单件主动、单件被动和单件无能力转化，不代表多件同时转化都无需滚动。
6. 图标的轮廓美感、48 件装备的辨识负担、品质期待、噪声物挫败感与长期循环仍需要用户体验判断。机器断言和本次截图不替用户标注审美 PASS。
