# 20世界区分度重构 · 验证

本批响应用户“地图纹理、巨构样式、色彩风格都像差不多”的反馈。范围是现有20世界，正式新包为v3修订4；不是新增20世界，也不结束目标36世界的I07。

## 发现并修复

1. 第一轮次材料遮罩产生黄楔、等距粉蓝条带、米白直带，虽然更鲜明但像图案地毯，未通过内部美术审查。改为双轴扭曲的非周期材料区域，并由源图细节打断交界；保留`first-pass/`而非用后图覆盖。
2. 可走浅纤维因碰撞角色为非solid而被当作底床着色，金色材料只出现在残骸上。现在按实际物质表面选择色阶，物理可走属性独立。
3. 骨白壳亮面损失细节，已拉开作者暗／中阶和局部明暗反差。
4. 第二轮使用可热更新3027服务器，最后一例发生模拟时间推进不足，整轮不计运行通过。切换冻结源执行最终证据；失败产物保留在`second-pass/report.json`，不通过放宽时间阈值来消除失败。
