# 裂隙空间专项复评：空洞与探索

2026-10-11 · 知情设计复评。对象为 `fc5a5f2b` 的正式修订 7 空间推广，入口为正常备行新出发；取证来自用户三张全图、`browser-release` 的实际生产全图、冻结配方与生成源码。本报告完成静态设计诊断和首轮作者布局交接，**不是新地图的运行通过或人审通过**。

绑定 COH-F007（有限视野与不可照亮空洞）、F011/F012/F013/F014；关联 F006、F039、F044、F052。执行 `game-review` 的模块专项及迭代复评方法，并按 `game-state` 区分已接入、旧技术验证与本次用户否决。已知先验包括全部旧制作历史，不能称盲测。

## 结论

接受本次反馈。正式版本的空间探索仍然脆弱；扩大画布、保证绕行、改变出生与撤离位置，均不能替代空洞对信息的分隔。最重要的优势是保住：唯一撤离需要寻找、实体与真实身体同源、多种材料及构造有身份、VOID 不可走且吞光。下一笔投入应放在**重新组织岸线与内部缺地，让玩家必须换观察位置才能理解下一块空间**。

范围以三张代表先验证共享作者方法：`cleft-tableland` 对应用户指出的双台地问题；`pale-sail` 检验稀疏双主体能否依靠负形形成探索；`cinder-ridge` 检验二十件成组实体是否仍有独立的空洞层。当前不把三张的坐标复制到其余世界，也不以三张技术通过代签 108 世界。

## 核对到的事实与原因

### VD-01 · 只验证身体绕行，遗漏了信息绕行 · P1

`r100-master-world.ts` 的正式 `sight.isOpaque` 只以缺失地面判遮挡；普通 solid、relief 不自动挡视线。这是既有正确规则，**本轮没有证据表明吞光代码失效**。问题在于生成内容与验收：推广任务要求至少两组实体或内空洞形成双侧绕行，两个实体就能满足，没有要求空洞实际遮断一次有意义的观察。

玩家目标是找资源与未知撤离；当大多数有地空间只靠视距限制信息，已知物体只增加步行距离，观察、绕端、揭示、重新选路这条因果链不足。两种障碍不可互相代数：真实 solid 负责限制行进和接近角度，真实 VOID 同时限制行进与感知。不得给普通 solid 偷加不透明属性，或用黑贴片、远景、地面暗纹顶替缺地。

证据：`docs/tasks/rift-spatial-rollout.md` 原“至少两组”闸门、`src/generation/world-study/r100-master-world.ts:170`、`docs/specs/system-movement-vision.md` 的 DEC-106。把握高；全库发生频率尚未逐图统计，技术契约上的遗漏适用于整轮。

### VD-02 · 全缺地面积把外部黑区计作内部探索结构 · P1

对 `browser-release/capture.json` 中 14 份冻结配方做静态多边形面积核算：封闭内洞只占画布 0–3.81%，总缺地却占 18.13–36.99%。`ash-strata`/`cinder-ridge` 各一洞、0.85%；`shell-chain`/`shell-gel-delta` 无封闭内洞；`cleft-tableland` 三洞、2.17%；`rib-vault`/`pale-sail` 两洞、1.04%。这里“内洞”仅按多边形不接触画布边界分类，面积按顶点鞋带公式计算，**不是 8px 栅格的可见性测试**；深入地图的外海湾同样可能形成有效信息屏障，不能因此判无效。

数字解释了为什么旧缺地比例看似充分而全图仍然空旷，却不构成新的统一面积配额。长窄裂口可能比一个大圆洞更有效，宏观面积必须辅以正常视距下的观察位置与路线证据。

### VD-03 · 保留作者关系被固化成保留全部坐标关系 · P1

86 个作者世界使用统一 1.6 倍变换，`source-once`、零抖动，运行时再次验证每个实例的中心、大小和朝向符合整组仿射。新岸主要由四角切除、两个侧裂和原海口延伸构成。旧小图的中心关系得以保留，但放进更大基底后没有重新编排新增的边缘空间。

用户紫色图对应 `cleft-tableland`；最终 `browser-release/cleft-tableland-medium-full.png` 虽增加侧湾，双板与中轴海口、小洞关系仍清楚可见。**双板本身是可走 relief**，真实 solid 只有两件较小物体；静帧中的体量不能直接当作实际障碍密度。材料身份值得保留，但它不要求每件物体永远保持同一个全局仿射关系。

整改允许重新布置世界中既有实例，优先保源身份、solid/relief 角色、材料、构造与主体关系；不能为凑二十件把唯一巨体复制成树林。旧在途的冻结配方仍须恢复原图，不能用新作者数据追改历史局。

### VD-04 · 岸线局部不规则，宏观仍是切角基底 · P1

已实看 `browser-release` 的 cleft、shell、cinder、ash 去雾全图。末版比矩形中间态多了缺口，但 cleft 的长直段与四角关系仍主导轮廓；cinder/ash 的两根主分隔体加中央细洞仍有显著同构。微小锯齿、切角数量与世界名称不能证明拓扑多样性。

竞争解释：缩小的全图会夸大规律、遮掉局部差异。这限制了本报告对正常镜头压迫感的结论，但不能推翻已知的物件角色、源坐标和缺地分布。下一步必须用真实视野连续走一段，而非只增加全图细节。

## 独立美术判断及覆盖边界

所见为正俯视地表与带高度侧面的低多边形物质构造，8px 阶梯岸缘配合连续颗粒/沉积纹理；黑色负形与异色侵蚀裂面承担边界，人物灯属于局部亮点。六材料的表皮、断面和形制差异值得保护。当前主要问题是**构图与负形组织不足**，不是需要换色、增亮或加纹理。

静态身份有基础，宏观构图成熟度不足；正常相机连续显露、压力下行动读法未由本报告实测，声音、动作手感不在本次取证内。专家判断不代签用户对美术或趣味的认可。

## 本轮可执行的三层作者规则

1. **外岸定空间分支。** 从不等大伸展区、偏轴深湾、收窄后重开的连接组织全图；至少一个深湾进入有效探索区，而不是仅削掉缓冲区角。长短岸段交替，不把四个角、四个方位、四个洞作为可见模板。岸边允许局部较直，但不能有一圈连续宽阔的外缘捷径，绕开内部所有决策。
2. **内空洞定观察分隔。** 三个代表先各安排三处有明确观察职责、互不等距且非镜像的内缺地：隔开邻近可达地带；沿岸到端点后才出现下一段；与外湾共同形成至少两条能重连的路线。每处需要“看得到近岸、看不到邻近另一岸目标、移动后发现”的真实证据。洞不是噪声小孔，也不能全并成一条把地图劈成固定左右两端的鸿沟。
3. **实体定局部走法。** 大实体有主次和方向差异，小实体集中于转角、接近区与回接处；留静区，避免均匀撒点。可走 relief 不能计入物理障碍。物体不得横跨不存在的地面形成看似桥梁；若足迹与新 VOID 冲突，重新摆放或调整局部轮廓，不能悄悄填洞。

三层一起读：玩家先发现可行分支，沿空洞换位获得新信息，再面对局部实体选择接近角度；所选路径消耗真实时间并影响回撤。不添加假的门钥匙、额外界面或未授权的新惩罚。

## 三张代表的首轮输入与职责

具体坐标已交 Code Agent，由 `data/rift-spatial-sector-{layouts,cuts,anchors}.csv` 和 `data/rift-spatial-sectors.csv` 保存实际作者输入。**CSV 是坐标唯一正文，本节仅说明设计职责，不维护第二份数值配方。** 初稿坐标经过实现准入允许小修，实际采用值必须以新增 CSV 与最终图为准。

- **裂台地 cleft-tableland**：两块可走低床错阶，两个真实实体分守不同接近区；北岸深切偏到西侧，东岸形成较浅横湾。三内洞分别为西中横斜裂口、中央折纵裂口、东北短弯裂口；取消原南北中轴对称框架。西南回接处留通路，不再塞障碍将环路误变单线。
- **苍白帆 pale-sail**：双帆从中央对称陈列改为西北/东中错位关系；三内洞分别隔开西南、中央与东北的观察。北湾深切负责宏观分区，西湾与南湾长度不同。初稿实际足迹与北湾冲突，已允许保持深度向东微调湾口，或缩小双帆后实测摆位；Code 初步找到帆 1 `(560,590)`、`480×240`，帆 2 `(1570,1010)`、`525×240` 的连续几何净距，**这只是放置候选**，需美术复看是否仍读作双帆主体，不能以碰撞通过宣告身份成立。
- **余烬脊 cinder-ridge**：保二十实体的群落身份；两根主脊分处西北和中东，长轴方向不同，小块按接近与转向成簇。北岸深湾取代旧中央细洞的单一职能，三个内洞分别在西南、东北、中南。各区保重连关系，不能再用统一外围物件环把空洞挤回边角。此图应独立覆盖，不能改公共 `offset-divides` 时意外改变其余世界。

出生候选由实现方在多个真实连通区域找完整身体席位，不能为方便取证固定出撤点。唯一撤离继续消费既有随机区域/距离层选择器，不偏向洞后、不强制最远、对岸或两端。视线样点是 QA 数据，不是玩家提示或出撤选点的暗规则。

## 验证：数量、拓扑与实际发现分开

**第一道：实际空间合法。** 沿用 20px 身体、8px 地面、完整候选拒绝、内容配额与巡逻空档。不出现 solid 跨 VOID、孤岛交互物、不可达出生/撤离、狭缝吸附、悄悄填洞或削减收益。新作者输入必须冻结到配方，旧 r7 配方恢复前后几何一致。

**第二道：空洞有独立信息贡献。** 每张代表至少三处不同区域取观察点 P、被遮目标 Q 与揭示点 R。P、Q 都必须是实际可达的有地席位；Q 在当前前向视距内，朝向对准 Q，标准基准 224px，并记录混乱/装备倍率。实际视线 P→Q 不可见；对同一位置、朝向、半径、实体数据只将相关 VOID 改为光学透明的反事实查询，Q 可见。反事实仅用于离线 QA，不能写入正式地图或记忆。沿完整身体路线从 P 移动到 R 后 Q 实际可见，原因是绕过洞端而非仅从超距走进半径。洞内依然不可照、不可走；站原地转向不能代替移动绕端。三个样点只证明最低职能，不等于整张地图已经有趣。

**第三道：有选择的探索结构。** 全图上能指出不止一条有效回接，正常镜头下走两条不同探查方向，记录何时遇到缺地、何时获得新信息、何时决定继续或回头。不能用 97% 连通率代替路线差异，也不能靠一圈外围宽路跳过三处空洞。局部连接以能转向、回撤、利用工具为目标；首轮通常保留 80–160px 可走宽度，64px 左右的收紧只用于短接缝，**这些是作者起点而非全库硬阈值**，最终按真实身体与场景关系判断。

**第四道：两种障碍分别验。** 保留实体造成真实身体绕行的验证，同时单独报告上面的 VOID 遮视线结果；不能再“solid 或 VOID 任意两个”相加凑数。可走 relief、装饰阴影、不可见外缘黑区均不计作成功样例。

**第五道：变化与身份。** 三张全图并排，必须从陆地分支、洞的方向/位置、主体关系看出区别。再换种子核对出生、撤离区域与相对方向，并披露固定几何与种子变化各自范围；移动出生点不等于重新生成空间。后续推广按作者组织等价类核验，不能将这三个坐标模板换材料后称全库设计完成。
