## 最新：不可通行实体边界复修

用户肯定上一批改善，但用正常／法线两图再次指出：折板从下往上看时，低斜面仍与地面混合。前批54帧中的局部正照观察不能推出全部边界清楚。[用户原图与新对照](interactive/r100-solid-boundaries.html)保留此次反例；本次基于`e8888655`修正，源码指纹见[实际运行记录](artifacts/rift-r100-solid-boundaries/after/report.json)。

原因是三项叠加：不可走的南侧低面本来就一路降到地面；实体和地面共用同向纹理；原外沿提亮最高把实体0.73倍率抬到约0.87，恰好抵消地面0.87的区别。不是可以要求玩家适应的气氛表达，也不能靠法线诊断图证明正常画面可读。

现在作者`solid`显式驱动几何`blocking=1`，折板低端增加真实厚度与短陡断面，原XY外足、最大高度、像素投影、8px占区保持。可走浅浮雕原样，纤维／壳的形体原样；阻挡表面用对象自身UV，并撤掉错误的沿边增亮。普通受光画面靠真实断面、材质与接地显示边界，不新增荧光描边或扩大肩灯。材质像素输入与几何职责分别检查，不能用CPU mockGL证明最终画面。

[几何回归](artifacts/rift-r100-solid-boundaries/geometry-check.json)含64个折板种子／旋转样本、12个relief旧指纹、16个其他形体不变检查；真实发光面的像素仍存在。材质上传回归防止边沿增亮再次抵消实体与地面差别；九组视野／近战语义、18组Host与曲线、表面字段、类型与构建通过，保留既有bundle大小警告。此次没有共享混乱／Host规则改动，不冒充重跑上一批完整恢复或内存性能检查。

同站位中、重档的南侧60px对照经root与非作者检查，普通画面能在碰撞前辨认前缘；三档东南／西南另补40px近照，六次实际接近20–26px后停止且HP100。合计50次真实按键接近、44个独立方向、600个150ms采样均有身体支持；初批3项沿边滑动、4项受敌人伤害干扰均保留。重折板西、纤维低／重东、重壳北这4个方向在64／40px起点未取得合法测试站位，不能据此断言无路或已通过。

### 实际改变

- **绿色侵蚀与变化：** 绿色沿实际裂面、纤维和壳内层扩展，保留病态灰绿；低档也保留可辨识的单处面积。取消多次亮度衰减，按材料表面展开变化；真实存活污染体提供局部反光，死亡或消失后移除。结构发光本身不是额外伤害规则。
- **实体边界：** 原先低矮实体按高度混回地面，导致下沿漏画。现在实体保留完整材料、法线与接触明暗；只有可走浅起伏允许与地床自然过渡。没有扩大角色光圈或给全图提亮。
- **吞光：** 沿用DEC-106的不可走侵蚀区／VOID规则，新增灰绿破损边缘与黑暗内部有明确区别，肩灯照射会被截断。独立 QA 还发现绿反光能穿过单侧对角缝，修复后真实 WebGL2 的7例全部通过，修前3例失败。占空造成的视野缩减逐帧读取，不再等待污染值变化事件；沿用 Host 既有更新顺序，接触位置仍可能晚一个游戏帧。
- **真实污染体：** 低／中／重为占漆2／4／6、占空1／2／3；占漆真实接触面积约13,312–16,384／30,720／59,392–61,440px²。占空部署包围区9,216／24,576／46,080px²，实际危险仍由体内密度和活动周期决定，不能将整个矩形称作常驻伤害区。沿用正式 Host、受光、接触与视野系统，不以装饰冒充污染体。入口—搜取—撤离保留20px身体和额外8px余量的无强制污染路线。

**光学范围澄清：** 静态侵蚀多边形仍映射为既有VOID，身体不能进入；当前增强其侵蚀边缘和吃光可见性，不宣称新增“地面尚存、可进入但被Host完全遮黑”的独立光学层。真实占空的视距缩短也不等于完整吞光。此前制作单中要求Host承担全部黑区的表述超出实际，本批不据此虚报实现，也不暗改旧VOID规则。

同起点、相同准备的安全停留便能体现等级差异：DEV实际起始污染15、核心倍率0.79时，90秒约32.06／45.40／64.02；180秒约51.79／83.26／130.02。安全移动与站立使用同一时间曲线，触碰污染额外计价。抗性仍对增量有效，不能把示例抗性当当前装备赠送。完整搜撤、收益与准备平衡仍属后续等级闭环，不据短样本宣称已平衡。

## 本轮实现边界

- 地床/普通景观、实体阻挡、侵蚀吞光、真实虚空分开声明。`solid` 阻挡身体及攻击，`relief` 可走；普通景观的背光面仍由原生有限视野观察。独立侵蚀区拥有完全不可见的光学语义，不能从物体高度或画面黑度推导。
- 三张原始材料母片为材料绘制来源，经过固定像素化、表面区域与坐标映射进入连续地床/实体表面；不是整场景背景。形体、浅起伏、法线、AO、接点发光、运动与光照仍由确定性代码驱动。源图、制作约束和哈希在 `public/assets/r100-materials/README.md`。
- GPU材料受光层在原Rift fog之下；普通自阴影仅削弱局部入射光，不删除地面或目标。额外的CPU像素逐帧重绘已改为四张静态材料输入和每帧灯光uniform；原生像素、960×640画布、1.5镜头、角色、80px/s速度和20px身体保持。
- 同源几何提供厚切面、曲束与内腔，角色遮挡只消费实体角色掩膜；被击败敌人的已销毁显示对象不再继续求getBounds。加载失败/重建撤销释放纹理、离屏GL和声音；旧异步加载错误不能覆盖新选择。
- 接点蓄压、短峰、回落与材料碎屑同钟；碎屑方向绑定实际产生光的mesh，不能用过滤后数组下标套未过滤mesh。音源仅复用已有环境摩擦/阻力，最多两声部，不复用受损或奖励提示。本轮不声称压力伤害、等级奖励、准备选择已经完成。
