# I02 原生实体试制：首批工程与实际退回

这是 I02 的技术批次，不是 I02 结单、九格母版通过或新世界资格。入口为 `/rift-r100-masters.html`；当前正式出击仍用封存 v1/v2。完整压力、选级、等级收益、材料声音尚未接入。独立美术裁决在[集中记录](../art/rift-r100-i02-review.md)，不得由下述测试覆盖。

## 实现与工程验证

CSV 编译九格作者配置；共享顶视几何编译可见面、UV、法向、高度、实体物质与独立 8px 物理/光学掩膜。20px 身体的出生/翻找/撤离站位先验实体再部署。原生角色、80px/s、视野、操作和场景生命周期复用。无悬挑下穿越或第二层通行能力。

DEV 部分视野查询保持原范围/朝向/混乱带，实体另求实际高度和 opaque VOID；游戏目标继续使用原完整 LOS。视野缓存消费 `VisibilitySystem.getQueryRevision()`，不以装饰时间代替视野变化。高度场射线按静态几何缓存，光源任何 XYZ 变化失效；强度/色变不复算几何。实测没有宣称 GPU 或原生内存上限已通过。

巡查按钮提供显式可选输入方向，键盘优先；正式入口不提供这个回调。原 Player 仍拥有归一化、速度、加速度、碰撞、朝向和动画。路线从身体完整支撑网格求得；不会通过瞬移绕过实际碰撞。它用于开发审查，不是自然试玩或玩家体验证据。

针对检查：几何 59 项、18 作者配置/种子与 VOID/非法参数共 24 项、输入/巡查 12 项；部分视野 16,900 点；缓存射线 5,310 次比较，包含 1,707 次真实遮光变化。现有视野能量、占漆完整形体/部分可见/旧表现回归通过。统一构建、恢复与最终复核结果由本文件末段登记。

## 真实浏览器证据

Codex IAB，固定 1600×1040，DPR 1；逻辑 960×640，相机 1.5。通过页面按钮操作，没有浏览器私有游戏对象注入。折板/低/20261002 的完整巡查从入口经过侧缘、背面、另一侧、翻找点，再返回：24.071 秒，实际累计 1580.17px，计划 1504px（转向/制动会产生实际路程差）。未发生堵塞退出。[诊断与 0.5 秒轨迹](artifacts/rift-r100-i02/slab-low-r4-patrol.json)，[返回画面](artifacts/rift-r100-i02/slab-low-r4-patrol.png)。一份被热更新中断的早期记录已被这次完整重跑替代。

同次移动前段的 2 秒预热 + 12 秒采样：帧间隔 p95 **20.1ms** / max 38.1ms；CPU 提交 p95 **18.9ms** / max 36.2ms。帧间隔略高于20ms目标、CPU高于12ms目标，**性能未通过**，R100-P02继续开放。这不是60秒长路线、GPU耗时或回收后保留内存验证。

此前[重档 R3 诊断](artifacts/rift-r100-i02/slab-severe-r3-diagnostic.json)记录静止 CPU p95 26.5ms/帧间隔27ms，属于更早的形体与缓存实现。不能与最终低档移动样本直接算优化百分比，也不能把中途机器争用下的秒级冷调用计为算法基准。

## 实际美术判定与下一批

[低档 R3](artifacts/rift-r100-i02/slab-low-r3.png)与[重档 R3](artifacts/rift-r100-i02/slab-severe-r3.png)均被退回：扇面/薄片读法、平填面、与地床分离。改为厚体后，[低档 R4](artifacts/rift-r100-i02/slab-low-r4.png)证明了宽斜断面及肩灯受光可以成立；仍因规则围台、重复锯齿纹、材料层级不足而退回。

下批只推进折板局部：三条不等厚的连续层位同时控制厚度、断裂、压合与材料区域；一端埋回地床、另一端在真实折轴错断。保留已有几何/受光底座，不再在薄带和平填面上加随机细节。先同站位复审，过关后才迁移束/壳和逐级扩展；不让用户替内部审查批准不合格样板。

动态目前主要是接点光的有序增强与回落，未达到三种物质的完整运动、危险相位或声景资格。第二种子虽改变几何，尚未逐图美术审查。九格配置、代码入口及自动路线均不计合格世界：仍 **0/108、0/324**。
