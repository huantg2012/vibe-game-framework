## 实际变化

原5世界×2空间仍是基础配方，新增CSV定义的沉积、定向断裂、聚合过程。条件编译器先检查能力兼容，再冻结连续参数与六条随机支流；地貌侵蚀、材料和景观共用方向场。新出击使用v2，旧v1及更早无generation局保持原生成路径。

资源布置从随机格子分档变为路线与最终敌人能力共同决定：短路/低暴露绕路、顺路安全堆、受感知覆盖的争夺堆和需明显深入的高价值堆。普通布置不合格时，最多12个确定性候选组织一个非出口敌人，不改变身份、形态或配额。完整占漆必须在同一轮部署中落座，并避开11个资源点与低暴露退路的身体带。

深区成本精查真实8px支撑、20px身体、48px可见翻找圈及可撤离站位；在可用站位之间取最低额外网格路程与最低接近风险。它不是连续任意角度运动的数学最优证明，潜在暴露也不是命中概率。实际等待、观察、战斗和长期重复体验未被自动指标代替。

三处导航地标采用同世界原生的层理、晶面、剥釉分面绘制，周边降低普通散布。它们可跨越、不发奖励光、不伪装新碰撞；局部反射/沉降/剪移使用原地表活层并受真实支撑和视野裁切。新增运动遵循减动偏好；Scene暂停和终局不推进活层。实际观感待用户复看。

## 验证入口与范围

- `npm run check:world-conditions`：CSV产物一致、能力/范围/版本拒绝、条件确定性与独立流；最终形态威胁、8向路径、资源分档、遭遇重组及交互站位反例。
- `npm run worlds:compile-library`：30个组合各代表值/上下界，加4个正式选池种子；保留全部拒绝记录、实际条件/种子、语义指标与生成依赖哈希。[当前资格库](artifacts/rift-conditions-2026-10-02/library.json)。有限样本通过不代表所有连续参数、所有种子或人工品质准入。
- `npm run check:rift-recovery`、`npm run check:world-production`：旧无快照及v1金样、v2冷重建、完整占漆/退路身体扫掠、随机正式出击和小地图。[恢复输出](artifacts/rift-conditions-2026-10-02/recovery-final.txt)、[生成输出](artifacts/rift-conditions-2026-10-02/world-production-final.txt)、[源版本](artifacts/rift-conditions-2026-10-02/regression-source.json)。
- `npm run check:world-scenery`：五世界地表原图、unsupported纯黑、灰度身份、材料尺度差异、动效时间与合成状态。[地表记录](artifacts/rift-conditions-2026-10-02/scenery.json)。这是未加游戏迷雾的烘焙检查，不冒充实际玩家可见全图。
- `node tools/qa/check-rift-conditions-browser.mjs`：隔离Chrome，真实新建/移动至入口/备行/出击/暂停/刷新继续/走路/长按E搜取/撤离/首归和关闭报告。读取完整地形规划路线，不设人物状态、不传送、不改种子或游戏时钟；因此是诊断导航，不是陌生玩家首次体验。[实际记录](artifacts/rift-conditions-2026-10-02/browser/report.json)与同目录录像/截图。用户自己的浏览器和存档未动。
- `npm run build` 包含TypeScript与Vite生产构建；另执行 `git diff --check`。仓库没有独立全项目lint脚本，不声称执行了它。

## 检查确实改变了实现

1. 旧曼哈顿距离高估八向移动；改8向欧氏成本并禁止穿角。
2. 转面形态按360°估计会错误地把背面资源当危险；改真实初始方向±45°转面范围，静态身体也进入不可走格。
3. 占漆在语义检查后落座可能切断退路；改为同地貌重排的一部分，用实际危险场及20px身体扫掠独立复算。
4. 原随机敌人位置导致某些世界全部候选耗尽；增加有限、确定性的分支遭遇组织，出口守卫和形态预算保留。
5. 原deep以节点中心计费，忽略48px翻找范围。独立细格复算发现seed0一堆中心411.8px、实际313.7px，seed70421一堆中心429.3px、实际352.0px。旧结果未达到其承诺的377/425px阈值，已增加真实交互站位精查并保留反例检查。

`library-before-paint-retry.json` 是早期90例诊断；`library-before-interaction-seat.json` 是交互圈修正前94例结果。它们当时通过的门槛不足，不证明最终合同。

浏览器最早一轮在生成代码仍变化时写入v2，刷新签名不同被拒绝，保留 `browser-development-drift`。第二轮 `browser-input-too-early` 的记录在独立冷进程全部校验通过，实际失败是测试驱动在首页图解码完成前按Enter；驱动现等待真实按钮enabled，只输入一次，不改游戏菜单。失败轮保留报告、存档和关键截图，删去重复首页/录像。随后通过的一趟归档为 `browser-before-interaction-seat`，不覆盖后续合同修复；最终 `browser` 是修正后的重新实跑。
