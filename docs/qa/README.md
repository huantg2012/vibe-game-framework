# 验证与质量记录

本目录保存自动检查、复现与操作实录、实现合同核查、代码/集成审查和修复验收。它回答“这项实现是否满足既定要求，实际验证过什么”。

**游戏设计与美术等专业审查结果已集中到 [docs/reviews](../reviews/README.md)**，用于判断体验、设计关系和品质问题。请从[审查浏览器目录](../reviews/index.html)查阅，不再将新的专业审查正文放在这里。

- `iteration-*`、`report-*` 等：对应任务的实现及验证记录。
- `artifacts/`：测试与取证材料；旧专业审查已封存的原始证据继续原位保留。
- `_template-report.md`：机制验收模板。
- 原审查文件名：仅为旧链接兼容指针，正文只有 `docs/reviews/` 一份。
- 原 `reports/` 网页：仅保留跳转；审查摘要在 `docs/reviews/interactive/`，设计与内容展示在 `docs/reading/`。

测试通过不等于审美、好玩或长期平衡通过；审查建议也不等于整改已验收。两类记录通过链接关联，各自保留范围与时点。
