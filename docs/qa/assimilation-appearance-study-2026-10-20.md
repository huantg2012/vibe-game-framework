## 本轮实现

使用实际A人物、晶化林床156、破膜盆地82和真实Last Light净化点，保留原肩灯、场景光、深度遮挡和持具。晶纤沿上身形成束，膜面位于腰侧/衣摆；来源混合按身体局部区域分布。同化连续增加覆盖与法线起伏，两个局部材料相位连续运动；疗愈沿同一固定组织位置消退。页面可移动、挥击、切真实姿态方向、暂停、单源/混合比较、原角色对照，并保留切场时的来源比例。放大图从实际POST_RENDER画面裁取，没有另补光。

Rift首次显式启用时为208帧建立稀疏掩码；Haven在现有shader内计算同源区域，不增加sampler或pass。两者都在实际受光前改材料，不向人物添加自发光。净化点主观层只在远/中层已有暗表面低幅变化，近层、平台/设备、人物与能量覆盖保留。

本轮**没有**新的骨架、外轮廓、坐姿同化、持久来源谱或正式玩法接线。坐下显示原人物，页面已提示。逆yaw局部坐标能支持本次材料小样，不能冒称完整关节静息坐标蒙皮。运动为组织表面相位，不改变脚点、持具与战斗时序。余烬脊及自然跨趟/疗愈保存不在本次验证范围。

## 实际验证

Chrome 155，1360×1160，960×640实际游戏场景，deviceScaleFactor=1；每场独立context。三场共17项检查，零page error，15张材料/姿态图和3张整页图。[运行回执](artifacts/assimilation-appearance-2026-10-20/report.json)覆盖真实移动、两Rift实际挥击冒烟、动态时钟、暂停冻结、零浏览器存储写入。截图中的“side”是选定源yaw的斜侧视，不是严格正交侧视，也不能与首轮不同朝向做严格像素前后对比。

[固定画面检查](artifacts/assimilation-appearance-2026-10-20/pixel-checks.json)直接调用实际renderer，冻结相同姿态、照明与场景时间：

- A0与默认null：Rift/Haven均0差异像素。
- 关闭组织运动后仅改变打版时间：均0差异像素。
- 打开组织运动：Rift35、Haven42个实际像素随时间改变，证明不是静态换色页面。
- 同一混合态分别不同于两个单源；A0.5变化总量小于A1，回到0逐字节恢复原画。
- Haven主观层确有60,053个远中暗部像素发生低幅变化，最大差3/255；这是受控固定帧程序验证，主观压抑感仍待人审。

208帧实际图集纯检查通过：105,753个稀疏像素、材料覆盖连续/有限值/来源差异、两手/灯/帽/靴保护、左手审查反例。A100正向可变布面覆盖约58.85%，各视角因遮挡/保护区投影不同为34.9–66.7%；不宣称每视角严格45–60%。既有玩家呈现/生产合同/持具回归由实现代理运行通过。`npm run typecheck`和`npm run build`通过，构建保留既有大chunk警告，见[日志](artifacts/assimilation-appearance-2026-10-20/build.log)。仓库无lint配置，不声称lint通过。

独立art复看最终晶化混合斜侧、破膜混合、净化点混合三帧：首轮混合不明显的问题改善，玩家身份保持，可交用户判断。正常尺度先读到两块异源材料，组织细节在3×更清晰；静图意见不签署动态或完整角色异化的审美通过。

## 性能：新增成本与限制分开

新增Rift掩码固定740,271 B，约0.71MiB，来源/同化/时间变化不增长缓存；固定帧检查测得首次准备约5.7ms。Haven无辅助掩码、无新增纹理槽或全屏pass，首次setter约0.1ms；shader初次编译及原场景准备不含在该数值内。

放大读回关闭、相同场景固定镜头，A0/A0.9各两个2秒窗口，交替采样：

- 晶化角色CPU render平均约0.185→0.206ms，增量0.021ms；p95均约0.30ms。
- 破膜角色CPU render平均约0.274→0.299ms，增量0.025ms；p95为0.30–0.40ms。
- 净化点整个compositor CPU提交平均约0.146→0.278ms，波动明显，p95约0.20–0.50ms；这是提交耗时，**不是GPU执行时间**。
- 实际POST_RENDER帧间隔中位数约16.6–16.7ms；p95裂隙约22.1–24.3ms、净化点约17.9–18.4ms。不能据此宣称全场稳定60fps或长期发行性能达标。

页面只运行一个游戏实例；Haven仍有既有Phaser和专用compositor两个WebGL上下文。切场用整页导航销毁上一场。3×放大是额外GPU画面读回，性能比较已关闭，正式游戏无需这项开销。

GPU timer、低端硬件、长时间内存/帧峰值、全动作与全角度动态审美尚未验证。已有50ms/I14/P49继续开放。后续若扩姿态/轮廓，必须重新核算，不以本轮材料成本给未来功能背书。
