# 外部评审协议：俯视潜行生存与撤离类游戏

**目的：第一次接触游戏的评审组，能够独立判断它承诺什么体验、实际产生什么体验、哪些因素阻碍体验，以及后续制作是否值得投入。**

本文件原地替换上一份以项目问题为中心的规范。协议与执行记录分开：2026-09-18的[地图样板专项](rift-world-review-2026-09-18.md)不代表整游戏；随后按[全游戏补审计划](game-wide-review-plan.md)完成有限覆盖的[实机补审](game-wide-review-2026-09-18.md)，阻断和未测项另列。正文从品类假设推导，既有版本、作者反馈、项目画法和实现参数不作为首轮的及格标准。适用对象包括完整可玩版本、地图样板与生成器；不同对象可支持的结论分别限定。

## 1. 评价架构：先有体验问题，再分专业工作

评审以一条可追溯的链条组织：

**品类承诺 → 玩家目标 → 掌握的信息 → 可选行动及代价 → 系统后果 → 玩家理解与感受 → 下一次选择。**

每个问题都应指出这条链上的缺口。随后才追查关卡、规则、视听表达、交互或技术实现的原因。职业分工负责从不同角度验证同一条链，不能各自列一份不相交的检查清单。

机制、游戏过程与体验之间的关联借鉴 MDA；本文的具体品类判断与评审程序是针对本次任务提出的方法，不是文献验证过的专用品质量表。[MDA 原论文](https://aaai.org/papers/ws04-04-001-mda-a-formal-approach-to-game-design-and-game-research/)

### 三个嵌套的评价对象

1. **游戏体验**：一次与多次游玩是否值得，玩家能否形成、执行和修正自己的计划。
2. **内容及表达**：空间、遭遇、资源、视听和交互如何共同产生这种体验；地图在这里承担什么作用。
3. **生产系统**：运行、生成、创作与维护怎样支持上述质量，成本与覆盖范围是否可承担。

低层实现成立不能自动推出高层体验成立。高层体验的失败也不能在未经诊断时直接归咎于某种技术。

### 美术的评审权重

美术作为主要判断维度，单列“美术设计归类与品质判断”。原则上为美术专项安排约三分之一的取证与报告投入；这是关注度安排，不是加权总分，也不要求凑篇幅或挤掉重要的玩法问题。

美术可以直接创造兴趣、情绪、地方感与作品身份，无需先证明它改变了某次操作才获得评价资格。整体视觉语言、表达力度或完成度不成立，可以独立影响交付判断；玩法与技术成绩不能将其平均抵消。声音和游戏手感继续保留各自判断，美术专项投入不以它们代替。

## 2. 品类假设：带着问题进入，不带着答案进入

初始最小简介为：**俯视2D、单人、潜行/生存、搜集并撤离、程序化关卡。** 这些标签用于提出下列待验证假设：

- **潜行**：获取和利用局势信息能改变行动结果；玩家有控制暴露、规避或应对威胁的机会。
- **生存**：有限资源及状态会影响计划，管理它们具有情境性，而不只是周期性操作负担。
- **搜集与撤离**：继续获取和保全现有收益都可能合理；撤离决定应与局势、目标或代价发生关系。
- **单人体验**：主要的博弈和意外需要由世界、规则和玩家知识产生；不预设多人竞争的刺激与社会交互目标。
- **程序生成**：跨局变化能重组问题，已学知识又能迁移；需要同时考察惊喜、稳定性和重复感。
- **俯视2D表达**：相机、遮挡、动作和视觉层级要共同支持空间理解；不预设像素尺寸、照明方式、明暗取向或题材。

不能从标签推出永久死亡、局外成长、重惩罚、必须战斗、某种视野、某类障碍或某种地貌都是必选项。游戏可以偏离惯例；评审要说明它的替代方式是否成立。首次体验后记录“我们认为这款游戏在邀请玩家做什么”，再与作者意图对照。

## 3. 沿完整循环、三个时间尺度取证

### 循环节点

准备或定目标 → 进入并定位 → 探索与判断 → 获取并承担代价 → 应对变化 → 决定深入或离开 → 理解结果 → 形成下一次目标。

节点允许合并、简化或采用不同形式。每个实际存在的节点统一问五个问题：

1. 玩家当前想达成什么？
2. 玩家知道什么，怎样获得尚缺的信息？
3. 有哪些实际可用的选项，它们付出什么代价？
4. 执行后得到什么反馈与后果？
5. 结果是否改变后续计划或形成可迁移的认识？

### 三个时间尺度

- **瞬间与局部行动**：输入、观察、反应、操作反馈和状态辨认。重点是控制、读法与因果。
- **一次完整出行**：路径、遭遇、资源消耗、机会成本与离开时机。重点是节奏、计划调整与结果价值。
- **多次出行**：经验迁移、不同策略、恢复成本、内容变化及再次开始的动机。重点是学习与重玩。

不按固定秒数定义一次体验。一次决策须观察到后果；撤离与学习的判断须覆盖完整出行及后续尝试。缺失某一尺度的材料，相关结论留空。

## 4. 六个质量领域

所有领域使用同一结构：**要成立的体验关系／反例／取证方式**。领域之间可以共享事件，但不把一个根因重复计算成多个独立缺陷。

### Q1 目标、选择与价值

- **判据**：玩家能够形成目标；在不同局势下，不同选项有成立的理由；收益、时间、资源和风险能够影响计划。
- **反例**：没有上下文地重复捡取；总有明显通解；所谓取舍由必选项伪装；继续和退出的价值长期失衡。
- **证据**：记录若干真实决策前后的目标、状态、选项与后果。对照保守、冒险或不同资源状态，不强迫所有策略成功率相同。若使用真实玩家访谈，询问当时为何如此选择，不先告诉正确答案。

### Q2 信息、控制与公平

- **判据**：玩家能获取、试探或事后追溯足够信息；风险存在不确定性，但行动规则可学习；输入和反馈可靠。
- **反例**：关键读法反复误导；失败原因无法解释；获得信息无实际用途；控制失误与策略失误混在一起；要依靠作者口头说明才能避开常见后果。
- **证据**：首次遭遇、失败、重新尝试的连续记录；玩家事前预期与事后解释；针对输入、显示或规则的复核。紧张感与操作障碍分开分析。可访问性同时检查必要信息是否过度依赖单一颜色、细小图形或单一感官通道。

### Q3 空间、遭遇与节奏

- **判据**：空间改变观察、到达、暴露、追逐、搜集或退路的条件；相邻情境有节奏，紧张与喘息都服务整次出行。
- **反例**：分岔只改变步行距离；地标不能帮助辨路；全程奔跑或全程高压；关卡只有可达性，没有局势变化；相同摆放机械重复。
- **证据**：路线选择与改道事件、资源/威胁分布、迷路及回头片段、完整出行节奏。地图全貌用于解释组织，正常相机下的连续体验用于判断实际效果。开放、狭窄、室内或室外都可以成立，不在评审前限定答案。

### Q4 视听表达、环境美术与游戏手感

环境既承担行动信息，也具有独立的情绪和艺术价值。信息清楚、技术精细、审美有力分别作出判断。

#### Q4-A 美术设计归类：先识别画面正在使用的语言

在A阶段从实际画面独立归类，不提前采用作者的风格名称、参考游戏或技术说明。归类采用以下六个观察轴；它们是描述工具，不是要求作品只能落入一个固定流派。

1. **空间与投影**：俯视、轴测或透视的观感；平面、分层、体积及遮挡的组织方式。描述画面如何建立空间，不凭观感断言底层使用2D还是3D。
2. **画法与图像语言**：像素簇、线描、平涂、绘画笔触、照片拼贴或模型渲染观感，以及边缘、轮廓、细节尺度的规则。“像素风”只完成本轴的一部分，不能作为整款游戏的完整归类。
3. **造型与材质语言**：比例、抽象程度、夸张方式、几何/有机倾向、剪影，以及表面怎样表达材料。分别说明角色、环境、物件的共性与差异。
4. **色光与构图语言**：色彩关系、明度块、冷暖、照明方式、焦点与留白；描述组织规律，不只罗列色号或“明亮/黑暗”。
5. **视觉母题与情绪**：可见的自然、工业、生物、历史或幻想语汇，以及克制、荒凉、温暖、诡异等情绪读法。题材和情绪分开记录，不据此编造世界设定。
6. **运动与视效语言**：动画的姿态与节奏、镜头运动、特效形状和时间变化；判断它们延续了何种视觉语言。只有静帧时本轴标未验证。

每个轴给出可见依据和判断把握。最终形成“主导风格＋次级语言＋分布与衔接规则”的描述，分别检查角色、环境、物件、界面与特效；未提供的部分标未覆盖。

- **混合风格**：说明不同语言分别承担什么、靠什么联系，辨别有组织的混合与缺少衔接的拼接。
- **尚不能明确归类**：区分观察材料不足、存在多个合理候选，以及作品的视觉规则尚未稳定；不强贴标签。
- **技术归属**：手绘、程序生成、三维渲染转图等制作事实在D阶段确认，另列技术档案。归类依据是玩家看到的结果，不能把推测的制作流程当成事实。

归类先于品质评价。明确采用某种语言不代表执行成功；粗糙、廉价感或未完成也不能自动命名成一种风格。有意粗粝、低保真或不协调的表达，同样需要说明其组织规则与表达效果。

#### Q4-B 美术品质：在识别出的语言内评价表达与完成度

- **构图与空间表达**：大形、负空间、层级、尺度、遮挡及连续视口的组织；世界有可辨的形态与地点记忆。
- **视觉语言与完成度**：形体、材质、色彩、明暗、笔触与运动协调；细节有选择，重复有节奏，静区有表达；不以复杂度或写实程度直接计分。
- **情绪与身份**：画面及声音能建立兴趣、气氛与世界性格；独特性不完全依赖简介和名称。
- **行动与感官反馈**：角色动作、镜头、声音、特效和响应时机让行动有重量、因果与辨识度；装饰不会持续淹没必要信息。

**反例**：功能清楚但画面平庸；视觉华丽但难以行动；不同层像临时拼接；一段镜头成立而移动后失去组织；声音与画面提供互相冲突的信号。

**证据**：首次无解释观看、正常游玩、代表性状态的连续视口，以及针对构图/材料的局部诊断。保留评审者明确的艺术判断及其依据；实际玩家反应需另做用户研究，不能由专家审美代替。

美术报告必须分别回答：**它属于怎样的美术设计；这种语言是否清晰且有自身辨识度；执行是否成熟；与实际玩法是否相容。** 每项给出优点、主要问题和证据。允许“归类明确但执行薄弱”“视觉精致但缺少身份”“艺术表达成立但行动读法冲突”等不同结论，不能用一个“好看/不好看”覆盖。

### Q5 学习、变化与重玩

- **判据**：玩家逐渐理解规则，能够用知识改进判断；新局变化带来新情境，同时保持可学习的规律；成功与失败后都有合理的下一次尝试空间。
- **反例**：失败主要增加重复劳动；生成结果很多但决策一样；随机性抵消学习；某些组合系统性失效；变化太弱或太乱，难以形成期望。
- **证据**：同一人的后续尝试、不同经验者的独立观察、多局策略与失败分布。把布局差异、艺术差异、策略差异分别记录，不用种子数量代理重玩价值。

对生成器的技术分析关注输出特征的分布、偏置、空缺及输入影响，参考“表达范围分析”的思路；它提供变化证据，具体体验价值仍由本节任务验证。[Expressive Range 原论文](https://www.pcgworkshop.com/archive/smith2010analyzing.pdf)

### Q6 交付可靠性与制作可持续性

- **判据**：在声明的平台、设备和内容规模下稳定运行；等待与卡顿符合游玩节奏；内容创建、扩充、验证与修改成本可承担。
- **反例**：整帧体验明显失稳而只提供某函数耗时；生成或换图导致持续等待/内存增长；扩大内容后须逐张返工；创作工具无法定位失败；一种优化破坏另一种关键体验。
- **证据**：实际运行、首次与重复加载、整帧分布、失败恢复、内存趋势，以及一次有代表性的内容扩充与修改记录。制作期、加载期、每帧成本分别计量；目标与预算在测量前声明，未知硬件或成本标未知。

此阶段可以查看架构和素材管线。手工、程序、预生成、实时生成均按质量、控制力和总成本评价，不先指定正确技术路线。

## 5. 四项跨领域裁决

1. **紧张与公平**：不确定性是否仍给玩家可利用的线索或可理解的后果？不能通过泄露全部信息来机械消除不确定性。
2. **惩罚与学习**：代价能否让选择有重量，同时保留合理的试验与再尝试机会？不能把高损失直接等同于深度。
3. **惊喜与一致性**：新情境是否要求重新思考，同时保留关键规律？少见不自动构成不合理。
4. **表达与行动**：神秘、丰富或强烈风格带来的体验价值，是否值得其增加的理解负担？把有意保留的歧义与反复误导分开。

先列收益、代价与证据，再裁决取舍。不要通过给所有画面增亮、所有风险显式标注、所有地图变宽等通用处方，提前抹去游戏个性。

## 6. 外部评审组与信息披露

### 分工

- **游戏设计/制作负责人**：维护完整循环、玩家价值及优先级；聚合问题，避免只修局部表象。
- **美术负责人**：首先完成有证据的美术设计归类，再独立判断感官吸引力、视觉语言、环境与情绪表达；与行动读法交叉复核。拥有独立的品质结论，不只为玩法或技术作附属说明。
- **技术美术负责人**：复核显示、动作、材质、性能及创作管线如何支撑体验；在技术资料披露后调查原因。
- **研究记录职责**：统一任务、记录、证据类型和结论边界，可以由一人兼任。

这些是分析职责，不表示已经招募了相应真人。首轮审查者不得参与被审内容实现，也不得接收其历史反馈；做不到时明确标为知情专家审查。隔离上下文的agent仅收到最小简介与本协议，不能把模拟视角称为真实用户测试。

### A阶段：首次接触

只提供正常玩家可得的简介、操作/教程、可玩版本、运行条件与必要的已知启动故障说明。保留正常引导，不刻意删教程来制造盲测困难。隐藏作者解释、旧评分、精选截图、修复清单、设计正文与实现。

各审查者先独立体验并封存按时间排列的记录：看到什么、预期什么、做了什么、发生什么、当时怎样理解。未经提示自行发现的部分单列。需要外部提示时记录提示内容与时间；同一人后续重玩不能再次算首玩。

美术审查者同时封存初步六轴归类、主次语言及证据。C阶段才将其与作者宣称的风格对照；D阶段确认实际制作技术，不能回写成首轮已经知道的事实。

### B阶段：有针对性的重复体验

先由首轮观察提出可被推翻的假设，再设置任务或受控比较。例如比较不同资源状态下的离开决定，或观察首次失败后的下一次解释与行动。优先解释高影响矛盾，保留竞争解释。

若有真实用户，分别记录其品类熟悉程度与设备；可覆盖新手、潜行熟手、撤离类熟手。样本规模须与研究问题相称，不能凭角色模拟或少数专家推演计算用户满意度、学习率或人群成功率。

### C阶段：披露创作意图

封存首轮判断后再阅读作者定位、目标人群、叙事和美术意图、已知缺项及制作约束。形成三个独立栏目：作者希望发生的事；实际观察到的事；两者之间的差距及可能理由。

作者的解释可以澄清事实、提出设计取舍，不能抹去首次误解的记录。游戏自身明确教会的规则用于后续一致性检查。题材与世界观的完整考据在此阶段进行，不先拿内部设定替玩家解释画面。

### D阶段：技术诊断与生产建议

最后查看代码、生成规则、数据、素材、性能与工具链。按证据区分症状和原因，为重要问题提出候选解法与最小验证实验。制作约束独立列出；建议与作者约束冲突时明确呈现，不擅自修改游戏。

## 7. 按决策覆盖取样

任务来自实际存在的循环：理解目标、定位、规划、判断威胁、规避或应对、获取与取舍、处理突变、离开、失败归因、再次尝试。每个任务记录状态、信息、行动、后果，而不只保存画面。

样本选择同时覆盖：

- 常见情境与默认流程；
- 对高影响问题的失败/边界情境；
- 未参与调优的随机结果；
- 不同资源、压力、熟悉程度及适用硬件状态。

固定回归样本用于定位变化；新样本用于探查适用范围；失败样本用于复核修复。生成前记录抽样方法，公开拒绝、重抽及回退；不能悄悄筛掉难看的或难玩的结果。

截图数、地图数和录像秒数由证据需求决定，不预设“看够固定数量就合格”。在约定预算内覆盖主要任务及风险；预算耗尽仍存在缺口时，报告缺口。以解释清楚的决策事件和可复查分布结论收尾，不作无限样本承诺。

## 8. 判定、严重度与证据边界

### 每个领域的质量结论

- **成立**：其体验关系在声明覆盖范围内得到支持，关键反例已处理或得到合理解释。
- **脆弱**：局部成立，但依赖特殊条件、熟练知识或未经确认的设计取舍。
- **不成立**：反例持续破坏该领域承担的体验功能，或艺术表达明显未达到声明目标。
- **未验证**：材料、时长、可玩范围或用户证据不足。未实现也不能用推测补齐。

不把六领域简单加总为一个总分。独特优势单列，同时说明它在哪些条件下成立。整体结论由核心循环的证据、严重问题及支持范围决定。

美术的整体表达与完成度问题按其对作品身份、持续观感和吸引力的影响定级，不默认归入“有限的表现瑕疵”。风格归类的置信度与美术质量结论分别报告。

### 每个问题分别标注

- **影响程度**：阻断核心任务／破坏关键判断或长期体验／可恢复的局部摩擦／有限的表现瑕疵。
- **影响范围**：哪些情境、内容、用户经验或设备；未知则明示。
- **证据把握**：直接可复现证据／重复专家观察／单次现象或假设。美术判断另注明评审者与观察条件，不伪装成机器结论。
- **竞争解释与反证**：什么别的原因也能解释现象；出现什么结果会削弱或推翻当前判断。

严重度不代替复现频率和置信度；一处严重问题无需靠凑数量成立，多处轻微问题也可能累积破坏体验，需说明累积路径。对同一问题的证据不足不能被误写为没有问题。

### 局部版本的结论上限

- **只有画面**：可作艺术表达与静态信息层级判断，不能判游戏循环、操作或性能。
- **可移动地图样板**：可检查空间感、行动读法、镜头、局部反馈与运行；完整风险收益、敌人博弈、撤离及重玩动机仍需实际系统。
- **完整可玩循环**：可以研究出行体验；长期学习与重玩仍须多局及适当用户证据。
- **生成器与数据**：可以检验结构、覆盖、可控性和成本，不能单独证明产物有趣或好看。

专家审查发现风险和形成判断；真人研究验证玩家反应。报告明确哪些已做、哪些只是待测假设，不把多agent结论包装成目标人群调查。

## 9. 报告与后续决策

报告固定包含：

1. 外部评审组实际收到的材料、评审者背景、版本及信息披露顺序。
2. 首次接触时理解到的产品承诺，与作者后来声明的意图分别呈现。
3. **美术设计归类与品质判断**：六轴画像、主次语言、各画面层的关系、归类把握，以及表达力度、完成度、辨识度和玩法适配结论。明确哪些是作者意图，哪些是实际可见结果。
4. 完整循环及三个时间尺度的覆盖图谱，六领域质量结论与依据；引用美术专项结论，不重复计算问题。
5. 值得保护的独特优势，以及阻碍体验的主要因果链；报告最有影响的问题，不按部门平分问题数量。
6. 独立的问题档案：情境、可见信息、预期、行动、实际结果、证据、影响、竞争解释与反证条件。
7. **另列**处方候选：预期收益、风险、成本、前置依赖与最小验证实验。不要在原因未明时直接指定加纹理、换引擎或重做关卡。
8. 下一步制作判断：继续并保护什么；先验证什么；优先修什么；哪些方向需重新设计；哪些结论尚不能给出。

未来若使用参照游戏，应在定位明确后按具体体验功能选择，并在比较前声明维度、阶段、平台与受众差异。作者的旧版本仅用于回归，不能成为独立质量标准。

## 10. 全游戏审查的覆盖要求

六个质量领域是评价轴，不能替代对实际内容和循环的覆盖。执行前，协调者列明正式可玩入口、实际存在的系统、必要状态、已有证据及未审部分。首次审查者仍按 A 阶段接收最小简介；下面的清单在首次记录封存后用于补测，不提前教他们如何理解游戏。

### 必须逐项交代的内容范围

- **据点及准备阶段**：若存在可行走据点，审空间组织、装置与交互、状态可见性、准备操作负担，以及它与危险场景的情感关系。不能只检查面板是否能打开。
- **威胁与应对手段**：审敌人、环境危险、武器、工具及消耗品如何产生不同局势和选择；区分条目数量、数值差异与实际解法差异。物件的外形、动作、音效和用途理解一并检查。
- **成长与资源经济**：审获取、保存、投入、消耗、损失和恢复的完整链条；成长是否改变行动，是否产生长期通解、囤积、滚雪球或不可恢复的困局。没有长期数据时只能列风险。
- **跨局循环**：覆盖准备、出行、带回收益或失败、分配或成长、再次出行，并观察前一次的结果是否改变下一次选择。一次成功撤离不等于循环价值成立。
- **整体视听与学习**：贯穿首页、据点、出行、物件、敌人、界面、特效与声音，按六轴归类分别说明共性、合理差异及断裂；新手如何学会关键规则也是跨系统问题。
- **连续运行与恢复**：审跨场景、暂停、存档、继续、失败和重试中的状态一致性。技术恢复成功与玩家愿不愿意再开始分别下结论。

实际没有的系统标“不适用”并解释，不为满足清单发明功能。存在但本次没玩到的内容标“未覆盖”；历史已验收、代码存在或单项自动测试不能将其变成本轮已审。

### 覆盖、推论和整改之间的边界

1. 覆盖记录至少包含“系统或循环节点 → 实际状态与入口 → 操作事件 → 证据 → 可支持的结论 → 缺口”。不得仅凭六领域标题宣称完整审查。
2. 正式游戏、隔离实战样板、陈列馆和数值模拟分别登记；不能把不同入口的局部成功拼成一条从未发生过的完整循环。
3. 用于深层内容复核的预置存档须注明来源与改动，不能计为新手自然成长；模拟所得经济风险须由实玩核实其体验后果。
4. 同一次决策的机制、表达和技术原因共同归档，再排整改优先级。美术保持约三分之一的专项投入，并贯穿各模块，不集中到地图纹理。
5. 风格归类描述所见样本，不自动成为全游戏或生成器的输出约束；饱和度、色温和明暗倾向不得从局部样本外推为必选目标。
6. 区分新手局、已经学会规则的重玩及高级状态检查。AI 专家不能由几趟试玩推出长期留存、玩家群体偏好或整体经济平衡。

## 方法补充

目标、反馈、控制、挑战、学习与投入感等检查维度参考 GameFlow 的启发式思路。原论文的初步验证对象是即时战略游戏；此处按单人潜行/生存与撤离循环重新组织，不机械要求社会交互或承诺跨品类有效性。[GameFlow 原论文](https://www.valuesatplay.org/wp-content/uploads/2007/09/sweetser.pdf)

本协议中的品类假设、六领域、任务及裁决程序均为本次提出的评审方案。它们须接受实际观察的修正，不具有替作者作创作决定或替真实玩家作体验证明的权力。
