# 迭代21：正式裂隙中的构筑与遭遇对照

规格：`docs/tasks/iteration-21.md`、`docs/progress/content-expansion-plan.md`阶段一。代码基线：`2d9725f`后的本地迭代21工作区。本报告只验收阶段一的玩法实验入口与实际操作，不代表世界概念图获用户认可，也不将隔离训练库存当作持续供给验收。

**结论：对照场功能、隔离及阶段一代表实玩通过；没有该批遗留阻断项。** 三遭遇普通配置均能实际获取物件后撤离；技能允许改变通道的行动时机，轻装保留可测减负取舍，近战可以实际清除守卫。静默短路的高代价结果照实保留，各配置长期价值与总体平衡没有获证。整轮迭代21仍需用户选择世界方向，本报告不替代该选择。

## 方法与证据边界

使用独立新建、非持久化Chrome上下文；显式断言cookies/origins为空，正式存档键原先不存在才写入测试哨兵。未连接用户浏览器、未指定用户profile、未导入用户存档。自动审批第一次误将哨兵视作用户存档覆盖风险而拒绝；补充上述失败即停止的安全断言后批准重试。没有在用户已有存档上实施哨兵写入。

初始装备／遭遇由公开URL配置；之后只有真实keydown/keyup、鼠标点击页面、正常游戏时钟。场景API只读。没有瞬移、遥控敌人、直接调用技能、手推计时或免伤。位置阈值用于停止实际移动；周期试验在可见实体前停步，通过只读相位观测对齐观察条件。它是可复现操作实验，不是声称测试者只凭肉眼完成了盲测。

每条路线有独立目录、`evidence.json`（完整生产记录及关键观察）、截图与不拼接的`continuous.webm`。脚本：`tools/build-lab/qa-playthrough.mjs`。实际失败路线一并保留。录像无音轨，不作为音频质量验收；只有桌面Chrome，没有全平台或长局平衡结论。

## 已完成的真实玩法

- **被观察的捷径／白板**：北侧外圈进入、按住E翻找争夺物、循外圈返回，实际携回1件回声空壳；最终85HP、混乱42.13。目录`watched-bare`。
- **静默／轻装配对**：同种子、同fixture，先走到薄墙。静默实际F穿墙，耗带缺口的石头1次；轻装没有该能力，实际从墙北侧绕行。两者均翻找并携回同一族物件。初始负重分别9.0/16.0与7.0/16.0，速度倍率0.98与1.00；静默本次100HP、36.23秒，轻装85HP、35.13秒。两次仍各走北侧后半段，实际总路长相近；不能把这组单样本称作穿墙必定更快或免伤。它确认了可用动作、耗次与减负取舍。目录`watched-wall-quiet`、`watched-wall-light`。
- **周期／白板直行**：首次到达恰逢消散，未等待即直穿并携回1件沉重的石块。保留这条自然成功路线，证明工具不是唯一解，也明确这条样本不能证明法术收益。目录`periodic-none`。
- **周期／相位对齐**：在西侧可见气团处观察到蓄积。白板等待到消散再走，11.11秒到达东侧；延后和压制各实际Q耗1次，分别9.40／9.36秒到达东侧，三者都携回1件。白板付出约额外1.7秒等待，工具付出真实有限次数。通过时延后的气团仍处蓄积、压制的气团已自然消散，体现暂停释放与暂时抑制危险的区别。全趟后半段听觉敌人的警戒时序不同，不能把最终混乱差值全部归因于工具。目录`periodic-phase-none`、`periodic-phase-delay`、`periodic-phase-suppress`。
- **争夺点／白板**：真实北绕两道掩体、进入争夺物、翻找后撤离，100HP携回1件，32.20秒；有可走退路，没有必须用技能开锁。目录`contested-bare-fixed`。
- **争夺点／近战，修正真实转向后**：使用A实际转向左侧来敌，再按Space；三次真实命中事件27／25／28击杀75HP守卫，武器耐久60→57。Q／F／承伤被动各耗1次，受伤15HP，随后实际E翻找并携回1件，41.38秒、混乱47.79。相对白板快速取物，选择消耗资源清除守卫，而非证明近战无代价更强。目录`contested-melee-facing`。
- **静默短路／实际声诱饵**：穿墙后走中路并Q投出回声空壳，延长实际按住E至完成后撤退，携回1件；共耗2次、最终40HP、34.58秒。比轻装外圈仅快约0.55秒却多承伤45HP，**这次没有证明该短路有实用优势**；它是应保留的负面战术结果，不能通过调整正式技能数值来美化。目录`watched-wall-quiet-direct-lure`。
- **雾团／尘絮群合法目标抽查**：走近真实Host后Q压制，各耗1次，走入并穿过区域、折返实际E撤离；本项没有翻找，不冒充这两种宿主的完整收益对照。目录`periodic-near-suppress-mist`、`periodic-near-suppress-dust`。
- **自然死亡**：真实绕掩体走近敌人后站定，被实际攻击至0HP；正式账本`settled/death`，带入白板消失，未将死亡损失的剩余耐久错算为命中消费。目录`death-fixed`。

以上实际操作均保持测试上下文原存档哨兵不变。隔离专项另覆盖启动、暂停、配置切换重开、中止重开、刷新和出生点实际E撤离（`isolation`）；出生点撤离是零收益隔离检查，未计入上述玩法可行性。

## 失败与发现

- **确定说明偏差，已修复**：初版操作说明写“鼠标朝向”，实际`Player.resolveFacingTarget()`只随WASD方向，`CombatSystem`取该朝向。代码代理修正页面及开发合同为“WASD移动／转向”，QA复核实际文案，不改生产攻击行为。
- **配置聚焦暂停，已修复并补验**：初版配置控件聚焦未暂停场景；代码添加聚焦暂停，最终`isolation-final`真实点击种子输入框后检查场景已暂停、300ms内实玩时间不增长；修改配置仍需明确重开才生效。
- `periodic-delay`／`periodic-suppress`：初次站在x470，距真实核心约150px，大于128px，Q失败且不扣次。后续靠近x500成功；属于失败的操作路线，不记技能失效。
- `contested-bare`／`contested-melee`／`death`：初次北绕y176撞到第二道真实墙。改走y144，保留失败录屏；不是碰撞错误。
- `contested-melee-fixed`：玩家仍朝下，敌人从左侧接近，空挥未扣耐久；Q/F和承伤被动实际各消耗1次。敌人攻击打断翻找，最终空手撤离，**不计作近战抢夺成功**。
- `watched-wall-quiet-direct`：穿墙后尝试更短中路，虽然步行路径缩短，但守卫追来打断翻找，空手撤离。**不把缩短路线本身当作有效收益优势**。
