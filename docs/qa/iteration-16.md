# 迭代16验证

## 已实现

1. 出击组合限制为当前有真实行为消费的词素，完整CSV字母表仍可在练习场检视。休眠/脉冲/凝聚等未支持配方不再被生产抽中；没有将其偷偷重命名成常开。四种占据、地图数量与唯一听觉主轴保持。
2. 门框/街具固着，转面原地观察，巡游才导航；固着不受邻体分离、追击或工具击退平移。保留原五态与近身反击，镜像引导不授予真实玩家的近战资格。
3. R2虫残余在渗透档仍可辨认；改写档（R3）保留连续头胸腹、五足与残余双甲，污染集中替换一侧肩背和中足；覆盖档以扭转折返面和偏心空隙为主体，仅留一个分节残足。待机、行走、警觉、蓄势、命中、收势接入真实时间；生产、练习场和离线烘焙共享新baker。
4. 所有占地体的通用攻击信号改读真实攻击阶段；虫额外读取相位进度与承诺方向。受击/死亡池复制当前形体，模型销毁后仍能显示自身轮廓。

## R2：污染逐级取代基底

保留R1的步态时钟、攻击预备/命中/收势时序、伤害与碰撞范围，只替换覆盖档身体结构。高档支撑也被折面取代，仅留下少量原物痕迹；不以染色/增亮代替形体改写。

新增DEV外观选择器，通过正式渲染器切换同一实体的三档外观；可在暂停时立即重烘焙。不会改生成词素、AI、HP、坐标或攻击状态。选择新实体、原实体死亡或重进会清除预览。正常生产仍读取生成的覆盖档。
