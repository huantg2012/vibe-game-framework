# 净化点 R8：用户反馈核实与制作路线复审

## 总结

**接受七项反馈，R7不得标记艺术通过。** 先停止局部施工，完成整体设计。净化点是重复驻留的固定场所，当前单体轮廓已具身份，但整景仍像几何搭台加补片；壁缘、核心地位、主体动作、外景空间没有形成统一体验。

本次采用源码/历史接线核实、原尺寸R7留档观察、独立空间设计和成熟作品一手研究。没有重新运行游戏，动态体验引用用户本轮反馈；源码里的动作参数不是新实机证明。独立设计者没有先读过往方案，诊断者知道项目上下文，均不冒称盲审。无新分数。

## 有证据的问题

### P1 / R8-01：入口表现确有跨版本丢失

`c3b1d9f` 首次双层改造删除旧 `RiftEntranceVisual` 接线；`f9eb02d`改为当前多层星状坑。旧8帧、6FPS图集沿不等角裂纹传播，当前只剩固定8像素变透明度。R7未进一步改入口，但R6→R7纹理相同不能证明保留了I30之前的品质。旧类/资源仍在，不等于正式挂载。

本项根据上下文定位**净化点里的裂隙入口**。`RiftScene`最近修改仍为`6332096`，R7不含其改动；这只能排除R7直接修改该场景，不能证明正式Rift全链没有任何运行回归。若用户指进入后的地图，仍需同种子/状态实帧另行定位，不标已解决。

### P1 / R8-02：读数资格与动画缺陷

世界完整度条把E的24px操作锚范围、同层和6px脚圆直达判定全部拿来决定显示。纯函数确认核心正前脚(253,318)可站、可直达但距锚31.4而不显示；(261,316)与(261,317)相差1px就能改变通路资格。每帧清空重画，出范围即隐藏和清除侧记忆，没有出现/退出/切侧时序。0HP红填充为零，只剩暗轨。

旧专项选择了有效操作路径，明确绕过“核心左侧超24px”。通过只证明那些路径下避让正确，没有证明范围合理。此处需要改变显示设计，不是再补一组相同路线测试。

### P1 / R8-03、04、07：构图与构造不足

R7正常全景中，墙顶小缺口没有改变围边大形，外景明暗与材质频率相近；核心仍以独立立碑加地光为主，缺专属空间。接受用户对鼠啃边、仪式不足和纵深不足的判断。解决手段是墙段/楼板/支承重组、核心尺度和位置、外景遮挡层级；继续加碎纹不能解决。

### P1 / R8-05、06：动画存在但缺少可感知行为

核心亮活物固定烘焙，动态光又排除其自发光像素；现有sin主要改变周围地面，主体只叠32像素固定小块。R7提高光基准比提高振幅多，相对变化反而变小。培养藏确有移动气泡，其余多为小块alpha，供奉仅charge>0有活动；不支持“所有设备已具工作动效”的结论。

旧图形缓冲差异验证只能证明程序更新，不能证明人看得到。新方案给每件装置不同物质动作；核心主体、约束件和投光共享事件，静置、真实损伤、成功操作分开。

## 处理决定

采用[完整优化方案](../design-notes/purification-scene-art-plan.md)，保留浅透视和自由八向，允许核心及周边空间重组。工序改为整景作者构图、体块辅助、像素资产拆层、局部动态合成；不继续将程序多边形补丁当主美术生产方式。

本次没有改游戏、没有修复以上问题。A整体样稿→B完整画面核心样板→C全装置/外景→D读数体验→E验收的计划已登记[I30 R8](../tasks/iteration-30.md)，实施尚未开始。原技术证据与R2旧评分保留，不把本轮诊断改写成修复PASS。
