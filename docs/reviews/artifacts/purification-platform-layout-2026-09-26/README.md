## 方法与限制

原站位图使用 0.16 场景单位网格、0.22 足半径，脚圈八点高度差上限 0.27，图边高差上限 0.25。站点吸附到原检查认可的最近节点。距离为八邻域 Dijkstra 的三维累计长度，禁止越过不合法侧邻格抄对角；不是行走耗时或生产移动结果。`direct` 是原作者操作锚之间的三维直距，`length` 是吸附节点间路径，二者起终点略有差异，不应解释为精确的玩家绕行倍率。

去西坡连通探针保持原检查的四邻域，用于检验东坡是否独立接通两层。原检查对设备与断墙采用低位三角形合并后的世界轴向矩形包围盒，炉体采用作者矩形。因此原模型偏保守，倾斜物体的包围盒空角也会算阻挡。

补静物模型加入木箱旋转矩形、铁罐圆形、三座书架旋转矩形和五根支柱近似底面。书架、支柱尺寸来自 `environment.ts` 的作者几何；支柱以基部矩形近似，未做完整三角形连续碰撞。它不是全部环境静物的物理重建：低碎屑、纸、缆线、高层悬挑和非足层几何没有全部纳入。当前新增对象均是 footprint 近似，路径仍沿原设备 AABB；不可把结果称为“所有真实碰撞已验收”。裂隙附近备选站位只是说明邻近仍有通路，不改写作者操作点。

## 本次结论

1. **原图的东坡仅从下层可达，上口未连通上层。** 去掉西坡后，下层 3900/3900、东坡 169/169 可达，上层 0/1351。代表探针 `x=12.08,z=-2.28` 在上层高 2.6，脚圈最大高差 0.2919 超过 0.27，因而被筛。最后东坡行 `z=-2.12` 与下一合法上层行 `z=-2.44` 相隔 0.32，不能以 0.16 单步连接。此筛除在不考虑实体障碍时仍发生，不是核心堵住坡下口。上层前缘与坡面有约 0.17 的几何竖槛；这证明当前检查未证明双坡跨层，不证明生产玩家实机卡住。
2. **重要跨层路线被迫走西坡。** 原模型核心→储藏 19.903、裂隙→储藏 20.534、培养藏→裂隙 17.560；培养藏→储藏为 3.106。单位均是场景建模单位。
