# 污染选择威胁表达：独立美术与声音方案审查

## 范围与结论

知情专家设计审查，已读用户目标、冻结[初稿](plan-draft.md)及既有制作规范；不是首玩或盲测。亲眼查看的画面只有[现行重档选择页](../../../qa/artifacts/preparation-flow-2026-10-09/frames-02/pollution-severe.png)。该图是 2026-10-09 实现的开发夹具静帧，上缘有开发工具条；不是本提案的新样板。没有操作新方案、没有连续视频、没有审听新增音频。

方向值得保留：背景承担第一感受，A 文案负责机制，B 低语保留人物的身体尺度；两环节与单列装备不再被表现任务打散。最大风险是**描述了更强的背景，却把可见的背景空间留得过窄**。应先把效果位置、静态大形差异和稳定参照画到同一张实景上，再做节奏和混音。下述修订针对计划能否正确进入制作，不是宣称新画面失败。

- 决策与操作关系：书面结构成立，实际新表现未验证。
- 静态表达力度：目标清楚，具体构图脆弱；A01 应优先处理。
- 字体与文案主从：方向成立，版位与低档语义须修订。
- 同世界感：依托现有裂口、人物、受光的原则成立；异常归属仍需小样排除基地受损误读。
- 动态、声音、压力与疲劳：未验证。没有音频不能判断音色或混音好听，没有连续材料不能判断节奏有效。

## 独立美术归类

以下归类仅来自已看静帧，不以作者使用的技术名推断底层实现。

1. **空间与投影**：斜俯视、具有明确建筑断面与高度层次的场所。平台顶面、外缘竖面和后方结构形成纵深；人物站在裂口旁的有限通行面。把握高，限这一机位。
2. **画法与图像语言**：世界由可见的硬像素轮廓、大小不一的像素簇与连续受光共同组织；文字是细小、清楚的无衬线 UI，非强制点阵字。两种语言通过明度和空间主从相接。把握高。
3. **造型与材质**：暖棕工作服与负重人物对照冷暗建筑；混凝土断沿、金属/木架状残构和裂口边缘各有体量，属于被使用过的工业残存空间。深暗区的材料不可从单帧强判。把握中。
4. **色光与构图**：左侧人物及脚下是稳定亮部，裂口灰绿边缘提供次焦点；右侧连续渐暗托住无框排字，整体留白大。当前右侧大部分环境已不易独立辨认；这直接限制“主要靠远景改动”能产生的视觉幅度。把握高。
5. **母题与情绪**：狭小立足点、深暗断面、低亮裂口、一个暖色人物，形成“有限秩序面对不可见空间”的身份。单帧支持孤立与谨慎的阅读，不支持低中重三档已可排序或玩家实际压力升高。把握中。
6. **运动与视效**：无连续材料，未验证。

主导语言是**具有实体受光与断面关系的暗色像素场景**，次级语言是**边缘无框读数与短标记**；人物/建筑/裂口承担世界存在感，文字承担当前决定。提案应继续利用这一组织关系，不把背景变成套在场景上的通用烟雾视频或难度壁纸。

四项品质结论分别为：既有场所身份在此样本中成立；提案与现有语言原则相容；新三档的构图完成度未验证；新表现是否改善选择并避免误导未验证。不以现有文字清楚推导新氛围已经成立。

## 发现与最小修订

### THREAT-A01 · 可见空间不足可能让“整体背景”再次退为局部效果

- 类别：艺术表达与制作定义缺口。严重度 **P1（方案风险）**；影响三档的核心承诺；频率未测；对缺少空间定义的把握高，对未来成片无效的推断把握中。
- 证据：初稿 34–40 行限制效果在远层/裂口内部，同时保持阅读暗场、人物与脚边稳定；80 行让 P1 从三档静态样板开始。现行截图右侧暗场占据大部分背景，左侧主要可辨对象恰好是人物、裂口和近处地面。
- 玩家后果：若只改已看不清的右后景或裂口数个亮像素，玩家仍必须读文字才辨档，未完成用户“直接在选择界面背景上做文章”的诉求。另一极端是压黑整屏，破坏空间层次却只有亮度差。
- 反证/竞争解释：当前运行时可能有足够的可见远层可独立塑形；只需较小构图变化也可能有效。因此不要求重烘整景或新增三张壁纸。
- 最小修订：P1 明确交付一张**表现归属/保护区示意**及三档正常尺寸稳定帧。保护的是人物轮廓、脚边实际地坪、既有结构身份和文字可读性；不能将整个左侧世界区理解为完全不许变，也不能把效果都藏到文字暗场下面。先从已存在的非通行远层轮廓、可见空隙与裂口内层关系调整，保持前景实体坐标。
- 三档候选读法：低档让可辨远层之间留下分开的暗隙；中档让同组远层形成一侧或局部围合，但仍有清晰间隔；重档让同组远层与裂口暗形有更强的接续/对向关系，缩小视觉上的疏松间隔。只改同一语言的组织和权重，不靠新怪物剪影、地面开裂或换调色体系。
- 最小验证：同机位/亮度设置/阅读暗场下先去文字、静音、停动；看正常 960×640 图是否仍有大形和负形的差异，而不只是整体更黑。恢复文字后检查世界仍有存在感。排序是定向专家诊断，实际压力由用户复看。成本低至中，依赖分层技术短查；这是 P1 的第一产物。

### THREAT-A02 · “收获”字段低档内容错位，文学层有一句在解释情绪

- 类别：信息语义与文案表达。严重度 **P2**；低档每次显示都涉及；把握高。
- 证据：初稿54行“收获：深入仍需承担路程”在讲代价，无法与中/重的收获位置比较。64行“肩膀可以松一点”直接告诉角色可以放松；与世界观“从观察和身体反应留白”的要求相比，前半句已经更有具体着落。
- 后果：A 层字段虽对齐，玩家读到的比较维度仍不一致；低档 B 从身体观察滑向难度说明，削弱两类文案各自的特点。
- 反证：轻档也可有自语式松肩，句子并非世界观违禁；本项不要求禁止角色主观感受。收益精确信息需 Design 对 CSV 核对，本评审不自造掉落结论。
- 最小修订：A 三档的收获均写同一维度的已实现事实，或将“收益”的段落统一改为同时容纳路程与收获的清楚结构，不能只给低档换一个含糊标签。低档 B 优先尝试删去“肩膀可以松一点”，用“灯照着鞋尖，石面的细纹还看得清。”之类更短的观察候选；逐字稿与实际照明一起定，不把本句当批准成稿。
- 验证：逐项追到 CSV 和规则；朗读三条 B 时检查是否总靠“可以/需要/应该”解释感受。成本低。收益是 A 的可比性与 B 的具体感；风险是修得过短而只剩陈述，须在实景里判断。

### THREAT-A03 · 新增风险标题和 B 后缺固定版位，容易重新拥挤或出现第二主标题

- 类别：排字与构图规格缺口。严重度 **P2**；影响选择页全档与行装承接；发生未测；把握高。
- 证据：初稿50行增加16px风险判断；68行只写 B 放“阅读区下方留白”并预留两行，未给 A/B 的相对起止；74行又在行装页头和动作边缘保留摘要。现行 Kit 中正文在 x534–928，footer y526–588，当前对象只一处18px；本轮已由用户明确要求文字编排突出重点。
- 后果：实现者若按内容流式堆叠，会因重档长事实压缩 B 或推近主动作；若风险判断用大亮色或更重字重，可能与18px当前档并列成第二主标题。行装两处摘要同时过亮又会抢物品。
- 反证：现行选择页确有下部留白，合理分配可容纳，不是必然要扩屏或加滚动。
- 最小修订：在 P1 固定布局中，声明 A 风险判断是当前档的从属结论，不再复制另一个大档名；风险解释、应对、收益在同一列，固定 B 两行区与 footer 的间隔。B 明确沿 Kit 13px衬线族、正常字重，不仅写“现有字样”，不使用引号框、打字机或大面积斜体。行装页两处摘要同样使用辅助层级，只有物品名和当前主要动作获得高分量。
- 验证：正常字体、重档最长 A + 两行 B、键盘焦点与行装最长物件名同时出现时不重叠、不推移；定帧分别标注第一/第二阅读焦点。对比度闸门也覆盖 B 与次动作；不能为了文学层“轻”而降到不可读。成本低至中，依赖 A 逐字稿。

### THREAT-A04 · 声音需要声明来自哪一层，不能借高混乱音景伪造已经遇险

- 类别：听觉归属与制作边界缺口。严重度 **P2（方案风险）**；三档切换与长时间配装；频率未测；把握中高。
- 证据：初稿36–42行只有“稀疏/受压/低沉紧绷”与包络清理，没有规定现有净化点床和新增选级层的关系。[音频方向](../../../audio-direction.md)规定声音来自空间，不用紧张旋律评点处境；[现行声音合同](../../../specs/system-audio.md)将 Tension/Threat 与真实混乱/被发现绑定，且说明8轨并非所有床的绝对硬限。
- 后果：若切档直接调用现有高混乱或被发现层，会暗示玩家已处于机制危险；若只是重档更响，会用响度替代质地并造成重复疲劳。净化点机械声被随档位压掉也可能被读成基地状态变化。
- 反证：Code 可通过独立实例/参数正确隔离；现有素材可能足够，不等于必须新增音源。
- 最小修订：先审听已有素材可否作为裂口方向的一条选级表现层；保留净化点主床与功能声身份，不调用真实混乱/追击 cue，不把整座基地变调。三档候选在同一音色家族内改变事件间隔、纹理密度与谐波/摩擦质感；响度只是辅助且不持续攀升。制作规格明确新增实例归属、切档时最大临时重叠、行装态目标及取消恢复原混音；由 Code/QA 记录实际峰值而不是只写“8轨”。素材不合适再限定一条环境层的制作任务，不预先承诺现有素材听感成立。
- 验证：同监听音量依次听低/中/重、重→低、快速来回与持续配装；先单听选级层，再听实际混音，检查点击、停止、接缝、提示遮蔽与疲劳。静音只验证替代渠道完整，不代替审听。成本未知，P2 开始短查后限定；不需要现在请求用户另选工具。

### THREAT-A05 · 动效只有“缓慢/不完全同步”，尚缺切换优先级与静态退路的参数交付

- 类别：运动规格与证据缺口。严重度 **P2**；切档、减少动态及进入行装时；频率未测；把握高。
- 证据：初稿34–42行给方向，70行仅给 B 250ms候选，82行进入连续样板。没有要求制作时记录世界过渡时长、曲线、周期/幅度及中途改选如何衔接。旧 Kit 的即时短划与120ms说明淡入不可被慢背景吞掉。
- 后果：下一位实现者可能把慢世界动效变成慢输入，或在连续改选时叠加中档/重档的目标；减少动态若随便截取当前动帧，也可能丢掉静态层次。
- 反证：计划阶段无需今天冻结毫秒与幅度，提案也明确候选未锁；缺的是 P2 必须交付的参数表和责任，而非某个正确数字。
- 最小修订：P2 的视觉规格记录触发、目标层、幅度上限、周期/时长、缓动、打断和恢复。档名/短划/A 立即按最终输入更新，背景追随最新目标从当前值过渡，不排队、不封锁操作、不播放过期低语；减少动态直接使用 P1 每档已设计的稳定构图。进装备只减去运动幅度，不切回低档构图；关闭恢复原场景表现，不能留残影或继续计时。普通静态书面方案不必现在发明一组“已验证参数”。
- 验证：连续录像包含低→重→中快速切换、切换中 Next/Back/Close、减少动态与失焦恢复；每个阶段记录实际层值与可见状态，观察频闪/界面漂移/旧目标残留。成本中，与既有 QA 生命周期样本合并，不另开无边界视效探索。

## 开工 HOW 与 U1–U12 书面自核

载体复核：同一裂隙旁的世界内备行读数，屏幕文字挂 `#dom-ui-root`；背景归实际场景表现层。没有发明可控制世界的终端。参考沿既有 Kit 的 Signalis 主从、Darkwood 场景留白、Hyper Light Drifter 短标记；未重新研究这三款的现行版本，不凭记忆新增其制作技术结论。

三问：审美的制作抓手是近处稳定参照与远处负形的关系，须通过 A01 实景样板而不是口号判断；游戏行为仍是辨认风险—整理装备—出发，不是软件表单；同世界的约束是已有建筑身份、像素簇、受光与身体自语，避免通用恐怖滤镜。三问暂为规格依据，未能签新画面的人审结论。

- U1：书面载体与挂载延续现有根；新背景挂载/清理待 Code 样板。
- U2：提案未引入卡片、弹窗、通用图标或渐变按钮；是否形成外来层需实景看。
- U3：只沿既有世界/Kit色系；未授权新增色格。若后续用危险色，不让颜色成为唯一档位线索。
- U4：18/16/13/12/11px均可追到现有层级；B明确13px衬线族，A03需补版位。
- U5：低/中/重、混乱、备行、行装沿既有术语；低档收获语义须A02修订。
- U6：人物/脚边与固定footer保护，背景不盖读数；具体边界由A01/A03样板核。
- U7：不改两阶段键鼠绑定、不靠hover获得事实；后续交互回归未执行。
- U8：自由进入，不添加未解锁/战力不足假门槛；缺武器仍由现有装配页真实规则解释。
- U9：保留字级、位置和短标记，不靠颜色；4.5:1/3:1应覆盖新合成背景和B，旧测量不可沿用。
- U10：选档即时反馈；慢背景不得延迟状态回应，A05明确后用连续材料验证。
- U11：同一实景与共享排字；三档Degree not Kind；A01/A04防止三套壁纸或三种无关音景。
- U12：既有三参考的维度已写明；当下判断基于本作实帧与Kit，不以参考名称替代图像核对。

## 建议制作顺序及保留项

先处理 A01 的作用域/负形，再处理 A02/A03 的逐字稿与版位；二者可在 P1 同一静态样板完成。P2 按 A04/A05补有限音景与运动合同。保留首稿已经写好的静音/减少动态、拒绝准入警告、未知目的世界、暂停/销毁清理和两阶段动作语义。

此审查只允许把方案修得足以制作样板。未验证的新三档图像、听感、心理压力及用户认可均保留开放；P49/I14不得因此关闭。没有修改初稿、生产代码、资产或他人文件。

## 修订稿限定复核（2026-10-10）

复核对象：[修订方案](../../../tasks/preparation-threat-ux.md)，仅检查上述五项意见的书面处置，不重新做全面评审。A01 已明确左世界区不是全冻结，P1 增加表现/保护区图及相同曝光、暗场下的大形/负形诊断；A02 已将收获统一为深处资源比较，低档 B 删除直接的情绪解释；A03 已给出 A/B/footer 固定版位、字体族、从属权重与行装摘要；A04 已限定裂口局部音层、原床保留、有限尾音及实际资源峰值；A05 已要求 P2 交付完整时序/打断参数及 P1稳定构图的减少动态退路。五项的设计意图均已准确纳入。
