# 污染选择：威胁感知优化方案与计划

本轮交付设计与执行计划，并经子代理审查修订。正式版本仍为 `8cbd86ec` 的两环节备行；本文的新背景、文案与声音均未实施。P49 保持开放，I14 保持 13/14，现有运行证据不证明本方案的视觉或心理效果。

## 1. 已确定的方向与边界

用户明确接受三档自由进入；撤销早期“完成一次中污染搜撤才开放重度”的候选条件。低档目标为相对安全、可从容；中档有压力但仍有信心；重档危险明显、需要谨慎决定。相对安全不承诺无伤、无敌或稳赚。

选择界面的**整体背景视觉**是第一层表达，不能只改档名颜色或裂口的一点闪光。文案分 A（简洁准确的机制说明）与 B（符合世界观的文学化氛围低语）；两者必须在职责与排字上可分。

继续保留先选污染 → 配置行装 → 踏入的顺序、单列背包及其键鼠行为、返回时的装备/选择/滚动记忆、具体目的世界未知。这里优化出发决策的信息与感受，不改敌人、混乱、掉落、消耗、准入和保存规则。

**尚属制作候选**：背景的具体形状、各档明暗与动效幅度、音色与混音、文案逐字稿、淡入时长。用户认可方向不等于这些细节或最终实景已获认可；本计划不要求再选一遍方向。

## 2. 玩家经过的体验

靠近裂隙打开备行，第一眼通过整幅背景感知所选档的压力；随后读档名和风险，再读必要的应对及收益。选档只改变表现与公开说明。前往行装后，背景动势收敛，所选档与简短危险判断保留；装备成为阅读焦点。返回可立即比较其他档。取消恢复净化点原表现。

一个当前选择、一份说明、一个前进动作。等级名称维持低污染／中污染／重度污染；“轻”只用于沟通，不增加第二套玩家术语。

## 3. 背景与声音方案

载体是实际裂隙边的世界内交互读数；背景是这次辨认暴露条件的表现层。沿当前像素实景、无框排字与连续暗场，挂载仍为固定 960×640 的现有场景/overlay。Signalis 取主从与克制文字，Darkwood 取人物在场与暗处准备，Hyper Light Drifter 取直接选择与短标记；不移植其皮肤。

同一机位、人物、裂口和建筑身份贯穿三档；采用远层遮蔽、裂口内侧异样层次和局部明暗节律的组合，构图先于动效。场景本身不改碰撞、视野、装置完整度，也不预先生成或展示某个将进入的世界。

- **低：空间舒展。** 人物脚下、裂口边缘与几处原有空间层次可辨；暗部有间隔，异样局限在远处。稳定静帧成立，声音稀疏且留有较长安静段。
- **中：围合增强但仍能掌握。** 远层暗部在两侧形成更明确的包围，裂口内部有缓慢的遮蔽/明暗变化；人物及脚下仍保有清晰的空间。节奏大体可辨，声音增加克制的受压质感。
- **重：环境占据更大分量。** 大片有内部层次的暗形与局部错位关系压缩背景留白；少数稳定的场景边缘与肩灯构成人的立足点。缓慢变化的方向与停顿不完全同步，声音低沉紧绷。不能把黑色遮罩加深、全屏泛绿、放大音量作为主要差别。

新增异常只作用于背景层/裂口内部的表现，不让脚下地坪断裂、装置闪出损伤状态、人物扭曲或相机摇晃；也不出现类似可走路径、敌人或奖励的剪影。文字后方的阅读暗场、人物和脚边保护区保持稳定。重档可以有压迫，不能只剩一片黑。素材与已有世界像素共用画法，不叠通用烟雾、CRT噪点或惊吓跳帧。

声音为辅助：选档切换用连续包络衔接，不叠多档循环、不重播冲击/受击/追击警报；失焦、取消、入场前准备及销毁必须退出。静音和减少动态时，静态构图与文字仍完整。减少动态采用每档设计好的稳定构图，不统一退成低档或完全同图。

三问开工核：审美靠空间层次、人物尺度与单一阅读焦点；游戏感靠真实裂口旁的辨认—备行行为；同世界靠既有材质、受光、像素与克制自语。三问是制作依据，效果仍待实景验证，不能写成人审 PASS。

## 4. A / B 文案与信息编排

### A：规则说明

内容顺序为危险判断 → 危险原因 → 应对 → 收获。各档用同样的字段与位置，可直接比较。选中档名 18px、危险判断 16px、事实 12px、标签 11px；高对比只落在当前决定，不放大所有文字。收益留在次级位置，避免高档首先读成奖励升级。

候选文案仅用于方案审查，实施时迁入对应 CSV 并由 codegen 消费，本文件不成为运行文案的第二真源：

- **低污染／威胁较低**：混乱增长较慢，污染体较少。应对：观察路线，逐步搜取。收获：深入仍需承担路程。
- **中污染／威胁升高**：混乱增长更快，受侵占的区域更多。应对：留意绕行机会，提前考虑撤退。收获：更多收获在较深处。
- **重度污染／高度危险**：混乱增长很快，且更早加速。地面与空气大范围受侵占。应对：准备脱身手段，为返程留出余量。收获：更多收获在深处，入口附近没有额外收益。

事实逐项对照 `rift-pollution-grades.csv` 与 `rift-expedition-grades.csv`；“更早加速”对照当前 90/60/40 秒起点，不显示保证成功的停留时长。没有装备评分、推荐战力、必备物检查或精确掉落预告。`威胁较低`是相对其他档的判断。

### B：氛围低语

从角色当下的灯、鞋尖、石面、背带、手心出发；用观察和身体反应烘托气氛，不替玩家宣布绝望/勇敢，不虚构 NPC、灾变解释或世界预知。每档先一条主稿，最多 40 字、两行，不靠大量轮播稀释判断。

- 低：灯照着鞋尖，地上的裂纹一条条分得清。肩膀可以松一点。
- 中：背带又收紧了一格。裂口边上的光，怎么也接不到另一头。
- 重：裂口很窄，里面却没有近处。还没迈步，手心已经湿了。

B 沿现有低语 13px 字样，与 A 的无衬线事实说明分开；放在阅读区下方留白，不进入左侧人物/世界保护区，不侵占固定动作。预留两行高度，出现/消失不推移控件。无需增加“A/B”“氛围提示”等玩家标签。未来新增句必须符合实际背景，不能描述未画出的场景事件；正文不得借诗意承诺路、出口或安全窗口。

档位与 A 立即响应；候选为选档停稳 250ms 后 B 渐入，快速改选撤销旧回调。每次选级会话每档最多呈现一次，重复来回不抽新句；停留不轮播、不催促。进入行装、离开、失焦清掉低语，回来是否允许同句再显在 P1 样板中验证后冻结。一般净化点自动低语继续让位，不能与本页低语同屏叠句。

### 行装承接

标题附近保留“所选档／危险判断”短摘要，低于当前物件；出发动作旁保留等级身份。两处消费同一选档值，重复是防止长时间配装后误发，不能重复整段风险文案。行装页背景保留静态档位差异，动态和声音收敛以免干扰阅读；不能暗示准备后危险已经下降。

## 5. 实施分批与依赖

**P0 方案收口（本次）｜Director 主责，Design/Art/QA 分审。** 保存已确认方向、候选方案、机制边界与审查修改；更新归属 spec/Kit 的“计划中”链接、P49 与现状索引。交付仅为方案，不创建游戏源码或数值改动。完成条件为三份独立意见及逐项处置可追溯。

**P1 三档静态实景样板｜Art 主责，Code 协助。依赖 P0。** 在隔离备行入口复用真实场景与组件，先做三档固定构图、A/B 排字和行装承接；使用同一场景/存档/尺寸对照。输出每档正常文字及临时隐藏文字的诊断帧。先验证静态排序与同世界感，再加动效。成本中，已有分层能否独立控制由开始时短查决定。没有充分分层时优先补最小遮罩或静态层，不以扩大整景重烘代替评估。

**P2 连续视觉与声音样板｜Art/Audio 定规格，Code 实现。依赖 P1 静态内部核。** 增加档位交叉过渡、B 呈现时序、环境动势与声音包络；含快速切档、返回、关闭、静音、减少动态与失焦。先一版，最多一次针对实际缺陷的修订；仍不成立则保留失败并回到构图/分层原因，不无限调参。成本中到高，声音素材适配未审听前不作精确工期承诺。

**P3 正式接入与生命周期回归｜Code 主责，QA 独核。依赖 P2。** 将选档表现接入正式唯一选择回调；关闭与切场景集中清理。A 使用现有等级 CSV 增补公开字段；B 使用 `atmosphere-lines.csv` 的备行专属池并由 codegen 导出，呈现节奏由备行状态持有。视觉/音频预设与业务等级分离，表现不消费生成 RNG，不写出击状态。复用并扩展既有备行检查，更新 architecture 中的实际模块和资源归属。成本中。

**P4 体验验收与收口｜QA 取证，Art/Design 判读，用户终审。依赖 P3。** 交付可直接体验的选级→行装→返回/出发过程、三档静帧及连续视听记录。独立区分机器检查、知情专家意见和用户感受；用户未审则停在待复看，不关闭 P49/I14。将最终规格与 CSV 收口，候选值/失败样板保留在对应证据，移除落选运行分支。成本低到中，返工按实际问题重新限定。

## 6. 验证问题与停止条件

- **辨认强弱**：只看三档稳定背景、不放档名和 B，能否给出低→中→重的压力顺序；再恢复正常 UI 检查 A 是否准确解释原因。隐藏文字仅为表达诊断，正式玩家始终看完整信息。知情代理不能冒充盲测。
- **读懂并保留信心**：正常页面上能否说清至少一个真实差异；中档是否既有压力又仍愿意尝试；重档是否促使认真检查行装而不是误以为被禁止进入。真正心理效果由用户描述，不能由颜色/字号测试代签。
- **误读反例**：玩家是否以为背景正在损伤基地、计时惩罚已经开始、目的地已确定、整张地图必定是这一形状或重档必掉好物。若成立，先修表现归属和措辞，不能靠追加大段免责声明补救。
- **阅读与舒适**：默认尺寸和实际显示比例下三档关键信息可读；正文/关键标记合成背景对比分别保持 4.5:1 / 3:1，覆盖动效最暗/最亮阶段。静音、减少动态保留层级；持续配装不靠晃字、突闪、响度攀升制造压力。
- **行为回归**：第一步不能出发；普通 Enter/Space、Shift+Enter、返回/退出沿既有语义；长库后段装配、4/5槽、空工具与无武器、未成熟物、旧入口兼容均保持；三档各至少一次正式出发核冻结等级一致。
- **隔离与清理**：选择/返回不改变库存、设施、生成身份或世界历史；旧句/旧音/旧特效不在下一页或场景残留。快速切档、关闭中切换、失焦/恢复、准备取消、拒写重试、场景 shutdown/destroy 是不同生命周期样本。DEV 不访问正式存档。
- **性能范围**：同设备同场景对比开关表现的帧时间/长任务与资源数；先记录无新增层基线，再连续切档/开关至少 20 次看是否增长。具体预算由现有场景基线与 P1 技术核确定；不把这项写成整库/弱设备重新验收。

本次不运行新游戏样板；以上全是后续验收计划。没有新图像或音频即不判新的审美/听感成立。方案审查通过只允许进入样板制作，不能提升发布结论。
