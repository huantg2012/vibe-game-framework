# 净化点 R8 · 独立整体创作方向

日期：2026-09-23。状态：概念提案，未生成效果图、未实现、未获人审。

主功能：COH-F042；空间与移动关联 COH-F026 / COH-F006，原人物关联 COH-F039，世界背景关联 COH-F043。只读现状入口、世界观及两张指定 R7 静帧；未使用旧轮次方案和评审作为创作依据。项目技能用于兼容检查与事实交接，不把历史像素工艺上限当作本轮审美边界。`world.md` 的 DEC-180 与本轮用户授权优先于旧技能中的“材料不得有颜色”等历史措辞。

## 结论：受压的维护井

净化点值得以一张反复观看的主场景来创作。建议把它组织成**一个仍在承重的厚壳，围着一台必须反复维持的受控活腔**。两层地面和双宽坡道保留；核心移至上层后部偏中，建筑与行走共同指向它。右侧出现一处具有受力来由的大断构，透出无法量尽的外部。内部能辨认、能维护，外部仍按另一套规则运作。

“维护井”仅为创作工作名，不新增场所历史、宗教组织或建筑功能正史。核心为何存在仍保持未知。

### 现图最需改的关系

两张指定静帧显示：六物的单体轮廓已有差别，但它们仍像各自放在平台上的展品；核心前方亮、后方接坡道，缺少专属于核心的空间。墙顶密集小缺口分散了结构力；上下层平地、墙面和外残构使用相近的粗面语言，使尺度与远近主要靠变暗区别。给这些面继续加裂纹，不能解决场所组织的问题。

## 1. 先决定空间大形与行走

全景先读出三块量：**后部高厚壳、下部低维护场、右侧外部深空**。墙不再绕房间做同一高度的齿状项圈。后墙中段最高，两端降成厚肩；近景留低矮断面，只在角部用两块暗的前景结构压住画框。封闭感来自体量与包围，不来自每条边都画满。

核心落在上层后部偏中、略避几何正轴的位置。两块不同宽度的实墙肩夹出深暗设备凹位，核心向室内露出活腔；上方不补拱门、不补尖顶。它的建筑附属体可以明显增大，真正会动的活腔保持清楚且有限。建议首轮按原人物身高作比例稿：可见活腔及约束体约为人物的 2–3 倍高；最终高度由全景与近看共同决定，不能只把旧精灵放大。

下层中间留一块能站人、转身、穿过的完整空地。它是给玩家身体和光点的负形，也把六物从“均匀排开”改为有前后主次：

- 右侧边界地缝与净化器构成短的出入关系。净化器朝向地缝露出处理面，仍是独立物体，不把裂隙包成机器制造的门。
- 储藏处于下层较安静的一侧；人与机器前面有明确工作站位。
- 人体液缸与供奉立环分居上层左右的维护湾，向中央留出视线，不与核心组成三座等大的竖直纪念碑。
- 两条宽坡道保留为左右选择，形成“下层—一侧上行—核心前工作带—另一侧下行”的可选环路。双坡都能直接抵达核心，不强迫绕满一圈。

每次从裂隙归来，玩家在近处先被净化器接住视线，抬眼能看到更远、更高的核心。回访仪式发生在熟悉路线里，不添加跪拜、献礼任务、慢走区或新交互步骤。核心前工作带不贴墙，人物靠近、侧身和离开时仍完整可见；核心也不能遮住另一条坡道出口。

## 2. 三层材料、颜色和负形

**第一层：决定场所的大材料。** 主体由不均匀浇筑的混凝土块与成片灰泥形成；暗石灰灰、带冷意的旧涂层、局部低饱和氧化色能各自存在。每块大面先维持连续，只在构造接缝和受力处中断。后壳厚重，工作地坪被磨平，坡道用成片防滑面；不要把所有面做成同一种金属板，也不要给所有面加同密度划痕。

**第二层：解释人如何维持。** 钢制束带、旧检修板、接缝填补、压住开裂面的垫片形成中尺度关系。少而有用：补片横跨裂缝、污迹从接头向下、擦亮只在手能碰到和脚会经过的位置。核心前维护带稍净，角落保留积灰；由使用造成局部差别，不铺一圈亮色导航线。

**第三层：解释仍在发生什么。** 介质、接触活层、真实小灯和偶发运动占最少面积。青绿主要被关在核心、液缸、过滤腔、地缝及外侧接触面里；暖灯对应真实维护照明。可考虑让一盏偏侧的小维护灯把核心支架与人物照出共同落点，但不把整间屋子洗成温暖据点。

留三种不同的黑：核心背后的近暗腔、结构背面的遮蔽黑、外部无底的深空。三者靠边缘、遮挡与局部反光区别，不靠全部提亮。主亮点为核心活腔，玩家灯是可移动的第二注意点；液缸有色但减反光面积，地缝低位短促，供奉环主体不靠整圈发光争夺焦点。

## 3. 核心的仪式来自求生动作

核心的形象是“被约束而仍活着”。把目前像独立立碑的体量重新分成：承力底座、偏心约束臂、露出的活腔、进入结构暗部的工作连接。可让支架在高度或受力方向上不对称，形成紧张；不能靠小挂件堆成神龛。

一次**现有薪柴注入成功**触发可读的短因果：入口锁闭 → 活腔在约束间收束 → 两个相隔部位先后传力 → 波动回到受控幅度。建议完整动作在约 1–2 秒内自然结束，操作结果立即按现有机制生效，动画不额外锁人、不拖慢下一次操作。资源耗尽或注入失败不能播放成功归稳。

这里的庄重来自三件事：玩家很小、装置持续受力、每次动作确实改变了眼前状态。无需香火、圣像、经文、祭坛或新的神秘仪式；它也不应像一个神赐安全的避难所。修复后仍能看见被使用过的痕迹，世界没有被治愈。

## 4. 墙垣必须能倒推原始构造

先画一座完整壳体，再选择一处主要失稳和少数次要剥落。主要失稳设在右后侧：一整段墙在竖向施工缝附近偏转或被剪开，连带顶板沿斜向断裂；断下的大块仍有重量和落点，留在外沿或被已改写的外部秩序托住。它不是一个能走出去的新出口，实体下边界仍封闭。

由外到内能辨认外皮、粗骨料芯和断掉的约束件。墙肩保留足够的整段直边；破口里也有一两片长的断面。支撑没断的地方不该无因地锯齿化；没有承托的大悬挑不靠加阴影伪装合理。

本世界的主因是覆盖而非爆炸。构造损坏只是两种秩序接触后的次生结果：例如同一接缝外侧已按错位节律继续接合，内侧束带还在把它拉回原位。局部活层改变走向或节律，受力带先反应；禁止把整个外围做成怪兽在撞墙，也不靠均匀撒石块解释所有破坏。

## 5. 外景要有可估量与不可估量的两端

- **近层，边界外一个房间尺度内：** 可见墙背、底部支承、断面与接触侵蚀。材质细节最清楚，和室内确属同一建筑。视差与遮挡首先发生在这一层。
- **中层，数个房间尺度：** 一两组大残构保留原先延伸关系，又产生不可能的错位或重复；用大遮大、局部反射和缓慢遮蔽建立深度，不复制左右同形护栏。给一组清楚的方向，其余隐去。
- **远层：** 几乎无细节，只留两三块尺度难判断的层影及很慢的明暗移位。不要把远景填成可识别城市天际线或新增文明遗址；空无本身构成压力。

视差幅度应受实际相机移动约束：近层较明显、中层很小、远层近乎不动。固定镜头时靠间歇遮蔽、材料反光变化和极缓慢结构错位证明外部仍在运作；不靠所有层飘粒子。外景最大明暗反差低于内部焦点，只有靠边界的接触点有短促清晰变化。

## 6. 六物应有六种动作，而不是六盏呼吸灯

以下动作仅消费已有状态或操作事件。核心、储藏、净化器有模块完整度；另外三物不凭空获得耐久。日常环境动作不预告尚未公开的冲击目标或强度。

- **核心：收束、承力、归稳。** 静置时介质两处不完全同步地收缩；机壳基本静止，承力件只有极小负载位移。低完整度表现为受控节律缺拍、约束区域不均、局部泄漏增多。注入后先有反作用，再归稳；不能简单把“越健康”做成“越亮”。
- **储藏：压存、沉降、封住。** 深口中的物质缓慢沉落、压板偶尔追随负载微移；可用的封存量由现有数据驱动可见程度。低完整度是密封间歇失守、沉降被打断。修复后压板重新落定，缝中逸散收回；不播放喷烟庆祝。
- **净化器：摄入、分离、回吐。** 过滤腔内存在明确方向的短程循环，前后两段不同相。已有出击操作可触发一次可读的剥离动作。低完整度表现为流路断续和滞留；修复使流路恢复连贯，不能假造玩家掉血或装置需要冷却。
- **人体液缸：悬浮、偏移、重新悬住。** 人体轮廓先可读，折射和悬浮介质随后读；身体只有呼吸量级的偏移，悬挂点或管线约束其运动，不做鬼影大幅摇摆。已有刻入完成时出现一次更明确的介质传递，再回到静置。没有动作时不循环播放“正在改造”。
- **供奉立环：暴露、受压、锁住。** 环本体有重量；残渣在承压面上出现微小形变或偏转，锁具传递力量。空槽保持空、充能跟随已发生冲击、转化仅在真实成熟时出现清楚的一次变化。空环不空转、不全圈扫光。
- **边界地缝：错位、渗漏、复位。** 地面两侧短暂失配，缝内深度与反光分段变化。近处碎粒可以被拉近又落回，但不向上喷成传送门。它始终贴在地面；可进入状态只表达已有可进入事实，不制造可选择目的地的暗示。

总体节奏：全景只允许一处强动作，其他维持弱动作或间歇静止。核心与外侧压力可以有感知上的不同步；不把全场所有材质绑定同一个正弦时间。即使关掉发光，姿态、接触点和局部运动仍要能区分六物。

## 7. 制作路线：先整体美术，再拆为游戏资产

不建议再以“新增几十个多边形、加若干噪点函数”作为主创作路线。程序几何可以承载投影、遮挡与拼装，主场景的轮廓、材料边界、破坏节奏和光色组织需要作者画出来。

建议使用**固定视角的低模体块辅助 + 整体绘画修订 + 分层二维资产**：

1. 用最简体块确定双层地面、双坡、三块大墙、核心新位置；直接放入原人物真尺寸剪影。先交一张完整灰度场景与一张色彩稿，禁止先完成一箱局部细节。
2. 通过空间与构图后，低模或绘画建立一致面向，再人工修订为与原人物兼容的边缘、像素簇及细节频率。像素密度允许比随机 Rift 丰富，但不可让人物像另一分辨率贴上去。不要把精致效果图一键缩小当成资产完成。
3. 按遮挡和活动职责拆：后墙肩与凹位、上/下地坪、两坡、近景遮挡、三层外景、六装置主体、各自活层。场景局部采用大块定制画面，不必一律切成小砖复用。整张绘画可供构图，却不能以单平面背景替代人物脚下的高差与遮挡。
4. 固定表面保存色图、局部遮蔽和可受光分区；动态光仅影响真正可照到的部分。核心、人物灯和外部局部变化再实时合成。不要把已经画好的强阴影与实时影叠两遍。
5. 六装置的承重体与活层分开制作；有需要的机械位移也做成受约束的独立件。先完成一个核心的静态、低完整度和注入短动作，再确定其余装置的制作精度，避免六套同时陷入错误方向。

最小可判断样本是“原角色站在双坡之间的完整房间 + 核心一次注入 + 右侧三层外景”，不是一个孤立核心特写。若这张整体样本仍像灰色展台，暂停局部材质细化，返回空间大形。

## 8. 风险与下一轮应证明的事

- 核心移上层可能让常用操作变远。下一步用原角色实走左右两路，核核心、储藏、净化器间的往返；不能为构图美感强迫多次绕路。
- 更厚的后壳和更大的核心可能吞掉角色。先验证两个坡口、核心前侧及绕背的原人物可见范围，再确定遮挡分片；不以全墙透明来补救构图。
- 增加材质色容易让场景显得舒适。颜色集中于原材料和有限维护区，完整连续大暗面必须保留；暗不等于没有材质，丰富不等于全部发亮。
- 精致环境可能压过原人物。必须在正常全景与近看都放原角色，不允许先给环境做成另一个画风后再改人物迁就。
- 宏大核心可能被误读为宗教圣物。全景需看见工作站位、承力与接线，单体需看见受控介质和可维护构造；装饰性的神圣符号不能替代这些事实。
- 六物动态若无真实状态事件，只会制造假反馈。静置、操作、低完整度、真实转化分别核对；普通环境呼吸不承担尚未公开的玩法信息。
