## 2. 完整度条：显示资格与过渡

### 显示资格直接照搬 E 交互资格

`src/entities/purification-chamber-module.ts:23–24`：

```text
inRange = canInteract && 到操作锚点距离 <= 24
```

`src/scenes/purification-scene.ts:440–444` 把 locomotion 的资格直接传入三模块。`src/systems/purification-chamber-locomotion.ts:211–217` 中 `canInteract` 要求：

1. route 必须等于设备楼层；站在坡道 route 时也不行。
2. 玩家脚底到设备**操作锚点**之间，以半径6px脚圆扫掠，要求整段没有碰撞。
3. 检查的不是相机视野、朝向或视觉射线，而是一条能容纳角色脚圆的直达通路，障碍包含设备自身底座。

操作锚点和设备实体底座分开定义，见 `src/systems/purification-chamber-layout.ts:50–54,74–78`。因此实体旁边清楚可见、乃至距锚不到24px，都可能不显示条：距离规则偏向操作点，扫掠规则还会在底座边缘拒绝。把读取完整度也绑到 E 的接近资格，是目前体验苛刻的直接原因。

## 3. 六设备的常态活动与条件活动

共同入口：`src/scenes/purification-chamber-visual.ts:173–180,200–270`；绘制约每80ms更新一次。结构缓存按公开状态变化，不在普通 idle 重画。

- **核心**（`:213–220`）：3个固定矩形共32px改变透明度，无位移或形变；另有地面、墙体、壳体受光变化及3颗慢尘。
- **培养藏**（`:221–228`）：确有上升气泡，约230ms走1px，约5.5秒循环；另有慢亮度变化。
- **净化器**（`:229–232`）：2个固定矩形共11px改变透明度，无流向或内部形变。
- **储藏**（`:233–235`）：4×1px小缝 alpha `.38–.53`，无独立发光源。
- **供奉台**（`:236–246`）：仅 `offeringCharge>0` 才画活动物质；空供奉时主体确实不动。非空物质固定形状、局部变明暗，没有循环形变。
- **裂隙入口**（`:247–252`）：固定8px改变透明度；旧8帧沿缝传播没有保留。
- active target 的接触标记（`:254–259`）以及成功修复/供奉/成长后的1秒脉冲（`:261–270`）均为特定状态反馈，不能算六设备持续 idle。

供奉量来自 `src/scenes/purification-scene.ts:1017` 的实际槽占用数/4；不能在空供奉实景里预期看到非空活动。

### 核心有 sin，却仍可体感静止的具体原因

1. 最吸睛的青绿活物、亮块和高光是静态缓存多边形：`src/art/purification-chamber-pixels.ts:931–943`。
2. 动态受光明确排除青绿自发光像素：`src/art/chamber-light-field.ts:99,256–259`；静态烘焙同样保护自发光：`src/art/chamber-surface-map.ts:220–222`。因此核心 source 的 sin 主要改变周围壳、地面和墙，主活物本身不整体随之明灭。
3. 核心局部 activity 仅固定位置的32px透明度变化，不改变运动轮廓或内部流向。
4. `src/scenes/purification-chamber-lighting.ts:111` 核心周期约4.65秒；70HP时理论源强约`.259–.343`。R7基准由`.29→.43`，振幅仅`.055→.060`，相对起伏约19%降至14%。主焦点变亮不等于活动更容易看见。

以上建立的是源码因果解释，不是对用户感知的反证。设计需要评估“玩家是否看见物质在活动”，不能以已有 sin/命令缓冲变化宣称解决。

### 已有动态证据的边界

`docs/qa/artifacts/iteration-30-r7/lighting-runtime/manifest.json` 记录四光源、受光 Graphics 与外部碎屑命令缓冲确实变化，六设备静态纹理保持缓存；其中明确声明：命令缓冲变化证明提交活动，**不证明最终 GPU 合成的可感知品质**。所列 activity 主要是受光层，也不能替代逐台设备内部活动辨识验证。

本调查未启动动态实机。后续应在普通镜头下持续观察核心至少一个完整周期，并分别看空/非空供奉、入口沿缝是否有方向感、净化器内部是否像流动；以实际观察记录区别“存在动画”“看得见动画”“符合装置含义”。
