# 污染选择遮罩样例：美术独立复核

本轮依用户最新纠正：背景指整层半透明 UI 遮罩，视效在世界之上、文字之下；人物保持清楚。此前只改外部远景的方案不再约束本轮，也不能用其复核结果证明当前方向成立。未接正式游戏，未改变机制或准入。

## 开工核对

已重新显式读取 `.cursor/agents/art.md`、`.cursor/skills/in-game-ux/SKILL.md` 与当前 UI Kit。载体仍为裂隙边的现场备行读数；新增的是同一暗场上的暴露感表现，不虚构污染控制终端。沿 Signalis 的文字主从、Darkwood 的在场与暗处准备、Hyper Light Drifter 的短标记，不借用其皮肤。用户本次授权遮罩视效，高于旧稿“仅远层变化”和 Kit 对旧静态暗场的限制；该授权不推广到全游戏其他界面。

低档以通透和大面积安静空间为主，只有少量断续渗痕；中档从上/右两侧侵入宽薄、错位的痕迹；重档沿同一语言增加重叠和对向侵占，保留冷灰半透明层次。三档不能仅改变总黑度。差异须在正常 UI 的阅读周边/组间可见，而非再次藏到左下角。人物保护区稳定且没有可辨圆边；文字和键提示不受扭动、闪烁或位移影响。静止构图先有差异，缓慢运动再支持感受。

## 实际观察

在独立 Chrome 临时页实看同一 HTTP 样例（本代理的 IAB 当时不可用，未操作 root 的预览页）。已先看三档停动正常帧与重档氛围开关对照；下列首版观察不依据源码推断。

首版正确覆盖了整个 UI 遮罩：由低档薄边，到中档更宽的内侵，再到重档覆盖增厚；实际人物一直清楚，文字不被扭动。关闭氛围后新增纹理消失，人物与基础阅读暗场仍在，没有可辨的圆形保护洞。

首版需要修正的形态是中重档过多相近线宽的近闭合圆长圈，容易读作塑料泡膜或弯曲花纹。建议删去多数闭合边，改以两三组大小差异明显、内部薄厚不一的宽污痕为主，局部保留短蚀边；从上/右不对称侵入，重叠形成厚度，而不是继续加均匀颗粒。这是一轮形态修正，方向不再退回外景变化。

修订后重新载入同一入口，逐档查看“氛围开启＋静止查看”的正常文字帧，再看重档隐藏文字、恢复动态后的隔时帧和行装承接。图像实际显示：多数闭合线圈已消失，主体改为上、右、下的宽薄污痕；低档保持通透，中档有几组可见侵入，重档覆盖更宽、前后重叠更强。正常文字存在时仍能分辨差别，没有再将变化限制在远景或左下角。

人物的帽、躯干和肩灯持续清楚，脚边暖光仍能辨认；未出现清晰圆形保护孔。风险标题、事实、B 低语和动作的位置稳定，污染层没有覆盖在文字笔画之上。行装页仍以当前物件为阅读焦点，污染摘要没有升为第二个主标题。

隔时截图中，上沿及底部污痕轮廓、宽度有缓慢变化；文字和人物位置不随之移动。这里仅证明取样时发生持续变化，没有保存连续视频，不能据此签署全部时间的闪帧或舒适性验收。

本轮无需再增加形态修订，可以将这套遮罩候选直接交用户体验。最终形态偏宽而柔软，究竟更像污染膜还是一般雾层，以及中档是否保留信心、重档压力是否足够，都仍由用户判断。此意见不宣称用户的情绪目标已经实现。

## 三问复核

**审美如何成立、仍有哪些边界。** 背景的主要差异由覆盖面积、叠层和空隙变化承担，文字继续用既有大小与明度组织；删闭环后均匀装饰花纹感下降。灰墨薄痕与暖色人物形成对照。宽软团块的具体气质是本轮候选，不以代码参数或静态差异代替审美终审。

**玩家是否读作此刻的游戏行为。** 人物仍在裂口旁，选择和行装按先后呈现；遮罩表达选档的压力，不画污染控制仪表，也不新增门槛、计时、推荐战力或额外窗口。页外氛围/动态开关只是审稿工具，不属于游戏流程。

**与既有世界怎样保持联系。** 现场、人物及光源身份保持，覆盖层借灰墨、灰绿、侵占和不均匀分层表达异样。用户已明确要求在 UI 遮罩上表现，所以软层位不需要冒充真实远景构造，也不能再以“建筑没有变化”否定它。新色/形态不自动成为其他界面的全局规范。

## U1–U12 限定核对

- **U1 载体**：现场备行读数＋屏幕空间氛围膜；世界、膜、文字的实看层级正确。正式场景生命周期未接入。
- **U2 控件套路**：画内仍是无框排字和短标记，没有把膜变成卡片边框；页外审稿按钮与游戏画面分离。
- **U3 色彩**：未见鲜绿洗屏或危险红替代；维持灰墨覆盖和原人物暖光。未将候选色数值登记成新锁定色板。
- **U4 字体**：本轮没有改变上一套候选的字号/字体职责；实看选中档、风险、事实、低语、动作仍有主次。
- **U5 术语**：玩家文案仍沿原候选 A/B，没有因视效增加世界解释或机制承诺。
- **U6 不遮挡**：三档人物轮廓和肩灯保持可辨，文字在最上层；膜可以进入整个阅读暗场，这是本次明确授权。
- **U7 输入**：实际用鼠标切档、停动、氛围开关、隐藏/恢复文字及进入行装；未独立重跑完整键盘或真实游戏输入。
- **U8 状态语义**：等级选择同时有短划/字号/文字内容变化，不仅依赖遮罩颜色。样例仍不执行正式装配或出发。
- **U9 可读性**：本次看到的正常和动态取样帧没有文字截断、重叠；未做全相位合成背景 4.5:1 / 3:1 定量验证，不借用旧画面结果。
- **U10 反馈**：点击切档有可见的档位/文案/覆盖变化，未测量 400ms 上限。
- **U11 一致性**：底图、人物、现场光色和文字主次延续，膜形态在同一语言内增减；正式共享样式接入未发生。
- **U12 参考**：保持开工所述三个既有参考维度，没有引入另一款游戏皮肤。未做新的外部原图并排研究。
