## 交给作者的执行指导

现有截图的右侧阅读区域已经很暗。若把全部新增效果放在右侧文字底下，正常阅读时三档差异仍会被遮住。表现要进入人物背后的可见远层及建筑外缘空隙，但保持人物轮廓、脚下真实地坪和裂口石唇不变。

同一外景片层语言依次增加围合关系：低档保留数段彼此分离的远缘和宽空隙；中档两侧出现局部接续，间隔仍清楚；重档相对的大暗形压缩视觉空隙，并保留内部冷灰层次。先看无字、静止、无声音的并置画面，不能靠把重档统一压黑宣称差异成立。避免通用烟团、均匀噪点、完整怪物、椭圆黑盘和发光传送门。

素材优先引用当前同源实景与远中近/深度数据；样例可采用离线分层合成。当前已有获认可的外景巨影可提供局部屈折与褶片语言，不把旧整景重新烘焙成新的正式资源，不以样例实现宣称生产状态桥已接好。

文字保持单一当前对象：当前档 18px，危险判断与唯一推进 16px，事实 12px，标签 11px，低语沿现有 13px 衬线层。选择短划有独立位置，三档文字起点固定；资源信息不比危险亮。B 独占两行并与操作保留至少 16px，不能落在人物暖灯区。本次为便于比较可以常驻 B，但必须在样例范围说明中将其与未来 6 秒会话规则区分。

### 本轮抓出的缺陷与修订

**ART-S01：首版背景区别藏在极暗的左下角。** 三档正常文字帧几乎是同一张图；去字后才能找出左下/下缘斜带宽窄不同。人物背后、裂口旁的可见空间仍一致。要求提高合法远层的中间调和可见大形，不增加全屏黑度、噪点或小碎片。

**ART-S02：提亮后出现额外横向地台读法。** 中间稿左下连续亮上缘、下方统一渐暗，跨过柱隙，很容易读作可站立桥面。最后修订删除贯穿亮带，换成错高、不等宽、向画外延伸的斜坠侧面，纵向暗缝切断连续顶面。封样的横向可走平面线索已减弱。

**ART-S03：封样仍未充分证明整幅背景压力。** 低档左下只有一段远缘；中档出现分开的斜坠面；重档形成更宽、更密的对向侧面。三档的局部差异现在能在正常文字帧辨认，但变化仍集中于画面左下，人物背后和主要注视区接近不变。新增面较原建筑平整，重档具有灰色板片/剪纸感。可作为候选交用户判断，不应表述成“整体背景压力已经成立”或“静态美术验收通过”。本轮封样，不再以追加纹理或连续调参无限修补。

### 可以保留的关系

- 人物、肩灯、裂口石唇与脚下地坪持续可辨；三档没有用全场变绿、人物扭曲或相机震动表达危险。
- 当前档比风险标题重一档；A 的事实、应对与资源位置一致，资源没有抢到首要焦点。重档最长事实仍完整显示。
- B 的衬线和独立留白使它与事实说明分开；没有给它额外窗口、引号框或 UI 标签。页外明确它本次常驻供审稿，不能据此声称未来限频合同已实现。
- 行装页当前物件名为主要文字焦点，污染摘要退到辅助层；单列与详情有明确主从，底部动作保留独立空间。仅看了一件撬棍的静态承接，未验证长库存/正式装配。

## 三问书面复核

**审美依据与当前问题。** 既有场景的暖棕人物、局部肩灯和厚建筑断面仍承担画面主体；文字通过明度、字号与留白区分职责。新增片层的平面感与局部化是实看后仍存在的质量问题，不能因为人物保护或层级正确而忽略。用户仍须判断整体观感及低/中/重的心理强度。

**是否作为此刻的游戏行为被理解。** 画面保留人在裂隙前选择并准备的关系；第一步只读等级，进入第二步才出现行装。右侧无框文字没有发展成卡片墙。页外查看工具属于独立审稿页，不是游戏控件。样例操作仅用来切换画面，不能代表正式备行流程的验收。

**是否仍属同一个世界。** 原场景、人物、暖光和冷灰材料身份保持；没有凭空增加仪表、NPC 或完整怪物。但新褶片的材质密度尚不及原场景，这是同世界一致性的剩余风险。具名参考用于主从、留白与短标记，未复制其外壳。

## U1–U12 限定核对

- **U1 载体**：沿现场裂隙旁读数；样例挂自己的固定画布/overlay。没有核验生产 overlay 生命周期，本轮也未要求接入。
- **U2 外来控件套路**：960×640 画内未见卡片堆、通用图标或渐变按钮；页外工具是审稿用元界面。此项不替代审美判断。
- **U3 色彩**：文字主层沿既有灰绿/暖褐语义，现场仍保留暖棕人物；褶片是候选冷灰中间调，未登记成新全局色板或生产规则。
- **U4 排版**：读取 CSS 确认画内使用 18/16/13/12/11/10px 的已有职责层，B 用现有衬线族；没有把页外标题字号当游戏规范。
- **U5 术语**：污染等级、混乱、行装、裂隙、深处资源等沿候选稿；没有新增准入或掉落承诺。CSV 事实核验归 Design，本文不重复签署。
- **U6 不遮挡**：实看人物轮廓、肩灯、裂口及脚边仍可辨；正文位于右侧，B 没有进入人物暖灯区。
- **U7 输入**：鼠标实际完成三档切换、去字、恢复及进入行装；未独立跑全部键盘/正式业务，不将静帧冒充其验证。
- **U8 状态语义**：选中短划与文字权重同时变化。行装“已在手”和样例“踏入”不可执行的范围已在页外说明；本轮不证明正式不可用原因逻辑。
- **U9 可读性**：实看默认 960×640 时事实、低语与底部动作没有重叠/截断；未执行合成背景 4.5:1 / 3:1 定量测量，不沿用旧帧数据。
- **U10 反馈**：点击后能看到当前档、说明与背景变化；没有计时测量，不签署 400ms 定量结论。
- **U11 一致性**：UI 主从与原场景身份延续；独立样例 CSS 不是正式共享样式推广。新增褶片的平面感为明确剩余问题。
- **U12 参考**：沿 Signalis / Darkwood / Hyper Light Drifter 的既有维度，参照关系见开工依据；没有进行新一轮外部参考截图对照。
