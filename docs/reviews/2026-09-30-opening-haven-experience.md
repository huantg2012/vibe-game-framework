# 从开场到净化点：体验与背景重构裁决

日期：2026-09-30。审查版本：`15ed7bf`，`coh` 分支；既有未提交 `CLAUDE.md` 不属于本次审查成果。关联：COH-F002 / F005 / F026 / F039 / F042。

## 裁决

**建议重构开场的取景、场景对应关系和交接；保留原画的美术方向。** 原画仍然是合格而有感染力的开场图。需要更新的是它承担的任务：让玩家从“看这个世界”自然进入“我就在这里”。不支持推翻既有画风，也不支持仅换一张更精细的独立海报。

两屏的世界身份成立，空间连续性与入场注意力脆弱。当前开场强调“一个人在巨大废墟边缘求生”，净化点首先展示“完整平台和多个功能设备”。人的落脚位置、炉火和画面主焦点重新排列，导致情绪需要重新建立。背景单独换图不足以修复整个交接。

## 质量判断

| 方面 | 判断 | 依据及体验含义 |
| --- | --- | --- |
| 标题画面的吸引力 | 成立 | 小人物、大残构、深落差和有限暖点建立脆弱栖身感；左侧标题留白克制。 |
| 世界与材质身份 | 成立 | 两屏共享残损书架、石层、线缆、深黑虚空、冷色污染和局部炉火。不能只因素材管线不同就说是两款游戏。 |
| 空间对应与人物连续性 | 脆弱 | 标题人物位于右侧断沿；入场变为整个平台俯视，人落在炉火附近。可推断同类地点，但难以直接认出同一处。 |
| 情绪与视觉焦点延续 | 脆弱 | 标题以人面对深渊为主；入场以平台与核心为主。当前静帧中外景更多并入黑暗，宏大威胁的尺度感减弱。 |
| 第一步行动的可理解性 | 脆弱 | “坐下”是有价值的生活行为，但同时出现的潮汐、归来预报等术语没有先建立情境。首屏是否能帮助全新玩家找到角色并理解下一步，尚无盲测证据。 |
| 动态与声音整体品质 | 未验证 | 有微动、灯影和声音交接实现；离散操作与静帧不足以裁定连续观感及听感。 |

独立美术归类：标题是写实废墟材质取向、细密颗粒与绘画塑形结合的斜俯视插画；游戏是具有明确空间投影、材质受光与硬边人物精灵的可玩场景。区别不只是“像不像素”。标题的大体块组织、材料厚度、虚实递进成立，应该继续作为表达质量参照；不能靠统一像素颗粒或加噪点消除镜头差异。

## 三项主要发现

**OH-01 / P2 / 空间表达：同世界，但缺少“我刚才就在这里”的证据。** 真实标题点击进入后的两张实帧与源码都支持地标、人物锚点和取景发生重新组织。影响首次入场，不是功能阻断；实现事实把握高，实际新玩家迷失程度未知。黑场完全可以是合理的电影剪辑，因此不把“非无缝”本身当 bug。若匹配人物、炉火与一个断沿后，用简单剪辑就能明确传达同一地点，则无需连续长镜头。

**OH-02 / P2 / 情绪组织：从“人和世界”过早切到“设施总览”。** 净化点全景对后续导航有价值，但首次揭幕同时暴露全平台，把人压回操作单位。原画中更清晰的远近残骸也使随后外景显得收缩。这是两端镜头与焦点的共同问题，不能全部归咎于旧原画。建议首个可玩镜头短暂承接人物与炉席，再放开全景；保持最终游玩构图。若实际新玩家已能自然找到人、辨认同一炉火，并维持世界尺度感，本项可降级。

**OH-03 / P2 / 主题与初始引导：有孤独与炉火，缺少本游戏独有的庇护原因。** 标题没有清晰表现当前核心——受约束的污染物却维持这片据点。入场后核心突然成为强视觉中心，同时 HUD 引入未解释的术语。世界机制来自现有设计与用户明确的核心定义；“新玩家一定不理解”仍是推断。建议用构图里可辨的核心约束结构及其受光关系提前建立疑问，不加一页世界观说明。保留坐席，把它作为可选停留，而非默认认为第一次必须坐下。

## 推荐方向：净化点里的一口喘息

以**当前真实净化点的炉席区**作为开场地点，从那里朝破碎世界取景。开场与首个可玩镜头共用“角色—炉子—可坐残墙—一个独特断沿”的空间关系。原画里的末世图书废墟、压倒人的巨大残构和深渊继续保留。

1. **近景承载人的生活。** 同一个头盔、背包、肩灯轮廓，处在当前出生位置附近；暖炉和原建筑残墙组成可辨的栖身点。用少量有因果的使用痕迹表达停留，不为丰富度堆新设施。
2. **中景提前建立核心的身份。** 可以只露出受约束能量体与部分仪式装置，灰冷污染绿的光真正作用于地面与结构。靠取景和遮挡控制出场分量，核心仍保持场景最强光源的设定。炉火给人温度，核心给这片地方存续的条件。
3. **远景继续压迫这片庇护。** 保留近层连接残构、中层可辨书架/建筑、远层将隐未隐的巨大轮廓。左侧自然暗部承载菜单。明度按纵深组织，不用整体提蓝、满屏发光裂纹或纯黑填空。
4. **点击后，认得出同一个地方。** 菜单退去，人物/肩灯有简短回应，镜头围绕同一炉席锚点拉回正式游玩构图，再交还操作与 HUD。优先使用同源场景可实现的取景；若大幅角度变化无法自然过渡，采用人物和炉火匹配剪辑。无缝变角度不是硬指标，不需要为标题引入整套新渲染引擎。
5. **第一次操作先让人站稳。** 角色脚下、邻近通路及炉席的读图关系要清楚。坐下可保留为自然选择；陌生预报是否应晚些显露，作为后续引导专项验证，不在本次评审直接改 HUD 或机制。

制作取舍：建议局部场景重构与开场镜头更新，成本中档；若追求当前引擎不支持的大角度连续镜头，成本与美术退化风险显著提高。先验证两端关键帧及一次最短交接，再做细节。原画保留为美术母参考，不要求用正式全景截图替换标题，也不重做已获认可的净化点全场。

## 最小验证与验收

- 在相同游戏画框尺寸下比较标题、交接终点和可操作首帧，排除 QA 工具栏及缩放差异；人物、炉火及一个独特断沿能对应，角色不会被误读成换了一个人。
- 静音观察也能读出：这里只够暂时栖身、外面巨大且危险、核心提供异样庇护。检查这些意图是否可见，不以文案替画面解释。
- 找未参与制作的人实际首次进入，观察他如何定位角色、理解可走地面、选择坐下或探索；不提前告诉他三处地标，再收集原因。不能拿熟悉项目者替代该验证。
- 连续录制新档、继续与减少动态模式；另行试听火声/环境底音衔接。继续游戏不强制重复首次开场表演。

本轮评审完成，**尚未实施开场重构，未获得用户对新方向的终审**；I13/I14 的历史验收不被撤销，也不自动覆盖当前净化点更新后的衔接。
