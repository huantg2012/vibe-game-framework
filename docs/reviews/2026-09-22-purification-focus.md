# 净化点 R7：核心焦点、地坪与完整度提示复评

## 结论

这一轮接受用户五项反馈，并完成对应施工。知情独立复评确认：核心的形体和局部光成为第一焦点，三处原齐边出现实际破损；地坪增加了材料面积，修正重复条带后更接近同高程的工作面；壳外保持冷暗，补回一个右侧完整断面后仍可读厚度。完整度提示在侧置样本中不再压住人物，正常与危险状态采用同一套语义色。

**美术归类仍是浅透视错层建筑的大块硬边像素、较密的装置/人物像素和局部柔光。** 本轮改善了构图层级与材料组织，没有把全游戏锁到低饱和，也没有完成全场发布精度验收。材料断口、薄皮与露芯仍偏概括；长期停留的粒子节奏、声音和新玩家辨识不由截图代签。

## 五项反馈的处置

1. **地坪单薄：接受。** 上层保留一块跨施工接缝的宽工作层，其他磨耗开放到墙、楼板切缘与坡前；下层裸底与维修接合依附实际基础/服务沟。首稿出现重复豆荚形/平行暗唇，已按实帧撤除，不通过加噪点掩盖重复。
2. **墙缘过齐：接受。** 后墙帽、东侧顶缘、前基础下边改变实际轮廓，缺口大小不等并露出断芯；前沿仅改厚侧，不改可走面或碰撞。
3. **核心不突出：接受。** 核心开放腔增高、上下夹持不等高；亮内芯、深腔和较强的局部受光共同建立焦点。培养藏/净化器退到次级；受损仍按公开健康衰减，不能为追求好看伪造健康状态。其他五物身份与静态纹理保持。
4. **壳外重构：接受。** 冷暗断构、错位面和黑隙重新组织，窄侵入点维持与室内抵抗位置的关系。首稿右侧退暗过头，修后补一个有面积的朝内断面；弱冷受光只落实体，12片慢碎屑在建筑后方，不用整屏光雾争夺核心。
5. **完整度条颜色/位置：接受。** 世界细竖规与聚焦整组读数侧置，正常骨白、低于25%危险红；真实人物、上身、旋转持具与肩灯参与避让。近景还避让装置名、投入列与视口。专项捕获并修复了变焦首帧的更新错相；核心增高带来的标题压顶另按真实模型顶边定位。
