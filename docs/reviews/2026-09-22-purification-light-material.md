# 净化点 R4：材质与运行光影复评

## 结论

**接受用户两项品质反馈。** 上一版收回暖色后保留了结构可读性，但不同材料趋同，装置的亮点与周围表面缺少联系。问题不是简单缺颜色或缺动画，而是使用、材质和受光的关系不足。

R4已经补上局部材料与统一受光，并修正首轮引入的光盘和重复修补圈。独立美术复评建议冻结本轮供人体验，**不等于整体画面通过**：大墙面、外侧残构的塑造仍偏图形化，维护历史只部分成立。保留原三项80/75/50评分，不自行提分。

## 对象、方法与覆盖

正式入口 `http://127.0.0.1:3025/` → 新游戏/继续 → 净化点。基线为`09d37a9`，新版本由[R4运行证据](../qa/iteration-30-r4.md)中的源码指纹锁定。

这是探索、负重搜撤与归来整备循环中的基地。场景需要让人迅速找到准备下一趟的装置，也要表现一个仍在承压、被使用和维护的场所。审查链为：归来/进入 → 看懂空间和装置 → 行走接近 → 操作确认 → 看见运行状态 → 准备出击。

采用**知情专家复评**。美术子代理先独立看正常全景、核心聚焦和上下层静帧，封存观察，再对照实现；技术代理独立检查光源、遮挡、灯锚和生命周期。制作中的主代理另亲看修前/修后及受损图。所有参与者都有项目背景，不能称为盲测或真人用户研究。

- **已覆盖**：本轮正常全景、核心聚焦、上下层及合成公开损伤的视觉比较；同一几何下的层次、装置辨识和修正回归。
- **部分覆盖**：正式入口已知路线、六交互、两坡、设备遮挡、入Rift；动态技术事实单列QA，不用静帧替代。
- **未覆盖**：初见玩家导航、自然经历严重损伤的完整循环、专门音频、长期整备疲劳和成长获得感。
- **不适用**：此次未重审战斗数值、升级深度或地图生成。

## 美术设计归类

当前属于**浅透视错层的硬边像素场所**：黑隙包围厚重残存构造，冷灰建筑、旧矿物层和回收件承载青绿介质装置，原人物与极少暖灯提供局部温差。

造型依赖分面、断面和剪影；表面依赖有限像素簇，光照采取2D投影近似。六物的旧工业、生物容器和空间击裂语言与建筑相容；“可辨认”已经有基础，“精致且有真实构造关系”仍较脆弱。颜色丰富度不以低饱和为门槛，也不把本场景的色彩安排推广为Rift生成要求。

应保护：六物不同剪影、核心开腔、培养藏的身体尺度、黑色高差/空洞、原人物身份、两条宽坡与安静的可走地面。

## 核心发现与裁决

### ART-01 · 光源和场所割裂（P1，艺术品质/表达关系，基线常态，高把握）

装置已有介质亮点、活动与少量地面反光，因此“没有光”不准确。但正常全景里，核心旁的地坪/立面缺少足够响应，较大的培养藏绿色反而更抢眼；运行装置读成摆在模型中的标记。技术核查原三池覆盖很小，核心自身底座裁掉了最亮部分，设备面/墙没有共同接收层。

**接受并实施**：源强统一驱动活动像素及地面、墙、装置面；核心为主，培养藏/净化器为次，小壁灯局部暖光。公开HP影响相应模块源强，不读未来事件。新增短方向影、修复重复人物灯池及整数端点投影断续。

收益是装置融入场所且运行状态有环境回声。代价为新增小型光场编译层和Graphics重放；风险是绿色地坪误读污染、规则光圈误读范围。最小验收为同景源—表面有联系，光不越过地面空洞/底座，近源明暗变化不抹掉物体材料。

**当前：关系明显改善，精细度仍有限。** 不宣称完整3D遮光或物理材质系统。

### ART-02 · 材料职责趋同（P1，艺术品质，建筑大面常见，高把握）

基线有分面和厚度，不能说“全无体积”；但涂层、断面、工作地坪在冷灰回收后过于接近。同一片灰上加更多随机细节不会形成材料。

**接受并实施**：局部矿物表皮→粘结层→骨料，实际接缝修补、回收窄盖、工作区磨耗；颜色附着于具体材料，通路中段留安静面。六物本体、碰撞和模型足点保持。

收益是近看有材料差异，工作区有少量自身信息；代价是维护有限手绘簇，不能代替后续大形塑造。风险是补块像可拾取碎物或贴纸。最小验收为首屏能区分涂层/承载层/金属，不因颜色增多重回暖色铺场或杂乱。

**当前：部分改善。** 墙体和远端残构仍偏图形化，有限表皮历史尚未组成充分的体积与构造细节。

### ART-03 · 维护痕迹的因果弱（P2，表达关系，局部常见，中把握）

既有接触点、支撑和修补已在，因此不能诊断为“没有使用史”。不足是损伤、修补与日常操作位置尚未充分对应，孤立材料贴片难解释由来。

**接受有限修正**：储藏沉积接回墙脚，剥落接楼板破边，设备前痕迹打断为不等厚片段。没有新设家具、假交互物或额外供电玩法。通过条件是痕迹依附可识别构造、不误导为可拾物；未来若继续投入，应从真实工序与构件连接扩展，先画清接合关系再增细节。

**当前：脆弱，部分改善。** 未经初见用户验证，不能用说明文案替画面消除误读。
