# 净化点 R8 实施视觉复评

## 后续用户裁决（2026-09-23）

用户评价R8整景“非常差”，要求先静态重审安全区/外景占比与结构。随后接受偏置与集中外景的布景思路，授权R9重构，且明确原画渲染画风不得照搬。以下独立复评是历史内部判断，不能覆盖用户否决；原功能验证也不表示艺术通过。新工作见[当前方案](../design-notes/purification-scene-art-plan.md)。

## 当时独立结论

**R8 的改善可读：墙体大形、材料区分、核心主次、核心活动与状态反馈均有直接视觉证据。尚不建议记为可发布美术完成。** 核心背后的空间组织、右墙断构的承接、外景的尺度与遮挡关系仍有三个 P2 品质差距；本次未确认 P1 视觉阻断。最终源帧、灯光补片与真实交易已经有限复核。供奉空/有/成熟返空的因果可读；六物动作的沉浸程度不等齐，不能从技术接入齐全推成艺术完成。

值得保护的是：两层可读、房间封闭、六物剪影有差别、下层留白允许人物成为尺度参照；核心光不再与其他装置平均分配；大段墙缘不再靠密集小咬口表现受损。下一笔投入优先修空间接合，不用全场加噪点、加亮或堆特效。

## A. 第一眼读图记录（读取方案前封存）

证据：[stage-a/01-main.png](../qa/artifacts/iteration-30-r8/stage-a/01-main.png)，1440×960 输出。下列坐标均为此图屏幕像素，不能直接当世界坐标。

1. **焦点**：第一眼落在下层偏左的高竖核心与青绿地面光，其次是左上培养藏。核心比 R7 的存在感更明确。其背后紧接坡道斜边和上层地坪，尚没有一个只属于它的暗后景。
2. **材料**：地坪首先读为细颗粒矿物面；墙顶更亮、更冷，背墙两块偏褐面提供材料区别。大面比 R7 的平涂补片更连贯，但墙内 U 形线和地面裂缝仍偏“画上去的线”，不能全靠这些线解释维护史。
3. **空间**：上层平台、两条坡和下层环行面能够区分。壳墙是连续厚体，不再主要读作被啃过的边条。右侧大黑断缝与悬横杆造成局部受力关系含糊。
4. **模型功能**：核心像被两侧构件拘束的活腔；培养藏像立缸；供奉像可从中看穿的环架；储藏像封闭矮罐；净化器像双腔箱；入口像地面分叉裂纹。剪影区别成立，但从这一帧不能读出所有装置各自的工作动作。
5. **外景**：左右近处厚块和顶部较暗斜构件已有体积，房间确被包围；中远层仍像一圈放大的同族建筑块，远近靠变暗较多，空间距离和不可知尺度的表现较弱。

## B. 四个独立品质判断

### 表达力度与身份：改善可读，仍脆弱

核心、暗壳与外部裂痕能传达“局部维持”。本轮增加的夹持件使核心的约束关系比纯亮腔更具体。仪式感目前主要由高度和主光承担，建筑尚未充分围绕核心组织，房间身份仍有“设备散置在两层台面”的成分。仪式感无需宗教装饰；需要的是单一焦点的占地、背景、前方停留带与承力关系共同成立。

### 语言一致性：静帧范围内基本连贯

冷矿物面、局部褐色旧材和青绿活层不是互相冲突的三套皮肤。原人物没有因环境更细而失去辨识；前地坪保有足够安静区域。核心特写中框体的大平面与细粒地面存在精度差，这本身不是错误；需要保护核心外沿与内部层次，不能用给主体平均撒点来“补齐精度”。

### 完成度：P2 接合与纵深差距仍在

大形重构比 R7 更明确，但右墙裂段、核心与坡道相切、外景近中远关系仍表现出拼装感。这些处不是合规清单可替代的品质问题。当前证据支持“有方向的改善”，不支持把整场记录为可发布美术已完成。

### 玩法适配：静态行动读法成立，连续体验部分覆盖

可走平台与墙体有差别，核心世界条和聚焦读数在已看帧没有遮住人物。布局留在主层的工程依据来自路径预算，不能因为方案曾提出上移就要求机械照搬。路线测量只证明该几何的路径成本，不证明画面有仪式感，二者分开。

## C. 七项对应（随最终证据更新）

### R8-01 裂隙入口：传播可读，轮廓仍有星形倾向

普通全景中的入口已能读成低位裂缝；`integrity-runtime/01-front-observation-without-e.png` 有更多细支与局部亮传播，比 `runtime/07-prepare.png` 的少量粗分叉丰富。两帧所属实现批次不同，不能混用成同一动画。封存 `normal.webm` 的约7–13秒采样能看到局部青点沿分支亮起、迁移、归暗；没有全圈同步闪烁。最终`runtime-final/07-prepare.png`与`transactions/01-final-main.png`仍有中心放射的主轮廓倾向，细支存在不能完全消除这点。故可判传播和细支改善已可读，未有同尺度旧版动态基线，不宣称“完全回归”。

### R8-02 完整度颜色、显隐与位置：静态改善可读，显隐有范围受限的补证

证据：`runtime/02-repair-core.png`、`runtime/05-front-core.png`、`integrity-runtime/01-front-observation-without-e.png`、`integrity-runtime/03-hp-0-of-100.png`。

- 聚焦读数把“完整度”、状态词与数值分开；受损赭金、失效锈红可在实底上读到。0HP仍有端帽与“失效”，不再只剩黑条。
- 条位于设备侧面；已看站位没有挡人物或持具。普通前观察帧没有虚构 E 操作资格，观察与操作有所区分。
- `integrity-runtime-final/03-hp-100-of-115.png` 的“稳定”、100/115及仍未填满的容量条可同时读到，与0HP锈红“失效”有别。0HP保留端帽，已看站位无遮挡。
- `integrity-runtime-final` 记录实际键盘开关和13项最终检查完成，未出现DOM重叠；这是作者提供的范围明确的机械补证，不是本评审亲手完成的试玩。视频35–37秒的聚焦采样未见世界条与面板读数挤在人物上，但采样不足以排除160ms淡入、快速跨界、换侧或逐帧闪烁问题。
- **证据纠偏**：0HP聚焦样本起初呈现旺盛核心，协调者说明该中间 UI fixture 只改读数、未通知缓存视效。复看真实启动 `investment/damaged/01-main.png`（核心8、储藏24、净化器0）与 `investment/purchase/01-main.png`（三模块70），核心地面光域确实缩弱。因此撤回“生产视效不随损伤变化”的推测，不把该中间 fixture 当生产缺陷。0HP并不必令异物全黑；需要核的是失效是否仍假演稳定工作。

### R8-03 墙垣大构型：改善已直接可读

长段墙肩、右侧剪切和前楼板厚面已经能在全景区分，小咬口不再统治轮廓。右墙受力承接仍有 P2，见下文 V02。墙体可继续保持大面完整，无需恢复 R7 的碎缺细节。

### R8-04 核心仪式：主焦点成立，独占空间脆弱

核心是全景首要注视对象；夹持件和竖向尺度提升了“受约束活物”读法。主层位置有路线预算理由；当前不足在背后，而非单纯尺寸不够：右剪影与坡道密线相接、顶部贴近上层明面、后方缺少与建筑连接的暗承托。优先修这些关系，不继续同比放大核心。

### R8-05 核心动态：活动改善可读，短时修复采样有响应

封存视频中，正常核心内腔有上下不等幅的挤压与横向收窄，夹持位置略有变化，外壳主体保持稳定。约7–13秒的8fps原像素采样能区分扩张、偏移与收紧，不再只是静态亮物；地面光域有轻变化，未出现均匀放大缩小整物的机械呼吸。

损伤24HP对照明显缩弱地面光域，形变有较长停留和较窄振幅；这和“旺盛正常循环只换读数”不同。约35–39.75秒的真实键盘修复片段中，读数24→28、薪柴100→99，形体与地面亮度出现短促增强后归稳。采样能证明响应存在，尚不足以定量确认每一承力阶段。视频所用正常值是70HP；损伤fixture为24/0/70，与前述投资测试8/24/0不可混称。

后续`motion-light/paired-light.webm`约每0.5秒采样和原尺寸帧仍保持核心主光、设备局部轻光的等级。作者的`phase.json`给出110次真实场景读数，主体活动与发光采样误差最大0.00281，缓存步长80ms；它支持同源时序已接入，不能替代逐帧肉眼判断。`transactions`实购加厚后100/100→100/115，退出培养藏面板后的全景采样中核心仍保持主光，记录中静置光值同为0.457。此处行为因果成立。

### R8-06 六物动作：常态有主次，供奉事件因果可读，表现力不等齐

六物静态身份不同，空供奉环中未见凭空供物。核心的挤压、培养藏内部介质轻动、裂隙亮点迁移已在原像素采样中看见，三者没有明显同拍循环。全景约每2秒采样跨越两段31秒待机，主焦点始终是核心，没有看到所有装置一起抢注意力。

供奉、储藏和净化器的常态变化在原像素裁片中仍很轻；本评审不能仅根据记录里帧号变化，就把它们各自的工作动词判为已清楚传达。允许它们长时间静默；关键应由实际结果使不同动作有因果。

补看`transactions/transactions.webm`：全段约1秒采样，供奉放入约12–15秒和成熟归来约26–28.25秒按8fps补采。放入时空环出现绿色介质与短暂小点，夹持部位有轻变化；退出聚焦后有物状态保留；成熟归来、关报告后回到空环，顶端结果文字说明收入储藏。**空/有/返空关系清楚，短开合动作的力度仍弱于状态变化本身。** 实际供奉触发不再只是待证；储藏与净化器各自的细小常态动作仍不能据此一并签收为成熟表现。无声录屏不能验证听觉层的沉浸感。

### R8-07 外景深度：体积改善可读，中远关系仍脆弱

近处断构比 R7 有厚度；静帧能分室内与室外。最外层形状仍多为同样粗细的折角带，左右近景和壳墙相似度高，缺少一条强的前遮后关系与尺度递减。需要更清楚的少量遮挡链，不能以“有三层资产”代替纵深。

## D. 具体可修问题

### V01｜核心后景与坡道相切（P2，常驻，高把握）

- **位置**：全景 x510–715 / y495–625；特写 `runtime/02-repair-core.png` 中核心右肩后方。
- **所见及后果**：坡道明暗横线直抵核心右轮廓，核心顶部与后平台接近明度；主物虽亮，但像立在通道前的一台独立展示设备，建筑没给它足够独占空间。
- **竞争解释**：运动或局部光有可能分离轮廓；但不能靠持续动作弥补静态主次。
- **建议**：在通路不变的前提下，收静核心背后的坡面细线/局部明度，或调整可见坡缘与核心轮廓的关系；承托面若加到不可走后区，要能连接底座与建筑。不要用外描边、整圈光晕或进一步加大躯壳解决。
- **收益/代价**：改善主物轮廓与场所记忆；局部资产级，具体工量由实现方确认。要保护坡道可走读法和人物遮挡。
- **最小验证**：同倍率全景、核心聚焦、人物从后侧经过；不读文字也可看清核心完整外形，坡仍可辨。

### V02｜右墙剪切段承接含糊（P2，常驻，中高把握）

- **位置**：全景 x1100–1200 / y395–530。
- **所见及后果**：贯穿黑缝与悬横杆附近缺少清楚的断面、落点或内外板关系，像几张不同方向的面片拼在一起。大断裂方向正确，但重量感不足。
- **竞争解释**：可读作用横杆拉住的剪切墙，若画清杆的两端接点与后段回面，即可成立，不需要改变整堵墙。
- **建议**：只修这一处的断面厚度、遮挡先后及横杆连接；保持下部封闭，避免制造看似可走的出口。
- **最小验证**：全景与入口聚焦中都能看出哪一段在前、哪一段在后、杆连在哪里；无需添加更多小缺口。

### V03｜外景的近中远主要依赖变暗（P2，常驻，中高把握）

- **位置**：左 x0–180 / y255–805，右 x1285–1440 / y290–855，及上方折带。
- **所见及后果**：近壳有厚度，但外围形体面向、粗细和转折节奏相近，容易读成房间外又围一圈相同构件；不够支持外部巨大且陌生的空间。
- **建议**：定点建立一条近断面遮住较小中段、中段再消入低细节远形的关系；远形减少可数折角，近处保有明确厚度。别通过整体增亮或满屏尘点制造深度。
- **最小验证**：无粒子静帧已分出至少一处明确的前后关系；聚焦镜头变化时这些形体仍连接在空间里，不能像壁纸滑开。

## E. UI 方法自检与闸门范围

载体为实际设备旁的世界读数与聚焦观察；当前不是新设计通用软件面板。观察依据是本作已认可的核心交互，参考维度沿现行 Kit 的 Signalis 克制读数、Darkwood 世界留白、Hyper Light Drifter 局部信号主次，不移植其皮肤。

三问书面结论：

1. **审美**：已看聚焦帧文字退于实体，受损/失效有辨别，未出现大片色块抢焦。淡入与换侧未独立逐帧验证；不代签审美。
2. **游戏内行为**：完整度紧邻正在操作的实体，投入量和真实效果在右侧展开；静帧读法清楚，键鼠时序由连续证据与 QA 补充。
3. **与当前世界的关系**：无框读数、灰绿文字、窄规与克制暗场仍属现行交互语言；新状态色不是新一套窗口。世界条和聚焦条需要共享状态，技术挂载仅按 `#dom-ui-root`/世界标记约定核对，尚未作代码审计。

U1：静态载体成立，挂载事实未审；U2：未见卡片/渐变按钮等反模式；U3：所见颜色符合本轮状态提案，最终登记由协调者收口；U4：未见字号或字体突变，未测CSS；U5：可见用词为完整度/受损/失效/投入/薪柴；U6：已看站位不遮人，全站位未审；U7：截图不能证明输入绑定；U8：资源不足与失效各有文字；U9：标签/状态/数字分离，0HP有端帽；U10：400ms反馈时序待连续证据；U11：静态与现行共享语言连续，复用代码未审；U12：沿现行Kit具名锚点，不另造视觉参考皮肤。

## F. 时间采样证据与交付边界
