# R6 场景评审：让脚下这段路也值得走

## 判断

**用户关于同纹理、全图相似和人工公园感的反馈成立。R6 应优先重组可玩近景的形体和观看节奏，再用材料把这些关系画清。** 现在最有吸引力的是空中的巨构；角色走到的地方，反复是宽平台、连接带和几块摆石。远景许诺了一个陌生世界，近景尚未兑现探索它的体验。把缺陷修到不破面，或把岩石纹理换成另一张，都不足以兑现这个许诺。

我会坚持三个取舍：保留冠台的大块安静走面和开阔空腔；撤掉每个台面都放两三块独立岩块的重复构图；让一个区域主要由一个可记住的形体关系成立。五区应是同一身体上连续变化的五处经历，不能变成陈列五种岩性的五个展台。

本报告只有评审和计划建议。唯一执行清单仍在 [iteration-23.md 的 R6](../tasks/iteration-23.md#dec-166--r6自然地貌与材质分化计划2026-09-15not-started)，所有 R6 项仍未实施。

### 看见的事实与解释分开

- **直接画面证据：** 五处脚下普遍是相近灰褐大面、斜向细碎笔触、整片崖边、少量孤立岩块；区域之间最显眼的变化来自相机位置和背景占幅。岩块有体积、转面和投影，不是完全无法辨认；问题是主体材料和形成关系不足，不能夸大为“所有石头都看不见”。
- **源码复核：** `vista-model.ts:147` 的 `setSurfaceTexture` 将同一 `texture` 赋给 `texturedMaterials`；地面、岩石和崖壁经同一材料登记方法加入。`vista-terrain.ts:93`、`vista-rocks.ts:55/67`、`vista-cliff.ts:34` 的 UV 均采用 `/744` 尺度。可确认共享覆盖图与相近世界尺度。不同表面有坐标映射差异，不能写成所有像素完全相同。
- **美术判断：** “公园”“长凳”“摆盘”是观看类比，依据是重复的大平台与孤立摆石组合，不是推断世界里存在人工建设。自然感不足同时发生在轮廓、摆放关系与材料分布上。
- **未获证明的形成原因：** 风化、背风沉积、受压剥落、纤维拉伸，是 R6 可采用的设计解释。现有截图不足以验证它们。先选一个能被画面支持的原因，不能先给区域命名再宣称玩家已看懂。
- **证据限制：** 七张静帧不能验证完整动画、受力传递时序、音频、实际操作、相机移动稳定性、全路线通行、碰撞与回程记忆。本轮没有浏览器操作或试听，也不复用历史测试代签这些项目。

## 七项建议，按优先级推进

### 1. P0：质量段先证明“我想走到那里”，材料在这段路上成立

**原帧位置与证据：** 起点左上通向西台的颈部约 `(350,390)`；西台右上通向冠台约 `(1010,365)`；冠台角色背后的双石约 `(390–740,350–450)`。道路可见，目的地仍主要是另一块摆石平面，最吸引眼睛的巨构又不能走到。

**玩家影响：** 能沿路移动，不等于有继续探一段的视觉动机。远处精致、近处单调会让玩家觉得自己在风景画前绕圈。

**可执行处方：** 首段采用入口→西台→望向冠台，至少包含两处实际站位和一次转折。入口提供相对安静的落脚面；西台用一条从本体露出的斜向壳脊组织转向；冠台保留可辨的大壳肩与天空开口，成为下一处可达的观看位置。壳脊方向服务现有路线，不画发光引路线，不增加奖励、任务或新交互。裸岩、沉积、剥落、崖壁沿这段经历自然出现，无须同屏平均陈列四种材料。

**验收问题：** 在正常镜头里，玩家能否指出“接下来想去的那一处地形”，并从入口、西台、冠台分别说出不同的观看感受？不用区域标签和箭头还能否成立？

**映射：** R6-01 增加“两站一转折/目的地”；R6-05 负责通行构成；R6-06 增加前望与到达对照。

### 2. P0：打破圆台＋步道＋摆石组合，改中尺度构成

**原帧位置与证据：** `route-08-lower` 全图前后双台面；`route-15-middle` 的中段 `(0–1200,460–650)`。长连接带和轮廓规整的大台面构成主要空间，石头只加在平面上，没有改变空间的由来。

**玩家影响：** 每走一段都经历相同的“宽场地—窄路—宽场地”。自然景观应有受结构挤出、绕过、展开的空间感；现状更像沿预画路线铺好地板。

**可执行处方：** 在路线旁让连续露壳从地面中升起、局部断开、再埋回沉积；同一形体同时影响坡向、石根和外缘。中脊只需一侧出现明确的搭接/折面，另一侧保持顺畅的长边，避免两边同时平均锯齿化。回折处用一个宽浅内湾集中褶皱和积屑，外弧保留连续安静面。允许按 R6 授权重新组织外缘、宽窄和起伏，同步真实高程和身体支持；不以旧圆台外轮廓作为必须保留的审美前提。

**验收问题：** 暂时不看细纹和石块小件，是否仍能看出露壳脊、搭接和内湾三个不同的大形关系？通路是否像从这些结构之间形成？

**映射：** R6-03、R6-05；在 R6-01 先验证，不等五区全部铺完才改轮廓。

### 3. P0：岩体与覆盖物分开画，接触要讲得通

**原帧位置与证据：** `route-06-east` 右侧大石 `(655–785,420–540)` 与其下方地表；`route-08-lower` 右下长石 `(655–805,480–630)`。石顶和走面均有相近的刷纹，石根的小碎块呈绕放感；入口左石也重复此关系。

**玩家影响：** 对物质的触感缺少判断：像同一团材料压出地板再捏出石头。画面因此欠缺重量、尺度和自然形成的可信度。

**可执行处方：** 岩块主体保留少量完整大面，硬断口由形体及明确面色承担；细碎低反差沉积只占凹处、背侧和根部。嵌生壳脊与游离崩块区别处理：前者延续地层方向，后者在来源侧有断口对应和集中碎屑，不能每块石四周同样围一圈砾石。剥落层有少量清楚的搭接边，不把全区切成鳞片。可以共用底层资源，但覆盖分布、边缘、尺度与方向必须服从材料，而不是继续只靠整体明暗区别。

**验收问题：** 在角色正常大小的同屏画面里，能否分出“完整硬体”“附着的碎屑”“露出的断面”？石块看起来是从这里露出或落在这里，而不是统一放置的吗？

**映射：** R6-02、R6-03；R6-06 看正常机位接触关系，不以材质数量作为结果。

### 4. P1：五区的身份首先是可记住的形体，不是五套材料标签

**原帧位置与证据：** `route-02-west` 立石＋矮石，`route-04-crown` 双横石，`route-06-east` 长石＋矮石，`route-08-lower` 长石＋石组。变化存在，却主要是类似小件的布置；冠台开阔视野反而是更强的区域体验。

**玩家影响：** 往返容易只记住“有石头的平台”，区域称谓不能转化为空间记忆。让每区均展示露岩、沉积、裂缝、纤维，会进一步抹平差异。

**可执行处方：** 沿用 R6 已提形成逻辑，每区只推一个主关系：入口偏心半埋壳肩；西脊斜向露壳；冠台完整壳面与大天空口；东台沿受力展开的定向长折面；回折台内侧搭接积屑。材料跨区继续，主形不平均复制。去程可先见主形轮廓，回程从另一侧仍能认出它的方向和邻接空腔。具体比例由真实场景调整，不给五区硬凑同一套配件清单。

**验收问题：** 不看文件名，把五区正常机位帧混在一起，能否凭形体说出不同处？真实回程能否靠已见的主形与空腔找回入口，而非背石块坐标？

**映射：** R6-04；R6-06 增加去程/回程成对观察。静帧可先筛同质性，实际空间记忆必须走一趟。

### 5. P1：脚下要与远处同一个世界，保留一处可追踪的组织关系

**原帧位置与证据：** 起点左上和西台上方是带层片、跨接束的巨大体；`route-15-middle` 下方 `(280–640,640–800)` 的褐色弯体及上方厚板属于更简化的材料语言。近景与远景在色彩上接近，组织方式和受力方向却缺乏一处清楚的衔接。

**玩家影响：** 巨构可作为景观成立，但还容易读成背景画。单独把脚下修成逼真的矿物地质，也不会自动使玩家相信自己行走于生命大陆。

**可执行处方：** 在首质量段选择一处既有台缘/承托关系，让顶面层理转入侧壁，再沿一个有方向的接续指向外侧承体。只做一处足够清楚的关系，其余保持空气，不把每段边缘都挂满纤维。沿用 R5 近中远的材料家族与距离分层，同时让近处大面具有与中景相容的面色和定向层片，避免通过增加同样密度的细纹来“统一”。生命表达仍由原生组织和已有局部动作承担，不添加草木、建筑、血肉符号或新生态玩法。

**验收问题：** 正常站位能否沿可见形体指出“脚下这段如何接入更大的存在”，无需术语解释？转入动态验证后，这个已辨认的接点是否仍可追踪，动作是否让关系更清楚？

**映射：** R6-01、R6-03、R6-04；R6-06 保留既有动画复核。完整承重/污染机制仍冻结，不能借本项重新开启。

### 6. P1：丰富地貌时保护角色与落脚，近景必须有自己的主次

**原帧位置与证据：** 七张角色均约四五十像素高，能辨出头、躯干和脚；`route-06-east` 角色约 `(543,505)`，细长身躯与地面颜色接近。当前角色附近较空，使它仍可找见；起点与西台高反差细节主要聚在左上巨构。

**玩家影响：** 一旦把裂纹、壳片和碎屑均匀加密，小人的腿和下一步落脚会最先被吞没。若继续缩人来强调壮阔，则会用操作辨认换规模。

**可执行处方：** 维持当前角色尺度作为首轮对照；沿必要通行带布置低反差的大面，以地形坡向和材料边界表达变化。集中高反差断口于路线旁的主形和局部崖唇，不在角色脚下铺同等密度的裂纹。先让近景一个主形能接住眼睛，再考虑局部调远景细节；不以全屏模糊、统一去纹理或角色光圈补救。新增会影响通行辨认的材料在规格期补充当地背景对比/明度检查，由 code 在真实采样后落实数值，不凭这组压缩展示口算通过阈值。

**验收问题：** 进入每区无需寻找，能否立即看到身体、双脚和前方一至两身长的走面？在丰富地貌的帧里，视线能否从角色到近处主形再到下一处，而不是一直跳回远景细纹？

**映射：** R6-01、R6-05、R6-06；这是地表的可读性约束，不新增 HUD 或角色美术需求。

### 7. P1：把绘制精力用于大面与疏密变化，别把质量段做成材料样板

**原帧位置与证据：** `route-04-crown` 顶面和 `route-15-middle` 长走面存在连续、方向近似的斜向笔触；`route-08-lower` 在前后两台都能看到类似纹理频率。现在问题同时包括“一样的材料”和“一样的画面节奏”。

**玩家影响：** 增加五种同样密集的纹理，仍会让所有地方看起来工作量很满而体验相同；过分强调每块断口的解释，会失去远景已提供的孤独和宏大。

**可执行处方：** 绘制分配遵循主形：冠台大面安静，断缘是少量重点；西脊用大硬面与断口对照；回折以成片低反差积屑衬一个搭接。先拉开大块边界与细纹的尺度，再精修笔触。四类材料是画面语法库，五区是路线经历，不要求每区等量展示。质量段与全路线评审同时回答“脚下是什么”“下一段为何值得走”“哪一处让我停一下”，保留不解释、不铺满的空处。

**验收问题：** 正常镜头下是否存在明显的安静面、集中刻画处和大尺度空腔？冠台是否比西脊更舒展，而不是只是换了一种裂纹？不给地质名词，场景是否仍能说明它的形体和去处？

**映射：** R6-01、R6-02、R6-04、R6-06。R6-07 保存上述对应站位、失败帧与未验证项，不把检查结果统一写成美术通过。
