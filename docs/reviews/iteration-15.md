# 迭代15：裂隙污染体生成系统审查

## 总体判断

当前体系最有价值的方向，是让污染占据地面、墙面和空间，使探索路线本身成为遭遇。下一步应让「看见的形体 → 预计的行为 → 可采取的应对」形成稳定关系。现有生成组合数量已经超过行为兑现与模型辨识的成熟度；继续增加外形参数，收益会低于先修通这条关系。

审美上应保留「原物残留、结构被改写、材料仍来自现场」的方向。低覆盖模型需要先让人看见虫的身体、门框的空洞、残骸的重量，再让异常发生。单纯增加青绿光、碎像素和不规则轮廓，会让模型更加相似且难以理解。

## 证据与限制

- 代码基线 a626417，检查生产 `RiftScene → generateRiftLayout → drawSortie → attachLexiconForms → AISystem / ContaminationHostSystem → scheme-d-mixed`，并与设计正文、生成数据和现行模型对照。
- 当前浏览器检查陈列馆的虫、门框、街具、哺乳动物、有机残影、蠕虫、油膜、余响，以及句法课占空体积；保存11张截图，见[证据目录](../art/iteration-15-evidence/README.md)。虫另外检查 idle / strike 信号相。
- 打开了隔离存档的正式裂隙入口，但本轮未完成可复述的移动战斗路线。因此不声称已验证实战反应时间、死亡公平性或所有模型的雾中辨识率。陈列馆不带生产地面/视野，句法课不等于正常受伤体验。
- QA只读调用生产生成器抽样 seeds 1–64：共214个占地体、34个占墙体、30个占空体、460个占漆体。占地基底为有机残影114、街具34、残茎22、门框15、蠕虫13、虫11、哺乳动物5。这是有限种子样本，不代表完整概率分布或玩家遭遇时长。
- `npm run build`、`npm run check:lexicon`、`npm run check:layout`（8 seeds）、`npm run check:paint-quota`（12个地图/年龄样本）通过；构建存在原有大包警告。这些检查不能证明模型好看或行为词素已全部兑现。

## 当前生成到底提供了什么

正式名称为「污染句法」（DEC-078）。基底与覆盖度决定原物和被改写程度，连续性与占据方式组织存在形式，运动/感知/节律/接触词素描述其动作和危险，外形基因谱绘制个体。设计要求生成结果交付外观、存续、运动、感知、攻击和消亡，而非只有名字组合。

生产每图有3–4个占地体，另有1个占墙或占空体；占漆按地图年龄为3–5、6–8、9–12个，同图复用占漆形态配方、用不同种子改变几何。四类已有实质不同的基本应对：占地侦测追击近战；占墙邻近预警后伤害；占漆踩踏增加混乱，部分可清核；占空在范围内增加混乱并压缩视野，部分有核、部分为不可杀领域。

依据：`src/generation/rift-layout.ts:673,688,829,851`，`src/generation/contamination-draw.ts:58,575`，`src/systems/contamination-host-system.ts:631,685,724,771`。四类基础差异应保留，类内丰富度需要按玩家实际能识别的行为重新评估。

## 优先处理：外形与行为的对应

### F01 高优先级／源码与生成样本确认：固着的门框、街具仍被安排巡逻

渲染器将门框和街具识别为固着体，只给呼吸形变，不播放行走；AI仍为它们建立巡逻路径并更新位置。结果具备「固定物整体平移」的条件，与地面门框须固着的规格冲突。64种子中门框/街具共49个，不能视为极小概率边角。

复现入口：seed 1，旧图书馆，ENM_INF_03 门框，巡逻格点(33,18)↔(40,13)；seed 3，ENM_RWR_01 街具，(51,25)↔(37,25)。这是生成与代码证据，本轮未录制其实际平移视频。

依据：`src/entities/form-renderers/d/genome/attach.ts:36,100,114`；`src/systems/ai/ai-system.ts:861`；`src/systems/ai/behaviors.ts:180`；`docs/specs/system-contamination-lexicon.md:307`。

建议：先决定每种原物允许怎样运动，再让合法组合、AI和渲染共同消费。若保留移动门框，必须设计可理解的运动方式与信号；不能仅取消固着标签使它播放通用步态。

### F02 高优先级／源码确认：部分运动和节律词素没有成为行为差异

占地体抽到巡游、转面、凝聚，以及常开、休眠、脉冲等词素后，仍主要进入同一套五态、两种基础角色配置。当前基因谱主要消费朝向、AI信号和是否移动，未把这些运动/节律含义兑现成相应的遭遇规则。64种子占地样本包含巡游116、凝聚46、转面52，以及常开78、休眠68、脉冲68；生成池确实在使用这些组合。

占墙攻击主要按邻近判断；占空范围内的混乱结算也没有按抽到的感知/节律建立相应开关。外观可能有差异，但不能因此宣称产生了对应的玩法差异。

依据：`src/entities/enemy-factory.ts:73`；`src/systems/ai/ai-system.ts:861`；`src/entities/form-renderers/d/genome/attach.ts:100,145`；`src/systems/contamination-host-system.ts:631,644,771`。

体验影响：玩家难以从观察中学到稳定规则；如果表现暗示休眠窗口，实际危险却没有同步，可能产生不公平感。后一项属于需实战验证的风险，尚未观察到具体误伤案例。

建议：逐个追踪词素的真实消费方，划分已兑现、纯外形变化和未兑现。先锁几种完整的遭遇配方，减少失真的组合；不必为了形式上的排列组合为每个词素新增一套AI。

### F03 中优先级／源码确认：受击与死亡闪白还使用旧角色贴图

`captureEnemyFlash` 根据 infiltrator / rewriter 角色选择旧贴图，没有复制当前基因谱外形。新虫、门框等形体进入战斗反馈时，存在闪出旧轮廓的接线错误。

依据：`src/systems/combat-system.ts:539,578,956`；`src/scenes/rift-scene.ts:1155`。需要在正式受击/死亡过程中验证可见程度。建议让闪白来源于实际显示的形体，并覆盖不同朝向、覆盖度和尺寸。

## 模型与审美判断

### F04 高优先级／当前画面判断：虫的身体结构被两束直脚取代

在当前陈列馆尺寸下，多条细腿重叠成左右两束近竖直支撑，身体缩在顶部。第一眼容易读成凳子、夹具或门架；拉高的变体尤其接近门框。问题来自重心、关节方向、腿间负空间与着地点的关系。

依据：[虫馆藏](../art/iteration-15-evidence/insect-gallery.png)；`src/entities/form-renderers/d/genome/insect-remnant.ts` 的 `layoutInsectNodes`。身体位于高度约18%–24%，足端贴近底部，顶部甲块小，同侧足线间距窄，像素合并后失去多足读法。

建议：以一个虫模型为首个形体重建样本，先明确躯干质量、前后方向与有节奏的着地关系，再施加污染变形。加腿、加描边或提高亮度都不能替代结构修正。

### F05 中优先级／当前画面判断：部分生物残影缺少原物质量，家族之间相似

部分哺乳动物缩成尖耳小块，难判断头、躯干、四肢关系；蠕虫虽然有正确横向轴线，但短段变体像折断的零件。门框有清晰空洞这一优势，但不少变化主要发生在横梁宽度和线条位置，与虫的倒U形又接近。

依据：[哺乳动物](../art/iteration-15-evidence/feline-gallery.png)、[蠕虫](../art/iteration-15-evidence/worm-gallery.png)、[门框](../art/iteration-15-evidence/doorframe-gallery.png)。判断限于已检查样本，不外推所有种子/覆盖度均失败。既有像素去重和粗占格差异通过，也不等于玩家记得住不同威胁。

建议：给每个家族保留稳定的大轮廓、重心和动作轴，再随机局部破坏。低覆盖能读出原物，高覆盖再逐步失去原物秩序。让随机变化围绕可辨认的形体展开。

### F06 中优先级／画面与源码支持，实战待验证：动作与危险信号容易被随机结构吞没

虫的 idle / strike 检视中，变化不足以改变主姿态。共用 strike 主要有约2像素的前倾与核心增亮，通用步态时钟为6fps；这些数值本身不构成错误，但复杂轮廓下能否提供足够可辨的攻击准备值得优先验证。占墙预警边线较细，大体积占空模型的边界、核心与实际危险范围也需要一并读清。

依据：[idle](../art/iteration-15-evidence/insect-idle.png)、[strike](../art/iteration-15-evidence/insect-strike.png)、[占空观察场](../art/iteration-15-evidence/ding-arena.png)；`genome/attach.ts:107`、`genome/bake.ts:269`、`d/yi-paint.ts:139`（均在 `src/entities/form-renderers/` 下）。

建议：先设计蓄势、出手、收势的大动作关系和轮廓停顿，再决定帧数。让信号在玩家移动与视野边缘仍可辨识；不通过整体提亮所有敌人来解决。

## 玩家体验与生成节奏

### F07 中优先级／生成确认、体验判断待实战：缺少随出击经验建立的遭遇学习层次

地图年龄与残破由种子抽样，当前生成没有按出击次数安排介绍顺序。首次出击也可能抽到古老地图和较多占漆。64种子年龄分布为新生23、标准18、古老23。此行为未必违反现有随机合同，但与「先学会观察，再权衡绕行、出手、撤退」之间存在体验风险。

依据：`src/generation/fragment-roll.ts:20`；`src/generation/contamination-draw.ts:381`。尚不能从数量直接推定首局难度：路线、可见性、玩家装配和逃离条件都会影响压力。

建议：先限制同时需要学习的陌生规则数量，让少量可识别的威胁重复出现，再逐步组合；具体首局池与强度数值应在实战后确定。

### F08 中优先级／源码确认：墙面听觉变体未进入当前抽样路径

生成器重抽非听觉的墙/空宿主，再把恰好一个听觉名额分配给占地体。64种子中听觉占地64、听觉占墙0。满足听觉敌人数量约束，却没有兑现设计允许的「占地听噪或占墙听缝」替换，缩窄环境遭遇的变化。

依据：`src/generation/rift-layout.ts:673,699,730`。建议先明确是否仍需要墙面听觉配方，再与 F02 一起实现并验证其应对方式；不要只扩大随机池。

## 审查边界与待验证项

- 菌毯/灰幕的练习场基因谱与生产旧渲染存在分叉。迭代7明确未将它们升级出击，这是已记录的范围边界，不能误报成新回归，也不能拿预览新模型给生产打分。依据 `scheme-d-mixed.ts:25` 与 `d/gym-attach.ts:20`。
- 占墙/占空基因谱 deferred 仍保留；本轮审查不自动开启重做。
- 实体可见度仍有分档处理，需观察大体积污染穿过视野边缘是否整块跳显；仅由源码不能断言体验失败。需同时核实较大外形与实际受击范围，贴图画布不等于可见实体面积。
- 占地基因谱默认材质色未直接随碎片类型取色，与美术HOW需要对照；这不等于应该给不同碎片的敌人统一换色。先看真实场景中的材料归属与可读性。
- 本轮未测试音频识别、长期重复疲劳和完整的撤离压力曲线，不能为这些项目打分。
- 裂隙敌人/玩家不互相物理推挤是既有AI合同；不能将净化点新增底座碰撞直接推广为裂隙缺陷。

## 建议执行次序

1. **先统一行为事实。** 优先F01/F02/F03，逐项确认外形所承诺的规则。F08并入合法配方盘点。保留四种占据方式，不继续扩充无实际应对差异的组合。
2. **再完成一个代表模型与遭遇。** 建议先用虫验证原物识别、污染变形、移动、警觉、攻击、受击和消亡。样本必须进入正式裂隙地面与视野，通过后再推广到其他家族。
3. **以几种稳定的危险读法组织随机生成。** 移动威胁、墙面伏击、区域占据各有可观察信号与明确应对；个体随机化保留其关键特征。按实际体验决定学习顺序和组合预算。
4. **最后扩模型与种子变化。** 以实际记忆点和不同决策为标准，不以陈列馆数量、像素去重率替代体验质量。

以上为审查建议，尚未实施或获用户锁定。此次只更新迭代文档与证据，不改生产系统。
