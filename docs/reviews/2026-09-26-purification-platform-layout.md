# 净化点平台：对象摆放与动线设计审查

**结论：分区骨架成立，使用空间还没有全部成立。** 旧图书馆残构、沿边设备、中央炉边休息、右前核心已经组成有性格的据点。现阶段应修正坡口接合、裂隙前场和几组静物的归属，而不是重新洗牌所有装置、填满中央空地或重做已经成立的画法。

本轮只审查并提出修改建议，没有改场景。六个原功能站、独立坐下点、炉子，以及平台建筑/书架/箱罐/缆线/纸页/碎石均覆盖；外景只作为背景，不展开外景、美术渲染、声音、数值和生产UI的全面审查。

## 证据与判断边界

- 当前入口：`docs/art/demos/purification-last-light/index.html`，固定960×640；实际查看站立和坐姿整景，结合三维作者几何、装置操作锚及现行游戏机制。
- 这是知情设计审查。主审参与了前轮制作；空间视觉复核、静物清点与动线测量分工独立，不称为玩家盲测或用户研究。
- 当前样景不支持真实自由行走；“走起来”部分采用设计推断和布局模型，未用生产R10的行走结果冒充当前样景试玩。
- 补充路线采用0.16场景单位网格、0.22脚半径、八邻域不切角及三维距离。保留原检查的保守装置包围；路线长度是**该模型中的比较值**，不是实玩秒数，也不是最终角色碰撞结果。距离单位来自作者场景，不能直接换算真实游戏时间。
- 原6739个可站样本全连通，只能证明有一条路串起全部点；不能证明两条坡道分别贯通。它还漏掉了书架、箱罐、建筑柱等object 0静物。
- 现行“储藏”影响薪柴价值，不等于每趟必须去柜子存包。库存信息可通过基地Tab查看，出击装配在裂隙；供奉、维修与蜕变也不是每趟必须全做。因此不以“六站顺序巡回”强制重排场景。

## 需要保护的关系

1. **右侧核心与中央炉火是两种不同的中心。** 核心承担方向、仪式和公共秩序；炉边承担短暂停留和人的尺度。二者的距离与明度层级有意义，不应合并成一个亮点。
2. **上层保留“旧场所”，下层承载日常流动。** 上层书架、残柱和设备互相依托，楼板不是凭空加出的装置展示台；双坡原本有形成环路的价值。
3. **沿边布置让出完整的中央活动地面。** 净化器朝右、供奉朝内、核心朝几何中心，都让玩家站在场内操作。中央的空地是转向、辨认和选择下一站的余地，不是待填的洞。
4. **断墙坐席与炉的现有关系保留。** 坐席可解释为建筑遗存，坐姿有依托，炉火落在身体与热源之间。它已经构成完整小场所，无需再补桌、椅或一圈装饰。

## 优先发现

### PL-01：东坡上口没有兑现第二条上下通路

**类别：空间接合与验证缺口。优先处理，把握高（限定布局模型）。**

在现有布局模型中去掉西坡后，下层和东坡仍相连，上层却不可达。断点在东坡上口，不是核心堵住下口。东坡轴线x=12处，上层前沿约z=-2.2265；斜面在相交处约高2.432，上层高2.6，留下约0.168场景单位的竖槛。足圈/高差规则在接口剔除了整排采样点，于是“站得到东坡”不等于“走得上二层”。

当前模型核心→储藏约19.9、裂隙→储藏约20.5，都绕西坡。两者是模拟比较值；不据此声称正式游戏已经卡路。0.168的槛也并非现实中必然跨不过去，问题在于当前设计没有明确它是连续坡、台阶还是需要额外跨越规则。

**建议：先把东坡上口与二层做成清楚连续的接合，并留落脚缓冲；不先搬核心或储藏。** 验收时分别封闭另一条坡，确认两坡均能从下到上、从上到下，且不依赖从坡侧蹭入。工程代价小至中，需同步楼板/坡几何与通行面；艺术风险是把破损接口补成新施工的完整楼梯，应保持同一残破建筑语言。

证据：environment.ts:27–30、166–167、219–235；check.mjs:466–490。原测试只要求已访问集合包含两个坡的任意节点，故未发现此问题。

### PL-02：裂隙前场同时承担出击、杂物堆放和断沿展示

**类别：操作空间冲突＋视觉语义混淆。优先处理，把握高。**

裂隙操作点在[9.4,0,6.07]，位于伤口与前侧断沿之间；木箱仍在[8.95,.02,5.78]。操作点距旋转后的箱体约0.188，距外伸顶盖投影约0.158，小于同一布局模型的0.22脚半径。精确操作锚与道具占地不协调；补入大静物后，附近偏移约0.124仍有可站点，不能夸大为整区被堵死。正式交互若允许整片范围接近，冲突可能减轻，但指定锚仍应可靠。

长缆横穿裂隙东北分叉，松散盘缆也留在旁边。两者与裂口都是细暗线；木箱和铁罐又压住部分识别空间，使“时空伤口”容易读成一团设备管线。这伤害的是场所意义，不仅是画面干不干净。

**建议：保留裂隙的大致区域，先划出能完整站立、退一步和转身的操作前场；把木箱/罐收成侧边的一组，长缆避开伤口并交代端头。** 操作朝向优先服务中央来路，但需结合核心前场及断沿净空比较，不能先拍定一个新角度。保留少量备品能表达“有人从这里出发”；无需把所有东西随炉搬走。

最低验收：实际人物在精确操作锚可站立，脚和身体不与箱罐重叠；从中央接近及离开不必擦断沿；在正常镜头下，第一眼能从缆线中分辨裂隙的主体。代价小至中，主要是静物编组与局部操作区，不涉及重画六站。

证据：devices.ts:451–484、513；environment.ts:196–208；check.mjs:443–450。炉迁移只改了炉坐标，旧周边物仍留原处。

### PL-03：储藏的“最显眼一面”和“实际操作一面”没有同等清楚

**类别：操作读法。第二顺位，把握中。**

储藏靠二层前缘，最清楚的正面朝下层；实际操作点在西侧[9.02,2.6,-3.55]。这不是漏做控制器：模型在西侧确实有操作杆，因此不判方向错误。但正常整景中侧杆远弱于正面大结构，玩家可能从下层被正面吸引，到了设备旁才发现应从侧面使用。

**建议：保留二层位置与西侧操作，优先让“侧杆—玩家站位—可站楼板”组成清楚的一小片工作面。** 可通过侧面结构、局部受光和少量使用痕迹表达；不要加发光箭头，不必把整台翻向镜头。东坡接好后再评估是否还需微移。正常镜头带人物核对侧向操作是否可见、结束后能否顺接东坡；没有真实人物到位画面前，不断言设备一定遮住角色。

证据：devices.ts:263–307，特别是299–303的西侧操作杆；manifest中储藏与操作点投影。

### PL-04：部分生活静物的用途关系停留在旧炉位

**类别：场所可信度。第二顺位，把握高（位置），中（叙事读法）。**

木箱、罐、盘缆和下层散页原本围着旧炉，炉内移后没有重新分组。现在它们可以转为出击备品，但画面尚未明确这个关系。核心背侧的小叠物则有维护/仪式遗留的合理解释，不应与旧炉杂物一起清空。

**建议：每组道具确定一个归属：出击备品、炉边日用、核心维护、建筑残骸。** 同组有依托和留空，组间不靠碎纸和电线随意串联。最小改动应先移动/删除失去理由的物件，再考虑增加；不为所有杂物补写看不见的世界观。

炉顶直接放着两张纸，没有隔热或承托构件，是一个低优先的具体不合理。若要保留可读纸页，可移到石压顶一端或箱上；当前体量很小，不应为它开启大规模美术返工。

证据：environment.ts:195–215、306–309。

## 逐对象结论：交互物与炉

- **核心：保留。** 右沿、朝向中央、前方停顿区及后侧低残墙共同建立仪式感。它应成为目的地，而非主要过路点。没有证据证明它堵死东坡，不因此移动；避免把裂隙备品搬到其开口前。
- **净化器：保留位置和正右朝向。** 靠左断沿释放中央，操作面向场内，前轮检视窗使侧视内腔成立。操作点距坐席保守包围约0.909，扣除足半径仍约0.689；两物包围的横向间隔约1.146，大于足直径0.44。投影靠近没有构成实体挤占，不因此移动坐席或回转已确认角度。后续人物到位仍应核对上半身的遮挡读法。
- **供奉：保留。** 左后方作为有停顿的终点合理，开口朝中央，前场不与主交通重叠。后背临断沿不是必须修的问题，单人操作无需强求整圈绕行。与裂隙较远是有代价的节奏，但没有“每趟必须往返供奉”的规则，不足以支持搬站。
- **蜕变：保留二层区域。** 偏低频、停留较长的身体成长与书架背景相容；西坡抵达后有明确前侧操作处。它不会因不在最短出击线上就不合理。重点保留前沿完整站位，不在缸前添加箱柜。
- **储藏：保留，强化侧向操作读法。** 功能是影响薪柴价值的可维修模块，不能按“频繁存取仓库”机械地搬到裂隙旁。先修东坡，再评估微移。
- **裂隙：区域可保留，重整前场。** 自然伤口无需建筑底座或机械门框；跨裂口缆线与紧贴操作点的箱罐须优先理顺。
- **断墙坐席：保留。** 地坪中的基础、厚石压顶、单侧断柱说明它的来历，独立坐下功能也让停留有目的。避免用更多家具把它变成完整客厅。
- **炉：保留新位置，维护通往西坡的绕行带。** 炉门未正对座位不构成错误，侧向取暖成立。炉是路边的目的物，不应让主路线穿过炉与双脚之间；当前没有证据支持把它搬回旧处。

## 静态对象覆盖与处置

- **主平台、四块残留面层、五条大裂纹**：保留。中央的大面安静而有通行价值；不用碎物填平留白。
- **平台断面、三段墙残体、两块大岩断面、承力梁、五根断支撑、八根外露钢筋、两条悬缆**：保留。它们说明建筑从何断裂，不按生活杂物整理；未来接碰撞应区分楼板下结构与人物所在层。
- **十一组边沿石屑与五处断面骨料**：保留。贴近破口有因果；不得把同样碎屑均匀撒满行动区。
- **上层楼板、两段厚断口、两块沿边石体、前缘横梁、三处支承**：主体保留。确认柱与上层前缘在实际人物高度的净空，不能因为全部归object 0就忽略占地。
- **西坡与单侧扶手**：保留。主来路可辨；无须对称复制栏杆。核对独立贯通而不只看坡面可达。
- **东坡**：修上口接合。保留它连接上层与核心/裂隙区域的交通职责。
- **三座上层书架及其书册**：保留。沿后缘构成原图书馆的壳体，完整和破损的差异合理。两处架脚散页有明确归属；不随炉迁移。
- **两根高柱、斜顶梁、断柱头、左侧高木梁与垂索**：保留。承担背景边界和破损来源，不占中央；垂索与可站空间需要按高度检查，不能一律落成地面障碍。
- **核心背侧低残墙、断石和短钢筋**：保留。建立安装边界而不遮开口；不补高书柜来封满核心后方。
- **四组地面碎石**：按其断口/架脚来源保留，仅做贴边和净空核对；不是全部属于旧炉的道具。
- **旧炉位木箱与金属罐**：重新归组，木箱先离开裂隙操作锚。可留作出击备品，不必整体搬到炉边。
- **长缆与松散盘缆**：重布。不要横穿裂隙；给端头、挂靠或收纳理由，也不能假定它们就是六设备供能系统。
- **下层三处散页**：重新归组，失去来源的可以删。核心背侧两张散页与布/纸/木叠物可少量保留，收向后侧低墙。
- **炉顶两张纸**：低优先移位，避免直接烘在热金属顶板上。
- **六站脚座、轨条、夹具及设备内管路**：保留。它们已经说明不同设备如何安放进旧建筑；局部管线不等于全平台有一套已经建立的供能网络。

## 下一步建议与验收顺序

1. **先确认使用空间**：修东坡上口；将书架、箱罐、柱和静物合理占地加入专项检查；六个操作锚、坐席前方及两坡分别验通。不要为了让检查通过把所有小碎屑当成不可通行的墙，也不要继续遗漏大静物。
2. **再整理裂隙附近**：操作前场、备品组、缆线三者一次完成。检查能从中央自然接近、站稳、转身离开；正常画面读得出伤口而不是线缆团。
3. **最后调整工作面读法**：储藏侧杆、上层站位和炉边少量日用物。用真实人物到位图比较；若现有关系已经清楚就保留，不为变化而变化。

最小体验验收不要求全六站巡回：分别模拟“归来后只修一台便出发”“处理供奉后出发”“蜕变/修储藏后从东侧下楼”“坐下后起身去净化器或裂隙”。这些仍是后续验证场景，不是本轮已经完成的试玩。

独立美术结论：当前是轴测体积塑造、像素级材质与源光混合的废墟据点；核心的仪式轮廓、旧书架的建筑背景和炉边的人尺度构成主次。表达与身份成立，空间使用细节脆弱，不能通过增加纹理或全面提亮解决。本轮不审音频，不对真实行走手感作通过判断。
