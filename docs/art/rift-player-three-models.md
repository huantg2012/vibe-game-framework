# Rift 玩家模型三方案

**当前选择（2026-10-16，DEC-218）：用户选 A「短摆工装」。** 本批在余烬脊、晶化林床、破膜盆地的真实 Rift 场景试装，使用实际世界光、脚点和遮挡截图确认；不使用下述比较页检视光作为世界光源。B/C 仅是历史比较证据，不进入试装。完整战斗动作与全世界默认接入不是本批确认范围。

目标是让玩家从净化点进入 Rift 后仍认出同一个人。交付为透明底、实际像素尺寸、带脚点的模型帧与三视比较；原画、插画式转身图和只有放大后才成立的细节不算模型。

## 已核实的身份母型

权威来源是 [Last Light 人物几何](demos/purification-last-light/actor.ts)、[正式资源清单](../../public/assets/last-light/manifest.json)及[真实像素站姿](../qa/artifacts/last-light-actor/whole-body/idle.png)。已目视核对[人物模型图](demos/purification-last-light/assets/model-actor.png)。旧 `actor-pixels.md` 的“双场景共用 32×32”是旧实现描述：当前净化点为 15 朝向、1035 帧，Rift 仍是旧密像素人物。

三卡共同保留：

- 同一 1.665m 骨架与头身比例；完整、略收肩的人类体态。
- 圆铁盔、单条黑面罩及耳侧结构；不露面容，不画成对眼睛。
- 有重量和褶皱的旧帆布工装、分开的双腿和厚靴；布面与金属按真实构造相接。
- 帆布背包、折盖、两道背带、少量铁背架；不是新职业或新派系。
- **母型 local +X 肩侧唯一的暖灯**（源代码命名为右肩）。屏幕左右取决于生产 `cameraBasis.right`，沿原几何投影，不套用正面示意图的左右约定；不能以镜像复制把它换肩。灯壳、镜口与布面受光分开。

本质锁：这是靠维护旧工业装备穿行异时空的同一个幸存者。要求可辨的保护、负重和行动结构；排除重甲战士、长袍法师、污染变体及额外机械肢体。成立空间是同一工装系统的短摆、分襟长摆、覆肩三种体量组织。

## 共同机制与制作合同

本轮只抽形体与布料分布。移动、蹲伏、冲刺、受击、攻击时序、装备槽、武器握持与光照规则全部沿用生产；画出较大背包不增加容量，画出较长衣摆不改变防护或速度。

- **载体**：脚底接地的世界内人物。地面投影与模型分开；不画带黑底座的“立绘”。
- **相机**：同一 Last Light 正交相机，direction `[19,24,30]`、约 34° 俯角。正面 yaw=`atan2(19,30)`，灯侧 yaw=正面−π/2（local +X 为灯侧），背面 yaw=正面+π。只绕身体纵轴转向，相机俯角、焦距和身体高度不变；运行时 sprite 不旋转。
- **尺度**：统一源身高 1.665m。保留 64×80 透明画布、脚点 `[32,66]` 这一母型格式，实尺可见身高以共同导出相机为准；不得逐卡自动填满画布。比较页同时显示 1:1 和整数倍最近邻放大，放大不改变资产。
- **玩法碰撞**：继续使用 Rift 的 20px 身体，导入适配仅处理视觉脚点及偏移；不能因画布变大扩大角色碰撞。现有 `DENSE_PLAYER_GROUND_OFFSET_Y` 对应关系必须在接入阶段明确映射，不能把图集中心当脚底。
- **材料和颜色**：复用 Last Light 的 `cloth / iron / black / bronze / wood / lamp` 连续材质烘焙与原渲染计算，输出 color、albedo、normal、roughSpec、depth 同源 G-buffer。此候选继承当前母型画法，旧 32px 有限索引色板不适用；不做重新量化，不新增色族，不把旧人物灰阶当新母型。三卡采用同一套材料和光，禁止靠换色区分。
- **光照权威**：灯镜允许自发光，衣物、铁盔和背包不自发光。生产光源仍由正式肩灯系统决定；样片不得叠加一盏强光来补救黑成一团的身体。材质图与受光图分开，保留重新受光的可能，不把某张地图色调烘死在衣服上。
- **姿态**：三视静态共用一个中性承重姿态；步行动画复用母型的髋胸反向、分腿承重与摆臂，不用拉伸整张 sprite 模拟呼吸。先看形，再用同一短步态验证衣装遮挡。

参考锚点统一为本项目已经存在的三件东西：**Last Light 站姿母型**学头盔、软布、负重和右肩灯，不学整景的暖光强度；**Last Light 全身步态**学承重与停步归位，不把 1035 帧数量当本轮交付目标；**Rift 现行密像素人物**只保留实际脚点、碰撞与灯的游戏身份，不沿用其方块式躯干和低细节比例。

## A · 短摆工装

一句话读法：离开工作台，带着原来的行装进入裂隙。

肩到腰明显收束，短开衩衣摆留在大腿上段；双手、肘部和两腿各自可读。背包处于肩胛到腰间，厚度集中在背部中段，工具挂于包侧。正面读“头盔—收腰—两腿”，侧面读“胸身—背包”的前后关系，背面读折盖与双带。

以母型的短摆结构为基准，衣摆下缘约 0.62m；肩宽和包宽保持母型范围。这张卡的成立点是工装零件之间的清楚分离，不以增加补丁和扣件数量制造完成度。

## B · 长襟行者

一句话读法：旧外衣护住身体，双腿从分开的长襟间迈出。

头盔和骨架不变，肩部收紧；两片独立长襟延至膝上，前后中央均留开衩，衣摆向两侧分开。背包稍窄、纵向拉长、贴近背部。正面读纵向分襟，侧面读后垂布料和薄背包，背面仍清楚露出双腿及包带。

衣摆低点约 0.38–0.44m；不能遮住靴口或连成从腰到脚的一整块。包体宽度约为 A 的 0.80–0.88，增高时不越过颈根。无兜帽、披风尾巴或法袍式全包下身；重点是分离的布片体积。

## C · 覆肩负重

一句话读法：一层磨旧的护布压在肩背上，装备重量落得更低。

软帆布肩轭形成上宽下收的肩背轮廓，止于上臂和胸下，右侧让出肩灯；短衣身、收腰、裸露的前臂分段与双腿保持可读。背包的体量下移且横向展开，上缘低于肩胛，不长出高耸货架。

肩轭轮廓宽度约为 A 肩部的 1.18–1.28，非盔甲肩甲；包体宽约为 A 的 1.12–1.20、中心下移约 0.10–0.14m。正面读软质肩面，侧面读下垂折边与低位包体，背面读肩轭／背包两级体量。不得增添武器、氧气罐或与现机制无关的功能装置。

## 允许重组与不能拆开的内容

可在用户选卡后重组：衣摆长度与分襟、背包宽高及挂点、肩轭有无、现有材质的明暗分配。头盔、骨架、右肩灯、承重姿态、相机、脚点和世界比例是三卡共同身份，不参加重抽。三卡必须先按完整组合呈现，不排列成“衣服×背包×灯”的碎片菜单。

## 对比场景和检查

透明模型为可用资产，纯色底只供查边。艺术判断同时叠在当前认可的晶化林床与吸光釉原材质截块上，利用两者明度与色相差检查模型；使用相同截块、脚点、显示比例和照明。此处是地表材质对照，不是实际 Rift 场景，也不宣称已实现其动态光照。母型同场并排，不能拿放大的新模型对照缩小的旧人物。

机械检查只排已知错误，不代签审美：

1. 三卡的三视图均有非空硬边 alpha；相同尺寸与脚点，无裁断、阴影烘进身体或边缘抗锯齿晕圈。
2. 同视角的源骨架高度相同；无逐卡自动缩放。灯的局部 X 始终为角色右侧正值，各朝向投影位置随几何变化。
3. 保留头、躯干、两腿、包、灯的可识别体量。正/背中性姿态在靴之间至少留 1 个原生透明像素；B 的开衩不得在目标尺寸合成单片。
4. 同视图 A/B/C 不得像素完全相同；以去灯的身体 alpha 测差异，每对至少有一个正/侧/背视图的差集占并集 ≥8%。指标仅用于防止三卡退化成换色，不证明差异已经足够。
5. 布料／铁盔关键接面在标准灯下至少有两组明暗，灰度差 ≥8/255；全部身体不能只靠灯旁几个像素可读。以两张实景底检测：人物非发光外缘至少 55% 的像素与邻近背景亮度差 ≥10/255；失败先修材料/受光，不加整圈描边或光晕。
6. 若提供运动预览，脚点误差不超过 1px，头盔、衣装与背包同一动作骨架；右肩灯不能因衣装变体换到左肩。移动／物理数据与正式分支一致。

逐卡最短核：三卡均是站立世界对象，引用同一组生产参考；本轮不更改游戏内 HUD/DOM，U1–U12 的菜单布局项不适用。A 须检查零件是否因缩小糊成一块；B 须检查长襟是否误读为裙袍；C 须检查肩轭是否误读为战斗护甲。以上均为待看实际模型的检查点，不能凭本合同宣称效果成立。

用户只在模型比较后选方向。本轮不改净化点正式角色、不翻 Rift 默认，不宣称已经具备完整行走／战斗动画或完成生产接入。
