# 裂隙视野表现（迷雾 / 渐变带 / 光池）

## TL;DR

三件处方全部落在纹理生成函数内部与遮罩合成路径，**不动任何 constants 数值、不动任何规则**。迷雾：单像素白噪换成「2×2 成团颗粒 + 8×8 团块」双八度低频颗粒，破 45° 等速滚动。渐变带：三条带边界做 2px 宽、1px 颗粒的有序棋盘抖动（spec 待验证假设已挂的最小代价方案），墙截断的硬边不抖。光池：暖光与手电的径向渐变从线性斜坡换成「热核平台 + 快速中段衰减 + 长低尾巴」曲线族，手电光池沿朝向椭圆拉伸。全部处方挂**纹理能量平价闸门**（机器可核），保迷雾下亮度不回退。

---

## 定位与载体

迷雾 / 渐变带 / 光池是**引擎世界层表现**：钉世界坐标，住在世界空间 RenderTexture 遮罩（depth 50）与遮罩之下的 ADD 光池（depth 49）里，不是 UI 表面，不挂 `#dom-ui-root`，U1–U12 不作本包闸门（合同已锁）。两北星照样适用：审美过关（对得起 art-direction 与具名参考）与读作游戏——成品不得读作**调试可视化的视野多边形线框**。

出击与净化点共用同一套 `VisibilitySystem`（spec 规则 24，净化点 omni 配置、无虚空噪点）。本处方的纹理与合成变化对净化点同样生效：同一台设备、同一套语言，不为净化点或练习场另做分叉。人终审以裂隙出击画面为准，净化点顺带看一眼。

## 现状读法诊断

### 件 1：迷雾遮罩质感

现状实现：`ensureNoiseTexture` 生成 64px 可平铺画布，逐像素 30% 概率点亮、点亮值 140–255 中性灰；TileSprite alpha = 0.04（`VOID_NOISE_ALPHA`），X/Y 同速 2 px/s 对角滚动，近撤离点加速（≤5 tile 全效，≥40 tile 无效）。噪点画进遮罩、被三次 erase 一起剪，只留在视野外。

读法弱点：

1. **单像素白点是「雪花/星星」签名。** 逐像素独立随机 = 白噪，频率内容就是电视静态本身；30% 密度下每个亮点孤立无邻，读作「点在闪」，不读作「空间在那里」。黑暗里的「存在」应是成片的、比背景略亮的团块。
2. **点亮值 140–255 太亮。** 4% alpha 下仍是局部对比度最高的那类像素；「看不见的空间」的颗粒应低对比、成簇。
3. **45° 等速对角滚动是「屏幕叠层在滑动」的运动签名**——读作一层效果膜从画面上滑过，不是世界里的东西。

已 PASS 的是亮度与「不是纯黑」的基本盘；本件换颗粒语言，不是加亮。

### 件 2：三档渐变带过渡

现状实现：三层多边形 erase（alpha 1.0 / 0.5 / 0.2，复合残余暗度 0 / 0.40 / 0.80），带边界是硬多边形边。前向锥带宽 32px；环身圈半径 80px，带宽被 clamp 到 16px——三圈环挤在脚边。最外沿（0.80 vs 虚空 1.0）也是硬边，整个视野形状的多边形剪影外露。

读法弱点：

1. **1.0 → 0.6 → 0.2 → 0 的阶跃在像素画面里读成同心阶跃环**，环身圈尤其明显——三圈环套着玩家，是「视野多边形线框」感最强的地方，正是「读作调试可视化」的风险点。
2. **外沿硬边让视野读作「一个被剪出来的多边形」**，不是「光在黑暗里熄灭」。Darkwood 的边缘是破碎、不规则的熄灭线；我们的边缘是矢量多边形。

spec「待验证假设」已挂：三级硬分层带状感若过重，最小代价方案 = 带边界 1–2px dither。本件直接回答那条假设。

### 件 3：光池读法

现状实现：`ensureLampTexture` stops (0, 1) / (0.6, 0.45) / (1, 0)；`ensureFlashlightTexture` stops (0, 1) / (0.45, 0.55) / (1, 0)（即 a(r)=1−r 锥面）。两者都是 canvas 径向渐变的**线性 alpha 斜坡**。手电光池中心前推 0.34×射程（≈76px），直径 0.85×2×射程，被遮罩锥形孔剪成光束；暖光环身 360°。

读法弱点：

1. **线性斜坡 = 「渐变贴图」签名。** 无热核、无快速衰减段，读作「一个柔和的圆形渐变叠上去」，不是「一盏灯在黑暗里烧」。Darkwood 的光衰是热核小、中段快、尾巴长。
2. **手电的方向感完全由遮罩锥形孔的外轮廓提供**，光池内部缺少「从源头向外熄灭」的读法：玩家自己站在池值 0.6 处，热区飘在身前 76px 但衰减太慢，整锥读作「前方被均匀提亮」≈「被揭示」，弱于「被照亮」。
3. **暖光 0.6 处仍有 0.45 的平盘**让贴身一圈暖得太均匀——玩家读作「站在暖色圆盘里」，不是「带着一个点光源」。§2.3 规则 4 的叙事（你是唯一的暖色来源）要的是烧着的点，不是圆盘。

## 处方 1：迷雾噪点（改 `ensureNoiseTexture` 内部 + 滚动比）

**目标读法：** 视野外是「那里有空间，只是看不见」——低频、成团、极低对比的黑暗底噪；不读作「没加载完」（平黑无信号），不读作「电视雪花」（高频孤立白点）。

**纹理生成（参数级）：**

- 画布 64×64 不变（`VOID_NOISE_TILE` 不动），可平铺不变。
- **八度 A（颗粒）：** 32×32 细胞格（每细胞 2×2 px）。每细胞以概率 ≈0.55 点亮，点亮基值均匀取 [70, 130]；细胞内 4 像素共享基值，逐像素加 ±12 抖动。**最小颗粒是 2×2，禁止孤立单像素亮点**——这是去雪花签名的核心。
- **八度 B（团块）：** 8×8 细胞格（每细胞 8×8 px），每细胞偏移 ±18，加到八度 A 结果上，钳 [0, 160]。给黑暗「大块的存在感」，低频团块。
- **色：** 轻微冷偏——`r = v×0.90, g = v×0.95, b = v`，与 void-black #080a0c 的蓝灰同族。禁暖（§2.3 规则 3：无叙事理由的非灰）。
- **alpha 通道：** 点亮 255 / 未点亮 0，同现状。
- **无缝：** 64 被 2 与 8 整除，细胞级自动无缝，无需额外处理。

**滚动（改 `drawMask` 两行，不动常数）：** X 保持现状（`VOID_NOISE_SCROLL` × 近撤离加速，机制与取值不动）；**Y 取同一加速后速度的 0.6×**。破 45° 等速对角 = 去掉「屏幕叠层滑动」签名，双轴不等速读作世界里的缓慢气流。

**平价闸门（机器可核）：** 新纹理的 `mean((r+g+b)/3 × alpha/255)` 落在现状的 **0.90–1.10×**。现状基准 = 0.30 × 197.5 ≈ **59.3**；本处方起点 = 0.55 × 100 = **55.0** ≈ 0.93×，在带内。code 用一次性脚本核对新旧两张纹理；出带时只调覆盖率（纹理内部参数），**不调 `VOID_NOISE_ALPHA`**。

**不动：** `VOID_NOISE_ALPHA` / `VOID_NOISE_TILE` / `VOID_NOISE_SCROLL` 数值；近撤离加速语义；规则 17 的机制（噪点仍只在视野外，仍随遮罩 erase 被剪）。

## 处方 2：带边界 dither（改遮罩合成路径）

**目标读法：** 带与带之间不读成同心圆色带；视野外沿读作像素级破碎的「光熄灭线」，整个视野形状不再暴露矢量多边形剪影。三档数值与带几何不动——dither 是边界两侧各 1px 的**像素级交错**，不是第四档，不是连续渐变（连续渐变与 §7.1「3 级」冲突，spec 已写明）。

**合成法（每条边界两步，三条边界共 6 步）：**

对边界 k（k=0 核心|r1，k=1 中带|r2，k=2 外带|r3；r1 = 射程−2×带宽，r2 = 射程−带宽，r3 = 射程外沿，均按射线逐条取 `min(hitDist, r_k)` 后的现有多边形）：

1. **实擦收缩版：** 多边形 k 的每射线半径 −1px（钳 ≥ 0），以该层原有 erase alpha（1.0 / 0.5 / 0.2）擦除——硬边内移 1px。
2. **环抖版：** 沿**未收缩**多边形 k 的轮廓描 2px 环（`lineStyle(2)` + `strokePoints`，闭合），用 2×2 棋盘（1px 颗粒，50% 占空）TileSprite 经几何掩膜剪进环内，以**同一 erase alpha** 再擦一次——环内「开」像素获得内侧暗度、「关」像素保持外侧暗度。

净效果（erase 乘法可交换，保持由外向内顺序即可）：

| 边界 | 交错条带（2px，两侧各 1px） |
| ---- | ------------------------ |
| r1（核心\|中带） | 残余 0 / 0.40 棋盘交错 |
| r2（中带\|外带） | 残余 0.40 / 0.80 棋盘交错 |
| r3（外带\|虚空） | 残余 0.80 / 1.0 棋盘交错——视野外沿成破碎熄灭线 |

边界平均位置不变；r3 条带最外 1px 落在射程外，只影响**地面像素**的遮罩明暗（0.80 残余 = 外带同款 20% 可见），实体 alpha 仍走 `getVisibilityAt`——规则 23 逻辑渲染一致不破。

**墙截断的边不抖（工艺要点）：** 射线被墙截断处（`hitDist < r_k`），带边界本来就是「墙切光」的硬事件，保持硬边。dither 只给「射程尽头」的软边。实现：环按**线段**组装，仅当线段两端射线的边界都是射程边（两端 `hitDist ≥ r_k − 1`）才画出该段。若此判定落地别扭，可退化为全边界统一抖、接受墙根 2px 毛糙——我不推荐但可接受，code 自行权衡，不必回问。

**棋盘相位钉世界坐标：** 棋盘 TileSprite 位置按 `maskOriginX & 1, maskOriginY & 1` 校正，让同一世界位置的颗粒相位不随相机爬。静止时边界颗粒稳定；移动时边界随视野重建自然变化。

**验证点（code 先做 spike，两条路线像素等价，自选其一，不必回问）：**

- **路线一（首选，少活动件）：** `RenderTexture.erase` 对被几何掩膜剪过的 GameObject 是否生效。生效 → 每边界 1 次 stroke + 1 次 erase，共 +3 stroke +3 erase。
- **路线二（兜底）：** 一张遮罩尺寸的 scratch RenderTexture（`create` 一次性分配），每边界：clear → draw 环 stroke → 以 MULTIPLY draw 棋盘 → `mask.erase(scratch)`。

**性能：** 收缩半径在 `buildPolygons` 内派生（预分配数组，update/render 路径零新分配）；+3 次 erase 是固定成本，属规则 21「不降级 alpha 分级与噪点」的固定成本档，射线 2ms 预算路径不进新代码；静止缓存与两级降级不动。

**不动：** `BAND_ALPHAS` / `ERASE_ALPHAS` / `EDGE_BAND_WIDTH` 数值；固定带宽、以射程为基准的带几何；`getVisibilityAt`；混乱边缘抖动（jitter 改射程，dither 由多边形派生，天然跟随，不打架）。

## 处方 3：光池衰减曲线（改 `ensureLampTexture` / `ensureFlashlightTexture` stops + 手电椭圆拉伸）

**目标读法：** 光池有热核、有快速衰减、有长尾巴——「一盏快死的灯把黑暗推开一小圈」。手电前向锥读作**有方向的照亮**（光打在前方地上、沿轴向熄灭），不只是「前方被揭示」。暖光仍是裂隙唯一暖色（§2.3 规则 4 不破），`clipLightsToIsland` 陆地掩膜语义不动（暖色不得涂亮虚空）。

**曲线族：** 热核平台 + 快速中段衰减 + 长低尾巴（平方反比的读法；学 Darkwood 的光衰速度，不学其手绘打光）。

**暖光 stops（现状 → 处方）：**

| stop | 现状 alpha | 处方 alpha |
| ---- | ---------- | ---------- |
| 0.00 | 1.00 | 1.00 |
| 0.25 | —（线性段） | 0.90 |
| 0.50 | —（线性段） | 0.45 |
| 0.60 | 0.45 | — |
| 0.75 | —（线性段） | 0.18 |
| 1.00 | 0.00 | 0.00 |

读法：贴身 0.25 半径内是热核平台（玩家 = 点光源，不是圆盘），中段快速衰减，尾巴贴地伸长。手算能量 ≈ 现状 0.87×（ ∫a·r dr 0.157 vs 0.180 ），在平价带内（见下）。

**手电 stops（现状 → 处方）：**

| stop | 现状 alpha | 处方 alpha |
| ---- | ---------- | ---------- |
| 0.00 | 1.00 | 1.00 |
| 0.18 | — | 0.82 |
| 0.42 | — | 0.50 |
| 0.45 | 0.55 | — |
| 0.70 | — | 0.24 |
| 1.00 | 0.00 | 0.00 |

读法：热核更紧（光斑打在前方地上，76px 前推不动），中段衰减加快（锥内不再是均匀暖），尾巴保留（锥尖方向仍有将熄的暖，不是灰）。手算能量 ≈ 现状 0.87×（0.145 vs 0.167）。

**手电椭圆拉伸（实现层变换，非纹理、非常数）：** `drawFlashlight` 的 `setDisplaySize(d, d)` 改为长轴（沿朝向）= d × 1.15、短轴 = d × 0.87，image `rotation = facingAngle`。能量不变（同一张纹理），分布改：横向溢暖收紧（减少「玩家身边一团暖雾」），轴向延伸强化「打向前方」。这是「有方向的照亮」的主抓手；纹理 stops 是衰减读法，两者配套。抓手清单写的是「光池读法」的可动层——椭圆拉伸不改数值、不改规则、不改接线，属同一层；若派发方读为抓手仅限纹理，本项可独立延后，不阻塞 stops 落地。暖光保持圆形（环身 360° 本无方向）。

**平价闸门（机器可核）：** 光池纹理的 mean alpha 落在现状的 **0.85–1.05×**。现状基准：暖光 0.360、手电 0.333（a(r)=1−r）。带比噪点宽的理由：遮罩残余暗度（0 / 0.40 / 0.80）才是画面亮度的主项且不动，光池是 0.12 / 0.16 alpha 的 ADD 层，±15% 能量对最终像素亮度的影响在 1–2% 量级，而**形状**变化（热核 vs 平盘）恰是读法所在；能量向核心再分配，玩家视线所在的贴身区反而更亮。出带时统一缩放非 1.0 stops（纹理内部调整），**不调 `PLAYER_LAMP_ALPHA` / `FLASHLIGHT_ALPHA`**。

**净化点共用注意：** 暖光纹理同一份服务净化点（半强度）。形状变化在净化点同样成立（同一台设备）；人终审看裂隙，净化点顺带复核。

**不动：** 两个光池色值（warm-dim #8a5c2a / #a8906a）、alpha、前推与半径比例（`FLASHLIGHT_FORWARD_FRAC` / `FLASHLIGHT_RADIUS_FRAC`）、depth 49 接线、ADD 混合、陆地掩膜；薪柴不发光；不加任何新 glow source。
