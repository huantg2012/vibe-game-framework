## 悬在头顶的海

**原生与改写。** 原生海洋的迁徙与冲刷没有人类造物；覆盖后，相邻水层拥有不一致的下方。海床裸露，海的重量仍悬在极低的上空。

**第一眼。** 垂直的深海像低垂的天穹；大到看不全的腹影从头顶扫过。沙质海床与压扁的壳在脚边提供脆弱尺度。水柱向下伸出，却转向接回海里。

**局部可玩关系。** 水的下缘变厚→壳屑沿沉积槽滑动→一片水幕落到通路→逐渐回卷。低矮壳脊可以先观察；较长干露海脊保持普通绕路。短路尽头的可翻找沉积处于水幕扫过范围内。

**工具与边界。** 信息/误导应通过当地实体感知成立；现有气雾压制技能不自动获得控制海水的能力。玩家先学会等候和绕行，再设计明确的工具接点。F样板已实现水幕伸缩与正式承伤、稳定旁路及同种子对照；牵引、多层导航和完整世界循环尚未制作，图像不能代替它们。

**声音与运动。** 低而巨大的水压、远处壳体摩擦；大面积运动缓慢，危险下缘的加速可读。原生海水与异向回流构成视觉冲突，不用发光符文说明污染。

## 彼此托举的生命大陆

**原生与改写。** 没有固定地面。角质与纤维构成的庞大生命通过舒展、承重互相维系；覆盖使部分连接只能收紧。

**第一眼。** 远处整个地貌缓慢翻身，露出另一层群落。脚下是干燥柔韧、宽阔如山坡的鳍面，几道失去弹性的连接把它勒出不自然的锐折。

**局部可玩关系。** 连接纤维逐渐拉直→受力面抬高→接缝收窄→松动部位恢复。较长的根部路线稳定；近路跨过会被拉动的鳍面，能先躲进不受力的褶底观察。残留集聚在受力边缘，拿取时间和返程要一起考虑。

**工具与边界。** 本地实体应是承重生态中的残余结构或临时分离部分，不能简单塞入地球虫兽。移动支撑只需先做一个明确局部，确保可见移动与身体碰撞一致；不把呼吸贴图冒充活地形。

**声音与运动。** 干燥的低声伸张、纤维逐股崩开的细响；主体节律各异且相互牵动。避免血肉器官、统一脉动和长满眼睛的惯用符号。

## 被撑出厚度的世界

**原生与改写。** 原生事物生活在连续曲面内，依靠边缘和邻接关系存在。覆盖迫使薄面拥有体积，使原本相邻的位置被新增的内部隔开。

**第一眼。** 一个如裂线般窄的存在转向，展开成巨大的不透明面积。它的边缘被撑成空腔，像一个世界第一次露出了截面；周围曲面反折进深处，没有建筑或纸制品的尺度。

**局部可玩关系。** 边缘的细线出现双重轮廓→局部膨出→薄面转向扫占一块区域→收拢露出通路。褶缝提供稳定避让位；绕过面根可以保留退路。被挤出的层片形成一次性可翻找物。

**工具与边界。** 先把一次展开的占用范围、遮挡与安全侧做清楚。现有穿墙技能不能默认支持任意维度跳转；不增加随机瞬移、返还物品或重置死亡的隐含规则。

**声音与运动。** 极薄的擦声突然带上空腔共鸣；转向时从线到面的面积变化比持续发光更重要。材质偏干燥、哑光、带矿物般断面，避免折纸玩具、低面数科幻平台和漂浮HUD图形。
