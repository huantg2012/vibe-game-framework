## 1. 三部分到底哪里不一样（给人看）

人说得对：不是「有没有网页味」这一档了，是 **并排截图不像同一套输出**。说不清很正常——差别不在「好不好看」一句里，而在四件事各走各的：字怎么排、占多大、有没有屏的特效、颜色站在哪一侧。

先把三块（外加小地图）摊开。不是要强行合成一块屏，是要看清它们现在在喊三种不同的东西。

### 对照：现在各自在干什么

| | 主菜单 | 净化点大屏 | 裂隙角落读数 | 裂隙小地图 |
| --- | --- | --- | --- | --- |
| **它以为自己是** | 标题页上的大字 | 墙上那块磷光玻璃 | 贴在画面角上的状态条 | 通用游戏雷达 |
| **字** | Courier，标题 **28px** 加粗居中，「存续」两个大字；选项 16px，一行一个 | Courier **13px** 正文，标题很多是 **12px 暗字**；字印在玻璃上 | Courier **12px 标签 + 13px 数字**，左上两行条；薪柴右上 **14px 加粗** 带 ◇ | **没有字** |
| **占位** | 整屏空黑底，字浮在正中 | **680×468** 一块，放在画布 `top:52 left:140`，四周漏场景 | 四角：生命/混乱叠在左上，薪柴右上，工具左下 | 右下一块约 **192×132** 的小矩形（地图 64×44 格 × 每格 3px） |
| **特效** | 无扫描、无发暗、无玻璃 | **teal 扫描线** + 径向发暗（这块最像「一台旧屏」） | 无扫描、无玻璃；只有字后面 2px 黑晕（为了能读，不是屏） | 半透明 **0.85** + **1px 灰框**；无扫描 |
| **颜色** | 亮灰字 `#c8cdd4` / 暗灰字 `#8a8f96`（色板内）。底 `#0a0a0a` **不在色板** | 玻璃 `rgba(15,17,20,0.88)`；扫描用了污染色 teal `#1aad96` 的透明 | 字同样两档灰；混乱条 teal；生命条灰、低时红；薪柴暖橙。条槽是半透明黑，刻度是 **白**（白不在色板） | 底/地/墙已换成色板暗色；玩家暖橙圆、撤离近白青圆——**两个都是圆** |

一句话对照：

- **主菜单** = 黑底上的标题字。允许「我知道这是游戏外面」，所以没有玻璃。但它和后面两块的关系，目前只靠「也是 Courier、也是那两档灰」。选项还在说存档软件词（那是文案，本轮不改）。
- **净化点大屏** = 中间一块会发光的矩形。扫描线是 teal 的，发暗是从中心往角上黑。没有金属壳、没有 1px 线（这是人已经锁过的）。四周能看到混凝土地面，但矩形边缘是 **一刀切的硬边**——玻璃和房间之间没有「嵌进墙里」的那一圈暗。
- **裂隙读数** = 角落里的扁条和数字，直接印在战场上。没有玻璃、没有扫描。字和条都非常干净、锐、像调试用的 overlay。色谱其实是对的（混乱用污染 teal、薪柴用人类暖橙），看起来却不像随身装备，而像「游戏在屏幕上叠了一层 UI」。
- **小地图** = 见下一小节。它是人唯一能一锤定音的「不像」。

还有一个方向反了的地方，并排时很刺： **安全区的墙机扫描线是污染色 teal；裂隙里的随身读数反而完全没有屏的脏。** 美术方向写的是：净化点「干净 = 颜色缺席」，裂隙才是 teal 渗出来。本轮 **不要** 再给裂隙读数加 teal 扫描来「补脏」——那会把这条反着的色谱再加一档。裂隙只加 **暗的** 扫描（黑线），剂量低于墙机。

### 为什么小地图一眼就是「不像这个游戏」

不是「小地图这个功能不该有」。是它那几笔在喊 **别的类型游戏的雷达**，而且挂法还在喊网页。

具体是这几笔（都可以在 `minimap.ts` 里对上）：

1. **挂在浏览器上，不挂在游戏画布上。** `document.body` + `position:fixed`。窗口不是 960×640 时，它会贴在窗口右下角，和 letterbox 黑边、画布对不齐。看起来像网页右下角浮了一块 canvas，不是装备上的一块屏。架构已经点名这是债。
2. **1px `#2a2d32` 实线外框。** 这就是人已经否过的灰金属线，只是缩到了右下角。通用小地图的第一记号往往就是「一个带细框的小窗」。
3. **玩家和撤离都是圆点，只靠色分。** 圆点是 RTS / 许多 Roguelike 雷达的默认笔。这个世界的污染签名是 **矩形、网格对齐、数据错误**；圆被留来表达「面积光池」这类事，不该当通用 UI 点。转成灰度后两个圆更分不清。
4. **整块 85% 透明，压在世界上。** 像一层 UI 贴纸，不像一块装在设备上的小屏。
5. **没有这套游戏其它屏上的任何「机器语言」**：没有扫描、没有凹槽暗边、没有 Courier、没有和左上读数的亲属关系。
6. **深渊模式：敌人和薪柴节点同色同方形。** 连「两种东西」都没画出来，更像调试标记。

人「唯一能确定不像」，是因为小地图在用 **另一套图形词典**（细框小窗 + 同形圆点 + 浮在浏览器上），而另外三块至少还共用 Courier 和色板灰。

### 本轮要统一成什么关系（不是合成一块屏）

三块继续做三件不同的事，但改成 **同一族设备的三种用法**：

```
主菜单（元界面，还在世界外面）
  仍是空场大字，不加玻璃、不加扫描。
  跟墙机同字体、同两档字色；底色改成色板里的深黑。
  不学墙机的占位，也不学小地图的框。

净化点墙机（嵌在墙上的磷光屏）
  仍是 680×468 那块大玻璃。
  本轮只补「嵌墙」：凹槽暗边 + 更贴矩形的发暗。
  不加金属壳，不加 1px 灰线。

裂隙随身装置（同一族，更小、更暗、更脏一点）
  左上：状态读数，一块小玻璃，不是裸条。
  右下：小地图，同一块装置上的第二块屏，不是雷达窗。
  扫描只有暗线、比墙机弱、不用 teal。
  字必须仍能读（见第 3 节）。
```

暂停小窗、裂隙结算小窗：**保持居中小读出**（已锁，320 / 360，不要改成 680×468）。本轮只让它们吃墙机同一套玻璃语言（凹槽暗边变薄一档），不扩成整页大屏。

**学什么动作 / 明确不学什么**（从已锁五款里取，本轮用三款）：

| 游戏 | 本轮学的动作 | 明确不学 |
| ---- | ------------ | -------- |
| Signalis | 信息是设备读出来的；扫描线是旧屏的结构，不是装饰滤镜；层级靠亮度，不加新色相 | 显像管曲面畸变、家用圆角电视机 |
| FTL | 名和量贴在边上、随时能读；一块槽就是一件东西 | 全息蓝、圆形供电格、舰桥雷达圆点 |
| Barotrauma | 装置自己报状态（灯、槽、读数），不是系统对话框 | 仿真指针/阀门；整屏仪表 |

Darkest Dungeon / Into the Breach 本轮不当施工锚（词条三层编码、预告诚实是六块面板那一批的事）。

本轮明确不像：通用小地图雷达、网页 canvas 小窗、调试用 HP 条、**已被否的灰金属显示器框**。

## 2. 净化点大屏要不要边框

人的直觉：已经不像网页了，但要看上去像显示器，似乎缺一个显示器边框。

**判断：直觉对了一半。缺的不是「显示器的金属边框」，是「这块玻璃嵌在墙凹槽里」的边缘。**

- **不要** 加回灰金属面壳。
- **不要** 加 1px `#2a2d32` 外框（这就是已被否的方案，缩成细线交差也不行）。
- **不要** 圆角、不要投影、不要外发光。
- **要** 用本世界允许的材料做出「嵌在墙上的屏」：墙凹槽里的暗（void-black）、磷光玻璃在边缘发暗、扫描线贴齐这块矩形。

物理原因（答得出才留）：净化点墙是混凝土/金属，屏是嵌进去的一块旧玻璃。你看见的「边」是 **凹槽里的暗** 和 **玻璃自己变暗的边缘**，不是另外画的一圈金属装饰条。金属已经是墙本身，不必再描一圈。

硬切的矩形边（现在的 `border: none` 之后，玻璃和地面之间仍是刀切）才会让人觉得「缺框」——眼睛在找分离，找到的却不是嵌墙，而是浮层。补分离用凹槽，不用金属线。

### 用什么代替「金属框」

三件一起做，都挂在已有的 `.game-panel` 上，**不改 680×468、不改 `top:52px; left:140px`**（占位已锁）。

**① 凹槽暗边（墙洞，不是金属）**

在 `.game-panel` 的背景上叠四条向内淡出的暗边，色 **`#080a0c`（void-black）**，宽度 **8px**，由实到透明。不要 `border`，不要 `outline`，不要 `box-shadow`。

```css
.game-panel {
  /* 已有：无 border、无 radius、无 box-shadow */
  background-color: rgba(15, 17, 20, 0.88);
  background-image:
    linear-gradient(to bottom, #080a0c 0%, transparent 8px),
    linear-gradient(to top,    #080a0c 0%, transparent 8px),
    linear-gradient(to right,  #080a0c 0%, transparent 8px),
    linear-gradient(to left,   #080a0c 0%, transparent 8px);
  background-repeat: no-repeat;
  padding: 14px 16px 4px; /* 原 10px 12px 0，让字不要吃进 8px 暗边 */
}
```

**② 径向发暗加重、更贴矩形**

现有 `::before`：椭圆 78%×72%、透明度 0.4。边缘在角上仍偏亮，所以矩形外沿仍是硬切。

```css
.game-panel::before {
  background: radial-gradient(ellipse 86% 82% at 50% 46%, transparent 28%, #080a0c 100%);
  opacity: 0.58;
}
```

色仍是 `#080a0c`。不引入新色。不把透明度加到「字读不清」——正文仍是 `#8a8f96` / `#c8cdd4` 印在 `rgba(15,17,20,0.88)` 上，对比度规则不变。

**③ 扫描线：teal 剂量不准再加**

现有 `::after` 已是每 3px 一条 `rgba(26,173,150,0.08)` + `rgba(8,10,12,0.28)`。teal 已经进了净化点墙机，本轮 **保持 0.08，禁止上调**。只允许把暗线从 0.28 调到 **0.34**（玻璃纹，不是更绿）。扫描仍覆盖整块矩形（已是 `inset:0`），不要改成圆角扫描。

backdrop 仍透明。不要为了「更像显示器」加全屏暗罩。

### 暂停小窗、裂隙结算小窗

已锁：居中小读出，不铺 680×468。

- `pause-menu-panel` 仍 **320px** 宽、垂直水平居中。
- `#rift-result-panel` 仍 **360px** 宽、垂直水平居中。
- 它们已经是 `.game-panel`，会自动吃到扫描和发暗。凹槽暗边对小窗改成 **5px**（不要 8px，否则吃内容）：

```css
.game-panel.pause-menu-panel,
#rift-result-panel.game-panel {
  background-image:
    linear-gradient(to bottom, #080a0c 0%, transparent 5px),
    linear-gradient(to top,    #080a0c 0%, transparent 5px),
    linear-gradient(to right,  #080a0c 0%, transparent 5px),
    linear-gradient(to left,   #080a0c 0%, transparent 5px);
  padding: 12px 14px 8px;
}
```

不要给这两块加金属框、不要改成贴边、不要改成整页。

## 3. 裂隙读数「太清晰」

人确认 **能看清**，但嫌太干净。硬门槛仍在：DOM 字 **≥12px**，正文对比度 **≥4.5:1**。**不许**用变糊、降到 12px 以下、或把字改成 `#5a5f66` 来换氛围。

「太清晰」的具体来源（不是字号太大）：

- 条和字直接印在战场上，没有「一块小玻璃」
- 条槽是 `rgba(0,0,0,0.4)` + 几乎看不见的 `#0f1114` 边，读成网页进度条
- 混乱刻度用了 **白色**（不在色板，也是最「调试器」的一笔）
- 薪柴 **14px 加粗**（字号档外）+ ◇，比标签更像 HUD 贴纸
- 零扫描、零脏，墙机却有 teal 扫描——随身装置比据点墙机更像软件

### 选这四件（不堆）

**A. 左上状态进一块小玻璃（随身装置的读出面）**

把生命行 + 混乱行 + 档位行包进 `#rift-hud-status`。不是 `.game-panel`（那会变成 680×468）。新类 **`.device-plate`** 写在 `panel-styles.ts`，右下小地图共用。

```css
.device-plate {
  position: absolute;
  background: rgba(15, 17, 20, 0.72);
  border: none;
  border-radius: 0;
  box-shadow: none;
  padding: 6px 8px;
  pointer-events: none;
}
.device-plate::after {
  content: "";
  position: absolute;
  inset: 0;
  pointer-events: none;
  background: repeating-linear-gradient(
    to bottom,
    transparent 0px,
    transparent 2px,
    rgba(8, 10, 12, 0.14) 2px,
    rgba(8, 10, 12, 0.14) 3px
  );
  z-index: 0;
}
```

- 扫描 **只有暗线**，没有 teal。墙机 teal 是 0.08；这里暗线 0.14，低于墙机那条暗线 0.28/0.34。
- 玻璃 0.72，比墙机 0.88 更透——随身罩比墙机薄。
- 禁止 1px `#2a2d32` 外框。凹槽暗边 **不要** 做在这块小读数上（太小会像卡片）。

占位（逻辑 960×640）：`left:12px; top:12px;` 包住现有生命/混乱/档位。生效中状态行仍在这块板下方或板内底部，不另开第二块板。

**B. 标签略暗于数值（已经对，保持；不要再暗）**

- 标签（「完整度」「混乱」）：**12px**，`#8a8f96`
- 数值（`42/60`、混乱整数）：**13px**，`#c8cdd4`
- 低生命 / 混乱溢出：数值改 `#cc3333`，标签仍 `#8a8f96`（危险靠数字和第二编码，不靠把标签也染红到发糊）
- `text-shadow: 0 0 2px rgba(0,0,0,0.8)` **保留**（可读性暗晕，不是装饰发光）
- 禁止标签改 `#5a5f66`，禁止 `<12px`

「完整度」三字：标签槽 **`min-width:56px`**（现 32px 是给 `HP` 两个字母的）。**不要缩写成 HP / 完 / 度。** 用词由 code 改；本规格只管字号、色、不缩写。

**C. 条槽更深，刻度离开白色**

生命条、混乱条共用：

| 项 | 现 | 改成 |
| -- | -- | -- |
| 槽底 | `rgba(0,0,0,0.4)` | `#080a0c` |
| 槽唇 | `1px solid #0f1114` | `1px solid #151a1e`（阴影灰，装饰槽，不是金属外框） |
| 条高 | 6px | **保持 6px** |
| 生命宽 | 75px | 保持 |
| 混乱宽 | 135px | 保持 |
| 生命填充 | `#8a8f96`；&lt;25% `#cc3333` 脉动 | 保持 |
| 混乱填充 | `#1aad96`；溢出段 `#2ae6c8` | 保持 |
| 刻度 50/75 | `rgba(255,255,255,0.3)` | `#5a5f66`，1px |
| 刻度 100（门） | `rgba(255,255,255,0.75)` 且 2px | `#8a8f96`，2px |

槽唇用 `#151a1e` 不是 `#2a2d32`：后者是已被否的灰金属线同色，条上细线也容易读成「小金属框」。

**D. 薪柴右上：降回字号档，去掉 ◇ 贴纸感**

- 表名「薪柴」**12px** `#8a8f96` + 数字 **13px** `#c4873a`（与净化点右上同一套名/量，不再 14px、不再 ◇）
- 位置仍 `right:12px; top:12px`
- 不套第二块 `.device-plate`（右上只是一个数；再加一块玻璃会变成两张卡片）

工具行（左下）、撤离提示（底中）：本轮不动字号/色。撤离提示保持裸字，走近才出现，不是常驻屏。

临界脉动（生命&lt;25%、混乱溢出）保持现有 300ms、alpha 0.6–1.0。物理原因仍是装置告警，不加新发光。

## 4. 小地图——本轮必须落地

现状：`minimap.ts` 挂 `document.body`，`position:fixed; bottom:8px; right:8px`，`1px solid #2a2d32`，每格 3px 的地/墙色块，玩家/撤离同为半径 2px 的圆，深渊敌人和节点同色同方。

### 挂载与占位（逻辑 960×640）

- 挂 **`#dom-ui-root`**（`getDomUiRoot()`），禁止 `document.body`。
- 外层 `#rift-minimap`，`class="device-plate"`（与左上读数同族）。
- `position:absolute; right:12px; bottom:12px; z-index:1000; pointer-events:none;`
- 内层仍是 canvas，`border:none`；canvas 尺寸 = `mapWidth * 3` × `mapHeight * 3`（现图 64×44 → **192×132**）。每格仍 3px，不改玩法、不改迷雾规则。
- 板的 padding **4px**（小屏用薄一点的玻璃边，不是 8px 墙凹槽）。
- 整块不设 `opacity:0.85`。透明走玻璃底 `rgba(15,17,20,0.72)`；canvas 本身不透明。
- `image-rendering:pixelated` 保持。
