# 迭代 17：人形残余

本次是独立程序像素样板。方向依据人的本轮授权和世界设定中“污染改写运作关系”的含义建立；不引用已有审美 skill、旧角色模型、旧模型 HOW 或历史审美结论。已显式读取 `.cursor/agents/art.md`，本次独立建模和直接生成程序像素以人的授权为准。

## 形体与污染递进

核心动作是“被错位承重的人”。低档仍有人的前倾姿态；中档保留同一具身体的大部分基底，但各段身体开始服从不同动作关系；高档的承重躯块取代人形，只剩少量曾经是人的证据。

- **低污染**：双腿承重，胸向前移 5px、头向前移 8px；右肩低于左肩 3px，右手垂得更低。脸是被抹平的窄面，只留一条凹缝。胸部只有一处斜向暗接缝，没有眼牙、伤口、装备、盔甲或武器。
- **中污染（R2）**：保留双腿与头部，但骨盆向右、胸肩大幅向左前方错位，头又偏回另一侧，形成偏斜的承重链。高低肩差增大，一只手垂近脚踝，另一只停在腰侧。异质肩胸实体环绕背部，旧背部只剩一条错层连接，使四向都能从轮廓而非仅颜色区分低档；步行动作仍按不同摆臂相位推进。
- **高污染**：移除独立头部和右侧自由臂；右半躯体向下延伸成着地重块，只余一根可辨腿、左侧拖垂长臂。脸片嵌在偏斜胸块侧前方，另一只掌嵌在躯体中段。没有成对的脚、正常头肩线或腰部收束。步行由残腿、拖臂和整体承重起伏呈现。

三档均用同一组干燥、厚实的材质。异常面不发光，不加触手、虫壳、眼球或随机裂纹。细节只落在脸缝、胸接缝、手掌与承重结构上。

## 技术合同

生产实现：`src/entities/form-renderers/d/human-model.ts`。

`bakeHumanModel({ seed, coverage, facing4, phase, phase01 })` 返回 `{ buf: PaintBuf, canvas: GenomeCanvas }`。

- 画布 64×64；原点 `(32, 42)`；`offsetX / offsetY = 0`；collision 为 20。
- `HumanPhase` 为 `idle | walk | alert | windup | strike | recover`。
- 每个顶点先在地面 X/Y 与高度 Z 中建模，再按上、下、左、右投影；高度不随朝向转动。逐像素深度缓冲决定遮挡，不旋转成品图。
- 无透明边、柔化、抗锯齿或随机噪声。面光照量化到四档；全套扫描实际使用 18 个不透明 RGB 值。
- 入参进度限制在 0–1；非有限值归零。随机种子只控制固定形体细微偏差，不参与逐帧随机取样。
- 画布外顶点触发异常，禁止静默裁切。生产渲染器承担脚下投影，本模型不内烤投影。

## 六相动作

- **待机**：一次周期内约 0.45px 的胸头起伏，脚保持接地；首尾完全一致。
- **走路**：960ms 周期；双脚反相，抬脚 2.2px，躯干有承重起伏与微量前后位移。中档手臂脱离正常反相规律，高档只保留单腿推进与拖臂。
- **警觉**：头部向面对方向探出，仍保持脚底注册点；不靠光效提示。
- **预备**：350ms，下沉 2.5px，胸后收 2px，手向后蓄势。
- **攻击**：80ms；`phase01 = 0` 立即为最大前压姿态，对齐伤害发生时刻。胸前移 9px，攻击手额外前伸；到末帧收至 80%。
- **收势**：240ms；从 80% 前伸平滑回零，与攻击末端及静止起点逐像素一致。

动作时钟由运行时传入。本文件只表达形体，不修改 AI、伤害、距离或平衡参数。
