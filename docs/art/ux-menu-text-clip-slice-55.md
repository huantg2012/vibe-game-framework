# 主菜单字上沿裁切（Slice 5.5 热修）

## 1. 结论

**这是 bug，不是设计。裁切不是故障审美 / 扫描 / CRT 吃字。**

截图（人带回）：标题「存续」、副标题「界/尚/熄」、选项「沿/返/新/录」等每一行最上沿被切平。对照实现：

- `docs/art/ux-visual-pass-slice-55.md` 已锁：主菜单 = 空场大字，**不加玻璃、不加扫描、不加框**。裁切不在该语言里。
- `src/scenes/main-menu-scene.ts`：全部 Phaser `Text`，Courier New，`setOrigin(0.5)`（摘要行 origin x=0），**没有** `setPadding` / style `padding`。
- `src/config/game-config.ts`：`pixelArt: true`、`roundPixels: true`、`antialias: false`。Courier New 的 canvas 度量按拉丁 ascent；CJK 上沿超出度量 → 纹理顶被切。全屏每一行上沿同病，与截图一致。
- Kit §A5-1 选中 `▸` / 未选中 `>` 是已有语言，**不是**裁切原因。

禁止把裁切收成「低保真 / 故障 / 显像管吃字」。那是发明新审美。

## 2. 载体仍 C；不加玻璃/扫描/框

- **载体：C 元界面。** 玩家尚未进入叙事空间。本屏允许「这是标题页」，不允许做成净化点墙机。
- **不要**改成 DEC-049 的 680×468 磷光屏（无金属无 1px 外框那块）。墙机语言不进主菜单。
- **不要**加玻璃、扫描线、外框、凹槽、径向发暗。
- Overlay 根（`#dom-ui-root`）**不适用于**本屏：字画在 Phaser 画布上，主菜单 camera zoom = 1，不是角锚 HUD。禁止为修字改挂 DOM。

参考锚点（本屏已锁，不新选）：

| 游戏 | 本屏锚的动作 | 明确不学 |
| ---- | ------------ | -------- |
| Signalis | 标题页的空：黑底上几个字，没有屏壳 | 显像管曲面、扫描吃字、家用圆角电视 |
| FTL | 层级靠亮度两档灰，不加新色相 | 全息蓝、舰桥窗 |
| Barotrauma | 选项是装置行（`>` / `▸`），不是网页按钮 | 仿真仪表、CRT 滤镜当标题页 |

本屏不像：设置页、确认对话框链、墙机磷光玻璃。

「哪台机器」：世界外标题字（Courier New，两档灰），不是任何一块屏打出来的。padding 只为字形完整，没有物理装饰原因——它是度量修正，不是材质。

## 3. 禁止动全局像素设置

**禁止**为修字关掉或改写全局 `pixelArt` / `roundPixels` / `antialias` / `antialiasGL`。裂隙像素地砖依赖这套。

只修：

1. `src/scenes/main-menu-scene.ts` 里**每一个** Phaser `Text`
2. `src/scenes/boot-scene.ts` 的「载入」那一行（同源：Phaser `Text`、origin 0.5、无 padding、吃同一套 canvas 度量）

不要用 CSS。不要给 DOM 面板加 padding 冒充修这个 bug。

## 4. Padding 表（code 可执行）

Phaser：每个相关 `Text` 在创建后立刻

```
setPadding({ top, right, bottom, left })
```

或 style 等价 `padding: { top, right, bottom, left }`。只加 **top**。左右/底 = 0。

| 字号 | 出现处 | top | right | bottom | left |
| ---- | ------ | --- | ----- | ------ | ---- |
| 28px | 主菜单标题「存续」 | **6** | 0 | 0 | 0 |
| 16px | 主菜单选项行；摘要数值；boot「载入」 | **4** | 0 | 0 | 0 |
| 13px | 主菜单副标题；摘要标签 / extra；覆盖警告 | **4** | 0 | 0 | 0 |

理由：CJK ascent 超出 Courier 度量，缺的是纹理顶，不是左右/底。4 / 6 是整数 px 起点（13/16 → 4；28 标题 → 6）。origin 0.5 时字形视觉中心会下移 `top/2` px——本轮接受，**不要**为补偿改行距或组间距（那是问题 2，下一轮）。

`setText` 之后 padding 仍留在 GameObject 上，选项刷新不用重设。摘要行 origin x=0 同样只加 top。

落地后验收：逻辑 960×640 主菜单一帧，每一行 CJK 最上沿完整（横笔不被切平）。boot「载入」同检。人否决剂量再改整数，禁止改成扫描/故障。
