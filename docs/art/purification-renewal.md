# 净化点：有纵深的封闭错层遗存

## 当前合同与依据

DEC-180：用户否决c3b1d9f灰钢双层舱；R2原位替换。旧版核心开腔、深收容体、人体液缸、供奉立环和地面伤口的功能身份值得保留；旧膜蛋、轨道式陈列及其同色机柜不作新基准。当前源为`purification-chamber-pixels.ts`与`purification-chamber-visual.ts`，实际几何单源为`purification-chamber-layout.ts`。

## 本质、相机与尺度

场所是持续被外来规则压迫、有人维护的封闭遗存，不编造原设施职业或新防御机制。厚墙、夹层、基座与两条宽坡道构成可走空间，外部不可走；镜头侧遮蔽物的剖切属于展示约定。排除泡膜、露天平台、等距展架和把墙上附属件画成可操作终端。

固定640×400世界画布与960×640逻辑视口、常态zoom1.5，保持原人物大小。画面稍俯看，有顶面/侧面/墙厚度；足点已投影，不再次按高程移动。地面实际有深度，原四向人物可以八向绕行。人物、五立体装置分别按脚底排序，入口绘在地面。人被高设备遮住时，仅遮挡设备局部淡出、退出后恢复；原人物不隐身也不换皮。

## 六种物件的因果链

- **核心**：维持用的受控活性腔 → 细高的开放内腔、上下约束与基础 → 自制压脚/不对称修补把活质限制在腔内。排除普通电箱、橙火壁炉和可穿过的门。
- **储藏**：深收容与留存 → 有厚度的容积、封口和束箍 → 混凝土土座、回收箍件与小功能灯。排除抽屉工具柜和按假库存摆满的散物。
- **净化器**：踏入前剥离外来渗透 → 低宽的可见介质腔与分隔结构 → 固定于出击侧并朝裂隙安装。排除百叶柜、玩家必须操作的净化门禁。
- **培养藏**：身体进入并发生蜕变 → 人体尺度圆柱液缸 → 粗箍、窄液柱、内部活动与使用痕迹。排除座椅、售货机及新的主角外观。
- **供奉**：收容、控制、暴露同时成立 → 保留贯通负形的承压立环、夹持内物 → 依附有承载依据的外压侧构件。排除实心钳床、香炉/祭坛；匿名介质不揭隐藏身份。
- **裂隙**：时空伤口而非出口门 → 地面放射击裂与错位断口 → 内腔异常青绿与受损原材料。排除竖门框或通往壳外的普通走廊。

物件可以有多种成立剪影；R2选择恢复已有可辨身份，并统一适配当前角度，不把程序上容易画的方盒当作本质。底座是实体，操作点与机体分开；脚下留能站/绕行的空间。

## 材料、构图与外部

### R3施工锁与验收问题

本质是**有厚度且仍在被维护的围护结构**。成立范围包括实体台基、梁柱托板、夹层壳壁；当前沿R2实体错层台基处理，排除无支撑悬板、膜和金属舱。立面竖立、地坪及坡道躺于既有投影平面，相机与640×400像素画布保持。六物脚底、三缝锚、可走面及碰撞不变。

- **谁造/用什么/工艺**：沿世界观，维护者用可得的混凝土、旧灰泥和回收夹件修补，施工接缝允许不整齐；补层覆盖旧断口，夹件必须落在实体上。
- **维护状态/光/颜色**：有磨耗但道路可用，主要细节聚在接触、断面与修补；局部灯与受控介质承担微光，不另造舞台顶光。世界观DEC-180允许原材灰褐与冷灰区分，不把灰度低饱锁为净化点目标。
- **参考动作**：沿用户已选《死亡细胞》的浅透视厚墙/楼板体积；学《Rain World》的承载、接缝与维修痕迹如何连成环境；学本作R2核心的面色与内腔分离。不移植跳跃、侧卷视角、明亮城堡皮肤或满屏环境杂物。
- **色板与底**：只取`palette.json`现有格；同R2地坪上检视六物。没有新色、没有程序色板外混色；动态反光由场景层另行登记。
- **可核对问题**：上下水平面与垂直面至少两档结构明度；墙根有连续接触暗部，坡道两端不断开；地坪至少覆盖层/原层/磨耗三种作用，主要裂缝不描成均匀方格；外部每个主残体至少有可见断面和负形内腔；三处外压线必须能追到原抵抗锚，受控缝不连成整圈霓虹。截图和像素分析记录实值，不能用这些条件代签审美。

建筑大块用哑混凝土与旧灰泥；当前按用户指定的旧净化点基调，用冷灰原材/涂层/断面与少量锈铜接合分工。该局部配色选择不反向约束Rift世界空间。金属只承担箍、夹、连接、剥离腔等实际用途。地面保留静区，磨损/骨料/剥落集中于修补、承重、踩踏与破口，避免均匀撒噪点。像素簇有粗细层级，不用长边全描亮制造钢板感。

### 暖色收敛：建筑专用色槽

`building`只分配建筑表面的现有色板格：主地坪/裸底`#2c2e33`，上层涂层/壳体断面`#3a3d42`，侧返面沿`#1e2228`；`#4a4e55`仅用于既有金属及极少窄断口。大面积`#50463c`壳边与修补块被移除，少量回收夹件、沟盖及原功能灯保留材质色。中央双坡间主/侧面仍与主地坪拉开一档。几何、剥落形状、材质分层、外部残构和全局`CHAMBER_PALETTE`不改，六设备与角色不被建筑调色连带影响。

最短像素核：载体、相机、面色外沿及层级保持；直接按建筑材质槽换色，未使用全屏滤镜或增加反光。源码22个RGB全部在既有39格色板内；六物/状态/抵抗绘制、外部残构与共享色板较`42894d7`逐字一致。正式正常/受损实帧及人审另记，不用静态核查代签色彩通过。

前缘、台面、垂直挡面、坡道踏面和落脚必须连续可读；两层高度不只靠一条描线。墙面补片须跨越接缝、有覆盖关系，不能形成假门。少量巨大外部残构以厚断面、凹腔和黑色间隙建立质量与距离；被另一套规则截断/重复错位，不能只是绕房间的暗色纸带。

主要外压来自西侧基础与东侧壳体；背部接缝作为次级渗透。接触处有外部改写、内侧约束与修补止口的关系。当前模块损伤可以延伸裂缝/活层，健康时局部受控；不把每条边都涂成发光轮廓，不生成隐藏下次冲击的方向暗号。
