# 净化点：有纵深的封闭错层遗存

## 当前合同与依据

## 本质、相机与尺度

场所是持续被外来规则压迫、有人维护的封闭遗存，不编造原设施职业或新防御机制。厚墙、夹层、基座与两条宽坡道构成可走空间，外部不可走；镜头侧遮蔽物的剖切属于展示约定。排除泡膜、露天平台、等距展架和把墙上附属件画成可操作终端。

固定640×400世界画布与960×640逻辑视口、常态zoom1.5，保持原人物大小。画面稍俯看，有顶面/侧面/墙厚度；足点已投影，不再次按高程移动。地面实际有深度，原四向人物可以八向绕行。人物、五立体装置分别按脚底排序，入口绘在地面。人被高设备遮住时，仅遮挡设备局部淡出、退出后恢复；原人物不隐身也不换皮。

## 六种物件的因果链

- **核心**：维持用的受控活性腔 → 细高的开放内腔、上下约束与基础 → 自制压脚/不对称修补把活质限制在腔内。排除普通电箱、橙火壁炉和可穿过的门。
- **储藏**：深收容与留存 → 有厚度的容积、封口和束箍 → 混凝土土座、回收箍件与小功能灯。排除抽屉工具柜和按假库存摆满的散物。
- **净化器**：踏入前剥离外来渗透 → 低宽的可见介质腔与分隔结构 → 固定于出击侧并朝裂隙安装。排除百叶柜、玩家必须操作的净化门禁。
- **培养藏**：身体进入并发生蜕变 → 人体尺度圆柱液缸 → 粗箍、窄液柱、内部活动与使用痕迹。排除座椅、售货机及新的主角外观。
- **供奉**：收容、控制、暴露同时成立 → 保留贯通负形的承压立环、夹持内物 → 依附有承载依据的外压侧构件。排除实心钳床、香炉/祭坛；匿名介质不揭隐藏身份。
- **裂隙**：时空伤口而非出口门 → 地面放射击裂与错位断口 → 内腔异常青绿与受损原材料。排除竖门框或通往壳外的普通走廊。

物件可以有多种成立剪影；R2选择恢复已有可辨身份，并统一适配当前角度，不把程序上容易画的方盒当作本质。底座是实体，操作点与机体分开；脚下留能站/绕行的空间。

### R5 表面作者合同与自检

`ChamberPixels(ctx, surfaces?)`在原颜色填充处同步标面，`translate`同步局部像素与世界高程；单台透明图仍按原足点绘制。`setPlane(null)`停止标面并保留宿主，不能清除已有面。`block`分别标前/顶/右面并恢复原面；仅其真实新增实体（例如已购压脚）允许覆盖。固定轮廓、原角色与六物的绘制内容保持；受本轮追加要求，双坡每坡六条全宽亮横条收为两条短磨耗，楼板前缘三段亮条缩短变薄，原接触暗部仍在。两种构造入口的颜色输出应一致，不保留“仅开启新照明才换画”的分支。

主地坪高度0，上层32；两坡跨宽度等高、沿下降方向32→0。按`worldY = screenY + Z`变换坡面导数，法线用`(-riseX,-riseY,1+riseY)`归一化。左坡约`(0,0.955,0.298)`，右坡约`(0,0.936,0.351)`，上端的顶分量不是0；现有投影对应较陡实体坡，不将视觉宽坡误写成竖直断面。设备内腔按`baseZ−localY`赋高程，上层的培养藏/供奉以32为底；黑腔与发光色由最终像素在接光阶段排除。墙脚、帽檐底面、凹腔与断面的遮蔽系数是美术指定的局部可见度，不宣称几何光追结果。

1. **因果链与载体**：围护/承重是本质；实体台基属于成立范围，梁柱托板/夹层也可能成立，本轮沿既有台基而未替人改空间。墙竖立，地坪和坡道在原投影面，接触阴影由已有墙脚/楼板产生。
2. **实际底与剪影**：在正式净化点640×400缓存层绘制，不另造对比课皮肤；不动原六物身份或相机。已亲看首轮正式正常镜头与上层镜头，接受“材料场迷彩、墙根黑带粗”的复核并作一次针对性修正；随后亲看[最终正常镜头](../qa/artifacts/iteration-30-r3/presentation/normal/01-main.png)，地坪迷彩已消退，水平/垂直面更可分。后壁大形仍偏简化，外部远残构仍偏图形化；不把这些局部改善写成精致成品验收。完整运行与读数复验由根代理补录。
3. **外沿**：主要轮廓直接由灰泥、混凝土与外部残构的面填到边缘；没有围建筑加第三色整圈描边。接触深线仅用于凹缝、墙脚、断口或受压内腔。实体外沿统计的原32像素物件阈值不冒充整幅建筑验收。
4. **平色**：地坪取消首轮全域三档材料场，回到有明确受光关系的施工面、窄交界损耗；墙/断面/残体的材质极值收窄，避免同频大块迷彩。结构明暗先于纹理，非均匀随机散点。是否仍显单薄由最终正式截图与用户判断。
5. **静/活层**：建筑材料只烤一次；六装置主体、投资配件、细部函数与基线逐字一致。没有结构呼吸或摆动。
6. **色板**：源码22个RGB全部在39格色板内，无新增格；没有把历史角色色复制过来。外部污染侧只取冷灰和既有青绿，灰褐原材只在室内建筑；暖光仍取原功能灯。
7. **相机与落地**：沿R2浅透视，无GameObject旋转，无新增等距菱形。前切面不高于原合法脚底轮廓，坡道使用同一控制器多边形。
8. **未涉及类别**：未做薪柴容器、像素抽卡或新物件剪影，因此相应壳内容/跨卡指纹检查不适用；已有设备保持。
