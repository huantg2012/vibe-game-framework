# 净化点：有纵深的封闭错层遗存

## 当前合同与依据

本文件描述R9偏置据点与集中外景。用户已明确否决R8整景；先认可静态稿的偏置布景与分层，再授权实施。概念图的画风、渲染与人物比例不可照搬。此前80/75/50分及R8内部积极评语均不构成本轮人审通过。

方案依据：[当前整体方案](../design-notes/purification-scene-art-plan.md)。生产源为 `assets/source/purification-r9/{interior,exterior,schema,environment}.ts`、`chamber-authored-architecture.ts`及既有设备/活动绘制；实际通行单源为`purification-chamber-layout.ts`。

## 本质、相机与尺度

场所是持续被外来规则压迫、有人维护的封闭遗存。厚墙、夹层、支承和两条宽坡道围出可工作的空地；外部不可走。镜头省略朝观察者的遮蔽面属于展示约定，不代表露天。没有新增宗教、设施职业、外部探索或防御机制。

固定640×400世界画布、960×640逻辑视口、常态zoom1.5，沿原浅透视与像素尺度。角色仍为原模型，屏幕八向面内移动、原四向人物帧。主层0、上层32，两坡连续连接；脚底坐标已投影，不再次按高程挪动。设备按底座Y排序，地面裂隙低于人物。人物被设备遮挡时只淡设备，不隐去人物。

核心仍在主层，底座 **(141,305)**、操作点 **(175,320)**。本轮压缩空地并整体左置，几何地坪面积由56928减为33620世界像素²；人物和六物原尺度不变。新壳最高点在足点上91px，UI/遮挡保守包围盒为 `[-30,-92,32,3]`，底座碰撞仍34×20。以体量、深暗内腔、约束件、独立暗龛背景和工作面建立主次，不让玩家为构图多绕路。

## 建筑大形与材料

后墙为宽窄、高低不等的承重墙肩；东墙成段剪切、旋偏并保留下部封闭面；前沿是向下展开的厚楼板、基础和支承。断裂服从各自构造，不沿整圈打缺口。可行走面、两坡及操作点按R9几何重排，绘制性裂口不新增通道；后承托227/151与右基础394/273实体延伸进壳外。

完整形体以具名面保存在 `environment.ts`，包含 architecture / floor / foreground 与外景 far / middle / near。色图与表面方向、高程同源；静态一次栅格化。`tools/art-pipeline/purification-chamber.ts`导出分层像素SVG、结构SVG、albedo / baked / normals / height PNG与表面清单，便于低成本复核。结构SVG只表达面，不冒充最终材质像素。

材料使用不同倾向的矿物灰、灰蓝涂层、暗紫背面，有限哑光石灰与赭褐粘结层；金属功能件更硬，玻璃/介质反光更窄。沿用DEC-180允许材料色扩展，旧“只用22格”不再约束这套专用资产。中尺度铺砌/层积/接合承担精度，底层仅有限5阶连续色簇，取消逐像素颗粒；细色不伪造高度；工作地坪留可转身的静区，不用满地碎点填复杂度。暖材料不发光，异常青绿留在受控腔或真实接触缝。

参考吸收《死亡细胞》的视觉职责、可控面光与关键姿势，《风来之国》的自然结构分层；外部与动作研究另见R8方案，不移植其城堡、城市或信仰图案。项目历史技能用于兼容检查，不充当创作上限。

## 六件装置及其活动

- **核心：收束—承力—归稳。** 两侧不等高重壳约束连通活腔；壳体没有永久烘焙的最亮活质，主体姿态与投光共用 `sampleCoreMotion`。6.2/7.4/5.6秒三个不同长度的周期包含停顿；108秒内三个间隔30–42秒的局部轻颤窗口。真实修复1.68秒依次闭合、聚集、归稳；重复事件替换表现，不排队或锁玩法。主焦点仍由整景实帧确认。
- **储藏：封住—沉降。** 厚容积、封口和束箍；口部压片偶尔小幅落定。只表现已有完整度和修复，不画假库存数量。
- **净化器：摄入—分离—回流。** 低宽介质腔与分隔结构，左右介质先后转移，当前损伤可滞留。次光取同一活动帧；实际修复才有强化，不虚构正在处理一次出击。
- **培养藏：悬浮—传递。** 人体尺度液缸，深部轮廓轻微偏移、气泡分组错相；次光同源。既有成长成功才强化介质传递，不替换玩家模型。
- **供奉：受压—锁合—释放。** 贯通负形的承压立环，空槽只有夹具微动，有供物才有匿名介质。新增供奉读取成功提交的库存变化，成熟释放读取实际持久化后的转化结果；完成时退夹具与少量匿名残流，不继续画已回库的物件。占槽比例不是充能、身份或成熟进度。
- **裂隙：沿缝渗行—错位—退回。** 地面伤口；9条不等向主裂、5条从属分叉与1段不闭合连接，中心仅少量深格，末端渐浅渐窄，单侧碎口与少数翻片。亮段只在有实际裂岸支撑的缝中行进，不绘竖门、星形大洞、光圈或壳外去向。

六物活层为6张局部裁切图集：核心36帧、供奉32帧，其余各24帧；合计630,784像素，RGBA约2.41MiB，GPU与canvas各一份时约4.82MiB，不含驱动开销。普通更新只换帧，不逐80ms上传六张全世界图。公开健康档位、供奉空/有物变更才重建对应图集。视效确定性采样不消费玩法随机数；实例销毁幂等移除纹理与对象。

## 光、表面与外景

固定方向烘焙负责厚度、凹腔与接触；局部动态源负责正在发生的事。颜色填充处同步写法线、高程、遮蔽、粗糙度，`setPlane(null)`表示继承宿主。投影约定 `X=x, Y=y+height, Z=height`；这是作者面驱动的有限2.5D照明，不声称闭合3D模型或光追。

核心源在 **(141,246)、Z59**，活腔和主光同源；培养藏与净化器次光跟随各自活动帧，壁灯独立。动态面光按80ms重放已编译扫描段，人物原灯仍在POST_UPDATE后同步。效能与活动使用 `min(1,hp/100)`；100/100→100/115不能变暗或伪装受损，容量空余仅由读数表达。

外景主要集中在右侧：近层厚断芯遮住中层的横跨支承与折面，远层较小构造从深隙露出；背承托和基础连回室内。三层深度−50/−55/−60，相机跟随率1/.52/.12；只有真实相机平移产生视差，不自动漂成壁纸。近处冷面光、沿缝输运和少量碎屑共享接触节奏，粒子只在已有受光实体附近显露；取消悬空移动的中层遮暗贴片，远层不铺亮点。没有普通天空或云。

系统减少动态偏好下，主体保留稳态、无偶发颤动，次光稳定，外部输运/碎屑停止；真实成功仍可有一次低幅柔和亮度结果提示。Esc暂停冻结现有场景；三个重入检查不等于长期无泄漏认证。

## 完整度读数

只给核心、储藏、净化器三件原模块；观测资格与E操作资格分离。最近距离取脚底到实际底座轮廓，进入44px、退出58px、候选稳定120ms；可见性用同源建筑/前沿作者面的视线检测，不能凭楼层标签或足部可走资格裁掉可见机体，也不能透墙。E仍受原同层、24px操作点与直达资格约束。

单一读数拥有者优先当前操作、其次保留可观察对象、再选最近候选。淡入160ms，离开后保留250ms再淡出180ms；必要换边60ms淡出、原地切侧、140ms淡入，不横穿人物。实际遮人立即隐藏，安全侧稳定后再出现。世界条与聚焦DOM共用生命周期，不双显；世界条在角色POST_UPDATE后避让，DOM在game PRE_RENDER按同帧镜头投影。

状态使用固定100基准：hp≥100稳定、25≤hp<100受损、0<hp<25危险、hp=0失效；条长才使用hp/maxHp。灰青瓷色 `#9eaaa8`、赭金 `#bf965b`、铁锈红 `#bd685e` 与状态字/形状同义；0HP世界规仍有危险端帽，聚焦读数显示“失效”。人物/持具/灯、其他设备、视口与操作列均参与避让。尺寸、排字、颜色、状态机唯一细则见[UI Kit的I30 R8节](../design-notes/ui-art-overhaul.md)。
