# R100：实体表面与可走地面的材质分工

日期：2026-10-03。关联 COH-F052 / F049 / F007。用户在 b5dd6cdd 后反馈：「好一些了，不过纹理、材质还是和地面太接近，我觉得你需要找个更彻底一点的方案。」本文件集中记录这次画法选择，现行渲染合同仍归地图生成 spec。

## 为什么上次仍然不够

真实断面改善了边界，但实体与地面仍从同一张碎屑地表母片取样，且粗糙度近似；坐标分离不能改变材料的组织。结果仍像被抬起来的地板。不能通过再加一圈亮边、随机脏点、整体换色来回应这个问题。

## 这次的表示

本质：异界材料在挤压、拉伸或断裂后成为不可穿过的致密实体；地面是同种材料的磨损床与松散产物。它要求相同来源、不同组织，排除普通人造地砖、木板、绳索或所有东西共享砂砾纹。成立的形体包含实心层板、融合矿丝、空腔厚壳；当前三个形体和俯视相机已经存在，本轮保留它们与碰撞占地，只改变表面制作。

- 地面、可走浅起伏保留原三张素材和原有受光。
- 实体新增三张独立母片；每张左部是完整表皮，右部是断层。CSV选择区域、世界尺度、表皮／断面粗糙度和各自色值倍率。真正的面类型选择素材，而不是凭画面亮暗推导物理意义。
- 折板：连续致密的灰色层皮、疏而长的压痕，对应清晰的灰白层状断面；地面保持斑驳碎屑。
- 纤维：长而融合的矿物束皮与较粗的断端；束身组织顺实际对象坐标，避免成为铺在地面上的碎石。
- 壳体：连续灰白釉皮与暗哑断层。表皮和内部倍率分开，避免为了压住白皮连带把内层压黑。
- 表皮法线以真实大面为主，保留少量既有微结构；不再复制地表颗粒的法线起伏。纹理亮度不生出几何、法线、碰撞、遮挡或污染光。
- 粗糙度明确区分致密表皮与松散地面；表皮的弱反射随真实光源移动，同样经过原来的阴影与吞光查询。污染仍只来自真实污染位置，不用绿色识别所有实体。

这是三张独立图像母片 + 同源几何／光照的生产方法；不是用生成模型绘制完整场景，也不是自动把图里的阴影转换成几何。使用内置 imagegen，新图原样存入 public/assets/r100-materials；完整 prompt 与来源见该目录 README 和本次 QA 产物。无图片后期编辑。

## 检查与边界

先看正常原生尺寸，不以 albedo 或法线图证明可玩。用同一合法站位的修前／修后、三材料三档及折板斜照对比，记录可见材料差异；普通背光面仍可以暗，但不能与能走的地面混为一体。几何、通路、侵蚀和角色不改。

自动回归验证：地面素材变化不能污染实体上传，实体素材变化不能污染地面；图片不改变法线／高度／污染发光；表皮与断面有不同粗糙度；加载任一实体图失败必须报错，不悄悄退回地表材质。六张512² RGBA素材合计6MiB缓存，旧三图3MiB的内存范围不能原样套用。
