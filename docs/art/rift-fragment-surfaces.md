# 裂隙碎片地表（表驱动）

## TL;DR

每一次踏入抽一种「曾经是什么」。身份由渍色 + 纹理语法 + 墙/体量结构承担；底色只给极弱色温倾向，不强求落到不同色板格。可走地面的环境污染成品是崩坏簇（与改写体同源的青绿团落到地板），不是矩形平涂错误块。接缝漏光可以仍在，簇是主签名（DEC-069）。虚空三种地方同一套 void-black。加第四种 = CSV 新行，不新开着色器。

标定四张：`frag-outdoor` / `frag-clinic` / `frag-metro` / `frag-library`。本迭代只开旧图书馆（I6-G 已翻 `enabled=true`）。`frag-residential` 本迭代不启用，但配方已给：它是质量语法向量上「短而密、多缺口」的参数点（原「簇」），不是缺一个生成器。无新 HUD、不重做小地图、不写撤离多样性、不碰音乐。每一次踏入必须抽 `contaminationAge` × `ruinSeverity`（DEC-064）；尘点是漆，不是碰撞。载体是世界内地表，不是面板或读数；游戏内界面验收十二条不适用本文件。

源：`data/rift-fragments.csv` → 构建期 `src/generated/`。身份字段对齐 `FragmentTypeDef`；视觉列按本表追加。禁止在 `procedural-surface.ts` 再手写第二套主题表。

```text

floorBv, floorBiasR, floorBiasG, floorBiasB,
stainKey, stainThreshold, stainStrength,
grimeAmp, macroAmp, scratchPer1000px2, fleckPer1000px2, scratchAngle,

```

| 列 | 替换现实现的什么 |
| -- | ---------------- |
| `l1Key` / `floorBias*` / `floorBv` | 地面 `bv * (0.88, 1.02, 0.82)` 写死户外橄榄 |
| `stainKey` / `stainThreshold` / `stainStrength` | 苔藓 lerp 到 `(0x12, 0x2a, 0x14)`（该 hex **不在**色板，必须废掉） |
| `grimeAmp` `macroAmp` `scratch*` `fleck*` | `const SURFACE = { ... }` 单例 |
| `scratchAngle` | 划痕全向随机 |
| `wallBodyKey` / `wallBias*` / `wallBv` | 墙 `bv * (1.0, 0.88, 0.75)` 写死暖石 |
| `massGrammar` + `feature*` | 体量怎么长。着色器只涂墙 bitmap，不在着色器里分叉墙算法 |
| `sourceDomain` / `coverage` / `join` | 残片身份。本 Slice 三行都是 mundane × remnant × single |
| `enabled` | 本 Slice 谁参与抽取 |

`scratchAngle` 只约束已有划痕线段的角度，不换基元：

| 值 | 含义 |
| -- | ---- |
| `free` | 现实现：0–2π |
| `orthogonal` | 吸附 0° / 90°（瓷砖缝） |
| `longitudinal` | 吸附本趟最长残块轴线；没有则吸附缓冲长边（站台走向） |

加行纪律：新 `id` + 已论证的 `l1Key` + 本列填满。新色必须先论证进 art-direction / `palette.json`——本任务禁止论证新色。着色器循环（噪声、划痕图、崩坏簇漆、可选接缝漏光、墙沿、抖动、量化）加行时不准加新 pass。

## 并排怎么分清（渍 + 纹理 + 结构，禁止只靠底色）

32px + 视野遮罩下，只换雾/亮度/底色标为不够（`system-map-generation.md` A28）。烤图已证实底色众数分不开四张世界。

| | 户外 | 医院 | 地铁 |
| - | ---- | ---- | ---- |
| 渍 | 苔斑（橄榄键） | 缝脏（影灰） | 锈斑（砖红） |
| 地面残影 | 土 + 乱向刮痕 | 正交砖缝 | 长轴磨亮 |
| 墙形状 | 弯/厚的脊 | 细直角围合残 | 锈板/混凝土板片 |
| 禁止的偷懒 | 直墙刷成土色 | 石堆刷成冷灰 | 石堆刷成锈色 |

验收问的是：多坨更小的体量铺在岛上，空地被切成能绕能穿的小院子/巷；墙形、渍、划痕方向不同。覆盖浅时可能还认得残影；指不出名字不算失败。五张配方见下「碎片身份配方」。

## 组合轴

`FragmentRoll = typeId × contaminationAge × ruinSeverity`。两轴只乘已有旋钮，不换表达。种类行决定「曾是什么」；组合轴决定「覆盖多深 / 残块多破」。污染主签名始终是崩坏簇，不随种类换成矩形块。

**DEC-064 收工交付（两轴都抽）：** 每一次踏入必须抽 `contaminationAge` ∈ {`new`, `standard`, `ancient`} 与 `ruinSeverity` ∈ {`intact`, `broken`, `eaten`}。禁止所有出击永远 `standard` + `broken`。禁止只抽年龄、残破永远停在 `broken`。

生成器抽失败、或调试入口未带组合轴时，**回退**仍是 `standard` + `broken`。回退只用于缺字段，不是生产路径。生产路径必须抽，不能永远走回退。

### `contaminationAge` → 浓度表 + 色相滑动

簇色**不**按年龄去色板里选死一行 `contam-*` 套所有岛。先走下方「配色公式」：L1 按偏置进色温组，组内按色相方向取格；L2 强制在青绿家族内同一函数；再按年龄在色相窗内往蓝或往绿推。量化不得跳出该组。`ancient` 若落到 `contam-ancient`，按 art-direction §14.4 **压饱和**，禁止原色铺开。

| `contaminationAge` | 浓度行 | 簇尺度 | 簇密度 | 色相滑动 | 可选接缝 |
| ------------------ | ------ | ------ | ------ | -------- | -------- |
| `new` | 轻度 | 小团 + 散点 | 稀疏 | 往蓝拉 | 可省 |
| `standard` | 标准 | 标准团 | 中等 | 青绿轴中位（色相窗内，不按碎片分工） | 可并存细线 |
| `ancient` | 重度 | 大团 + 卫星瓣 | 密 | 往绿拉 | 可并存 |

乱码（仅 `ancient` / 重度）：在量化后打 1px 错点，色取色板内非本行 L1 的暗色（`shadow-grey` 或 `bone-grey`）。不是新纹理，不是另一块碎片的底色铺上来。

禁止 `CONTAM_TEAL = contam-cold`（或任何一组写死的 `CONTAM_*`）冒充所有岛、所有年龄。医院新生和户外新生可以分清，靠的是渍色 + 划痕语法 + 墙形状（隔断 vs 土脊），**不是**底色落到不同色板格，**不是**污染色相分工，不是「医院少 teal、地铁多 teal」，也不是网格矩形块的个数。

生产不得再用平涂矩形错误块当地面主签名。平涂仅练习场对照。不要用加粗折线冒充簇。

### 配色公式（别人改坏会出事）

**本段是 I6-A 定稿的可执行算法（污染层）。** 步骤 5–6 补的是污染协同、不提亮。碎片身份不再靠本段 L1 落到不同格——见下「碎片身份配方」。禁止给 `docs/art/palette.json` 加色。禁止整体提高 CSV `floorBv`。禁止把偏置三通道平均抬到现行 0.887 的 ±5% 之外。禁止把污染色相写成碎片身份（户外绿青 / 医院白青 / 地铁蓝青）。`docs/art/samples/proto-fragment-ramp.png` 与 `world-coordination.png` 最右栏是**已撤回**的色相分工与**不采纳**的色板亮端整只发光，只当反例。

**现状事实（写进合同，禁止再写成「回退即可用」）：**

- 现实现若仍把 `cluster` 映射成围合体再按枚举名验收，会抛错。居民区配方是向量上的「短而密、多缺口」点，落地走参数化，不新开生成器。本迭代不启用该行。
- `frag-residential` 不进四张标定，不进本迭代闸门。
- 标定四张：`frag-outdoor`（户外土壤）/ `frag-clinic`（医院实验室）/ `frag-metro`（地铁工业）/ `frag-library`（旧图书馆）。旧图书馆 `enabled` 待 I6-G 翻转。

**共用选色函数（地面与敌人必须调这一份，禁止两套）：**

```
mean(rgb) = (R + G + B) / 3
chromaDir(rgb) = rgb / max(1e-6, mean(rgb))

quantizeInGroup(targetRgb, candidateSet, used) -> paletteRgb
  在 candidateSet 里去掉 used，取 ||chromaDir(c) - chromaDir(targetRgb)|| 最小的一格。
  并列时用 RGB 欧氏距离拆开。
  禁止到 candidateSet 之外找更近的格。允许结果比目标更亮。
```

**为什么按色相方向、不按 RGB 距离：** 组内候选亮度差大时，RGB 欧氏被亮度主导。先除以自身平均亮度再比，只留色相方向。本函数服务污染四档与对比度用的地面主色，**不**用来把四张地板众数拉开——那条路烤图已证伪，见「碎片身份配方」。

**对冷组 / 橄榄组：** 同一公式，不另开切法。橄榄组现表只有 `#1a1e18`，改口径不会与别张撞。冷组现表四格亮度差大；医院实验室（偏置不动）会从 RGB 最近的 `#151a1e` 改落到色相方向最近的命名格 `#1e2228`，仍独占冷组，与户外不撞。**不要改医院或户外的偏置。**

**对 L2：** 四档子集已按明度切开（核 / 高光是单格；深 / 中靠 `used` 互异）。明度归一化不取消「四档必须互异」；年龄在色相窗内滑蓝 / 滑绿仍然有效。

地面崩坏簇与敌人四档污染漆都调用它。迭代 5 基因谱甲若已存在，只许调这一份。禁止 `preview-paint.ts` 与 `fragment-ramp.ts` 再各写一份无约束 `nearestPalette`。生产像素量化（`writeQuantizedRgba` 一类）必须改调这一份：先 `temperatureGroup` 再 `quantizeInGroup`。只改 CSV 偏置、烤图仍走无约束最近色，居民区公寓与旧图书馆在 `+16` 后仍会撞到 `#2a2420`。

**色温分组函数（L1 用；L2 不用碎片的暖/冷/橄榄组）：**

通道为 0–255。诊断脚本 `measure:l1-reach` 与此同构，禁止另发明切法。

```
temperatureGroup(r, g, b):
  if (r - b) >= 6: return WARM
  if (b - r) >= 6: return COOL
  if (g >= r + 2) and (g >= b + 2): return OLIVE
  return NEUTRAL
```

对碎片有两路输入，函数相同，取样不同：

- **对比度 / 污染四档用的地面主色：** 模拟 RGB = `floorBv * (floorBiasR, floorBiasG, floorBiasB)`（**不加**绘制器 `+16`）。偏置方向对、亮度够不着暖格时，组仍是暖。
- **生产像素量化：** 对画出来的 RGB 调用同一对函数。地板那路是 `bv = floorBv * (1 + grime + macro) + 16` 再乘偏置（可再叠阴影 / 渍 / 划痕）。墙那路是 `bv = wallBv + n` 再乘偏置（**没有 `+16`**）。禁止把 `+16` 写进对比度合同目标；也禁止生产量化绕过分组、改走全色板最近。

墙路同样分组，供墙像素使用。身份闸门不再看地板众数，见下「身份指纹闸门」。

**对比度用的地面主色（可执行定义）：**

**感知距离（可执行定义）：**

CIE76 ΔE*ab。sRGB 8-bit → 线性 → XYZ D65 → Lab，再欧氏距离。禁止用交并比。禁止只断言两个 hex 字符串不相等。禁止用 RGB 欧氏距离当对比度闸门。`quantizeInGroup` 组内比的是明度归一化后的色相方向，并列才用 RGB 欧氏拆开。

```
srgb_to_linear(u) =  u/255 <= 0.04045  ?  (u/255)/12.92  :  ((u/255 + 0.055)/1.055) ^ 2.4

[X Y Z] = M · [R_lin G_lin B_lin]
M = [[0.4124564, 0.3575761, 0.1804375],
     [0.2126729, 0.7151522, 0.0721750],
     [0.0193339, 0.1191920, 0.9503041]]
白点 D65：Xn=0.95047, Yn=1.0, Zn=1.08883

f(t) =  t > 0.008856  ?  t^(1/3)  :  (7.787·t + 16/116)
L* = 116·f(Y/Yn) - 16
a* = 500·(f(X/Xn) - f(Y/Yn))
b* = 200·(f(Y/Yn) - f(Z/Zn))

ΔE*ab = sqrt( (L1-L2)^2 + (a1-a2)^2 + (b1-b2)^2 )
```

输入：本趟 `RIFT_FRAGMENT_DATA[fragmentTypeId]` 的地板 `floorBv * floorBiasRGB`、墙 `wallBv * wallBiasRGB`，以及 `contaminationAge` 与本趟种子。

1. **算模拟 RGB。** 地板 `Rf,Gf,Bf = floorBv * (floorBiasR, floorBiasG, floorBiasB)`；墙同理。通道独立。禁止把 `floorBv` 直接当成 HSV 的 V。禁止把绘制器 `+16` 加进对比度合同目标。`+16` 是污垢/宏观纹理，只出现在生产像素那一路。
2. **L1 定组。** `gFloor = temperatureGroup(Rf,Gf,Bf)`。这是地板色温组。L2 污染**不**继承此组。
3. **L1 组内色相方向 = 对比度用的地面主色。** `floorCell = quantizeInGroup((Rf,Gf,Bf), L1池[gFloor], used=[])`。允许比目标亮。这一格只服务污染对比度，**不**承担碎片身份。户外与医院与三张暖世界的 `floor_bias` **都不必为身份改**。墙像素用墙模拟 RGB 走同一函数。生产像素对画出来的 RGB 再调一次本函数。
4. **L2 只构造色相与模拟明度，不定量化组。** 两路模拟 RGB 转 HSV。地图色相：若两路饱和都 < 0.06，取青绿轴 `H=0.48`；否则取饱和更高的那路色相。往青绿轴拉：`H = 0.48 + (mapH - 0.48) * 0.52`（0.52 沿用现实现混合系数）。年龄：`new` 再 −0.07，`ancient` 再 +0.08，`standard` 不额外推；允许种子抖动 ±0.025。然后**夹到色相窗 [0.42, 0.56]**（约 151°–202°）。夹窗是已锁纪律：混合系数再大也不得滑出青绿窗去当碎片身份。饱和沿用现实现：`S = clamp(0.50 + max(Sf,Sw) * 0.38 + (ancient ? 0.08 : 0) + jitter, 0, 1)`。明度沿用现实现构造，**不**把 `floorBv` 当 0–1 的 V：`mapV` 来自模拟 RGB 的 HSV.V；`V = clamp(max(0.36, mapV + 0.18) + jitter, 0, 1)`。这一步只产模拟 HSV，不写合同 hex。
5. **L2 的组强制为青绿家族。** 不是步骤 2 的暖/冷/橄榄。暖碎片的污染也进青绿组，禁止进暖组变成褐斑。
6. **L2 四档在对应子集内组内色相方向。** 由步骤 4 的 H/S/V 生成四档模拟 RGB（沿用现实现倍率：深 `S*0.82, V*0.68`；中 `S, V*0.95`；核 `S*0.78, V*1.20`（上限 1）；呼吸高光 `S*0.46, V*1.42`（上限 1））。然后：
   - 深 = `quantizeInGroup(deepRgb, 深子集, [])`
   - 中 = `quantizeInGroup(midRgb, 中子集, [深])`
   - 核 = `quantizeInGroup(coreRgb, 核子集, [深,中])`
   - 高光 = `quantizeInGroup(glowRgb, 高光子集, [深,中,核])`
   四档 hex 必须互异。每一档对步骤 3 的地面主色算 ΔE*ab，已锁 ≥ 18。禁止把中间 HSV 的 hex 写成合同色。禁止四档填 `#1aad96/#2ae6c8/#3cffd4` 以外的更亮核，且 `#3cffd4` 不得作四档填充。

**身份指纹闸门（形状优先；I6-E 落地）：**

```
features = 本次 mask 的墙体量（已画进烤图的残块，不是另读没画的表）

jogPeriod  = 各残块沿长轴每出现一次 1 格侧移的间隔中位数（格）
gapCount   = 各残块包围盒内「非墙可走格」个数的中位数
turnCount  = 各残块中轴 90° 转向次数的中位数
capClass   = 端点形态：flush | stub | pier | widen
             （2 格突出=stub；端点 2×2=pier；端点比中段宽=widen；齐平=flush）
widthMed   = 各残块 min(包围盒宽, 高) 的中位数
facingVar  = 残块长轴角的圆方差
             低=主轴对齐；双峰 0/π/2=正交交替；高=全随机

shape[id]  = (jogPeriod, gapCount, turnCount, capClass, widthMed, facingVar 分档)

stainHex   = 可走地板中、距该行渍色条目比距地板众数更近的像素众数 hex（排除青绿）
scratchμ, scratchσ = 地板上被划痕压暗的短线段主轴角及其角标准差

assert |{ shape[id] }| == 4
```

`facingVar` 分档用户外 / 医院 / 地铁三张标定（高 / 双峰 / 低），不要写死枚举名。

**现状必须 FAIL：** 旧图书馆与户外土壤现表同走脊预设（错位 4/1、缺口 0、转折 0、短杵、宽 1、朝向随机）、同地物 1/6/12–24、同墙偏置、同污垢。烤出来的 `shape` 会撞。渍键与划痕枚举现表已不同，只验渍 / 划痕会误绿——所以先验 `shape`。

禁止用 `floorBv * bias`、`measure:l1-reach`、`wall_body_key` 冒充本闸门。

### `ruinSeverity` → 材质残影（浓度表「暗色地面 / 可辨」侧）

不改污染主签名，不加藤蔓，不换墙语法。不把残破轴拿去改簇的形状语言。

| `ruinSeverity` | 对应浓度表哪一侧 | scratch 乘数 | fleck 乘数 | stainThreshold 偏移 | 墙沿 |
| -------------- | ---------------- | ------------ | ---------- | ------------------- | ---- |
| `intact` | 轻度：材质仍可辨，暗地约 90% | `0.70` | `0.70` | `+0.06`（渍更少） | 顶沿高光保留 |
| `broken` | 标准：仍可辨 | `1.00` | `1.00` | `0` | 现有顶沿 / 落影 / 侧 AO |
| `eaten` | 重度：几乎不可辨，暗地约 50–55% | `1.40` | `1.50` | `−0.10`（渍更多） | 顶沿减弱，侧 AO 加重 |

`ancient` + `eaten` = 大团更密 + 材质更糊。仍是崩坏簇 + 同一套噪声，不是第二种污染。

## 呼吸（三层活体，不是描边）

给 code 的死约束：

1. **地面像素烤一次。** 出击与练习场都只烤内核；中间层与外层走活层。禁止每帧重画整张地面 ImageData，禁止每帧 `compositePaint`。
2. **活层是面积，整团胀缩。** 中间层与外层同一呼吸相位，几乎不透明，沿簇自己的不规则外沿填实。胀缩幅度是该团休息大小的 5–20%（每团随机）。中间层向内核叠一点，禁止核心与外层之间漏出地板。禁止沿圆周走鼓包。禁止描轮廓线。禁止整团透明度呼吸。
3. **甲：内核不动。** 收缩 = 外围收回，烤死的心仍在。膨胀不得进墙或虚空。
4. **出击已挂同一套活层（DEC-071）。** 呼吸精灵必须低于裂隙视野黑暗蒙层（`DEPTH.visionMask` 约 50；painter 用地表 depth + 0.05）。迷雾下亮度等人终审。
5. **无新色、无新 HUD。**

   - 头注释「outdoor rift feel using `frag-outdoor`」

   - 一组 `CONTAM_*` 冒充所有岛、所有年龄的污染色（含 `CONTAM_TEAL = [0x1a, 0x7a, 0x9a]`）
