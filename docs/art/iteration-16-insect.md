# 迭代 16：虫类基体的覆盖退场

状态：HUMAN-PASS（2026-09-07）。用户认可动作，并在R3降低中档污染程度后明确PASS；当前三档为本迭代验收结果。

本轮依人的明确要求，从 `world.md`、`vision.md` 与实际裂隙场景独立推导造型，不采用旧虫体、旧美术规范、像素技能或历史评审作为造型依据。人的纠正是：玩家应先看到污染体，覆盖越深，原基体越应退出。

## 当前造型：折返壳

外来表面沿虫类基体生长，却把原有解剖关系替换为一个会折返、扭转的连续实体。它仍承担重量、接触地面，并按稳定规则行动；不靠随机碎块或全身发光表示异常。

- **渗透**：原虫体仍可辨。六足、头与腹部是残留身份；一侧腹甲提前错移抬升，肩部偏离中线，矿质面穿入壳缝。不是普通虫体加一层统一染色。
- **改写（R3）**：保留头、颈、胸与大部分腹部的连续连接，完整一侧腹甲与另一侧后半甲仍可辨。五条分节足和一长一短触须保留原物身份；污染替换一侧中足与肩背，以较窄的侧向折面翻起，折面与残甲之间形成局部裂隙，尚未贯穿整个躯干。
- **覆盖**：不生成原腹部、头、胸、触须或成对甲壳。主体由厚薄不均的返回曲面组成，逐段扭向变化，局部接近立起，内侧再次悬挑；开口与偏心负空间阻止它闭合成均匀石环。三个接地点中的两个已变成承重折面，仅一个保留分节残足。后沿还有短小的退化触段，不再重建完整虫轮廓。

灰褐角质逐渐被灰绿矿质的连续厚面取代。暗内壁、浅顶面和少量接缝色说明体积。污染程度改变解剖、支点和空隙，不以面积放大或追加青绿装饰代替。

模型采用地面坐标与体高构成的正交投影。转向时旋转地面坐标，体高仍向屏幕上方抬升；光源固定来自画面左上方。四向不旋转成品贴图。阴影由现有运行时负责；模型包含实体与一像素轮廓。

## 接口与动作

代码入口：`src/entities/form-renderers/d/insect-model.ts`。

- `bakeInsectModel({ seed, coverage, facing4, phase, phase01 })` 返回 `{ buf, canvas }`。
- 覆盖枚举：`infiltrate / rewrite / overwrite`。
- 方向：`up / down / left / right`。
- 导出 `InsectPhase`：`idle / walk / alert / windup / strike / recover`。
- 画布 48 × 48，原点 (24, 24)，offset 0，沿用 collision 20 的现有技术合同。
- seed 决定比例与改写侧；同一实体跨帧保持这些形态参数，不重新抽样。

动作时序沿用获认可的版本：

- 静止：约 0.34 像素的呼吸。渗透档触须轻扫；高档表现为折面轻微起落。
- 步行：延用原足迹相位和位移，66% 支撑后蹬、34% 抬足回摆。已被替换的支撑仍沿原接地点轨迹加载重量；不会把高档复原成六足。
- 警觉：停止行走；低档触须展开，高档保持观察姿势。
- 预备攻击：身体后缩 1.8 像素、压低 1.1 像素，前支撑收回；高档前端折面同步收拢。phase01=1 可保持。
- 攻击：phase01=0 已是实际命中时的最大前伸；前支撑前探，前端折面同步展开。末帧收至 80% 前伸。
- 回收：从 80% 前伸缓动回静止位置，与攻击末帧连续。

伤害时刻、攻击承诺朝向和战斗状态由现有运行时驱动，本次未改变。
