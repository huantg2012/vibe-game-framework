# 世界地图小样

本系统保留世界观背景；色彩与环境画法不受旧项目锁色、极暗、teal 或旧 pixel-models 画法限制。**2026-09-18 用户明确：低饱和不是其预期，也不是新 Rift 地图系统的输出要求。** 当前三份数据偏低饱和、偏矿物化，地面外轮廓接近椭圆，这些都是样本现状，不能上升为生成规范。

独立可移动 viewer 当前提供三份具名世界和两份空间预设；材料与空间分别由 CSV 配置，可交叉组合。它们不是世界、物质、造型或色彩目录的上限。迭代 26 按本文推进通用视觉构成与现场核验，不接入旧战斗。**所有改进作用于材料/形体/区域组织能力；不得按世界 ID、seed、截图坐标或旧样本色调写专属补丁。**

## 不变的行动语义与本批边界

用户已锁定本批边界：保留正式角色；障碍是不可行走、不可照亮且截断视线的缺失空间。本文只改可见陆地侧的表达，不改角色、洞内纯黑、碰撞或视野算法。旧样本偏好与旧评审结论不是新配方的质量标准。

- **空洞没有材质表面**：内部与外空最终都写成不透明纯黑，截断视线。旧石板顶面和立面彻底移除，禁止补亮洞内任何格。
- **当前可见材料生长在陆地**：低矮晶片、沉积断页、釉壳碎片是可跨过的地表浅浮雕。地面平面内的片、带、簇都成立；竖立高柱、实体屏障不属于本批行动语义。形体可以放大成组，但不靠竖直侧面或长投影假装具有新的阻挡能力。18–42px 是入场晶片的已有尺度，不是所有新形体的上限。
- **角色直接复用正式32×32四向动画**：环境可以无彩，角色保留原色和精灵中的暖灯像素。32帧与修改前正式atlas的散列一致；这不代表地表已具备正式暖色加法灯光合成。
- **实际步行用视野审查**：样板复用前向224px、环身80px的光场数学与32级强度，在连续空洞边缘截断。当前仍是四向照明；正式的连续转向、侧向射程收缩和暖色光层未完整迁入，本轮不改。未知地面无残影；全图和关闭视野只作美术检查。

## 当前三份示例配方（现状，不是输出要求）

以下记录迭代 26 入场数据。无彩属于第一份配方的选择；灰紫、米灰及矿物化分别属于其他样本的取值。新增配方可以采用高饱和主调、强互补、异质的非矿物形态；其正当性来自世界配方与可观察的行动关系，不来自是否像这三张图。

- **ash-strata／无彩层原**：层岩底材＋层岩覆盖，保持环境无彩。定向沉积床、错断层理、灰砾簇和薄层碎页形成材料身份；宽地面包含宏观明暗、区域斑驳和细粒，安静不等于纯色。
- **crystal-fibre／晶化林床**：层岩底材＋晶化覆盖，晶体不再充当石板上的条纹。晶化区域从地表不规则碎面发展为独立实心晶簇，晶片有外轮廓、明暗切面、折断线和地层根部；大小碎晶沿局部改写前沿聚集。当前为低矮、嵌入地面的晶化结构，未引入高大水晶柱的独立碰撞语义。
- **ivory-basin／吸光釉原**：层岩底材＋釉层覆盖，保留亮釉与深色断缘。区域釉色、暗沉积、开片、剥落壳片和小碎片共同构成表面。大块壳片也位于陆侧，纯黑空洞里没有盆壁或可受光石头。

## 空间与视觉构成的接口

当前空间样本以连续开放陆地为承重主体，侵蚀形成局部团状空洞和短裂口。旧 `loops` / `channels` 只保留 URL 兼容含义；当前两预设不画四条平行长洞，也不把拓扑关系画成平台桥网。**开放、近椭圆、团状孔洞是当前样本能力的范围，不能被本美术规格锁为以后地图的唯一主形。** 侵蚀面积、尺度、方向性、聚集和裂口比例来自独立空间数据；运行时检查开放度、宽通行核心及身体可达，不能只凭“连通”验收。美术构成读取支撑与方向信息，不改写空间可达性。

完整地面应容纳横穿的宽区域、局部绕行与材料变化。空洞始终是黑色缺失空间；地面层次来自陆地上的物质关系，不通过补出洞壁获得立体感。

## 已有通用地面绘制接口

静态预烘焙的组合顺序为：**底材 → 覆盖材料 → 磨损露底 → 薄层接触边 → 沉积与碎屑 → 地面局部形体**。三种绘制基元 `strata` / `crystal` / `glaze` 都可作为底材或覆盖层；按材料能力分支，不按世界名称分支。新增已有基元范围内的组合，应修改 CSV 配方并验证；新增物质规律仍需要实现新的表达能力。

`SurfaceRecipe` 的八项参数为 `substrate`、`coating`、`coverage`、`wear`、`deposits`、`scale`、`relief`、`contrast`，分别选择底材/覆盖材料及其覆盖、磨损、沉积、尺度、浅浮雕和对比强度。色板独立决定各材料角色颜色。名称和 ID 不参与地表像素选择，因此同一组合改名不应改变画面。

`material-field.ts` 保留布局的沉积历史与方向；`surface-field.ts` 再分别生成覆盖、磨损、沉积、露底等过程。覆盖可被磨损剥开，碎片可随局部沉积和破损前沿聚集；各场相关但不完全重合，避免全图所有细节都挤在同一条浓淡边界上。

层岩基元提供不连续层理与断口，晶体基元提供有边界的切面，釉基元提供厚薄变化和开片。底材与覆盖使用独立材料纹理及颜色坡道；薄层上下缘以局部亮边/接触暗部表达。中尺度结构与沉积碎片可以进入宽阔地面内部，局部晶簇/层片/釉片同样从全体受支持陆地取样，不再为每个洞口摆一组装饰。密度、尺度和附着仍受材料过程控制，静区应有低强度物质变化，不能靠均匀撒点填满。

晶面与釉面记录稀疏反射位置、朝向、强度及锐度。步行中根据角色灯的位置响应，统一乘以原视野遮罩；反射属于所绘材料，不依赖世界 ID，不添加独立光源。层岩保持哑光；所有反射像素必须在完整受支持的2×2像素块内，不能跨进空洞。沉积和形体后来覆盖的像素会清除其底下的旧反射，同色覆盖同样更换归属。

以上是迭代 26 入场时的实现接口，不代表本迭代新增构成已经落地或验收。已有组合检查记录见 `docs/dev/rift-world-study.md`；新字段、色彩覆盖与形体调整须按下文重新验证。可以表达组合，不等于任意联合参数已经具备可交付的审美与玩法质量。

## 色彩自由与配方色板

每份配方当前提供 16 个颜色角色，实际数值唯一来源为 `data/rift-world-profiles.csv`，不在本文复制一份锁色表。角色顺序为 `void shadow floorDeep floor floorLight materialDark materialMid materialLight faceLight accentDim accent accentLight peak actorDark actorMid actorLight`。这些颜色不写入旧生产色板；允许材料层内插值，不应把每格平均铺满。`void` 与 `actor*` 是兼容字段，缺失空间使用系统纯黑，正式玩家不读取这些格。

- 底材、覆盖、断口、响应可以使用不同色相；高饱和与暖色可作为大面积材料本色，不限于点缀，也不自动表示自发光。**不得施加全局去饱和、强制偏冷或把所有配方映射回旧色板。**
- 明度、色相、饱和度是可独立组织的维度。强互补可以分配给底材与覆盖；两套材料各自拥有完整的暗/中/亮关系，不用跨两主色的全局插值把交界抹成泥色。
- 配方需声明哪一层主导、哪一层形成变化。主导可以靠面积、形状、明度或色彩对比成立；不规定所有世界必须低饱和、暗底、冷暖分工或只留一个亮色。
- 玩家与地面可读性通过正常视野、实际底色和轮廓邻域复核；发现冲突时改该配方的关系或共享材料对比能力，不统一压暗/去色，也不改玩家来迁就地表。

## 迭代 26：可执行的视觉构成 brief

### 1. 本质、载体与尺度

本批对象是**异时空承重表面上，原有组织被另一种物质或规律覆盖、割断、聚集或抹除的关系**。要求关系有可见依据，不要求观者叫出地球材料名。可成立的形体包括相连宽片、定向长带、成组放射体、圆钝积聚体及其残缺状态；本批以已有三材料操作验证其中的片、带、簇。不能把矿石、晶体、层岩当作以后所有世界的本质。

载体为地面平面，环境局部结构全部可跨越，画在玩家脚下；相机沿用当前俯视读法。基础标尺用正式 32×32 玩家：主区域跨度约为角色宽的 6–14 倍，中尺度主体约 1.5–4 倍，碎屑约 0.1–0.5 倍，接触断缘约 1–3 原生像素。以上是**本批起调范围**，不是美术系统的永久尺寸表。主区域须在一段正常行走中形成进入、经过、离开的变化；不以一张全图的纹理拼盘代替。

### 2. 区域主形与静区

区域先组织“连续片区、方向条带、成组聚簇”三种关系，再由材料画法表现它。三种关系都可接受任何合法色板和底材/覆盖组合；不能写成“晶化只能聚簇、釉只能片区”。区域主形不等于碰撞形，不沿每个洞口平均摆一圈物件。

主形区保留完整的大块轮廓，让中形附着、穿入或从它剥离；静区降低碎屑、破口和高频面分割，保留缓慢的材料厚薄/方向变化。静区不是统一变黑、去饱和或填纯色。至少用一条实际路线验证“密 → 疏 → 另一种组织”的变化；可以有大面积安静世界，不强制每视口一个装饰焦点。

### 3. 最小共享参数建议与接线

在现有 `SurfaceRecipe` 八项及独立 `WorldPalette` 上，本批接入以下六项构成字段。字段名与当前实现对齐，配置由 CSV → loader → code，不能在代码里按样本名手写值。

- **`organization: patches | bands | clusters`**：控制区域之间的组合关系。`patches` 为宽片相接/相离，`bands` 依局部方向延伸并错断，`clusters` 为若干主团与疏区。接入 `surface-field.ts` 的覆盖/沉积场；只决定组织，不选择材料、色板、碰撞或地图外轮廓。它是本批三种组织算子，不是未来形态目录上限。
- **`regionScale: 0.5–2`**：只改变宏观区域的跨度与间隔。接入当前 `broad`/区域分布尺度；不把细粒、晶面、碎屑一同放大。现有 `scale` 暂保留材料内部纹理尺度含义，迁移时须检查两者不再全局联动。
- **`quietness: 0–1`**：增加同一材料内部可连续经过的低活动区，调制微粒、碎屑、细裂和次形体。`0` 不额外压制；增大后静区扩大或活动下降，但覆盖、色相和主要轮廓不消失。建议生成独立低频 `activity` 场，禁止直接把 `deposit` 低处全部当静区而让所有过程重合。
- **`formScale: 0.5–2`**：只改变中尺度主体的足迹与组内大小关系。接入 `material-forms.ts` 的主体，不改变世界地块、光场或微粒。主体增大时减少同范围候选数量/提高间隔，不用“大又密”制造屏障感。
- **`fragmentation: 0–1`**：在覆盖/磨损允许的区域，控制主体连续程度、断口比例及与母体相关的脱离碎片。低值保留完整宽面，高值形成同源碎段；碎屑总量仍由已有 `deposits` 控制。禁止把它实现为全图独立撒更多小三角。

- **`accentCoverage: 0–1`**：控制稀疏强调区域的面积，接入独立 `accent` 场；可以增加局部形体或材料响应，不等于把强调色均匀撒满，也不限定高饱和只能位于强调区。

复用已有字段：`coverage` 管材料面积关系，`wear` 管剥露与破损位置，`deposits` 管沉积/碎屑量，`relief` 管低矮接触面差，`contrast` 管材料内部差异。现有 `relief` 同时影响形体出现率的耦合须收窄：新 `quietness`/组织场承担疏密，不能要求把形体全压平才能获得静区。空间数据现有 `directionality`/`clustering` 仍属于空间；材料可读取其历史方向，但不改其碰撞结果。

这些参数须有独立实效：只改色板不得换布局/形体，只改 `regionScale` 不得使细粒同步变粗，只改 `quietness` 不得全图去饱和，只改显示名称/世界 ID 不得改变像素。更换 `substrate`/`coating` 操作本身应改变材料画法。参数间允许有明确因果关系，不允许无说明的全局同涨同落。

### 4. 材料形体、覆盖、断口、碎屑与响应

**最优先形体更改：从孤立同族碎片，转为有完整主体、局部断口与附属碎屑的低矮成组体。** 主体承担第一眼读法，小碎片解释主体经历的变化。禁止先铺碎屑，再期待它们偶然形成主形。

- **片状语汇**：完整宽面＋少数不连续断缘＋从边缘脱落的同向薄片。可表达层床、膜、覆皮或其他平面结构；本批 strata 使用错层薄片，glaze 使用连续壳面。两者差异来自断面与覆盖关系，不仅来自颜色。
- **带状语汇**：沿局部方向连续伸展、局部压窄/分叉/错断，粗细有主次；不画成均匀平行线或每段同宽的道路。既可承载层纹，也可承载晶化前沿或异质覆盖。
- **簇状语汇**：一至两个较大的连接主体带少量侧生形体，根部确实落地；大小、朝向与完整程度相关。晶化可用宽扇面/短棱束，不沿圆周等角复制小尖片，不立成高柱。未来可用其他材料解释同一聚集关系。

覆盖边缘需要能看出“上层终止、下层露出”，但不沿整个区域勾亮圈。断口位置从 `wear` 与 `fragmentation` 导出；碎屑的材质、方向和尺寸从附近母体/沉积方向导出，减少没有来源的同质点。接触暗部保持短、贴地，不能借长投影制造新碰撞语义。

反射继续属于实际可见材料，受已有视野遮罩裁切；保留哑光、宽而弱的响应与窄而锐的响应差异。不能用闪亮替代厚度/覆盖表达，也不能因为“吸光”一词把该配方所有局部变化抹掉。上层覆盖清除下层反射，改色不改反射归属。

### 5. 缺失空间：只加强陆地侧的消失关系

本批保持洞内与外空不透明纯黑、不可走、挡视线。候选表达只落在受支撑陆地：材料条带被截断，覆盖表皮在边界前出现不完整断缘，少量同源碎片沿存留一侧聚集。边缘带建议先在 3–10 原生像素内起调，宽度由材料尺度/磨损调制；不是新增洞壁，也不画横跨空洞的悬空片。

现有均匀暗边可保留作为低强度支撑信息，但要让材料终止关系承担身份，不能把所有洞口画成同宽发光圈或深色描边孔。边界变化从支撑 mask、局部方向、覆盖/磨损取得，不能按洞编号或屏幕位置设计。不得增加洞内反射、独立光源、透视墙面或改变视野衰减来掩盖边界问题。

### 6. 三个入场样本怎样使用共享能力提升

下列参数是首轮起点，须在实景核验后再调，不是已锁审美值；它们都能交换给其他配方。

- **无彩层原**：从近均匀层纹＋零散立片感，改为宽层床的错断和完整页片，露底区承担静区。起点 `bands / regionScale 1.5 / quietness 0.45 / formScale 1.2 / fragmentation 0.45`。依靠方向/厚薄与断口辨认；维持此样本的无彩，只是验证无色相帮助时的形体能力。
- **晶化林床**：把重复小尖片优先改成少量较宽、低矮、根部相连的晶化前沿；完整切面与细碎断晶交替，让远观先读到组形、近观才见碎晶。起点 `clusters / 1.3 / 0.35 / 1.4 / 0.25`。保留可跨越语义，不靠把每面提亮或给每颗补轮廓解决辨识。
- **吸光釉原**：用连续壳面包覆下层，局部开片/剥落与少量较大的壳片相连；扩大完整面与粗糙露底的节奏差，减少到处同量的小粒。起点 `patches / 1.4 / 0.55 / 1.35 / 0.20`。本体可以哑光；厚薄、接触和破口先于反光说明材料。

三例完成后必须交换组织算子和色板复核。若改进只在原样本与原色调成立，不能算通用能力交付。

### 7. 可观察的完成标准与覆盖验证

**正常行走判据：** 同一路线中能分别指出主区域、依附它的中形和安静表面；缩略全图能看到组织变化，150% 步行也能看到其因果。没有新增物理阻挡，但可跨越形体不能反复被评审者误判为高墙。靠近黑色缺失区时，画面说明材料在此终止；试走后理解能迁移到另一个未看过的缺口。

**材料与静区诊断目标（未测，不记为通过）：** 首批起调可比较同配方预声明活跃区/静区 mask：以静区微粒与碎屑覆盖率约为活跃区的 40% 以下作为诊断目标，同时检查宏观明度/色彩变化是否保留。关键接触/断口可用未乘视野的邻接面差排查：线性相对亮度差约 0.04（0–1），或 OKLab 欧氏距离约 0.10（L 为 0–1），仅作定位过弱边缘的参考。这些数值不是新全局硬锁，不要求所有材料、世界或地表像素满足；实测须连同配方、位置与方法记录，未测不得声称达标。偏离目标时先报告画面实际得失，不自动增亮、降饱和或套描边。正常视野的观察与人的审美判断仍须完成。

**色彩覆盖至少包括以下三族，均交叉材料与空间；这不是每个世界必须同时满足的色彩配方：**

1. **高饱和主调**：用主导材料中间色 HSV 饱和度约 0.60 以上、关闭视野后约 35% 承重面积保有饱和度 0.50 以上作为覆盖样本的诊断目标，检查高饱和能否成为主体而不只是一颗装饰点；这些不是所有世界的输出阈值，需实测才记录结果。该覆盖样本不得通过去饱和修可读性。
2. **强互补**：覆盖样本以两主材料中间色相差约 150°–210° 为起调范围，各自具有完整明度关系；检查区域交界不因跨材料插值变泥，细部不会把互补打散成均匀花点。需在关视野与视野核心区都看到两种材料关系。
3. **无彩**：覆盖样本以环境色角色 RGB 最大通道差约 2 以内作为无彩诊断口径；角色保持原样。区域与材料读法仍靠轮廓、分布、面差和响应成立，不能靠名字过关。

每族须覆盖当前三材料中至少两种组合，三族合起来覆盖全部底材/覆盖角色及两份空间预设；程序组合检查可更广，人工只对预声明的代表路线与失败样本作判断。调优种子和未预看种子分开登记，不用“换一张 R”的确定性步进冒充随机抽样；不拒绝或隐藏失败结果。记录同一路线的进入/经过/离开视口，辅以全图；未经过的组合和高/低视野边缘明确记缺口。

**不随构成变化的闸门：** 玩家帧散列、空间可达与视野遮罩保持；洞内 RGBA 始终纯黑且不透明，材质/碎屑/反射不能跨入；ID/标签重命名输出等价。以上成立只允许报告实现合规，不能替人签审美 PASS。
