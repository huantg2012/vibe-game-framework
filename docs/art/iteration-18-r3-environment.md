# I18 R3 环境模型与动作交接

状态：IMPLEMENTED，内部图像/类型检查已执行；人的审美与实战终审待定。用户授权重新评估所有基底，不引用旧美术 skill/HOW。

## 生产更改

- 墙门框：唯一门框身份，沿墙缝的双梃、残余门楣、交错吞合页。低档保留门结构，中档内部出现错层，高档间断门楣与多层闭合页。实际 windup 收口，strike 向地侧伸出，recover 回收；核在可走地侧缝，不画在墙内不可打面。
- 墙锈：墙内搭接矿化壳片，低档锈质、较高档褶层取代原材。苏醒时壳缝张开，攻击时层片朝正常方向外掀。并非门框换色。
- 菌毯：重写 field 拓扑为非对称棚状菌褶团，带短褶缝/鳃片方向；污染越深，原来的褶层越错位分裂。去掉旧同心团块。菌毯现与油膜共享生产挂载、危险 footprint 接口。
- 油膜：保留可复现的聚珠/沾抹/薄滩种子映射与液体拓扑，整体表面改成密实暗液、短断反光、张力边，避免随机青点成为主体。结构污染仍由 topology 档位控制。
- 灰幕：重写 field 拓扑为重叠破损沉积层片，短横层纹与横向剪动，不再是菌毯或油膜的另一种配色。
- 余响：重复的压力痕与错相回纹；高档失去共同圆心、出现相反方向回折。
- 散光：错断的窄光束、断口折向与次生光段；三档由少量基本射线逐步改写为多重折向。删除首轮过于规整的虚线束。
- 间距：原本可对应的接缝被重复、侧移和压缩；低档保留平行关系，高档相邻段落的错位与重叠更明显。不是实体小怪，也不使用云朵代理。

## 接口与动作

- 世界边缘 1px；材质以 2–4px 相连簇组织，3 主阶 + 深缝。异常组织偏灰青绿，不以全身高饱和亮青覆盖。
- 墙读取 pose.attack/pose.activity；自主周期 2400ms。地表材质自主周期 2400ms，液体实际形变保留 PAINT_BREATH=0.002，与 Host 现有计费脉冲一致；休眠时停止形变。
- 占空在 Host 实时 live rectangle 内绘制，活动增加形变/明晰度、苏醒逐步展开，休眠仍留淡痕。不会伪造近战攻击姿态。
- 所有漆输出 field 推导的 stepFloors。活面读取 Host isPaintFloorActive，死核失效范围降为暗残痕，活 tile 有低对比材质铺底，避免呼吸收缩后看起来完全干净却计费。高频像素不逐个查询 Host，使用每 tile 缓存。
- 非油丙由 bing.ts 代理同一新生产挂载；避免检视器与出击出现两套模型。
- 消亡、核数量、危险计费、音频由 Host/部署工程负责。美术不引入新的伤害规则。
