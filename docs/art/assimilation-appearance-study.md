# 同化形象：同一个人逐渐带回异源组织

以已接入的 A「短摆工装」为母体，在身体表面长出当地类人的组织关系：晶纤收束成有方向的承力束，破膜在关节之间拉成有厚缘的片面。变化同时涉及体块、材质响应和次级动作；多个来源留在不同身体区域，不把颜色平均成一种脏色。归返后同一组组织仍在身上，净化点的轻微感知异常只作从属反馈。

本文件是[体验打磨第三项](../tasks/rift-experience-polish-2026-10-19.md#3-同化形象角色逐渐偏向当地人形污染体后续)的美术提案。强度、来源累计、来源数量上限及疗愈数值由唯一[同化系统 spec](../specs/system-assimilation-healing.md)承担；这里的量级是 DEV 试样目标，不能直接变成新的机制或存档合同。需要用户看动态小样后确认。

## 开工闸门：本质、形体与世界输入

**本质锁。** 这是尚未被完全覆盖、仍维护行装并主动行动的幸存者；外来组织正在利用人的原有表面和关节生长。要求保留人的动作控制、装备构造和部分可辨的原材，排除直接换敌人、身体分裂、长出独立肢体、变成重甲职业或全身自发光。成立的形体范围包括沿衣缝收束的筋束、跨原有关节的片膜、贴体的薄层积片；它们都依附同一人的骨架。本轮先用已有类人对应的前两种验证，未替用户锁定额外第三家族。

**载体与相机。** 世界空间、脚底接地的 A 人物。继承正交相机 direction `[19,24,30]`、约 34° 俯角、64×80 透明画布、脚点 `[32,66]`、源高 1.665m；运行时不旋转整张 sprite。Rift 身体碰撞仍为 20×20。净化点沿原母型相机与帧系，同源身体区域必须在两个场景中对应。

**世界输入六问。**

- 谁造：工装和工具属于仍在维护生活的人；异源组织没有人类工匠。
- 材料从哪来：布、旧铁和背负结构已有；新增组织借当地类人使用的纤维或膜材料侵入，不凭空加宝石、饰物或武器。
- 什么工艺：工业接缝原本服务穿戴，外来纹理则沿自己的方向拉直、粘连或包覆；两种秩序应同时可见。
- 维护状态：旧服仍完整够用，污染不等于任意破衣或新增伤口；疗愈后要能回到同一套工装。
- 光从哪来：保留真实肩灯、环境灯和场景遮挡；组织以方向性受光显形，不用额外补光将其点亮。
- 颜色意味着什么：原材色、当地材料色和污染活性分开。蓝紫/膜红首先是来源材质；不把颜色变化本身当作同化全部内容。

**三个参考锚点。** A「短摆工装」学帽、背包、分腿、持具与单肩灯的身份关系，不学比较页检视光；晶化林床 `human_remnant` 学有方向的束、分叉和材料面，不学长肢、敌人猎食姿势与敌方攻击；破膜盆地 `human_remnant` 学支点间的连片、厚缘和回缩，不学整副敌人骨架与轮廓。三者均是本项目现有实际产物，未追加外部游戏皮。

**落地底。** 晶化林床 seed156、破膜盆地 seed82、余烬脊 seed92 的中污染真实场景，以及现行 Last Light 净化点。优先真实 960×640 镜头；纯色底与 3×局部仅作查错。

## 身体变化的尺度

先做能在正常镜头读到的两三块组织，再做局部材料。不能用几十颗随机点代替形体。

**大尺度：原有质量向局部集中。** 胸身—收腰—分腿的总关系保持。晶纤在非持具侧肩背形成一条上重下收的斜向牵拉，沿上臂及侧腰延续；破膜在肩背与髋外侧形成偏心面，边缘轻微离开布面。高同化时，新增轮廓最远只超出原身体 1–2 个原生像素，不增高帽顶、不扩大背包、不填平腿间空隙。至少在正、侧两个方向之一能读到组织改变了局部厚度，而不只是衣服上有花纹。

**中尺度：两种组织各用自己的构造。**

- 晶纤：每个主区域 2–3 条相连的束；单束约 2–3px 宽、6–12px 长，中间留窄暗槽。束在肩、肘外侧或腰带上方发生一次岔接，亮面随受光方向改变。禁止规则条纹覆盖全身，也不把每束拆成悬空像素。
- 破膜：主面约 4×6px 至 5×8px，跨两个原有支点拉起；面内有一处较宽暗折，局部 1px 厚缘翻回暗面。先读出片面，再读出褶皱；禁止像贴纸的平色三角或整片糖果亮膜。
- 两者都先改变局部朝向、凹槽与反射宽度，再调 albedo。材料变暗时保留轮廓与邻面的差，不能把侧身再次压成黑柱。

**细尺度：有位置才有细节。** 只在组织末端、卷缘与旧布接缝加入少量短纹；不加随帧随机噪点、星光、粒子雨或全身青绿裂纹。

**连续强度。** 以归一化同化 `u=A/100` 连续驱动覆盖、厚度与动作幅度；可用平滑曲线 `s=u*u*(3-2*u)` 起步，具体曲线由动态小样校准。提议最高覆盖可变布面约 45–60%，帽、灯、带扣、工具、手与靴底不计入分母。A=25/50/75/100 只是截帧检查点，禁止四档换皮。A 接近零时组织从原有接缝附近开始，A 上升时同一块组织长大、压厚并连接，不能每次换一批位置。

## 跨世界混合：同一身体保留不同来源

混合单位是身体表面的连续区域，不是整个人的平均颜色。区域至少区分左肩背、左臂外侧、左右胸腹侧面、左右衣摆与腿外侧；背包、灯、持具链和脚底属于保护区。区域随身体转向和动作，不贴屏幕坐标。

同一个人的初始区域种子固定。来源选择由来源谱确定；每个来源先占自己稳定的一两块区域，再随其影响扩大。晶纤留下长条方向，膜留下宽面，交界处允许一段束从膜边下穿出，但不把两种微纹理同时叠满同一个像素。新增世界不能重抽旧区域；权重接近时不能每帧交换“主来源”。

首个混合样例指定为：晶纤占左肩背—外臂，破膜占右腰侧—衣摆；前胸保留一条可读的工装面，背包双带仍可追踪。这是检查混合语法的固定夹具，不是所有玩家永远左蓝右红的世界规则。第二种来源加入后，第一种应在相同解剖部位仍能被找到；去掉色相后也应留下束与面的差异。

本轮先证明两个已有本土类人家族；同一家族在其他世界使用同一组织规则与世界材料参数，不画专属套装。余烬脊目前没有已核实的当地人形材料模板，因此作为**携带既有混合进入第三场景**的验证点；不能把现有两类强行冒称余烬脊的当地类人。以后新增家族要补一份结构规则及小样，不能仅由世界名猜皮肤。

视觉预算应限制同时精细求值的组织家族数量，不能因此静默丢弃来源记录。若机制允许超出两个来源，第三来源宜占剩余连续小区域；更少的可辨面积如何折叠由 Design 与 Code 在来源谱方案中说明，本稿不承诺在约 500 个身体像素中无限辨认历史世界。

## 动作：逐渐出现材料自己的节律

先保留全部脚接触、行走距离相位、转向输入、握点和攻击时序。改变的是身体上非关键部位的附随动作，不给玩家制造额外输入延迟或假前摇。

- 晶纤逐渐抑制非持具肩的自然摆幅，肩背束以同一方向牵拉；停步时组织比布更快绷住，形成短促的收束感。静息的明暗移动沿束传播，整个身体不能同步亮灭。
- 破膜在转向/停步时保留一次较慢的回收，末端约落后 80–120ms，最大偏移 1px；不是果冻式全身弹跳。局部暗折随着卷边展开而移动。
- 混合时两种次级节律同时存在于各自区域。最高强度下，非持具侧肩/领口的投影偏置不超过 1px；帽、肩灯和整个持具臂的锚点保持原轨迹。若没有可独立驱动的骨骼/部件权重，先只动组织，不伪称已实现姿态蒙皮。
- 挥击期间始终保护肩—肘—腕—真实工具链；受击白闪仍沿实际身体 alpha，不能将组织残留闪到身体外。碰撞、受伤与命中没有新节拍。
- 动作幅度随同化连续缩减；普通停步只停止附随运动，不表示同化自愈。暂停时所有次级时钟冻结，恢复不能追补一段墙上时间。

这一步需要看到“原动作上的异源材料”，而不是给同化角色另放一段敌人动作。

## 归返与疗愈

归返第一帧保持同一来源、同一身体分区和强度，接受净化点自己的光照。暖炉光照在膜片或纤维上时材料应重新受光，而不是把 Rift 的蓝红照明烘在身上。净化点与 Rift 的母型虽使用不同帧系，分区语义必须相同。

主观异常只取一条可验证的效果：**已有暗部材质出现极弱的延后辨认**。优先利用已经在画面中的深层、低对比表面；沿来源方向的细纹比真实转身迟 60–100ms 消退，峰值亮度差约 2–4/255、最多 1 个原生像素的局部位移。由原场景亮度/深度裁切，不能穿实体、显露未知区域或创造新轮廓。纤维来源偏纵向细纹，膜来源偏少数宽暗折；它们来自同一来源谱，但不将世界材质贴满建筑。

近处可行走地面、平台断沿、设备操作边、肩灯、人物与文字全部排除。无全屏变色、色差描边、镜头抖动、假敌人、假拾取物或新光源。看不出上述迟滞时，先检查其真实上下文；不要以提高全屏对比补救。小样可以暂关闭这一层，角色本身仍必须成立。

疗愈只消费实际前后状态的视觉投影：在同一身体坐标中，卷缘先收平、束的凸起变浅，覆盖边界再沿原接缝退回；剩余部分仍保留原来源。用约 1.2–1.8 秒的平滑展示连接前后值，不改机制提交时机，也不在无疗愈事件时慢慢洗白。多次疗愈不得每次重抽纹理。归返主观层同步下降；A=0 时形体、动作附加与主观层都精确归零，恢复原资产输出。

## 制作路线与性能约束

**路线建议：共享母型的稳定表面坐标 + 有限区域材料求值。** 现有 `player-last-light-presentation.ts` 已有可见像素位置、法向、albedo、depth 及持具分层，先在这条已有稀疏像素循环中合成组织，再走原受光。让同一表面坐标同时约束覆盖、槽/卷缘、法线和次级位移，避免每项各写一张无关噪声图。世界输入只给材料与组织参数。

**本轮首件范围已收窄。** 为控制实际成本，第一版使用已有位置/法向数据、逆 yaw 的局部区域和共享材料函数；动态限定为布面组织推进及左袖/衣摆的材料相位，真实步态与骨架不变。没有同源深度支撑时不扩张 alpha。此首件可以验证材料分区、来源混合、跨场景一致与持续疗愈；不能据此宣称完整骨架蒙皮、真实姿态改变或外轮廓形变已经完成。后续只有看图证明体内组织不足时，才扩到下述辅助数据路线。

为了跟随关节，优先从同源作者模型导出一次可复用的部位/静息表面坐标与保护权重。不得为每个世界、每个 A 值各导出完整 104/1035 帧；也不运行时重建 3D 模型。若先用现有位置图做小样，至少逆 yaw 到身体局部并分部位；屏幕坐标纹理和每帧重新采种均不可作为候选成品。

生产化之前需评估是否真正需要小幅外轮廓扩张：扩张像素必须同时拥有实体深度、法向和实际连接，不能只涂 alpha；若完整关系无法保持，先收回凸起，保留体内中尺度组织并明确“轮廓阶段未完成”。不能为 1px 视觉收益破坏已认可的遮挡和攻击臂。

建议给独立样片设以下**新增成本目标**，由 Code 测量，不把目标写成已达结果：

- 单角色，复用现有纹理上传；新增热路径 p95 ≤0.5ms，p99 ≤1ms，暂停/稳定输入时不重复构造材料或分配数组。
- 缓存只键入模型帧/部位与有限组织模板，不以浮点 A、时间、来源任意组合无限扩张；连续 A 作为参数，不能量化成明显的几套皮。
- 初始辅助数据只准备本镜头需要的姿态，后续分批；新增解码/常驻数据目标 ≤8MiB，不预烘“世界数 × 同化级 × 动作”的图集。净化点 1035 帧需按需或稀疏辅助数据，不能直接乘上两张全尺寸 RGBA 图。
- 归返主观层优先复用现有合成过程；若必须增加 pass，最多一个低分辨率被遮挡裁切的 pass，单独计时，新增 GPU p95 目标 ≤0.5ms。平台/设备边界保护必须在上采样后仍成立。
- 样片提供同镜头效果开/关与来源数量增减对照，分别记预热、连续移动、转向、挥击、净化点合成成本。CPU 与 GPU 分开；无 GPU 查询能力时明确未测，不能用 JS 回调耗时代替。
- 既有 50ms 长任务与 I14/P49 保持开放。效果达预算并不说明整个游戏已达预算；超出本增量预算时先删主观层和微纹理，再优化求值，保留角色的大/中尺度差异。

本轮由 Code 运行模型导出、后处理与性能验证；Art 只定义输出及判断标准。没有外部生图请求，故不新增生成 Prompt、色板或后处理 config。已有母型资产不重写；辅助资产应留在独立 DEV 目录并有模型来源、尺寸、脚点和语义通道清单。

## 最小动态演示与判定点

一个正常尺度主视图，按同一人的连续经历演示；可在画外 DEV 控件冻结任意时刻，不设计新的游戏 HUD。至少包含：

1. **未同化 → 晶纤**：正常晶化林床走四向、停步、持具挥击；A 连续从 0 到 70，至少留 A=23、47、69 的中间帧。先看组织沿原身体长出，再与当地类人同尺度并置。不能以剧烈放大作为主验收镜头。
2. **保留晶纤 → 混入破膜**：同一角色进入破膜盆地，旧束留在原部位，新膜在另一连续区域增长；冻结总强度相同的晶纤、破膜和混合三态，检查差异是否超出换色。A 及来源连续往返，不在临界值跳壳。
3. **带着混合进入余烬脊**：更换场景光、走到亮暗交界并转身，旧材料在新光下仍各自成形；不声称余烬脊当地人形已完成。
4. **归返**：净化点同一角色原尺度，正侧背转向、行走到炉光与核心光之间；先关闭主观层看身体，再开启极轻异样。设备操作边和平台边缘应像原场景一样清楚。
5. **部分疗愈 → 再次疗愈 → 零**：保持角色站位和来源区域，使用真实每周期降幅的 DEV 投影；一周期后仍可见两来源，最终回到 A=0。停止演示后再次开启不得留下残色、位移或缓存旧皮。
6. **保护和负载**：最大强度下真实装备的挥击三阶段、受击、暂停恢复；同一循环开关效果测增量。演示状态全在内存，不读取、写入或迁移正式记录。

每段要留下 960×640 原图和一段连续实录；3×局部只能附在其后。画面判定问题是：仍能认出同一人吗；是否看见从布向当地组织的变化；两个来源分别在哪里；停步/挥击是否有错位；回到净化点是否感觉异常跟着人；部分疗愈是否沿原组织退去。回答要指出帧与部位，不能用实现说明代替观看。

## 书面自检与未完成边界

0. 因果链：幸存者仍主动行动 → 变化只能依附原身体与行装 → 当地纤维/膜的组织覆盖工业材质 → 体块、反射与附随动作一起改变。束、连膜、贴体积片都落在成立范围；本轮只验证已有前两族。
1. 载体：站立的世界对象，沿 A 原相机和脚点；主观层属于感知合成，不制造建筑或改变世界导航。
2. 1:1 第一眼：目标仍是戴帽、背包、单肩灯的人。A=0 原图已看；新增同化尚未生成，是否误读成新怪物/铠甲/袍服须实图判定。
3. 外沿：提案不加第三色描边；凸起使用当地材料受光面。新增边缘与暗边占比尚无资产可测，不能借旧装置阈值宣称通过。
4. 平色：束的槽与转面、膜的折面与厚缘必须分别可读；去色诊断是本轮反换色检查，实际输出待看。
5. 动层：只允许区域组织和非关键附随运动；灯、帽、持具链、脚接触与真实攻击时序保护。未改变装置结构。
6. 色：连续 A 母型与已接世界材料使用现行例外；无新 hex、无组织自发光、不把历史像素色板重新套给 A。
7. 相机：全程沿现行母型投影，没有混入 45° 装置相机或正对 10° 相机。
8. 落地底：三世界与现行净化点；不以黑底判断可读，不旋转整张 sprite。
9. 薪柴容器：不涉及。
10. 抽卡：本轮提供一条待验证的组合路线，不替用户锁方向；未开展形体候选抽卡，也不把三张换色图当三张卡。
10b. 世界观：工装仍被维护、单灯仍可用，外来束/膜在人的构造上产生另一套秩序；若只像通用感染皮肤，必须回组织关系重做，不能继续加污斑。
11. 孤立像素：要求组织始终连接实体，生成后须逐格检查；目前没有新资产，尚未执行。
12. 活层：不画规则亮矩形、成对眼、整圈荧光。正常镜头的读法尚待动态样片。

本稿不触碰游戏内 HUD、DOM 或面板视觉；U1–U12 的菜单载体、字号与布局项不适用。若后续改动这些表面，必须另行执行 `in-game-ux`，不能以本稿替代。当前只完成基线图像核对和设计提案；动作效果、疗愈连续性、增量性能与用户判断均未验证。
