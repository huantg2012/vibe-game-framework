# 同化形象：同一个人逐渐带回异源组织

以已接入的 A「短摆工装」为母体，随同化增长改变全身材料、真实肩背/胫肘体积和承重姿态：晶纤收束成有方向的承力束，破膜在关节之间拉成有厚缘的片面。A=100 时全角色主要可见面约 75–90% 受影响，头前探、胸背前屈与肩高差必须在正常镜头可见。多个来源留在不同身体区域，不把颜色平均成一种脏色。归返后同一组组织与姿态仍在身上，净化点的轻微感知异常只作从属反馈。

本文件是[体验打磨第三项](../tasks/rift-experience-polish-2026-10-19.md)的唯一美术提案。强度、来源累计、来源数量上限及疗愈数值由唯一[同化系统 spec](../specs/system-assimilation-healing.md)承担；这里的量级是 DEV 试样目标，不能直接变成新的机制或存档合同。需要用户看动态小样后确认。

**当前用户结论：首件 50/100，纹理可保留，A=100 只有局部异化、没有模型结构与姿态，整体不合格。** 该反馈替代本稿首轮“可变布面 45–60%／骨架不变／帽包手腿大片保护”的保守范围。此次只做一条连续增强方向，不重开三套候选，也不重新绘制已认可的束/膜纹理。身份靠帽形、面罩开口、单肩灯和工具读法保持，不再要求保留一套完好工装。

## 开工闸门：本质、形体与世界输入

**本质锁。** 这是仍主动控制身体的幸存者；外来组织正在利用人的骨架、行装与关节重排承力。要求双脚可承重、手仍能握具、灯仍工作，不要求原材完整。排除直接换敌人、身体断裂、独立新肢体、重甲职业和全身自发光。成立范围包括受拉的脊束、跨关节的折膜和附着的薄层积片；本轮只用前两族，它们必须改变真实体积与姿态，而非停留在衣缝花纹。

**载体与相机。** 世界空间、脚底接地的 A 人物。继承正交相机 direction `[19,24,30]`、约 34° 俯角、64×80 透明画布、脚点 `[32,66]`、源骨架高 1.665m；前屈允许站立投影变矮，不自动放大填满画布。运行时不旋转整张 sprite。Rift 身体碰撞仍为 20×20。净化点沿原母型相机，同源部位与形变规则在两个场景中对应。

**世界输入六问。**

- 谁造：工装和工具属于仍在维护生活的人；异源组织没有人类工匠。
- 材料从哪来：布、旧铁和背负结构已有；新增组织借当地类人使用的纤维或膜材料侵入，不凭空加宝石、饰物或武器。
- 什么工艺：工业接缝原本服务穿戴，外来纹理则沿自己的方向拉直、粘连或包覆；两种秩序应同时可见。
- 维护状态：人仍在使用原行装，但高同化时原材大部分已变质、包覆或收束；不是任意破衣或新增血肉伤口。疗愈后能沿同一形变回到原工装。
- 光从哪来：保留真实肩灯、环境灯和场景遮挡；组织以方向性受光显形，不用额外补光将其点亮。
- 颜色意味着什么：原材色、当地材料色和污染活性分开。蓝紫/膜红首先是来源材质；不把颜色变化本身当作同化全部内容。

**三个参考锚点。** A「短摆工装」学帽/面罩/单灯/持具的身份与实际承重，不把完好衣服当身份要求；晶化林床 `human_remnant` 学骨盆—肩—肘的成束承力、肩高低与胸颈前移，不学长肢、吞腿和敌方攻击；破膜盆地 `human_remnant` 学肩—肘—髋支点间连片、折面厚缘及不对称垂落，不抄完整敌人轮廓。三者均是本项目现有实际产物，未追加外部游戏皮。

**落地底。** 晶化林床 seed156、破膜盆地 seed82、余烬脊 seed92 的中污染真实场景，以及现行 Last Light 净化点。优先真实 960×640 镜头；纯色底与 3×局部仅作查错。

## 身体变化的尺度

先用没有纹理的轮廓与灰材检查头、胸、肩、肘和胫的关系，再将已获认可的纹理放回。只增加覆盖面积仍不完成本轮要求。

**单一连续方向：上身向前收束，肩背与肢体长出异源承力。** 参数均在作者局部坐标：+Y 向上、+Z 朝面部、+X 为灯/持具侧。`u=A/100`，形变总量 `s=u*u*(3-2*u)`；纤维权重 `f`、膜权重 `m` 归一且 `f+m=1`。下列是 A100 的源几何初值，各项乘 `s`，不在 25/50/75 处切换模型：

- 胸身绕约 `[0,.76,0]` 的骨盆上缘向 +Z 前屈 `16°+4°f`。髋以下不整体前倾，不能把全人斜着推过去。
- 头随胸身变换，再相对胸身前探 `.08m`、下沉 `.025m`；颈关节抵消约 40% 胸身俯角，保留面罩朝向，不能把脸完全埋进胸口。侧向目标：帽中心较 A0 前移约 4–7px、下降约 2–4px；正常镜头可直接辨认前探。最终以投影校准，不叠加两次前移。
- 左肩比基准高 `.04m`，右肩低 `.04m`，合计高低差约 `.08m`/2px；连续过渡到颈根和上臂，不能在肩缝切断。双肩仍从同一胸廓长出，颈椎不折成直角。
- 背包随胸身前屈并贴背，外壳可变质并受组织包覆；不留一个原姿态的包悬在新背后。帽壳、灯壳、带扣可变质但保留主要构造。
- 双膝只增加约 3–5°承重屈曲，小腿外侧允许增厚；脚掌按原行走接触固定，不能靠下移整张图制造弯腰。必要的髋膝补偿由同一关节链求解，不能使腿长在动作中伸缩。

**晶纤组织。** 2–3 条有体积的脊束从左侧腰/背带旁通向抬高的肩，再接肘外侧；一条继续在胫外侧形成同方向的纵脊。不是另加铠甲：束根宽约 `.06–.10m`，肩背最大凸起 `.07–.09m`，胫/肘最大凸起 `.04–.06m`，按当前比例约 1–3px。束之间是凹槽和仍被压住的旧表面，不挖穿躯干。至少一处肩背峰与一处肘或胫突改变真实外沿；现有细束纹理服从这些凸面，不再贴在平坦工装上。

**膜组织。** 肩背—肘外侧—髋为三个支点，形成两块相接但偏心的实体薄面；胸身仍在下面，不拆成敌人的空架。膜中央离旧面约 `.04–.06m`，外折/厚缘最远 `.07–.09m`，厚约 `.02–.035m`；肩后、腰外侧和膝外侧至少两处轮廓可见。卷边是有回面的小体积，不是一条涂亮的线；边到支点的收紧关系比新增皱纹重要。禁止长成披风、翅膀或裙罩，肘和腿之间的行动间隙仍存在。

**混合组织。** 共用上面的连续骨架姿态；肩/上臂/一侧胫以脊束主导，胸侧/另一肩后/腰髋及另一腿以膜面主导。两种组织都能延伸到包、帽壳和手背，转身后仍有来源对应。交界可见束压在膜下、膜绕束收边；不在同一像素平均红蓝，不将两副敌人身体对半拼接。

**覆盖分母改为全角色。** 统计当前视角全部人物不透明表面，含帽、脸部面罩结构、灯壳、包、双手、衣裤与靴；仅外部武器、落地影不属于人物表面。不先剔除深色像素、背面或大块设备。A100 目标 75–90% 表面以足量异源材料呈现；以材质混合权重 ≥0.5 统计，不能以几乎不可见的权重凑覆盖。正/背/左右斜侧均检查，视角遮挡带来的差异须列出。保留的原材是零散断续痕迹，不是一件完整棕色外衣配两块彩色补丁。

真正不可改的是灯镜的发光语义、面罩的单一暗开口、掌内握持接触及承重足底的小范围；这不等于保护整个头/手臂/靴。灯壳能长膜，镜口仍发光；手背能变质，手指仍围住工具；帽壳能被束/膜包覆，帽形与黑面罩仍可认；包体材料能变化，背负关系仍成立。保护区总面积以全角色计宜不超过约 10–15%，超过时逐项说明，不能用整块坐标截断扩大。

首件“全帽/包/手/靴逐像素不得变”的检查只适用于旧局部材料范围，本轮由上述功能性保护替代。更新检查定义后再验证，不为维持旧检查数字继续保留过大免疫区。

覆盖与姿态均从 A0 连续起步。覆盖中心固定；强度上升时范围、材质转面和体积沿原组织一起增长，A0 必须回到原模型/原材料。A=23/47/69/85/100 只是取样点。低值不能全人突然换色，接近满值也不能继续只有原来三块局部区域。已获认可的细纹样式保留，不加随机亮点、粒子雨或全身发光。

## 跨世界混合：同一身体保留不同来源

混合单位是身体表面的连续区域，不是整个人的平均颜色。区域扩到帽壳、胸背、包壳、双袖、手背、衣摆、双腿与靴面；只有上述功能性小区保护。区域随真实身体表面与关节变换，不贴屏幕坐标。

同一个人的初始区域种子固定。来源选择由来源谱确定；每个来源先占自己稳定的一两块区域，再随其影响扩大。晶纤留下长条方向，膜留下宽面，交界处允许一段束从膜边下穿出，但不把两种微纹理同时叠满同一个像素。新增世界不能重抽旧区域；权重接近时不能每帧交换“主来源”。

首个混合样例沿现有“上身束、腰摆膜”扩展：束连接到帽后、包肩和一侧胫；膜包到另一肩、胸侧、髋膝与另一靴面。保持同一侧身可见两类组织；背包双带可以被改写，但其受拉方向仍可追踪。此夹具不规定所有玩家永远左蓝右红。第二来源加入后，第一来源仍在原解剖位置，不被最后进入的世界覆盖；去掉色相后仍有束的凸脊与膜的回面差异。

本轮先证明两个已有本土类人家族；同一家族在其他世界使用同一组织规则与世界材料参数，不画专属套装。余烬脊目前没有已核实的当地人形材料模板，因此作为**携带既有混合进入第三场景**的验证点；不能把现有两类强行冒称余烬脊的当地类人。以后新增家族要补一份结构规则及小样，不能仅由世界名猜皮肤。

视觉预算应限制同时精细求值的组织家族数量，不能因此静默丢弃来源记录。若机制允许超出两个来源，第三来源宜占剩余连续小区域；更少的可辨面积如何折叠由 Design 与 Code 在来源谱方案中说明，本稿不承诺在约 500 个身体像素中无限辨认历史世界。

## 动作：逐渐出现材料自己的节律

保留行走距离相位、转向响应、承重脚接触、攻击开始/实击/收回的真实时间。当前姿态由“原动作骨架 + 连续同化形变 + 附着组织”共同计算，不是新放一段敌人动画，也不再只做衣摆材料相位。

- 静息也保持上节的前屈/头前探/肩高差；A100 停住时必须与 A0 有明显姿态区别。肩背组织产生极缓的局部张力，幅度约 `.01–.02m`，小于固定形变；不能靠全人缩放呼吸。
- 行走时晶纤主导侧的肩摆幅减少约 25%，肩背随实际脚落地出现一次有限收束；头—胸的相位差上限约 40ms。脚步、手电瞄向和输入没有额外迟滞。
- 膜的支点使用当帧肩/肘/髋位置，只有支点之间的折面延后约 80–120ms，最大偏移约 `.03m`。停步后最多一次回收，不把手臂、头或整个人拖成果冻。原已认可的布面相位继续作为次级细节。
- 混合不平均出一套“中性抖动”：同一胸肩姿态上，束与膜分别响应。源权重小改只调连续幅度/局部组织，不切换整套身体。
- 灯壳、镜口和实际灯源同取形变后肩部变换；上臂/肘/腕与手使用同一关节链，工具继续挂最终腕。不能把新身体渲染在旧灯源或旧手的旁边；不能只形变身体 RGB 而保留旧深度、法线和影子。
- 持具手背可受影响，真正保护的是握紧关系和工具轮廓。挥击仍沿正式时序；接触相位须检查工具实际末端与原命中意图的对齐。需要保留实击位置时，对变形后肩与原接触目标求解手臂，不拿拉伸前臂或视觉提前命中补救。
- 受击反馈沿实际变形后的身体 alpha；脚底、手与灯连接不穿插。暂停冻结所有附随时钟，普通停步不降低同化；疗愈才让固定姿态、组织体积和材料一起退回。

## 归返与疗愈

归返第一帧保持同一来源、身体分区、组织体积与前屈强度，接受净化点自己的光照。暖炉光照在膜片或纤维上时材料应重新受光，而不是把 Rift 的蓝红照明烘在身上。净化点与 Rift 的母型虽使用不同帧系，分区与形变语义必须相同。本轮最小实物先验证站立/行走/挥击；坐姿不能沿用旧首件“坐下变回原人”冒充完整归返，若未接必须明确标为未实现，不把那一镜头算完成。

主观异常只取一条可验证的效果：**已有暗部材质出现极弱的延后辨认**。优先利用已经在画面中的深层、低对比表面；沿来源方向的细纹比真实转身迟 60–100ms 消退，峰值亮度差约 2–4/255、最多 1 个原生像素的局部位移。由原场景亮度/深度裁切，不能穿实体、显露未知区域或创造新轮廓。纤维来源偏纵向细纹，膜来源偏少数宽暗折；它们来自同一来源谱，但不将世界材质贴满建筑。

近处可行走地面、平台断沿、设备操作边、肩灯、人物与文字全部排除。无全屏变色、色差描边、镜头抖动、假敌人、假拾取物或新光源。看不出上述迟滞时，先检查其真实上下文；不要以提高全屏对比补救。小样可以暂关闭这一层，角色本身仍必须成立。

疗愈只消费实际前后状态的视觉投影：在同一身体坐标中，卷缘收平、束的凸起变浅，胸背与头部随同一强度逐渐回正，覆盖沿原接缝退回；剩余组织保留来源。用约 1.2–1.8 秒平滑连接前后值，不改机制提交时机，也不在无疗愈事件时慢慢洗白。多次疗愈不重抽纹理。归返主观层同步下降；A=0 时几何、材料、动作附加与主观层归零，恢复原输出，不能仍留驼背或残色。

## 制作路线与性能约束

**路线改变的可验证原因。** 上轮表面 mask 决定了可改范围，平面着色无法改变被原 alpha/深度锁死的肩背、头与承重。因此保留已认可的材料函数，改由 `buildActor` 同源几何先形变、再按原相机像素栅格化；一次共同更新轮廓、法线、深度、灯锚、腕与投影。这是一个人的表现源改造，不是重开三维游戏。

**同源变换合同。** 作者模型局部 yaw0 → 当前动作 → 同化关节/形体 → yaw 与原相机 → 64×80 G-buffer。法线从形变后三角形或正确变换重新计算；帽、包、灯、手与组织使用同一骨架/部位变换。接触影/投影胶囊也从最终关节导出。局部材料使用静息部位坐标，不能在形变后跟屏幕滑动。轮廓、深度或附件关系未完成时，样片必须保留失败状态，不能退回平面染色并宣称完成本轮。

**最小实物。** 先做同一人物的正斜/左右侧/背向站姿、两个真实承重相位及三段挥击关键姿态。A0、A50、A100 与双来源混合用于固定镜头检查；随后用同一参数函数连续驱动任意 A，不将这些检查点做成三档皮。不同 idle/walk 源几何可能拓扑不同，不能直接跨姿态顶点线性混合；同一姿态内的连续形变需保持拓扑/部位对应。首件不必预导全部 1035 帧，但未覆盖动作不能获得完成声明。

**性能进入路线选择。** 作者 CPU 离线栅格可以产出证明图；若单帧重烘耗时达到数毫秒到几十毫秒，它不能进入游戏每帧热路径。可复用有限姿态源网格/部位权重，以共享形变参数更新并在人物的小渲染目标中栅格化；或使用具有对应关系的有界形变数据。由 Code 选并实测，不预设一定要新增全屏 pass。不得按世界、混合比例和 A 值复制整套图集，不拿几个关键帧交叉淡化冒充真正连续几何。对 CPU 实时重建、GPU 局部栅格或有限缓存的选择，要先证明至少站姿到一步动作的实际成本与质量，再扩动作量。

建议给独立样片设以下**新增成本目标**，由 Code 测量，不把目标写成已达结果：

- 单角色，优先复用现有合成；材料求值新增 CPU p95 目标仍 ≤0.5ms，真实几何/栅格新增部分单独计量，CPU+可测 GPU 合计增量先以 p95 ≤2ms、p99 ≤4ms 为 DEV 选路目标。暂停/稳定输入时不重复建模或分配数组。此预算是新路线待测目标，不继承首件约 0.02–0.03ms 的材料结果。
- 缓存只键入模型帧/部位与有限组织模板，不以浮点 A、时间、来源任意组合无限扩张；连续 A 作为参数，不能量化成明显的几套皮。
- 初始辅助数据只准备本镜头需要的姿态，后续分批；继续以新增常驻数据 ≤8MiB 为首轮目标，网格/权重/深度缓存逐项列账。超过时先裁减重复姿态缓存与微细节，不能拿去掉满同化体块来满足数字。净化点 1035 帧不得直接乘上世界与强度数。
- 归返主观层优先复用现有合成过程；若必须增加 pass，最多一个低分辨率被遮挡裁切的 pass，单独计时，新增 GPU p95 目标 ≤0.5ms。平台/设备边界保护必须在上采样后仍成立。
- 样片提供同镜头效果开/关与来源数量增减对照，分别记预热、连续移动、转向、挥击、净化点合成成本。CPU 与 GPU 分开；无 GPU 查询能力时明确未测，不能用 JS 回调耗时代替。
- 既有 50ms 长任务与 I14/P49 保持开放。效果达预算并不说明整个游戏已达预算；超出本增量预算时先删主观层和微纹理、缩减缓存，再调整求值路线。高覆盖与正常尺度可见的几何/姿态是本轮目标，不能再次作为性能退让项被删掉。

本轮由 Code 运行模型导出、后处理与性能验证；Art 只定义输出及判断标准。没有外部生图请求，故不新增生成 Prompt、色板或后处理 config。已有母型资产不重写；辅助资产应留在独立 DEV 目录并有模型来源、尺寸、脚点和语义通道清单。

## 最小动态演示与判定点

一个正常尺度主视图，按同一人的连续经历演示；可在画外 DEV 控件冻结任意时刻，不设计新的游戏 HUD。至少包含：

1. **未同化 → 晶纤**：正常晶化林床走四向、停步、持具挥击；A 连续从 0 到 100，留 A=23、47、69、85 的中间帧。固定同一姿态、朝向和光源，先给 A0/A100 的正常尺度轮廓与灰材对照，再开已认可纹理；检查头前探、肩高差、脊束和胫/肘凸起，最后与当地类人同尺度并置。不能以放大或不同朝向冒充结构差异。
2. **保留晶纤 → 混入破膜**：同一角色进入破膜盆地，旧束留在原部位，新膜在另一连续区域增长；冻结总强度相同的晶纤、破膜和混合三态，检查差异是否超出换色。A 及来源连续往返，不在临界值跳壳。
3. **带着混合进入余烬脊**：更换场景光、走到亮暗交界并转身，旧材料在新光下仍各自成形；不声称余烬脊当地人形已完成。
4. **归返**：净化点同一角色原尺度，正侧背转向、行走到炉光与核心光之间；先关闭主观层看身体，再开启极轻异样。设备操作边和平台边缘应像原场景一样清楚。
5. **部分疗愈 → 再次疗愈 → 零**：保持角色站位和来源区域，使用真实每周期降幅的 DEV 投影；一周期后仍可见两来源，最终回到 A=0。停止演示后再次开启不得留下残色、位移或缓存旧皮。
6. **连接和负载**：最大强度下真实装备的挥击三阶段、受击、暂停恢复；检查新肩—肘—腕—工具、新肩灯和实际灯源、双足接触及新影子。同一循环开关效果测增量。演示状态全在内存，不读取、写入或迁移正式记录。

每段留下 960×640 原图和一段连续实录，3×局部只能附后。A100 的每个主要视角报告全角色分母、影响像素数、比例与保护区；至少一个正斜视和一个侧视的灰材图同时看见固定姿态与组织外沿改变。正常镜头若仍只读作“一个站直的人穿了彩色衣服”，本轮未达目标。头/胸局部位移、全身影响比例和新增体块分别记录，不用三者中一项抵消另两项。

画面判断还包括：帽形/面罩/单灯/持具是否仍认出同一人；两来源是否各有组织；手脚/光/影是否连贯；归返是否保留强同化；部分疗愈是否沿原几何和材料一起退去。回答要指向帧与部位，不能用实现说明代替观看。最后由用户判断整体完成度，不将数值闸门自动升级成审美认可。

## 书面自检与未完成边界

0. 因果链：幸存者仍主动行动 → 外来承力必须依附原骨架而不能吞掉操控结构 → 束/膜沿当地类人同源支点重排体积 → 前屈、肩高差、脊束/折面与材料共同改变。束、连膜、贴体积片都落在成立范围；本轮只验证已有前两族。用户反馈已证明只做局部表面不足。
1. 载体：站立的世界对象，沿 A 原相机和脚点；主观层属于感知合成，不制造建筑或改变世界导航。
2. 1:1 第一眼：A100 仍凭帽/面罩/单灯/工具识别，但不再是完好工装的直立人。上轮原图及材料稿已看，强几何稿尚待生成；需要用同角度正常尺度图判断。
3. 外沿：必须有真实肩背与胫肘/膜折凸起，不描第三色线；alpha、深度、法线和影子同源。新几何尚未测，不能借旧装置外沿阈值宣称通过。
4. 平色：保留用户认可的束/膜纹理，但纹理贴在真实转面上；灰材下仍须读出脊与回折。高覆盖不能成为整只平色或亮色人。
5. 动层：本轮允许真实人体姿态与组织体积改变。保护的是动作时钟、握具关系、承重接触和功能语义；帽、包、灯和手本身随关节变换，不冻结在旧轨迹。装置结构不改。
6. 色：连续 A 母型与已接世界材料使用现行例外；无新 hex、无组织自发光、不把历史像素色板重新套给 A。
7. 相机：全程沿现行母型投影，没有混入 45° 装置相机或正对 10° 相机。
8. 落地底：三世界与现行净化点；不以黑底判断可读，不旋转整张 sprite。
9. 薪柴容器：不涉及。
10. 抽卡：本轮提供一条待验证的组合路线，不替用户锁方向；未开展形体候选抽卡，也不把三张换色图当三张卡。
10b. 世界观：工装仍被维护、单灯仍可用，外来束/膜在人的构造上产生另一套秩序；若只像通用感染皮肤，必须回组织关系重做，不能继续加污斑。
11. 孤立像素：要求组织始终连接实体，逐格与几何连接共同检查；强几何新资产尚未生成，不能引用旧材料稿检查结果覆盖。
12. 活层：不画规则亮矩形、成对眼、整圈荧光。正常镜头的读法尚待动态样片。

本稿不触碰游戏内 HUD、DOM 或面板视觉；U1–U12 的菜单载体、字号与布局项不适用。若后续改动这些表面，必须另行执行 `in-game-ux`，不能以本稿替代。首件材料纹理已获用户局部认可，整体仅获 50/100 且要求返工；本轮强同化设计、连续几何、动作连接、疗愈与新增性能尚待实物验证。不得将首件的机器结果或此次文字设计记作整体完成。
