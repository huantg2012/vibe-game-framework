# I18 R4：气团、雾团、尘絮群

状态：实现与机器回归已交，正式实景与美术终审由 Director / 用户完成。用户授权直接制作并接入检视室和正式裂隙；不读取旧美术 skill/HOW，不增加外部生图审批。

## 三种形体的独立构思

气团（gas_mass）是体积。低档为有厚度的浑浊紧团，多个内层被共同轮廓包住；中档压缩时出现不贯通的暗缝和被分开的内层；高档外缘外胀时内部反向收拢，保留气体线索但失去可信的深度关系。材质以有限灰绿深浅阶形成相叠的尘气层，不使用光滑法线球面或三角面。

雾团（mist_bank）是悬浮薄层。低档有同向分流的长薄绦，层与层之间能看穿后景；中档薄层在不同高度错开、分流再聚；高档层带穿过自身后折返，方向不再一致。边缘采用短连续像素丝，不画成灰幕的地面沉积片，也不靠半透明球体堆叠冒充雾层。

尘絮群（dust_swarm）是离散群。低档为灰尘纤维与少量纸屑，在同一流场内聚集；中档前锋扫动、后部滞留，留出真实空隙；高档出现逆向流束和迟滞碎片。以 1–3px 纤维、2–5px 折屑组织，不能用全画布随机噪点或另一种雾球代替。

三档污染改变可见内层的组织与运动秩序；外部真实占据几何不随污染档位改变，以免视觉档位暗改危险距离。颜色负责材质，低档保留顺流原物线索，中档增加折缝/交错，高档内部逆行。余响保留；散光、间距仅供历史兼容，不进入新生产目录。

## 共享体积合同

部署工程提供 `src/systems/volume-presence.ts` 的共享 presence。真实危险、画面密度、脚下污染必须读取同一场；不把整个外接 AABB 当作无形危险。生产 renderer 优先使用 Host 权威帧，独立检视使用同一个纯更新函数生成帧。墙/VOID 由显式地形查询剔除。

内部观看最多两轮，提交三基体×三档×关键阶段的同一生产画法联系表，以及像素边界、危险可视性、确定性与性能测量。内部检查不代用户美术 PASS。

## 生产落点与第一轮修正

新三类统一通过 `ding.ts → volume-paint.ts`，直接读取 Host 的权威 `VolumePresenceFrame`。世界位置由 `frame.rect` 中心确定，核画在 `frame.coreX/coreY`，不会因核在某个活气瓣中移动而带动整团。独立检视使用固定出生范围与同一 updater，`volumeTimeMs` 支持零 delta 精确定位、回退与重建。余响和两个退休兼容身份保持旧画法。

首轮实际联系表发现气团的连续色阶类似等高线，雾团的等长水平丝纹类似织物；第二轮将气团内部改成 2px 卷涌、透隙与反向暗折，把雾丝改成断续、局部受光和不等长的纤维。尘絮的颗粒间隙压成深阶低密度悬尘，纸屑与纤维保持离散。整体危险处始终保留可读物质，材质没有制造隐形危险孔。

可见像素全部限制在共享密度场中，显式墙/VOID 查询同样作用于实体、亮核和脚下污染。脚下污染还读取真实危险阶段，静默或回散不会仍按包围盒挂污染。动态纹理键包含 subjectId 与可选 namespace，同 seed 的不同实体不互相覆盖或销毁。

## 复查入口

- `npx tsx --tsconfig tools/contam-preview/tsconfig.json tools/contam-preview/render-r4-volumes.ts` 生成同一生产 painter 的联系表、完整周期像素回归和绘制性能记录。
- `npm run check:volume-integration` 由独立 QA 验证 Host、受击、接触、脚下污染、时钟、暂停、seek 和纹理生命周期。
- 联系表目录 `docs/art/iteration-18-r4-volume-evidence/`：三行分别低/中/高；六列分别静默中点、聚集中后段、释放初段、释放中后段、消散中段、消散末段。原图为世界像素 1:1，`-2x` 仅最近邻放大。
- `checks.json` 记录真实画布绘制的 CPU 时间，不包括 Phaser GPU 上传、迷雾合成或浏览器帧调度，不能代替实战帧率。

本记录不代用户审美 PASS。新三类的形体与间歇性危险需要在检视室和实际裂隙中一起体验；单张联系表只能核材质和形态，不能证明运动节奏。

## 最终本地测量

第二轮联系表为 54 张独立档位/阶段画面，逐周期扫描 768 帧；585,741 个实际危险像素样本均有至少 48/255 的物质 alpha，未发现越过共享实体场或墙/VOID 的墨迹，重复渲染确定一致。CPU P95（本机，包含显式地形采样）在 192px 画布/160×144px 范围分别为气团 1.00ms、雾团 0.90ms、尘絮 0.53ms；384px 画布/352×336px 压力范围分别为 5.28ms、4.86ms、3.09ms。压力场景测量不等同正式单体体量。

当前可见局限：气团低→中主要增加局部暗折和异质内层，静态差异较轻；高档逆向内流需要实际播放观察。雾团中央空隙属于真实通行机制，保留明确的留空关系。内部两轮已结束，这些判断交正式实景与用户反馈，不在无反馈状态继续扩写方案。
