## 一、工作方式

**抽卡制**：每个美术对象一轮出 3 个方案，人看图拍板；不 pass 就根据反馈重抽，pass 才进入下一节点。
每一轮都记录「改了什么 / 为什么改」，避免多轮之后丢失上下文。

**产出要求**：全部 1:1 真实尺寸、透明底、硬边无抗锯齿，**可直接进游戏**，不是示意图。

**统一约束（贯穿所有节点）**：
1. 45° 伪 3D 视角（顶面压缩 0.55 / 侧面明暗 / 高度轴 / 接地投影）
2. 画布尺寸即层级：裂隙 40×56 > 净化器 32×44 > 核心 32×40 > 储藏·操作台 32×36 > 供奉台 32×32
3. 可见像素明度 ≥ 45（低于此值在 `#0d1114` 背景上等于没画）
4. 面与面之间必须有分隔线——2D 顶视的体积感来自分隔，不来自明暗渐变
