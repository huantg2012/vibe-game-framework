本轮改走「生图 → 像素化」管线（不再手写结构、也不再从素材反推经验改旧稿）
流程：生成 2D 素材 → 自动抠底 → 等比降采样 → 量化到项目调色板（冷灰 7 阶 + 主题色 ramp）→ 棱线提亮 → 接地投影 → teal 点缀动效。
已应用你放开的三项约束：
· 放大画布 32×36 → 48×48：实体像素从约 400 增到 1400+，方盒子终于有足够预算交代结构
· 靠特征物辨识：门缝渗漏、锁具旁状态点作为高辨识特征
· 可提亮：暗部目标从 50%+ 降到 45~47%（此前压到 92% 时形体被吞掉）
管线中修掉的两个坑
1. 生图偏亮 → 直接按明度映射会全落亮阶（实测暗部仅 0~3%）。加了直方图重映射 + 幂函数压暗。
2. 背景色不能假设 → 军用箱那张生图背景是纯白而非黑，按黑底阈值抠会把整张当实体（满屏填充）。改为四角采样自动判定底色。
