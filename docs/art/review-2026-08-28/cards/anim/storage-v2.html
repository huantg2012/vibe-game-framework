本轮修正
1. 形态 —— 全部走箱子 / 货柜 / 陈列架语言（v1 的罐类已弃）。
2. 主题色 —— teal 是「污染公约色」，不是某交互物的主题色。主题色 = 各交互物独有颜色，用于快速区分；主体结构冷灰，主题色落局部材质/五金。
3. 写实（v3 重点） —— v2 假在 box() 只画三个纯色面：表面无材质、无磨损、无反光，五金是像素点。v3 改用写实工具重建：面板含竖向反光带 + 顶部高光 + 底部 AO + 磨损斑；铆钉/锁扣/把手做立体（高光+本体+下缘投影）；结构缝带下缘高光（读得出厚度）；接地投影。
4. teal 只做点缀 —— 观察窗微光、缝隙渗漏、标识灯，小面积，不再是 v2 那种大面积内容物。
