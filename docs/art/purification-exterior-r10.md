# I30 R10 外景：被吞没的承重空间

**本质与形体范围。** 外景是净化点所在现实被外来规则挤压后的继续，不是绕据点摆放的景片。它要求厚度、承托关系、被遮掉的根和大面积未知。成立的形体包括剪切后仍承重的斜肋、错移的厚断面、沉入暗处的残层；排除悬浮小岛、等距齿列、地平线、全圈洞口和满屏细碎折带。本轮让「承重体裂开后仍连着」主导近层，让「尺度超过画幅」主导中远层。

**载体、尺寸与落地底。** 世界空间实体，沿 R9 固定斜投影 `X=x, Y=y+Z`；不是 UI。三张透明独立 plate 共用 `640×400` 原生画布，以生产室内、六装置及人物合成判断。外景一块完整断面大于人物与单装置，局部体量延伸画幅之外。近根接 `(227,151)`、`(394,273)`；接触区不随视差滑脱。中远层无全幅不透明底，背景由运行时承托。

**世界输入。** 据点由守着它的人以混凝土、灰泥、回收钢件维持；外侧沿这些原材继续却已被规则错位压坏。工艺够用、修补不齐，内侧有人维护，外侧无法维护。光来自实际据点功能光与接缝微光，远处无便利照明。遵循 `world.md` 当前 DEC-180：原材可有色相，入侵通过形变／不合原材的活层表达；不以旧「所有颜色皆污染」限制覆盖当前决定。关键词：孤立、微光、空旷、勉强维持、不可理解的合理。

**参考锚点。** `Rain World`：学巨大基础设施被层层遮挡时人的微小与深暗间隙；不学管道平铺、生态物种。`Darkwood`：学大面积未知与局部才能辨认的威胁；不学树林剪影。已锁核心 v6-B：学填面产生体积、光只在真实凹部；不复制其整体相机和历史色值。

**绘制与运行时合同。** 近层用大斜断体、少数厚切面和接触处碎裂；中层仅两三座巨大残面跨出画幅，细节靠凹腔和缺失推断；远层以大片暗色轮廓吞入背景。中央偏右保留暗隙供偶发存在穿过，不画眼睛、不加亮绿装饰。固定锚固下接人物驱动视差：近主体位移小，中／远相对室内逐级增大，同层结构不呼吸变形。纹理只在完整材料内，破口／层裂来自应力走向，不均匀撒点。
