# 统一物件的场景呈现

> TL;DR：武器与技能污染物共用存续报告的视觉语言。早期布卷与B独立窗口已由用户此次反馈撤下；本文件只描述当前实现。

净化点Tab报告在现有「装置／物件／潮汐／蜕变」结构中接入物件页；列表与检视分工，真实净化点和已锁装置仍在画面中。无基地负重、无第二份污染物清单、无装配按钮。供奉在供奉台，出击配置在入口备行。规则唯一正文为 `docs/specs/system-field-inventory.md`。

固定960×640逻辑画布，挂现有DOM根。背景与边缘使用当前场景侧边展开的噪纹、渐隐和半透明暗色，不加独立布卷、厚窗口框或新的材质体系。正文沿普通中文无衬线、低强调灰绿层级；标题不用大宋体。列表只在内容区滚动，动作和详情稳定，翻页范围必须对应完整可见行。

备行显示实际玩家贴图、一处武器挂位与现有动态主动/被动槽。玩家手侧到在手武器只有一条低对比细折线，建立归属；其余技能槽不串出多根装饰线。槽显示物件本体、动作键和消耗状态：武器为当前／最大耐久，技能为剩余次数，武器/品质/属性分别排，不造综合战力评分。

裂隙Tab「本趟拾获」保持同一层级，只呈现拾获和附近合法物件；装备在HUD按实际实例显示，主被动空槽也保留。总负重读数可说明装备占重，但不在拾获列表再插装备栏。

18类技能物件各有24px硬边实物图标，铁灰/矿物块与局部灰青污染色；供奉前后共用同一物体轮廓，以阶段/进度/余次说明变化。武器使用正式十款像素图标。图标资产源是 `src/art/contaminant-icons.ts` 和 `src/art/crowbar-pixels.ts`，不以大概念图代替实际图标。

内部实景核已发现并修正报告末行裁切及备行人物关联弱。截图与验证记录见 `docs/qa/iteration-19-unified-equipment.md`；最终审美待用户确认。
