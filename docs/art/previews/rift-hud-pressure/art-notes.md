# 负重与同化：像素标记样本

2026-10-19 · COH-F032 / COH-F054 · 仅美术试装，未接正式 HUD，待用户观看。

- 载体：视野边缘的屏幕读数；不是角色实际新装备，也不虚构监测装置。`pixel-marks.js` 两个记号均为 32×40 原生像素，透明底，只用整数矩形写色。
- 负重：布包体积随实际重量膨胀，松弛的绑带被拉直；近满的灰黄限定在承力带、扣与受力折线。体积变化、余量数字及有限色彩三者共同承担辨识，不画普通进度条。受力动作仅由一次性 `feedback` 参数触发，不以循环闪烁制造虚假死亡倒计时。
- 同化：头—肩—胸结构始终保留，外来几何面片由侧腹逐步连到胸、颈、脸。覆盖而不画血肉、内脏、骷髅或发光眼睛。组织状态在不增长时仍完整保留，只有 `growing` 才出现局部两像素侵入活动。
- 配色：全部来自 `docs/art/palette.json`。身体与布包使用灰阶，负重预警使用既有灰黄，侵入使用暗绿/绿；高亮青绿仅两个像素、仅增长动作，静态没有霓虹边圈。
- 参考锚点：Darkwood 取边缘读数和安静暗场；Signalis 取低色数的身体/物资表意；Hyper Light Drifter 取短小硬边记号。均不借其面板壳、符号体系、字体或配色。
- 展示：同一实景，`3 / 16 + 0%`、`14 / 16 + 60%`、`16 / 16 + 100%`。原生尺寸是主证据；整数最近邻放大只辅助看像素构成。

## 最短美术自查

1. 审美判断：已查看一次六图并列放大稿；负重从收束到膨胀、同化从完整到侵入有可见差别。用户尚未评价，不登记审美通过。
2. 游戏 UI 读法：无底板、无渐变、无悬浮解释、无条形第三生命栏；保持右上次级读数，标记与精确值并列。不拿纯图标要求玩家猜数值。
3. 同一世界：工业布包与无表情身体同用有限色面；污染体现为错误几何秩序而非随机脏点；画面不借装饰光制造存在感。
