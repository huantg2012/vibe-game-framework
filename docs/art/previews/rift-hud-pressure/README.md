# 右上角 HUD 简形像素样例

COH-F032 / COH-F054 · 2026-10-19 · 纯美术预览，待用户看图，未接入游戏。

用户否决上一版32×40材质贴图：太重、过于复杂。当前改为16×16图标，每状态最多两色、100个实心像素；不画体积、布纹、扣件、胸肩明暗。负重由包轮廓与一条装载线表示，同化由完整人形剪影和单侧替换色表示。每项收成单行，图标与名称数值并排；整个右上预览高度116→64px。

真实960×640场景沿用上轮生产截图。原生尺寸是主要判断依据；图册提供2倍局部与4倍图标最近邻放大。中文保留当前游戏字体，数字与图形使用硬像素。

固定机制：负重50%后连续减速、87.5%强调；同化跨局0–100，上限不等于死亡。预览两值独立，只有演示增长时推进一格侵蚀；受力反馈只做一次1px下沉。没有新增机制或正式输入。
