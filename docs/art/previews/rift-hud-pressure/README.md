# 右上角 HUD 简形像素样例

COH-F032 / COH-F054 · 2026-10-19 · 纯美术预览，待用户看图，未接入游戏。

按本轮六点反馈重画：负重为抽绳布袋，袋内从下向上连续填满；同化为小头、窄肩、垂臂和长腿的成人剪影，以连贯异色表示侵入。两项名称从HUD移除。薪柴沿用文字标识，三行统一24px标识列、数字右缘与24px行距，不随数字长度漂移。

原稿16×20，每状态最多两色。延长高度用于成人比例，满载由实心面积表达，因此原100像素预算改为128（实测最大114）；仍无体积明暗、布纹、扣件、外框、渐变和半透明像素。固定960×640实景中总占位112×68。原生尺寸是主要判断依据；图册提供2倍局部与4倍图标最近邻放大。中文保留游戏字体，数字与图形使用硬像素。

固定机制：负重50%后连续减速、87.5%强调；同化跨局0–100，上限不等于死亡。预览两值独立，只有演示增长时推进一格侵蚀；受力反馈只做一次1px下沉。没有新增机制或正式输入。
