# 改写体 · 程序化占位（俯视 4 向）

对照：`docs/art/demos/entity-rewriter/VERDICT.md`（渲染崩坏 ~50%，强不对称）、`docs/art-direction.md` §5.2、渗透体占位 `src/scenes/boot-scene.ts` `generateEnemyPlaceholders`（只读：24×24 不对称多边形 + 4 点 `#1aad96`，旋转表达朝向）。

本 Slice **不要等** Midjourney / 管线。Code 按下面整数格画 4 张纹理。碰撞仍用现有 `BODY_SIZE` 20，不改手感。

## 画布与朝向

| 项 | 锁 |
| -- | -- |
| 画布 | **32×48**（宽×高），透明底，`image-rendering: nearest` |
| 锚点（世界位置对齐） | 画布 `(16, 30)` |
| 纹理名 | `placeholder-rewriter-down` / `-up` / `-left` / `-right` |
| 朝向 | 跟 `Facing4`。**禁止**一张图旋转——崩坏在身体右侧，旋转会把溶散甩到错边 |
| 个体变体 | 本 Slice 只画 **爆发散射型**（VERDICT 第一张）。纵轴溶解型合法，不做 |

本地坐标：原点 = 锚点映射后的身体中心。`+F` = 面朝方向，`+R` = **身体右侧**（面朝方向顺时针 90°）。

| `Facing4` | 画布 `+F` | 画布 `+R` | 原点 `(ox, oy)` |
| --------- | --------- | --------- | --------------- |
| `down` | `(0, +1)` | `(+1, 0)` | `(15, 22)` |
| `up` | `(0, -1)` | `(-1, 0)` | `(16, 26)` |
| `left` | `(-1, 0)` | `(0, +1)` | `(16, 24)` |
| `right` | `(+1, 0)` | `(0, -1)` | `(15, 24)` |

画布像素：`x = ox + F.x * f + R.x * r`，`y = oy + F.y * f + R.y * r`。越界丢弃。后写覆盖先写。

## 家族（与渗透体同一套语法）

- **前倾**：质量偏向 `+F`。头在 `-F`，爪在 `+F`。
- **爪**：细长直角指，3–4 节 1–2 px，不是圆掌。
- **崩坏覆盖 ~50%**：`r < 0` 完整；`r > 0` 溶散。第一眼须看两眼才确认曾是人。
- **teal 成簇 15–20**：本占位锁 **17** 个 `#1aad96` 簇像素 + 其中 2 个被 `#2ae6c8` 盖住。不是 17 个散点。
- 完整侧只留 **1** 个家族散点（渗透体是 3–6），避免两侧一样“点彩”。

## 本地格清单（四向共用）

整数 `(f, r)`。先铺基底，再铺簇。

**完整侧 `#2e2d30`（躯干）**  
`f ∈ [-6, 5]`，`r ∈ [-6, -2]`。跳过空洞 `(2, -2)`。

**头 `#2e2d30`**  
`f ∈ [-10, -7]`，`r ∈ [-5, -2]`。头上不画第二点。禁止在头上画成对像素。

**肩高光 `#3a3838`**  
`(-6, -7), (-5, -7), (-6, -8), (-5, -6), (-4, -3)`

**爪 `#2a2a2e`**

`f ∈ [-7, 6]`，`r ∈ [1, 7]`。若 `(f + r) % 5 === 0` 则留空（数据孔）。

## 警戒变形（搜寻 / 追击，无新色）

本体指示物（头上 1/2 方点或锁定三角）**沿用渗透体 R2**，色 `#2ae6c8`，`INDICATOR_OFFSET_Y = -24`（sprite 更高）。状态仍靠行为 + 指示物；崩坏侧只加重同一语言。

| FSM | 崩坏侧 | 残影（仅改写体；渗透体数字不动） |
| --- | ------ | -------------------------------- |
| 巡逻 / 归位 | 簇按上表。基底 alpha 在 **0.80–1.00** 间正弦，周期 **2000 ms** | 不发 |
| 警觉 | 同上。运行时在头 `(-9, -3)` 加 **1 px** `#2ae6c8`（不是眼睛） | 不发 |
| **搜寻（警戒）** | 再把 `(-4,3), (-2,3), (1,4), (0,5)` 写成 `#2ae6c8`（崩坏侧更亮，仍是同一 teal）。这 4+2 个亮点跟 **3.0 Hz** 方波，亮 1.00 / 暗 **0.55** | 不发（形态 = 更亮，不靠残影） |
| **追击** | 17 个簇格全部改为 `#2ae6c8`，只留 `(-4,2), (1,3), (0,6)` 为 `#1aad96`（还能读出块，不是一片糊光） | **更快**：间隔 **55 ms**、寿命 **240 ms**、alpha **0.28**、槽 **5**。残影用同一张朝向纹理，alpha 只乘可见度 |

追击额外：每 **8 帧**把 sprite 沿 `+R` 抖 **1 px**，下一帧回锚（VERDICT：两偏移位置间跳动）。不要换色相。

动态飘散（可选，B 类粒子）：1×1 `#1a6b5c`，只从崩坏侧外沿出。巡逻同时 2 颗、寿命 240 ms；搜寻 6 颗、寿命 140 ms；追击 10 颗、寿命 110 ms。禁止圆形软粒子、禁止粉紫。

## 禁止（占位即不合格）

- 圆润四肢、粗描边、Q 版头身比
- 眼睛、嘴、对称脸
- 两侧同形（对称史莱姆 / 水滴）
- 触手、黏液条、血浆
- 用渗透体那张 24×24 纹理放大冒充
- 左右镜像一张图当四向
