# 改写体 · 程序化像素（俯视 4 向）

对照：`docs/art/demos/entity-rewriter/VERDICT.md`（渲染崩坏 ~50%，强不对称）、`docs/art-direction.md` §5.2、渗透体 `src/entities/infiltrator-sprite.ts`（32×32 密像素前倾人形，不是 24×24；保持直立，朝向用侧向伸出，不旋转剪影）。家族对照、朝向禁忌、练习场怎么验：`docs/art/actor-pixels.md`。

Code 按下面整数格画四向与步态帧。碰撞仍用现有 `BODY_SIZE` 20，不改手感。

## 画布与朝向

| 项 | 锁 |
| -- | -- |
| 画布 | **32×48**（宽×高），透明底，`image-rendering: nearest` |
| 锚点（世界位置对齐） | 画布 `(16, 30)` |
| 纹理名 | `placeholder-rewriter-down` / `-up` / `-left` / `-right` |
| 朝向 | 跟 `Facing4`。四向都是**直立站姿**（头在画布上方、足/爪在下方），与玩家同一条原则：不转 actor，也不把同一剪影烘进贴图里转 90°/180° |
| 个体变体 | 本 Slice 只画 **爆发散射型**（VERDICT 第一张）。纵轴溶解型合法，不做 |

本地坐标：`+F` 沿身体纵轴（头 = −F，爪 = +F），`+R` = **身体右侧**（完整侧 r < 0，崩坏侧 r > 0）。四向共用原点 `(ox, oy) = (15, 22)`。`y` **永远** `oy + f`，禁止绕原点乘旋转矩阵。

| `Facing4` | 画布 | 读作 |
| --------- | ---- | ---- |
| `down` | `x = ox + r`，`y = oy + f` | 直立正面；崩坏在屏幕右 |
| `up` | `x = ox − r`，`y = oy + f` | 直立背面（头仍在上，头色改骨灰）；崩坏在屏幕左。**禁止 Y 轴翻转** |
| `right` | `x = ox + r + 2`，`y = oy + f` | 直立右侧影，向右伸出爪。不躺倒 |
| `left` | `x = ox − r − 2`，`y = oy + f` | 直立左侧影，向左伸出爪。不躺倒 |

越界丢弃。后写覆盖先写。侧向另加 4 格溶散伸出（`SIDE_REACH`），只加像素，不转身体。

## 步态

四向保持直立。待机 / 行走各 4 帧：身体绕锚点轻微伸缩；行走时崩坏色像素沿身体右侧 ±1 px 摆，允许出现「裂开」缝（渲染崩坏，不是 bug）。转向不生成 45° 中间朝向——切 `facing4` 时用压缩帧 + 旧朝向滞后剪影。禁止触手。

| 名 | 色值 | 用途 |
| -- | ---- | ---- |
| flesh-dead | `#2e2d30` | 完整侧基体 |
| cloth-dark | `#2a2a2e` | 爪 / 前臂 |
| bone-grey | `#3a3838` | 完整侧 2 px 肩高光 |
| contam-deep | `#0e4a3f` | 崩坏侧基底（带孔） |
| contam-mid | `#1a6b5c` | 溶散喷点、偏移爪副本 |

## 家族（与渗透体同一套语法）

- **前倾**：质量偏向 `+F`。头在 `-F`，爪在 `+F`。
- **爪**：细长直角指，3–4 节 1–2 px，不是圆掌。
- **崩坏覆盖 ~50%**：`r < 0` 完整；`r > 0` 溶散。第一眼须看两眼才确认曾是人。
- **teal 成簇 15–20**：本文件锁 **17** 个 `#1aad96` 簇像素 + 其中 2 个被 `#2ae6c8` 盖住。不是 17 个散点。
- 完整侧只留 **1** 个家族散点（渗透体是 3–6），避免两侧一样“点彩”。

## 本地格清单（四向共用）

整数 `(f, r)`。先铺基底，再铺簇。

**完整侧 `#2e2d30`（躯干）**  
`f ∈ [-6, 5]`，`r ∈ [-6, -2]`。跳过空洞 `(2, -2)`。

**头 `#2e2d30`**  
`f ∈ [-10, -7]`，`r ∈ [-5, -2]`。头上不画第二点。禁止在头上画成对像素。

**肩高光 `#3a3838`**  
`(-6, -7), (-5, -7), (-6, -8), (-5, -6), (-4, -3)`

**爪 `#2a2a2e`**  
`(-2, -8), (0, -8), (2, -8), (4, -8), (6, -9), (8, -9), (9, -10), (10, -10), (11, -11)`

**崩坏基底 `#0e4a3f`**  
`f ∈ [-7, 6]`，`r ∈ [1, 7]`。若 `(f + r) % 5 === 0` 则留空（数据孔）。

**簇 A（胸，7）`#1aad96`**  
`(-4,2), (-4,3), (-4,4), (-3,2), (-3,3), (-3,4), (-2,3)`

**簇 B（髋，6）`#1aad96`**  
`(1,3), (1,4), (2,3), (2,4), (2,5), (3,4)`

**簇 C（外沿，4）`#1aad96`**  
`(-1,5), (0,5), (0,6), (1,6)`

**簇心 `#2ae6c8`**（盖在簇上，仍算 17 格内）  
`(-3,3), (2,4)`

**完整侧家族散点 `#1aad96`**  
`(-3, -4)`

**溶散喷点 `#1a6b5c`**（轮廓外，只在崩坏侧）  
`(-6,9), (3,9), (7,8), (5,10), (-2,8)`

**偏移爪副本**（baked 重影，VERDICT）  
`#1a6b5c`：`(8,3), (9,3), (10,4)`；`#1aad96`：`(11,4)`

画完后完整侧轮廓应仍读得出头/肩/爪；崩坏侧是矩形块+喷点，不是圆斑。

## 警戒变形（搜寻 / 追击，无新色）

本体指示物（头上 1/2 方点或锁定三角）**沿用渗透体 R2**，色 `#2ae6c8`，`INDICATOR_OFFSET_Y = -24`（sprite 更高）。状态仍靠行为 + 指示物；崩坏侧只加重同一语言。

| FSM | 崩坏侧 | 残影（仅改写体；渗透体数字不动） |
| --- | ------ | -------------------------------- |
| 巡逻 / 归位 | 簇按上表。基底 alpha 在 **0.80–1.00** 间正弦，周期 **2000 ms** | 不发 |
| 警觉 | 同上。运行时在头 `(-9, -3)` 加 **1 px** `#2ae6c8`（不是眼睛） | 不发 |
| **搜寻（警戒）** | 再把 `(-4,3), (-2,3), (1,4), (0,5)` 写成 `#2ae6c8`（崩坏侧更亮，仍是同一 teal）。这 4+2 个亮点跟 **3.0 Hz** 方波，亮 1.00 / 暗 **0.55** | 不发（形态 = 更亮，不靠残影） |
| **追击** | 17 个簇格全部改为 `#2ae6c8`，只留 `(-4,2), (1,3), (0,6)` 为 `#1aad96`（还能读出块，不是一片糊光） | **更快**：间隔 **55 ms**、寿命 **240 ms**、alpha **0.28**、槽 **5**。残影用同一张朝向纹理，alpha 只乘可见度 |

追击额外：每 **8 帧**把 sprite 沿 `+R` 抖 **1 px**，下一帧回锚（VERDICT：两偏移位置间跳动）。不要换色相。

动态飘散（B 类粒子，已接入）：1×1 `#1a6b5c`（改写体偶发 2×1 `#1aad96`），只从崩坏侧外沿出，往外/往下飘。巡逻同时约 2 颗、寿命 240 ms；搜寻 6 颗、寿命 140 ms；追击 10 颗、寿命 110 ms。禁止圆形软粒子、禁止粉紫、禁止玩家那套上飘暖尘。

## 禁止（不合格）

- 圆润四肢、粗描边、Q 版头身比
- 眼睛、嘴、对称脸
- 两侧同形（对称史莱姆 / 水滴）
- 触手、黏液条、血浆
- 用渗透体那张 32×32 纹理放大冒充
- 左右镜像一张图当四向
- 把同一俯视剪影绕画布转 90° / 180° 充当侧向 / 背面（那就是 actor 旋转，只是烘进了贴图）

## 与管线的关系

**不走** `spr-rift-enemy-rewriter-*`、不走 `art:postprocess` / `palette.json` 量化。概念图只作方向档案，不参与平铺、不替换本文件。过关标准：和渗透体并排时读作同一家族（同一密像素密度、崩坏语言）、崩坏一侧明显、朝向可读、行走时允许裂开。覆盖体若做，不默认套本文件。
