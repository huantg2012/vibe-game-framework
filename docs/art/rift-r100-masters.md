# R100 三构造 × 三级：原生美术母版制作单

本文把[已批准的大版本标准](../art-direction.md#rift-r100-standard)落实为第一批制作对象。它不另立画风、不代替地图机制 spec，也不宣布样板已制作或已获审美认可。制作顺序为**折叠板低／中／重 → 纤维结低／中／重 → 厚壳腔低／中／重**；九格均为 I02 样板，合格世界计数仍为零。完整压力、准备、收益及搜撤资格在 I03 审核。

## 1. 现有方法能做什么，缺什么

基线取 `ac9ddd7`。本次只读源码，并看过现成的[正式搜取截图](../qa/artifacts/rift-conditions-2026-10-02/browser/05-searched.png)与[无彩层原烤地](../qa/artifacts/rift-conditions-2026-10-02/ash-strata-v2.png)，未在本次试玩或审听。

- `src/generation/world-study/ground-material.ts` 已有连续材料场、涂层交界、磨损与方向；`material-forms.ts` 已画层片／晶面／釉体。不能把现状说成“没有材料机制”。
- `material-response.ts` 记录面向，且剔除后来被覆盖的反光；`material-light.ts` 按玩家位置调节稀疏反光。它尚不是体积表面及跨物体遮光求解。
- `world-scenery.ts` 明确约束为地面低浮雕；现有 `strata-fold` 仍是地面上的层片组织。`world-space-surface.ts` 把整张底图挂在 depth 0、反光挂在 depth 1。把该图案放大不会产生可绕行的高板，也不能表达角色绕壳腔前后时的遮挡。
- 已看图像中，细纹与若干层片能够被看见，但层片大多同等孤立地铺在地表；正常灯照范围里缺少决定视口组织的中尺度实体。截图只能支持这一可见判断，不能据此断言所有种子均相同。
- 角色仍用 `player-sprite-dense.ts`：32×32 原生画布、20px 碰撞边长；`config/constants.ts`：32px 地块、1.5 相机倍率、80px/s 基础步速。上述尺度与动作保留，不用净化点的高精角色来美化样板。

**制作方法的改变：由共享构造实例生成支撑边界、可见面、孔腔与遮光关系，使厚度、转面、角色前后遮挡和灯照移动一起成立。** 连续地面与已有材料算子继续承担底层，不把整图再次画成一张不能拆开的背景。

## 2. 表示与绘制合同

### 可编辑的对象

每个构造实例持有：身份与种子、地面锚点、构造轴、实体占地、多层可见面、厚度／高度、孔腔、接合点、材料区、污染寄附面，以及受控运动的端点和幅度。字段与冻结格式由 Code 写进现行地图 spec；此处规定它们必须共同表达的视觉事实。

1. **板**用相连的厚折面；**束**用共根、汇入结点的带状截面；**壳**用有厚度的闭合外壁和向内凹的腔壁。三者不得共用同一种菱形棱柱，仅改纹理。
2. 高物体必须独立于烤地。保持 Rift 地面坐标与原相机，构造在同一固定投影下生成可见面／高度和覆盖遮罩；禁止整个世界改成净化点轴测视角。角色遮挡按照实例与面的位置关系处理，不能只给整个大物体一个永远高于角色的 depth。
3. 表面法向、遮挡和接触关系来自同一几何。预烤可以保存面归属、深度、法向、底色与粗糙度；运行时用它们响应肩灯与异源光。孔腔不是画一个黑圆：须有入口厚缘、内壁转折和向深处衰减的受光。
4. “世界平面无支撑”与“实体投影覆盖到该像素”分开处理。现行烤地按屏幕像素的地面支撑掩膜擦黑，不能原封不动用来裁高物体。悬出的实体有其支撑归属，可以遮住背景；背景虚空本身仍无受光表面。I02 不新增可站立的第二层、可穿越的上下叠层或实时坍塌拓扑。
5. 同一对象的涂层、刻痕和污染附着在局部面坐标，转面时随面转向，不能铺一张屏幕空间噪声。先看隐藏细纹后的大形和中尺度面，再添材料加工；碎屑只从真实断口或接缝脱出。
6. 接地处用局部接触暗部，悬挑有投影，深腔有自遮蔽；阴影可深但不以纯黑伪装虚空。微光必须照到邻面，并被厚面挡住。孤立“亮绿线”不算光源。

### 像素、色与尺度

- 原生像素先画实，最近邻显示；不把高分辨率平滑图缩小充当终稿。大形跨若干地块，面内材料簇以 4–16px 的有方向形态为主，1px 只服务断口转折与少量末级颗粒。噪声幅度不是完成度旋钮。
- 首轮构造尺寸起点：板片长 3–7 地块、断面厚 4–12 原生 px；主束宽 1.5–3 地块、可辨副束宽 4–10px；壳段外径 5–9 地块、口沿厚 0.5–1 地块。重度巨构可延续到当前视口之外，但由相连构造组成，不能只把同一 sprite 放大。这些是试制起点，不是最终地图密度或通行平衡。
- 外沿是面本身的颜色；内缝、接触阴影、背光面有具体结构来源。禁止统一深描边、统一亮边和所有顶面朝同一方向发亮。
- 材料色沿用现有 CSV 角色：板首样取 `ash-strata` 的中性层次；束取 `crystal-fibre` 的材料组；壳取 `ivory-basin` 的基材组。它们是画法试制配色来源，**不把三个既有世界换名计作三个新世界**。不新增色板格，不手写角色历史 RGB；污染沿既有污染 ramp 获取灰绿／青绿，不取 `contam-ancient` 鲜绿直接填满主体。
- 当前世界材料生产使用 CSV 色角色及连续 ramp；旧地表文件与 `pixel-models` 的全像素量化约束不能被误用来重写已接入的材料系统。沿用其“本质→形体”“面色外沿”“原生尺寸”“真实背景”纪律；本批不扩色表，任何后续调色都留可复核配方。
- 可操作边缘与物体外形分开验。新增构造的关键可走／不可走交界，在肩灯正照的 1–3 地块距离，首轮机器目标为沿边局部中位亮度差至少 12/255，连续可辨段至少 4px；两侧取样不得跨污染高光或虚空。它只是防吞边下限，须随首次原生样板校准并留记录，不能据此宣布审美或所有方向可读。既有翻堆继续使用其既有对比度检查，不套构造阈值。

## 3. 九格具体要画什么

共同本质：原生物质具有自己的组织，外来模式跨越并取代这种组织；它在玩家之外持续运作。不是人造祭坛、废墟展台或围着玩家搭的竞技场。载体是地表及植根于地表的实体；空中活层必须依附已存在的面、腔或连接。非人环境没有“谁制造、如何维护”的工业默认答案：板是沉积／压合，束是聚集／受拉，壳是逐层封合；污染改变其接续规则。

### A. 折叠板：先完整做这三格

一句读法：**脚下的层片本来沿一个方向铺展，另一套折痕正在把它折回自身。** 成立的形体包括错叠台阶、反向翻折与套叠夹层；排除散布的独立石板、等距琴键和薄纸折扇。首样取“反折贯穿既有铺层”，因为能同时验厚度、跨面、前后遮挡与路径余量。

- **低污染。** 一片连续宽床面从入口延伸到视口外；靠一侧留一组卷起的三层厚板，露出压合断面。只有一个逆向折口穿过原有层纹。玩家能沿长边走到背面，看见同一折口的另一段与接触阴影；灯照绕过后，原亮面转暗。翻堆靠一处断裂端面落脚，不放在构图中心。静处能观察短暂的层间光，不让全块地面呼吸。
- **中污染。** 保留宽床面的方向与同一断裂端面，但逆折贯穿第二组板；两组沿不相容方向套入。长边形成可读的绕行，断面之间留可窥视的间隙，路线在一次转角之后显出搜取点。连接处必须出现原纹理被切断／转入里层的证据。活动从一条折缝推进到另一条，绝不是所有缝同时闪。
- **重污染。** 巨型反折跨过正常视口，主要看见承压的一个内角和上方压来的多层端面；别完整展示“一个大折扇”。玩家沿临时保留下来的地表通路贴过套叠结构，身旁留一小片低纹理、可回头观察的静区。结构的方向、接点与断面仍能追溯低档。重量由大面积静止厚面与少数吃力接点表现；活层到峰时，先接点收紧，再内缝露光，最后近处碎屑落下，结束后留下足够安静的回落。I02 运动不暗改碰撞或制造假攻击；受影响区域与伤害相位由 I03 同源机制接入。

板的材料描绘：外表压实、内层细密、断面松裂，至少三种结构尺度。宽面受光应完整而不均匀；折痕外脊磨亮，内角积暗；薄剥层只在应力端出现。隐藏污点后仍要读出厚板，不靠一面浅灰上几条横线交差。

### B. 纤维结：迁移受力关系，不迁移板片纹理

一句读法：**曾经同向输运的纤维，被异源结点拉成互相抵消的张力。** 成立形体包括束根汇聚、悬紧长束与偏心绞结；排除触须森林、均匀细毛和每根都自由摆动的水草。首样取“宽束汇入偏心硬结”。

- **低污染：** 两条宽束在地表汇入一个未闭合结点，留可追溯的分束；局部几根硬化后逆向穿出。以整束的截面、压扁和根部贴地说明体积。通路沿束外侧，散断纤维不得长成一圈装饰刺。
- **中污染：** 第三条横向束强行贯穿原结；一侧绷紧、一侧松垂，形成偏置绕行。副束沿主束受力走向分叉，结内小腔露出被替换的材料。交界上的光有传播次序，静止外皮保持不动。
- **重污染：** 当前视口只看见巨束的收束喉部和一小段被拉直的长轴，原纤维床被压成边缘夹层；玩家从束根之间的地表余量绕行。运动由结点开始，沿受力束延迟传递，松束最后回落。禁止全束按相同正弦节拍缩放；关掉动效仍要有被拉住、随时可能失衡的结构。

束的材料描绘：共根暗缝、宽束转面、编结挤压形成中尺度；细纤维只在断头与磨开的表面，不能把细线数量当“纤维感”。光泽沿束轴，横断面偏哑；污染硬结的光从夹缝而非整条束外沿溢出。

### C. 厚壳腔：检验真正的内外层

一句读法：**逐层封合的厚壳，开始把外表折进内腔，把内层挤到外面。** 成立形体包括偏心破腔、串接腔室与翻出的壳瓣；排除平涂黑洞、完美同心圆和复制的陨石坑。首样取“厚口偏心开裂、内壁与一瓣外翻”。

- **低污染：** 一段有实体厚度的壳口露出近侧内壁、后壁与底部沉积；背光部仍是材质暗部，不直接填 void。只在一个封合接点发生内外互换。玩家沿厚缘外侧走，不能误以为黑处全部可走。
- **中污染：** 邻腔被同一异源接缝贯通，一瓣翻出造成遮挡与绕行；第二内壁从侧面出现。擦亮区沿曲率连续变化，破口断面有层叠和崩落方向，腔底堆积与上方断口对应。
- **重污染：** 视口上半由巨大壳内壁统摄，几层不同方向的壳片向同一狭部压合；可走地表只在结构间延续，存在一处低压观察口。外壁沉重静止，内腔压力先改变窄缝光，再出现壳层错动和沉积回落。不得用整个圆洞均匀呼吸或一圈高亮边冒充能量与压力。

壳的材料描绘：外层失光、断口致密、内层局部釉化；曲率用宽明暗带与稀疏窄反射共同塑造。粗糙度决定反射宽度；不把孔周围画满白线。内外面要能在肩灯移动时先后受光，不能都是固定渐变。

## 4. 母版装配与审查镜头

每个母版取约 28×20 地块的连续局部作为初始制作范围，接入真实世界图与正式角色／视野／翻找物／敌人表现；范围可按原生取景调整。保持相同入口轴、地标主接点和观察站位，再由污染等级重组结构。绝不按三个画面逐像素相同来约束真实几何变化。

制作范围必须同时包含：一处长向引导、一处可绕行转角、一处厚断面或深腔、一件可翻找物、一段可观察危险先兆、一处静区、压力峰及回落。普通通路先以两地块净宽起步、入口和回头处更宽；最终以真实 20px 身体的路径／搜取／撤退资格裁决，不为压迫把路压成卡人细缝。

审核交付采用正式镜头，不改 FOV、不缩小角色、不抬全局曝光来展示巨构：

1. **进入定位：** 从未知处走入，常规视野内先见哪一段大形、何处能走。原生截图一张。
2. **绕行与照明：** 沿同一构造前→侧→后走，停下转灯，查面受光、接触影、玩家排序；连录，不靠剪辑隐藏边界。
3. **搜取与受压：** 翻找物、玩家、敌人／危险先兆同场；展示先兆出现时哪个视觉层退让。I02 若只有受控相位演示，必须标注“表现样板，完整压力机制未接入”。
4. **高峰→回落→撤走：** 录一个完整过程并实际听声；捕捉峰前、峰中、峰后三个静帧。回落不是全场突然变亮，结构压迫仍在、可行动的局部余量恢复可读。
5. **诊断镜头：** 同站位暂关颗粒和污斑、单独移动灯，附无雾结构图及实例边界叠图。诊断图不代替正式画面。

每格先一组配对种子锁方法，再补第二种子和未挑选保留种子。第一组折叠板未解决的体积／遮挡问题不复制到束和壳；同一根因连续两次退回，暂停增加纹理，检查几何表示与渲染关系。

## 5. 声音与动态的实施接口

现有 `audio-catalog.ts` 有通用 Rift drone／威胁／接近层及步骤音，不能据文件名宣称已有板、束、壳的材料声。前三种新声景需实际制作与试听；复用 AudioManager 的对象所有权、空间衰减与清理，不另开不受暂停／音量管理的播放器。

- **板：** 接点短促应力摩擦 → 层间低沉错动 → 零散薄片落下；干、短、有硬面距离感，不用金属铁门通用长吱声覆盖一切。
- **束：** 结点低频拉紧 → 延迟的纤维摩擦 → 松束回弹与沉静；声音沿张力路径传递，不模拟怪物喘气。
- **壳：** 腔内低共鸣 → 近口短敲／剥落 → 尾声向深处收回；内外的空间尾音不同，不把壳当房间混响预设。

每次大运动必须能指出声源、传递方向和结束原因。重度更多是较长的蓄压与近处回应，不能靠总音量常驻抬高。危险先兆须从材质底噪中可分，听觉敌人提示及翻找中断声保留优先级；音量数值、通道与时长进入声音配置，初样审听后冻结。本文件不预先捏造混音通过值。

## 6. 锚点、自检与证据限制

采用三个仓内可追溯锚点：现有 Rift 原生角色与视野（继承尺度和搜撤读法，不继承小层片铺满地表）；Last Light 已获认可的实体描绘方法（继承断面／内腔／光与物体的因果，不继承轴测相机与高精角色）；`material-forms.ts` 的同源材料组织（继承方向与接合，不将可走浮雕当实体体积）。当前任务不是多方案抽卡，九格是同一制作任务的材料与等级验证。

规格期自检：

- 本质与形体成立范围：分别在板／束／壳章节写明；有跨越原关系的可见证据，不靠设定说明解救画面。
- 载体、相机、原生画布与落地底：地表＋植根实体，原 Rift 相机，32px 角色和地块；实际 CSV 材料地面。不用黑卡片判断合格。
- 外沿、平色、浮空颗粒与活层：规定面色外沿、先中尺度再细节、归属面坐标、腔内断续光；尚无新图，不虚填像素统计或“看起来像什么”。
- 动态结构：可动部分为专门定义的材料关系；I02 碰撞与导航包络冻结，不能在无人审核下让表演改变可通行边界。现有装置“只动内腔”规则不误套到已授权的新材料形变。
- 色与一致性：沿既有世界 CSV 材料组和污染 ramp，不新增色、不改玩家。材料光与发光不同，不把温暖的哑材质判成新增人类灯。
- 翻堆：复用正式表现和交互，不泄露内容物。形体类统计和高物体可读闸门由 Code 在实际产物上执行；本轮只有制作规格。
