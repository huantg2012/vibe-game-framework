# R100 原生美术母版：重新校准的制作依据

**当前：I01 / I02 人审未通过，按六项要求重新整改。** [最新用户原话、长期表达约束与逐项验收](rift-r100-i02-review.md#human-feedback-2026-10-03)集中保存，优先于本文尚未更新的历史实例。绿色侵蚀与吞光必须直接看得见；结构下沿等可见边界要与碰撞相符；真实占漆／占空的数量和面积、玩家污染增长曲线都必须参与三级区分。低污染的单处侵蚀不能弱到无法辨识，重度也不能只加模型尺寸。

已获得有限肯定的结构方向与连续材料画法继续利用，重做具体失败处。`03d4e4c` 的代理实图复核为历史证据，不再用“无艺术 P1”抵消人的否决；Worker、受控 GC 等工程证据保持原范围。当前 0 个世界、0 个等级格合格。集中艺术方向仍归 [R100 美术标准](../art-direction.md#rift-r100-standard)。后续直接描述发光、绿色侵蚀、声音和数值，不给它们另造名称，也不声称未实现的危险或安全窗口。

这次要改善的是**玩家脚下直到视野边缘的完整世界描绘**。此前把主体几何当主要答案，而地面仍是灰底、斑块和细纹；又把普通实体的高度/自阴影接成战术不可见，画面因而又薄又黑。增加模型面数、雕几个厚截面，都没有回应这两个根因。

## 1. 实际看过的参照，分别学什么

2026-10-03 已用原图查看以下官方实景，随后重看净化点获认可的 `35f17ba` 像素整景。下面是画面观察与可迁移判断，**不是对竞品内部渲染管线的推定**。

- **Darkwood：地表本身承担环境。** [官方 presskit](https://www.darkwoodgame.com/presskit/) 的[室内图](https://www.darkwoodgame.com/presskit/images/dw_scr8.png)中，板缝、裂口、边缘积聚和散置残物共同描述地面；受光区不是干净灰底。灯外仍有局部材料层次，墙体、物件投影、未知区域不是同一种黑。[林地灯锥图](https://www.darkwoodgame.com/presskit/images/dw_scr6.png)中，通行区较安静，地面组织向两侧变密；上方树枝另成遮盖层。借鉴材料密度分配与暗部层次，不复制森林、血污、画面颗粒或视线规则。
- **Hyper Light Drifter：细节放在关系发生处。** [官方发行商页面](https://abylightstudios.com/game/hyper-light-drifter-special-edition/)的[遗迹实景](https://abylightstudios.com/wp-content/uploads/2021/08/gallery-image-3-hyper-light-drifter-abylight-studios.jpg)里，宽阔底面与成组遗留地砖、破墙、根边残片相互衬托；[雪地实景](https://abylightstudios.com/wp-content/uploads/2021/08/gallery-image-4-hyper-light-drifter-abylight-studios.jpg)里，雪、建筑和树冠的交界有明确厚薄、覆盖与材料切换。借鉴簇状描绘、边界层级与大面休止，不复制鲜色、等距构图、建筑题材或露侧面的斜视画法。
- **本项目净化点：结构、材料、光具有同一依据。** [获认可原图](demos/purification-last-light/assets/baseline-35f17ba.png)可见楼板延续、断口、残墙和堆积的因果；地面内部也有连续的材料变化。学习可编辑构造、接触和材料坐标共同驱动画面，不搬入轴测相机、高精人物或人类废墟题材。方法及源码入口见个人 `visual-art-production/references/pixel-scene-case.md`。

这组参照并不支持“纹理越多越好”或“只要真实三维就会好看”。它们共同说明：**安静的平面仍有被充分画过的材料；复杂处有可追溯的结构原因；二者在一个完整地点中相接。**

## 2. 先分清五种不同的画面事实

1. **普通地表。** 具有正常材质与受光，包含浅浮雕、磨耗、沉积和小型地物；不因像素有高度就不可走、挡视线或吃光。
2. **普通实体景观。** 可以有实际碰撞、接触影、自阴影和前后覆盖。材料阴影只改变受光，不清除表面的存在；本次 R100 景观不得自动获得吞光/权威视野遮挡资格。旧正式墙规则由系统 spec 单独处理，不作全局翻转。
3. **侵蚀/吞光区域。** 必须由明确污染对象或区域语义授权，具有可见的边缘、覆盖/改写过程和等级差别；不能由“高于肩灯”“灰黑材质”“巨物”推导。普通景观与它相接时，玩家应看出改变发生在哪里。
4. **真实虚空。** 没有可受光表面、没有地表细节；它与普通材质深阴影不能共用一张无解释的黑遮罩。
5. **玩家可见范围。** 来自正式范围、朝向与权威显隐规则。材料渲染消费这个结果；局部灯影不能重新抹掉它，普通材质法线更不能改写敌人是否可见。

这些语义需在作者输入及渲染接口可区分，由 Root/Code 更新同源合同。物理攻击阻挡、导航和视线分别验，不能为了让普通实体可见而允许隔物攻击。绿色自发光只属于具体污染来源；正常材料本色允许丰富，不能拿全场青绿替代异世界身份。

## 3. 制作单元：完整材料地段，而非黑底独立模型

首个生产单元取一个正常视口及其绕行余量：原 Rift 960×640 逻辑画布、1.5 相机、32×32 玩家精灵、20px 身体、32px 地块不变。约 640×427 世界像素是审美发生的主要尺度，不能缩人物、改相机或放大灯圈使作品显得精致。

地段包括一片可连续行走的材料地床、一处受侵蚀的材料交界、一处与地床相连的中尺度景观、安静通路、搜取物与接近位置、可回望转角。普通地形先完整，再在有归属的一部分施加污染；关闭污染表现作诊断时，普通世界仍有形、材质和地点感。诊断不是把低污染改成世界观中的零污染。

**制作表示：作者可编辑的材料区域与形成事件，共同生成底色、浅表形状、法向、粗糙度和局部遮蔽；实体只在需要实际厚度、腔体、碰撞的位置另建共享几何。** 不继续把所有地表问题交给一个独立大体块。具体字段进入现行 spec/CSV，不在此另立系统：

- **基材区域**：连续范围、材料身份、主要走向、原生组织。形状可以跨 tile，不把每格独立随机后拼接。
- **形成事件**：一条延续的作用轴或一处局部交界，以及实际影响范围。依该世界选择两三种作用，如剥露、压密、沉积、断续生长；不强制所有世界都用层岩。事件改变原基材组织，而非贴不相关花纹。
- **可见结果**：成组露面、埋边、薄堆积、根部、残片从事件边界或源头产生。同源改变高度、表面方向、颜色、粗糙度、接触暗部；不能各用一份随机场凑巧碰在一起。

具体像素加工顺序：

1. 正常受光下先画长向组织和宽面变化，使通路与材料过渡在完整视口可辨。宽面不等于纯色：内部有缓慢色值与粗糙度变化，避免硬阈值迷彩斑。
2. 以约 6–24 原生 px 的有方向材料簇塑造接边、露面、压密/剥离区和薄堆积。尺寸是当前人物尺度下试制起点，不是每种材料都长成相同多边形。簇之间有合并、间断与疏密，不生成全场等距纹。
3. 只在实际末端、裂口和加工方向添加约 1–3px 细节。细点可以存在，但不能承担主要材质识别。暂关细点后，大面和中尺度仍有丰富关系。
4. 确定性绘制保留硬像素簇与作者选择；不能只靠全图平滑噪声，也不把平滑噪声简单量化成彩斑。可使用作者绘制的轮廓/像素面簇作为可编辑形状，从同一坐标输出表面数据；不得采样参考截图。
5. 真实肩灯下，粗糙面有宽缓转折，致密/剥露处有短窄反光，接缝有局部暗部。宽亮面、半调子与暗面同时有材料信息。反光跟灯走，材质本色和形成痕迹不跟灯漂移；过曝白点、塑料亮边都应调回材质本体。

先画透一块约 160×160 原生材料局部并放回正式视口比较，再推广连续地表；这个局部同时包括连续基床、完整宽面、一次剥露／材料交界与末端小细节。它是工艺验证，不是独立小图交付。若首轮只是闭合石片和平滑波纹，先修画法，不能以整图铺满作为进度。

净化点案例里“几何法线管稳定面类别，扰动法线只管连续材料受光”仍适用。旧地面混合阈值或重复浅浮雕造成迷彩/贴花，应修稳定分类及同源事件；更多 noise、sin 条纹或更低曝光不是完成度旋钮。

只读复核 `purification-last-light/render.ts` 的 `sampleSurface` 可见，获认可画面也使用多尺度 noise，木材还使用 sin；这些函数本身不是禁忌。有效点是材料各有尺度、粗糙度、色值变化和真实构造承接，暗面保留漫反射。应避免把本次判断机械化为“禁 noise / 多画多边形簇”，让另一种公式再次替代画面判断。

**R16 制作纠偏：程序字段不自动产生描绘质量。** 实际缓冲测量表明，正式中档最大承压面 albedo 的 P10/P90 只有 73/76；不是有 event/roughness API 就画好了材料。新一轮允许先制作具有完整层皮/露面/断端描绘的静态材料源，再作原生像素加工、结构区域映射与实时受光。它只提供材料，不把整张景观图当地图，不代替几何/导航/污染作者数据。原图的明暗不等同高度；浅法线与粗糙度需按材料区选择生成，不能连烘焙阴影一起当凹槽。材料源接入仍先以同站位正常图与 albedo 比较，若只是灰底变成均匀噪纹，同样退回。

### R20 实际生产方法与已完成事实

`03d4e4c` 是旧证据所绑定的生产版本，双种子九格曾完成代理图像审核；当前人审要求修改，文件不再因旧审核而冻结。完整实现入口与本轮技术证据归 [I02 QA](../qa/rift-r100-i02.md)，过程中的实图退回及定向修复归 [R20 审查记录](rift-r100-i02-review.md#r20--由审查转入定向修复等待-root-独立实图)。当前方法是以下明确分工：

1. **源材质负责描绘。** 三张 1254×1254 原始母片原样存入 `public/assets/r100-materials/`，运行时准备为 512×512 像素。素材用途、生成指令摘要、原图出处与 SHA256 见[来源 README](../../public/assets/r100-materials/README.md)。它们只提供层皮、露面、碎料与面内半调子；没有把整幅地图贴入游戏，也没有采样竞品截图。
2. **作者选区负责材料身份。** `data/rift-master-materials.csv` 除原生/world 尺度，还逐图声明目视选定的 `skin_region`、`cleaved_region`、`loose_region`，格式为归一化 `x:y:width:height`。编译器拒绝越界、空项与不足 8 个原生像素的区段。灰岩裸层、矿质纤维与釉壳的明暗意义不同，不以统一亮度/方差阈值自动判材质。
3. **几何事件负责取材位置。** 普通连续基床与表面用世界材料坐标，切面用沿断口弧长/真实高度，纤维主体用自身 swept UV。真实 `region` 与地面 `materialEvents` 选择源片段及粗糙度；不再用整个顶面模糊、整个断面锐化代替“表皮—剥露—断端”的分区。取样保留原生材料簇，源图灰度不生成实体高度或战略黑暗。
4. **构造负责可编辑厚度。** 折板断带改为不对称宽剥口，中段展开、两端归床，并有共面 peeled 肩部；非断裂侧保留普通母材，不做完整发亮围边。绿色侵蚀发光面贴合实际几何表面。纤维与壳维持各自共享几何，形体、几何法向、浅起伏、AO 与最高高度合同继续由代码负责，材质改动不重定义导航/攻击/显隐。
5. **实时层负责光和过程。** 四张静态材料输入交给 GPU 受光，正式 Rift fog 在其上；侵蚀发光的增强、减弱和材料碎屑使用同一时间；只表示画面变化，不能冒充危险机制。原生角色、相机、身体与移动速度不变。源材质若在转灯时出现冲突的烘焙方向，必须修源区/映射，不能改视野掩盖。

已完成的定向检查包括几何 63 项、九格双 seed 共 18 组原生身体部署、CSV/来源区校验、材料载入/失败重试/缓存、renderer 输入与释放合同、TypeScript 检查。renderer 明确验证只有材料事件可改变 finish；法向、编码高度、实体归属和自发光通道不因素材取样而改变。它们是生产与技术完成事实，不代替本轮实际图、持续游玩、性能或用户审美结论。

## 4. 构造与污染等级如何重新进入

三种材料能力及低/中/重的九个作者地段已在 I02 实现并完成双种子图像复核；它们仍不是九个正式世界或已获人审的母版资格。I01 曾按代理观察重结，当前污染定义与验收要求已重新打开；上一批板/束/壳外形未获得优先保留权，当前保留依据是完整地段的实际观察，不是 API 已有三个 family。

- **低档**先使普通世界值得探索：材料连续、局部异变具体、明暗与行走关系自然。不能故意少画，用重档替低档补完成度。
- **中档**体现相同材料被侵蚀、截断或重新连接。普通空间与侵蚀空间可比较，不只提高地面噪声覆盖率。
- **重档**静帧就有人相对结构、通路余量及侵蚀范围形成的压迫；吞光侵蚀有来源，普通残留材质保持可识别。动态显示绿色侵蚀在材料中的蔓延、闪动与局部变化。视觉高压不等于持续黑屏、遍地闪动或把碰撞暗改成攻击。

先在代表性地段把材料描绘完成，再验证其他构造和三级。不以轮廓小修替代全景；九个按钮或九张导出不等于九个母版。

## 5. 独立审核实际需要的产物

每次先提供正常使用尺寸原图及世界/等级/种子/源码版本/灯位，再给作者解释。DEV 入口存在只证明工具存在。

第一组是同一完整地段的进入位、贴近材料交界、绕行回望三个原生截图及连续移动/转灯。重点核查：

1. **地表是否画够。** 玩家脚下、安静通路、景观接地各看一处；若都是平底色加斑，即退回，不因主模型丰富而放过。
2. **普通世界与吞光是否分清。** 同站位关污染诊断仍有完整材料；开启时改变位于有归属区域。普通实体背光面不凭空消失，普通阴影不等同虚空。
3. **中尺度是否组织画面。** 能描述材料怎样经过转折、与别的材料相接，而非只能说“很多裂纹/颜色/噪点”。细节沿关系集中，安静处也不是未画。
4. **灯和动作是否有实效。** 肩灯移动时材质响应与真实遮蔽合理；角色脚底、搜取物、退路在混光中可读。未经连续观察不判移动、排序或操作完成。
5. **等级是否在同一世界成立。** 同结构意图的低中重先对照，再查普通种子；重度关闭动态后仍有空间压力，各处可见边界与实际可走范围一致。不同主题插画不能充当等级。

声音实现已接入原生 AudioManager，复用已有环境摩擦/阻力源，绑定实际侵蚀位置与画面变化；每周期锁定一个来源，最多两个声部，含距离/声像、暂停及销毁释放。`check-master-audio.ts` 的 47 项资源注册与播放端口行为案例已通过，不是未接入状态，也不是三套新制专用声库。**实际听感、混音与视听同步的独立审听仍未完成**：当前没有可用的实际审听证据，不能以行为测试冒充听过。审听继续核查有来源、有停顿、不过量，也不能用损伤/奖励提示暗示尚未实现的压力机制。

## 6. 当前验证结论与交接
