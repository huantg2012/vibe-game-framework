# 悬海：海离开了海床，水仍在寻找低处

2026-09-13用户“验证ok，提交吧”，验收本轮实际交付。内部局部观察与Agent未审听记录保留于[美术复核](../reviews/iteration-22-art-review.md)，不扩大成全目录或发行品质验收。

玩家走在被水长期压平、又被冲刷开裂的沉积面上。海悬在上方；一部分水周期性落回旧河道。地面、壳片和声音共同说明水的去向，巨大海体保持安静的重量。这里的异常来自稳定而不合常理的空间关系，不靠满屏闪光、随机蠕动或堆满异形装饰。

本合同只依据 [世界背景](../world.md)、用户选择的写意悬海与固定三维机位，以及 M 正常画面：[中岸](../qa/artifacts/iteration-21-gameplay/composition-2026-09-12T08-39-33-916Z/10-middle-bank-look-s.png)、[地面物件与断面](../qa/artifacts/iteration-21-gameplay/composition-2026-09-12T08-39-33-916Z/04-pressure-offset.png)。不使用历史审美 skill、HOW 或基因谱结论。机制、布局、时间和掉落的唯一正文为 [悬海内容合同](../content/suspended-sea.md) 与其 CSV；以下状态摘要只规定它们怎样被看见、听见。

## 1. 固定投影与画面主次

保留 M 的 35° 高度角、0° 水平偏角、1060 世界单位跨度与 960 × 640 逻辑画布。镜头随行只作平移。人物继续使用当前 42 世界单位高度，不因地图变大而缩小，也不为展示机关放大人物。

本文件的“屏幕像素”均指 960 × 640 原生画布，不能拿浏览器放大后的截图尺寸代替。在本机位下，1 世界单位沿左右约投影 0.906 px，沿地面前后约 0.519 px，沿竖直高度约 0.742 px。尺寸须在南北与东西两个方向都看一遍。

- 头顶海保留宽的灰蓝水光、墨蓝厚部和少数自然孔。近处流光面可以有硬像素轮廓，内部保持整块颜色；不把每条水光打散成密集噪点。
- 主角、敌人的准备动作、当前落水接地点依次获得可辨的局部对比。背景海的最高亮度不随技能施放突然抬升。水体变化来自现有世界时间，不跟着人物转身一起呼吸。
- 可走沉积面比垂直断面暖、略亮；薄岸唇下立即转入炭黑。保留 M 已修好的空间关系：天井通视但不能跨越，海只由当前视线及自然孔打开，记忆地形不再主动掏海。不得恢复跨海的岸壁栅栏或矩形透明块。
- 最外侧海的人工截面保持在正常取景外；不能用扩大黑幕、缩人物或抽远镜头解决地图接续。

## 2. 海床：用水流留下的大形状替换通用碎石

目前 M 的细碎石片能够说明“地面”，还不足以说明“海床”。本世界专用地表从三个尺度建立，不改其他世界的通用地面。

**大面是受压沉积。** 约七成可见地面保留连续的灰褐沉积底，不铺逐格随机石片。每片沉积面沿旧水路缓慢转向，长约 160–280 世界单位、宽约 48–96；边缘有宽窄与缺损，不能做等间距等宽的沙纹。实际已有缓坡决定足底起伏，材质随坡连续，不用画面明暗假造一道不可走的台阶。

**中层是冲刷与薄层翻边。** 在转弯、合流、天井出口附近出现少数成组的层缘：每组 2–4 道，组间留空。层缘投影宽约 2–4 px，长度约 24–70 px，不能横贯全部道路形成栅栏。退水沟从承水壳口连续通向实际天井边；只有真实水流时才出现移动湿光。普通干沟是浅的地表痕迹，不画成需要跳跃的深裂缝。

**小物只集中在水曾停下的地方。** 壳残片、被压扁的钙质碎片与细砂形成偏在一侧的滞留带。每处主簇 3–6 块，单片投影约 3–9 px；不是全图均匀撒贝壳。壳残堆若承载正式翻找，应有一个完整主轮廓和两三个附片，投影约 22–34 × 12–20 px；真实拾取与揭晓沿用既有规则，外观不提前泄露内容物。

色彩沿用当前 Stage 的物质关系：沉积主体取现有灰褐 `#45444a / #58534f / #6a6053` 的相邻层，局部干层缘可到 `#817565`；水湿部转向灰蓝，不能整片涂成荧光青。地面小纹理与本底的最终合成对比宜低于约 1.5:1；可击壳唇、真实接地水缘等少数行动信息需要更高对比。该值是初版制作目标，未测量的帧不得写成已通过。

岸边继续是很薄的干沉积唇，向下露出间断竖裂。竖裂亮部不连成横向平台，底部不出现能落脚的“井底”。海床在视野外仍未知，不为了展示纹理放宽感知。

## 3. 两种布局的空间节奏

以下是构图称呼；实际路线、危险位置与正式名称跟随内容合同及 CSV，不由材质绘制另造道路。

**开阔潮沟（`sea-open-channel`）。** 从西南低岸进入，先看见一片平缓沉积面与远处悬海腹部，随后沿西岸接近承水处。玩家从安全外侧可以同时看见薄壳唇、受侧溢影响的中央低道，以及通向天井的退水沟；让第一次完整水周期具有可观察的因果关系。北岸旁路从这个观察面也有可理解的入口。危险之后留一段安静的开面，再进入远岸搜取点；返程从不同距离重新遇到同一承水处。大面向前展开，细节集中在合流口，不把整条路径都做成窄桥。

**折返岸脊（`sea-folded-ridge`）。** 从南侧裂岸进入，路线被不同尺度的天井拆出先收、再开、再转向的节奏。先从斜对岸看见远端收获与退水去向，绕至另一岸后找到薄唇、接水核心和原侧溢路线。远端满载返回时，中央低鞍与绕过脊端的长岸需要再次作出选择。窄处后必须有能看清下一步的落脚面；危险不能与全部转弯、全部战斗、全部收益挤在同一小块地面。返程的远岸对照保留先前辨认过的层缘和壳残簇，不能仅靠换色区分前后。

两图共享沉积材料、壳口结构与水的方向关系。区别来自开合、接近角度、看到危险的先后次序及绕路，不以镜像同一构图、加倍纹理、换一套滤镜交差。海的天然孔不必跟天井一一配对，也不保证每一处收益点上方恰好有一圈展示孔。

## 4. 合拢的壳片：低矮、可踩过、受压后有着力点

这个对象是嵌在海床里的薄承接结构。绝大部分壳面与地面齐平；不新增阻行体，不阻断视线，不画成箱子、胸高水槽或站立敌人。真正的边界仍是天井与实际伤人的水。

初版壳面外形长约 64–80、深约 40–52 世界单位，在本机位投影约 58–72 × 21–27 px。采用一片偏长的浅凹壳面、一个短断角和一段可击薄唇；外轮廓不做标准圆、五瓣花或对称扇贝。最大抬唇高度不超过 8 世界单位，即约 6 px。干地可挥击站位距正式可击目标约 24–32 世界单位，必须落在正式撬棍 40 单位范围内；不能把有效目标藏进落水核心。

壳面主体是沉积覆盖的暗灰，薄断缘为少量灰白钙质；建议主面约 `#535751`、断缘约 `#909184`、内缝接近炭黑。这对基础材质色的 sRGB 对比约 2.31:1，不等于正常合成后已经达标。颜色进入现有光照与雾，不能以屏幕恒亮覆盖环境。玩家侧有效薄唇至少保留 16–24 px 的可辨长度，暗缝至少约 2 px；可击状态主要靠轮廓和受压姿态，不靠整件染亮或悬浮标记。

表现仅消费只读 `ShellView`：`mode`、`canHit`、`spillActive`、`diversionProgress`、`returnProgress`、`spillOutline`、`drainPath`、`hitSequence / hitAtMs` 与共享周期时间。`closed` 不等于可击，要同时看 `canHit`。

1. **静息压合：** 壳唇伏低，轮廓贴在沉积面内，几乎没有下方暗缝。保持安静，不做全壳呼吸。这里没有可着力的有效目标；挥空不播壳体命中音，不装作击中了无敌怪。
2. **汇流受压：** 真实汇流开始、`canHit` 成立后，薄唇沿已有折线逐渐抬高约 3–6 px，露出暗缝。面向岸道的一侧积水加宽，来水方向与将要侧溢的方向一致。不能在静息提前闪出攻击提示。
3. **真实命中并改流：** `hitSequence` 增加才出现一次短促抵抗与钙屑，约 70–100 ms；随后薄片沿折线侧错，投影错位约 8–12 px，露出连接退水沟的缺口。不爆碎、不弹出血、不播敌人受伤叫声。壳面总体不膨胀，击中动作不挪动权威目标。
4. **最多 600 ms 排空：** `mode=diverting` 要与 `spillActive` 一起读。若已经接地且侧溢仍有效，旧 `spillOutline` 的完整危险边界保留连续湿水边；水量可顺 `diversionProgress` 退去，但不能刚敲中就把旧危险范围画干。新流向逐步接上 `drainPath`。若在汇流早期敲开、水头尚未到地面，只表现壳片改变，不凭 `diverting` 提前画危险水。晚命中的余水最多维持到 `min(hitAt + 600 ms, contactEnd)`，自然已排空就随之停止，不补出额外伤害或假水。
5. **偏开排水：** `mode=diverted` 后旧岸道不再保留活动溅射或危险亮边。确实有接地来水时，水沿真实沟道入天井，接地点核心仍保持自己的危险窗；尚未落地或已经自然排空时，沟道不常驻流水。偏开的壳唇失去可着力姿态，不继续闪出可击提示；没有“关闭悬海”的大范围海面变化。
6. **卸压回摆：** 最后尾水接地结束后，按真实 `returnProgress` 在 650 ms 内回压。只有这一次有限回摆，不弹两三次橡皮反弹。新一轮危险必须经过新的完整汇流，不能回合瞬间突然恢复危险水缘。

壳片踩过时必须与脚底支撑一致。其内部暗缝读作薄片之间的窄缝，不画成可掉下去的大黑洞。线与石不控制壳片或水；声音诱饵只影响对应敌人；抗污染效果不伪装成挡住物理落水的护罩。确实受到水伤害的玩家仍需有正常身体承受反馈，壳片动作不能替代玩家受伤。

## 5. 水必须先到，危险与余水才成立

保留当前 `WaterFlowCycle` 的迟滞关系：上方先汇流，水头向下到达海床；上方断供之后，尾水继续向下，直到最后接地结束。禁止把整个水柱沿高度缩放收回海里。

- 汇流在海腹表现为一片收窄的宽暗褶和朝同一点汇合的浅光。范围局部，不让整张海都为一处危险发出统一呼吸。
- 下落主体分成两三束不等宽的水带，边缘有短暂分裂与再合。水带实际落点沿权威不规则轮廓展开；不能用标准圆盘或等距白点充当接地范围。
- 落地水缘在完整视线内投影宽约 2–4 px，短水舌约 4–10 px。高亮只沿当时真实触地和流向分布；不画一圈持续同亮的技能范围线。
- 接地核心、原侧溢和改流沟之间能够沿水纹追到连接；连接只发生在真实可承水地表。水进入天井后下坠、转暗，不横铺过无支撑空间。
- `contactEnd` 之后只允许无伤害的薄残湿退去；不能留下跟活动水同亮、同动作的残水，让安全恢复变成猜测。状态结束时改变的是流动和接触，不是整片地面突然换色。

## 6. 入场在 1.2 秒建立空间，最迟 1.5 秒交接

先听见近乎没有节拍的海压，随后看清脚下支撑和人，最后读到头顶宽阔的海。只做一次短入场，不插入文字说明或固定观看水周期。

建议 0–200 ms 接入世界底声；0–450 ms 让最终合成画面的下部与脚下地面脱离暗场；350–1100 ms 渐次建立上方海腹与远部大面；1200 ms 前结束入场遮罩。最多再保留约 200 ms 的已有镜头平移收稳，整个过程不超过 1500 ms。机位角度、投影跨度、人物比例始终不变，不为了抬头看海改成另一种透视。

该入场作用于**已正确合成的场景**。不能先隐藏海几何，借此临时展示本来不可见的敌人和地面；不能用入场强制打开视野。按内容合同，场景在准备态冻结模拟，入场完成或主动跳过后从同一准备态交控；表现层不私自改时钟、追加无敌或继续播放一段遮眼动画。若玩家已开始正常移动、攻击或已经进入活动模拟，立即撤掉剩余入场遮罩。该能力只用于本批隔离入口，不改主菜单或基地出击政策。

## 7. 音景：真实阶段驱动，离线合成后进入同一管理器

M 基线的实际文件由 `tools/audio-placeholders/generate.mjs` 使用 ffmpeg 的正弦、噪声与滤波离线合成，再编码为 OGG / MP3。现有素材没有悬海专用水声。本批可沿用这一可复现来源制作更具体的物质音，明确标注**程序合成，非现场采录、非外部生成模型产物**。本机已有 `tools/audio-placeholders/.bin/ffmpeg` 与 `ffprobe`，新增专用生成脚本可复用，不能重生或覆盖旧 43 个键，不需网络下载。不要求用户另找素材或生成资产。源参数、噪声种子、双格式时长、响度和循环接缝须记录；合成是否足够可信必须听实际混音，不能因文件非空而判定听感过关。

建议新增以下最小声音集合，最终键名由 `audio-catalog.ts` 注册；源配方与种子须随资产保存，保持双格式、44.1 kHz 单声道。所有空间方向由 `AudioManager` 给出，不在文件里烘焙固定左右声道。

- **海压床 `amb-suspended-sea-pressure`：** 一条约 16–24 s 可无缝循环的低沉宽噪声。主体在普通扬声器仍能听到的低中频，约 90–350 Hz，少量更低共振提供重量；不要以可辨的单正弦长音代替水体。高处有很薄的空气摩擦，不能满频白噪。进入本世界时替换 `amb-rift-alien-atmosphere`，不叠一床恒定海浪冲岸声。音量不随玩家转身起伏，也不暗示此刻正在落水。
- **汇流 `sfx-suspended-sea-gather`：** 约 1.2–1.8 s 的轻颗粒摩擦源，可循环或从状态取连续包络。少量不等距细碎声逐渐聚拢，低部共振略紧。只在真实静息结束至 `feedStart` 之间成立，强度读实际汇流进度；不能自行每隔数秒播放一次“预警”。
- **下落 `sfx-suspended-sea-fall`：** 约 0.5–0.9 s，无撞击开头的空气撕开与重水束。真实 `feedStart` 触发，水头到接地前不能已经有落地闷响。它不替玩家判断伤害，真正接地由下一声说明。
- **接地 `sfx-suspended-sea-contact`：** 约 1.5–2.5 s 的不等间隔低闷冲刷，宽噪声之下有断续湿沙摩擦。只在 `contactStart…contactEnd` 及真实侧溢状态期间维持。沿用同一水对象的近场实例；改流后声源可以移向实际沟道承接点，不能像关闭开关一样瞬间静音。
- **断供与尾水 `sfx-suspended-sea-drain`：** 约 0.6–1.0 s 的供水收窄与疏落尾声。上方供水停止可听到收窄，但接地冲刷继续至 `contactEnd`；之后留下短而分散的砂粒/水滴余响。不得把文件结束时间当成安全时点，不将残滴排成等距节拍。
- **壳体真实命中 `sfx-suspended-sea-shell-hit`：** 约 0.18–0.32 s。短钙质干裂声接低闷受压声，收尾是片缘摩擦；避免金属铃音、枪声、魔法爆破或动物哀叫。只消费新的 `hitSequence`，同一事件不在每帧重放。无效挥击不播“命中”，不以敌人伤音代用。

汇流、供水、接地、断供必须消费同一 `WaterFlowCycle` 的 `feedStart / feedEnd / contactStart / contactEnd / sourceFeed / residue` 与壳片权威状态。`closed / diverted` 是壳片姿态，不足以单独判定水声。暂停冻结阶段、声音与音频游标；恢复不中途补播已经错过的一串瞬态；中止、死亡、撤离与重开停止该场景实例，不留下一局的滴水。

接线使用现有 `playAmbient / stopAmbient`、`playSpatialSFX` 的 `instanceId / volume / loop`、`stopLoop` 与全局暂停/离场管理。汇流、接地和尾水不各留一个常驻声部；近场循环共用同一水对象实例，短瞬态按阶段切换。底声比干地脚步低约 8–12 dB，近场危险水比底声高约 5–8 dB，壳片有效命中应高于当时冲刷约 3–5 dB；这些是相同播放音量下的听感初始目标，需用实际混音调整，不是归一化文件峰值之间的机械比较。

总声部仍按现有 8 轨预算验收：本世界以海压替换原环境床，水循环最多一个；壳击、落地瞬态拥挤时先舍弃远处余滴等低优先级装饰，不吞掉真实近场命中与玩家受伤。`AudioManager` 目前对床音有名额豁免，因此不能只引用 `MAX_VOICES=8` 宣称实际没有超额；必须在正常战斗加落水的录音中检查实际声部。新素材不得另建 AudioContext 绕开管理器，也不复用敌人空间曲线来假装一种新的水体听距；本批近场对象可沿用现有 `point` 曲线，超过听距就以安静海压维持环境。

## 8. 本批有限验收

最多两轮内部视觉与音景调整。第一轮同时看两布局的正常原速录屏/录音，指出最影响读法的具体问题；第二轮只复核这些问题和相关回归。仍不清楚的部分如实保留，不能把持续扩充装饰算作完成。

必须留存以下正常证据：

1. 两图从进入、第一次观察水周期、可选绕行、一次有效敲开到返程。全程机位、人物尺度和支撑面稳定；海床的大形状能说明水流，不能只看见换色的碎石。
2. 同一对象静息、受压可击、命中、600 ms 排空中段、排空完成、650 ms 回摆及下一轮汇流。各截帧附同帧只读状态；静帧不替代动作平滑和时序证据。
3. 从安全位置看到薄唇；旧水没排尽时仍有危险读法；排尽后旧路可辨，而核心仍在落水。等待与绕行同样能够通过，不要求玩家读文字才能识别哪一片仍在落水。
4. 壳片/水被海与地形实际遮住时不显示贯穿描边。天井北沿、南沿及返程保留正确断面，不重新出现平面墙、海上栅栏或记忆开海。
5. 一段原音量录音覆盖海压、完整水周期、有效壳击、玩家真受水伤和附近战斗，并单独确认暂停/结束/重开没有重叠遗留。未实际监听就写“声音已接线、听感待复核”。

画面初版需要测到：可击唇至少 16 px 连续轮廓、受压抬起约 3–6 px、命中侧错约 8–12 px；当前可见薄唇与紧邻壳面的局部对比目标不低于约 2.2:1。只量正常合成帧的指定相邻位置，并记录视角、受光和状态；不要求黑暗深处仍恒亮。上述尺寸/对比只是抓“做了却看不见”，不能代替审美判断。
