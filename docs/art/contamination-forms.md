## 共享纪律

1. **不新色。** 污染亮核只用板里的青绿：`#1aad96` / `#2ae6c8` / `#3cffd4`（核点，克制）。墙锈 / 缝用该岛 `wallBias*` 量化后的暗灰，不要暖污染。
2. **不换精灵表。** 乙丁是程序像素或 Graphics 漆，不是第二套 walk cycle。
3. **连通 FATAL。** 漆、体积、墙斑不得改碰撞、不得切开墙后地板。乙核钉在墙格。
4. **覆盖体不是第三种人形。** 高度覆盖走缝 / 簇 / 体积。
5. **世界可读是第一课。** 旁白不得当救命字。核 / 缝 / 簇 / 云必须能在迷雾**可见区**内被读成「那里有一口」。
6. **头上无字。** 抽打格、体积、核都不要钉名字。

深度（相对裂隙 `RiftScene` DEPTH）：地表 0，簇活层 `surface+0.05`，乙核约 20（低于敌人 25），玩家 30，丁体积 **40**，视野蒙层 **50**。丁必须仍在蒙层之下。丙视觉 ≤ `surface+1`，不要盖过玩家。

## 迷雾与 `FormVisualPose.visibility`

练习场句法课**不开** `VisibilitySystem`（`gymVisible` 恒 1）。裂隙出击**开**。方案 D 四张孔谱在真实视野蒙层下的可读性，第一次由人在裂隙里看。

### 规格锁（I3-E 必须按此接线；可机器核对深度与采样，不可机器勾审美）

1. **采样。** 出击每帧把该实体代表点交给 `getVisibilityAt`，写入 `pose.visibility`。代表点：甲 = 身体位置；乙 = 缝坐标（`seamX/seamY`，不是墙格心）；丙 = 簇核；丁 = 当前盒心（活盒，不是静帧盒）。不要用玩家位置冒充敌人可见度。
2. **取值。** 与 `VisibilitySystem` 合同一致：`0`（蒙层未擦到）/ `0.2`（外圈）/ `0.6`（中圈）/ `1.0`（内核）。不要另发明 0.15、不要平滑插值成新档。
3. **消费。** `visibility === 0`：核 / 缝 / 簇 / 云 / 抽打点 / 脚底浊点 **alpha 0 或隐藏**，禁止在全黑区自己发光。`visibility > 0`（可见区，**含外圈 0.2**）：实体按该值乘 alpha；**仍须能被读成「那里有一口」**——靠剪影、核点、缝、簇外沿或云外沿，不靠头上字、不靠旁白救命。
4. **禁止照搬句法课下限。** 方案 A/D 甲乙实现里有过 `Math.max(0.2, pose.visibility)`。句法课恒 1 时看不出问题。出击若保留该下限，可见度 0 的个体会以 20% alpha 打穿迷雾。**出击禁止这条下限。** 句法课可继续恒 1。
5. **丁仍低于蒙层。** 丁视觉 depth = **40**，`DEPTH.visionMask` ≈ **50**。禁止把云抬到蒙层之上「为了看清」。可读性靠可见区内的剪影，不靠钻出雾。
6. **不要第二层雾。** 丁的体积感来自云本身；禁止再用一块黑暗蒙层冒充体积。反视核暗/亮是 `lexemes.sense`，乘在 `visibility` 之后，不要把反视做成迷雾开关。
7. **不新色、不抬核去对抗蒙层。** 亮核仍只许 `#1aad96` / `#2ae6c8` / `#3cffd4`。不要为了雾里更跳而加 bloom、描边、第二套更亮 hex。

### 留给人终审（禁止代勾 PASS / 好看 / 视觉过关）

- 可见区里核 / 缝 / 簇 / 云的**亮度**好不好看（外圈 0.2 是否太暗或太跳；青绿是否在蒙层下过亮）。
- 丁云在外圈是否还能认成云，还是糊成地板污渍。
- 甲身上的簇是否被地面崩坏簇淹没（区分规则仍走 `art-direction.md` §13.2：实体簇贴身并脱落；环境簇钉地板、尺度更大）。
- 贴身暖灯照到甲时，基体色能不能从地面里读出来。
- `art-direction.md` 里「迷雾下亮度等人终审」整条——本文不收口。

机器可以核对：丁 depth < 50；`visibility === 0` 不打穿；可见区仍画核/缝/簇/云。机器不能核对「亮得刚好」。

### 载体与参考（实体，不是面板）

污染体是钉世界坐标的实体，走 Phaser 世界层，不是 `#dom-ui-root` 上的装置读数。不要做成检视卡、进度条、圆角怪物肖像、头上名牌。练习场侧栏仍是开发说明，不要翻修成墙机。遭遇识别旁白是裂隙随身罩（元界面），挂 `#dom-ui-root`，**不是**本实体的字。

这些东西是裂隙里表征失败的物件（会走的残影、墙缝里的核、会呼吸的地、走廊里的错体积），不是哪台终端打出来的字。亮来自污染核（板内青绿），脉动来自覆盖后的节律，不是 UI glow。

### 共享：配色

一律 `deriveFragmentContamRamp(fragmentTypeId)`（`d/fragment-ramp.ts`）。语义：碎片 `wallBias*` / `floorBias*` → 往青绿轴 0.48 拉 → `nearestPalette`。禁止写死一组 `CONTAM_*` 当所有院子的污染色。禁止给 `palette.json` 加色。禁止改 `bakeGround` / `preview-paint.ts`。

| 层 | 色从哪来 |
| -- | -------- |
| 污染 DEEP / MID / CORE / GLOW | 该碎片 ramp 四档。**亮核像素**只许是 `#1aad96` / `#2ae6c8` / `#3cffd4` 三色之一（ramp 量化若偏了，画核时钳回这三色）。DEEP/MID 可以是 ramp 量化后的暗青绿，必须在 `palette.json` 内 |
| 基体残影（肉/布/骨/砖/金属） | 板内 `flesh-dead` `#2e2d30`、`cloth-dark` `#2a2a2e`、`bone-grey` `#3a3838`、`earth-dark` `#1a1c1f`、`brick-dark` `#2a1f1c`、`metal-grey` `#4a4e55`。允许按该碎片 L1 混 12–18% 再量化，让五种碎片的同一只敌人肉眼有色温差 |
| 墙锈 / 缝底 | 该碎片 `yardSurfaceColors.wall` 暗灰，不要暖污染 |

### 甲（R2-C3 → 出击生产）

路子：方案 A 的程序像素词法。画布渗透 32×32、改写/覆盖 32×48（听噪无论覆盖深度都 32×48）。碰撞边长 20；偏移 `(画布边长 − 20) / 2`。四向直立换贴图。禁止精灵表。禁止第三种人形。

**不要改** `infiltrator-sprite.ts` / `rewriter-sprite.ts` 来做本节。那两份仍给默认敌人课与 `placeholder`。裂隙甲走 `d/jia-*`。手法对照可以读那两份（密像素前倾、叠簇、melt），不要把整数 CLUSTER 表原样盖到灯柱上。

**覆盖深度 — 对标改写体手法，禁止 `applyCoverageFail`。** 方案 A 对照里的三档是透明掉 0% / 38% / 74% 再改点颜色。D 不许再用百分比挖洞当主手段。三档都是「基体剪影还在 + 污染层怎么叠」，浓度递进不换语言。

| 覆盖 | 基底层（启动时画进贴图） | 污染层（叠在基底上，不是挖透明） | 动态层 | 画布 |
| ---- | ------------------------ | -------------------------------- | ------ | ---- |
| 渗透 | 该族 FLESH/CLOTH/BONE 剪影完整可读 | **不要簇。** 5–6 个家族散点（渗透体 `paintSpecks` 那种）：多数 ramp.core，偶发板内 `#1a7a9a`。散点随步态 sway ±1px | 步态 squash-stretch；无 melt | 32×32（听噪 32×48） |
| 改写 | 完整侧仍是该族肉/布；崩坏侧先铺 ramp.deep（可留 `(f+r)%5===0` 数据孔） | **成簇，不是散点。** 15–20 个 ramp.core 像素分成 2–3 团贴在崩坏侧（改写体 CLUSTER 是 17：胸 7 + 髋 6 + 外沿 4），再盖 2 个 ramp.glow 簇心。完整侧只留 **1** 个家族散点 | `warpMotion`：ramp 青绿像素沿朝向 ±1px melt（行走帧 1 / 3）；按信号换变体：静默=簇为 core；搜寻感=`strike` 以外的警觉把 4 格改 glow；追击感=多数簇改 glow、留 3 格 core，并每 8 帧沿朝向抖 1px | 32×48 |
| 覆盖 | 该族轮廓还在，但完整侧打数据孔、肉只剩残边 | 簇加到 28–36 px，溶散喷点（ramp.mid）出轮廓外沿；仍是这只占地的剪影，**不是**覆盖体几何结构，也不是第二种走的人 | melt ±1px 每行走帧可发生；脱落尘往外/往下（若抄 `contam-flakes` 进 `d/`，不要改默认课那份） | 32×48 |

簇要贴在**该族剪影的崩坏侧**（有机/残茎：身体右侧；灯柱/栏柱：沿杆一侧），不要把改写体那张 32×48 CLUSTER 整数表原样盖到灯柱上。不要用整 sprite 降 alpha 冒充覆盖深度。

**族内剪影变体：** 每种占地合法基体 ≥3 种，由 `mix32(seed, substrate) % 3` 生产，与覆盖深度正交（变体改剪影，覆盖改叠簇）。不另写 CSV 行。概念基体禁止给甲。

| 基体 | 残余 | 变体 0 | 变体 1 | 变体 2 |
| ---- | ---- | ------ | ------ | ------ |
| `organic_remnant` | 走 | 前倾猎食、长臂（渗透体家族） | 肩宽 +2px、臂少伸 2px | 躯干中线 1px 缝（崩坏，不是触手） |
| `stalk_clump` | 摇 | 3–4 根竖茎聚中轴，顶碎 | 整体前倾 2px，一侧更密 | 2 根主茎 + 间隙；走时间隙开合 1px |
| `lamp_pillar` | 亮 | 3px 立柱，顶 1px 灯核 | 5px 粗柱，核在中上 | 上段错位 1px，核在折点 |
| `railing_post` | 拦 | 细杆 + 底座加宽 | 顶 1px 横杆 | 双杆相距 4px，仍一个碰撞 |

### 丙（R2-C4 → 出击生产）

路子：方案 B 的地表方言活体。外观 = 已烤簇语义 + DEC-070/071 整团胀缩。**不另做小人。** 不要第二套呼吸算法。不要走 infiltrator walk cycle。

人点名「几近完美，补多样性」。在 B 的 `ShapeKnobs` 上加可感旋钮，不要换语言：

| 旋钮 | 锁 | 句法课侧栏要能看出；出击随抽卡同样换 |
| ---- | -- | ------------ |
| 团扁 | `rxMul` / `ryMul`：菌毯偏圆瓣；油膜偏扁带（`thin`）；灰幕更扁、像覆层 | 切基体即换 |
| 核偏移 | 核相对团心 0–6px，跟 `sense` 朝向 | 切感知即换 |
| 外沿破损 | `notch` + `warp`：渗透缺口多、覆盖缺口少但团更实 | 切覆盖深度即换 |
| 碎片配色 | ramp 四档，禁止 B 对照里写死的单一 teal | 切碎片身份即换 |

新基底 `ash_veil`（覆）：薄幕，`thin: true`，瓣少，缺口沿外沿，像一层灰盖在已有地面簇上——仍是同一套簇漆，不是雾滤镜、不是小人披风。`fungal_mat` 保持多瓣团。`oil_film` 保持薄带。连续性：单核一团；菌落卫星；场=本图最显眼团。碰撞不改。depth ≤ surface+1。

被打核：核 1–2 帧 `#3cffd4`。死亡：核灭，漆可留作无害纹样，不要挖地板。迷雾：可见区内团外沿与核仍须能看成「这地在呼吸」；亮度等人终审。

### 乙（R2-C5 → 出击生产）

沿 B 的「缝里一颗核」方向重做位置与运动。禁止再把 32×32 锈斑画在墙格几何中心（`col*32+16, row*32+16`）。

**附着：** `pin.attach` 已有 `face` / `nx` / `ny` / `seamX` / `seamY`。核钉在 `(seamX, seamY)`。厚度只在墙格朝走廊的那 **1–3px**（沿法线 `(nx,ny)` 走进可走格），覆盖深度 渗透=1 / 改写=2 / 覆盖=3。核 2×2 或 3×3，覆盖不超过 4px，色 ramp.glow 或 `#2ae6c8`。墙皮底用 `yardSurfaceColors.wall`。不要把身体画进走廊碰撞；不要占满 32×32 墙格。出击活路径的 `getVisualPin` 必须含 `attach`。

**游荡：** 整只 Image/Graphics 跟 `pose.x/y`（缝坐标）走。运动是宿主沿 `orderWallEdgeTiles` 换钉，不是画布内 `seamSlidePx` 假滑。`motion_anchor` 停；`motion_wall` 缓慢沿相连墙皮；`motion_turn` 可掉头。开合相只胀核，不把核跳进走廊。

**抽打提示：** `signal === 'strike'` 时，对当前 `strikeFloors` **每一格**在地格中心画 1px `#1aad96`（方案 A 乙有过点，但钉在 pin 右侧一格——D 必须跟真实邻接可走格）。无全格闪白、无全息圈。一次提示正在抽打的那些格。B 藏掉默认 4×4 telegraph 之后，D 必须自己画这些点。点同样吃 `visibility`。

成句「缝里的眼」：1px 缝亮，不成对瞳孔。死亡：核灭，可留不挡路墙锈。迷雾：可见区内贴墙能看见缝里一颗核，即「那里有一口」；走廊中央仍可以看不见身体。

### 丁（R2-C6 → 出击生产）

要像缓慢移动、微微形变的**云**，不要方案 B `paintVolume` 那种逐像素 hash + 棋盘格跳采样填满 pin 盒。基底不是油膜。三类概念基体必须肉眼可分（灰度仍可分：靠形状，不靠色相故事）。depth **40**，禁止 ≥ 50。

云的共用语法：不规则外沿（椭圆/缺角/噪声轮廓，禁止统一圆球）；内核更实、外沿更薄；2–4 秒外沿呼吸（休息大小的 8–15%，不是 1–2px 描边、不是整团闪透明度）；位移跟体积盒（`motion_wind` / `motion_trail` 移盒；`motion_anchor` 只形变不位移）。alpha 外沿约 70–120、核约 160–220（8 bit），几乎不透明的薄体积，不是全屏滤镜。这组贴图像素 alpha 再乘 `pose.visibility`。

出击视觉跟**当前盒**（`pin.x/y/width/height`，活机制下为 `dingLiveRect`），不要画出生时的静帧走廊盒。

| 基体 | 残余 | 剪影（必须分开） | 不要画成 |
| ---- | ---- | ---------------- | -------- |
| `sound_echo` 余响 | 响 | **回声带**：同一外沿的 2–3 圈 1px 量化轮廓，相位错开 0.3–0.6s，像表征失败被延迟重画。带间距 3–6px | 音响波纹 UI、喇叭、声波图标 |
| `light_scatter` 散光 | 折 | **折裂亮脉**：云体几乎空，只有 3–8 条 1px ramp.core/glow 脉在体内折一下再接上；脉随节律微移 1px | 手电筒光锥、全息网格、镜头光晕 |
| `space_interval` 间距 | 挤 | **错位暗体积**：ramp.deep 为主的暗云，比走廊盒窄 1 格或错位 8–16px，路看起来被挤窄但仍可走 | 油膜棋盘、第二层黑暗蒙层、实心假墙（不得改碰撞） |

成句 `corridor_watching` 绑 `space_interval`：反视核（盒内一格可走地板 2×2 ramp.glow）在玩家扫到前几乎不亮，扫到后亮同一色。核不要做成眼睛。死亡：alpha 收掉；核灭；不要放光柱。残骸不挡路。

禁止：hash 填盒、棋盘跳采样当主签名、bloom、整屏雾、把云抬到视野蒙层之上。迷雾可读性：可见区内能认成「这段路有一口云」；外圈亮不亮由人终审。

内容层（I3-G）落地前，出击抽卡可能仍抽出油膜占空——那是内容开关事实。本 HOW 仍要求丁的**画面**是概念三类云，不要把油膜棋盘当生产外形。I3-E 请人看丁之前，I3-G 必须已收回油膜占空。
