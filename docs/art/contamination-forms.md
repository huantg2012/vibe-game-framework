## 共享纪律

1. **不新色。** 污染亮核只用板里的青绿：`#1aad96` / `#2ae6c8` / `#3cffd4`（核点，克制；`#3cffd4` 不得作四档填充）。墙锈 / 缝用该岛 `wallBias*` 量化后的暗灰，不要暖污染。四档对地面主色见「共享：配色」。
2. **不换精灵表。** 乙丁是程序像素或 Graphics 漆，不是第二套 walk cycle。
3. **连通 FATAL。** 漆、体积、墙斑不得改碰撞、不得切开墙后地板。乙核钉在墙格。
4. **覆盖体不是第三种人形。** 高度覆盖走缝 / 簇 / 体积。
5. **世界可读是第一课。** 旁白不得当救命字。核 / 缝 / 簇 / 云必须能在迷雾**可见区**内被读成「那里有一口」。
6. **头上无字。** 抽打格、体积、核都不要钉名字。

深度（相对裂隙 `RiftScene` DEPTH）：地表 0，簇活层 `surface+0.05`，乙核约 20（低于敌人 25），玩家 30，丁体积 **40**，视野蒙层 **50**。丁必须仍在蒙层之下。丙视觉 ≤ `surface+1`，不要盖过玩家。

## 迷雾与 `FormVisualPose.visibility`

练习场句法课**不开** `VisibilitySystem`（`gymVisible` 恒 1）。裂隙出击**开**。方案 D 四张孔谱在真实视野蒙层下的可读性，第一次由人在裂隙里看。

### 规格锁（I3-E 必须按此接线；可机器核对深度与采样，不可机器勾审美）

1. **采样。** 出击每帧把该实体代表点交给 `getVisibilityAt`，写入 `pose.visibility`。代表点：甲 = 身体位置；乙 = 缝坐标（`seamX/seamY`，不是墙格心）；丙 = 簇核；丁 = 当前盒心（活盒，不是静帧盒）。不要用玩家位置冒充敌人可见度。
2. **取值。** 与 `VisibilitySystem` 合同一致：`0`（蒙层未擦到）/ `0.2`（外圈）/ `0.6`（中圈）/ `1.0`（内核）。不要另发明 0.15、不要平滑插值成新档。
3. **消费。** `visibility === 0`：核 / 缝 / 簇 / 云 / 抽打点 / 脚底浊点 **alpha 0 或隐藏**，禁止在全黑区自己发光。`visibility > 0`（可见区，**含外圈 0.2**）：实体按该值乘 alpha；**仍须能被读成「那里有一口」**——靠剪影、核点、缝、簇外沿或云外沿，不靠头上字、不靠旁白救命。
4. **禁止照搬句法课下限。** 方案 A/D 甲乙实现里有过 `Math.max(0.2, pose.visibility)`。句法课恒 1 时看不出问题。出击若保留该下限，可见度 0 的个体会以 20% alpha 打穿迷雾。**出击禁止这条下限。** 句法课可继续恒 1。
5. **丁仍低于蒙层。** 丁视觉 depth = **40**，`DEPTH.visionMask` ≈ **50**。禁止把云抬到蒙层之上「为了看清」。可读性靠可见区内的剪影，不靠钻出雾。
6. **不要第二层雾。** 丁的体积感来自云本身；禁止再用一块黑暗蒙层冒充体积。反视核暗/亮是 `lexemes.sense`，乘在 `visibility` 之后，不要把反视做成迷雾开关。
7. **不新色、不抬核去对抗蒙层。** 亮核仍只许 `#1aad96` / `#2ae6c8` / `#3cffd4`。不要为了雾里更跳而加 bloom、描边、第二套更亮 hex。

### 留给人终审（禁止代勾 PASS / 好看 / 视觉过关）

- 可见区里核 / 缝 / 簇 / 云的**亮度**好不好看（外圈 0.2 是否太暗或太跳；青绿是否在蒙层下过亮）。
- 丁云在外圈是否还能认成云，还是糊成地板污渍。
- 甲身上的青绿是否被地面有主占漆淹没（区分规则仍走 `art-direction.md` §13.2：实体青绿贴身并脱落；环境青绿是钉地板的占漆宿主，不是氛围簇地毯）。
- 贴身暖灯照到甲时，基体色能不能从地面里读出来。
- `art-direction.md` 里「迷雾下亮度等人终审」整条——本文不收口。

机器可以核对：丁 depth < 50；`visibility === 0` 不打穿；可见区仍画核/缝/簇/云。机器不能核对「亮得刚好」。

### 共享：配色

污染四档与该碎片地面主色**协同但不提亮**（DEC-088）。任务是：读得出是污染（青绿光谱内）+ 与该碎片地面主色保持对比度下限。碎片身份由渍 / 纹理 / 结构承担（`docs/art/rift-fragment-surfaces.md`「碎片身份配方」），**不**由污染色相承担，**不**由地板众数或底色色温承担（DEC-088 / DEC-093）。禁止按户外绿青 / 医院白青 / 地铁蓝青给污染层分工。禁止「方言选择器按碎片分工色相」。禁止给 `palette.json` 加色。禁止整体提高 `floorBv`。禁止色板亮端整只发光（`docs/art/samples/world-coordination.png` 最右栏不采纳）。`docs/art/samples/proto-fragment-ramp.png` 右栏的碎片色相分工已撤回，禁止照抄。

地面有主占漆与敌人四档调**同一份**选色函数。禁止第三套 ramp。禁止 `preview-paint.ts` 与 `fragment-ramp.ts` 再各写一份无约束 `nearestPalette`。渲染器禁止 `if (substrate === …)` 选色。若生产仍把 `floorBv` 当 0–255 做全色板最近色，那是实现没跟上本 HOW，禁止另写一套函数凑对比度。烤地不再铺氛围簇；成片青绿走宿主。

**函数与数字（引用 I6-A「配色公式」，不另发明切法）：**

- `mean(rgb)`、`chromaDir(rgb)`、`quantizeInGroup(targetRgb, candidateSet, used)`、`temperatureGroup(r, g, b)`：全文见 `docs/art/rift-fragment-surfaces.md`「配色公式」。组内比明度归一化后的色相方向，并列才用 RGB 欧氏拆开。允许结果比目标更亮；禁止到候选子集之外找更近的格。
- **对比度用的地面主色：** 模拟 RGB = `floorBv * (floorBiasR, floorBiasG, floorBiasB)`（**不加**绘制器 `+16`）→ `temperatureGroup` → `quantizeInGroup` 得到的地板主格。四档、闸门、地面与敌人都对这一格算。不是烤图众数，也不当碎片身份。
- **L2 强制青绿家族**（与 `measure:ground-teal` 同一集合）：`#0e4a3f` `#1a6b5c` `#1aad96` `#2ae6c8` `#3cffd4` `#7fffee` `#4adf8a` `#b0fff5` `#1a7a9a`。暖碎片的污染也进青绿组，禁止进暖组变成褐斑。L2 **不**继承该碎片的暖 / 冷 / 橄榄组。
- **四档子集：** 深 / 中 = `#0e4a3f` `#1a6b5c` `#1a7a9a`（互异）；核 = `#1aad96`；呼吸高光 = `#2ae6c8`。亮核三色克制：`#1aad96` / `#2ae6c8` / `#3cffd4`。`#3cffd4` **不得作四档填充**，只允许 1 像素星点（若画星点）。`#7fffee` `#b0fff5` 体量与四档都不用。`#4adf8a` 不进四档填充。
- **感知距离：** CIE76 ΔE*ab（sRGB 8-bit → 线性 → XYZ D65 → Lab，转换式见 I6-A 同节）。禁止交并比。禁止只断言两个 hex 字符串不相等。禁止用 RGB 欧氏距离当对比度闸门。
- **对比度下限：** 四档每一档与该碎片地面主色的 ΔE*ab ≥ **18**。四张碎片同一数字。组内所有候选都 < 18 时：取该子集里 ΔE 最大的一格，仍不得离开子集，并记失败。禁止跨组去全色板「找更近」。迭代 5 的 I5-C / I5-H 与地面共用这一条，禁止两边各写一套阈值。

| 层 | 色从哪来 |
| -- | -------- |
| 污染 DEEP / MID / CORE / GLOW | 上表四档。亮核像素只许 `#1aad96` / `#2ae6c8` / `#3cffd4` 三色之一，且 `#3cffd4` 不作填充。DEEP / MID 必须落在深 / 中子集内 |
| 基体残影（肉 / 布 / 骨 / 砖 / 金属） | 板内 `flesh-dead` `#2e2d30`、`cloth-dark` `#2a2a2e`、`bone-grey` `#3a3838`、`earth-dark` `#1a1c1f`、`brick-dark` `#2a1f1c`、`metal-grey` `#4a4e55`。残影**不**承担碎片身份，禁止靠混 L1 让五种碎片的同一只敌人读成五个世界 |
| 墙锈 / 缝底 | 该碎片墙色暗灰，不要暖污染 |

切碎片时四档必须相对该碎片地面主色重算（对比度合同）。不要求五张碎片的污染色互相可分。只换地板、敌人仍用同一组写死 teal = 没做对比度。按碎片给污染分工色相 = 做错了题。

渗透档家族散点允许偶发板内 `contam-cold` `#1a7a9a`（在深 / 中子集内）；覆盖档簇心不用它当填充。

### 甲（基因谱；I5-A 已交）

对照样本**只许**这三张：`docs/art/samples/current-jia.png`（现状：覆盖不改轮廓、变体差 2 像素、非生物全是竖杆）、`proto-jia-individuals.png`（同基体同覆盖档多种子 = 不同个体）、`proto-jia-escalation.png`（同一个体三档 = 结构违规）。`proto-fragment-ramp.png` 与 `world-coordination.png` 展示的是已撤回的「按碎片分工污染色相」与不采纳的「色板亮端整只发光」，禁止照抄进画法。

路子：方案 A 的程序像素词法。四向直立换贴图。`GameObject.rotation === 0`。禁止精灵表。禁止第三种会走的人形。概念基体禁止给甲。

**不要改** `infiltrator-sprite.ts` / `rewriter-sprite.ts`。那两份仍给默认敌人课与 `placeholder`。手法对照可以读密像素前倾、叠簇、melt，不要把整数 CLUSTER 表原样盖到任何基体上。**I5-J 之前**裂隙默认甲绘制仍走 `d/jia-*`；基因谱模块练习场先行。出击抽卡在翻列前仍可能抽到灯柱 / 栏柱行——那些行走旧画法，不是下面第七条语法。基因谱甲厅不挂单独的灯柱厅 / 栏柱厅。

本 HOW 不产出 `residual_verb` / `legal_occupancies` / `legal_continuities`。上屏短名已锁，禁止微调：街具残骸 / 门框 / 残茎 / 有机残影 / 虫 / 哺乳动物 / 大号蠕虫。碎片不按世界偏置甲骨架（诊所杆更细等不在本迭代）。

#### 三层管线

| 层 | 输入 | 输出 |
| -- | ---- | ---- |
| 骨架语法 | 基体 + 种子 | 一组节点（位置 / 尺寸 / 朝向 / 角色） |
| 共享构件 | 节点 | 像素：杆 / 梁 / 团 / 座 / 丝 / 碎 / 核 |
| 违规预算 | 覆盖档 + 种子 | 作用在**骨架**上的算子；然后 `weld` |

污染漆（deep 铺崩坏侧、core 成簇、mid 溶散）**最后才刷**。覆盖档的身份是结构违规，不是漆更浓、洞更多。禁止 `mix32(seed, substrate) % 3` 三张手写变体表。变体 = 种子在语法参数上连续采样。同覆盖档 16 个种子的去重剪影必须 = 16。机器量形走粗占格，不用交并比。

#### 共享构件（跨七个基体）

构件跨基体共享，这是基因谱的物质基础。禁止为某个基体私造第八种构件。若要新种类：停，回 art。

| 构件 | 怎么读 | 像素约束 | 禁止读成 |
| ---- | ------ | -------- | -------- |
| 杆 | 原物的承重直线。竖向为主（柱、肢、茎）。读「还有一根东西立着 / 撑着」 | 宽 1–3px（街具骨干可到 5px）；长边明显大于短边；端头齐或错 1px | 触手、弯曲黏膜、电路走线 |
| 梁 | 原物的横向构件。跨杆或从杆伸出。读「曾经连着」 | 厚 1–2px；违规前与杆近直角 | 飘带、黏液桥 |
| 团 | 原物的质量块（躯干、灯箱、标牌、腹甲、楣心） | 硬边缺角的密像素块，不是圆球 | 肉团、囊肿、湿边 |
| 座 | 着地加宽。读「这东西站在地上」 | 底边比杆宽 2–6px；贴画布底。街具残骸必须有座。虫 / 哺乳动物的着地是足端，不必另做街具座，但足必须焊住身体 | 一摊液体、根须盘 |
| 丝 | 1px 连接线。原物的细构件或残骸连线 | 必须接到另一构件（`weld`） | 蛛网、黏丝、神经、触手 |
| 碎 | 从主体裂开但仍焊住的小块。读「坏了」，不是「掉了」 | 1–4px；必须 `weld` | 漂浮粒子、喷溅体液 |
| 核 | 污染亮点，不是原物器官 | 1–2px，贴崩坏侧；只许亮核三色 | 成对眼睛、灯具光源（灯柱邻域的灯箱残影用基体暗格，不是核） |

#### 禁忌边界（定稿，可执行）

**原则：** 基体 = 被污染的**原物残余**，不是污染自己长成的形态。`art-direction.md` 禁忌（触手 / 内脏 / 血浆 / 虫卵 / 黏液 / 有机腐烂）与「污染不是有机的」禁的是**污染侧**呈有机恶心；`world.md` 偏好几何异变 > 生物恶心。原物曾经是动物合法。「一头哺乳动物的残余，它的渲染坏了」合法。污染侧也不许画成可命名的晶体 / 电路 / 蜂窝（表征失败，不是一种新物种）。

**残余允许（基体侧）：** 骸骨、干尸、壳质、分节结构。硬边、脱水轮廓、甲片、干环。

**污染侧不允许：** 软组织、流体、蠕动黏膜、内脏外露、虫卵。以及触手、黏液、有机腐烂、血浆。

**正例（下游按此验收）：**

1. 哺乳动物：头–躯干硬边骸骨，肢按邻域（短肢长尾 / 长肢+角碎 / 四足撑开 / 直立两足两臂），崩坏侧焊青绿团 / 碎——基体仍是骸 / 干尸。禁止一律四条干肢。
2. 虫：左右对称的壳质足，腹甲硬边；污染只把足的数量或朝向违规——基体仍是壳质 / 分节。
3. 大号蠕虫：一串干环，环与环 1px 相接；污染把某几环放大或拧 90°——基体仍是分节，不是黏膜。
4. 街具残骸：锈杆 + 座，灯箱残影用骨灰 / 金属暗格，青绿簇贴杆侧。

**反例（出现即不合格，回 art，禁止 code 自己发明有机恶心）：**

1. 从灯柱或标牌杆垂下触手、黏液丝、湿边波浪。
2. 虫腹下挂成串圆粒（虫卵），或足间拉黏膜。
3. 哺乳动物胸口裂开露出内脏 / 血浆。
4. 蠕虫外沿波浪蠕动、拖一条流体尾、身体像湿肉。
5. 把污染画成电路走线或晶体簇，当作可命名的新物种。

灰度下仍须靠体轴 / 肢数 / 中空框 vs 实心杆分清七个语法，不靠色相故事。

#### 七个骨架语法

每条语法给零件与采样规则。禁止三行手写剪影。侧栏切基体时外形必须换语法，不能只换散点颜色。

##### `street_wreckage` 街具残骸

**语法：** 竖杆 + 底座骨干。至少 1 根杆、1 个座。可选梁、可选顶团或中上段扁团。读「街上还立着一截东西」。不是中空门框，不是一丛茎，不是生物。

**灯柱 / 栏柱 / 标牌杆 = 种子采样邻域，不是三行 CSV，不是三个基体，不是三个厅。** 种子在共用参数上连续采样；三个名字是邻域，用来检查「厅里看得到三种街具残法」，禁止硬切三条 `if` 当剪影身份。邻域可重叠。

共用参数：杆宽 2–5px、杆倾 0–2px、梁厚 1–2px、座高 2–4px、接缝错位 0–2px。

| 邻域 | 杆数 | 座 | 梁 | 团 |
| ---- | ---- | -- | -- | -- |
| 灯柱 | 1 | 杆宽 + 2..4 | 0–1 根短横 | 顶上小方（灯箱残影，基体暗格，禁止 teal 面积光） |
| 栏柱 | 1–2 | 杆宽 + 4..6 | 1–2 根横杆 | 无顶团 |
| 标牌杆 | 1 | 杆宽 + 3..5 | 0–1 | 无顶灯；中上段一块扁团（标牌残影，基体色） |

占地默认**固着**：步态用呼吸伸缩，不要巡路滑步。厅内 8 个采样种子并排必须看得出是不同个体，不靠肩宽 2 像素。

##### `doorframe` 门框

**语法：** 左右各一根杆 + 顶上一根梁，围出中空开口。可选楣（梁上的扁团）。签名是**洞**，不是实心竖杆。缺一柱或楣下沉仍是框，只要开口还在。

参数：柱宽 2–4px、开口宽 6–12px、楣厚 2–4px、完整度（满框 / 缺一柱 / 楣沉 1–3px）。禁止画成街具残骸那种单杆+座。仅当本只占地时走本节；墙皮门框残余仍是乙。占地默认固着。

##### `stalk_clump` 残茎

**语法：** 3–6 根竖杆聚在共享着地点，顶可碎。签名是**丛**与茎间空隙，不是一根粗柱，不是一条分节身体。

参数：茎数 3–6、茎宽 1–3px、丛宽、整体倾 0–3px、顶碎量、一侧加密。可走。走时允许间隙开合 1px，不要读成黏膜蠕动。

##### `organic_remnant` 有机残影

**语法：** 无定形残余。一块团当质量，2–4 根不等长的杆当肢，**没有**虫 / 哺乳动物 / 蠕虫的体轴。读「曾经会走，但叫不出是什么动物」。允许前倾、中线 1px 缝（崩坏，不是触手）。

参数：团大小、肢数 2–4、肢长差、前倾 0–3px、缝有无。可走。若剪影能被读成四足纵轴、多足横向、或无足分节长条，则侵占了另外三条语法，不合格。

##### `insect_remnant` 虫

**语法：** 多足虫残余、横向展开。中央一块团（头胸 / 腹甲，壳质硬边）。四向直立词法不变：横向 = 精灵画面上足往两侧伸，不是改成纯俯视圆虫。签名仍是多足，不要写成四足哺乳动物或无足蠕虫。不要过于局限「腿只在身体两边成对」：允许一侧多 1 条、前后错位。中央壳质腹甲不变。

**排足（透视；整只点数，不是左右成对）：** 足 **总数** 4–10（不是一边 4 一边 10）。投放：截断正态 μ=6、σ=1.5，钳到 [4, 10]。六足众数。允许奇数。长度由透视决定：禁止所有腿一样长，禁止每腿独立均匀随机。前足（朝向侧）更长更张开；后足缩短更直立；左右朝向近侧长、远侧短。腿多时禁止读成一扇门（等长竖杆齐地 = 门）。仍禁止纯俯视圆虫。

参数：足总数 4–10（上式投放）、腹节 0–2 个碎 / 团、透视长度（前长后短、近长远短）。可走。基体侧允许壳质 / 分节。污染侧禁止软组织、虫卵、黏液、黏膜。足必须焊住身体。禁忌（软组织 / 虫卵 / 黏液）不变。

##### `mammal_remnant` 哺乳动物

**语法：** 中央硬边骸骨（头–躯干）。仍是一行基体。不是左右摊开的多足虫，不是无足分节蠕虫。禁止用「一头四足异星兽」套全部采样。

**猫科 / 鹿科 / 爬行 / 类人 = 种子采样邻域，不是四行 CSV，不是四个出击基体。** 陈列馆馆藏目录拆成四个入口（含【类人】）；策划表仍一行 `mammal_remnant`。种子在共用参数上连续采样；禁止硬切四条 `if` 当剪影身份。邻域可重叠。街具残骸仍一厅（灯柱 / 栏柱 / 标牌杆不拆目录）。

共用参数：身低、肢长比、撑开、直立度、尾长、头 / 躯干相对大小、前倾 0–3px。种子在这些轴上连续采样，禁止 `seed % 4` 切身份。可走。基体侧允许骸骨 / 干尸（中央 / 头–躯干硬边）。污染侧禁止内脏外露、血浆、软组织。肢必须焊住身体。四向直立换贴图，`GameObject.rotation === 0`，不转画布。策划表仍一行 `mammal_remnant`，已翻出击（I5-T）。灰度下四个邻域须可分，且都不要读成虫（多足腹甲）或蠕虫（无足分节）。

| 邻域 | 体轴与质量 | 肢 | 尾 / 角 | 走 |
| ---- | ---------- | -- | ------- | -- |
| 猫科 | 身低；头团 + 低扁躯干 | 4 根短杆，焊躯干底 | 1 根长尾杆 / 丝 | 伏行 / 低重心；水平拉伸多于高抬 |
| 鹿科 | 头小；躯干团短于肢 | 4 根长杆（肢长于躯干） | 可选 1–2 个碎当角残；尾可无或短 | 高抬步 |
| 爬行 | 身长；头–长躯干沿朝向 | 恰好 4 根杆向两侧撑开（仍是 4 足，不要第 5 足、不要虫的多足横向） | 长尾杆 / 丝 | 撑开迈步，可轻微侧移；禁止黏膜波浪 |
| 类人 | 直立。头团在上、躯干团；体块学大重构前占地甲类人剪影（头 / 身 / 臂 / 足） | 两足杆向下、两臂杆侧伸 | 无尾 | 直立两足迈步，臂可对侧摆；不要伏行、不要多足横向 |

类人只用杆 / 梁 / 团 / 丝 / 碎 / 核。禁止软组织当主材料。禁止精灵表、禁止抄 `infiltrator-sprite.ts` / `rewriter-sprite.ts` 当本邻域贴图。这是甲的邻域，**不是**覆盖体第三种人形。

##### `worm_remnant` 大号蠕虫

**语法：** 无足、分节长条。身体永远横躺：4–8 节沿地面左右相接，是一条贴地的长条。是**一条**身体，不是残茎那种一丛竖茎。无足；长出足就变成虫，有四足就变成哺乳动物。禁止朝上 / 朝下时把长条立成图腾。陈列馆默认朝南也必须是横长条。

身体钉在碰撞原点。切朝向绕物体本身变：头端左右翻转，贴地高低最多 ±1px。禁止整条在画布里搬家。禁止整图画布旋转把横条立起来。

四个信号相必须可检视：`idle` 静；`awake` 头段亮 / 微抬；`inflated` 体段加厚并改核色；`strike` 头端伸出。禁止只做出手相、其余看起来等于 `idle`。

参数：节数 4–8、节宽 3–6px、轴倾 0–2px、某处加粗。可走。拱：硬边分节沿横轴依次离地抬 2–3px。不是黏膜波浪。基体侧允许分节 / 干环。污染侧禁止蠕动黏膜、流体尾、湿肉边。波浪外沿 = 不合格。

#### 覆盖档 = 违规预算；放射只在覆盖档；`weld`；画布

覆盖档不是浓度旋钮。疯狂 = 违反自己的身体规则。预算：渗透 **1** 条、改写 **3** 条、覆盖 **5** 条。同一档抽哪几条由种子决定，所以同基体同覆盖档也疯得不一样。

| 算子 | 违反什么 | 怎么读 |
| ---- | -------- | ------ |
| 数量 | 主构件数量翻到约三倍 | 残茎 3 根变十几根；虫足突然变多 |
| 对称 | 一侧整体拉长 / 加粗 | 从两侧平衡变单侧崩坏 |
| 层级 | 在某构件上递归长出缩小的同族骨架 | 门框上长出小门框；杆上长出小杆。同族，不是换基体 |
| 拼贴 | 焊上**另一个**基体的签名构件 | 街具残骸顶了门楣；残茎上挂框。签名见上节各语法第一句 |
| 朝向 | 构件在锚点上转约 90° 或反向弯 | 梁竖起来、丝往回长。弯用 1px 折，不是黏膜曲线 |
| 尺度 | 某构件放大到压过本体 | 核比杆粗、头比躯干大 |
| 放射 | 线性骨架变放射对称 | **只在覆盖档解锁。** 渗透 / 改写抽到放射 = 不合格。这张牌读作「不再是这个世界的物件」，不能早打 |

**`weld`：** 任何构件必须与其他构件相接；不相接的拉回最近构件。`weld` 后可见身体四连通分量必须为 1。飘着的碎片读作程序错误，不读作疯。算子作用在骨架上，然后 `weld`，然后才刷漆。

**画布与碰撞：**

| 覆盖 | 画布 | 听噪画布 | 碰撞 | 偏移 |
| ---- | ---- | -------- | ---- | ---- |
| 渗透 | 32×32 | 至少 32×48 | 20 | `(画布边 − 20) / 2`（32 宽 → x=6） |
| 改写 | 32×48 | 32×48 | 20 | 宽 6，高 (48−20)/2 = 14 |
| 覆盖 | **48×64** | 48×64 | 20 | 宽 (48−20)/2 = 14，高 (64−20)/2 = 22 |

画布变了只改偏移，不改碰撞边长。覆盖档多出来的画布给放射 / 尺度违规往外长，禁止只靠画布从 32 高变 48 / 64 高把整块质量挪位冒充结构差异（有机残影从渗透到改写曾经踩过这条坑）。

**污染漆最后刷**（语言沿用改写体手法，不是档的身份）。禁止 `applyCoverageFail` 百分比挖洞。禁止整 sprite 降 alpha 冒充覆盖。簇贴在该语法剪影的崩坏侧，不要把改写体 CLUSTER 整数表原样盖上。

| 覆盖 | 基底 | 漆 | 动态 |
| ---- | ---- | -- | ---- |
| 渗透 | 该语法残余完整可读 | **不要簇。** 5–6 个家族散点：多数四档核色，偶发 `#1a7a9a`。散点随步态 sway ±1px | 步态 squash-stretch；无 melt |
| 改写 | 完整侧仍是残余；崩坏侧可铺深档（可留稀疏数据孔） | **成簇。** 15–20 px 分成 2–3 团贴崩坏侧，再盖 2 个高光簇心。完整侧只留 1 个家族散点 | 青绿像素沿朝向 ±1px melt；按信号换簇亮暗 |
| 覆盖 | 轮廓还在，完整侧可打数据孔、残余只剩残边 | 簇加到 28–36 px，中档溶散喷点出外沿；仍是这只占地的剪影，**不是**覆盖体几何、不是第二种走的人 | melt 每行走帧可发生；脱落尘往外 / 往下 |

覆盖档画布更大，簇的绝对像素可以随剪影变大，但语言不换。不要用加漆代替五条违规。

街具残骸与门框占地默认固着。残茎、有机残影、虫、哺乳动物、大号蠕虫可走。

**数量：** 句法课观察用侧栏档 **2 / 4 / 5**（硬顶 5；同一格不得两只）。**出击甲只数由地图生成（3–4，撤离门仍是渗透体视锥），禁止用句法课数量档去砍巡逻。** 碰撞仍 20。

### 丁（R2-C6 → 出击生产）

要像缓慢移动、微微形变的**云**，不要方案 B `paintVolume` 那种逐像素 hash + 棋盘格跳采样填满 pin 盒。基底不是油膜。三类概念基体必须肉眼可分（灰度仍可分：靠形状，不靠色相故事）。depth **40**，禁止 ≥ 50。

云的共用语法：不规则外沿（椭圆/缺角/噪声轮廓，禁止统一圆球）；内核更实、外沿更薄；2–4 秒外沿呼吸（休息大小的 8–15%，不是 1–2px 描边、不是整团闪透明度）；位移跟体积盒（`motion_wind` / `motion_trail` 移盒；`motion_anchor` 只形变不位移）。alpha 外沿约 70–120、核约 160–220（8 bit），几乎不透明的薄体积，不是全屏滤镜。这组贴图像素 alpha 再乘 `pose.visibility`。

出击视觉跟**当前盒**（`pin.x/y/width/height`，活机制下为 `dingLiveRect`），不要画出生时的静帧走廊盒。

| 基体 | 残余 | 剪影（必须分开） | 不要画成 |
| ---- | ---- | ---------------- | -------- |
| `sound_echo` 余响 | 响 | **回声带**：同一外沿的 2–3 圈 1px 量化轮廓，相位错开 0.3–0.6s，像表征失败被延迟重画。带间距 3–6px | 音响波纹 UI、喇叭、声波图标 |
| `light_scatter` 散光 | 折 | **折裂亮脉**：云体几乎空，只有 3–8 条 1px ramp.core/glow 脉在体内折一下再接上；脉随节律微移 1px | 手电筒光锥、全息网格、镜头光晕 |
| `space_interval` 间距 | 挤 | **错位暗体积**：ramp.deep 为主的暗云，比走廊盒窄 1 格或错位 8–16px，路看起来被挤窄但仍可走 | 油膜棋盘、第二层黑暗蒙层、实心假墙（不得改碰撞） |

成句 `corridor_watching` 绑 `space_interval`：反视核（盒内一格可走地板 2×2 ramp.glow）在玩家扫到前几乎不亮，扫到后亮同一色。核不要做成眼睛。死亡：alpha 收掉；核灭；不要放光柱。残骸不挡路。

禁止：hash 填盒、棋盘跳采样当主签名、bloom、整屏雾、把云抬到视野蒙层之上。迷雾可读性：可见区内能认成「这段路有一口云」；外圈亮不亮由人终审。

内容层（I3-G）落地前，出击抽卡可能仍抽出油膜占空——那是内容开关事实。本 HOW 仍要求丁的**画面**是概念三类云，不要把油膜棋盘当生产外形。I3-E 请人看丁之前，I3-G 必须已收回油膜占空。
