## 共享纪律

1. **不新色。** 污染亮核只用板里的青绿：`#1aad96` / `#2ae6c8` / `#3cffd4`（核点，克制）。墙锈 / 缝用该岛 `wallBias*` 量化后的暗灰，不要暖污染。
2. **不换精灵表。** 乙丁是程序像素或 Graphics 漆，不是第二套 walk cycle。
3. **连通 FATAL。** 漆、体积、墙斑不得改碰撞、不得切开墙后地板。乙核钉在墙格。
4. **覆盖体不是第三种人形。** 高度覆盖走缝 / 簇 / 体积。
5. **世界可读是第一课。** 旁白不得当救命字。核必须能在迷雾可见区内被读成「那里有一口」。
6. **头上无字。** 抽打格、体积、核都不要钉名字。

深度（相对裂隙 `RiftScene` DEPTH）：地表 0，簇活层 `surface+0.05`，乙核约 20（低于敌人 25），玩家 30，丁体积 40，视野蒙层 50。丁必须仍在蒙层之下。

## 甲：会走路的东西

沿用渗透体 32×32 / 改写体 32×48。视锥填法用渗透体剪影；听噪填法用改写体剪影。不要为灯柱占地另做第三套 walk cycle——灯柱基体第一版若抽到甲，剪影仍走渗透体家族，残余用灯核（头部 1px teal）提示「还想亮」。碰撞边长 20 不变。

死亡：既有淡出。渗透深度可残 1–2 帧基体轮廓，不要留挡路尸体。

## 乙：缝在看路

**剪影从哪来：** 墙缘折线上的锈斑 / 门缝，不是站在走廊里的人。核是缝里一颗 2×2 或 3×3 的量化青绿点（`#2ae6c8`，覆盖深度越高核越大但不超过 4px）。门框渗透：核在门洞邻接的墙格，开合相时核亮、合相时核收成 1px。

**怎么读：「这是缝」**
- 走廊中央看不见身体，只在贴墙时看到锈从墙皮里鼓一颗核。
- 不要画完整头部或成对眼睛（禁忌仍有效）。窄视成句用一条 1px 缝亮，不是瞳孔。

**邻格抽打提示（不打血条）：** 该 `strikeFloor` 在前摇 350ms 内，地格中心 1px 变成 `#1aad96` 再回到地板色（量化）。禁止全格闪白、禁止全息圈、禁止新色。一次只提示正在抽打的邻格。

**死亡：** 核灭；可留不挡路的墙锈（`put` 在墙像素，不是地板）。抽打停。

**沿壁滑动：** 核沿折线移动，不要离开墙格跳进走廊。

## 丙：地在呼吸

**不另做小人。** 外观 = `bakeGround` 记下的簇核 + DEC-070/071 中间层/外层整团胀缩。菌落 = 多个 organism；场 = 本图污染方言下这一片最显眼的簇（`breathAmp` 最大者）当成有价的地。

**怎么读：「这是活的地」**
- 休息相与现行簇相同。胀满相外沿更大（已有 5–20%），踩踏价更高，不要再叠一层发光人影。
- 可打核：簇几何中心已有核。被打时核短暂改 `#3cffd4` 1–2 帧（板内最亮青绿），不要白闪整团。

**死亡：** 核灭后该团不再伤人；漆可留作无害纹样（烤死、不再呼吸）。不要把地板挖成洞。

与地表文的边界：painter 仍拥有怎么烤；本文只宣布「丙 = 那团已有的活簇，加生命期与踩踏，不换皮」。

## 丁：这段路本身在工作

**剪影：** 走廊包围盒里的错体积——暗带或假墙感，不是人形。用该岛墙/地板 bias 往青绿轴拉后的量化色，alpha 要几乎不透明的薄雾格（按格填，不要全屏滤镜、不要片元着色器演示文稿）。宽度错了：比走廊窄 1 格或错位 1 格的暗带，让路「看起来不对」。

**核：** 盒内一格可走地板中心，2×2 `#2ae6c8`。反视：玩家视野扫到核之前，体积可以很暗、核几乎不亮；扫到后核亮起来（同一色，不新色）。

**怎么读：「这是体积」**
- 走进去视野被乘 0.7（机制），画面上体积仍低于蒙层。不要用第二层黑暗蒙层冒充体积。
- 禁止抬到 `DEPTH.visionMask` 之上。建议 depth 40。
- 禁止整屏雾、禁止 bloom、禁止新色。

**死亡：** 体积散（alpha 收掉）；核灭；出口短暂更清楚（不要放光柱）。残骸不挡路。
