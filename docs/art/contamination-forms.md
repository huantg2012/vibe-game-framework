## 共享纪律

1. **不新色。** 污染亮核只用板里的青绿：`#1aad96` / `#2ae6c8` / `#3cffd4`（核点，克制）。墙锈 / 缝用该岛 `wallBias*` 量化后的暗灰，不要暖污染。
2. **不换精灵表。** 乙丁是程序像素或 Graphics 漆，不是第二套 walk cycle。
3. **连通 FATAL。** 漆、体积、墙斑不得改碰撞、不得切开墙后地板。乙核钉在墙格。
4. **覆盖体不是第三种人形。** 高度覆盖走缝 / 簇 / 体积。
5. **世界可读是第一课。** 旁白不得当救命字。核必须能在迷雾可见区内被读成「那里有一口」。
6. **头上无字。** 抽打格、体积、核都不要钉名字。

深度（相对裂隙 `RiftScene` DEPTH）：地表 0，簇活层 `surface+0.05`，乙核约 20（低于敌人 25），玩家 30，丁体积 40，视野蒙层 50。丁必须仍在蒙层之下。

## 甲：会走路的东西

沿用渗透体 32×32 / 改写体 32×48。视锥填法用渗透体剪影；听噪填法用改写体剪影。不要为灯柱占地另做第三套 walk cycle——灯柱基体第一版若抽到甲，剪影仍走渗透体家族，残余用灯核（头部 1px teal）提示「还想亮」。碰撞边长 20 不变。

死亡：既有淡出。渗透深度可残 1–2 帧基体轮廓，不要留挡路尸体。

---

## 乙：缝在看路

**剪影从哪来：** 墙缘折线上的锈斑 / 门缝，不是站在走廊里的人。核是缝里一颗 2×2 或 3×3 的量化青绿点（`#2ae6c8`，覆盖深度越高核越大但不超过 4px）。门框渗透：核在门洞邻接的墙格，开合相时核亮、合相时核收成 1px。

**怎么读：「这是缝」**
- 走廊中央看不见身体，只在贴墙时看到锈从墙皮里鼓一颗核。
- 不要画完整头部或成对眼睛（禁忌仍有效）。窄视成句用一条 1px 缝亮，不是瞳孔。

**邻格抽打提示（不打血条）：** 该 `strikeFloor` 在前摇 350ms 内，地格中心 1px 变成 `#1aad96` 再回到地板色（量化）。禁止全格闪白、禁止全息圈、禁止新色。一次只提示正在抽打的邻格。

**死亡：** 核灭；可留不挡路的墙锈（`put` 在墙像素，不是地板）。抽打停。

**沿壁滑动：** 核沿折线移动，不要离开墙格跳进走廊。

## 丙：地在呼吸

**不另做小人。** 外观 = `bakeGround` 记下的簇核 + DEC-070/071 中间层/外层整团胀缩。菌落 = 多个 organism；场 = 本图污染方言下这一片最显眼的簇（`breathAmp` 最大者）当成有价的地。

**怎么读：「这是活的地」**
- 休息相与现行簇相同。胀满相外沿更大（已有 5–20%），踩踏价更高，不要再叠一层发光人影。
- 可打核：簇几何中心已有核。被打时核短暂改 `#3cffd4` 1–2 帧（板内最亮青绿），不要白闪整团。

**死亡：** 核灭后该团不再伤人；漆可留作无害纹样（烤死、不再呼吸）。不要把地板挖成洞。

与地表文的边界：painter 仍拥有怎么烤；本文只宣布「丙 = 那团已有的活簇，加生命期与踩踏，不换皮」。

## 丁：这段路本身在工作

**剪影：** 走廊包围盒里的错体积——暗带或假墙感，不是人形。用该岛墙/地板 bias 往青绿轴拉后的量化色，alpha 要几乎不透明的薄雾格（按格填，不要全屏滤镜、不要片元着色器演示文稿）。宽度错了：比走廊窄 1 格或错位 1 格的暗带，让路「看起来不对」。

**核：** 盒内一格可走地板中心，2×2 `#2ae6c8`。反视：玩家视野扫到核之前，体积可以很暗、核几乎不亮；扫到后核亮起来（同一色，不新色）。

**怎么读：「这是体积」**
- 走进去视野被乘 0.7（机制），画面上体积仍低于蒙层。不要用第二层黑暗蒙层冒充体积。
- 禁止抬到 `DEPTH.visionMask` 之上。建议 depth 40。
- 禁止整屏雾、禁止 bloom、禁止新色。

**死亡：** 体积散（alpha 收掉）；核灭；出口短暂更清楚（不要放光柱）。残骸不挡路。

### 载体与参考（实体，不是面板）

污染体是钉世界坐标的实体，走 Phaser 世界层，不是 `#dom-ui-root` 上的装置读数。不要做成检视卡、进度条、圆角怪物肖像、头上名牌。练习场侧栏仍是开发说明，不要翻修成墙机。

| 参考 | 锚的动作 | 明确不学 |
| ---- | -------- | -------- |
| 本项目改写体 `rewriter-sprite.ts` | FLESH/CLOTH 底上叠 DEEP/MID/CORE/GLOW 青绿簇；teal 像素沿朝向 ±1px melt；按 AI 态换变体 | 头上名；把 CLUSTER 整数表原样贴到灯柱/栏柱上当唯一剪影 |
| 本项目渗透体 `infiltrator-sprite.ts` | 密像素前倾；四向直立换贴图；`GameObject.rotation` 恒 0 | 把剪影烘进贴图里转 90°/180°；给渗透档面积光 |
| 本项目崩坏簇活层（DEC-070 / DEC-071） | 内核烤死；中间层/外层沿不规则外沿整团胀缩 5–20% | Shader 演示文稿；沿圆周走鼓包；整团透明度冒充呼吸 |

本课实体明确不像：图鉴卡 / Darkest Dungeon 头上名 / 科幻全息圈。

### 共享：配色

一律 `deriveFragmentContamRamp(fragmentTypeId)`（`d/fragment-ramp.ts`）。语义：碎片 `wallBias*` / `floorBias*` → 往青绿轴 0.48 拉 → `nearestPalette`。禁止写死一组 `CONTAM_*` 当所有院子的污染色。禁止给 `palette.json` 加色。禁止改 `bakeGround` / `preview-paint.ts`。

| 层 | 色从哪来 |
| -- | -------- |
| 污染 DEEP / MID / CORE / GLOW | 该碎片 ramp 四档。**亮核像素**只许是 `#1aad96` / `#2ae6c8` / `#3cffd4` 三色之一（ramp 量化若偏了，画核时钳回这三色）。DEEP/MID 可以是 ramp 量化后的暗青绿，必须在 `palette.json` 内 |
| 基体残影（肉/布/骨/砖/金属） | 板内 `flesh-dead` `#2e2d30`、`cloth-dark` `#2a2a2e`、`bone-grey` `#3a3838`、`earth-dark` `#1a1c1f`、`brick-dark` `#2a1f1c`、`metal-grey` `#4a4e55`。允许按该碎片 L1 混 12–18% 再量化，让五种碎片的同一只敌人肉眼有色温差 |
| 墙锈 / 缝底 | 该碎片 `yardSurfaceColors.wall` 暗灰，不要暖污染 |

五种碎片（`frag-outdoor` / `frag-clinic` / `frag-metro` / `frag-library` / `frag-residential`）切同一只敌人时，污染层必须换 ramp。只换地板 bias、敌人仍用同一组写死 teal = 没做本题。渗透档家族散点允许偶发板内 `contam-cold` `#1a7a9a`（渗透体现行）；覆盖档簇心不用它。

### 共享：深度

与本文出击节同一套数字。脚手架 `attach` 传入的 `depth` 照用，不要另发明。丁 = 40，必须低于视野蒙层 50。丙视觉 ≤ `surface+1`，不要盖过玩家（30）。乙核约 20。甲约 25。

### 共享：受击表现（不推翻战斗 V3）

`docs/specs/system-combat.md` V3 锁死：无震屏、无命中停顿、无伤害数字。价目表本轮不涨。调性仍是 art-direction §1.2：缓慢、有节奏；压迫而非惊吓。禁止 jump scare、禁止全屏闪白、禁止科幻全息圈、禁止血液/红色叠层。

攻击发生时可见 = **敌人侧出手相 + 危险区在世界里 + 玩家既有 100ms 白闪**（`PLAYER_HIT_FLASH_MS`）。练习场须开「感受伤害」才能看见掉血；无敌时仍应能看见出手相与危险区。

| 孔谱 | 敌人侧出手相（`FormVisualSignal`） | 危险区（世界格 / 体积） | 打到玩家身上 | D 渲染器禁止 |
| ---- | -------------------------------- | ---------------------- | ------------ | ------------ |
| 甲 | `strike`：朝向再前倾 1–2px，伸出侧 +2px，领先簇 1–2 格改 ramp.glow，持续前摇 350ms | 不新画占位白线（战斗系统若仍画扇形细线，D 不要叠第二条） | 既有玩家白闪 | 伤害数字、震屏、顿帧、吓人放大 |
| 乙 | `strike`：核胀到不超过 4px，缝亮一档 | **将被抽打的地板格**中心 1px `#1aad96`（量化），前摇全程；格来自当前 `strikeFloors`，随核走。禁止只画核的 rim glow 交差 | 既有玩家白闪 | 全格闪白、全息圈、把点钉在墙格心 |
| 丙 | `inflated`：沿用整团胀缩上限；可打核时核 1–2 帧 `#3cffd4` | 不打血；不要地格抽打点 | 无白闪（不打血） | 另做小人、整团白闪 |

### 甲（R2-C3）

路子：方案 A。画布渗透 32×32、改写/覆盖 32×48（听噪无论覆盖深度都 32×48）。碰撞边长 20；偏移 `(画布边长 − 20) / 2`。四向直立换贴图。禁止精灵表。禁止第三种人形。

**覆盖深度 — 对标改写体手法，禁止 `applyCoverageFail`。** 方案 A 的三档是透明掉 0% / 38% / 74% 再改点颜色。D 不许再用百分比挖洞当主手段。三档都是「基体剪影还在 + 污染层怎么叠」，浓度递进不换语言。

| 覆盖 | 基底层（启动时画进贴图） | 污染层（叠在基底上，不是挖透明） | 动态层 | 画布 |
| ---- | ------------------------ | -------------------------------- | ------ | ---- |
| 渗透 | 该族 FLESH/CLOTH/BONE 剪影完整可读 | **不要簇。** 5–6 个家族散点（渗透体 `paintSpecks` 那种）：多数 ramp.core，偶发板内 `#1a7a9a`。散点随步态 sway ±1px | 步态 squash-stretch；无 melt | 32×32（听噪 32×48） |
| 改写 | 完整侧仍是该族肉/布；崩坏侧先铺 ramp.deep（可留 `(f+r)%5===0` 数据孔） | **成簇，不是散点。** 15–20 个 ramp.core 像素分成 2–3 团贴在崩坏侧（改写体 CLUSTER 是 17：胸 7 + 髋 6 + 外沿 4），再盖 2 个 ramp.glow 簇心。完整侧只留 **1** 个家族散点 | `warpMotion`：ramp 青绿像素沿朝向 ±1px melt（行走帧 1 / 3）；按信号换变体：静默=簇为 core；搜寻感=`strike` 以外的警觉把 4 格改 glow；追击感=多数簇改 glow、留 3 格 core，并每 8 帧沿朝向抖 1px | 32×48 |
| 覆盖 | 该族轮廓还在，但完整侧打数据孔、肉只剩残边 | 簇加到 28–36 px，溶散喷点（ramp.mid）出轮廓外沿；仍是这只占地的剪影，**不是**覆盖体几何结构，也不是第二种走的人 | melt ±1px 每行走帧可发生；脱落尘往外/往下（若抄 `contam-flakes` 进 `d/`，不要改出击那份） | 32×48 |

簇要贴在**该族剪影的崩坏侧**（有机/残茎：身体右侧；灯柱/栏柱：沿杆一侧），不要把改写体那张 32×48 CLUSTER 整数表原样盖到灯柱上。不要用整 sprite 降 alpha 冒充覆盖深度。

**族内剪影变体：** 每种占地合法基体 ≥3 种，由 `mix32(seed, substrate) % 3` 生产，与覆盖深度正交（变体改剪影，覆盖改叠簇）。不另写 CSV 行。概念基体禁止给甲。

### 丙（R2-C4）

路子：方案 B。外观 = 已烤簇语义 + DEC-070/071 整团胀缩。**不另做小人。** 不要第二套呼吸算法。不要走 infiltrator walk cycle。

人点名「几近完美，补多样性」。在 B 的 `ShapeKnobs` 上加可感旋钮，不要换语言：

| 旋钮 | 锁 | 侧栏要能看出 |
| ---- | -- | ------------ |
| 团扁 | `rxMul` / `ryMul`：菌毯偏圆瓣；油膜偏扁带（`thin`）；灰幕更扁、像覆层 | 切基体即换 |

### 乙（R2-C5）

沿 B 的「缝里一颗核」方向重做位置与运动。禁止再把 32×32 锈斑画在墙格几何中心（`col*32+16, row*32+16`）。

**附着：** `pin.attach` 已有 `face` / `nx` / `ny` / `seamX` / `seamY`。核钉在 `(seamX, seamY)`。厚度只在墙格朝走廊的那 **1–3px**（沿法线 `(nx,ny)` 走进可走格），覆盖深度 渗透=1 / 改写=2 / 覆盖=3。核 2×2 或 3×3，覆盖不超过 4px，色 ramp.glow 或 `#2ae6c8`。墙皮底用 `yardSurfaceColors.wall`。不要把身体画进走廊碰撞；不要占满 32×32 墙格。

**游荡：** 整只 Image/Graphics 跟 `pose.x/y`（缝坐标）走。运动是宿主沿 `orderWallEdgeTiles` 换钉，不是画布内 `seamSlidePx` 假滑。`motion_anchor` 停；`motion_wall` 缓慢沿相连墙皮；`motion_turn` 可掉头。开合相只胀核，不把核跳进走廊。

**抽打提示：** `signal === 'strike'` 时，对当前 `strikeFloors` **每一格**在地格中心画 1px `#1aad96`（方案 A 乙有过点，但钉在 pin 右侧一格——D 必须跟真实邻接可走格）。无全格闪白、无全息圈。一次提示正在抽打的那些格。B 藏掉默认 4×4 telegraph 之后，D 必须自己画这些点。

成句「缝里的眼」：1px 缝亮，不成对瞳孔。死亡：核灭，可留不挡路墙锈。

### 丁（R2-C6）

要像缓慢移动、微微形变的**云**，不要方案 B `paintVolume` 那种逐像素 hash + 棋盘格跳采样填满 pin 盒。基底不是油膜。三类概念基体必须肉眼可分（灰度仍可分：靠形状，不靠色相故事）。depth **40**，禁止 ≥ 50。

云的共用语法：不规则外沿（椭圆/缺角/噪声轮廓，禁止统一圆球）；内核更实、外沿更薄；2–4 秒外沿呼吸（休息大小的 8–15%，不是 1–2px 描边、不是整团闪透明度）；位移跟体积盒（`motion_wind` / `motion_trail` 移盒；`motion_anchor` 只形变不位移）。alpha 外沿约 70–120、核约 160–220（8 bit），几乎不透明的薄体积，不是全屏滤镜。

| 基体 | 残余 | 剪影（必须分开） | 不要画成 |
| ---- | ---- | ---------------- | -------- |
| `sound_echo` 余响 | 响 | **回声带**：同一外沿的 2–3 圈 1px 量化轮廓，相位错开 0.3–0.6s，像表征失败被延迟重画。带间距 3–6px | 音响波纹 UI、喇叭、声波图标 |
| `light_scatter` 散光 | 折 | **折裂亮脉**：云体几乎空，只有 3–8 条 1px ramp.core/glow 脉在体内折一下再接上；脉随节律微移 1px | 手电筒光锥、全息网格、镜头光晕 |
| `space_interval` 间距 | 挤 | **错位暗体积**：ramp.deep 为主的暗云，比走廊盒窄 1 格或错位 8–16px，路看起来被挤窄但仍可走 | 油膜棋盘、第二层黑暗蒙层、实心假墙（不得改碰撞） |

成句 `corridor_watching` 绑 `space_interval`：反视核（盒内一格可走地板 2×2 ramp.glow）在玩家扫到前几乎不亮，扫到后亮同一色。核不要做成眼睛。死亡：alpha 收掉；核灭；不要放光柱。残骸不挡路。

禁止：hash 填盒、棋盘跳采样当主签名、bloom、整屏雾、把云抬到视野蒙层之上。
