# 边界外的黑暗概念图评审结论

## 选定方向：渐变过渡 + 被占据的虚空

### 批准的参考图
- `2026-07-23_150039_gpt-image-2.png` — 通过

## 确认的视觉特征

### 静态层（tile/sprite 表达）

- **净化点边缘**：暖灰混凝土地面 + 金属栏杆/矮墙，amber 灯光照亮最后几 tile
- **过渡渐变**：3-4 tile 宽度内，地面从"确定"到"模糊"到"消失"——不是硬切线
- **黑暗基底**：非均匀近黑（#080a0c ~ #0d1114），角落/边缘有极微弱的结构暗示（倒塌建筑残影）
- **稀疏 teal 散点**：偶尔几个 teal 像素在黑暗中闪烁——"有数据在那里但无法解析"

### 动态层（BoundaryAtmosphere 代码系统负责）

静态图无法表达的"占据感"由代码实现：
- 极低透明度（5-10% alpha）的巨大几何形态缓慢漂过黑暗区域
- 偶尔从黑暗中浮现更密集的 teal 几何结构，持续 2-3 秒后消散
- 粒子系统：稀疏的微弱 teal 点在黑暗中漂移
- 周期性事件：每 15-30 秒，黑暗深处某个区域的亮度极微弱波动（暗示"有什么动了"）

### 空间过渡弧验证（§13.5）

```
暖灰工业空间     →    边界渐变区          →    被占据的虚空
(净化点内部)          (栏杆+光衰+模糊)         (黑暗但不空)
有秩序、有光          丧失确定性               存在但不可见
amber 暖色           暖色消失、冷色还未出现    偶尔 teal 闪烁
```

本概念图验证了这条过渡弧的视觉可行性。

## 设计决策

- **边界不是"游戏地图的边缘"**——它是叙事元素，传达"外面有东西"
- **静态层保持极度克制**——只提供最低限度的"非空白"暗示
- **动态层承载"占据感"**——这是代码系统的工作，不是 tile 的工作
- **玩家不应习惯边界**——BoundaryAtmosphere 的随机性确保每次看向边界都有微妙不同
