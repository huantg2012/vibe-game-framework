## 当前样例

用户明确“背景”是截图中整层半透明 UI 遮罩，并要求小人清楚；此前以真实远景暗形区分三档的解读已被否定。本轮遮罩修订已完成，并经限定实看与独立美术复核，强度、气质和心理效果待用户审看。

- 低／中／重使用完全相同的实景底图、机位、人物与光照；`LastLightRenderer` 及正式资产只读复用。`background.ts` 返回实际 `actorRegion`，世界远景、裂口、地坪与真实深度不随档位变化。
- 层位为**世界底图 → 基础阅读暗场 → 整层氛围视效 → 文字**。`overlay.ts` 的整层 Canvas 以宽薄渗痕的形状、疏密、方向、叠层和缓慢流动营造递进压力，不限于世界远景空隙，也不靠单纯加黑／泛绿。
- 人物周围有三档相同的稳定保护区域；文字、焦点和命中区保持原位且不扭曲。视效可见度须与人物清晰、正文可读同时成立。
- 预览提供动／静切换、氛围开关及隐藏文字审看；默认慢动，系统减少动态偏好下静止，行装页速度降低而人物保护区域固定。鼠标或 ↑ ↓ 选级，Enter 查看行装承接，Esc 返回或收起。逻辑舞台固定 960×640，只在预览容器中等比缩放。
- 选中档名 18px，危险判断和主操作 16px，事实 12px，标签 11px；氛围低语 13px 衬线独占两行，常驻供审稿。行装仅展示普通撬棍、空槽及单列清单／详情，物件名和耐久读取现有 CSV。
