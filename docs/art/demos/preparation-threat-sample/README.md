## 看什么

- 低／中／重使用相同的实景、机位、人物、阅读暗场与排字。鼠标或 ↑ ↓ 选级，Enter 查看行装承接，Esc 返回或收起。外层提供仅看背景、复位与重开。
- 选中档名 18px，危险判断和主操作 16px，事实 12px，标签 11px；氛围低语 13px 衬线独占两行。逻辑舞台固定 960×640；仅预览容器等比缩放，不重排游戏界面。
- 背景由同源 `LastLightRenderer` 与当前 Last Light 资产绘制，再以深度身份排除人物、近景和地坪，在合法远层空隙制作样例专属静态折面。低档一段、中档两段、重档三段；这不是新敌人、新地面或目的世界预告。
- 装配页仅展示一把普通撬棍、空槽及单列清单与详情的关系。物件名和耐久读取现有 CSV；不提供真实库存交互。

## 范围与已知不足

本次为静态无声样例；B 低语固定显示供排字审阅，不执行方案中的停稳、每会话一次或六秒时序。没有存档、出发、场景注册、音频或后台动画，也未完成 P1 的真实业务状态桥接。`src/**`、`data/**`、`public/**` 未修改。

美术复审认可最后一版已消除连续亮带造成的“新增桥面”误读，局部片层疏密可分；但变化仍主要集中在左下远层，重档侧面还有板片感。整体压力是否达到低／中／重目标尚未成立，也未经用户审定。不要将这个样例视为背景美术通过或正式接入许可。
