## 当前样例

用户明确“背景”是截图中整层半透明 UI 遮罩，并要求小人清楚；此前以真实远景暗形区分三档的解读已被否定。上一版 E201 虽有隔时变化，用户实际反馈动态像静态、缺少切档过渡，不能再把它记为动态目标达成。本轮按专业游戏美术的运动与转场要求重做独立样例，视觉强度、气质和心理效果仍待审看。

- 低／中／重使用完全相同的实景底图、机位、人物与光照；`LastLightRenderer` 及正式资产只读复用。`background.ts` 返回实际 `actorRegion`，世界远景、裂口、地坪与真实深度不随档位变化。
- 层位为**世界底图 → 基础阅读暗场 → 整层氛围视效 → 文字**。`overlay.ts` / `veil-shader.ts` 使用完整 960×640 WebGL2 画布，以主层／薄层的不同方向输运及局部形变营造递进压力，不限于世界远景空隙，也不靠单纯加黑／泛绿。
- 人物周围有三档相同的稳定保护区域；文字、焦点和命中区保持原位且不扭曲。视效可见度须与人物清晰、正文可读同时成立。
- `veil-motion.ts` 中低／中／重主流候选速度为 8／15／22 逻辑 px/s，薄层方向和速度错开；切档主前沿升级 0.82 秒、降级 1.02 秒，滞后尾层最晚 1.34 秒收拢。快速改选从当前外观追随新目标，不排队、不重置纹理时间。数值是当前样例参数，不是美术验收。
- 预览**默认播放**，有显式动／静按钮、氛围开关和隐藏文字；本轮为动态可行性演示，不因 OS 减少动态偏好默认静止，也没有修改 OS 设置或正式游戏合同。行装页降速且人物保护区固定，关闭停止 RAF。鼠标或 ↑ ↓ 选级，Enter 查看行装承接，Esc 返回或收起。逻辑舞台固定 960×640，预览容器只等比缩放。
- 页面可录制并播放／下载 10 秒实际流程：低 2 秒 → 中 3 秒 → 重 3 秒 → 低 2 秒。`capture.ts` 将真实 worldCanvas、CSS 阅读暗场、实时 veilCanvas 与同 DOM 的透明文字快照合成后由 MediaRecorder 输出本地 WebM；预热不计入录像，不运行另一套视效，不用静帧轮播冒充运动。
- 选中档名 18px，危险判断和主操作 16px，事实 12px，标签 11px；氛围低语 13px 衬线独占两行，常驻供审稿。行装仅展示普通撬棍、空槽及单列清单／详情，物件名和耐久读取现有 CSV。
