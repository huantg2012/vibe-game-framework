## 本批解决了什么

从“浅盘＋外围折带”转向有顶板、背墙、承托与断面的场所；外部通过实形遮挡和体块尺度表达距离。初稿外景过亮且缺少贴地裂隙，经一次集中修正，压暗远处、补齐六个功能占位、减少表面细节并整理入口。

独立读图在初稿与修正版均推荐 C。修正版确认远处巨孔不再抢主焦点、核心周围空地更清楚、桥头与平台接续改善。主线程采纳这些观察；仍保留外景偏常规废墟、近处通道去向未定及后台连接模糊的问题。

## 尺度和操作校核的边界

- 三张原图均 1536×1024，按当前正常视口 960×640 的 3:2 比例比较。
- 图像生成没有精确满足人物/装置像素尺寸。操作校核模式叠加由生产函数导出的原人物，按 53px 本体高显示；不能把概念图人物当尺度测量结果。事实来源见[尺度参照](scale-reference.md)。
- 六处装置编号、可走区和路线是空间容量与接近方向的示意。操作圈约 58px 对应当前 24 世界像素半径，但未验证同层资格、碰撞或遮挡；不会因画上路线而声明“已经走通”。
- C 的左后平台连接不明显，右后坡道与主地面的落点仍有歧义。下一批须用同源人物和实际尺寸，先落实“主地面→六处操作点→后台平台”的连续通行，再完成该区域画法样板。
- 前景长坡与后台通路的去向尚未定义，应收敛为净化点内部结构；不据此引入额外游戏出口或新玩法。

## 下一批样板建议

以 C 的整景关系为起点，取“人物＋核心＋工作地面＋后台平台连接＋右侧厚墙转面＋其后中景”的连续区域。其余保持灰阶占位，先证明原人物/原装置与新建筑能使用同一种像素语言，并将两处高差连接画清楚。样板须在实际显示尺度下成立，不能把概念图的完成度直接算作生产质量。
