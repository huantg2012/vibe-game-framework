### 不采用
无（两张均通过）

## 确认的视觉特征

### 与渗透体的递进关系

| 维度 | 渗透体 | 改写体 |
|------|--------|--------|
| 崩坏覆盖 | ~15%（散点） | ~50%（成簇/成片） |
| 人形可读性 | 高（第一眼像人） | 中（需看两眼确认曾是人） |
| 轮廓 | 基本完整 | 一侧明显超出/溶散 |
| 对称性 | 微妙不对称 | 强烈不对称（半完整半崩坏） |
| teal 存在感 | 散点提示 | 成片/成流主导一侧 |
| 体型 | 32x32 | 32x48+（崩坏部分超出边界） |

### 核心设计要素

- **强不对称**：一侧保持渗透体级别的完整度，另一侧正在失去形体
- **崩坏形态有个体差异**：爆发散射型 / 纵向溶解型 / 其他变体均合法
- **偏移复制**：部分肢体出现 2-3 个错位重影副本（baked in sprite）
- **teal 成簇/成流**：不再是散点，而是集中区域的密集存在
- **姿态不稳定**：像卡在两个动画帧之间，关节角度互相矛盾
- **仍保留爪状手/前倾特征**：与渗透体属于同一"家族"

### Sprite 实现备注

- 基底 sprite 保留：不对称轮廓 + 一侧收敛的 teal 簇 + 偏移副本肢体（baked）
- 动态层增强：崩坏侧持续像素飘散（比渗透体更密集/更快）、偶尔整体"闪烁"在两个偏移位置间跳动
- 不同个体可使用不同崩坏形态的 sprite 变体（增加视觉多样性、降低重复感）

## 对覆盖体的递进指导

覆盖体（100% 崩坏）应在改写体基础上彻底失去人形：
- 不再有"完整的一侧"——整体都是渲染错误
- 不再有可辨识的肢体——轮廓完全非人
- 自身就是光源——teal 占比从"一侧主导"变为"全体发光"
- 移动方式从"行走"变为"滑行/悬浮"——没有可见的运动机制
- 形态稳定而非不稳定——覆盖体是"完成品"，不像改写体那样在两态间挣扎
