# 覆盖体概念图评审结论

## 选定方向：多重偏移叠加几何体 — 稳定自发光

### 批准的参考图
- `2026-07-23_115626_gpt-image-2.png` — 通过

## 确认的视觉特征

### 核心形态

- **完全非人形**：菱形/钻石状抽象几何，无任何人体痕迹
- **多重偏移叠加**：像同一个实体被渲染了 30 次并叠在一起，水平方向的层叠错位几何
- **中心核心**：中央有一个稳定的亮点（感知核心），非"眼睛"
- **边缘散射**：外围像素向外延伸散开，轮廓边界不完全锐利
- **自发光**：实体本身是 teal 光源，底部投射连续面积光池
- **对称但异质**：整体近似对称，但不是简单镜像——有自身的内在秩序

### 情绪/氛围

- **稳定、自信、完成态**：不像改写体在"挣扎"，这是一个已经完成转化的存在
- **美丽但错误**：视觉上有吸引力，但本质令人敬畏/不安
- **静默威胁**：不需要动作就能传达压迫感——存在本身即威胁
- **不可理解**：观察者无法将其归类为任何已知事物

### 三级递进完整性验证

```
渗透体            →    改写体             →    覆盖体
"几乎是人"              "半人半溶解"              "纯粹的渲染错误"
微妙不适                恐惧                     敬畏/不可理解
前倾佝偻行走            不稳定挣扎               静默悬浮滑行
散点坏像素(3-6)         成簇teal(15-20)          全体自发光
32x32                   32x48                    48-64px
人形可读                半人形                   完全非人形
稳定(微错)              不稳定(挣扎中)           再次稳定(完成品)
```

递进逻辑：稳定 → 不稳定 → 更高层次的稳定。这不是线性恶化，是质变。

### Gameplay 联动

- 覆盖体投射 teal 面积光池（3-4 tile 半径），玩家远距离可感知"有移动的大面积光源"
- 区别于环境 teal（线性脉络）和裂口 teal（固定高亮点）
- 这是威胁预警系统：先看到光 → 再确认光源 → 决策回避或面对
- 覆盖体悬浮滑行，无可见运动机构——运动方式本身就是"等级标识"

### Sprite 实现备注

- 基底 sprite：菱形几何叠加形态，多层 dark grey + teal 交错（baked）
- 中心亮点常亮（baked）
- 底部光池由代码渲染（径向渐变 overlay）
- 动态层：边缘像素微幅漂移（缓慢、稳定节奏，不是改写体那种急促飘散）
- 移动动画：无行走帧——整体平移即可（悬浮滑行）
