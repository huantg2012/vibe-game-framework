> **TL;DR**：新出击中污染从交控起增长，100封顶后按有效暴露时间缓慢增加跨局同化；同化缓解缩视、降低未激怒污染体的主动感知，但清除更高同化需要更多疗愈周期。培养藏每次疗愈降低15个百分点，净化器实际完整度至少25才可开始；每次承受真实冲击、推进供奉和潮汐，不发成功归返或正稳定度奖励。

# 系统设计：同化与疗愈

## 概述与边界

服务“还敢不敢再多拿一点”和“维持最后一点光亮”：短期污染记录本趟暴露，长期同化把多次冒险的后果带回净化点。允许玩家保留中等同化换取裂隙内的适应收益，其治疗负担体现为更多疗愈周期，不改变任何一次冲击的强度。疗愈的主要成本是承受冲击及由此产生的修复需求，不新增通用货币、药材、随机治愈、职业树或大型新素材。

同化100是本系统数值上限，不等于意识完全消失、自动死亡、失去操作或剧情终局。现有稳定度100和无限Final潮峰不因此获得新结局。此系统改变长期存续的取舍，不替代尚未定义的终极目标。

本合同覆盖新规则出击；已冻结的旧在途局保留原污染上限、调制曲线和结算承诺，见“存档与兼容”。同化/疗愈规则与数值只在本文维护；相关系统spec需链接本合同并更新其接口，不能复制一套不同数值。

## 状态模型与策划数据

- `P`：本趟污染，沿现有Chaos领域持有，新规则范围0–100；不是第二份可写混乱状态。
- `A`：玩家跨局同化，范围0–100，保留小数。撤离、死亡、放弃、普通归返和重载均不清除。
- `rulesVersion`：出击冻结的规则版本，区分旧150混乱协议与本合同；兼容判定不能仅凭存档日期或P是否超过100。
- `healingCycleId`：一次疗愈事务的唯一身份，与真实run ID区分；同一身份只冲击、降低同化、成熟供奉、推进潮汐一次。
- 同化值必须进入长期世界快照及完整在途提交；运行中的Chaos可以投影/持有同一候选值，但不能形成相互覆盖的两套权威。出击结束快照即使不再保存Chaos运行态，也须保存当时A。
- 疗愈提交候选包含：A前后值、周期/预告及随机流、模块前后状态、供奉实例快照与生命周期、潮汐、成长经历、稳定度负向事实和幂等回执。实际TypeScript结构由Code映射，不能遗漏以上语义。

### 同化外观的持久来源谱（2026-10-20）

`A`仍是唯一玩法权威；来源谱只说明身体异化来自何处，不改变污染、同化速率、抗性、视野、敌意或疗愈费用。完整世界快照新增可选`assimilationSources: { version: 1, worlds: { [worldId]: points }, unattributed: points }`。贡献使用与A一致的0–100百分点单位；世界键记录真实冻结世界身份，不记录配色、当前地图或最后访问世界的替代猜测。

- `gameState.setAssimilation(targetA, frozenWorldId)`只把本次真实正向差量记到该世界；重复提交同值、在满A时继续停留、单纯进入另一世界均不改谱。无来源的旧开发调用增长记为`unattributed`。
- 下降时所有已知来源与无来源残留统一乘`A_after / A_before`。培养藏仍每周期减少15个百分点；不同来源不会被选择性优先清除，不存在额外治疗次数。A归零时空谱。
- 旧同化档无来源字段时，已存在A全部记为中性的`unattributed`；旧无同化档仍A=0。无法追溯的历史不能凭当前/最后世界补造。后续新增同化仅增加真实来源贡献；旧中性残留随疗愈同比降低。
- 贡献必须为有限非负数，已知世界条目为正数，版本固定1，总和不得超过A（仅容许浮点误差）；合法不足部分补入无来源残留。未知但合法格式的历史worldId保留，画面端可中性降级，不能删掉历史贡献或改变A。非法谱拒绝整档且不修改当前世界。
- 撤离、死亡、放弃、冷续和完整checkpoint保存均沿同一世界快照携带来源谱。疗愈的A及谱进入同一冻结保存候选；拒写后只重试同一候选，不能再削减一次，未提交的存档字节保持原样。普通需要回滚的世界事务通过完整`GameStateSnapshot`一并恢复谱。

美术端通过`AssimilationStatePresentation`读取只读来源谱，按真实贡献投影世界材料/结构；画面权重不写回A。现有世界材料路由能解析为晶纤/膜的来源使用对应已获批组织规则与该世界的真实三阶材料。两族保留各自稳定区域，不全身平均色。未具备组织模板的来源（包括余烬脊）沿全A保留通用前屈，但不生长晶脊/膜：只在第三稳定区域使用当地solid材料与轻微层纹；旧无来源或已不可解析的历史来源使用既有中性工业灰。`typedFraction`仅表示具备模板的贡献占比，用于限制新增组织，不改变姿态总量和同化规则。具体形体、材质与性能合同仍归`docs/art/assimilation-appearance-study.md`。

策划参数唯一来源为`data/assimilation.csv`，经codegen提供低/中/重同化速率、阈值、疗愈量和视距/速度/敌意系数。地图等级沿本趟冻结身份选择对应速率；当前同化协议只保存规则版本标记，未把同化CSV整包冻结进快照，因此不承诺未来调整CSV后仍复现旧参数。旧150协议与新同化协议的分派必须保持；若未来要求同化调参前后完全复现，应另做版本化数据兼容。不得在HUD或面板复制公式。

## 规则

### 1. 污染涨满后才累积同化

1. 新出击P仍从真实净化器/出发条件确定的起始值开始，钳制到0–100。交控后立即沿冻结的低/中/重污染曲线增长，无额外入场宽限期，也不强加一次满污染。
2. 正向污染仍使用原统一入口，保留自然时间、发现、战斗和真实Host接触的各自代价及抗性。新规则P上限100替代旧150溢出段；不会因到达100自动撤离或死亡。
3. 仅在P=100的有效模拟时间内增加A。每分钟基础速率低/中/重为0.6/0.8/1.0点：

   `ΔA = tFullSeconds / 60 × gradeRate × (1−R) × (1−G)`

   `A' = min(100, A + ΔA)`

   R为本时刻武器/有效工具/临时状态汇总的广谱污染抗性，沿既有60%上限；G为永久成长的自然渗透减缓，当前满级20%。各应用一次，不能把已经乘过R/G的污染增量再次代入。核心通过原污染增速减缓延后涨满，不再对同化速率额外相乘。仅减缓旧时间污染的其他工具不自动变为新的同化抗性来源。
4. 跨过P=100的模拟步需分割，只计算到达阈值之后的时长；Chaos内部临时倍率/减缓到期同样分段积分，不整帧套用到期前或到期后的值。外部ToolSystem提供的R沿既有帧序采样，到期最多存在一个有效模拟步（当前上限100ms）的量化误差；本轮未重构工具时钟。被发现、战斗、踩漆等离散加值只能提前达到100，超出部分不即时兑换A。同帧离散事件按既有模拟次序发生，不反向给此前时间记同化。
5. 不能监听`CHAOS_CHANGED`的正增量来驱动同化：污染封顶后事件可停止，但暴露继续。站立、阅读不暂停世界的拾获页仍计时；系统暂停、尚未交控、结束结果、离线和场景过渡不计时。续局沿原模拟时钟，不能重置宽限或补算墙上时间。
6. A为100后停止数值增长；持续污染侵蚀及真实环境危险保留，不生成隐藏债务、第二次满条或自动处决。

### 2. 同化改善适应，不清洗污染

令`p = clamp(P/100,0,1)`、`a = clamp(A/100,0,1)`。

- 污染与同化的共同视距倍率：`radiusScale = 1 − 0.45p + 0.35ap`。A=0时P从0到100令倍率从1线性降至0.55；满污染时A从0到100把倍率恢复至0.90。回补量同样随P缩放，因此P=0时所有A都为1，干净基础视距不放大；此通道始终处于0.55–1。
- 污染移速倍率：`speedMult = 1 − 0.10p`。新规则不叠旧100→150溢出瘫痪；原负重、攻击和工具速度修正仍按其规则叠加，不因同化免费消除。
- 边缘侵蚀、环境染污/闪动等污染表现由P驱动，不因A上涨退回干净画面。已锁减动设置继续生效。具体表现曲线由Art与Code沿现有表现通道核对，不把纯视觉反馈称为新伤害机制。
- 同化只改变此视距调制通道，不覆盖工具视距、Host缩视、真实遮挡、VOID、小地图发现历史或目标可见性规则。先投影本系统倍率，再由共享可见性系统按各来源合成。连续吞光正式接入以P/A分别派生暖灯与辨认范围，替代新协议三世界的旧视锥；同化只扩大辨认范围，不恢复暖灯功率、暖灯半径或隔墙感知。旧150协议的视锥保持。光学画法与接入范围唯一正文见[视野spec](system-movement-vision.md)。

未激怒敌人的主动感知倍率：`perceptionFactor = 1 − 0.60a`。单通道作用于主动视觉/听觉的感知距离，与既有工具控制来源合成一次；发现累积速度保持原值，不能再叠一次同化减缓。每个对应感官的距离最低为原值40%，视觉/听觉是分别判定的机会，不把两者系数相乘。真实追击、受击及显式噪声通道不减免，近身防卫仍成立；不能把主动听觉距离变化宣传为翻找/挥击无声或不被任何声音发现。

当前“未激怒”资格采用既有FSM的非CHASE状态，不增加受击历史账本：怀疑/警戒/调查可获得距离适应；CHASE期间本系统距离倍率为1。受击仍沿`reportDamage`立即触发原追击；A变化不降状态、不清目标/发现度、不取消已经成立的攻击。既有FSM真正从CHASE退回ALERT等状态后，距离适应重新生效，不要求另经过一整次return。近身防卫仍指原FSM发现/受击及近战命中规则，不新增一圈必定触发的防卫半径。声音诱饵仍指向实际落点，不能把全局音量降低或所有噪声都抹除冒充友好。

主动敌意减弱不等于交流、招降、队友或无敌。直接伤害后的反击、攻击动作的命中条件、身体/环境接触、占漆与占空危险仍沿原规则；环境Host不因未使用地面AI而被误记为已获得友好收益。

### 3. 同化不改变净化点冲击强度（DEC-223）

`preDefenseBudget = 30 × tideIntensity`

同化描述玩家的身体变化，不改变净化点外界潮汐。普通归返、死亡、明确放弃、疗愈和公开预告均不读取A来增加冲击预算、分配或损伤。相同潮汐、预告、供奉、模块状态与随机流下，A=0/30/60/100得到相同的单轮冲击；不存在同化附加倍率或额外收费。

疗愈的时间成本由周期数量体现：更高A需要更多次疗愈，每次经过一轮正常冲击与潮汐推进；后续潮汐自然变化可以改变之后的冲击，但原因不是A。预告沿原可信承诺，不因A变化重抽目标或调整压力。真实首次归返免伤规则保持；疗愈不复用首次归返豁免。已经完成的历史冲击不追溯重算，之后的结算按本规则。

### 4. 培养藏每次疗愈一个周期

开始资格：处于可交互的净化点，归返/保存事务已结清，A>0，净化器**实际HP≥25**。不是25%上限；加厚不会抬高门槛。培养藏功能不绑成长级别、路线进度或工具持有。没有额外薪柴入场费，低完整度时通过原注入修复恢复资格。

每次明确动作只进行一次疗愈：

1. 检查上述资格及当前可操作状态；冻结A、净化器HP、当前预告/潮汐、供奉实例和唯一疗愈周期身份。防重复点击和键盘自动重复。
2. 按当前潮汐执行一轮正常、非豁免冲击；供奉照常参与防御、副作用、一般/高潮积累及成熟鉴定，成熟物照原规则回库清槽。
3. `A_after = max(0, A_before − 15)`。本轮冲击即使使净化器跌破25或归零，仍完成已经开始的疗愈；下一轮重新检查资格。
4. 推进一轮潮汐，按推进后的潮汐建立/读取下一份预告。记录真实冲击和退潮经历，不伪造一次裂隙访问或成功撤离，不消耗出击被动趟数、武器耐久或本趟物品，不改世界访问历史。
5. 疗愈不发任何正稳定度积分，包括成功归返、有限潮峰完整和潮汐切换的正奖励；模块由正HP降至0的负分及潮峰已破损事实仍正常记录。真实供奉成熟及成长经历属于实发生的系统结果，允许保留，但不直接发一次成长购买奖励。
6. 以上候选同笔持久化，成功后展示一次真实结果。拒写保持未提交状态/冻结候选，不能先给A减免或成熟物；重试不重抽、不再冲击。结果关闭后回到培养藏，若继续须再次手动执行一周期。

疗愈推进的是冲击/潮汐周期，不能用“成功出击一次”代替；实现若历史上共用cycle字段，须保持计数语义和首次归返资格正确，不让疗愈制造假run账本。A=0不可疗愈，长按不连发，不提供一键治满或后台自动治疗。

治疗从A=10/30/60/100归零分别最多需1/2/4/7次**成功完成**的周期；净化器损坏会要求中途修复，不能承诺连续七轮无条件可执行。每轮减少固定百分点，保留小数，最后一轮精确归零；不用比例衰减产生无限尾巴。

## 数值结构与体验基线

以下为满污染、无其他工具/Host修正的投影；档位仅是观察样本，不是额外机制门槛。

| A | 视距倍率 | 未激怒感知倍率 | 归零所需疗愈周期 |
| ---: | ---: | ---: | ---: |
| 0 | 0.550 | 1.00 | 0 |
| 10 | 0.585 | 0.94 | 1 |
| 30 | 0.655 | 0.82 | 2 |
| 60 | 0.760 | 0.64 | 4 |
| 100 | 0.900 | 0.40 | 7 |

10是可读的残留；30提供保留适度同化的理由；60明显改变观察/绕行余量与清除所需周期；100仍有真实Host/反击危险。无抗性时，涨10点需满污染后低/中/重累计16分40秒/12分30秒/10分钟；这是跨趟累计时间。

R=60%、G=20%时同化仍以基础速率32%增长。最终潮强度3时，任意A的单次防御前预算均为90；实际损伤继续受供奉、模块HP和逐模块取整影响。

## 玩家交互与结构层约束

本节只约束新增事实和操作。视觉规格部分由Art agent补充/核对既有Kit，不据本文声明审美或实景通过。

**载体决策。** 裂隙污染属于随身即时读数，同化属于低优先级常驻、可主动详查的长期身体状态；培养藏疗愈为既有世界内装置旁的操作读数；归来报告保留真实场景。全部沿`#dom-ui-root`，不增加实体终端、独立软件表单或第七站。术语按world：同化、疗愈、培养藏、净化器完整度、冲击、潮汐。

**裂隙内读数（DEC-223纠正DEC-222实施）。** 生命/污染仍是左上即时主层；右上“随身”入口附近常驻独立短行“同化 30.0%”，标签和值分开，以较小字号、较低明度和空间分组降为次级，不画第三根条。A=0也显示，旧150协议不补造读数。HUD不显示“跨趟保留”“污染已满，同化加深”等机制介绍，不加toast或闪烁。Tab/原点击入口打开“随身”，身体小节只显示同化、满污染时视距相对基础值及未激怒敌人感知距离相对基础值；删除归返冲击增幅。数值消费已有派生函数，不抄公式。查看不暂停，已提交变化只刷新读数，不能重建物件列表或丢失滚动与选中。帮助默认收起，仅玩家主动展开。

**参考锚点。** 沿当前Kit已锁研究：Darkwood取场景留白与风险阅读，Signalis取当前对象/说明的主从与克制读数；不移植其皮肤、CRT外壳或大网格。本轮未另开新审美方向，当前培养藏/报告的实景必须由Art复核。

## 存档、失败与边界情况

- 旧合法基地档缺同化字段迁为0，不从出击次数、稳定度、死亡史或旧混乱峰值推算。新协议缺必需字段、值非有限数/越界或未知版本按存档验证拒绝，不能静默洗白。
- 旧active/settled在途记录沿其冻结协议完成，不把150污染截成100、不追溯同化、不套新AI适应规则。新同化规则仅在下一次真实新出发冻结启用。旧记录即使被现行开放世界政策弃局，也按该局已承诺版本结清一次。
- 新出击逐帧候选与结算保存A。死亡、撤离、放弃无额外同化结算加成，也不回退到出发时A；刷新恢复最后成功提交的完整状态，保存失败不继续模拟以取得免费适应。
- A=0不能疗愈刷潮汐或供奉。A>0时有限疗愈带来正常供奉成熟是承受时间/冲击成本后的真实收益，不能独立禁用成熟，也不能把它计作成功搜撤收入。反复“挂机同化→疗愈成熟”的净收益须实测。
- 全模块残破不会触发本系统自动死亡或锁死出击；通过原白板替补/低污染出击获取薪柴，修复净化器到25后恢复疗愈资格。这个路径必须实机成立，不能仅因规则上允许出发就声称已经可恢复。
- **保留高A的长期取舍待验证**：取消不合理的冲击增幅后，不疗愈即可保留适应收益，治疗周期成本只在主动治疗时发生。不得擅自补入隐藏债务、自动伤血、永久降上限或强制结局以制造代价；需要后续与用户认可的身体异化及核心体验一并设计，未实施的美术也不能冒充已有玩法惩罚。
