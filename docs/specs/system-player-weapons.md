# 玩家武器：种类定打法，品质定强度

> TL;DR：当前仅撬棍家族；开局白板、不可升级。所有撬棍共用一套攻击与受击反馈模式，品质提高伤害区间，同品质小幅重量/污染抗性取舍；每挥在固定区间内抽取伤害。正式CSV已接生产，数值为首轮实战校准基准。

## 1. 用户当前决定与架构分工

2026-09-09用户审查：武器种类承载攻击功能与性质区别，同种武器优先有低→高品质层次，玩家先选好品质再比同品质小差异。属性从后克苏鲁生存/搜打撤推导，污染抗性可跨装备和玩家累积，负重可影响行动。死亡全丢、开包不暂停保持。

因此撤下短柄/加长/扁口/配重/包布/复响/滞口的功能分支；不把旧长杆/锤/枪的玩法塞回撬棍。旧铁器与暗材质的世界质感延续；八种功能型外形作废。最新用户否决科技工艺升阶外观，改为污染/侵蚀导致的结构异化。

- Family定义攻击形状、距离、目标预算、时序、是否穿透/溅射以及动作。
- Quality定义同家族伤害区间；品质不自动增加抗性。成品区间固定，每次合法挥击在区间内浮动，后续不升级。
- 同档倾向只微调重量/抗性和对应构造，不改变攻击功能。
- 生存属性跨玩家/有效装备汇总，权威为[system-survival-attributes.md](system-survival-attributes.md)。
- 物品归属、库存、负重容量、拾取和装配归[system-field-inventory.md](system-field-inventory.md)。武器品质不再产生独立库存槽或容量限制。

## 3. 当前品质库与初始平衡

完整数据与造型说明见[撬棍内容](../content/player-crowbars.md)。首版四档普通/优良/精良/卓越，伤害区间分别22–28／29–35／36–44／46–56；高档下限高于前档上限，主要强度由品质决定。数值已接生产战斗，仍待玩家实战校准。

用户已确认：每件武器显示固定伤害区间，每次挥击在区间内浮动。本稿采用含端点的均匀整数抽样；不另加掉落实例的随机伤害词缀。每次合法挥击只抽一次，整次攻击快照和跨身体/核目标共用该值，不因有效帧数量、目标遍历次序、打开背包或查看说明重抽。未命中也不保留下次必中的有利随机值。

抗性退出品质基值。除普通白板无加成外，后三档使用相同的横向倾向：标准3.0重/+2%抗性，轻型2.7重/+0%，抗污3.3重/+4%。同品质共用伤害区间与动作，抗性为成品的绝对贡献，不再叠加0/6/12/18品质抗性。抗污款不对应一种专属攻击或科技隔附壳。实例归属和拾取只搬运同一成品，不能重抽属性。

普通白板保留一件，后三档各三件，共十定义；武器不可升级。高品质的主要收益是更强的伤害区间；同档用抗性和重量表达小取舍。外观异化程度不自动编码抗性，更污染不额外造成自伤、使用次数损失或混乱收费。

伤害浮动使旧固定击数承诺失效：当前75HP身体，普通可能3–4击，优良3击，精良2–3击，卓越2击；50HP核对应2–3／2／2／1–2击。精确概率见内容表及复算脚本。特别是普通22–28会有约44.6%的情况从旧固定三击变成四击，属于须测试的初始区间代价；必要时调整区间，不能用暗中保底、临界补伤或改敌人HP伪造稳定击数。

## 4. 撬棍只有一个攻击模式

全家族共用40px、120°短弧、最多2个合法目标、120ms起手/60ms有效/220ms回收、500ms攻击间隔。无穿透、无溅射、无迟到余击、无减速、无品质专属击晕，所有等级都保持同样的交战距离与操作节奏。

一次AttackInstance统一武器实例、伤害区间与本挥抽样快照、锁定朝向、时间、轨迹和目标记录；Combat身体与Host核消费同一份，不各读一组常量。目标按真实接触先后排序，遮挡校验后扣共同预算；每挥同一目标一次，同宿主最多一核。不可杀场体不进入伤害候选。

近身、背面、墙角判定须贴合可见棍端轨迹；不以16px自动全向命中造成身体背后挨打。低帧跨有效段不能漏判或多判。伤害来源仍为player，不借tool来源绕过混乱。

命中每目标基准混乱5、空挥/接触/击杀声96/160/192共用。新污染抗性接入后由统一正向混乱入口减免一次；高品质较少的预期命中次数是允许的品质收益，不能额外提高其混乱收费把升级感抵消。具体经济由掉落频率与死亡损失配合验证。

## 5. 同一反馈模式，明确的命中品质

玩家四向持握、起手收身、钩端加速、接触短停、带重量回收共用一套骨架与时钟；按品质替换侵蚀、扭结、错生钩根等完整形体，在相同握点和有效接触轨迹下映射骨架，不靠延长柄身扩大距离。移动中出手仍可读脚底着地关系，棍子不能成为贴着静态人物的旋转指针。

敌人受击使用同一接触反应规则：实体局部压缩/错位，核局部缩陷，不可杀场体不演掉血/击退；反馈按被击材料与致命状态变化，不因撬棍档位变为另一种受击模式。局部姿态停顿不冻结敌人攻击时钟，蓄势前兆不被白闪遮掉；死亡注销碰撞与伤害，视觉再按其基底收尾。

允许高品质的撞击声音更紧实、器物形态更完整，但不附带新功能、额外hitstop或更大逻辑击退。玩家自己受击也必须留出方向、失衡和危险反馈，持武层不能盖住伤势。

Space保持攻击。单次输入缓冲锚定下次合法攻击起点前100ms，不按动画回收末尾计算；开包清未执行输入，关包不误挥。鼠标瞄准、蓄力、连招和热切不趁机加入。

## 6. 品质与世界的视觉关系

v3污染造型方向已获用户认可；当前[补色概念v4](../art/iteration-19-concepts/crowbar-quality-v4.png)与内容§6的32px世界模型／48px图标为实际素材评审对象。用户认可v2的差异可见，但否决其科技工艺方向。品质递进改为：仍可使用的铁器逐渐受到更深的外来模式改写；这组作者设计的可用成品以异化造型体现品质，不建立“所有越烂或越污染的物品都越强”的通用规则。

普通保留原生铁撬棍；优良出现单侧错生钩根与折曲；精良杆身扭结、分裂再融合并形成负空间；卓越上部形成错位铁褶和不合常理的空腔钩根。钩头、杆身轮廓和空隙本身变化，而非原杆上贴一层装饰。金属质地和能被人握住的部位保留，侵蚀是改写的表征，不只是多加锈点。

四档仍使用同一近身攻击方式。造型可以改变外轮廓和内部拓扑，工作端有效轨迹、握持基准、命中范围与目标数保持同家族规则。高档不变成斧、镰刀、锤或具有额外打击部位的武器；没有飞散刀片、连锁追击、触手攻击等新功能。

抗性只由属性提供，不以异化强度或发光程度承诺。青绿污染色沿内腔与深层接缝可辨地出现，普通白板无污染色，大明暗块和结构承担识别。新图是概念审查，正式精灵仍须在角色与地面尺寸验证轮廓、握点和像素密度，不能用大图识别代替上线验收。

## 7. 来源与未来扩展

武器从环境翻堆与污染物共享揭晓/负重校验/取得或留地；不自动装备。旧八功能池与首发现功能款权重CSV作废，新池按品质分布再选同档倾向。首个成功揭晓的非安全档薪柴堆额外提供优良标准撬棍；之后按安全/争夺/深处8%/18%/30%机会追加武器，再按品质与同档倾向抽样。权重与首发现规则在正式CSV中，实际物件走同一负重事务。

来源数量/品质概率须按当前出击长度、场景危险与死亡全丢校准，不暂定每图必出卓越、不凭打开背包重新抽样。后续危险来源可提高高品质概率，但地图背景联动目前只保留来源/材料标签，不藏地铁伤害倍率或未实现的撬门能力。
