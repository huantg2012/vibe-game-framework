# 首页 → 净化点入场

## 载体与触发

960×640固定逻辑画布上的短过渡，DOM黑罩挂#dom-ui-root，与既有canvas缩放/letterbox对齐。首页选中新游戏（含覆盖确认后清除）或继续后运行，保存/载入仍走session共享逻辑。其他场景入口不自动套此过渡。无进度条、章节卡、额外确认或文案。

## 时序意图

新游戏约2.1秒，继续约1.1秒；生产配置为2100ms/1100ms，实景逐帧记录约2108ms/1107ms；短版明显短于新档。

1. 首页输入立即锁；标题/菜单文字先退（新160ms、继续100ms），原背景沉黑（新420ms、继续240ms）。
2. 现有净化点mechanical hum于新120ms/继续60ms提前进入，isolation drone平滑接替菜单音乐。不新增传送/撞击声，切场不能halt掉已开始的hum再重启。
3. 全黑才切净化点，不人为增加黑屏等待；复用同一个罩或等价保证连续遮挡。场景创建完成即显现，摄像机从最终zoom的96%/98%居中起步，平滑落到原精确值，不旋转/平移。
4. 新1250ms/继续620ms左右逐渐揭开世界，镜头在新1460ms/继续720ms完成（从净化点创建起算），移除tween后恢复精确zoom，再让HUD出现；HUD/底部提示末段220ms/140ms进入，显完开放控制。

黑罩色#080a0c；原场景强光自然先于暗地被看见，无需逐个装置造额外显现层。轻镜头由远近变化表达空间，不变装置排序/边界/出生点。

## 行为约束

- 模式new/continue明确传递。继续读档失败时共享逻辑回退new，使用新档节奏；不能只根据按钮文案推断最终模式。
- 重复Enter/Space/鼠标点击不重复重置、载入或切场。覆盖确认出现本身不触发过渡。
- 入场期间移动、E/Tab/Esc及指针世界交互关闭，物理速度归零，不能把确认键带到落位后的操作。视觉大气和装置动画可运行。
- 不借用全scene暂停做入场锁，以免timer/tween停走。失焦由既有暂停处理，恢复时不消耗后台时间，不跳到结束。
- reduced-motion为两路共用500ms短淡变（160ms离场+240ms显现+100ms HUD），取消镜头运动。音频未解锁/静音/资源缺失不得阻断入场。
- scene shutdown/中途切走必须释放罩、timer/tween、监听和输入锁；HUD恢复由当前场景管理，不污染下一次访问。
