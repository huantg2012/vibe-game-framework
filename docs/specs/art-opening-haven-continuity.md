# 首页与净化点视觉连续性

## 1. 状态与规格边界

本规格记录2026-10-01用户要求落盘的下一轮计划，**规格已记录，实施未开始，美术未验收**。本次落盘不修改游戏、资产或正式首页。

本文件是这轮联合视觉制作与验收的唯一规格；[美术方向](../art-direction.md#resume-art-rebuild)继续维护全游戏材料、污染和场景原则。[入场规格](ui-menu-entry-transition.md)独占新游戏/继续、存档安全、输入锁、时序和清理等运行时行为。本文件不另建一套转场参数。

现行入场仍按原合同执行，包括遮黑切场和轻微居中缩放。下文“不借黑场也能认出同一世界”是**两端画面的独立验收方法**，不是已经取消黑场或批准新镜头。若新制作需要改转场，先在原入场规格中原地修订，再实现和验证。迭代14的验收只属于当时的实现，不覆盖本轮新美术。

[旧静态换镜头母版](../art/demos/opening-master/index.html)已被否决；[三版独立首页](../art/demos/opening-three/index.html)均未获选，不作为定稿推进，保留作失败对照。下一轮不默认选择A/B/C，不继续独立首页抽图。

## 2. 要解决的体验问题

用户的两项要求必须同时成立：

1. **首页有足够的吸引力。** 玩家一眼惊艳，或因人的处境、遗迹尺度和未知空间产生好奇，想点进去。
2. **进入实景后承诺得到兑现。** 玩家认得同一个人物、核心和庇护场所，感到自己获得了在画中行动的能力；可以察觉精度变化，不能觉得换了一个更贫乏的世界。

连续性不能只靠相近配色、相同世界观名词或一段淡变。需要延续可被眼睛辨认的形体、材质层次、明暗组织和空间关系。获得控制后的身体重量、动态照明及可达空间，应增加真实感，补偿静态描绘细节的减少。

首页仍需独立创作：以人的处境和世界的吸引力组织画面，不按功能站位置拼一张地图。净化点则需展开行动与交互空间。两种构图服务不同观看距离，但共同内容及表现标准要在制作过程中同步建立。

## 3. 共同依据与视觉身份

### 两个依据，各有职责

- **现行净化点提供内容依据。** 以现已建立的人物、核心、炉子、建筑残骸坐席及平台结构为出发点，保持身份与相对尺度可辨。现有模型和渲染可以改进，不能成为品质上限；已有内容认可也不等于所有现行表现已获验收。
- **最初首页原画提供表现力标尺。** 对照[原画](../../public/assets/art/menu-last-light.png)的巨型遗迹、深渊纵深、厚重材料和人的渺小处境。学习这些效果如何由形体、明暗和空间构成，不逐像素复制，也不为了华丽另造一套人物与装置。

共同制作单元为：**人物—炉席—核心—平台断沿—外景巨构**。先让这一组在首页与实景都成立，再展开完整首页画幅与净化点视野。不是只做一张无法进入游戏的局部样板。

### 必须共同保住的内容

- **人物：** 同一身份、装备轮廓、身体比例与重量。首页可以坐、站或采用不同取景，不得靠加大体格、另换服装或英雄化姿势提升吸引力。姿态差异要有自然交接；继续游戏不得因此擅改存档状态。Rift低精度角色的一致性边界保持。
- **核心：** 是被收束、约束的异世界污染能量，具有体积、内外层与胀缩感；冷而克制的灰绿发光，向周围作用，是净化点最强光源。仪式感来自人、装置和空间的关系，不能把它改成更大的门、灯泡或与实景不同的圣物。
- **庇护建筑：** 平台是依附残存结构的厚重建筑，能读出楼板断面、承重和材料破坏；不是薄浮岛。炉子与可坐残骸构成可信的停留处。首页允许取景遮蔽功能布局，不能制造与实景相矛盾的建筑尺度和核心邻接关系。
- **光与材料：** 肩灯、炉火、污染对象的光共同塑造环境；绿色专用于污染相关表达，不变成生机勃勃的装饰色。金属转面、石材断面、接触阴影和混光必须在两端可读。
- **外景：** 近处残骸与据点有结构联系，中景隐约可辨，远景接近不可见但仍有尺度及偶发异动。远处巨构可以概括，不能从首页的深厚世界退成实景的大块空黑或均匀蓝底。

## 4. 合理降级的边界

降级应是**描绘变简**，而非形体与视觉身份消失。先保留大形、结构层次和光影，再减少微细节。

| 对象 | 可以减少或改变 | 必须保住 |
| --- | --- | --- |
| 人物 | 镜头变远后省略衣褶、面部与微小装备细节；按情境改变姿态 | 轮廓、身体比例、装备身份、承重与动作重量 |
| 核心 | 能量与光效采样密度、细小机械刻画 | 形态、相对尺度、受约束的体积能量、主光源地位 |
| 建筑与设备 | 微裂纹、骨料、书册等细节数量 | 楼板厚度、承重关系、设备体积、金属转面和层次 |
| 照明 | 散射、反射、阴影的采样精度与细密程度 | 光从何处来、照到哪里、冷热分区、遮挡与体积作用 |
| 外景 | 远处纹理与小物件，按距离概括轮廓 | 巨构尺度、前中远层次、黑暗中的空间与未知感 |
| 镜头 | 首页独立构图，实景退到可操作距离 | 可辨认的场所与对象关系；不能靠镜头切换掩盖身份变化 |

不得用“实时游戏必然做不到”跳过验证。现行净化点已经结合预渲染数据与实时合成；若出现成本问题，应在真实管线测量，再选择牺牲微细节的方式，不能先把建筑、材质和外景削平。

## 5. 制作顺序与内部检查点

以下是一个方向内的制作顺序，不是分批要求用户审批。阶段产物用于自查和纠偏，最终一次性交付完整体验供用户审查。

### 第一步：固定两端依据，确定共同画面内容

保存原始首页、当前真实净化点全景与关键对象近景，记录对应资产和代码版本。明确人物、核心、炉席、平台断面与外景巨构在两端各承担什么作用；首页包含实际标题和菜单所需的画面留白。

据此确定一个联合方向与首页构图。不得把旧三个候选默认视为通过，也不把当前相机坐标、现有模型精度、站立姿态变成创作限制。

**检查点：** 能具体指出两端同一个对象与空间关系，知道哪些要保持、哪些需要共同提升；不是用一串世界观词语证明同源。

### 第二步：同步制作首页与真实实景

围绕共同制作单元，两端交替推进、同轮比较。首页集中表达人的处境与世界吸引力；实景提供可走、可停留、可接近核心的空间。不得先把首页单独做到漂亮，最后要求游戏去追；也不能只压低首页精度来消除落差。

优先解决三项，顺序按当前差距调整：

1. **外景尺度与纵深：** 让首页和游戏中都存在可辨认的巨构及深度层次，验证角色移动后的远近层随动。
2. **核心与人物：** 对齐轮廓、相对尺度、材料与发光性质，检查同一观看尺度下是否仍像同一人物与装置。
3. **材质与照明：** 做实断面、金属转面、接触遮蔽及多源混光；细节服务形体和光照，不能靠噪点、脏污、贴亮片补足完成度。

制作方法以能稳定达到目标为准。使用参考、生图或其他离线手段时记录来源；进入游戏的内容必须落实为实际可用资产及可编辑配置，不能用生成图冒充已经实现的场景。保留每轮两端的对应版本，防止单边漂移。

**检查点：** 在正式渲染器中查看角色移动、肩灯照射、核心动态和外景随动。实景截图可以记录，但不能代替动态验证。

### 第三步：先检验两端，再设计交接

在正常显示尺度下直接并置首页与真实游戏画面，再交替查看；必要时对同一对象等比例裁切诊断。此时不加淡出、黑场或解释文案，判断玩家能否认出同一场所与同一画风，指出损失的是微细节还是视觉身份。

两端成立后，以人物或炉席等易识别内容作为交接锚点，制作短入场，展开到操作距离并交还控制。采用剪辑还是镜头移动由最终画面决定，**不预先强制一镜到底、同世界坐标或旧模型换镜头**。不为展示镜头添加无必要的角色表演、等待或功能步骤。

**检查点：** 转场帮助理解空间，不负责隐藏两端不匹配。若静态并置仍明显像两款游戏，退回第二步修两端。

### 第四步：完成可操作样片并回归

在隔离测试记录的入口中，提供完成首页、点击进入真实净化点、移动、接近与使用交互对象，以及返回首页的完整链路。返回比较入口是验收便利，不代表新增游戏机制。

保持现有业务行为。改变可行走几何、物件位置或遮挡时，同步核对导航、交互包裹区、上下层可达和深度排序，不能牺牲已修复的动线与动作换截图效果。改变渲染管线时对照基线检查运行成本，不另立未经测量的性能借口。

检查新建/继续的既有语义、重复触发、失焦恢复、静音和减少动态效果等受影响路径；具体行为继续以入场规格为准。不能为了镜头把继续记录伪装成新局，或重置用户正式存档。

**检查点：** 最终体验来自真实场景和真实操作；素材图、自动脚本通过、受控回放和亲自操作的证据分别记录，不相互替代。

## 6. 最终交付与验收

交付同一版本的三项成果：

1. **完成首页：** 足够评判成品品质的画面，含实际标题、菜单构图及最终采用的动态表现。
2. **对应实景：** 正常游玩镜头下的真实净化点，能检查人物、核心、炉席、建筑与外景；同时提供与首页的直接对照。
3. **可操作入口：** 可进入、移动、交互并返回，能亲自感受从观看到控制的连续过程。记录本次资产来源、版本、改动范围、实测路径与未验证项。

用户最终验收三问：

- **首页是否让我想进去？** 构图是否有明确吸引力，而非仅仅内容正确？
- **进去后是否认得这个世界？** 人物、核心、建筑、材料、照明与纵深的承诺是否兑现？
- **获得操作权带来的真实感，是否足以补偿细节减少？** 行走、光照、空间反馈是否使画面成为可信且可居留的场所？

任何一项不成立，继续修同一联合方向中对应的问题，不以另一批独立漂亮图绕开，也不把技术通过标成美术通过。完整样片通过审查前，生产默认首页保持现状。
