# 生存属性：污染抗性与负重行动

> TL;DR：污染抗性汇总多个有效来源，降低外来混乱的正向累积；负重仍是唯一携带计量，行动变化由已用负重推导。属性不改变同家族武器的攻击方式。

## 1. 属性的职责

- 武器家族：决定攻击形状、范围、目标数、穿透/溅射规则与动作模式。
- 武器品质：决定同一家族成品的主要强度。高品质是通常应优先保留的更好装备。
- 同品质倾向：小幅重量与抗性取舍；不再让同品质物品分别扮演长矛、重锤或控场器。
- 玩家生存属性：承接玩家本身、有效装备和临时状态的综合结果。属性不是藏在武器模块内的私有加成。

只先定义污染抗性与负重行动，不一次加入护甲、元素抗性谱、耐力、暴击、闪避、吸血或技能树。以后扩展时仍需由具体关卡危险与玩家决策证明其用途。

## 2. 污染抗性：多来源，汇总一次

抗性来源预留玩家基础/永久成长、当前装配武器、明确提供此属性的已装污染物工具、临时状态。当前只有武器同品质成品倾向提供抗性，品质本身不提供抗性基值，不顺手给所有旧工具或成长节点发一份新加成。未装战利品、基地物品和地面物品都不提供属性；不允许背十把撬棍叠抗性。

正式计算（初始平衡值）：

`有效抗性 = clamp(玩家 + 在手武器 + 已装抗性工具 + 临时抗性, 0, 60)%`

这里各来源贡献的是百分点：玩家8%、武器4%、工具5%，相加为17%有效抗性；一次10点正向混乱实际增加8.3。达到上限仍至少承受40%外来混乱，不会完全免疫裂隙。上限60%是待验证初值，当前不新增提供8%或5%的实际玩家/工具条目。

新抗性放在正向混乱写入的最后一层，只应用一次：

- 时间渗透：先算现有核心、追击、临时增长/降低等倍率，再乘`1−有效抗性`。
- 被发现、战斗命中、场域接触等离散正向增加：各自算完既有规则，再乘同一个抗性因子。
- 起始混乱不是本帧新渗透，不减；净化/负向清除不放大；生命伤害不减；攻击消耗和污染物使用次数不变。
- 模式改变或调试直接设值不算普通渗透，需使用独立set/reset入口；不能绕过正向累积入口给新效果免税。

旧“混乱增长速度降低”只作用时间通道，和新“污染抗性”语义不同。保留其既有倍率与持续时间，不改名后重复叠加一次。界面提供来源分解和最终抗性，不把同一能力分别计在工具与玩家两侧。

抗性不直接消除已经累积的混乱；已有视野/行动惩罚继续按当前混乱数值计算。堆抗性获得的是停留与交战余量，不是永久取消危险。

## 3. 负重影响移动：同一数值的连续后果

用户认可的单负重背包保持：容量16，武器/污染物都计入，含已装配物；薪柴不在本轮改为负重物品。内部以十分之一单位整数计量，容量160、污染物20、撬棍27/30/33，UI显示2.7/3.0/3.3，避免浮点边界吞物。

提议轻载前半段不减速；超过半载后平滑减速，满载最多降低16%：

`装载比例 = 当前负重 / 容量`

`负重速度倍率 = 1 − 0.16 × clamp((装载比例 − 0.5) / 0.5, 0, 1)`

以当前基础80px/s、无其他减速为例：8/16时80；12/16时73.6；16/16时67.2。满载归途约多花19%的行走时间，这是取更多物品带来的真实代价，不再另扣混乱或另加疲劳条。

轻型比标准少0.3重量，同档差异刻意较小，不把轻型变成高移速职业。清掉一件2重战利品则会同时腾出容量并恢复部分行动，形成背包管理与撤离路线之间的联系。

与已有移动叠加：先按现有移动/攻击/工具/混乱倍率和既有0.5下限求出速度，再乘负重倍率；因此重载在高混乱时仍可感知。不得把负重塞入现有总倍率下限后被悄悄夹没，也不新增“至少40px/s”来把该效果再抹掉。按上述初值最差速度为基础80×0.5×0.84=33.6px/s；此下界必须验证能否避开必要反击与回到出口，若过度惩罚先减轻负重曲线。

只影响移动速度，不改变撬棍攻击时序、范围或回收动作；角色步频匹配实际移动速度。没有超重后继续慢走模式，超出16依旧需要留下物件。背包开着世界继续运行，速度收益必须在丢弃事务成功后更新，预览不能先改变角色。

## 4. 玩家如何读到这些属性

整备页在最终负重旁给一条“移动 −N%”和最终污染抗性；默认只显示结果，需要时展开来源。比较同品质撬棍时直接看到“少0.3负重／少2%抗性”，并预览此次装配后的总重与移动变化。

武器详情先品质、再伤害区间与抗性、最后重量；同一家族共享的攻击范围和节奏只在家族说明里呈现，避免十张卡反复堆同样数据。不存在DPS综合评分自动替玩家选装备。

常驻HUD保持克制：主要在拾取/丢弃/接近满载时给负重变化；完整来源只在背包或报告展示。生产背包与整备已显示已提交属性和装配预览；HUD只显示简短负重。

## 5. 验证与限制

- 抗性加法、封顶、负值、未装备、工具失效/破碎只计一次；正增/负减/初始值分通道。
- 保留既有工具时间倍率，不把10%时间减缓与10%抗性混为同一数值。
- 负重整数边界精确；装备与背包不双计；取/丢/消耗成功才改最终速度。
- 8、12、16负重及低/高混乱四向移动实测；不能让攻击回收或角色步频意外发生变化。
- 抗性为同品质横向倾向，不随品质上升；普通白板0，其余档均使用同一0/2/4百分点。高品质的收益归伤害区间，不把视觉污染强度再算一份抗性，也不增加侵蚀自伤机制。死亡全丢和来源稀少性仍须实测，不宣称已完成经济平衡。
