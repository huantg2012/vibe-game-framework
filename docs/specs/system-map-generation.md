# 系统设计：裂隙地图生成

> **TL;DR**: 每一次从净化点踏入裂隙、开始这一次出击时，生成器交出一整张裂隙布局（tile 网格、可走掩膜、出生、一个撤离点、薪柴、污染物节点、巡逻、地标、碎片类型 id）；出击未结束前不变。活算法已锁：抽风格锚 + 新种子 + 邻域抖动再生成烤图（合同 `docs/design-notes/slice-6-layered-generation.md`「Agent 入口」）。十张画廊是样例不是地图库。本文件锁硬规则（P/G/C）；扩空间改锚/抖动/碎片表，不另起生成器。

## 概述

本系统替换裂隙的手写固定图（`src/scenes/rift-map-data.ts`，约 48×32 矩形边 + 细碎障碍）。净化点不换。

它服务两件事：

1. **贪婪与撤退仍然成立。** 出生与撤离分列两端，主干走路约 40–60 秒；薪柴仍按「离撤离的路程 × 巡逻覆盖」分档。玩家要算的还是「还敢不敢再多拿一点」，不是「选哪个出口」。
2. **每一次踏入是另一块世界碎片。** 可走陆地的外轮廓不能靠「这是一张长方形纸」预判；障碍要读得出「这曾是什么」；两次出击的色温 / 地表 / 障碍语言要能分清。

`vision.md` 把「多种裂隙环境 / 生物群落」写在明确不做；`world.md` 写过 MVP 共用一套视觉主题。**人本 Slice 的指令覆盖这两句**：做有限种碎片氛围，优先已锁 L1，不是无限生物群落，也不是丛林 / 冰原 / 岩浆那种新题材。

宏观方向已锁（DEC-005 / DEC-ARCH-003）：不规则碎片 + 有机内部 + 窄连接。**不退回 BSP 方正房间。** 内部怎么填、外轮廓怎么来，下面给多条路，禁止一棵树吊死。架构里的 Voronoi+CA 是要认真验证的技术路线，不是本文件已经定案的唯一实现。

本 Slice **不**做撤离多样性（多出口、第二种条件、捷径口）。提示仍是「[E] 撤离」。小地图继续标**一个**撤离点。不新开 HUD、不新造标记形状。

## 技术事实（实现层可果断）

### 不规则指什么

不规则 = **玩家看见的可走陆地外轮廓**，不是「数组变成多边形」。

- 引擎里 tile 数组几乎总是矩形缓冲。矩形缓冲合法。
- 缓冲里、可走陆地之外的格子当作**虚空 / 不可走**。合法。
- **禁止**用「数组还是矩形」当借口，交出一张矩形可走区。
- **禁止**先铺满矩形可走区，再在边上啃几个缺口充数。

玩家看到的应该是：一块（或几块拼在一起的）陆地漂在虚空里，边缘弯、缺、错位。不要再用一圈矩形墙当地图外框。墙只出现在「这段墙曾是什么」的情景障碍里。

### 虚空、墙、视线（本条定技术默认）

| 格子 | 可走 | 玩家看见 | 挡视线 |
| ---- | ---- | -------- | ------ |
| 地板 | 是 | 地表（L1 底色 + 材质残影 + L2 污染） | 否 |
| 墙 / 障碍 | 否 | 可读残块（砖 / 木 / 土 / 金属仍可辨） | 是 |
| 虚空 | 否 | void-black，不是墙皮 | **否**（默认） |

虚空不挡视线，陆地轮廓才能被看见。对岸若超出视野半径，照旧看不见。若试玩证明 C 形陆地隔虚空对射太狠，再收，不在本轮改默认。

`TileType` 有墙 / 地板 / 裂口 / 虚空。虚空不可走、默认不挡视线，着色走 `void-black`，禁止铺成地板。`src/types/game-types.ts` 里 Foundation 草案 `MapData.exitPoints: Position[]` 是复数出口——**本 Slice 不实现那份草案的多出口**。生成器输出以本节契约为准。

### 缓冲多大

玩家移速 80 px/s，tile 32 px → 约 2.5 格/秒。主干 40–60 秒 ≈ **100–150 格**的走路路径，不是 100–150 格的矩形边长。

现图 48×32 从出生到撤离直线大约 10 秒，不够。加长靠**弯路 + 陆地拉长**，不靠强上 80×80。`GAME_CONSTANTS.MAP` 的 80×80 和 Voronoi/CA 数字是架构占位，**不是本文件已锁算法**。人锁方向后再改常量。

建议缓冲落在现图同级到略长（大约长边 48–64 格），以主干秒数为准。可走陆地**不得填满**这个矩形。

### 生成器必须交出的数据

```typescript
/** 一次出击的完整裂隙布局。出击未结束前不变。 */
interface GeneratedRiftLayout {
  seed: number
  fragmentTypeId: string
  // 矩形 tile 缓冲。界外虚空在缓冲内，不是把数组做成多边形。
  tileMap: TileMapData
  walkableMask: WalkableMask
  spawnPoint: Vector2
  extractionPoint: ExtractionPointDef   // 恰好一个
  kindlingNodes: readonly KindlingNodeDef[]
  contaminantNodes: readonly ContaminantNodeDef[]
  enemySpawns: readonly EnemySpawnData[]
  landmarks: readonly LandmarkDef[]
}

interface WalkableMask {
  cols: number
  rows: number
  isWalkable(col: number, row: number): boolean
}
```

`ExtractionPointDef` / `KindlingNodeDef` / `EnemySpawnData` / `LandmarkDef` 沿用 `src/types/map-types.ts`。本系统**新增**的是：种子、碎片类型 id、可走掩膜、虚空格、以及「这些坐标从生成器来」。

地标（`LandmarkDef`）是地板上的视觉锚，**不是**情景障碍本身。情景障碍必须写进墙 / 不可走格，让玩家绕、让视线断。只贴纸不够。

### 数据从生成器出

RiftScene、撤离、小地图、视野、地表、工具，都读这一次的 `GeneratedRiftLayout`。禁止再各自假定手写图上的固定格子。手写图可留作对照夹具，不是运行时真相。

## 规则

### G — 何时生成、何时不变

1. 当玩家**从净化点踏入裂隙、开始这一次出击**时，生成完整 `GeneratedRiftLayout`。同一次出击内不重跑。
2. 当玩家撤离或死亡、回到净化点之后，本次布局作废。下一次踏入再生成。
3. 「按 R」一律回净化点（DEC-056）。阵亡不是原地再打这一次。C4 已改 `RunController.restart()`。
4. 同一种子必须得到同一张图（地表噪声已是确定性的，布局也必须是）。

### C — 连通与坏图（FATAL）

连通性是地图生成的硬约束，先于审美、氛围、装饰。坏连通 = 坏图，禁止当成品或预览样例交出。

5. 从出生格 flood-fill，必须能走到撤离格。走不到 = 坏图。
5a. 陆地掩膜本身必须是一块四连通（外轮廓只留最大连通块）。禁止一次出击交出互不相连的多岛。
5b. 墙上完之后，全部可走地板仍必须是一块四连通。墙把地切开 = 坏图。先就地挖通，再重试。
5c. 装饰 / 植被 / 残骸 / 光影 / 粒子 / 波动 **不得**再拆连通：只画在已连通的可走格上，或做成不挡路的漆。
5d. 预览草案与正式生成器走同一条连通闸门。看起来丰富但走不通，不合格。
6. 薪柴、污染物节点、巡逻每一个路点，必须可走，且从出生可达。
7. 坏图：先修补（挖通一条合法通道、把点挪到最近可走格），再重试新种子。修补与重试都留在**人锁定的那条算法路线里**。禁止失败就换一家算法。
8. 重试有上限。到顶仍坏：开发期大声失败；发行期最后一次强制挖通出生→撤离，并记一条警告。不换路线。

### L — 陆地与外轮廓

9. 可走陆地的外轮廓必须不规则。验收看玩家看见的陆地边缘，不看数组是不是矩形。
10. 禁止：矩形可走区 + 边上几个缺口。禁止：四边一圈墙当外框。
11. 外轮廓算法：**已收口为生长 + 腐蚀，取最大连通块**（路 1C）。实现：`src/generation/outline-mask.ts`。坏图（填满缓冲、啃边矩形、贴齐四边）丢弃重试。相交矩形并集不是本批实现。

### O — 障碍

12. 障碍是嵌进岛的体量，不是岛心道具，也不是胡椒粒。人要能指出走法（这边能绕、这边能穿）。覆盖浅时可能还认得「曾是什么」；覆盖到 unnamed 时指不出名字也成立，不算失败。
13. DEC-005 反的是「方正房间 + 走廊像地牢游戏」，**不是**「这段墙曾是一栋房子」。残缺体量允许。闭合房间 + 门廊，禁止。禁止完整器物剪影（整节车厢、完整月台色带）。**1 格宽长条正交织网同样读成迷宫**（DEC-058）：真实长墙可以有，但不能用很多根同样细的条拼接。障碍要读成体积残骸，不要读成地牢平面图。
14. 细胞自动机（CA）可以当风化（咬边、穿洞、让残块显老），**不能当唯一结构来源**。禁止只靠 CA 胡椒粒墙交差。
15. 现图已有 L/T/C 和小簇（2–12 格），人仍读成细碎随机。所以「把簇稍微加大」本身不够。见约束 2。把簇改成贯穿细篱笆也不够——那是迷宫，不是情景。
16. 障碍策略：**方向 1 厚短残块**（DEC-058，2026-08-18 人锁）。走法骨架与残片身份分开。预览栈：`structure-grammars.ts` + `cover.ts` + `stealth-density.ts` + 配方。`masses.ts` 的围院语言不进这条栈。诊所/地铁也走短板/坨，全图最多一把 L。墙围死的地就地挖开。CA 不当结构。
16a. 预览 **不得**用「最长轴对齐空直线 ≤14」当生产循环或 FATAL。形状闸门：1 宽直行 ≤6；非木墙至少一半属 2 厚/坨；平行窄槽 0；无三向 1 宽巷；至少一块 6×6 空地且边缘有厚掩护；禁 2–4 宽且长 >8 的巷；墙占比 ≤18% 是顶。连通仍 FATAL。
16b. 密度已锁（DEC-061）：DEC-060 结合层进生产岛。身份墙之后按可藏距离补厚短件。人认后空地再收约 20%（种子 101：墙约 18% 顶、空矩形 72–99、掩护 P90 5–7）。P90 到厚掩护 ≤8；距掩护 >7 的四连通块 ≤48 是尺不是 48 格硬闸门。禁止用空直线工厂或空矩形 48 倒逼篱笆。沿缘锚只向内补，岛心空。褶脊 / L / 双梁 / 宅基 / 残体 / 嵌板才允许尽端开口的 2 厚隔断。

### P — 布点（一个撤离，不要多样性）

17. 出生与撤离分列陆地两端。撤离是继续前进抵达，不是原路折返。
18. 恰好一个撤离点。走近按 E。触发半径沿用现规则。位置由生成器给。禁止落在手写图那个固定格上（现图大约是偏上居中的 `X`）。
19. 撤离格本身不在任何巡逻的常驻视野内。通往撤离的最后一段由 1 个巡逻覆盖（最后一道关）。**这道关必须是渗透体**（`type: 'infiltrator'`）。改写体不站撤离门。
20. 薪柴分档与数量沿用 `system-chaos-scavenge-extract`：safe 3 / contested 3 / deep 2。坐标改由生成器按「离撤离路程 × 巡逻覆盖」放置，不再写死 ASCII。
21. **换路是硬保证**（DEC-064，覆盖 DEC-061 / DEC-062 的软目标）。仍是**一个**撤离点。不是两个撤离点，不是捷径口。`npm run check:layout`：无换路 = **坏图（FATAL）**，不是 info。失败则**重试整岛**（换种子、同一条算法）。禁止为挤路加细墙、破坏规则 16a/16b、或让墙后地板四连通分量 ≠ 1。连通仍 FATAL。规则 8 的发行期强制挖通只救连通，不救换路。

    机器判定（按序；任一步失败 = 坏图）：

    1. **主路** = 出生格 → 唯一撤离格的四连通最短路。长度 = **格子步数**（BFS 移动次数 = 路径格数 − 1）。走不到已由规则 5 判坏。
    2. **第二路存在**：把主路内部格（路径上除出生、撤离外的每一格）**临时当作墙**之后，出生仍须能四连通走到撤离。走不到 = 无换路。临时墙只用于本判定，成品图上这些格仍可走。
    3. **第二路** = 上述临时墙上，出生→撤离的四连通最短路。其格子步数必须 **≥ 1.15 × 主路格子步数**。不够长 = 坏图。
    4. **开阔格**：可走格满足「四邻（上右下左）墙格数 ≤ 1」**或**「到最近墙格的四连通格距（曼哈顿，格为单位）≥ 2」。墙 = 墙格，不含虚空。四连通距墙 ≥ 2 蕴含四邻墙数 = 0，故本 OR 的有效判定是 **四邻墙数 ≤ 1**（贴着一面墙走仍算开阔；夹在两面墙之间的 1 宽缝不算）。
    5. 一条路的**开阔格占比** = 该路路径格中开阔格数 / 该路路径格数（含出生与撤离）。两条路里**较短者**（格子步数更小；若步数并列则主路视为较短）必须开阔格占比**严格更高**（= 更暴露）。较短者不够暴露 = 坏图。
    6. 以上任一步失败：丢弃本岛，重试整岛。禁止用加细墙、拆形状闸门、切开地板连通来「做出第二条路」。
22. 巡逻（过渡期，DEC-077）：仍是 3–4 个占地可追击，其中**恰好 1 个** `type: 'rewriter'`（听觉主轴仍由改写体占名额）。乙 / 丙 / 丁不进 `enemySpawns`，由钉层 + 宿主系统抽卡物化；抽卡带 `hearingAxisTaken: true`，禁止再抽听噪。钉层（墙缘折线、簇核、走廊包围盒）必须交出。路点可走、从出生可达。撤离门仍是视锥甲，不担任听觉主轴。全图听噪 === 1 的最终迁移未做。契约细节在 `system-enemy-ai`「生成器契约」与词法 spec 实现规格。
23. 污染物节点放在可走格，从出生可达。数量沿用现图量级（现为 3），本 Slice 不新开节点规则。

### A — 氛围

24. 禁止所有生成结果共用现在这一套户外灰绿（`procedural-surface` 写死的 `frag-outdoor`）。
24a. 每一次踏入抽 `FragmentRoll`：`contaminationAge` ∈ {new, standard, ancient} 与 `ruinSeverity` ∈ {intact, broken, eaten}（`typeId` 即本次 `fragmentTypeId`）。两轴必须实际抽取（同种子可复现），禁止跳过抽取、把所有图写成 `standard` + `broken`。允许某次抽中该组合。旋钮只走 `docs/art/rift-fragment-surfaces.md`「组合轴」；禁止新 hex。一张图一个 `typeId`。

26. 碎片类型的策划字段进 `data/*.csv`（建议 `data/rift-fragments.csv`），构建期进 `src/generated/`。禁止在代码里手写主题表再反向导出。

## 约束 1 — 不规则外轮廓（至少三条路，未定案）

要解决的问题：整张图是规则矩形，四边一圈墙。玩家对「往哪探」有稳定预期。

下面每条都能做出可走掩膜。人给的「相交矩形并集」必须在列表里，且旁边至少两条完全不同的路。

### 路 1A — 若干大幅相交矩形的并集

把 3–6 个大矩形错开叠在一起，并集 = 陆地，其余 = 虚空。

- **后果**：面积好控，主干秒数好调；轮廓在错角处拐弯。矩形少、又轴对齐时，玩家仍会读成「几块纸贴在一起」，不规则偏弱。
- **和世界观**：拼合说得通（被撕开的空间块）。矩形太多会顶到「不遵循常规建筑逻辑」。
- **和已有管线**：最好栅格化。和净化点极坐标团不是同一种形状语言——裂隙不该看起来像另一颗力场泡。
- **风险**：实现图省事变成「两个矩形咬一口」，等于禁止项。

### 路 1B — 宏观碎片并集，外围丢掉，外轮廓 = 拼合锯齿

先切 4–6 块不规则碎片（Voronoi 是做法之一，不是唯一），丢掉外围，留下的并集当陆地。外轮廓是碎片互相咬出来的锯齿。

- **后果**：最贴「异时空碎片被强行拼合」。容易出细刺、夹缝、空洞，要补最小宽度。
- **和世界观**：最贴 `world.md` 空间结构。
- **和已有管线**：和 DEC-005 / DEC-ARCH-003 的宏观层同方向。**本条不把 Voronoi 写成已定案。** 碎片也可以用斑块、印章、隐式场再切。
- **风险**：把约束 1 收成「做完 Voronoi 就等于不规则」——内部填满后外框仍可能是圆滚滚的一团。

### 路 1C — 从种子生长再腐蚀，取最大连通块

从种子蔓延，再腐蚀，最大连通块当陆地。

- **后果**：轮廓很有机，几乎不可能读成矩形。主干长度和「两端」不好控；容易长成一块洞穴岛，不像世界残片。
- **和世界观**：偏「有机洞穴」，弱于「被撕开的现实」。
- **和已有管线**：掩膜好做。情景障碍很难挂——没有「这是一条街」的骨架。DEC-ARCH-003 写明不设纯 CA 降级；若本条当**唯一**外轮廓，会和架构顶牛（人要求多条路，所以列在这里，不锁）。
- **风险**：和约束 2 抢：结构全靠生长，障碍只能再撒胡椒粒。

### 路 1D — 隐式曲面 / 极坐标压力团

用极径 + 噪声（或几个斑块的隐式场）画出陆地，再栅格化。净化点 `BoundaryShape` 只作技术参考，不照搬。

- **后果**：一块有叶瓣的团。不规则有，但常常是「一颗歪豆子」，不是拼合。
- **和世界观**：裂隙是伤口，不是门，也不是净化点那层膜。整张裂隙长得像净化点泡，两个空间会糊成一种东西。
- **和已有管线**：极坐标代码可参考，语义不能抄（净化点会随潮汐挤；裂隙陆地出击中不变）。
- **风险**：人一眼看成「又一个力场边界」。

### 路 1E — 预制轮廓章，旋转缩放当掩膜

手绘几枚破碎外轮廓，生成时旋转、缩放、可少量叠印，印成掩膜。

- **后果**：不规则有作者保证。章少了会被认出来（「又是那三块岛」）。
- **和世界观**：章可以画成撕页、碎玻璃，贴设定。
- **和已有管线**：章是内容资产，不是色表。不要把轮廓点写进污染物 CSV。种类少时，两次出击轮廓会撞车，和「布局不是上一趟」抢验证。
- **风险**：本 Slice 来不及画够章。

**禁止充数**：矩形可走区啃缺口。无论上面走哪条，这条都不算过关。

## 约束 2 — 障碍要有情景（至少三条路，未定案）

要解决的问题：人看见障碍，读成细碎随机，读不出「我在探索一块世界碎片」。

DEC-005 反的是地牢房间，不是「这段墙曾是房子」。CA 可以风化，不能当唯一结构。

### 路 2A — 先放 2–3 个可读地标，再填缝

先落下「一段街 / 一个院子 / 一道脊」这种人能叫出名的东西，缝再用小结构补。

- **后果**：玩家有东西可指。缝若仍用 CA 胡椒粒，地标一走过又碎。
- **和世界观**：贴「原有事物残影」。
- **和已有管线**：现有 `LandmarkDef`（水洼 / 刮痕 / 碎石贴花）**不挡路、不断视线**，不能当本条的实现。本条的地标必须是墙格组成的残块。
- **风险**：只完成贴花，墙还是细碎的。

### 路 2B — 按碎片类型换障碍语法

图书馆 / 医院 / 地铁 / 居民区 / 户外是表上的身份样本，不是五种换皮。墙形跟 `massGrammar` 走，走法骨架共用。

- **后果**：最能读出「这曾是什么」。和约束 3 绑在一起：氛围种类一少，语法种类也少。
- **和世界观**：基体不同、污染同一套（L2 崩坏簇，与改写体同源；DEC-069）。最贴设定。
- **和已有管线**：`procedural-surface` 必须吃碎片类型，不能写死 `frag-outdoor`。每种语法要 art A1 写墙 / 地表怎么画。五种全做，本 Slice 批次会爆。
- **风险**：语法只换贴图、不换形状，人仍读成同一堆石头。

### 路 2C — 提高最小特征尺度

禁止大量 1–2 格孤岛。残块至少到人能看成「一段东西」的长度（现图 2–12 格仍失败，下限要明显高于「一小簇」）。

- **后果**：画面干净一点。**单独不够**——现图已经不是 1 格胡椒粒，人照样读成随机。
- **和世界观**：中性。大石头不必曾是房子。
- **和已有管线**：好做，和任何一条都能叠。
- **风险**：把「加大」当成交差，约束 2 仍失败。

### 路 2D — 预制残块印章 + 污染侵蚀

先盖「未闭合的房基 / 半截站台 / 一排架子」印章，再用污染咬边、穿洞。印章不是闭合房间，没有门廊。

- **后果**：结构可读，风化后仍像残留。印章少了会重复。
- **和世界观**：就是「这段墙曾是房子」。只要不封成房间+走廊，就不犯 DEC-005。
- **和已有管线**：Qud 用 WFC 做历史建筑——可参考「先结构后侵蚀」，**不把 WFC 写成必选**（架构已标难调）。印章是内容，不是色表。
- **风险**：印章一封四壁、留门，就会退回地牢。

**CA 的位置**：上面任何一条都可以用 CA 咬边。CA 不能当本约束的唯一答案。

## 约束 3 — 不同出击，不同氛围（至少三条路，未定案）

要解决的问题：现在每次都是户外灰绿。人要求两次踏入能分清是另一块碎片。

已锁五套 L1：旧图书馆 / 医院实验室 / 地铁工业 / 居民区 / 户外。本 Slice 不发明新色。

`art-direction` 有一句内部张力：「同一张图统一一个 frag-*」和「碎片接缝两种底色相邻」同时存在。下面把「一张图一种记忆」和「一张图拼两种」分开写，等人拍。

### 路 3A — 每一次踏入抽一种已锁 L1，地表 + 障碍语法跟着变

五套记忆都进策划表，`enabled` 控制谁参与抽取。抽中谁，整张图的底色、材质残影、障碍语法跟谁走。

- **后果**：最能回答验证问题 4。A1 和障碍语法要按套数做。五套全开，本 Slice 重。
- **和世界观**：覆盖「MVP 一套主题」；仍是有限种，不是无限群系。
- **和已有管线**：优先。色板已锁，地表管线已在，只是写死户外。必须参数化，读 CSV，不手写第二套色表。
- **风险**：只换 L1 六位数、不换材质和语法——5–10 的色差在 32px + 视野遮罩下可能消失（art-direction 自己标过这个险）。

### 路 3B — 同一种记忆再叠污染年龄 / 浓度

同一套 L1，再叠偏蓝新生 / 正 teal / 暖绿古老（对应已锁轻 / 标准 / 重）。

- **后果**：同一种地方，新旧不同。两次都是户外时，人可能读成「同一个公园，故障多一点」，不是「另一块世界碎片」。
- **和世界观**：浓度梯度已锁，合法。单独不够撑「不同世界的碎片」。
- **和已有管线**：地表已有 teal 渗参数，最好做。适合当 3A 或 3C 的叠加，不适合当唯一手段。
- **风险**：验收时被当成「还是那套绿」。

### 路 3C — 本 Slice 只做 2–3 种，其余留给后面

策划表仍写五套，`enabled` 只开 2–3。优先开**语法差得最开**的，不要开两套都是灰绿近亲。

- **后果**：本 Slice 做完的概率高。验证「能分清」用 2–3 种就够。其余记忆留给后面的 A1。
- **和世界观**：仍是有限种。
- **和已有管线**：户外已经在跑，等于白送一种。另外 1–2 种要人点名（例如书架墙 vs 柱列，和户外土脊差最大）。
- **风险**：若只开户外 + 居民区，两套都偏褐灰，分不清。

### 路 3D — 只改雾 / 亮度 / 污染密度，不改障碍语法

同一套障碍，同一套地表家族，只拧视野雾、亮、teal 密度。

- **后果**：最便宜。
- **和世界观**：弱。氛围在设定里是基体 + 污染，不是天气。
- **和已有管线**：视野和地表都能拧。**标：可能不够。** 验证问题 4 写的是色温、地表、**障碍语言**。本条不改障碍语言，验收大概率失败。
- **风险**：做成「同一张图换滤镜」。

### 路 3E — 一张图拼两种 L1（拼合，不是新色）

一次出击里两块陆地两种已锁记忆，接缝色温跳一下。

- **后果**：单趟更像「强行拼合」。两次出击若都从同一池子拼，**两趟之间**反而更难分清。
- **和世界观**：贴「多块现实拼在一起」。
- **和已有管线**：顶到「同一张图统一一个 frag-*」。接缝要地表能画两种底色相邻。比 3A 更重。
- **风险**：本 Slice 批次爆；验证「两趟能分清」变弱。

**禁止**：继续全员户外灰绿。禁止未论证新色。

```typescript
  massGrammar: string
  join: string
  surfaceMaterial: string
  enabled: boolean
}

// 一次生成抽到的组合（种类 × 污染年龄 × 残破）。成品差异主要靠这里，不靠无限群系。
interface FragmentRoll {
  typeId: string
  contaminationAge: 'new' | 'standard' | 'ancient'
  ruinSeverity: 'intact' | 'broken' | 'eaten'
}
```

面向玩家的名字用术语表地点规则：`[状态/特征] + [原有空间类型]`。本 Slice 默认**不上屏**碎片名；种类先服务生成和地表。要上屏另走界面做法。

**扩展纪律**：加新「曾经是什么」= CSV 新行 + 美术论证。加组合 = 生成器抽 `FragmentRoll`，不新开系统。本 Slice 先接通户外 / 医院 / 地铁 三种 `typeId`。每一次踏入抽齐 `contaminationAge` 与 `ruinSeverity`（规则 24a），禁止永远 `standard` + `broken`。

## 边界情况

- 无换路（主路内部封死后走不到撤离）、第二路短于 1.15× 主路、或较短者开阔格占比不严格更高：坏图，重试整岛。禁止加细墙交差。
- 生成出两块陆地、中间全是虚空：算坏图。修补或重试，直到出生能走到撤离。不把第二块当第二张图。
- 撤离点滚到手写图那个旧格子：丢弃，重抽。
- 撤离点滚到出生旁边：丢弃。两端原则优先于「随机得很」。
- 可走区几乎填满缓冲、外轮廓贴着矩形边：算没通过约束 1，坏图。
- 障碍全是 1–2 格孤岛、没有可指名残块：算没通过约束 2，坏图。
- 连续两次生成抽到同一 `fragmentTypeId`：允许（有限种会撞）。不能靠「禁止连抽」假装种类很多。分清主要靠种类之间差得够大，不靠伪随机保证。
- 手写图夹具与生成器并存：夹具只给对照 / 测试。正式踏入走生成器。
- `tool-system` 的 abyss 若仍读固定图薪柴坐标：会指到空地。接线时必须改读本次 `kindlingNodes`。本文件不写代码。

## 与已有系统的接口

- 从 **净化点场景流转** 接收：踏入裂隙这一下（触发生成）。不读净化点力场形状当裂隙陆地。
- 从 **system-chaos-scavenge-extract** 接收：薪柴分档原则、一个撤离、走近按 E、主干 40–60 秒、换路体验（短暴露 / 长隐蔽）。换路机器判定在本文件规则 21。**坐标不再向固定图要。**
- 从 **system-movement-vision** 接收：OccluderGrid / 出生点契约。向它提供网格与出生。撤离点仍注册 glow source，位置改读生成器。
- 从 **system-enemy-ai** 接收：WalkGrid、路点必须可走、过渡期 `EnemySpawnData.type` ∈ {infiltrator, rewriter}。向它提供本次 `enemySpawns`（过渡期恰好 1 个改写体）。另交墙缘折线 / 簇核 / 走廊包围盒给污染词法。
- 从 **system-growth-tide** 接收：污染物节点契约。向它提供本次节点。工具 abyss 改读本次薪柴坐标，禁止 `import { RIFT_MAP }`。
- 向 **RiftScene** 发送：整份 `GeneratedRiftLayout`。场景不再在 create 时写死 `RIFT_MAP`。
- 向 **ExtractionSystem** 发送：恰好一个 `ExtractionPointDef`。规则仍是走近按 E。
- 向 **Minimap** 发送：本次 tile 与撤离世界坐标。标记形状不新造。
- 向 **VisibilitySystem** 发送：`setExtractionPosition` + glow source。虚空默认不挡视线。
- 向 **procedural-surface** 发送：`fragmentTypeId` / `l1Key` / 材质。禁止继续写死 `frag-outdoor`。
- 不与净化点分配 / 潮汐公式 / 战斗伤害直接交互。

## 对已有系统的影响

- **RiftScene**：改吃生成结果。固定图可留对照夹具。
- **ExtractionSystem**：规则不改；位置来源改生成器。旧规格那一句是否改写 → D2。

- **system-chaos-scavenge-extract**：换路体验句仍在其规则 21；机器判定归属本文件规则 21。已就地补句。
- **净化点 / BoundaryShape**：不受影响。极坐标团不拿来当裂隙陆地的唯一算法。
- **Foundation `MapData.exitPoints[]`**：本 Slice 不实现多出口。类型以后对齐到「一个撤离」。

## 验证标准

- 本 Slice 结束时，人连续踏入至少两次，能回答：
  1. 布局不是上一趟那张（墙、可走区、出生、撤离都是这一次踏入生成的；出击中不变）。
  2. 可走区外轮廓不是规则矩形。
  3. 障碍读得出「这曾是什么」。
  4. 两次氛围能分清（色温、地表、障碍语言，不只是形状）。
- 不验证「选哪个出口」。
- 预期正面：还会为了多拿一点而改路；多出来的是「这是另一块碎片」。
- 如果不 work 的信号：两趟轮廓仍像同一张长方形纸；障碍仍像胡椒粒；两趟都是户外灰绿；撤离还在旧格子；出生走不到撤离；无换路（只有一条出生→撤离的路，或短路并不更暴露）。

## 待验证假设

- [ ] 虚空不挡视线会不会让 C 形陆地隔空对射太狠（技术默认先不挡）。
- [ ] L1 只有 5–10 色差，不换材质和语法时，32px + 视野遮罩下人是否根本分不清。
- [ ] 有限种下连抽同一类型，人会不会觉得「没换图」（分清应靠种类差，不靠禁止连抽）。
- [ ] 主干 40–60 秒在不规则陆地上，会不会变成迷路而不是改路。
- [ ] 规则 21 的 1.15 加长比 + 四邻墙数 ≤ 1 作开阔，人是否读得出「短暴露 / 长隐蔽」，而不是两条几乎一样的路。

## 已锁定

1. 每一次从净化点踏入裂隙、开始这一次出击时生成完整布局。出击未结束前不变。
2. 只换裂隙。净化点不动。
3. 主干走路约 40–60 秒。不强上 80×80。
4. 一个撤离点，走近按 E。位置由生成器给，禁止钉在手写图那个格子。
5. 不要多出口、不要第二种条件、不要捷径口。
6. 可走区外轮廓必须不规则。矩形缓冲 + 虚空掩膜合法。禁止矩形可走区啃缺口充数。
7. 障碍必须有情景。DEC-005 反地牢房间，不反「这段墙曾是房子」。CA 只可风化，不可当唯一结构。1 格宽长条正交织网同样读成迷宫（DEC-058）；形状闸门打剪影，不用 `sight≤14`。
8. 不同出击禁止同一套配色 / 氛围。有限种碎片氛围，优先已锁 L1，不发明新色。
9. 不退回 BSP 方正房间。
10. 策划向字段进 `data/*.csv`。数据从生成器出。
11. 从出生必须能走到撤离。坏图修补 / 重试，不换算法路线。
12. 撤离点坐标由本系统生成。旧撤离规格已就地补句（D2）。
13. 阵亡 = 失败，回净化点。禁止原地按 R 再打这一次。
14. 换路硬保证：规则 21 机器闸门。无换路 = 坏图。禁止为挤路拆形状闸门或连通。
15. 每一次踏入抽 `contaminationAge` × `ruinSeverity`（规则 24a）。禁止永远 `standard` + `broken`。禁止新 hex。
