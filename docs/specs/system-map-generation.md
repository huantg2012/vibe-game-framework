# 系统设计：裂隙地图生成

TL;DR：正式新出发冻结修订7的世界、污染档和空间部署策略，生成较大的不规则实体地形；出生与唯一撤离分离，撤离位置需要探索发现。旧在途按原修订恢复，地图与实体、迷雾、内容和保存身份同源。

## 裂隙空间推广（DEC-197，2026-10-10）

用户已通过 `4459d7c3` 的余烬脊去雾代表世界并授权推广。`rift-spatial-prototype.html` 保留独立原型；正式新出发接入 `r100-spatial-world.ts`，不再读取原型专用表。交付与验证状态见[推广任务](../tasks/rift-spatial-rollout.md)，不能以旧修订6的图库资格替代扩大后的体验验证。

**空间配方。** `data/rift-spatial-{policy,layouts,erosion,anchors,worlds,materials,organizations,authored-groups,authored-erosion}.csv` 单向生成 `r100-spatial-data.ts`。72×56个32px单元构成2304×1792画布；有地边界由互斥侵蚀多边形切出，矩形仅是缓冲区。原v1/v2的20个成群材料世界显式分配错列分隔、断续湾地、交错地段三种宏观组织及镜像；v3/v4的88个作者世界保留完整物件关系组。86个使用冻结的统一1.6倍平面变换，单柱、压纤四角各有独立的整组方案；不得用重复实例抹掉唯一地标、双幕、四壳或交叉纤维的身份。

原角色、材料、形体、构造版本、朝向、高度、厚度和开口保留，作者组所有中心与长宽使用同一个变换，原VOID同变换保留。原先通向外边界的海口仍须通向新外边界；离线 `build-r100-authored-shores.py` 将相连海口与新岸做精确并集后写入显式CSV，运行时不隐式补切口。通用成群布局的材料比例由表冻结，作者组不再次套比例。多处出生候选参与种子变化，只有通用布局保留小幅物件偏移；出生吸附不得超过64px。

真实身体可达席位至少占合法支撑的97%。地形填充比与solid占比是诊断，作者组不能为凑统一占比而被加塞或切断。限定样本还须证明至少两组相距300px的真实实体或内部VOID阻挡：直穿失败，完整20px身体的八向最短绕行至少为直距1.25倍且额外路程至少120px，穿越线两侧各有完整身体通路；同一实体的分足不重复计组。不静默删障碍、填虚空、缩回旧图或减内容。

`WorldProductionRecipeV3.spatialPolicy` 在修订7必需，包含空间几何、材料适配、出生候选、撤离筛选、部署成本与来源hash，并参与包依赖身份。恢复只校验冻结值的合法性与签名，不与今日CSV逐值比较。原生光栅总预算仍为4,194,304像素；生成与表面Worker仍共享各自60秒硬截止。完整身份内最多8个确定性生成候选，耗尽明确拒绝。

**撤离选点约束（DEC-196）：** 寻找唯一撤离点是核心挑战。禁止出生旁配对，也禁止固定对岸、固定最远点、对角或固定两端；出生的变化不能掩盖相对方向恒定。生成器先求完整20px身体的八向可达图，再从全图合法候选按距离层、空间区、位置独立种子抽选。正式冻结的CSV参数为：到48px交互圈内可达格的最短路至少920px且至少达到该出生最大路程的28%，中心直线距离至少560px，28px半边净空；4×3空间分区、3个路程层，远端可入选但不优先。路径口径是8px格点图，不冒充任意连续走法的精确下限。无候选明确拒绝，不降级回出生侧或最远点。最终位置重新参与真实世界部署，并校验没有被局部吸附改位。

这一约束覆盖下文及旧DEC-061的“两端”设计措辞，也撤销上一轮原型“近侧归返”的错误解释；不改变旧保存身份或冻结执行器。原型与正式世界共用该选择器；正常视野不登记未知撤离的穿雾光，小地图在实际探索到之前不公开该点。

## R100：正式选级与 v3 世界（新出发修订7；修订6保留历史资格）

**当前合同与实现状态分开。** I01—I12的原范围已结案；108世界／324等级修订6的启用和内部资格绑定属于旧布局证据，修订7另做推广验证。新增56的原生成、限定成品审阅与双种子固定过程、324正式进入/冷续、342等价及48自然流程已有证据；后续性能74项、资源18混合与8语义反例按用户授权抽查通过。I13长期经济、I14真实弱设备/听感与用户终验保留。启用只改CSV的56个enabled字段，324完整配方和依赖身份前后精确一致。当前逐世界验证与迭代完成状态归 [R100看板](../reading/rift-r100.html)及[I10–I12 QA](../qa/rift-r100-i10-i12.md)。下文 I01/I02 的“仅DEV/未接等级”保留历史范围，不覆盖当前实现。生成版本保持v3，部署修订单独递增；旧v1/v2及无generation记录继续使用原冻结执行器，不在旧身份上重算新内容。

**选择和身份。** 备行选择低/中/重污染，目的世界在该等级已可用的包中随机；不能指定精确世界，不强迫选择重档，不把某件工具作为入场钥匙。一次踏入请求先冻结请求种子、包ID/版本/依赖、等级及等级规则版本、具体材料/形体配置、内容预算及其版本，再后台生成；有限候选和后备仅改变同一冻结合同内部允许的布局，不静默换世界/等级、减敌人或减奖励配额。用户取消未提交准备后可以重新选择；这不允许已经提交的出击、冷续局或保存重试重抽身份。冻结合同/来源不完整、签名不合、未知能力、生成耗尽则明确拒绝，原行装与记录沿库存事务保存。

**v3 部署修订隔离。** 当前新出发使用 `algorithmRevision=7`，配方version=3、内容定义version=2保持；revision 1–6均以独立执行器封存供原身份恢复。修订7增加冻结空间策略，扩大地形并按真实新出撤点重布内容；修订6的完整闭包从 `4459d7c3` 封存，包含作者材料及组织图。修订6增加显式构造版本4及作者缺失地面，不修改既有污染、巡逻或收益合同。修订5增加显式构造版本3及形体配置；原20世界作者定义与外观保持不变，并逐档检查旧新几何及预烤RGBA等价。修订4改变世界材料配方与派生实体构造，保留修订3的污染、敌人与资源合同。修订3只改变重度深薪预算的集中方式，保留修订2的巡逻/操作窗口合同；不得用当前CSV重算旧布局与收益。revision 1找不到巡逻终点时退为静止守卫的问题不能靠读取新算法悄悄改变旧存档。revision 2 在挑选巡逻起点时同时验证可形成真实往返巡路，不允许失败后静默退成 `static`。新初始朝向量化至百万分之一度，减少新修订三角函数跨运行时差异；这不追改旧 v2 或 revision 1 的签名承诺。

**世界的材料与构造（2026-10-05）。** `rift-world-appearance.csv` 是逐世界外观的唯一数据来源，地面、实体表皮、断面、次材料各有暗／中／亮色阶，另给地表组织方式、尺度、强度、覆盖、笔触反差和静区。它编入并冻结在新包内；旧身份不读取当前配色。色阶连续映射既有源图的明暗和细节，表面粗糙度、法线、接触暗部与真实光照仍各自参与；不能用全屏滤色或统一增饱和代替不同材料。普通材料的本色与局部污染绿分开；浅浮雕虽然可走，仍属于其物质来源，不能因碰撞为空被洗成底床颜色。翻找残骸继承同一世界色阶而保留形制、识别边界、动效与未揭晓内容。

`rift-native-worlds.csv` 显式声明 `construction_version`：前三母版保留版本1，17派生世界采用版本2。六材料族分别深化错层断板、分叉长纤维、开口厚壳、窄脊与堆积体、撕裂薄膜、凝胶前沿，实例尺度、高度与摆放仍来自CSV；不能借污染强度阈值暗中切换构造版本。可见面、法向、实体足迹与穿口同源；低／中／重继续消费同一世界身份。较大形体必须重新过完整身体与部署准入，不能继承旧布局的完整玩法证明。 新增世界使用版本3时，必须显式指定`shape_profiles`；形体组织与材料族独立。`native-volume-expansion.ts`提供肋列、错褶、开口多腔及分叶等真实表面，空隙不得有横跨的隐藏封底；solid的可见侧面和20px身体足迹同源，不添加桥下通行或第二层。旧v1/v2禁止夹带shape字段，缺失或未知v3形体直接拒绝。

构造版本4在独立`native-volume-ground.ts`增加宽断床、倒束、夹接岸和撕裂薄膜，配合中尺度solid与可走relief形成空间；旧v1–v3仍走原对应构造。CSV可选`erosion_polygons`用`x:y;x:y;…|…`表示作者缺失地面，编入冻结`nativeDefinition.erosion`。非空仅允许v4，完整替换该世界原默认缺地列表；空单元保持历史默认。每份含1–12个互不相交或接触的简单多边形，每个3–32个有限、地图范围内的不同顶点，面积至少64px²；拒绝自交、重叠、退化和未知字段。编译与恢复使用同一校验，不能按世界ID暗补地形。修订7使用不等切角与错位侧湾，准确并集后仍服从原32顶点和1–12多边形预算；原作者通海口保持。仅完全在作者核心矩形外的封闭残余角地可在离线作者工具中转VOID，逐例记录面积、边界和与核心相交面积0；不能无条件填掉内部孔。缺口仍消费原8px VOID及完整20px身体合同，不新增污染伤害、行走高度、桥下通行或第二层。地图细颈须有完整身体扫掠与部署证据；正常画面须表现真实断边和厚度，不能用可走地面上的黑线冒充裂谷。 岸壁与所属低床的材质坐标域须分开：整图岸线world UV不得参与本体连续源窗的缩放；原生像素尺度不能因拥有地沿而被放大。

I11另有两个显式v4形体：`compressed-wedge`为连体压实短纤及不等撕断端，`porous-break`为外皮包裹的不规则厚芯及局部多孔断面，由`native-volume-organization.ts`实现。小孔有真实斜壁和高于地面的封闭底面，口径小于20px身体；它们不是通道，不更改solid/relief含义。只有这两个profile对完整外皮做按角度加权的顶点法线平滑，55°以上硬折、断面、孔壁、孔底和侵蚀面保留逐面法线；位置、UV、材质、身体和光源点不因此变化。原四个v4形体与旧版本不选该分支。单形体仍受600三角预算约束，真实世界的大小、朝向和路线另做准入。

修订6另显式接受v3 `pleated-tear`与v4 `settled-sheet`／`settled-fan`／`settled-bundle`／`settled-clamp`，不追改原profile。`pleated-tear`在原褶脊上切出有底、斜壁和实际宽度的短裂口；微光只来自裂口内的材质3面，光源点与它同源，外部足迹和通路保持。四种`settled-*`只允许高度≤6px且显式`blocking=0`的浅浮雕：低层外缘逐渐压入原地表，不再围整片添加直立黑色切边；仍保留原撕口和分叉，不新增发光、碰撞或地面。`settled-bundle/clamp`复用原倒束/夹接岸的完整XY三角投影，以投影合并后的外边界控制高度；附接碎端内部的接缝不能成为另一圈下陷边。所有面使用连续局部UV和同一外皮，单体仍受600三角预算约束。它们由CSV逐实例指定，高卷边与实体边界继续使用原明确切面。旧修订5的校验及外层恢复入口均拒绝这些新profile。身体检查通过不等于正常肩灯下的边缘、材质相接与世界辨识已通过，须分别记录。

外观表可空`material_organization`仅接受`short-fibre`、`short-fibre-loose`或`porous-marrow`；空单元完全省略冻结外观中的`materialOrganization`字段，保留既有材料来源和采样。非空由`rift-material-organizations.csv`提供独立地表/实体源图、源区和物理尺度，只替换该世界主材，副材不跟着替换。松散短纤采用独立纤维源图，以可辨交织纤束替代云状颗粒；旧短纤源图不覆盖，已经冻结的身份继续使用原源。每件实例的皮面、断面、松散面各取一个连续源窗，按本地UV范围用同一比例适配两轴，禁止镜像或重复接缝横穿一件实体；窗口选择由冻结种子确定。材质组织不决定颜色、污染等级、碰撞或收益，也不因来源图存在就取得世界美术资格。

非空作者缺地显式写`authoredErosion:true`，可配CSV的`ground_edge_width`（8–24px）。它只归唯一的首个主材v4浅浮雕实例，冻结为`groundEdgeWidth`；该实例必须`relief`且高度≤6px，不能落到solid、次材料、第二实例或默认缺地。几何从同一多边形与实际`matterAt`派生地面侧浅断面，保留非零XY宽度、真实法向和材质，不往VOID内填地，也不修改身体碰撞；坐标不能重复消费实例旋转。缺少权威地形上下文时拒绝生成，不能静默漏画边沿。旧52不加这些字段。

断沿沿岸共享连续肩部，不能在每个8px格中央各立一个尖峰。转角使用同源共享边点，实际斜岸的8px地形阶梯保留；修断面不能把不存在的地面补回，也不能通过全对象高度归一改变原低母面。源世界范围（≤1280×1024）断沿预算为2048三角；修订7扩大地图的完整岸线独立上限为16384三角，仍受4,194,304像素预算约束。超限明确拒绝，不降低8px接缝精度或静默丢边；扩大预算须另验实际运行性能。

新形体的结构侵蚀继续从实际材质3裂面扩散，局部光的位置必须对应同一可见面上的joint。不能让光在无裂面的实体中心悬空出现；三档强弱和扩散仍消费原污染合同。普通断沿、材料裂纹和绿色侵蚀分别有来源，不将整条岸或所有浅浮雕统一染绿。

## R100 工程前置：可取消生成与正式入场（2026-10-03）

正式出击和冷续局的纯地图生成已移到专用 Worker。每次新出击先固定一次随机种子及完整配方，再调用原封存执行器；当前 v1/v2、无 generation 旧身份、签名和正式选池保持原合同。Worker 内的有限候选重排仍属于这份配方的原算法，不是等待失败后重新抽世界。取消、错误或单次 60,000ms 硬截止终止本次 Worker，不自动换种子重试。

**启动失败恢复（2026-10-07）。** 生成与表面准备 Worker 在模块加载完成并收到请求后、执行前，先确认该请求已开始。只有在这份确认前发生的 Worker 错误，允许终止旧 Worker、等待120ms后以同一请求再启动一次；不重新选择世界、种子、等级或行装，也不转移输入缓冲区。两个尝试共享原60秒总截止，取消立即撤销等待及重试。确认后的运行错误、明确计算失败、克隆/传输失败及构造失败均直接报错；第二次启动失败也报错，保留首次失败供诊断。该恢复不提交出击或改写存档，准备成功后仍由原事务提交。正常无错路径和冷续身份维持原合同。

`rift-generation-execute.ts`只依赖纯生成、身份计算及传输合同，不导入 Phaser、存档或会话 singleton。传输结果保留普通对象与 typed array，`walkableMask` 方法不越线程：主线程以原 tileMap 重建 TileGrid，并复核生成身份和签名后才登记有界缓存。Worker 的结果不会自行开始 run、改变库存或写入存档。

正式 `PurificationScene` 等待准备成功后才执行原出发事务。冷续局先读取精确存档快照，按其中身份准备，在没有 await 的同一同步段复核快照并执行 prepared-only 加载；事务及救援规则唯一正文见[统一库存第7节](system-field-inventory.md#7-死亡撤离与中断恢复)。`RiftScene.create` 在后续建场帧再次进入 prepared-only 作用域，防止等待后缓存被逐出；缺失、不匹配或未知身份拒绝入场，不能退回主线程重生成。

**跨运行时限制（R100-P05）。** 精确签名包含浮点朝向；生产金样复核已确认 Node 与 Chromium 的 `Math.atan2` 末位可不同，使旧 v2 签名不一致。当前同浏览器的开发/生产 Worker 结果相同；这不等于跨引擎或浏览器升级的旧档保证。不得修改封存执行器、忽略签名或将一个平台金样直接重写成另一个平台来隐去差异；后续兼容方案需明确原环境和迁移证据。

同步生成函数仍供既有离线检查与明确 DEV 入口使用。`#rift`、pollution-review 等不带正式 recovery 的 DEV 直入，以及自行提供布局的 DEV fixture 保持原开发用途；有正式出发/恢复身份的路径始终走已准备准入，不能借 DEV 例外补救正式缓存 miss。这些入口不新增正式可选世界，也不将 I02 母版翻入生产。

取消、失焦、SHUTDOWN、直接 DESTROY 均撤销等待所有权；请求编号隔离过期消息，Worker 完成或终止后释放监听、计时器与 Worker。直接销毁可能先使 ScenePlugin 失效，因此 Promise 收尾不得恢复、渲染或访问失效场景。

此批实现改变任务执行位置，不证明总生成时长达标。主线程的接收/重建/签名复核、完整状态准入、Host 清单、表面预烤和首次建场仍须分段测量；既有自然样本 p95 超预算结论不因使用 Worker 自动关闭。三级玩法、I03 及世界资格不随本批代码接线宣告完成。

## R100 I02：作者实体试制合同（仅 DEV）

`rift-r100-masters.html` 提供折叠板、纤维结、厚壳腔的局部作者配置。实例参数和三级组合来自 `data/rift-master-scenes.csv`，经生成模块进入作者布局；这不是正式世界包、污染等级选择或 v3 生成身份。现行 v1/v2 封存恢复不消费这些数据。

2026-10-03 用户否决前批三构造后，重做I01的空间/光学基础。几何提供面、法向、局部材质坐标、高度及投影；**不从高度或画面深浅推断战术遮挡**。CSV实例显式声明 `relief`（≤8px贴地可走浮雕）或 `solid`（普通不可走实体）。独立 `erosion` 多边形在8px格中心取样，拥有吞光/缺失地面语义。`matterAt` 只回答地面是否存在，solid下方仍有地面；`roleAt` 只供前景合成。

物理网格由地表→侵蚀→solid独立三角形覆盖合成；relief不擦掉它下面的solid。观察网格只由侵蚀、缺失地面和界外生成；普通景观保留材料明暗，后方仍可被正常视野揭示。攻击网格另含solid，避免观察穿透后出现隔实体挥击。DEV `createCombatGrid` 可明确供应；正式/历史路径默认仍使用原网格，不全局翻转WALL。

完整几何先于20px身体出生、翻找、敌人及撤离部署。保持960×640、原角色、80px/s、原有限视野/混乱/朝向与原XY顶视；没有第二层、钻入悬挑或高度改变地面投影。所有地表、实体和角色统一由原生fog遮蔽；本入口停止调用 `revealProjectedTerrain`，材质自阴影不再乘入“是否可见”。DEV的 `materialLighting` 仅把旧平面ADD灯交给材质着色器，防止重复泛白，不改变任何可见范围和玩法判定。

连续材料基床先生成，压实、剥露、断端细料共用 albedo/normal/height/roughness/AO 成因字段；可走低浮雕贴地处继承基床；不可走实体的低沿必须保留完整材质、侧面明暗及接触暗部，不按高度淡回地面。断面另露内层。静态像素字段预烤，WebGL2逐原生像素接收移动肩灯及局部源光，局部光沿同一8px侵蚀网格逐格检查；不存在的地面永远无受光。角色/敌人前景遮罩只由solid形成，并覆盖实际显示边界（包括挥击），可走relief不裁人物。

**不可通行边界（2026-10-03复修）：** 在正常有限视野内，玩家必须在碰撞前辨认障碍物与地面的交界。`world.ts`把作者`role`显式传成几何`blocking`标记，不按高度猜测可通行性。阻挡折板的低端保留原外足XY占地，在内部增加短陡断面与最低厚度；原浅浮雕和其他两族形体不改。实体采用自身UV组织材质，不让地面纹理原样穿过边界；取消会抹掉面值区别的统一外沿提亮。几何法线负责断面受光，不用发光描边、全图提亮或诊断色替代正常画面的可读性。对照须含由下向上及斜向走近，原碰撞、视野和攻击规则保持。

**实体材质（2026-10-03）：** 三族各有独立地床原图与实体表皮／断层图，六张512²RGBA缓存共6MiB。`solid`才使用实体图；`relief`与地面保留地床图。CSV声明实体图来源、取样区、世界尺度、表皮／断面粗糙度与色值倍率，禁止加载失败后静默换回地面图。完整表皮与断面由实际面类型选取；实体法线以同源几何为主，仅保留少量原微结构，不从图片灰度生成高度或法线。表皮的弱反射消费同一光源和遮挡，粗糙地面保留原响应；污染发光仍由真实侵蚀字段提供。材质参数不改变碰撞、视野或可通行面积。画法与源图归[集中设计](../art/rift-r100-material-separation.md)，原3MiB纹理缓存的资源记录只代表旧版本。

材料绘制来源另由 `rift-master-materials.csv` 声明：原始母片仅供材质色与细节，不拥有地图形状、支撑、侵蚀、法线或实体高度。异步解码与有限缓存不改变地图seed；表面取材按实际世界轴/几何UV及材料事件绑定。图像加载晚到或失败不得覆盖后续已选择场景。资源与绿色侵蚀动效在场景销毁时释放，暂停/失焦不推进闪动、材料声音或玩法时间。结构绿纹只表示材料受污染，不冒称伤害范围；实际接触范围来自原生占漆/占空系统。

三级参数现已在九格DEV母版用于结构、侵蚀、占漆/占空的数量面积及污染增长。`rift-pollution-grades.csv`为数值源，`pollution.ts`把正式Host投到完整32px地面上；只有全部16个8px细格可走的32px格可承载Host，身体碰撞仍用8px。投放复用原生油膜几何与接触格，保留出生、搜取和撤离的20px身体通路及余量；危险范围、视野缩小和生死由正式Host负责。增长曲线由ChaosSystem按模拟时间积分，等级、暂停、抗性和恢复规则见混乱系统spec；未指定等级的历史出击仍用旧增长。尚未接等级收益、准备资格、正式选级或新世界生成身份。九份配置的存在不表示九份合格世界；美术母版通过与正式玩法资格分别记录。制作与实际审核归 [I02](../tasks/rift-r100-i02.md)。

**路线—威胁—收益。** 先固定合法地貌和最终地面敌人身份、形态及路点，再以实际感知模式、初始朝向、转面范围、巡逻和遮挡建立潜在暴露场。不能把“距任一敌人很近”当作必然危险。保守32px内容网格使用8向欧氏路程、禁止穿角，静态身体不作为可走格；实际移动仍由8px支撑和20px身体决定。

## 概述

本系统替换裂隙的手写固定图（`src/scenes/rift-map-data.ts`，约 48×32 矩形边 + 细碎障碍）。净化点不换。

它服务两件事：

1. **寻找退路与贪婪抉择同时成立。** 出生与唯一撤离必须有足够探索间隔，位置不绑定地图两端或固定相对方向；选点遵守上文DEC-196。历史40–60秒主干预算不直接套用扩大后的DEV世界，须由完整搜撤实走重新验证；薪柴风险仍结合到撤离的路程与实际威胁。
2. **每一次踏入是另一块世界碎片。** 可走陆地的外轮廓不能靠「这是一张长方形纸」预判；障碍要读得出「这曾是什么」；两次出击的色温 / 地表 / 障碍语言要能分清。

`vision.md` 把「多种裂隙环境 / 生物群落」写在明确不做；`world.md` 写过 MVP 共用一套视觉主题。**人本 Slice 的指令覆盖这两句**：做有限种碎片氛围，优先已锁 L1，不是无限生物群落，也不是丛林 / 冰原 / 岩浆那种新题材。

宏观方向已锁（DEC-005 / DEC-ARCH-003）：不规则碎片 + 有机内部 + 窄连接。**不退回 BSP 方正房间。** 内部怎么填、外轮廓怎么来，下面给多条路，禁止一棵树吊死。架构里的 Voronoi+CA 是要认真验证的技术路线，不是本文件已经定案的唯一实现。

本 Slice **不**做撤离多样性（多出口、第二种条件、捷径口）。提示仍是「[E] 撤离」。小地图继续标**一个**撤离点。不新开 HUD、不新造标记形状。

## 技术事实（实现层可果断）

### 不规则指什么

不规则 = **玩家看见的可走陆地外轮廓**，不是「数组变成多边形」。

- 引擎里 tile 数组几乎总是矩形缓冲。矩形缓冲合法。
- 缓冲里、可走陆地之外的格子当作**虚空 / 不可走**。合法。
- **禁止**用「数组还是矩形」当借口，交出一张矩形可走区。
- **禁止**先铺满矩形可走区，再在边上啃几个缺口充数。

玩家看到的应该是：一块（或几块拼在一起的）陆地漂在虚空里，边缘弯、缺、错位。不要再用一圈矩形墙当地图外框。墙只出现在「这段墙曾是什么」的情景障碍里。

### 虚空、墙、视线（本条定技术默认）

| 格子 | 可走 | 玩家看见 | 挡视线 |
| ---- | ---- | -------- | ------ |
| 地板 | 是 | 地表（L1 底色 + 材质残影 + L2 污染） | 否 |
| 墙 / 障碍 | 否 | 可读残块（砖 / 木 / 土 / 金属仍可辨） | 是 |
| 虚空 | 否 | void-black，不是墙皮 | **是**（DEC-106） |

虚空挡视线（DEC-106 虚空吞光，2026-08-29 人拍板，翻转 Slice 6 的「不挡」默认）：射线打进虚空即停，手电光场不再穿过地图边界，虚空海湾两侧不可互见（玩家 / 敌人对称，同一套 `hasLineOfSight`）。对岸本来就在虚空之后，照旧看不见。虚空仍不是墙：不画墙皮、不参与墙体情景语法。

`TileType` 有墙 / 地板 / 裂口 / 虚空。虚空不可走、挡视线（DEC-106），着色走 `void-black`，禁止铺成地板。`src/types/game-types.ts` 里 Foundation 草案 `MapData.exitPoints: Position[]` 是复数出口——**本 Slice 不实现那份草案的多出口**。生成器输出以本节契约为准。

### 缓冲多大

玩家移速 80 px/s，tile 32 px → 约 2.5 格/秒。主干 40–60 秒 ≈ **100–150 格**的走路路径，不是 100–150 格的矩形边长。

现图 48×32 从出生到撤离直线大约 10 秒，不够。加长靠**弯路 + 陆地拉长**，不靠强上 80×80。`GAME_CONSTANTS.MAP` 的 80×80 和 Voronoi/CA 数字是架构占位，**不是本文件已锁算法**。人锁方向后再改常量。

建议缓冲落在现图同级到略长（大约长边 48–64 格），以主干秒数为准。可走陆地**不得填满**这个矩形。

### 生成器必须交出的数据

```typescript
/** 一次出击的完整裂隙布局。出击未结束前不变。 */
interface GeneratedRiftLayout {
  seed: number
  fragmentTypeId: string
  // 矩形 tile 缓冲。界外虚空在缓冲内，不是把数组做成多边形。
  tileMap: TileMapData
  walkableMask: WalkableMask
  spawnPoint: Vector2
  extractionPoint: ExtractionPointDef   // 恰好一个
  kindlingNodes: readonly KindlingNodeDef[]
  contaminantNodes: readonly ContaminantNodeDef[]
  enemySpawns: readonly EnemySpawnData[]
  landmarks: readonly LandmarkDef[]
  contaminationPins: ContaminationPins
  contaminationDraw: SortieDraw   // 句法抽卡结果，一次出击一份。不是地表烤漆风格枚举
}

interface WalkableMask {
  cols: number
  rows: number
  isWalkable(col: number, row: number): boolean
}
```

`ExtractionPointDef` / `KindlingNodeDef` / `EnemySpawnData` / `LandmarkDef` 沿用 `src/types/map-types.ts`。本系统**新增**的是：种子、碎片类型 id、可走掩膜、虚空格、以及「这些坐标从生成器来」。出击甲的 `EnemySpawnData.form` 与整份 `contaminationDraw` 也由本生成器交出（I3-A / I3-D）：同一份抽卡喂巡逻与宿主，种子 `mix32(layout.seed, 'lexicon')`，禁止吃 `placeOnIsland` 的 rng。`contaminationDraw` 的类型是句法 `SortieDraw`，**不是** `RiftSurfacePainter` 那个烤漆风格参数（同名、不同字段；禁止合成联合类型）。

地标（`LandmarkDef`）是地板上的视觉锚，**不是**情景障碍本身。情景障碍必须写进墙 / 不可走格，让玩家绕、让视线断。只贴纸不够。

### 数据从生成器出

RiftScene、撤离、小地图、视野、地表、工具，都读这一次的 `GeneratedRiftLayout`。禁止再各自假定手写图上的固定格子。手写图可留作对照夹具，不是运行时真相。

## 规则

### G — 何时生成、何时不变

1. 当玩家**从净化点踏入裂隙、开始这一次出击**时，生成完整 `GeneratedRiftLayout`。同一次出击内不重跑。
2. 当玩家撤离或死亡、回到净化点之后，本次布局作废。下一次踏入再生成。
3. 「按 R」一律回净化点（DEC-056）。阵亡不是原地再打这一次。C4 已改 `RunController.restart()`。
4. 同一种子必须得到同一张图（地表噪声已是确定性的，布局也必须是）。

### C — 连通与坏图（FATAL）

连通性是地图生成的硬约束，先于审美、氛围、装饰。坏连通 = 坏图，禁止当成品或预览样例交出。

5. 从出生格 flood-fill，必须能走到撤离格。走不到 = 坏图。
5a. 陆地掩膜本身必须是一块四连通（外轮廓只留最大连通块）。禁止一次出击交出互不相连的多岛。
5b. 墙上完之后，全部可走地板仍必须是一块四连通。墙把地切开 = 坏图。先就地挖通，再重试。
5c. 装饰 / 植被 / 残骸 / 光影 / 粒子 / 波动 **不得**再拆连通：只画在已连通的可走格上，或做成不挡路的漆。
5d. 预览草案与正式生成器走同一条连通闸门。看起来丰富但走不通，不合格。
6. 薪柴、污染物节点、巡逻每一个路点，必须可走，且从出生可达。
7. 坏图：先修补（挖通一条合法通道、把点挪到最近可走格），再重试新种子。修补与重试都留在**人锁定的那条算法路线里**。禁止失败就换一家算法。
8. 重试有上限。到顶仍坏：开发期大声失败；发行期最后一次强制挖通出生→撤离，并记一条警告。不换路线。

### L — 陆地与外轮廓

9. 可走陆地的外轮廓必须不规则。验收看玩家看见的陆地边缘，不看数组是不是矩形。
10. 禁止：矩形可走区 + 边上几个缺口。禁止：四边一圈墙当外框。
11. 外轮廓算法：**已收口为生长 + 腐蚀，取最大连通块**（路 1C）。实现：`src/generation/outline-mask.ts`。坏图（填满缓冲、啃边矩形、贴齐四边）丢弃重试。相交矩形并集不是本批实现。

### O — 障碍

12. 障碍是嵌进岛的体量，不是岛心道具，也不是胡椒粒。人要能指出走法（这边能绕、这边能穿）。覆盖浅时可能还认得「曾是什么」；覆盖到 unnamed 时指不出名字也成立，不算失败。
13. DEC-005 反的是「方正房间 + 走廊像地牢游戏」，**不是**「这段墙曾是一栋房子」。残缺体量允许。闭合房间 + 门廊，禁止。禁止完整器物剪影（整节车厢、完整月台色带）。**1 格宽长条正交织网同样读成迷宫**（DEC-058）：真实长墙可以有，但不能用很多根同样细的条拼接。障碍要读成体积残骸，不要读成地牢平面图。
14. 细胞自动机（CA）可以当风化（咬边、穿洞、让残块显老），**不能当唯一结构来源**。禁止只靠 CA 胡椒粒墙交差。
15. 现图已有 L/T/C 和小簇（2–12 格），人仍读成细碎随机。所以「把簇稍微加大」本身不够。见约束 2。把簇改成贯穿细篱笆也不够——那是迷宫，不是情景。
16. 障碍策略：**方向 1 厚短残块**（DEC-058，2026-08-18 人锁）。走法骨架与残片身份分开。预览栈：`structure-grammars.ts` + `cover.ts` + `stealth-density.ts` + 配方。`masses.ts` 的围院语言不进这条栈。诊所/地铁也走短板/坨，全图最多一把 L。墙围死的地就地挖开。CA 不当结构。
16a. 预览 **不得**用「最长轴对齐空直线 ≤14」当生产循环或 FATAL。形状闸门：1 宽直行 ≤6；非木墙至少一半属 2 厚/坨；平行窄槽 0；无三向 1 宽巷；至少一块 6×6 空地且边缘有厚掩护；禁 2–4 宽且长 >8 的巷；墙占比 ≤18% 是顶。连通仍 FATAL。
16b. 密度已锁（DEC-061）：DEC-060 结合层进生产岛。身份墙之后按可藏距离补厚短件。人认后空地再收约 20%（种子 101：墙约 18% 顶、空矩形 72–99、掩护 P90 5–7）。P90 到厚掩护 ≤8；距掩护 >7 的四连通块 ≤48 是尺不是 48 格硬闸门。禁止用空直线工厂或空矩形 48 倒逼篱笆。沿缘锚只向内补，岛心空。褶脊 / L / 双梁 / 宅基 / 残体 / 嵌板才允许尽端开口的 2 厚隔断。

### P — 布点（一个撤离，不要多样性）

17. 出生与唯一撤离保持足够探索间隔，按DEC-196从合法可达位置抽选。既不固定近侧归返，也不固定两端、对岸或最远点；玩家必须在探索中发现退路。
18. 恰好一个撤离点。走近按 E。触发半径沿用现规则。位置由生成器给。禁止落在手写图那个固定格上（现图大约是偏上居中的 `X`）。
19. 撤离格本身不在任何巡逻的常驻视野内。通往撤离的最后一段由 1 个巡逻覆盖（最后一道关）。**这道关必须是渗透体**（`type: 'infiltrator'`）。改写体不站撤离门。
20. 薪柴分档与数量沿用 `system-chaos-scavenge-extract`：safe 3 / contested 3 / deep 2。坐标改由生成器按「离撤离路程 × 巡逻覆盖」放置，不再写死 ASCII。
21. **换路是硬保证**（DEC-064，覆盖 DEC-061 / DEC-062 的软目标）。仍是**一个**撤离点。不是两个撤离点，不是捷径口。`npm run check:layout`：无换路 = **坏图（FATAL）**，不是 info。失败则**重试整岛**（换种子、同一条算法）。禁止为挤路加细墙、破坏规则 16a/16b、或让墙后地板四连通分量 ≠ 1。连通仍 FATAL。规则 8 的发行期强制挖通只救连通，不救换路。

    机器判定（按序；任一步失败 = 坏图）：

    1. **主路** = 出生格 → 唯一撤离格的四连通最短路。长度 = **格子步数**（BFS 移动次数 = 路径格数 − 1）。走不到已由规则 5 判坏。
    2. **第二路存在**：把主路内部格（路径上除出生、撤离外的每一格）**临时当作墙**之后，出生仍须能四连通走到撤离。走不到 = 无换路。临时墙只用于本判定，成品图上这些格仍可走。
    3. **第二路** = 上述临时墙上，出生→撤离的四连通最短路。其格子步数必须 **≥ 1.15 × 主路格子步数**。不够长 = 坏图。
    4. **开阔格**：可走格满足「四邻（上右下左）墙格数 ≤ 1」**或**「到最近墙格的四连通格距（曼哈顿，格为单位）≥ 2」。墙 = 墙格，不含虚空。四连通距墙 ≥ 2 蕴含四邻墙数 = 0，故本 OR 的有效判定是 **四邻墙数 ≤ 1**（贴着一面墙走仍算开阔；夹在两面墙之间的 1 宽缝不算）。
    5. 一条路的**开阔格占比** = 该路路径格中开阔格数 / 该路路径格数（含出生与撤离）。两条路里**较短者**（格子步数更小；若步数并列则主路视为较短）必须开阔格占比**严格更高**（= 更暴露）。较短者不够暴露 = 坏图。
    6. 以上任一步失败：丢弃本岛，重试整岛。禁止用加细墙、拆形状闸门、切开地板连通来「做出第二条路」。
22. 巡逻（过渡期，DEC-077 / I3-A）：仍是 3–4 个占地可追击，其中**恰好 1 个** `type: 'rewriter'`（听觉主轴仍由改写体占名额）。不要用句法甲配额 2–3 去砍巡逻人数；为**每条** spawn 配一个 `form`。`type` 由该 form 的感知词素派生（`sense_hear` → rewriter，否则 infiltrator）。撤离门仍是视锥甲：form 锁有机残影 + 渗透 + 视锥，写入 `spawn.form`，不是工厂按 role 三元覆盖。乙 / 丙 / 丁不进 `enemySpawns`。一次出击一份 `contaminationDraw`（种子独立 fork `mix32(layout.seed, 'lexicon')`）；宿主只物化这份抽卡里的非甲 form，禁止再调 `drawSortie`。钉层空的乙↔丁回退仍在。钉层（墙缘折线、占漆地板格、走廊包围盒）必须交出。路点可走、从出生可达。全图听噪 === 1 的最终迁移未做。契约细节在 `system-enemy-ai`「生成器契约」与句法 spec 实现规格。
23. 污染物节点放在可走格，从出生可达。数量沿用现图量级（现为 3），本 Slice 不新开节点规则。

### A — 氛围

## 约束 1 — 不规则外轮廓（至少三条路，未定案）

要解决的问题：整张图是规则矩形，四边一圈墙。玩家对「往哪探」有稳定预期。

下面每条都能做出可走掩膜。人给的「相交矩形并集」必须在列表里，且旁边至少两条完全不同的路。

### 路 1A — 若干大幅相交矩形的并集

把 3–6 个大矩形错开叠在一起，并集 = 陆地，其余 = 虚空。

- **后果**：面积好控，主干秒数好调；轮廓在错角处拐弯。矩形少、又轴对齐时，玩家仍会读成「几块纸贴在一起」，不规则偏弱。
- **和世界观**：拼合说得通（被撕开的空间块）。矩形太多会顶到「不遵循常规建筑逻辑」。
- **和已有管线**：最好栅格化。和净化点极坐标团不是同一种形状语言——裂隙不该看起来像另一颗力场泡。
- **风险**：实现图省事变成「两个矩形咬一口」，等于禁止项。

### 路 1B — 宏观碎片并集，外围丢掉，外轮廓 = 拼合锯齿

先切 4–6 块不规则碎片（Voronoi 是做法之一，不是唯一），丢掉外围，留下的并集当陆地。外轮廓是碎片互相咬出来的锯齿。

- **后果**：最贴「异时空碎片被强行拼合」。容易出细刺、夹缝、空洞，要补最小宽度。
- **和世界观**：最贴 `world.md` 空间结构。
- **和已有管线**：和 DEC-005 / DEC-ARCH-003 的宏观层同方向。**本条不把 Voronoi 写成已定案。** 碎片也可以用斑块、印章、隐式场再切。
- **风险**：把约束 1 收成「做完 Voronoi 就等于不规则」——内部填满后外框仍可能是圆滚滚的一团。

### 路 1C — 从种子生长再腐蚀，取最大连通块

从种子蔓延，再腐蚀，最大连通块当陆地。

- **后果**：轮廓很有机，几乎不可能读成矩形。主干长度和「两端」不好控；容易长成一块洞穴岛，不像世界残片。
- **和世界观**：偏「有机洞穴」，弱于「被撕开的现实」。
- **和已有管线**：掩膜好做。情景障碍很难挂——没有「这是一条街」的骨架。DEC-ARCH-003 写明不设纯 CA 降级；若本条当**唯一**外轮廓，会和架构顶牛（人要求多条路，所以列在这里，不锁）。
- **风险**：和约束 2 抢：结构全靠生长，障碍只能再撒胡椒粒。

### 路 1D — 隐式曲面 / 极坐标压力团

用极径 + 噪声（或几个斑块的隐式场）画出陆地，再栅格化。净化点 `BoundaryShape` 只作技术参考，不照搬。

- **后果**：一块有叶瓣的团。不规则有，但常常是「一颗歪豆子」，不是拼合。
- **和世界观**：裂隙是伤口，不是门，也不是净化点那层膜。整张裂隙长得像净化点泡，两个空间会糊成一种东西。
- **和已有管线**：极坐标代码可参考，语义不能抄（净化点会随潮汐挤；裂隙陆地出击中不变）。
- **风险**：人一眼看成「又一个力场边界」。

### 路 1E — 预制轮廓章，旋转缩放当掩膜

手绘几枚破碎外轮廓，生成时旋转、缩放、可少量叠印，印成掩膜。

- **后果**：不规则有作者保证。章少了会被认出来（「又是那三块岛」）。
- **和世界观**：章可以画成撕页、碎玻璃，贴设定。
- **和已有管线**：章是内容资产，不是色表。不要把轮廓点写进污染物 CSV。种类少时，两次出击轮廓会撞车，和「布局不是上一趟」抢验证。
- **风险**：本 Slice 来不及画够章。

**禁止充数**：矩形可走区啃缺口。无论上面走哪条，这条都不算过关。

## 约束 2 — 障碍要有情景（至少三条路，未定案）

要解决的问题：人看见障碍，读成细碎随机，读不出「我在探索一块世界碎片」。

DEC-005 反的是地牢房间，不是「这段墙曾是房子」。CA 可以风化，不能当唯一结构。

### 路 2A — 先放 2–3 个可读地标，再填缝

先落下「一段街 / 一个院子 / 一道脊」这种人能叫出名的东西，缝再用小结构补。

- **后果**：玩家有东西可指。缝若仍用 CA 胡椒粒，地标一走过又碎。
- **和世界观**：贴「原有事物残影」。
- **和已有管线**：现有 `LandmarkDef`（水洼 / 刮痕 / 碎石贴花）**不挡路、不断视线**，不能当本条的实现。本条的地标必须是墙格组成的残块。
- **风险**：只完成贴花，墙还是细碎的。

### 路 2B — 按碎片类型换障碍语法

图书馆 / 医院 / 地铁 / 居民区 / 户外是表上的身份样本，不是五种换皮。墙形跟 `massGrammar` 走，走法骨架共用。

- **后果**：最能读出「这曾是什么」。和约束 3 绑在一起：氛围种类一少，语法种类也少。
- **和世界观**：基体不同、污染同一套青绿（有主占漆与敌人 ramp 同源；氛围簇已下线）。最贴设定。
- **和已有管线**：`procedural-surface` 必须吃碎片类型，不能写死 `frag-outdoor`。每种语法要 art A1 写墙 / 地表怎么画。五种全做，本 Slice 批次会爆。
- **风险**：语法只换贴图、不换形状，人仍读成同一堆石头。

### 路 2C — 提高最小特征尺度

禁止大量 1–2 格孤岛。残块至少到人能看成「一段东西」的长度（现图 2–12 格仍失败，下限要明显高于「一小簇」）。

- **后果**：画面干净一点。**单独不够**——现图已经不是 1 格胡椒粒，人照样读成随机。
- **和世界观**：中性。大石头不必曾是房子。
- **和已有管线**：好做，和任何一条都能叠。
- **风险**：把「加大」当成交差，约束 2 仍失败。

### 路 2D — 预制残块印章 + 污染侵蚀

先盖「未闭合的房基 / 半截站台 / 一排架子」印章，再用污染咬边、穿洞。印章不是闭合房间，没有门廊。

- **后果**：结构可读，风化后仍像残留。印章少了会重复。
- **和世界观**：就是「这段墙曾是房子」。只要不封成房间+走廊，就不犯 DEC-005。
- **和已有管线**：Qud 用 WFC 做历史建筑——可参考「先结构后侵蚀」，**不把 WFC 写成必选**（架构已标难调）。印章是内容，不是色表。
- **风险**：印章一封四壁、留门，就会退回地牢。

**CA 的位置**：上面任何一条都可以用 CA 咬边。CA 不能当本约束的唯一答案。

## 约束 3 — 不同出击，不同氛围（至少三条路，未定案）

要解决的问题：现在每次都是户外灰绿。人要求两次踏入能分清是另一块碎片。

已锁五套 L1：旧图书馆 / 医院实验室 / 地铁工业 / 居民区 / 户外。本 Slice 不发明新色。

`art-direction` 有一句内部张力：「同一张图统一一个 frag-*」和「碎片接缝两种底色相邻」同时存在。下面把「一张图一种记忆」和「一张图拼两种」分开写，等人拍。

### 路 3A — 每一次踏入抽一种已锁 L1，地表 + 障碍语法跟着变

五套记忆都进策划表，`enabled` 控制谁参与抽取。抽中谁，整张图的底色、材质残影、障碍语法跟谁走。

- **后果**：最能回答验证问题 4。A1 和障碍语法要按套数做。五套全开，本 Slice 重。
- **和世界观**：覆盖「MVP 一套主题」；仍是有限种，不是无限群系。
- **和已有管线**：优先。色板已锁，地表管线已在，只是写死户外。必须参数化，读 CSV，不手写第二套色表。
- **风险**：只换 L1 六位数、不换材质和语法——5–10 的色差在 32px + 视野遮罩下可能消失（art-direction 自己标过这个险）。

### 路 3B — 同一种记忆再叠污染年龄 / 浓度

同一套 L1，再叠偏蓝新生 / 正 teal / 暖绿古老（对应已锁轻 / 标准 / 重）。

- **后果**：同一种地方，新旧不同。两次都是户外时，人可能读成「同一个公园，故障多一点」，不是「另一块世界碎片」。
- **和世界观**：浓度梯度已锁，合法。单独不够撑「不同世界的碎片」。
- **和已有管线**：地表已有 teal 渗参数，最好做。适合当 3A 或 3C 的叠加，不适合当唯一手段。
- **风险**：验收时被当成「还是那套绿」。

### 路 3C — 本 Slice 只做 2–3 种，其余留给后面

策划表仍写五套，`enabled` 只开 2–3。优先开**语法差得最开**的，不要开两套都是灰绿近亲。

- **后果**：本 Slice 做完的概率高。验证「能分清」用 2–3 种就够。其余记忆留给后面的 A1。
- **和世界观**：仍是有限种。
- **和已有管线**：户外已经在跑，等于白送一种。另外 1–2 种要人点名（例如书架墙 vs 柱列，和户外土脊差最大）。
- **风险**：若只开户外 + 居民区，两套都偏褐灰，分不清。

### 路 3D — 只改雾 / 亮度 / 污染密度，不改障碍语法

同一套障碍，同一套地表家族，只拧视野雾、亮、teal 密度。

- **后果**：最便宜。
- **和世界观**：弱。氛围在设定里是基体 + 污染，不是天气。
- **和已有管线**：视野和地表都能拧。**标：可能不够。** 验证问题 4 写的是色温、地表、**障碍语言**。本条不改障碍语言，验收大概率失败。
- **风险**：做成「同一张图换滤镜」。

### 路 3E — 一张图拼两种 L1（拼合，不是新色）

一次出击里两块陆地两种已锁记忆，接缝色温跳一下。

- **后果**：单趟更像「强行拼合」。两次出击若都从同一池子拼，**两趟之间**反而更难分清。
- **和世界观**：贴「多块现实拼在一起」。
- **和已有管线**：顶到「同一张图统一一个 frag-*」。接缝要地表能画两种底色相邻。比 3A 更重。
- **风险**：本 Slice 批次爆；验证「两趟能分清」变弱。

**禁止**：继续全员户外灰绿。禁止未论证新色。

## Schema（内容条目）

```typescript
// data/rift-fragments.csv → src/generated/
// 开放表，不是 5 个 id 的死枚举。新行可以加；新色必须先论证进 art-direction / palette。

interface FragmentTypeDef {
  id: string
  displayName: string
  coverage: string
  massGrammar: string
  jogPeriod: number
  jogAmp: number
  gapCount: number
  gapPlacement: string
  turnCount: number
  turnCorner: string
  capKind: string
  facingPolicy: string
  join: string
  surfaceMaterial: string
  stainKey: string
  scratchAngle: string
  scratchDispersion: number
  enabled: boolean
}

// 一次生成抽到的组合（种类 × 污染年龄 × 残破）。成品差异主要靠这里，不靠无限群系。
interface FragmentRoll {
  typeId: string
  contaminationAge: 'new' | 'standard' | 'ancient'
  ruinSeverity: 'intact' | 'broken' | 'eaten'
}
```

面向玩家的名字用术语表地点规则：`[状态/特征] + [原有空间类型]`。本 Slice 默认**不上屏**碎片名；种类先服务生成和地表。要上屏另走界面做法。

**策划表列说明（DEC-094；禁止再误判）：**

| 列 | 现行消费 | 处置 |
| -- | -------- | ---- |
| `surface_material` | **只选出击脚步音**（`rift-scene.ts` 的 `stepKey`）。烤地不读。禁止再读成「木地板看起来像木头」 | **保留。** `plaster` 未进脚步映射；启用居民区公寓那一行时补 `stepKey`，不补绘制、不另开迭代 |
| `jog_period` / `jog_amp` / `gap_count` / `gap_placement` / `turn_count` / `turn_corner` / `cap_kind` / `facing_policy` | 质量语法向量数字（I6-Q 已放开取值；I6-F 按身份配方填入）。`mass_grammar` 仍是最近预设名 | **活列。** 禁止靠已删列或第一层落格表达身份 |
| `scratch_dispersion` | 划痕角离散度（弧度）。`scratch_angle` 仍是 free / orthogonal / longitudinal 策略 | **活列。** 本批不改烤地划痕接线 |
| `wall_body_key` / `wall_rim_key` | 已删。墙读 `wall_bv × wall_bias_*` | **已删**，不接线 |
| `l1_key` / `source_domain` | 已删 | **已删**，不接线 |

**扩展纪律**：加新「曾经是什么」= 策划表新行 + 美术论证。加组合 = 生成器抽 `FragmentRoll`，不新开系统。Slice 6 先接通户外 / 医院 / 地铁三种。**DEC-090 / I6-G：** 迭代 6 已把旧图书馆纳入可生成范围（四张一起标定）。`data/rift-fragments.csv` 旧图书馆一行 `enabled` 已为真，生产路径。居民区公寓保持假（抽卡四张）。~~簇状质量语法未实现~~ **DEC-094：** 簇是参数点，禁止再当独立待开。抽卡已启用行等权；三张变四张后旧世界从约三分之一降到四分之一，不加权重列。每一次踏入抽齐污染年龄与残破度（规则 24a），禁止永远标准 + 残破。遇到「档位不够 / 只有 N 种」先看那个 N 是不是一段手写 if。

## 边界情况

- 无换路（主路内部封死后走不到撤离）、第二路短于 1.15× 主路、或较短者开阔格占比不严格更高：坏图，重试整岛。禁止加细墙交差。
- 生成出两块陆地、中间全是虚空：算坏图。修补或重试，直到出生能走到撤离。不把第二块当第二张图。
- 撤离点滚到手写图那个旧格子：丢弃，重抽。
- 撤离点落在出生附近或缺乏实际探索间隔：丢弃。按DEC-196从其他合法位置抽选，不以固定两端、对岸或最远点补救；无候选明确失败。
- 可走区几乎填满缓冲、外轮廓贴着矩形边：算没通过约束 1，坏图。
- 障碍全是 1–2 格孤岛、没有可指名残块：算没通过约束 2，坏图。
- 连续两次生成抽到同一 `fragmentTypeId`：允许（有限种会撞）。不能靠「禁止连抽」假装种类很多。分清主要靠种类之间差得够大，不靠伪随机保证。
- 手写图夹具与生成器并存：夹具只给对照 / 测试。正式踏入走生成器。
- `tool-system` 的 abyss 若仍读固定图薪柴坐标：会指到空地。接线时必须改读本次 `kindlingNodes`。本文件不写代码。

## 验证标准

- 本 Slice 结束时，人连续踏入至少两次，能回答：
  1. 布局不是上一趟那张（墙、可走区、出生、撤离都是这一次踏入生成的；出击中不变）。
  2. 可走区外轮廓不是规则矩形。
  3. 障碍读得出「这曾是什么」。
  4. 两次氛围能分清（色温、地表、障碍语言，不只是形状）。
- 不验证「选哪个出口」。
- 预期正面：还会为了多拿一点而改路；多出来的是「这是另一块碎片」。
- 如果不 work 的信号：两趟轮廓仍像同一张长方形纸；障碍仍像胡椒粒；两趟都是户外灰绿；撤离还在旧格子；出生走不到撤离；无换路（只有一条出生→撤离的路，或短路并不更暴露）。

## 已锁定

1. 每一次从净化点踏入裂隙、开始这一次出击时生成完整布局。出击未结束前不变。
2. 只换裂隙。净化点不动。
3. 主干走路约 40–60 秒。不强上 80×80。
4. 一个撤离点，走近按 E。位置由生成器给，禁止钉在手写图那个格子。
5. 不要多出口、不要第二种条件、不要捷径口。
6. 可走区外轮廓必须不规则。矩形缓冲 + 虚空掩膜合法。禁止矩形可走区啃缺口充数。
7. 障碍必须有情景。DEC-005 反地牢房间，不反「这段墙曾是房子」。CA 只可风化，不可当唯一结构。1 格宽长条正交织网同样读成迷宫（DEC-058）；形状闸门打剪影，不用 `sight≤14`。
8. 不同出击禁止同一套配色 / 氛围。有限种碎片氛围，优先已锁 L1，不发明新色。
9. 不退回 BSP 方正房间。
10. 策划向字段进 `data/*.csv`。数据从生成器出。
11. 从出生必须能走到撤离。坏图修补 / 重试，不换算法路线。
12. 撤离点坐标由本系统生成。旧撤离规格已就地补句（D2）。

14. 换路硬保证：规则 21 机器闸门。无换路 = 坏图。禁止为挤路拆形状闸门或连通。
15. 每一次踏入抽 `contaminationAge` × `ruinSeverity`（规则 24a）。禁止永远 `standard` + `broken`。禁止新 hex。
