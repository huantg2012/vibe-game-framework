### 自动供给的量纲与风险判定

**已批准的构造纠正（实施中）：** 生成和最终验收共用实际20px身体支持／扫掠通行契约。外岸在放置前编译冻结，孔的断缘也预先编译；规划和输出消费同一轮廓。出生点到全部合法身体中心全连通是初始地面及每次接受对象的硬前提，不能用空白／覆盖得分抵消，也不能将“到任意空洞的距离”当作全图连通证明。母体按真实几何参与通路与局部覆盖规划，不将其整个包围区域都视为不可布置。保持矩形拼合的开放宽地、自由断缘、G1–G4阈值及约2H:1S；不得从成图删除孤立区域或删内容获得通过。是否接正式入口以任务证据为准。

源模型的完整部件集也服从初始连通性条件；部件间形成身体可站但进不去的夹缝时，以共享几何间距规则安排部件及其附属relief，保留各模型形状和材质。最终位置／缩放随输入冻结，整体预算包含调整后的构造，不能先留通路再用缩放将其挤闭。

当前r14采用初排联合赋值（`joint-coverage-assignment-v1`）：三角覆盖格只提供完整2H/1S单元的初始职责与候选域；全部实际身体采样点都参与空白覆盖义务，不以源距离均值代替证明。源地标／岸线尚未覆盖的点由某个真实孔／实体候选承担，每次初排前向检查其余合法候选是否仍能覆盖全部需求；只能由一个对象承担的点直接收缩该对象候选域。每次选择维持实际身体／扫掠全连通，完整赋值同时检查物理空白和宽域连通，失败时在初排内回退；持续深空白跨度与孔接近代理保留诊断，最终准入使用实际G2遮蔽路径；不再在完成的摆放上执行单物件修补循环。

持续深空白失败以整个连通空白区域定位可能改变它的对象，不能只取中点；全局宽域比例／连通仍按完整赋值判断。局部失败回退是有界搜索中的启发式，不是存在性证明；未找到方案只拒绝该有限提案，不宣称几何要求无解。原2048站位／2048放置状态、每层8分支及60秒请求截止不增加，距离缓存最多16MiB；外岸、实际轮廓与原碰撞条件保持。当前固定低档样本仍有持续深空白／备用案覆盖通路冲突，未获正式资格。

唯一数值源为 `data/rift-auto-supply-policy.csv`。下列值为当前工程初值，尚不表示长期经济平衡通过：

- `A` 是实际可达的20px身体中心域面积，`D95` 是从出生到该域的通行距离95分位。初始节点预算 `N = max(档位最低内容数, ceil(A / 每节点面积 + D95 / 路程间隔))`。面积与距离分别反映搜索范围和绕行成本；相同面积的曲折图因此可以获得更多机会。
- 低／中／重每节点面积为100000／140000／180000px²，路程间隔320／400／480px。低档至少两个safe必燃料，中重当前各一个；不允许必要燃料被武器替代。这里的“节点”同时包含薪柴和污染物，配额比例来自共享档位内容，不是worldId。
- 覆盖基于实际可见48px翻找站位的多源身体最短路，最大距离分别480／640／768px，95分位320／448／512px。优先照顾未覆盖区域，32总节点内仍不满足则明确拒绝。预先将所有合法候选作为源计算理论下界，避免在无合法资源点的区域反复加数量。
- 既有 `extraTravel` 衡量偏离出撤最短路的额外成本，但长主路后段本身也有暴露成本。新协议的contested资格因此为“满足原额外路程范围，**或**从出生接近距离≥冻结阈值480px”，并继续满足实际交互站位、最大接近路程、污染地面净距与巡逻窗口。safe／deep规则不因这项修正放宽，早期必燃料仍须位于合法safe域。
- 共享导航图建立一次，覆盖增量更新；完成真实内容／巡逻部署后独立重算最终覆盖。每图最多131072身体格、64000000导航边操作，超限有诊断，不以删资源或漏测结束。新增数量不提高单堆价值，也不增加敌人数。

### 自动构造的尺度与验收口径

共享初值按低／中／重档分别以100／145／190万px²身体可行面积规划，允许原±10%面积容差。先估算整组源模型、孔、次级实体和断缘的损耗，再确定拼合宽地的尺寸。按目标面积与320px结构间隔计算完整2H/1S单元；所有对象在初始计划内一起放置，不因放不下而减少数量。当前构造使用错位宽地与共享断缘；跨种子的宏观变化质量仍须单独验证，不能仅凭生成参数称已保留全部历史构型。

母体连同附属relief作为完整组，包围面积预算为目标可行面积的20%，数值源为`data/rift-auto-construction-policy.csv`。先做两次快速原形尺寸估算；因固定relief高度等非等比情况仍超限时，最多16次有界区间求解，只保留实测符合预算的缩放。比例冻结到配方，估算、放置及最终编译消费同一变换。每次提案还检查实际投影是否仍符合预算，不按已完成地图反馈调整尺寸，也不依世界名字选择特例。

2026-10-21独立设计审查区分玩法约束与工程初值，以下校准仅适用于新r14，不改旧配方：

- 宽域仍是距离真实障碍／VOID边界至少48px的身体中心。用户2026-10-23明确接受49.45%，新r14按“约一半”采用共享48%底线、50%目标，最大宽域分量至少80%保持。质量目标不参与拒绝；空间通路与巨大空白仍独立硬判定，不按某世界设置例外。已冻结旧政策保留原值。

## 翻找物来源部署（2026-10-12，修订10注册世界）

### 来源与选点规则

1. 先完成原最终地形、实体、真实出生/撤离和危险场；原节点配额、价值、风险档、20px身体、8px支撑、48px可见操作站位、路程/间距及巡逻窗口为硬约束。来源偏好只在原 `allowed` 合法候选内评分；不能先出点再向母体吸附，不能为美术关系减配额、改risk或补地。
2. 支持三种来源关系：`detached` 母体断落、`surface-peel` 表层剥离、`ground-accumulation` 开放积留。它们不是奖励分类，不以内容物/tier/品质定形，也不硬塞每图固定比例。
3. 母体断落必须引用附近实际存在、材料匹配的几何及有效接触侧；按实际轮廓而非包围盒/实体中心判断，来源与核心不得跨VOID假连接。表层剥离须有节点当地地床/可走relief的材料依据，不新增凹坑或碰撞。开放积留是独立合法的作者语法，用局部稀疏铺展与承托解释，不能把原孤立堆改名当兜底。
4. 来源偏好有上限，不能让“最近母体”压倒原路程/分散逻辑；低实体密度世界不为凑母体关系大量拒绝合法图。仍允许宽地上的合法散落，不把所有点推向solid边/空洞边或形成沿边固定搜寻规律。
5. 选择后冻结交互锚点与来源描述；可翻核心位置与节点位置完全一致，不能只搬视觉。外围只作低矮材料表现，全部像素遵从实际支撑/表面遮盖，不跨孔造假桥、不改变导航/视线。空间不足先裁外围，不得把核心裁没。
6. 核心/散料/残留使用一份无奖励含义的视觉支流。来源关系读取实际局部材料，不能总用世界主材代替混材落点；渲染描述不交付kind/value/tier/rarity或dropPlan。调换隐藏奖励而保持来源描述时，所见形状、颜色及翻找前动作须相同。

### 冻结数据、版本与接口

实际合同为 `search-site-types.ts` 的 `R100SearchSitePlacement`，序列化在 `native.searchSites`，每layout节点恰好一条：`version:1`、`nodeId`、与layout完全相同的 `position`、独立 `visualSeed`、三类 `sourceKind`、`family`、可空 `sourceObjectId/sourceAnchor`、`axis`、`footprintProfile:'grounded-material-v1'`，另以 `groundFamily` 记录实际原生地床、`sourceDomain:'formation'|'ground'` 区分来源域。`nodeId` 仅作稳定引用，不能解析前缀猜奖励。`SearchSitePlanner` 只在原合法候选内附加有上限评分；来源查真实XY三角形及VOID LOS，地表来源不虚构实体锚点，接收端校验节点身份、材料、来源域和实际几何。

## 已认可作者机制：矩形拼合与自由断缘（2026-10-12，首代表已接生产）

用户认可 `ada26f43` 的[矩形骨架及三份断缘样例](../art/previews/world-fragment-open-field/index.html)，并授权正式推广。共享机制由显式注册的独立作者图消费，原六图为对照，新增项逐批接入；未注册世界保持原有几何，下文修订7的历史合同继续约束旧局。普通solid仍只阻挡身体和近战；空间空洞仍是真实缺地，同时阻挡身体与视线。样例的人审不自动覆盖正式成品、其他布局、108世界或自然搜撤。作者组织及推广步骤归[设计依据](../design-notes/rift-world-space.md#rectangle-fragment-authoring)。

### 输入、所有权与版本

`src/generation/world-study/fragment-shape/` 的共享入口为 `generateRectilinearFragment`，输入合同如下：

```typescript
type RequestV1 = {
  algorithmVersion: 'rectilinear-fragment-v1';
  layout: {
    authoringFrame: [width: number, height: number];
    worldScale: 2;
    landRects: [x: number, y: number, width: number, height: number][];
    voidRects: [x: number, y: number, width: number, height: number][];
  };
  edgeSeed: number; // uint32：0…4294967295的整数
}
```

以上为字段示意，实际类型与预算由同目录 `types.ts` / `validation.ts` 定义。输入矩形使用作者坐标；v1固定一作者单位等于2世界像素。输出的 `contours`、`pathD` 仍是作者坐标，`fragmentContoursToWorld(result)` 统一转换世界坐标，不得消费方各乘一次或遗漏缩放。`contourKinds` 区分外岸与内孔；结果同时携带算法版本、`worldScale`、规范化seed与诊断 `stats`。SVG路径和统计不是可直接出击的地图，也不包含出生、撤离、敌人或奖励。

作者负责矩形编排及内容身份：哪里保留宽地、哪里集中破坏、尺度层次与外岸偏置。算法只编译**给定的layout**并处理其局部边缘，不会自己生成已通过人审的宽面组织或全库构型多样性。预览 `geometry.json` 是获认可研究夹具；正式世界作者数据仍须来自 `data/*.csv` 单向编译，不能将这张图硬编码进运行时再复制到所有世界。

新增作者图还须核对实际原生主体三角与最终外岸/孔的交叉，不能只核矩形包络或顶点。需要挪让时优先整组平移或统一比例，保留实例相对接合，不为旧坐标回填主要缺失；本次推广的新增图要求固定验收seed三档主体无意截断为零。附加groundEdge不算主体，原六图已认可的接岸保留并单列回归。不可容纳20px身体的残余细地条直接删除/连孔，不以8px中心有地宣称可走。

v1冻结局部处理的概率、尺度限制、关联破坏区和样式规则；对外只选明确的布局与seed，没有任意噪声强度、圆角半径或每世界私有权重。改变策略需要显式新版本和母版对照，不以保持旧版本号的方式改变已保存结果。同版本、同完整layout、同seed须精确复现且不修改输入；不承诺编辑layout后其他边角仍局部不变。修订8已将算法版本、完整布局、来源与种子纳入正式身份；恢复只消费冻结快照并核对重新编译的轮廓，不读取今日CSV。未来改算法仍须保留旧执行器或等价编译产物，不能在v1名下追改旧局。

### 几何处理顺序

1. **先做集合运算：** `union(landRects) − union(voidRects)`。提取实际外岸和内孔，去除矩形重叠产生的内部接缝。伸向外界的void矩形形成外岸缺口，不伪装成跨越外环的内部erosion。禁止逐个矩形倒角后再拼接。
2. **再作局部自由断缘：** 在真实轮廓上混合保留原角、不等长斜切、多段崩角和少量长岸断缺；用局部关联的受损倾向形成疏密与方向节奏。相邻边长和到其他轮廓的净空共同限制处理范围；小孔保留不同原角分配，避免统一变成八边形按钮。保留足够长直岸及安静段，不全周加细噪，不套统一圆角或固定倒角宽度。
3. **校验再输出：** 地面保持一个主体，孔与原骨架一一对应；不得因打磨自交、并孔、吞孔、把内孔接通外界或切出独立地块。源布局本来不合法时拒绝，不靠局部处理补桥、填孔或自动取最大块隐去问题。轮廓计数、面积变化、原轴向边保留等只作诊断，不作为“开放世界”审美分数。

本机制不规定矩形数、孔数、实体数或统一空地占比。样例的10孔，以及前轮余烬脊8孔/22实体，均不成为后续新布局定额。“动态感”指形态节奏与seed差异；同一次出击地形保持固定，不引入随时间蠕动、坍塌、跳跃或多层通行。

### 明确失败与验证边界

`FragmentShapeError` 以 `INVALID_INPUT` / `UNSUPPORTED_VERSION` / `BUDGET_EXCEEDED` / `UNSUPPORTED_TOPOLOGY` / `INVALID_OUTPUT` 区分拒绝原因。有限坐标、正尺寸、frame范围及几何预算先验收；未知版本、超预算或几何失败不得静默换seed、退回矩形、补地、删除孔或粗简化轮廓。调用方可修订layout或按已冻结的有界候选策略另试，必须保留失败，不把挑出一份成功图当作全seed通过。

母版回归绑定获认可三seed的来源/输出，检查迁移共享算法后形状不变。其余输入/seed检查覆盖真实并集、确定性、输入不变性、孔关系和几何拒绝；**这不等于20px身体能通过，也不等于生产8px网格与真实LOS已通过**。预览的保守像素身体检查和224px转身几何参照保留各自范围；不能升级为正式移动、迷雾、自然搜索或全库质量证据。

### 修订8已接入的同源接口

以下路径用于显式注册的fragment世界；接入事实、技术检查与体验验收分别登记：

- 正式空间策略版本2带完整 `fragmentShape`，重新编译的外岸/内孔必须与策略存储值逐点相等。独立fragment预算允许每环至多2048点、至多128个内孔；共享编译器总输出不超过8192点。r7及未采用fragment的旧预算保持32点，不截点、凸包化、统一平滑或强压新断缘到旧限制。

**次级宽地块（DEC-214）。** 用户红框表达的是主体之外不等长、不同方向的伸展，不是待逐一描摹的坐标。共享扩展策略在岸线细化与最终fragment编译之前，从原始地块并集外岸选择偏置站位，混合短肩与较长宽臂；不递归给新台肩长台肩，不填合已有凹湾、不均匀包围四边。土地与其2H/1S共同提出，原主体物件及完整母体不搬空；新增覆盖、支撑、宽搭接与预算不足即拒绝该提案，保留原因。策略CSV定义宽度／外伸范围、搭接、槽位、候选及净增面积上限；确定性有限候选不调用布局搜索或完整地图编译来反复试错。

`data/rift-native-construction-extension.csv`为本轮唯一数值源：短肩1槽、沿岸宽384–512px、外伸128–224px；偏置宽臂2槽、宽448–640px、外伸256–448px。共同埋入320px；名义偏移64–192px从可行起点区间的种子所选端部量起，区间较短时收束到区间内，不能把提案移出原岸。24次候选上限，净增地面积不超过原并集30%，最多新增6H／3S；这些是当前初值，实际接受数由联合检查决定，不要求每图凑齐三块。

**未完成提案的实际边界反馈。** 每次真实编译后，仅在作者H与最终闭合VOID分量一一匹配时，缓存实际8px外海/B分区和各H单元；身份不明则不使用缓存。后续布局平移该对象的实际形状来预测宽域连通，移出旧位置并恢复试探状态，B/外海保持固定，普通实体仍按实际投影参与阻行。该缓存只存在于求解期间，不进入冻结配方；重新编译仍须检查全部几何/身份/支撑/空白/宽域门。局部候选先比较归一化约束的最大违规，再比总违规，平均空白仅用于平局，不抵扣硬性违规。首次提案尚无实际缓存时不报告已经满足连通性。 有缓存时完整规划精评同时消费同一次宽域测量的`wideCount`与最大连通比例，面积预测以该计数除以上一份真实`支持身体中心数`；不再用raw16加常数代替已取得的真实分子。旧分母只是平移预测，移位/断缘重编后身体数和宽点数都可能改变，因此正式准入必须重测实际分子与分母。无缓存初始提案及粗筛仍明确使用规划估计。

**G1 最大空圆与持续无结构区（2026-10-14 Director批准，接线验证中）。** 对原有全部合法20px身体中心p，最大空白硬门改为 `max(r_open(p)+4√2)≤160px`，其中 `r_open=min(实际solid投影距离,全部实际VOID边界距离)`。VOID包括内部H、B、外海及frame外侧，距离均取同一最终真实几何，不取raw矩形或轮廓端点近似；不再侵蚀一次身体或加新margin。外岸/B只限定真实空圆能否落在地面，不成为有效H/S、q或G4遇见。旧`d_internal`仍只到合格H/S，保留其全域max、最坏点及来源作内部结构覆盖诊断；deep仍以`d_internal+4√2>112px`标记，沿原20px身体连通与bbox跨度≤448px裁决，均值同样保持内部结构距离。G2、G3、G4、配额、面积域与原预算不变。

本决定由Root基于真实物理空圆定义及固定实际c25/c27/c3的同源双测作出，不是“四夹具全部通过”或用户新终验。[离线对照](../qa/artifacts/native-spatial-2026-10-14/open-radius-calibration-round1/summary.md)中实际三图的非max指标完全同值，c25仍161.429px拒绝，c27保持158.334px，原c3仍由max/deep/G3拒绝。短岸角与有结构长带两项正控因104×16名义S的正式有效面积不足失格，未完成原正控证明；原失败保留，不再调夹具凑通过。生产measure与planning接线、正式从头生成及完整内容分别验证，不由文档更新宣布实现通过。

**G1 精评采样独立。** 完整候选max规划遍历独立8px场（4+8k），保留raw L−B的margin≥12过滤，并无条件合入去重后的真实assessmentPoints；单物件完整候选与完整tuple使用同一场。16px分层场继续负责独立可放域、职责、粗筛、内部距离deep代理、wide分母和均值，不混入新增精查点。max规划须跟随实际空圆定义：有反馈时固定真实外海/B，与随整组移位的实际H格边界及solid投影共同限圆；不能仅将最终门换源而让规划继续追旧internal max。移动单物件时缓存其余边界距离，每1024点检查原截止，可按严格等价上界退出。不增加候选名额或虚报编译；原位占原12精评名额，只接受完整分数严格改善。该层仍是预测：fresh无反馈时使用明确标注的raw形体，局部移位后的自由断缘仍可能变化，正式G1须重测最终身体域和真实几何。deep与均值始终另用内部H/S距离，不能因贴岸/B而缩短无结构带。

**完整对象成组移位。** 单物件扫描未降低最大/合计约束违规且实际G1/G3仍失败时，下一次既有refinement可由双对象操作替代；同一实际几何身份只消费一次机会，失败或异常不刷新机会。候选从真实最坏区域选最近三个完整H/S，每个A保留四个有界位移；以移动后新出现的deep越界带及恶化的max-cover点生成职责见证，分别使用现有规划限值，禁止把原本已deep的最深点当新增带。B按真实footprint达到见证限值所需距离产生两档对齐站位，有限最近三个搭档先验共同合法性，单阻挡者保留同向释放；最多144次有限预检、48个完整规划tuple，替代一次单物件扫描。共同移出旧位置、试放新位置，核对支撑、间隔及随母体移动的relief，异常原子恢复；只在最大或合计违规严格改善时选择下一完整提案，均值改善不算进展。正式编译仍执行全部实际门。固定c39的三版有限策略均未改善，包含新版职责候选；逻辑检查通过不代表存在局部改善或完整地图通过。

**初始站位与完整空洞身份。** production fresh先采齐完整H/S形体，保留真实阻行足迹与含attached relief的完整承载足迹，再在本提案L−B上按对象序列进行有界初始落位；这仍是尚未准入候选的构造，不从旧图增补。每对象在既有rough域精评至多12个合法唯一坐标；仅原域0个合法坐标时，才遍历原16px场的snap8唯一站位，仍共用同12精评名额与原截止。最后一个H将已评完整H位置按tuple排序，在同72工作额度内逐份做最终H身份资格，首个通过即止；失败不补槽，不切换另一初始化器。实体母体及relief不拆分，后续实体仍核完整支撑。失败与原域/后备域/身份次数记录在placementSearch。

初始资格与最终测量共用VOID四连通、20px地条合并及作者H关联实现，禁止使用仅L−B的岸线代替完整断缘岸线。完整profile、solid/relief支撑及全部G门在最终几何重验。已有完整提案的单对象/双对象细化仍沿独立有界路径。 H单对象细化保留原位占原12评分槽，仅对其中严格更好的站位按完整分数做同源whole-H身份资格，首过即止、全拒保留原位；预算和截止不可被局部异常捕获吞掉。最终身份/profile、来源支撑或固定B已失效的提案保留证据，但不能驱逐有效工作前沿或继续细化。

全对象职责匹配初始化已因固定c3最大规范违规退化撤出默认，仅`reinitializeNativeSpatialLayout`诊断入口保留，不能在生产失败时隐式切入。该诊断仍受独立域/全局匹配、最多12个完整状态及同源H资格限制，其失败与实现细节见实施报告，不视为生产备选。

**真实几何工作预算。** 每attempt共用72份工作额度与原截止时间。完整提案入口先预扣1份final-geometry额度，再进入布局；其中每次真实初始或细化H身份编译/测量额外消耗同一账本1份。无余额则在执行前拒绝，失败、异常及执行后截止不退款；布局提前失败仍保守占用外层额度。trace分别记录占用的`geometryEvaluations`、实际最终测量开始数`finalGeometryEvaluations`及逐次`geometryWork`。外层耗时包含嵌套资格检查，不可将各条耗时直接相加；运行期账本不进入冻结配方。

**G4 整体路线机会与局部差异（2026-10-14，用户要求纠正过度开销后收缩验收）。** 路径族、最短路/平滑、真实48px操作站位、112px首遇和每条完整路线按身份去重保持。全路径族汇总首遇H与S，使用现CSV的`.60≤ΣH/(ΣH+ΣS)≤.75`检查整体空洞机会；同一结构跨不同路线可重复计入，故这是路线机会频次，不冒充独立物件数量，独立H约2S仍由几何门另验。至少一条路线满足原224px/6件资格，否则证据不足而拒绝。所有节点/出口必须真实可达，实际连续窄段不得超过224px。逐路线比例、连续六件窗口和窄段占比20%改为独立`qualityDiagnostics`，原始数值与失败位置完整保留，不触发重排或拒绝。局部路线允许偏孔或偏实体；不能为了让每条路相同而继续进行约束求解。区域等权摘要继续仅作诊断。G1最坏空白、G2真实遮视覆盖、G3宽地连通、有效身份/数量、完整内容与60秒预算不变。这是工程验收范围修正，不是美术或玩家终审。

**路线反馈退役。** 正常完整候选不再启动针对逐路线均匀度的固定probe/tuple闭环。旧route-feedback/route-layout仅保留为历史诊断工具，不参与正常G4通过判定；实际硬门失败继续按既有有界完整候选处理，不新增求解预算。

资源部署仍按全部真实合法操作站位的最低成本定价，保留风险、配额、间距、来源与seed排序。无足量候选即整份失败，不搬节点、删资源或增加full预算。160px只用于窄段分类，不要求所有物件间距均达到160px；实际连续窄段224px上限保留。

**B 岸湾原生合同。** 2026-10-14 Director 在 DEC-209 已授权实施范围内，依据[独立根审](../qa/artifacts/native-spatial-2026-10-14/bay-design-review.md)补齐原设计已有的 B 角色及首轮初值；这不是新的用户终验。`policy.version=2`新增独立`bayProfiles`冻结输入，world显式给出`bayGrammar='shore-rect-cut-v1'`、`bayProfileIds`和`bayCountOptions`。五个代表世界均引用`shore-bay-default`，候选B数量域为0/1/2，不是每图固定两湾。其他H/S规则、目标面积、G1–G4与预算不变；随后有界 core/shoulder 作者域校准见下段。旧r11按原闭包恢复，不读取新表补字段。

- 每个fresh plan从开始共同确定land/B/H/S及B的`bayId/profileId/sourceShore/rects`；先前成图后追加、由H触海失败改名B均禁止。来源是一段真实外露岸链及朝外方向，不锁定地图某一侧。母体、H及relief的规划支撑共同消费`union(land)−union(B)`。最终所有正负矩形一次进入共享v1断缘与真实几何，完整内容仍在几何准入之后部署。
- B使用独立profile，不复用H profile；首轮范围为1–3负矩形、内切深度128–480px、口部投影宽96–192px、横向错位0.15–0.45、接续向重叠0.35–0.80、组跨度≤576px、实际删去正向土地8192–61440px²、后方厚面320px。数值是待校准初值。面积以负矩形与正向土地并集的交集计，伸在原外海的部分不算删地；最后仍验身体面积在原目标窗内，不缩小A_target或H/S配额。
- 最终身份须真实通海外湾。首轮64px通海保护采用**存在一条64×64px轴对齐方形连续通路**的保守口径：在实际8px VOID上建立方形中心合法域，四向边连续扫掠；从B在原正向土地内的实际内侧厚核，到原land外海，全程在此B局部影响包络内。不能只在原外海证明宽通路，不能以8px/对角接触代验，也不将此检验称作任意方向的精确最小口宽。B封口成H、H与B/外海连通、局部身份合并均拒绝整候选，不互换标签。外海本身连通不将彼此独立的局部B合成一个巨大对象。
- B不进入H:S、G1近邻结构或G2的q集合。G2单H消融对照保留B遮挡，防止将B提供的断视归给H；G3的真实VOID、身体/宽面/路线窄段正常包括B，G4仅可另报B遇见。B不得穿过厚板主320×320宽搭接，其内端后方厚面先在land−B域核对；最终H/S造成的收窄仍须G3实际测量，不以预留320px代验。
- 所有B矩形、顶点、配方字节和复测共用原容量及每attempt72次评价/2份完整部署预算，不另开调整次数。冻结来源、profile、矩形组和断缘seed；源码/今日CSV变化不得改写已冻结候选。完整反例及采样顺序见批准合同§9.5；B接入、艺术效果和动态潜行各自验证，不能由表项存在标通过。

**core/shoulder 有界作者域校准。** B0/B1/B2实际对照后AR-N01仍未关闭，Director于2026-10-14批准在既有矩形/自由断缘机制内分层正向板片；这不是用户视觉终验，不修改任何G门。world新增core数3–5、shoulder数1–2，总数仍4–7；旧`land_rect_*`长/厚范围作为core域保持。shoulder长边576–768px、短边384–448px，`land_shoulder_attachment='core-outward-normal-v1'`：长边沿真实源岸法向向外，短边沿岸，实际外伸192–320px；仅挂core，且与该core两轴真实交叠均≥320px。先求core，再安排这份plan起初已决定的肩片，不允许最后大core填平肩片、不允许肩挂肩。

对每片肩先求相容区间：法向尺寸N、外伸E、父片该向尺寸P，须`E∈[192,320]∩[N−P,N−320]`，沿岸落点另满足实际交叠≥320；并受frame及原面积窗约束。最短N=576仍可外伸192–256；384是沿岸厚度，不拿它减320误做仅64px的小耳。区间无解即拒绝该提案，不能clamp外伸后违反输入域，不能靠只记录父岸距离而让其他core吞没外伸。两个手算尺度例仅排除输入的直接几何矛盾，不证明身体面积或G1/G3可行，详见批准合同§9.6。所有新增字段与plate角色/父片关系须冻结；实际接入、几何/完整部署及Art结论仍分别验证。

母体变换：solid的XY位置、长宽、高度与厚度按`source_scale × sampled(min_scale,max_scale)`同组缩放，源局部关系和旋转保持；附着relief保留作者贴地height/thickness，XY位置/长宽随同组变换，不能扩高成为障碍、夹高度后冒称统一缩放，或拿低面计实体/遮视收益。所有组仍须满足真实地面支撑与材质归属。

### 联合空间增补策略（2026-10-13，r11当前运行；方法已被DEC-208替代，旧证据保持范围）

用户纠正“逐图手放、只补实体”的方法：先测量真实空间，再由共享策略比较solid、VOID与组合候选。保留矩形拼合、自由断缘及漂泊开放碎片，不能靠统一孔数、实体数或密度铺满全库。具体公式、CSV初值、候选记录与负控见[联合空间方案](../design-notes/stealth-obstacle-distribution-2026-10-13.md)，执行状态归[推广任务](../tasks/rift-spatial-rollout.md)。本节记录当前共享实现及仍保留的验证目标。新策略配方的有限正式生成与保存重放已通过，范围和计数统一见[专项QA](../qa/spatial-augmentation-2026-10-13.md)，不从注册数量推定全库体验完成。

**当前数据与接口。** `data/rift-spatial-augmentation-policy.csv`只有一个全局策略行，含尺度、有限预算、三个损失上限、开放核保留、独立目标与最低收益；`data/rift-spatial-augmentation-profiles.csv`按材料族提供经Art确认的12个从属形体参数域，全部为适配实际 authored fragment 地形的 construction 4；codegen与冻结policy校验提前拒绝v3，单体形体合法不能代替地形兼容。两表单向生成、纳入来源hash与冻结身份，不按worldId暗填局部坐标。`createR100SpatialWorldCandidates` 在基底空间定义完成后、正式出撤/Host/内容部署前调用 `augmentSpatialTerrain({definition, fragmentShape, policy, seed, candidateSeed}) → readonly SpatialAugmentedTerrain[]`。返回最多两个小型plan：最佳合法结果及存在时的前一合法态/基底；每个plan含实际 `definition`、更新后的 `fragmentShape`、追加实例/孔记录及 `trace`。`seed`用于真实几何，正式入口必传独立派生的 `candidateSeed`；纯fixture省略后者时才默认使用前者。最终候选逐个创建完整栅格与内容，不同时烘焙两个世界。源实例的source-once不变；新增实例来自独立同族从属profile，不能缩复制独有主体，未提供该材料族profile时明确拒绝solid分支但保留VOID竞争；profile字段或构造能力非法则整个policy拒绝，不能降格成空间无解。

1. **同一真实几何测量。** 已抽出 `native-terrain.ts` 共享轻量地形层：8px matter/VOID、真实solid三角足迹、完整20px身体与连续扫掠、连通和真实LOS。基底固定32px身体中心样本及有效LOS端点对，候选不能换样本缩分母。被删除/断联样本与端点保留原缺口成本；已分别记录原地变VOID、新增solid足迹并集、身体中心损失三项比例。共同存活/可达子集的前后改善摘要尚未实现，保留为后续诊断项。不能拿包围盒、黑贴片、前景阴影或可走relief当有效阻挡。
2. **两个独立缺口。** 身体轴按中心到最近solid/VOID边界的净空计算负担；112px只是首版热点核，达到CSV面积或跨度才生成候选，绝非全图净空上限。遮视轴按固定8方向、两个观察半径的有效地面端点对，用实际VOID LOS计算静态遮断不足。ordinary solid仍只阻身体/近战，**不挡玩家或敌人LOS**。任一轴进步不能抵扣另一轴退步；两轴分别对基底目标检查。光学收益入选还须有当前候选影响半径内的观察点及真实VOID见证：初始两端距离不超过208px，完整身体换位80–720px后在224px参照视距内重新射线可见；这只是几何机会，不是完整AI潜行模型。
3. **同预算三类候选。** 每轮热点同时枚举solid、VOID和组合，记录缺profile/支撑/通路等拒绝原因。solid用同族从属形体组成有限错位关系；VOID向原fragment完整layout追加局部缺地矩形，再由同一`rectilinear-fragment-v1`和edgeSeed重编。新孔可竞争，原“孔不变”不约束本策略；完整重编可能改变既有断缘，必须测最终整图而非宣称稳定局部补丁。组合记录新增实体/孔以及整体两轴变化；尚未单独消融拆分每个部件的收益。不在v1名下改变共享断缘算法。
4. **通路与开放硬门。** 保持20px身体、8px支持、至少97%合法席位可达与原主体支撑。原地变VOID、新solid占G0、原身体中心损失分别受CSV上限约束。对基底宽核的分散锚点保活并保持原宽核连通，同时保留宽核总面积与最大大开放核的相对下限；不能把宽面降成20px窄桥，或挖掉坏点后用100%可达率过关。中心净空不是实测穿口宽度。新VOID/solid关系组按真实边界净距检查，禁止围孔/围岸连续墙、地洞串联；已密集基底可不增补。原32 solid/48总实例上限保持，追加数量上限仅限成本，绝非每图定额。

## R100 工程前置：可取消生成与正式入场（2026-10-03）

正式出击和冷续局的纯地图生成已移到专用 Worker。每次新出击先固定一次随机种子及完整配方，再调用原封存执行器；当前 v1/v2、无 generation 旧身份、签名和正式选池保持原合同。Worker 内的有限候选重排仍属于这份配方的原算法，不是等待失败后重新抽世界。取消、错误或单次 60,000ms 硬截止终止本次 Worker，不自动换种子重试。

**启动失败恢复（2026-10-07）。** 生成与表面准备 Worker 在模块加载完成并收到请求后、执行前，先确认该请求已开始。只有在这份确认前发生的 Worker 错误，允许终止旧 Worker、等待120ms后以同一请求再启动一次；不重新选择世界、种子、等级或行装，也不转移输入缓冲区。两个尝试共享原60秒总截止，取消立即撤销等待及重试。确认后的运行错误、明确计算失败、克隆/传输失败及构造失败均直接报错；第二次启动失败也报错，保留首次失败供诊断。该恢复不提交出击或改写存档，准备成功后仍由原事务提交。正常无错路径和冷续身份维持原合同。

`rift-generation-execute.ts`只依赖纯生成、身份计算及传输合同，不导入 Phaser、存档或会话 singleton。传输结果保留普通对象与 typed array，`walkableMask` 方法不越线程：主线程以原 tileMap 重建 TileGrid，并复核生成身份和签名后才登记有界缓存。Worker 的结果不会自行开始 run、改变库存或写入存档。

正式 `PurificationScene` 等待准备成功后才执行原出发事务。冷续局先读取精确存档快照，按其中身份准备，在没有 await 的同一同步段复核快照并执行 prepared-only 加载；事务及救援规则唯一正文见[统一库存第7节](system-field-inventory.md#7-死亡撤离与中断恢复)。`RiftScene.create` 在后续建场帧再次进入 prepared-only 作用域，防止等待后缓存被逐出；缺失、不匹配或未知身份拒绝入场，不能退回主线程重生成。

**跨运行时限制（R100-P05）。** 精确签名包含浮点朝向；生产金样复核已确认 Node 与 Chromium 的 `Math.atan2` 末位可不同，使旧 v2 签名不一致。当前同浏览器的开发/生产 Worker 结果相同；这不等于跨引擎或浏览器升级的旧档保证。不得修改封存执行器、忽略签名或将一个平台金样直接重写成另一个平台来隐去差异；后续兼容方案需明确原环境和迁移证据。

同步生成函数仍供既有离线检查与明确 DEV 入口使用。`#rift`、pollution-review 等不带正式 recovery 的 DEV 直入，以及自行提供布局的 DEV fixture 保持原开发用途；有正式出发/恢复身份的路径始终走已准备准入，不能借 DEV 例外补救正式缓存 miss。这些入口不新增正式可选世界，也不将 I02 母版翻入生产。

取消、失焦、SHUTDOWN、直接 DESTROY 均撤销等待所有权；请求编号隔离过期消息，Worker 完成或终止后释放监听、计时器与 Worker。直接销毁可能先使 ScenePlugin 失效，因此 Promise 收尾不得恢复、渲染或访问失效场景。

此批实现改变任务执行位置，不证明总生成时长达标。主线程的接收/重建/签名复核、完整状态准入、Host 清单、表面预烤和首次建场仍须分段测量；既有自然样本 p95 超预算结论不因使用 Worker 自动关闭。三级玩法、I03 及世界资格不随本批代码接线宣告完成。

## R100 I02：作者实体试制合同（仅 DEV）

`rift-r100-masters.html` 提供折叠板、纤维结、厚壳腔的局部作者配置。实例参数和三级组合来自 `data/rift-master-scenes.csv`，经生成模块进入作者布局；这不是正式世界包、污染等级选择或 v3 生成身份。现行 v1/v2 封存恢复不消费这些数据。

2026-10-03 用户否决前批三构造后，重做I01的空间/光学基础。几何提供面、法向、局部材质坐标、高度及投影；**不从高度或画面深浅推断战术遮挡**。CSV实例显式声明 `relief`（≤8px贴地可走浮雕）或 `solid`（普通不可走实体）。独立 `erosion` 多边形在8px格中心取样，拥有吞光/缺失地面语义。`matterAt` 只回答地面是否存在，solid下方仍有地面；`roleAt` 只供前景合成。

物理网格由地表→侵蚀→solid独立三角形覆盖合成；relief不擦掉它下面的solid。观察网格只由侵蚀、缺失地面和界外生成；普通景观保留材料明暗，后方仍可被正常视野揭示。攻击网格另含solid，避免观察穿透后出现隔实体挥击。DEV `createCombatGrid` 可明确供应；正式/历史路径默认仍使用原网格，不全局翻转WALL。

完整几何先于20px身体出生、翻找、敌人及撤离部署。保持960×640、原角色、80px/s、原有限视野/混乱/朝向与原XY顶视；没有第二层、钻入悬挑或高度改变地面投影。所有地表、实体和角色统一由原生fog遮蔽；本入口停止调用 `revealProjectedTerrain`，材质自阴影不再乘入“是否可见”。DEV的 `materialLighting` 仅把旧平面ADD灯交给材质着色器，防止重复泛白，不改变任何可见范围和玩法判定。

连续材料基床先生成，压实、剥露、断端细料共用 albedo/normal/height/roughness/AO 成因字段；可走低浮雕贴地处继承基床；不可走实体的低沿必须保留完整材质、侧面明暗及接触暗部，不按高度淡回地面。断面另露内层。静态像素字段预烤，WebGL2逐原生像素接收移动肩灯及局部源光，局部光沿同一8px侵蚀网格逐格检查；不存在的地面永远无受光。角色/敌人前景遮罩只由solid形成，并覆盖实际显示边界（包括挥击），可走relief不裁人物。

**不可通行边界（2026-10-03复修）：** 在正常有限视野内，玩家必须在碰撞前辨认障碍物与地面的交界。`world.ts`把作者`role`显式传成几何`blocking`标记，不按高度猜测可通行性。阻挡折板的低端保留原外足XY占地，在内部增加短陡断面与最低厚度；原浅浮雕和其他两族形体不改。实体采用自身UV组织材质，不让地面纹理原样穿过边界；取消会抹掉面值区别的统一外沿提亮。几何法线负责断面受光，不用发光描边、全图提亮或诊断色替代正常画面的可读性。对照须含由下向上及斜向走近，原碰撞、视野和攻击规则保持。

**实体材质（2026-10-03）：** 三族各有独立地床原图与实体表皮／断层图，六张512²RGBA缓存共6MiB。`solid`才使用实体图；`relief`与地面保留地床图。CSV声明实体图来源、取样区、世界尺度、表皮／断面粗糙度与色值倍率，禁止加载失败后静默换回地面图。完整表皮与断面由实际面类型选取；实体法线以同源几何为主，仅保留少量原微结构，不从图片灰度生成高度或法线。表皮的弱反射消费同一光源和遮挡，粗糙地面保留原响应；污染发光仍由真实侵蚀字段提供。材质参数不改变碰撞、视野或可通行面积。画法与源图归[集中设计](../art/rift-r100-material-separation.md)，原3MiB纹理缓存的资源记录只代表旧版本。

材料绘制来源另由 `rift-master-materials.csv` 声明：原始母片仅供材质色与细节，不拥有地图形状、支撑、侵蚀、法线或实体高度。异步解码与有限缓存不改变地图seed；表面取材按实际世界轴/几何UV及材料事件绑定。图像加载晚到或失败不得覆盖后续已选择场景。资源与绿色侵蚀动效在场景销毁时释放，暂停/失焦不推进闪动、材料声音或玩法时间。结构绿纹只表示材料受污染，不冒称伤害范围；实际接触范围来自原生占漆/占空系统。

三级参数现已在九格DEV母版用于结构、侵蚀、占漆/占空的数量面积及污染增长。`rift-pollution-grades.csv`为数值源，`pollution.ts`把正式Host投到完整32px地面上；只有全部16个8px细格可走的32px格可承载Host，身体碰撞仍用8px。投放复用原生油膜几何与接触格，保留出生、搜取和撤离的20px身体通路及余量；危险范围、视野缩小和生死由正式Host负责。增长曲线由ChaosSystem按模拟时间积分，等级、暂停、抗性和恢复规则见混乱系统spec；未指定等级的历史出击仍用旧增长。尚未接等级收益、准备资格、正式选级或新世界生成身份。九份配置的存在不表示九份合格世界；美术母版通过与正式玩法资格分别记录。制作与实际审核归 [I02](../tasks/rift-r100-i02.md)。

## 条件生成 v2（2026-10-02，当前新出击合同）

用户授权将 F052 从试点推进生产。下述合同用于 `generation.version=2`；无 generation 的旧图及 version 1 使用原算法与签名。后文旧图书馆的锚点、15格深区及40–60秒描述属于旧方案/节奏目标，不能覆盖本节的开放世界准入。实现与本轮证据见[任务](../tasks/rift-conditions-2026-10-02.md)、[QA](../qa/rift-conditions-2026-10-02.md)。

**生成单位。** 原有5份世界、2份开放空间继续定义材料能力与可走空间。`data/rift-world-conditions.csv` 新增沉积、定向断裂、聚合3种过程程序；它们组合已有能力，不是3张手工地图。能力需求/排斥、连续参数范围、深区成本、景观尺度与动效全部从CSV编译；未知能力、空范围、无效合同必须拒绝。支持范围内的每次新出击解析为完整不可变条件，记录程序版本与来源哈希。

**随机与共同成因。** world/layout/material/placement/encounters/motion 是命名支流。世界支流生成统一组织轴；连续强度、相干度与尺度共同改变地面片区、材料顺向、空洞侵蚀组织与中尺度形体。几何与绘制不得分别抽完全无关方向。增加材料细节不得消费敌人或资源随机流，保存的材料种子保持视觉重建。

**路线—威胁—收益。** 先固定合法地貌和最终地面敌人身份、形态及路点，再以实际感知模式、初始朝向、转面范围、巡逻和遮挡建立潜在暴露场。不能把“距任一敌人很近”当作必然危险。保守32px内容网格使用8向欧氏路程、禁止穿角，静态身体不作为可走格；实际移动仍由8px支撑和20px身体决定。

- 同一出生/撤离之间保留短路和较低暴露路线，后者至少多走64px、累计潜在暴露至少降低20%。它是常态地面甲的风险比较，不承诺绝对安全或战斗后的动态路径。
- 薪柴保持3/3/2堆、1/2/4价值，共17；污染物保持3堆，既有掉落不重定价。safe 放在低暴露路线附近且常态威胁不超过CSV阈值；contested 受真实敌人覆盖，但不索要比deep更大的路程成本。
- deep 由 `出生→合法翻找站位→撤离` 相对 `出生→撤离` 的最短路增量定价；当前程序阈值320–448px。精查消费真实8px支撑、20px身体、48px翻找半径、视线和最终坐标，枚举可交互站位取最低成本，不能把必须走到节点中心当作实际付出。进入和离开可用站位的接近段均须存在潜在暴露，两处deep不得挤在同一座位。网格测量不等于连续任意角度运动的数学最短路，也不等于40–60秒真实搜取时间；等待、搜寻和战斗需实玩另测。
- 地面部署与完整占漆共同验收。占漆不得覆盖任何翻堆，危险场要避让低暴露退路的完整身体带；实际宿主配额、完整形体、出生保护与巡逻合法性保持。放不下则换部署或地貌，禁止暗减配额。

**景观。** 三个较大材料形体群分别服务主转折、深区接近与撤离接近。沿用同世界色板、层理/晶面/薄釉断面画法与组织轴；普通散布在其周围安静下来。它们是可跨越低浮雕，不提供新碰撞或隐形遮挡；不使用奖励色、独立绿光、标签或图标。局部沉降/剪移/反射使用既有地表活层，仅在最终地面且当前视野中显示。

**失败与保存。** 每份地貌允许有限内容重排，外层尝试8个地貌候选，随后至多3个CSV后备种子；后备始终使用同一已冻结世界、空间及条件，仍过全部准入。耗尽时明确失败，不换皮、删敌人或回落v1。identity同时保存解析条件、原始profile/space快照、请求种子和实际成功身份；签名覆盖地形、部署、Host、条件与景观座位。重载只复算冻结承诺，不重抽当前CSV。

## 概述

本系统替换裂隙的手写固定图（`src/scenes/rift-map-data.ts`，约 48×32 矩形边 + 细碎障碍）。净化点不换。

它服务两件事：

1. **寻找退路与贪婪抉择同时成立。** 出生与唯一撤离必须有足够探索间隔，位置不绑定地图两端或固定相对方向；选点遵守上文DEC-196。历史40–60秒主干预算不直接套用扩大后的DEV世界，须由完整搜撤实走重新验证；薪柴风险仍结合到撤离的路程与实际威胁。
2. **每一次踏入是另一块世界碎片。** 可走陆地的外轮廓不能靠「这是一张长方形纸」预判；障碍要读得出「这曾是什么」；两次出击的色温 / 地表 / 障碍语言要能分清。

`vision.md` 把「多种裂隙环境 / 生物群落」写在明确不做；`world.md` 写过 MVP 共用一套视觉主题。**人本 Slice 的指令覆盖这两句**：做有限种碎片氛围，优先已锁 L1，不是无限生物群落，也不是丛林 / 冰原 / 岩浆那种新题材。

宏观方向已锁（DEC-005 / DEC-ARCH-003）：不规则碎片 + 有机内部 + 窄连接。**不退回 BSP 方正房间。** 内部怎么填、外轮廓怎么来，下面给多条路，禁止一棵树吊死。架构里的 Voronoi+CA 是要认真验证的技术路线，不是本文件已经定案的唯一实现。

本 Slice **不**做撤离多样性（多出口、第二种条件、捷径口）。提示仍是「[E] 撤离」。小地图继续标**一个**撤离点。不新开 HUD、不新造标记形状。

## 技术事实（实现层可果断）

### 不规则指什么

不规则 = **玩家看见的可走陆地外轮廓**，不是「数组变成多边形」。

- 引擎里 tile 数组几乎总是矩形缓冲。矩形缓冲合法。
- 缓冲里、可走陆地之外的格子当作**虚空 / 不可走**。合法。
- **禁止**用「数组还是矩形」当借口，交出一张矩形可走区。
- **禁止**先铺满矩形可走区，再在边上啃几个缺口充数。

玩家看到的应该是：一块（或几块拼在一起的）陆地漂在虚空里，边缘弯、缺、错位。不要再用一圈矩形墙当地图外框。墙只出现在「这段墙曾是什么」的情景障碍里。

### 虚空、墙、视线（本条定技术默认）

| 格子 | 可走 | 玩家看见 | 挡视线 |
| ---- | ---- | -------- | ------ |
| 地板 | 是 | 地表（L1 底色 + 材质残影 + L2 污染） | 否 |
| 墙 / 障碍 | 否 | 可读残块（砖 / 木 / 土 / 金属仍可辨） | 是 |
| 虚空 | 否 | void-black，不是墙皮 | **是**（DEC-106） |

虚空挡视线（DEC-106 虚空吞光，2026-08-29 人拍板，翻转 Slice 6 的「不挡」默认）：射线打进虚空即停，手电光场不再穿过地图边界，虚空海湾两侧不可互见（玩家 / 敌人对称，同一套 `hasLineOfSight`）。对岸本来就在虚空之后，照旧看不见。虚空仍不是墙：不画墙皮、不参与墙体情景语法。

`TileType` 有墙 / 地板 / 裂口 / 虚空。虚空不可走、挡视线（DEC-106），着色走 `void-black`，禁止铺成地板。`src/types/game-types.ts` 里 Foundation 草案 `MapData.exitPoints: Position[]` 是复数出口——**本 Slice 不实现那份草案的多出口**。生成器输出以本节契约为准。

### 缓冲多大

玩家移速 80 px/s，tile 32 px → 约 2.5 格/秒。主干 40–60 秒 ≈ **100–150 格**的走路路径，不是 100–150 格的矩形边长。

现图 48×32 从出生到撤离直线大约 10 秒，不够。加长靠**弯路 + 陆地拉长**，不靠强上 80×80。`GAME_CONSTANTS.MAP` 的 80×80 和 Voronoi/CA 数字是架构占位，**不是本文件已锁算法**。人锁方向后再改常量。

建议缓冲落在现图同级到略长（大约长边 48–64 格），以主干秒数为准。可走陆地**不得填满**这个矩形。

## 规则

### G — 何时生成、何时不变

1. 当玩家**从净化点踏入裂隙、开始这一次出击**时，生成完整 `GeneratedRiftLayout`。同一次出击内不重跑。
2. 当玩家撤离或死亡、回到净化点之后，本次布局作废。下一次踏入再生成。
3. 「按 R」一律回净化点（DEC-056）。阵亡不是原地再打这一次。C4 已改 `RunController.restart()`。
4. 同一种子必须得到同一张图（地表噪声已是确定性的，布局也必须是）。

### C — 连通与坏图（FATAL）

连通性是地图生成的硬约束，先于审美、氛围、装饰。坏连通 = 坏图，禁止当成品或预览样例交出。

5. 从出生格 flood-fill，必须能走到撤离格。走不到 = 坏图。
5a. 陆地掩膜本身必须是一块四连通（外轮廓只留最大连通块）。禁止一次出击交出互不相连的多岛。
5b. 墙上完之后，全部可走地板仍必须是一块四连通。墙把地切开 = 坏图。先就地挖通，再重试。
5c. 装饰 / 植被 / 残骸 / 光影 / 粒子 / 波动 **不得**再拆连通：只画在已连通的可走格上，或做成不挡路的漆。
5d. 预览草案与正式生成器走同一条连通闸门。看起来丰富但走不通，不合格。
6. 薪柴、污染物节点、巡逻每一个路点，必须可走，且从出生可达。
7. 坏图：先修补（挖通一条合法通道、把点挪到最近可走格），再重试新种子。修补与重试都留在**人锁定的那条算法路线里**。禁止失败就换一家算法。
8. 重试有上限。到顶仍坏：开发期大声失败；发行期最后一次强制挖通出生→撤离，并记一条警告。不换路线。

### L — 陆地与外轮廓

9. 可走陆地的外轮廓必须不规则。验收看玩家看见的陆地边缘，不看数组是不是矩形。
10. 禁止：矩形可走区 + 边上几个缺口。禁止：四边一圈墙当外框。
11. 外轮廓算法：**已收口为生长 + 腐蚀，取最大连通块**（路 1C）。实现：`src/generation/outline-mask.ts`。坏图（填满缓冲、啃边矩形、贴齐四边）丢弃重试。相交矩形并集不是本批实现。

### O — 障碍

12. 障碍是嵌进岛的体量，不是岛心道具，也不是胡椒粒。人要能指出走法（这边能绕、这边能穿）。覆盖浅时可能还认得「曾是什么」；覆盖到 unnamed 时指不出名字也成立，不算失败。
13. DEC-005 反的是「方正房间 + 走廊像地牢游戏」，**不是**「这段墙曾是一栋房子」。残缺体量允许。闭合房间 + 门廊，禁止。禁止完整器物剪影（整节车厢、完整月台色带）。**1 格宽长条正交织网同样读成迷宫**（DEC-058）：真实长墙可以有，但不能用很多根同样细的条拼接。障碍要读成体积残骸，不要读成地牢平面图。
14. 细胞自动机（CA）可以当风化（咬边、穿洞、让残块显老），**不能当唯一结构来源**。禁止只靠 CA 胡椒粒墙交差。
15. 现图已有 L/T/C 和小簇（2–12 格），人仍读成细碎随机。所以「把簇稍微加大」本身不够。见约束 2。把簇改成贯穿细篱笆也不够——那是迷宫，不是情景。
16. 障碍策略：**方向 1 厚短残块**（DEC-058，2026-08-18 人锁）。走法骨架与残片身份分开。预览栈：`structure-grammars.ts` + `cover.ts` + `stealth-density.ts` + 配方。`masses.ts` 的围院语言不进这条栈。诊所/地铁也走短板/坨，全图最多一把 L。墙围死的地就地挖开。CA 不当结构。
16a. 预览 **不得**用「最长轴对齐空直线 ≤14」当生产循环或 FATAL。形状闸门：1 宽直行 ≤6；非木墙至少一半属 2 厚/坨；平行窄槽 0；无三向 1 宽巷；至少一块 6×6 空地且边缘有厚掩护；禁 2–4 宽且长 >8 的巷；墙占比 ≤18% 是顶。连通仍 FATAL。
16b. 密度已锁（DEC-061）：DEC-060 结合层进生产岛。身份墙之后按可藏距离补厚短件。人认后空地再收约 20%（种子 101：墙约 18% 顶、空矩形 72–99、掩护 P90 5–7）。P90 到厚掩护 ≤8；距掩护 >7 的四连通块 ≤48 是尺不是 48 格硬闸门。禁止用空直线工厂或空矩形 48 倒逼篱笆。沿缘锚只向内补，岛心空。褶脊 / L / 双梁 / 宅基 / 残体 / 嵌板才允许尽端开口的 2 厚隔断。

### P — 布点（一个撤离，不要多样性）

17. 出生与唯一撤离保持足够探索间隔，按DEC-196从合法可达位置抽选。既不固定近侧归返，也不固定两端、对岸或最远点；玩家必须在探索中发现退路。
18. 恰好一个撤离点。走近按 E。触发半径沿用现规则。位置由生成器给。禁止落在手写图那个固定格上（现图大约是偏上居中的 `X`）。
19. 撤离格本身不在任何巡逻的常驻视野内。通往撤离的最后一段由 1 个巡逻覆盖（最后一道关）。**这道关必须是渗透体**（`type: 'infiltrator'`）。改写体不站撤离门。
20. 薪柴分档与数量沿用 `system-chaos-scavenge-extract`：safe 3 / contested 3 / deep 2。坐标改由生成器按「离撤离路程 × 巡逻覆盖」放置，不再写死 ASCII。
21. **换路是硬保证**（DEC-064，覆盖 DEC-061 / DEC-062 的软目标）。仍是**一个**撤离点。不是两个撤离点，不是捷径口。`npm run check:layout`：无换路 = **坏图（FATAL）**，不是 info。失败则**重试整岛**（换种子、同一条算法）。禁止为挤路加细墙、破坏规则 16a/16b、或让墙后地板四连通分量 ≠ 1。连通仍 FATAL。规则 8 的发行期强制挖通只救连通，不救换路。

    机器判定（按序；任一步失败 = 坏图）：

    1. **主路** = 出生格 → 唯一撤离格的四连通最短路。长度 = **格子步数**（BFS 移动次数 = 路径格数 − 1）。走不到已由规则 5 判坏。
    2. **第二路存在**：把主路内部格（路径上除出生、撤离外的每一格）**临时当作墙**之后，出生仍须能四连通走到撤离。走不到 = 无换路。临时墙只用于本判定，成品图上这些格仍可走。
    3. **第二路** = 上述临时墙上，出生→撤离的四连通最短路。其格子步数必须 **≥ 1.15 × 主路格子步数**。不够长 = 坏图。
    4. **开阔格**：可走格满足「四邻（上右下左）墙格数 ≤ 1」**或**「到最近墙格的四连通格距（曼哈顿，格为单位）≥ 2」。墙 = 墙格，不含虚空。四连通距墙 ≥ 2 蕴含四邻墙数 = 0，故本 OR 的有效判定是 **四邻墙数 ≤ 1**（贴着一面墙走仍算开阔；夹在两面墙之间的 1 宽缝不算）。
    5. 一条路的**开阔格占比** = 该路路径格中开阔格数 / 该路路径格数（含出生与撤离）。两条路里**较短者**（格子步数更小；若步数并列则主路视为较短）必须开阔格占比**严格更高**（= 更暴露）。较短者不够暴露 = 坏图。
    6. 以上任一步失败：丢弃本岛，重试整岛。禁止用加细墙、拆形状闸门、切开地板连通来「做出第二条路」。
22. 巡逻（过渡期，DEC-077 / I3-A）：仍是 3–4 个占地可追击，其中**恰好 1 个** `type: 'rewriter'`（听觉主轴仍由改写体占名额）。不要用句法甲配额 2–3 去砍巡逻人数；为**每条** spawn 配一个 `form`。`type` 由该 form 的感知词素派生（`sense_hear` → rewriter，否则 infiltrator）。撤离门仍是视锥甲：form 锁有机残影 + 渗透 + 视锥，写入 `spawn.form`，不是工厂按 role 三元覆盖。乙 / 丙 / 丁不进 `enemySpawns`。一次出击一份 `contaminationDraw`（种子独立 fork `mix32(layout.seed, 'lexicon')`）；宿主只物化这份抽卡里的非甲 form，禁止再调 `drawSortie`。钉层空的乙↔丁回退仍在。钉层（墙缘折线、占漆地板格、走廊包围盒）必须交出。路点可走、从出生可达。全图听噪 === 1 的最终迁移未做。契约细节在 `system-enemy-ai`「生成器契约」与句法 spec 实现规格。
23. 污染物节点放在可走格，从出生可达。数量沿用现图量级（现为 3），本 Slice 不新开节点规则。

### A — 氛围

24a. 每一次踏入抽 `FragmentRoll`：`contaminationAge` ∈ {new, standard, ancient} 与 `ruinSeverity` ∈ {intact, broken, eaten}（`typeId` 即本次 `fragmentTypeId`）。两轴必须实际抽取（同种子可复现），禁止跳过抽取、把所有图写成 `standard` + `broken`。允许某次抽中该组合。旋钮只走 `docs/art/rift-fragment-surfaces.md`「组合轴」；禁止新 hex。一张图一个 `typeId`。

## 约束 1 — 不规则外轮廓（至少三条路，未定案）

要解决的问题：整张图是规则矩形，四边一圈墙。玩家对「往哪探」有稳定预期。

下面每条都能做出可走掩膜。人给的「相交矩形并集」必须在列表里，且旁边至少两条完全不同的路。

### 路 1A — 若干大幅相交矩形的并集

把 3–6 个大矩形错开叠在一起，并集 = 陆地，其余 = 虚空。

- **后果**：面积好控，主干秒数好调；轮廓在错角处拐弯。矩形少、又轴对齐时，玩家仍会读成「几块纸贴在一起」，不规则偏弱。
- **和世界观**：拼合说得通（被撕开的空间块）。矩形太多会顶到「不遵循常规建筑逻辑」。
- **和已有管线**：最好栅格化。和净化点极坐标团不是同一种形状语言——裂隙不该看起来像另一颗力场泡。
- **风险**：实现图省事变成「两个矩形咬一口」，等于禁止项。

### 路 1B — 宏观碎片并集，外围丢掉，外轮廓 = 拼合锯齿

先切 4–6 块不规则碎片（Voronoi 是做法之一，不是唯一），丢掉外围，留下的并集当陆地。外轮廓是碎片互相咬出来的锯齿。

- **后果**：最贴「异时空碎片被强行拼合」。容易出细刺、夹缝、空洞，要补最小宽度。
- **和世界观**：最贴 `world.md` 空间结构。
- **和已有管线**：和 DEC-005 / DEC-ARCH-003 的宏观层同方向。**本条不把 Voronoi 写成已定案。** 碎片也可以用斑块、印章、隐式场再切。
- **风险**：把约束 1 收成「做完 Voronoi 就等于不规则」——内部填满后外框仍可能是圆滚滚的一团。

### 路 1C — 从种子生长再腐蚀，取最大连通块

从种子蔓延，再腐蚀，最大连通块当陆地。

- **后果**：轮廓很有机，几乎不可能读成矩形。主干长度和「两端」不好控；容易长成一块洞穴岛，不像世界残片。
- **和世界观**：偏「有机洞穴」，弱于「被撕开的现实」。
- **和已有管线**：掩膜好做。情景障碍很难挂——没有「这是一条街」的骨架。DEC-ARCH-003 写明不设纯 CA 降级；若本条当**唯一**外轮廓，会和架构顶牛（人要求多条路，所以列在这里，不锁）。
- **风险**：和约束 2 抢：结构全靠生长，障碍只能再撒胡椒粒。

### 路 1D — 隐式曲面 / 极坐标压力团

用极径 + 噪声（或几个斑块的隐式场）画出陆地，再栅格化。净化点 `BoundaryShape` 只作技术参考，不照搬。

- **后果**：一块有叶瓣的团。不规则有，但常常是「一颗歪豆子」，不是拼合。
- **和世界观**：裂隙是伤口，不是门，也不是净化点那层膜。整张裂隙长得像净化点泡，两个空间会糊成一种东西。
- **和已有管线**：极坐标代码可参考，语义不能抄（净化点会随潮汐挤；裂隙陆地出击中不变）。
- **风险**：人一眼看成「又一个力场边界」。

### 路 1E — 预制轮廓章，旋转缩放当掩膜

手绘几枚破碎外轮廓，生成时旋转、缩放、可少量叠印，印成掩膜。

- **后果**：不规则有作者保证。章少了会被认出来（「又是那三块岛」）。
- **和世界观**：章可以画成撕页、碎玻璃，贴设定。
- **和已有管线**：章是内容资产，不是色表。不要把轮廓点写进污染物 CSV。种类少时，两次出击轮廓会撞车，和「布局不是上一趟」抢验证。
- **风险**：本 Slice 来不及画够章。

**禁止充数**：矩形可走区啃缺口。无论上面走哪条，这条都不算过关。

## 约束 2 — 障碍要有情景（至少三条路，未定案）

要解决的问题：人看见障碍，读成细碎随机，读不出「我在探索一块世界碎片」。

DEC-005 反的是地牢房间，不是「这段墙曾是房子」。CA 可以风化，不能当唯一结构。

### 路 2A — 先放 2–3 个可读地标，再填缝

先落下「一段街 / 一个院子 / 一道脊」这种人能叫出名的东西，缝再用小结构补。

- **后果**：玩家有东西可指。缝若仍用 CA 胡椒粒，地标一走过又碎。
- **和世界观**：贴「原有事物残影」。
- **和已有管线**：现有 `LandmarkDef`（水洼 / 刮痕 / 碎石贴花）**不挡路、不断视线**，不能当本条的实现。本条的地标必须是墙格组成的残块。
- **风险**：只完成贴花，墙还是细碎的。

### 路 2B — 按碎片类型换障碍语法

图书馆 / 医院 / 地铁 / 居民区 / 户外是表上的身份样本，不是五种换皮。墙形跟 `massGrammar` 走，走法骨架共用。

- **后果**：最能读出「这曾是什么」。和约束 3 绑在一起：氛围种类一少，语法种类也少。
- **和世界观**：基体不同、污染同一套青绿（有主占漆与敌人 ramp 同源；氛围簇已下线）。最贴设定。
- **和已有管线**：`procedural-surface` 必须吃碎片类型，不能写死 `frag-outdoor`。每种语法要 art A1 写墙 / 地表怎么画。五种全做，本 Slice 批次会爆。
- **风险**：语法只换贴图、不换形状，人仍读成同一堆石头。

### 路 2C — 提高最小特征尺度

禁止大量 1–2 格孤岛。残块至少到人能看成「一段东西」的长度（现图 2–12 格仍失败，下限要明显高于「一小簇」）。

- **后果**：画面干净一点。**单独不够**——现图已经不是 1 格胡椒粒，人照样读成随机。
- **和世界观**：中性。大石头不必曾是房子。
- **和已有管线**：好做，和任何一条都能叠。
- **风险**：把「加大」当成交差，约束 2 仍失败。

### 路 2D — 预制残块印章 + 污染侵蚀

先盖「未闭合的房基 / 半截站台 / 一排架子」印章，再用污染咬边、穿洞。印章不是闭合房间，没有门廊。

- **后果**：结构可读，风化后仍像残留。印章少了会重复。
- **和世界观**：就是「这段墙曾是房子」。只要不封成房间+走廊，就不犯 DEC-005。
- **和已有管线**：Qud 用 WFC 做历史建筑——可参考「先结构后侵蚀」，**不把 WFC 写成必选**（架构已标难调）。印章是内容，不是色表。
- **风险**：印章一封四壁、留门，就会退回地牢。

**CA 的位置**：上面任何一条都可以用 CA 咬边。CA 不能当本约束的唯一答案。

## 约束 3 — 不同出击，不同氛围（至少三条路，未定案）

要解决的问题：现在每次都是户外灰绿。人要求两次踏入能分清是另一块碎片。

已锁五套 L1：旧图书馆 / 医院实验室 / 地铁工业 / 居民区 / 户外。本 Slice 不发明新色。

`art-direction` 有一句内部张力：「同一张图统一一个 frag-*」和「碎片接缝两种底色相邻」同时存在。下面把「一张图一种记忆」和「一张图拼两种」分开写，等人拍。

### 路 3A — 每一次踏入抽一种已锁 L1，地表 + 障碍语法跟着变

五套记忆都进策划表，`enabled` 控制谁参与抽取。抽中谁，整张图的底色、材质残影、障碍语法跟谁走。

- **后果**：最能回答验证问题 4。A1 和障碍语法要按套数做。五套全开，本 Slice 重。
- **和世界观**：覆盖「MVP 一套主题」；仍是有限种，不是无限群系。
- **和已有管线**：优先。色板已锁，地表管线已在，只是写死户外。必须参数化，读 CSV，不手写第二套色表。
- **风险**：只换 L1 六位数、不换材质和语法——5–10 的色差在 32px + 视野遮罩下可能消失（art-direction 自己标过这个险）。

### 路 3B — 同一种记忆再叠污染年龄 / 浓度

同一套 L1，再叠偏蓝新生 / 正 teal / 暖绿古老（对应已锁轻 / 标准 / 重）。

- **后果**：同一种地方，新旧不同。两次都是户外时，人可能读成「同一个公园，故障多一点」，不是「另一块世界碎片」。
- **和世界观**：浓度梯度已锁，合法。单独不够撑「不同世界的碎片」。
- **和已有管线**：地表已有 teal 渗参数，最好做。适合当 3A 或 3C 的叠加，不适合当唯一手段。
- **风险**：验收时被当成「还是那套绿」。

### 路 3C — 本 Slice 只做 2–3 种，其余留给后面

策划表仍写五套，`enabled` 只开 2–3。优先开**语法差得最开**的，不要开两套都是灰绿近亲。

- **后果**：本 Slice 做完的概率高。验证「能分清」用 2–3 种就够。其余记忆留给后面的 A1。
- **和世界观**：仍是有限种。
- **和已有管线**：户外已经在跑，等于白送一种。另外 1–2 种要人点名（例如书架墙 vs 柱列，和户外土脊差最大）。
- **风险**：若只开户外 + 居民区，两套都偏褐灰，分不清。

### 路 3D — 只改雾 / 亮度 / 污染密度，不改障碍语法

同一套障碍，同一套地表家族，只拧视野雾、亮、teal 密度。

- **后果**：最便宜。
- **和世界观**：弱。氛围在设定里是基体 + 污染，不是天气。
- **和已有管线**：视野和地表都能拧。**标：可能不够。** 验证问题 4 写的是色温、地表、**障碍语言**。本条不改障碍语言，验收大概率失败。
- **风险**：做成「同一张图换滤镜」。

### 路 3E — 一张图拼两种 L1（拼合，不是新色）

一次出击里两块陆地两种已锁记忆，接缝色温跳一下。

- **后果**：单趟更像「强行拼合」。两次出击若都从同一池子拼，**两趟之间**反而更难分清。
- **和世界观**：贴「多块现实拼在一起」。
- **和已有管线**：顶到「同一张图统一一个 frag-*」。接缝要地表能画两种底色相邻。比 3A 更重。
- **风险**：本 Slice 批次爆；验证「两趟能分清」变弱。

**禁止**：继续全员户外灰绿。禁止未论证新色。

## Schema（内容条目）

```typescript
// data/rift-fragments.csv → src/generated/
// 开放表，不是 5 个 id 的死枚举。新行可以加；新色必须先论证进 art-direction / palette。

interface FragmentTypeDef {
  id: string
  displayName: string
  coverage: string
  massGrammar: string
  jogPeriod: number
  jogAmp: number
  gapCount: number
  gapPlacement: string
  turnCount: number
  turnCorner: string
  capKind: string
  facingPolicy: string
  join: string
  surfaceMaterial: string
  stainKey: string
  scratchAngle: string
  scratchDispersion: number
  enabled: boolean
}

// 一次生成抽到的组合（种类 × 污染年龄 × 残破）。成品差异主要靠这里，不靠无限群系。
interface FragmentRoll {
  typeId: string
  contaminationAge: 'new' | 'standard' | 'ancient'
  ruinSeverity: 'intact' | 'broken' | 'eaten'
}
```

面向玩家的名字用术语表地点规则：`[状态/特征] + [原有空间类型]`。本 Slice 默认**不上屏**碎片名；种类先服务生成和地表。要上屏另走界面做法。

**策划表列说明（DEC-094；禁止再误判）：**

| 列 | 现行消费 | 处置 |
| -- | -------- | ---- |
| `surface_material` | **只选出击脚步音**（`rift-scene.ts` 的 `stepKey`）。烤地不读。禁止再读成「木地板看起来像木头」 | **保留。** `plaster` 未进脚步映射；启用居民区公寓那一行时补 `stepKey`，不补绘制、不另开迭代 |
| `jog_period` / `jog_amp` / `gap_count` / `gap_placement` / `turn_count` / `turn_corner` / `cap_kind` / `facing_policy` | 质量语法向量数字（I6-Q 已放开取值；I6-F 按身份配方填入）。`mass_grammar` 仍是最近预设名 | **活列。** 禁止靠已删列或第一层落格表达身份 |
| `scratch_dispersion` | 划痕角离散度（弧度）。`scratch_angle` 仍是 free / orthogonal / longitudinal 策略 | **活列。** 本批不改烤地划痕接线 |
| `wall_body_key` / `wall_rim_key` | 已删。墙读 `wall_bv × wall_bias_*` | **已删**，不接线 |
| `l1_key` / `source_domain` | 已删 | **已删**，不接线 |

**扩展纪律**：加新「曾经是什么」= 策划表新行 + 美术论证。加组合 = 生成器抽 `FragmentRoll`，不新开系统。Slice 6 先接通户外 / 医院 / 地铁三种。**DEC-090 / I6-G：** 迭代 6 已把旧图书馆纳入可生成范围（四张一起标定）。`data/rift-fragments.csv` 旧图书馆一行 `enabled` 已为真，生产路径。居民区公寓保持假（抽卡四张）。~~簇状质量语法未实现~~ **DEC-094：** 簇是参数点，禁止再当独立待开。抽卡已启用行等权；三张变四张后旧世界从约三分之一降到四分之一，不加权重列。每一次踏入抽齐污染年龄与残破度（规则 24a），禁止永远标准 + 残破。遇到「档位不够 / 只有 N 种」先看那个 N 是不是一段手写 if。

## 边界情况

- 无换路（主路内部封死后走不到撤离）、第二路短于 1.15× 主路、或较短者开阔格占比不严格更高：坏图，重试整岛。禁止加细墙交差。
- 生成出两块陆地、中间全是虚空：算坏图。修补或重试，直到出生能走到撤离。不把第二块当第二张图。
- 撤离点滚到手写图那个旧格子：丢弃，重抽。
- 撤离点落在出生附近或缺乏实际探索间隔：丢弃。按DEC-196从其他合法位置抽选，不以固定两端、对岸或最远点补救；无候选明确失败。
- 可走区几乎填满缓冲、外轮廓贴着矩形边：算没通过约束 1，坏图。
- 障碍全是 1–2 格孤岛、没有可指名残块：算没通过约束 2，坏图。
- 连续两次生成抽到同一 `fragmentTypeId`：允许（有限种会撞）。不能靠「禁止连抽」假装种类很多。分清主要靠种类之间差得够大，不靠伪随机保证。
- 手写图夹具与生成器并存：夹具只给对照 / 测试。正式踏入走生成器。
- `tool-system` 的 abyss 若仍读固定图薪柴坐标：会指到空地。接线时必须改读本次 `kindlingNodes`。本文件不写代码。

## 验证标准

- 本 Slice 结束时，人连续踏入至少两次，能回答：
  1. 布局不是上一趟那张（墙、可走区、出生、撤离都是这一次踏入生成的；出击中不变）。
  2. 可走区外轮廓不是规则矩形。
  3. 障碍读得出「这曾是什么」。
  4. 两次氛围能分清（色温、地表、障碍语言，不只是形状）。
- 不验证「选哪个出口」。
- 预期正面：还会为了多拿一点而改路；多出来的是「这是另一块碎片」。
- 如果不 work 的信号：两趟轮廓仍像同一张长方形纸；障碍仍像胡椒粒；两趟都是户外灰绿；撤离还在旧格子；出生走不到撤离；无换路（只有一条出生→撤离的路，或短路并不更暴露）。

## 已锁定

1. 每一次从净化点踏入裂隙、开始这一次出击时生成完整布局。出击未结束前不变。
2. 只换裂隙。净化点不动。
3. 主干走路约 40–60 秒。不强上 80×80。
4. 一个撤离点，走近按 E。位置由生成器给，禁止钉在手写图那个格子。
5. 不要多出口、不要第二种条件、不要捷径口。
6. 可走区外轮廓必须不规则。矩形缓冲 + 虚空掩膜合法。禁止矩形可走区啃缺口充数。
7. 障碍必须有情景。DEC-005 反地牢房间，不反「这段墙曾是房子」。CA 只可风化，不可当唯一结构。1 格宽长条正交织网同样读成迷宫（DEC-058）；形状闸门打剪影，不用 `sight≤14`。
8. 不同出击禁止同一套配色 / 氛围。有限种碎片氛围，优先已锁 L1，不发明新色。
9. 不退回 BSP 方正房间。
10. 策划向字段进 `data/*.csv`。数据从生成器出。
11. 从出生必须能走到撤离。坏图修补 / 重试，不换算法路线。
12. 撤离点坐标由本系统生成。旧撤离规格已就地补句（D2）。
13. 阵亡 = 失败，回净化点。禁止原地按 R 再打这一次。
14. 换路硬保证：规则 21 机器闸门。无换路 = 坏图。禁止为挤路拆形状闸门或连通。
15. 每一次踏入抽 `contaminationAge` × `ruinSeverity`（规则 24a）。禁止永远 `standard` + `broken`。禁止新 hex。

## 专业侧已收口（不再把技术组合踢给人）

人负责拍**体验方案**。算法组合由 design/code 收口，见 `docs/design-notes/slice-6-system-proposal.md`。

- **外轮廓**：生长 + 腐蚀，取最大连通块。预览：`docs/art/demos/slice-6-outline/`。
- **障碍**：按碎片身份换墙的形状；禁止细碎孤岛；禁止 1 格宽长条织走廊网（DEC-058）。CA 只风化。密度已锁（DEC-061）：方向 1 厚短残块；正交 B；DEC-060 结合层。空地再收约 20% 已进岛。
- **氛围**：五类是词表起点，不是天花板。成品靠 CSV 扩展 +（种类 × 污染年龄 × 残破）组合。本 Slice 先接通三种：**户外、医院、地铁**。一张图一种类型。每一次踏入抽 `contaminationAge` 与 `ruinSeverity`（规则 24a）；旋钮合同 `docs/art/rift-fragment-surfaces.md` 组合轴。禁止永远 `standard` + `broken`。禁止新 hex。
- **阵亡**：回净化点；薪柴仍为 0；这次出击仍走归来/冲击。不另扣稳定度。
