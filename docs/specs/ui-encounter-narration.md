# UI/UX：遭遇识别旁白（污染句法的识别表面）

> **TL;DR**: 污染句法的识别表面，不是独立玩法系统。裂隙里第一次识别到某形态时，随身罩打出一行无人称现场记录：覆盖 / 基体 / 占位（占地加主感知）分开展示。新基体短名（残茎 / 栏柱 / 灰幕 / 余响 / 散光 / 间距）走同一套分节点，禁止粘成复合传奇名。成句用已锁污染侧强调。同身份短时间不刷。无头上名字。逻辑以句法 spec 为准。出击已接（体验未验证）。

## 概述

污染句法会生成海量可读变体。世界必须能教孔谱，但人还需要强化「刚才遭遇了什么」。头上挂名会把裂隙变成 RPG 名牌场，也挡迷雾里的身体。本表面用**一行现场记录**在识别当下报身份，然后闭嘴。

本文件是污染句法的识别表面合同，不是另一套玩法系统。形态怎么生成、玩家怎么认出遭遇了什么，叙述在设计正文 §7；规则在句法 spec。

只在裂隙出击。净化点没有。练习场默认不开（不是出击）。打开方式不是按键——满足「遭遇」条件就出现，限频挡住连刷。

## 约束来源

- 世界观（`world.md`）：污染是改写。文本冷峻、无人称、不写「你」、不写玩家感受。敌人命名 = 覆盖程度/行为特征 + 基体，禁止传奇称号。简述 ≤15 字、详细 ≤40 字。禁止感叹号、诗意、软件词。
- 美术 / Kit（`art-direction.md` §6、`docs/design-notes/ui-art-overhaul.md`）：裂隙读数是随身装置；屏幕空间挂 `#dom-ui-root`；字默认 `12px 'Courier New'`、`#c8cdd4`、可读性晕 ≤2px。成句强调只用已锁污染侧 teal（`#2ae6c8` / `#1aad96`），禁止新色。禁止圆角卡片、禁止 14px 自造档（混乱阈值旁白已因此被记偏差）。
- 既有通道：`#toast-inline-queue` 是拾取 / 开局残留 / 短闪，不是识别日志。混乱阈值是全屏闪 + 居中句，已被记文学化，**本表面禁止抄它的占位与文案腔**。

## 载体决策（第一步，不可跳过）

**本模块的载体**：**A. 世界内装置**  
**理由**：这是裂隙随身罩在外来模式进入可识别距离时打下的现场记录行——角色带着的那台勉强还能工作的记录仪在吐字，不是游戏外通知，也不是净化点墙机。  
**屏幕空间还是世界坐标**：屏幕空间。挂 `architecture.md` 声明的 overlay 根 `#dom-ui-root`。禁止 Phaser 角锚、禁止挂 `document.body`、禁止钉在敌人精灵上方（那就是头上名字）。

只有主菜单 / 设置允许元界面。本表面不是 C，禁止做成 Windows toast / 成就解锁框。

从 `docs/design-notes/ux-references.md` 取气质；识别动作另锚护甲/日志，不锚卡牌旁白。

## 屏幕流

```
[踏入裂隙] → 本表面静默
    → 某形态进入「遭遇」→ 若通过限频：打出一行记录（不暂停、不挡键）
    → 停留约 2.5s 后熄
    → 同一身份在冷却内再遭遇：静默
[撤离 / 阵亡] → 销毁；冷却表丢弃（裂隙状态不存档）
```

无子屏、无打开键、无确认。与屏缘干涉可同时存在（一个贴缘、一个贴底栏上方）。与混乱阈值重叠时：**等阈值层结束再打记录**，禁止两行居中大字叠在一起。

## 信息层级

玩家在这一拍必须回答：**刚才进视野 / 踩上 / 走进去的，是哪一种形态？** 不是血量，不是词缀表。

| 优先级 | 信息 | 原因 | 来源系统 |
| ------ | ---- | ---- | -------- |
| P0 | （本表面无常驻项） | 不占贴顶三槽；身份不是时刻要盯的压力条 | — |
| P1 | 识别行：覆盖深度、基体、占位（占地时加主感知），分开展示 | 遭遇当下才需要把组合读成「一种东西」 | 污染句法 |
| P1 | 成句标记（若有）：已锁 teal + 同一字号的错位强调 | 少数具名遭遇要从无名变体里跳出来 | 污染句法 `utteranceId` |
| P2 | 无。第一版不做图鉴、不做回顾列表 | 决策不靠翻历史 | — |

**U9**：覆盖 / 基体 / 占位（及可选的主感知、成句短标记）是**分开的节点**（各一个 span，间隙约 0.55em），禁止粘成「渗透门框墙缝体」或「覆盖余响占空」这种会被读成新传奇名的一句。前缀「识别。」是设备骨架，不算第四个身份词。禁止用间隔号 `·` 把节点堆成暗黑词缀串。表名 / 数值 / 档位本来就不在本行——本行只有短身份词，更不能再粘。

## 画面占用与不遮挡区

- 逻辑分辨率：960×640。
- **禁止占用区**：画面中心战场、玩家周围、屏缘干涉带、贴顶三槽、右下圆窗。
- **本模块占用**：底栏工具/键印**上方**一条，水平约 480px 内，偏左或居中靠下——是底边装置面，不是屏幕正中标题。
- **冲突**：不要进 `#toast-inline-queue` 和拾取 `+N` 抢同一队列语义。拾取短闪仍贴源。本行 `pointer-events: none`。

不写响应式断点。

## 交互模式

| 操作 | 输入 | 反馈 | 结果 |
| ---- | ---- | ---- | ---- |
| 遭遇 | 无按键。见下方触发 | 一行记录淡入；可选极轻机内嘀一声（第一版可无声）。禁止复用 `sfx-shared-chaos-threshold` | 写入该身份的冷却 |
| 跳过 / 关闭 | 无。不给「知道了」 | — | 超时自熄 |
| 冷却中再遇同身份 | 无 | 无新行 | 保持静默 |

键盘不是本表面的操作面。信息不得只在 hover 出现。

## 状态与条件（游戏语义）

| UI 状态 | 触发条件 | 显示 |
| ------- | -------- | ---- |
| 静默 | 未遭遇，或冷却中，或已撤离 | 无节点 |
| 记录中 | 通过限频的一次遭遇 | 一行可见，约 2.5s（淡入 200ms + 停留 + 淡出 300ms） |
| 等待阈值 | 混乱阈值全屏层仍在 | 排队；阈值结束后若仍在冷却窗内则**作废这次**（阈值优先，不补打） |
| 不可用 | 练习场 / 净化点 | 不创建本表面 |

没有「变灰」。冷却不是缺口，是故意闭嘴。

## 「遭遇」与限频

**逻辑真相**以 `docs/specs/system-contamination-lexicon.md` 为准。下文是本表面合同对同一规则的复述；冲突以句法 spec 为准。

**身份键**（限频用，不是给玩家看的内部键）：

- 有成句：`utteranceId`
- 无名变体：`coverage + substrate + occupancy + continuity`；占地时再加上主感知词素（否则渗透体与改写体撞键）。不把四条运动/节律/接触全编进键，否则几乎永不「相同」。止损不另进键（已由连续性 × 覆盖深度决定）。不上屏止损术语（打不死 / 更硬 / 更脆 / 打散重组）。

**遭遇触发**（第一次进入可识别，且通过限频）：

| 孔谱 | 可识别 |
| ---- | ------ |
| 甲占地 / 乙占墙 | 对该个体 `getVisibilityAt` > 0（与身体显隐同一套） |
| 丙占漆 | 玩家所在格踩在该漆上，或视野扫到该簇核 |
| 丁占空 | 玩家进入体积，或视野扫到核 |

持续留在可识别里（一直看着同一只）= **同一次遭遇**，不重复触发。必须先掉出可识别（看不见 / 离开体积 / 离开漆），再进来，才可能是下一次遭遇，且仍吃冷却。

**限频**：

1. 同一身份键：本趟出击冷却 **60s**（从该行开始显示起算）。冷却内静默。
2. 任意身份：两条记录之间至少空 **2.5s**（含上一条淡出）。
3. 同时只允许 **1 行**。
4. 出击结束清空冷却表。不进存档。

## 文案合同

骨架（设备打字，不是小说）：

```
识别。[覆盖深度] [基体] [占位]
```

占地加主感知节点：`识别。[覆盖深度] [基体] [占位] [视锥|听噪|…]`

节点与节点之间用空格或已有 HUD 间隔（实现：各 span + `margin-right: 0.55em`），**不要**用间隔号 `·` 堆成暗黑词缀串。不要「体」当后缀硬粘。不要把两个节点写进同一个 span。

成句：上面那行仍然出现；另加一个**短行为标记**节点（残余动词或孔谱课，≤4 字），用污染侧 teal、同一 12px、允许 1px 基线错位（记录仪被覆盖咬字）。**禁止**把设计暗号「门还想关 / 缝里的眼 / 簇的肺 / 走廊在看你」印上屏——那是内部配方名，传奇口吻。

映射（游戏内成句标记）：

| 内部配方 | 上屏标记 |
| -------- | -------- |
| 门还想关 | 开合 |
| 缝里的眼 | 缝视 |
| 簇的肺 | 呼吸 |
| 走廊在看你 | 反视 |

整行（含「识别。」）按详细描述计，**不超过 40 字**。各身份节点合计按简述精神控制，不要写成一段勘察报告。

禁止：你、感叹号、血量、词缀伤害、「新怪物解锁」「图鉴已更新」、软件词、止损设计词（打不死 / 更硬 / 更脆 / 打散重组）。

名称词素实现时走 i18n 碎片键，禁止在代码里写死一整句中文再反向导出。

## 止损怎么被读到（结构层；DEC-083）

玩家在遭遇当下必须能回答「这东西能不能杀、杀一个够不够」。这是绕 / 冲 / 杀的价目，不是图鉴条目。

| 优先级 | 信息 | 载体 | 不做什么 |
| ------ | ---- | ---- | -------- |
| P0（世界） | 可打核的有无与个数 | 世界内装置读数的身体：缝核 / 簇核 / 体积相。钉世界坐标，走引擎世界层，不是本行 overlay | 不在 HUD 加「可杀」灯 |
| P1 | 本表面现有分节点：覆盖 / 基体 / 占位（占地加感知） | 随身罩一行。覆盖深度间接区分更脆/更硬（渗透核露、覆盖核埋），连续性不另开节点 | 不上「打不死」四个字 |
| P2 | 无 | — | 不做图鉴「如何击杀」 |

打开方式：无。止损不是一块新面板。挥击扫到打不死个体：不白闪、不飘免疫字（战斗 V3）。

具名参考仍是本文件已锁三款。本要求明确不像：RPG 弱点图标 / 血条上的「免疫」标签 / 怪物图鉴击杀说明。

像素（核多大、多亮、怎么埋进覆盖）归 `docs/art/contamination-forms.md`，本文件不画。审美待人终审。

## 设计原则（本模块特有）

1. **世界可读仍是第一课。** 旁白是强化，不是让缝/簇/体积可以画成不可辨的色块再靠字救命。止损靠核的有无/个数读，不靠本行印设计词。
2. **头上无字。** 任何钉敌人世界坐标的名字、血条名、传奇飘字 = 不合格。
3. **限频是功能。** 同一形态刷屏等于没教。
4. **成句用已锁污染色跳出来，不用新色、不用更大字号。**
5. **不与混乱阈值抢腔。** 阈值是压力事件；本表面是识别日志。
