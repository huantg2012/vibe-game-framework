# UI/UX 设计：被发现 · 屏缘干涉

> **TL;DR**: 裂隙出击中，玩家随身罩的屏缘在威胁方向亮起干涉纹；强度跟该威胁的察觉度（0–1），形态跟五态（留意 / 搜寻 / 锁定）。无数字、无百分数、无条。最多叠 2 个方位。

## 概述

渗透体和改写体共用同一套察觉度。玩家需要在不看文档、不看敌人本体（视野外完全不画，`system-enemy-ai` R4）时，仍能回答：**有没有东西在注意我、从哪一边、有多急**。本表面把察觉度外化成屏缘方向脉冲，而不是雷达或数字条。

它只在裂隙出击中存在。净化点没有。打开方式不是按键——察觉度过线就出现，降回巡逻就熄。

## 约束来源

- 世界观约束（from `world.md`）：污染是改写。外来模式锁定玩家时，玩家尚未被完全覆盖的那一层会起干涉。术语：污染体 / 渗透体 / 改写体 / 混乱。禁止「侦测」「警报进度」「锁定中 73%」。本表面**几乎无可见词、完全无数字**。
- 美术约束（from `art-direction.md` 的 UI 节 / Kit）：裂隙常驻读数是随身装置，半透明、贴边、不挡中心。色只引用污染侧 teal（`#2ae6c8` / `#1aad96`）与已锁 ui 色。禁止新色、禁止圆角卡片、禁止投影当装饰。
- 本项目已验证基线（from `docs/design-notes/ui-art-overhaul.md`）：屏幕空间一律 `#dom-ui-root`；裂隙 HUD 贴顶三槽 + 底栏工具/撤离 + 右下圆形局部窗。本表面复用同一挂载根，**不套** `.game-panel`，可与 `.device-plate` 同族但不要做成第二块小地图。

## 载体决策（第一步，不可跳过）

**本模块的载体**：**A. 世界内装置**
**理由**：这是玩家裂隙随身罩边缘被外来模式咬出的干涉纹——角色在世界里带着的那层皮在响，不是游戏外的雷达软件，也不是净化点墙机。
**屏幕空间还是世界坐标**：屏幕空间。挂 `architecture.md` 声明的 overlay 根 `#dom-ui-root`。禁止 Phaser `scrollFactor(0)` 角锚（`camera.zoom ≠ 1` 会把四角甩出画面）。禁止新开 HUD 根、禁止挂 `document.body`。

> 当前进度文件曾写过「元界面边缘装置」——作废。DEC-064 + 本 D1 锁的是 **A**，不是 C。只有主菜单/设置才是元界面。

## 参考锚点（不可跳过）

从项目参考研究取气质与「装置自报」；屏缘方向这一动作另锚一款机制同构（学动作不学皮）。

| 参考游戏 | 锚的维度（学什么动作） | 明确不学什么 |
| -------- | ------------------------- | ------------ |
| Dead Space | 威胁在护甲/视野**边缘**给出方位；强弱用刻痕疏密/亮度，不报百分数 | 全息脊椎、数字生命、科幻外发光条 |
| Barotrauma | 承压时是**这台机器自己**用闪、亮、节奏报严重度，不是弹出「系统错误」 | 精密指针仪表、整屏管线拟真 |
| Signalis | 读数是随身设备上的一块内容，不是浮在游戏外的软件层 | 显像管曲面畸变、检视仪整页 UI |

**本屏不像**：雷达圈 / 小地图光点堆 / Windows 通知 toast / 后台进度条（「察觉 73%」） / 准星旁数字条。

## 屏幕流（Screen Flow）

```
[踏入裂隙]
    → 裂隙 HUD 常驻（完整度 / 混乱 / 薪柴 / 工具 / 圆窗）
    → 本表面：默认静默
         察觉度过线 → 屏缘干涉出现（不暂停、不挡键）
         全部威胁回到巡逻且察觉度掉下熄灭线 → 静默
[撤离 / 阵亡] → 销毁，不带到净化点
```

无子屏、无打开键、无确认。

## 信息层级（每屏）

### 裂隙出击 · 屏缘干涉

玩家必须零操作回答的问题：**哪边在注意我？现在是留意、在搜，还是已经锁定？**

| 优先级 | 信息 | 原因 | 来源系统 |
| ------ | ---- | ---- | -------- |
| P0 | 最多 **2** 个屏缘方位脉冲 | 被发现的方向是撤退/停步决策的输入；R4 下本体可能不可见 | `system-enemy-ai` `getPosition` / `getDetection` / `getState` |
| P0 | 形态三档：留意 / 搜寻 / 锁定（无可见表名；用疏密、亮度、节奏编码） | 同一方位上，「它好像听见了」和「它正朝我跑」必须能分开 | FSM 状态 |
| P0 | 强度 = 该威胁察觉度 0–1（映射到亮度/厚度/脉冲速率，**不上屏任何数字**） | 反悔窗口（察觉累积）必须外化，但不能做成百分条 | `getDetection()` |
| P1 | 无 | 不靠走近、不靠一键 | — |
| P2 | 无。禁止把察觉度放进检视面板或 debug 默认开 | 决策信息不得进 P2 | — |

> **组合规则**：本表面**没有表名、没有数值、没有档位词**。三档形态用形状/疏密/节奏分开展示，禁止写成「察觉搜寻中」一类粘串。禁止「察觉 73%」。

P0 项数：方位 ×1–2 + 形态编码（叠在同一刻痕上，不另占一项）≤ 6。

## 画面占用与不遮挡区

- 目标逻辑分辨率：960×640。
- **禁止占用区**：画面中心；玩家周围可视区（中心约 ±160×110 逻辑 px）；贴顶裂隙 HUD 三槽带（顶边向下约 36 px）；底栏工具槽与 `[E] 撤离`；右下圆形局部窗（含其 `.device-plate` 外沿）。
- 本模块占用：四条屏缘内侧一条窄带（建议厚度 12–20 逻辑 px，Art 定像素）。脉冲贴**最近那条边**的对应方位，不伸进禁止占用区。顶边与底边只使用 HUD/底栏**没有占用的中段空隙**；右下圆窗所在角不画第二套雷达。
- 与已有 UI 的冲突检查：不是小地图替代；圆窗继续只标撤离/探索，不画本脉冲。不要在准星或角色脚边再叠一层。

## 交互模式

| 操作 | 输入 | 反馈 | 结果 |
| ---- | ---- | ---- | ---- |
| 无主动操作 | 无。不绑定任何键 | 干涉纹自己亮、变、熄 | 不暂停、不吃键、`pointer-events: none` |
| 停步 / 进掩体 / 甩掉视线 | 既有移动与潜行 | 强度随察觉度下降；形态从锁定→搜寻→留意→静默 | 与 FSM 降级链一致 |

- 键盘是第一公民：本表面不增加键。
- 不依赖 hover。没有任何信息只在指针悬停时出现。

## 状态与条件（用游戏语义命名）

| UI 状态 | 触发条件 | 显示内容变化 |
| ------- | -------- | ------------ |
| 静默 | 没有合格威胁（见下「选威胁」） | 不绘制 |
| 留意 | 合格威胁的 FSM 为巡逻或警觉（suspicious），或仅有察觉度、尚未升态 | 疏、暗、慢。强度随察觉度 0.15–1.0 |
| 搜寻 | 该威胁为警戒（alert） | **更密、更亮、更快**（游戏语义：它在找） |
| 锁定 | 该威胁为追击（chase） | 最密、最亮；节奏改为急促且几乎常亮（游戏语义：它看见你了）。强度按察觉度，追击中察觉度不衰减故顶格 |
| 熄灭 | 该威胁降回巡逻/归位且察觉度 < 熄灭线 | 该方位消失；另一方位仍可独立在 |

归位（return）读作巡逻：不显示该敌人的脉冲（与 `system-enemy-ai` R1/R2「归位不显示警戒指示」一致），除非察觉度仍 ≥ 显现线（罕见；若发生，按留意）。

### 选威胁（写死，不再问）

1. 候选：`detection ≥ 显现线 0.15`，或状态 ∈ {suspicious, alert, chase}。
2. 排序：先按察觉度降序，同值时按状态阶 chase > alert > suspicious > patrol。
3. 方位合并：两个候选的屏缘方位夹角 < 28° 则合成一条，取察觉度较高者的强度、取较高状态阶的形态。
4. **最多画出 2 条**。第三条及更弱的丢弃——不画成雷达点阵。
5. 不采用「只显示察觉最高者」：渗透体从右侧看见你、改写体从左侧听见你时，两条判断必须同时在。

显现/熄灭用滞回：显现 ≥ 0.15，熄灭 < 0.10，避免闪烁。

方位算法（结构，像素归 Art/code）：威胁世界坐标相对玩家的方向 → 与摄像机同一套变换 → 与 960×640 逻辑框四边求交 → 落在最近边上。不跟 zoom 漂移（因为挂在 `#dom-ui-root`，与画布 letterbox 对齐）。

## 设计原则（本模块特有）

- **方向是信息，数字不是。** 玩家读方位和形态，不读百分比。
- **两条潜行判断都要能指到。** 改写体可以在视野外用听觉推高察觉度——此时脉冲往往是唯一预警。
- **第一可读信号仍是敌人行为**（停下转身）。脉冲是行为不可见（R4 / 屏外）时的补通道，不是替换。
- **UX 不制造机制里没有的犹豫。** 不提供「标记威胁 / 切换显示」选项。

## 视觉规格（Art agent 填写）

结构层锁死：无数字、无表名、无百分条、最多 2 方位、三档形态（留意疏慢 / 搜寻更密更亮更快 / 锁定急促近常亮）、色只引用已锁污染 teal、挂 `#dom-ui-root`。

### 组件样式

| 组件 | 状态 | 样式描述 | 世界观关联 |
| ---- | ---- | -------- | ---------- |
| 屏缘干涉纹 | 静默 | Art A1 补 | 随身罩未被咬到 |
| 屏缘干涉纹 | 留意 | Art A1 补 | 外来模式刚擦到边缘 |
| 屏缘干涉纹 | 搜寻 | Art A1 补 | 改写正在找宿主 |
| 屏缘干涉纹 | 锁定 | Art A1 补 | 模式已经对上 |

### 排版

- 无字。若 Art 必须加装饰像素，不得形成可读数字或「ALERT」英文。
- 世界观关联：不是哪台机器打出来的**字**——是罩皮上的纹理在闪。

### 动效

| 触发 | 动画 | 时长 | 缓动 | 世界观关联 |
| ---- | ---- | ---- | ---- | ---------- |
| 显现 | Art A1 补 | 建议 ≤ 200 ms | Art 定 | 干涉突然咬上，不是淡入卡片 |
| 形态升级 | Art A1 补 | 即时或 2 帧（art-direction UI 状态变化） | — | 状态跳变，不播一段过场 |
| 熄灭 | Art A1 补 | 建议 ≤ 180 ms | Art 定 | 模式松开 |

### 复用声明

- 挂载：`getDomUiRoot()` / `bindDomUiRootToGame()`。建议根下 `#rift-detection-rim`，`pointer-events: none`。
- 不套 `.game-panel`。不要新造第二套色板。
- 新增基元（纹的具体画法）由 Art 定后写入 Kit 一行，禁止面板内联一套霓虹。

## 结构层自检（design，SKILL 画完自检 1–3、5、7–8）

1. 载体 **A**。屏幕空间挂 `#dom-ui-root`，不另起 body、不用 Phaser 角锚。
2. Dead Space（屏缘方位、强弱无百分数）/ Barotrauma（机器用闪与节奏自报）/ Signalis（随身设备上的内容）。本屏不像雷达、toast、后台进度条。
3. P0：≤2 方位 + 叠在同一纹上的形态。无操作截图应能读出「哪边」和「急不急」；本表面故意无数字。
5. 无「不可用」控件。静默 = 没有威胁，不是灰掉的按钮。
7. 打开方式 = 察觉度/状态过线，不是玩家打开面板。阻断确认 0 条。
8. 无可见词。不新增键。
