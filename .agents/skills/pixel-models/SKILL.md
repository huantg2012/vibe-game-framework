# 像素模型：世界内物体怎么画

口号「要像这个游戏」不够。本 skill 是 **HOW**：教 agent 按本游戏已锁像素模型来画世界内实体，而不是靠会话记忆发明描边和色板。

抽卡**决策循环**（机制先锁 → 完整组合 → 对比课 → 人抽 → DEC）住在 [visual-card-draw](../visual-card-draw/SKILL.md)。本文件只管**怎么画**。像素抽卡两份都要 Read：先流程，再画法。

HUD / DOM / 蒙层走 [in-game-ux](../in-game-ux/SKILL.md)。世界内像素实体走本文件。

自定义 agent **不会**自动加载 skill。被派到像素模型 / 像素抽卡时必须显式 Read 本文件；Director 的 Task Brief 必须写明这一步。

已锁范例、学什么 / 不学什么、闸门命令见 [exemplars.md](exemplars.md)。色板 hex、画布表、禁忌全文**不抄进本文件**，按文末指针去读。

## 适用 / 不适用

**适用**：世界内像素实体、精灵图集、程序像素、像素抽卡卡面、对比课里的物体（不是侧栏）。净化点装置、玩家、裂隙内可交互物、薪柴 / 翻堆、入口一类世界物体都在这里。

**不适用**：

- HUD / DOM / overlay / 菜单 → `in-game-ux`（薪柴**计数**的 warm-dim 是 UI，不是世界内实体色）
- 抽卡流程本身（几张卡、何时翻生产、何时删课）→ `visual-card-draw`
- 连续地面大面积烤漆细节 → `docs/art/rift-fragment-surfaces.md`（本 skill 只收物体与地面交接的纪律：物体外沿必须是面色；成片青绿 = 有主占漆，不是装饰）

## 因果链：本质 → 形体剪影 → 世界观 → 外观

**这一节是本 skill 的脊梁。下面所有闸门都是在保护这条链。**

```
本质（它到底是什么东西）
   ↓  收窄（不是唯一映射：排除掉一大片，剩下的仍有多个）
形体剪影（它怎么占空间：载体平面 + 体量 + 第一眼的轮廓）  ← 抽卡在这一层抽
   ↓  乘上
世界观（谁造的 / 用什么造得起 / 什么工艺 / 维护成什么样 / 光从哪来 / 颜色意味着什么）
   ↓  才得到
外观（材质、明度梯度、色、磨损、活层）
```

三件事必须记住：

1. **本质是过滤器，不是函数。** 它把形体空间切成「不成立」和「成立」两半——**但成立的那一半里通常还有好几个都对，那个剩余空间就是可抽卡的空间。**

   两头都是错的：

   - 先挑一个好画 / 好看的形体，再给它编一个本质 → 发明场景里不存在的东西（裂隙入口连废六张就是这样：凭空造了一段墙）。
   - 反过来，拿「本质唯一决定形体」当借口只做一个形体就交差 → 该抽的没抽，把选择权从人手里拿走了。

   **形体是抽卡的合法第一轴。** 项目里的现成反证：裂隙入口的本质锁是「伤口渗漏，不是门」——它排除了立着的体积、排除了门框，但**卡 4 地缝与卡 5 击裂都落在成立范围内，人最后两张都留了**（DEC-113）。同一个本质，两个都对的形体。供奉台同理：本质锁「收容 + 控制 + 暴露」排除了没有敞面的封闭罐（那是储藏）、排除了祭坛与香炉，但方块 / 横伸 / 竖高 / 贴地四类**都能同时读出这三件事**，所以四类都是合法取值。

   本质要做的事只有一件：**把不成立的形体挡在门外，并说清为什么。** 挡完之后剩几个，就抽几个。
2. **同一个形体，在不同世界观下是完全不同的东西。** 「矮槽 + 偏心压板」这个形体：放进奇幻是石棺或祭坛；放进硬科幻是低温舱或检修口；放进本作，它必须是混凝土浇的槽 + 回收钢板 + 长短不齐的螺栓（手头有什么用什么）+ 没有环境照明 + 全身几乎无色。**形体对了但世界观没喂进去，产出就是「通用科幻皮」**——那是本框架在 UI 上翻车过的同一个病，只是换到了像素上。
3. **链上任何一环断了，下游全废，而且机器闸门查不出来。** 已经实测过三次「闸门全绿但人否掉」，三次断在不同环节（见 [exemplars.md](exemplars.md) 的「三次全绿但不合格」）。闸门只能证明「没犯已知的错」，证明不了「链是通的」。

链是**单向**的。不许倒推：不许从旧卡反推本质，不许从 AI 生成图反推本质，不许因为「这个形体好画」去改本质。

## 开工闸门（缺一步不许画）

书面写完再动笔。缺任一项 = 停工。步骤有名字，**引用请用名字，不要用编号**（编号会随 skill 增长而变）。

### 1. 本质锁（并当场划出形体的成立范围）

先一句话：**它在世界里是什么**，不是长什么样。对照：储藏锁的是「收容体」；入口锁的是「伤口渗漏，不是门」。禁止从旧卡或 AI 图述反推。

**然后必须往下走一步：用这句本质划出形体的成立范围，并写下推理。** 注意划的是**范围**不是单点——本质是过滤器不是函数（见因果链第 1 条）。书面答三问：

- 这个本质**要求**什么？（伤口要求没有框；收容体要求封闭；「要挨压」要求有朝外的敞面）
- 这个本质**排除**什么？（伤口排除立着的体积；只关不开排除敞口；「暴露」排除全封闭的罐）
- **于是哪些形体成立？** 列出来，通常不止一个。只列得出一个时要警惕：是本质真的这么紧，还是自己想象力不够——回头用下面的手法再找几个。

只写本质不划范围，等于把最关键的一跳留给随手发挥；只划出一个点，等于替人把卡抽了。

**在成立范围内找候选形体的三个手法**（启发式，不是穷举）：

1. **让本质的不同分量主导剪影。** 供奉台的本质是「收容 + 控制 + 暴露」三件同时成立——三个分量都在，但让不同分量说话最大声会长出完全不同的形体：暴露主导 → 把东西举出去（横向外伸）；控制主导 → 箍死在柱子上（竖向细高）；收容压制主导 → 压板压死在槽里（贴地矮宽）。**没指定主导分量，就会默认落回最平庸的那个形体。**
2. **换载体平面**（前提是本质允许多种）。地面平面内 / 立着 —— 这一跳最能改剪影。
3. **换体量分布。** 方块 / 横伸 / 竖高 / 贴地，见下面「形体可以抽，但要落在成立范围内」的判据表。

候选凑齐后再逐个回头验：**它还落在成立范围里吗？** 落在外面的删掉，不要为了凑数把本质放宽。

### 2. 声明载体平面，再声明相机

**载体平面选错，像素画得再好也不成立。** 这是实测代价最大的一条：裂隙入口连续两轮共六张全废，共同病根就是把「时空的伤」画成「一段墙被弄坏」——而那个位置根本没有墙（净化点边界是变暗带 → 力场膜 → 虚空）。凭空造一段内壁 = 发明场景里不存在的建筑。

先答两问：**它长在什么上面？**（地面 / 已有实体 / 空气）**它是躺着还是立着？** 然后查表：

| 载体平面 | 谁在用 | 像素怎么画 | 锚点 / 层 |
| -------- | ------ | ---------- | --------- |
| **地面平面内**（与地面纹理同一平面，顶视） | 裂隙入口（卡 4 地缝 / 卡 5 击裂，DEC-113）、裂隙占漆 | 缝 / 渍 / 漆直接画在平面里，**不做竖直体积** | 锚点取**中心**；层压在地板之上、玩家之下（`ENTRANCE_DEPTH = 1`） |
| **立着 · 正对 + 向下俯视 10°** | 立在地上的世界物体（人锁的入口相机曾用于此） | 前脸近竖立，顶面只露一条窄带 | 锚点取**脚底**；层与读数桩同层 |
| **立着 · 45° 等距**（顶面旋转 45° + 压缩） | 已锁三台：核心 v6-B、净化器 B1、储藏 C1 | `iso_prism` 只填面 | 同上。**已锁三台不要改相机** |

**地面上的东西必须画在地面平面里。** 按「立着」的相机画会被压没：下俯 10° 时一格进深只换来 0.17 行，一道地缝几乎看不见。反过来，把立着的东西画进地面平面会丢掉体积。

**禁止默默混用。** 一件对象一个平面，写进身份锁。PLAN 文首「45° + 面分隔线」是那三台装置的历史公约，不是全对象默认。分隔线的合法读法 = **邻面不同色**，不是第三色描圈。

架构后果登记在 `architecture.md` DEC-ARCH-019。

### 3. 声明画布尺寸（层级）

写出宽×高，以及它在同场物体里比谁大、比谁小。填充物：`docs/art-direction.md` §3.2、PLAN 统一约束第 2 条、`docs/art/actor-pixels.md` 画布表。不要为练习场另开一套尺寸。

### 4. 喂世界观输入（形体 → 这个世界里的那个东西）

**形体定了还没完。同一个形体在不同世界观下是完全不同的东西**（见上面因果链第 2 条）。这一步把形体变成**本作**的东西，不是通用科幻 / 通用奇幻的东西。

书面答六问。答案只许从 `docs/world.md`「对美术的约束」+ `docs/art-direction.md` 取，不许即兴发挥：

| 问 | 为什么问 | 本作净化点的答案（**读 world.md 核对，不要背这一列**） |
| -- | -------- | -------------------------------------------------- |
| **谁造的？** | 决定工艺水平与形制合理性 | 守着净化点的人自己造的，不是工厂出品 |
| **用什么造得起？** | 决定材质档位 | 金属、混凝土、功能性工业材质。手头有什么用什么 |
| **什么工艺？** | 决定边缘是否精密、部件是否对称 | 够用就行，不是精加工。**长短不齐、不对称是对的** |
| **维护成什么样？** | 决定磨损的读法 | **磨损但有人维护**——不是废弃遗迹，也不是崭新 |
| **光从哪来？** | 决定有没有环境照明、暖色能出现在哪 | 灯光微弱但存在；唯一的暖色是功能性光源，面积要能答「指示」 |
| **颜色意味着什么？** | 这条最容易漏，也最要紧 | **黑暗是底色，颜色是入侵——有颜色的地方就是被污染的地方；「干净」体现为颜色的缺席。** 所以装置本体几乎无色；青绿不是装饰，是「这里有外来的东西」 |

关键词也要抄一遍再画（净化点：孤立、微光、功能性、空旷、安静、**勉强维持**）。「勉强维持」直接落到像素上：形制看起来是**够用**而不是设计精良，允许有加固与补丁的痕迹。

**世界观没喂进去的症状：** 形体读得出、闸门全绿，但整件看起来可以出现在任何一款游戏里。这时不要去调色，回来把这六问答完。

### 5. 锁定色板

只许 `docs/art/palette.json`。列出本对象要用的色板**名**。禁止会话发明 hex，也禁止把已锁生产图上的历史 hex（核心 / 净化器的 `CORE_*` / `MET_*`、玩家身体灰）当成新对象的色板。新格 = art 提案 + 人拍板 + DEC + 全链路传播。本 skill 不授权新增格。已锁三台与已锁玩家不要为「对齐色板」去改生产图。

色板是上一步的**下游**：先定「用什么造得起」，再从板里挑对应材质的格。反过来先挑好看的格再编材料 = 世界观没喂进去。

### 6. 钉 2–3 个具名参考

表：游戏名或已锁生产对象 | 学什么动作 / 体积 / 材质 | 明确不学什么。只写「学核心」而不写「学 `iso_prism` 只填面」= 停工。项目参考入口：`docs/art-direction.md` §1.5。已锁像素锚点见 [exemplars.md](exemplars.md)。

### 7. 若是抽卡：先走 visual-card-draw 步骤 0–1，再声明每张卡取的是哪个形体

机制没锁不开画。每张卡是完整组合，不是变量排列。

**然后答一问：这几张卡是几个不同的形体，还是同一个形体的不同实现手段？** 后者 = 白抽。每张都必须落在本质锁划出的成立范围内。见下面「形体可以抽，但要落在成立范围内」。

### 8. 声明落地底

写出对照与验收叠在哪：净化点混凝土，还是某张碎片的烤地。对照课必须用这个底，禁止只在纯黑卡纸上判断描边。

## 画法定律（可执行约束）

1. **硬边、透明底、1:1 真尺寸、可进游戏。** 不是页面示意图，不是抗锯齿概念图。最近邻缩放。产出必须能直接当精灵 / 图集用。
2. **只许锁定色板。** 最终不透明 RGB 必须能在 `palette.json` 找到同一格。禁止会话发明 hex，禁止抄已锁核心 / 净化器 / 玩家身上的历史 hex 当新色。
3. **剪影像素 = 那个面的填色。** 先填可见侧面和顶面，然后停。禁止物体外再描一圈更深的第三色。`INK` / `VOID` / `SHADOW` / 深 clinic 当外沿都算描边。把描边换成另一种深色（换色描边）= 不合格。深色只许落在包围盒最底 3–4 行接地斑，不许爬上墙棱。
4. **体积 = 邻面明度差。** 有明确多面的装置：顶亮、前中、侧暗；侧面不得与顶面同亮。不是渐变、不是 mottle 灰阶量化、不是第三色描圈冒充分隔。玩家是密像素分件（面罩 / 背包 / 分腿），不要套 `iso_prism`。薪柴翻堆是残骸堆（渍缝 + 高光条 + 底影），不是棱柱。
5. **结构钉死，只动活的那一层。** 装置：框 / 罐 / 井逐帧相同；能动的只有窗内介质、口内光幕、灯、被关住的鼓包。玩家：四向换贴图 + 灯尘上飘，允许 1 像素步态形变，不要扭骨架去「呼吸」。翻堆：堆外形不随内容物变；翻找时只许碎屑 / 揭晓粒子动。
6. **暖色稀缺，按侧分工。** 裂隙内世界实体不带暖光源。净化点装置允许极小功能暖灯（面积要能答「指示」，不能答「好看」）。玩家灯是人类侧唯一高亮。薪柴世界内实体属污染侧：teal 余晖，不是壁炉橙火；核心烧薪柴时，光与污染同源（teal）。残骸材质色三格是世界材料、哑不光，口径见 `art-direction.md` §2.3 规则 8 注 2——不要写成光源。
7. **青绿 = 外来模式 / 污染 / 薪柴余晖。** 不是装饰霓虹，不是玩家签名，不是堆皮上的「这里有燃料」。成片青绿在地面上 = 有主占漆。污染侧不要暖色。翻堆主体走残骸材质，teal 只出现在揭晓，不画在堆皮上。
8. **活层青绿有三种画坏法，都是实测撞出来的。** 逐格隔一个点 = 一串小灯；整条 / 整面铺亮 = 霓虹；绕着一个口走满一圈 = 传送门。正确写法：连着一段、段间断开，主体压在最暗两档（`contam-deep` / `contam-mid`），只有几格在走；要么从一个点往外淡出、可达半径随帧呼吸。青绿**只许在缝里 / 口里 / 凹进去的面里**——一贴到透明背景就读成涂上去的荧光线。
9. **不旋转 GameObject。** 四向靠换贴图。四向都是直立（头在画布上方）。45° 与正对 10° 是**画进贴图的投影**，不是运行时去转精灵。无四向的装置也禁止用旋转摆出 45°。
10. **可见像素要在将要落地的场景底上读得出。** 净化点装置叠在净化点混凝土（生产地板主色见 exemplars），裂隙实体叠在该次出击烤地。不要只在纯黑底上判断描边。PLAN「可见像素明度 ≥ 45（对 `#0d1114`）」只适用于那三台装置对着环境暗部看会不会溶掉，**不是**混凝土地面合同，也不是裂隙烤地合同，更不要套到裂隙甲身上。裂隙堆 vs 地面走 `check:loot-pile-contrast`（见 exemplars）。

## 45° 等距的实现陷阱（都是实测碎过的，不是理论）

这些坑的共同点是**数学上对、像素上碎**。一格进深在 45° 下只换 0.5 横 × 0.275 纵，所以任何"细"的东西都会掉到亚像素以下。

| 陷阱 | 症状 | 怎么做 |
| ---- | ---- | ------ |
| **斜梁沿垂线逐格 `put`** | 梁身漏成一串点，读成噪点 | 45° 斜线的单位垂线四舍五入成 `(+1,-1)`，加上去得到的是**隔一格**的平行线。必须**填面**（`fill_poly` 出带宽的四边形），再画顶棱 / 底棱 |
| **小于约 2 格进深的 `iso_prism`** | 侧面不到一像素被丢掉，只剩一颗顶面**浮在空中** | 桩 / 耳 / 螺栓 / 拉杆这个尺度的零件在**屏幕空间**画成 2 像素粗的短条 |
| **挂件锚点钉死行号** | 一改主体尺寸，耳朵 / 栓就浮空 | 45° 下同一件东西的左右两端**不在同一行**（左端高、右端低）。锚点必须用 `iso()` 从主体几何算出来 |
| **可见侧面上抠不出开口** | 凹槽被鳞边 + 内缘吃到只剩一格活层 | 前左面的可用宽度 = **dx 跨度 × 0.5**。鳞边和凹槽内缘各吃一圈，所以面宽 < 8 像素基本抠不出口（实测 5 像素 → 活层只剩 1 格）。要开口就沿 dx 把体量拉长、把进深压薄 |
| **磨损 / 指示灯直接 `put`** | 一颗漆浮在空中，读成噪点 | 统一走一个只落在已有实体上的守卫函数 |

顺带一条不属于 45° 但同源的：**从顶面往下切角、从侧面往里挖口，都要先算出边界再切**。凭坐标范围硬清一片，容易把主体切断（实测把柱身切成两截）。

## 剪影误读清单（实测撞过的，别再撞）

小尺寸下剪影会被自动归类到最近的熟悉物体。这些都是本项目真实被否掉的读法：

| 画了什么 | 被读成 | 怎么破 |
| -------- | ------ | ------ |
| 光滑对称的纺锤 / 椭圆 | 一只眼 | 上下缘不对称，岔出支线 |
| 四根对称的支撑 | 四条腿 → 一只虫子 | 改三根、不对称、不等高 |
| 立柱顶端与主体齐高 + 横向连杆 | 灯笼 / 门框 / 神龛 | 主体要高过立柱顶；连杆只在下半截 |
| 碎成一格一格的顶沿 | 绒毛 / 苔 | 顶沿做平，只在两三处断档 |
| 等角均分的放射线 | 车轮辐条 | 角度与长度都不等分 |
| 一大团深色 | 墨点 / 污渍 | 团压到两三格，其余靠细线 |
| 又多又细的放射线 | 蜘蛛 | 减少条数、拉长、只留一条环向弧 |
| 宽矮的块 + 顶面亮带 | 箱子 / 板条箱 | 加高、破对称、让它长进地里 |
| 填实的深色椭圆压在底部 | 花盆 / 底座 | 换成短放射地裂 + 断口亮棱 |
| 环绕一个洞的连续亮圈 | 传送门 / 舷窗 | 亮只留一段弧；洞形不规则 |
| 紧凑封闭块 + 高处一块矩形青绿 | 一张脸；青绿劈成两块就是**两只眼** | 让爪 / 齿 / 指**越过**发光物往上伸，剪影顶端是岔的；青绿逐行宽度不等 |
| 立柱顶端安一个比柱粗的部件 | 图腾 / 路灯 / 柱头 | **柱顶必须高过那个部件**，让柱子从它身上穿出去 |
| 一像素宽的悬腿（哪怕只两三根） | 虫腿 / 噪点 | 至少 2 像素宽、只留两块、长短不等 |
| 又高又暗的附件（配重 / 罩 / 背板） | 一片黑帆盖过主体 | 压矮，并给附件**自己的三级明度**，不要让它整片落在最暗档 |

判断办法：把 1:1 的图缩到实际观看尺寸，问「第一眼像什么」，不要问「像不像我想画的」。

这张表会继续长。**引用它请按名字，不要按行号**——按行号引用，将来有人往中间插一行，所有引用会静默变成谎言。

**青绿的形状本身会引发误读，不只是位置。** 整齐矩形往高处一放就是眼睛或屏幕；这条与画法定律第 8 条（一串小灯 / 整条霓虹 / 满圈门环）是同一件事的不同方向：活层必须长得**不规整**。

## 抽卡场景怎么用本 skill

流程归 `visual-card-draw`：完整组合、真实上下文对比课、打开即播带动效、人没抽不翻生产、落选整支删除、人抓回必须沉淀定量闸门。

### 形体可以抽，但要落在成立范围内

**形体是抽卡的合法第一轴。** 本质把形体空间收窄，但不收成一个点（因果链第 1 条），剩下的成立范围就是抽卡空间。抽卡要做的是在这个范围里取几个**互不同类**的形体。

**不能抽的是「同一个形体的不同实现手段」。** 实测（供奉台第一轮，2026-09-04）：三张卡分别声明了夹 / 围 / 浇三种收容手段，本质锁、相机、色板、十二条闸门全部合规，三张也确实不一样。人的评语是「**三个卡本质上是同一个方向只是调整了大小，区分度非常低**」。

按因果链诊断：夹 / 围 / 浇都是「一个把东西关起来、再开一面」的容器，**三张的形体是同一句话**——竖立的实心块 + 某个可见面开个洞。手段属于表面处理，在 32×32 上只值几像素纹理差，不构成第二个剪影类别。第二轮改成让本质的不同分量主导，四类形体就分开了。

所以三层要分清，只有中间那层适合当第一轴：

| 层 | 例子 | 能不能当抽卡第一轴 |
| -- | ---- | ------------------ |
| 本质 | 「伤口渗漏」vs「一道门」 | 通常是**人锁死的前提**，不在画法层抽。未锁时属 design / ideation 的活 |
| **形体** | 地缝 / 击裂；方块 / 横伸 / 竖高 / 贴地 | **可以，而且应该。** 只要每张都落在本质的成立范围内 |
| 实现手段 / 表面处理 | 夹 / 围 / 浇；纹理、材料细节 | 不行。区分度在小尺寸上趋近零 |

**形体类闸门的作用是检测塌陷，不是禁止抽形体。** 本质塌成一个、或者几张卡其实是同一个形体换皮时，形体类必然撞成一类——而形体类可以被量出来，本质不行，所以用它反查。

四类的判据（本项目当前标定）：

| 形体类 | 第一眼 | 机器判据 |
| ------ | ------ | -------- |
| 方块 | 竖立的实心块，开口在某个可见面上 | `0.58 ≤ aspect ≤ 0.90` 且 `\|shear\| ≤ 0.12` |
| 横伸 | 重心与体量偏向一侧，长臂把东西送出本体之外 | `\|shear\| ≥ 0.20` |
| 竖高 | 细柱贯到顶，功能件套在中段 | `aspect ≤ 0.56` |
| 贴地 | 几乎不往上长，横向铺开，开口朝上 | `aspect ≥ 1.05` |

`aspect` = 材质包围盒宽 / 高（去接地两行、去近黑地裂）。`shear` = (上半重心 x − 下半重心 x) / 宽。

**为什么用 `shear` 而不是整件重心：** 整件重心抓不到悬臂式对象。长臂往左上伸，底座与配重把它配平了，整件重心仍然居中（实测 +0.022），只有上下两半错开才看得出（−0.311）。这是判据要写成**物理量**而不是直觉的又一个例子。

四个区间互斥，所以这条闸门能抓住「换了名字没换形体」。落地时要**验证它会咬人**：把横伸那张谎称成方块，闸门必须立刻红。

**闸门红了的时候，回成立范围里另找一个形体，不要把手上这张拉长拉扁去骗阈值。** 两张卡撞同一类，说明它俩其实是同一个形体换皮；硬掰过去得到的是一张没有理由的图。正确做法是回本质锁那一步，用三个手法（分量主导 / 换载体平面 / 换体量分布）再找一个**本来就成立**的形体。

上面的四类和数字是本项目当前的取值，新对象可以增类，但**必须先写判据再画**，不许画完了回头调阈值把自己放过。

本 skill 负责：

- 每一张卡的物体服从上面的画法定律与开工闸门。
- 对比课背景必须是**将要落地的场景底**（净化点混凝土 / 裂隙地面），不是纯黑、不是另一套练习场渲染。
- art 逐卡最短核：身份锁 + 声明相机 + 外沿是面色 + 色在板内（没有抄历史 hex）。人点名「学核心 / 学净化器」时这四件必须书面答。只核不改。不代勾好看。
- 人抓回的描边 / 平色 / 相机混用，修复时必须补或扩一道机器闸门。只修本体不补闸门 = 未完成。
- **闸门要按对象类别分套，判据要写成物理定义。** 实测的误判：
  - 「外沿深边」用**全局中位数**做基准，在双材质对象上会误报（一半深混凝土 + 一半浅地层 → 误报 25%）。正确定义：**描边 = 外沿比它紧挨的内部更暗**；同色的面碰到背景不是描边。
  - 「主导外沿是面色」是给**整块实体**写的，对骨架式对象（3 像素宽的桩）会误报——那一列背光是形体明暗。
  - 地面贴花另有自己一套：**宽 ≥ 高**（防画成立着的）、**亮断口断续 < 70%**（防勾边）、**缝有三档深度**（防读成一条涂上去的线）。
- **判据不许落在众数上——平票会抖。** 「整件不许读成一坨暗剪影」这条改过三版，前两版都是误判：
  1. 「外沿众数亮度 ≥ 内部中位数 − 4」——细高 / 骨架式对象几乎全是外沿，内部样本少且偏亮，合法背光面被判成描边（实测 dom=46.0 vs 内部中位 60.7）。
  2. 「外沿众数亮度 ≥ 40」——判据落在**众数**上，两色接近平票时会抖：实测 33.5 档占 23%、77.6 档占 22%，动三颗像素就翻红。**众数不是稳定量。**
  3. 现行：**外沿压在某档以下的比例 < 45%**。不依赖内部构成、不依赖平票。
  改完要拿它去查已经"过了"的旧卡——第三版立刻抓出一张老卡的残留问题（最大的可见面就是最暗档，46%）。**这时候要修那张卡，不是抬阈值。**
- **人抓回的意见如果是「区分度低」「都差不多」，那是维度问题，不是像素问题。** 沉淀方式是给每张卡声明形体类 + 一道跨卡的指纹闸门，而不是把某一张画得更细。

## 写完自检（必须书面作答；不许自称好看）

0. **因果链是通的吗？** 书面复述一遍：本质是什么 → 这个形体凭什么落在本质的成立范围内（**范围里还有哪些别的形体也成立？**）→ 世界观把这个形体改造成了什么。中间任何一跳答不上来，后面每一条都白查。
1. 载体平面对不对？它长在地面上还是立着？平面选错，后面每一条都白查。
2. 缩到 1:1、叠在声明过的落地底上：第一眼像什么？会不会撞上「剪影误读清单」里的任何一条？
3. 外沿（去接地 3 行、去青绿）众数是不是面色？深边占比是否接近储藏的 41%（在学 `edge=INK`），还是核心 4.8% / 净化器 0% 那一档？
4. 主体是不是一块平色？单一非青绿不透明色是否高到读成整板灰？
5. 动的是不是不该动的框？装置结构帧是否逐像素相同？
6. 每个不透明 RGB 是否都在 `palette.json`？有没有抄核心 / 净化器 / 玩家历史 hex？暖色是否越权到裂隙实体或污染侧？
7. 相机是否与身份锁声明一致？有没有把 45° 菱形和正对 10° 顶带画在同一件未声明的东西上？
8. 对照时的底是不是将要落地的场景底？有朝向的对象 `rotation` 是否恒为 0？
9. 若是薪柴容器：堆皮有没有泄露内容物或画上 teal？
10. 若是抽卡：几张卡是几个**不同的形体**，还是同一个形体的不同实现手段？每张是否都落在本质的成立范围内？再把 `aspect` / `shear` 打出来核一遍，数字有没有落在各自声明的类里？
10b. **把图放到别的世界观里想一下：它会不会一样成立？** 会 = 世界观没喂进去（回开工闸门「喂世界观输入」的六问），这时候调色没用。
11. 有没有浮在空中的像素（漆、指示灯、退化的小零件、挂件）？逐格扫一遍孤立像素，不要靠肉眼。
12. 活层青绿是整齐矩形吗？逐行宽度是否不等？

机械层可以扫。**不许**写：好看、审美过关、像这个游戏、PASS。交付写「机械层已扫；审美待人终审」。

## 反模式（出现任一条 = 不合格）

- **倒着走因果链**：先挑一个好画 / 好看的形体，再给它编一个本质；从旧卡或 AI 生成图反推本质
- **反过来也是错的：拿「本质决定形体」当借口只做一个形体就交差**，或者把形体从抽卡里划掉。本质是过滤器不是函数，成立范围里通常还有好几个都对——不抽 = 替人把卡抽了
- **本质只写一句话就开画**，不往下划形体的成立范围（把最关键的一跳留给随手发挥）
- 只划出一个形体就当成范围，也不用三个手法（分量主导 / 换载体平面 / 换体量分布）再找几个
- **本质有多个分量却不指定谁主导剪影**（会默认落回最平庸的那个形体）
- **形体对了但世界观没喂进去**：产出看起来可以出现在任何一款游戏里（通用科幻皮 / 通用奇幻皮）；工艺画得过于精密对称、当成废弃遗迹或崭新出厂、给装置本体上色当装饰
- **给地面上的东西找一个不存在的载体**（例：那个位置没有墙，却画一段墙给它靠）
- **在错的载体平面上反复打磨**：人否掉方向后继续微调旧载体，而不是回到「它是什么 + 为什么」
- 漫画描边；物体外一圈深线；换色描边（把 `INK` 换成 `SHADOW` / `VOID` / 深 clinic 交差）
- 真门框小屋；水池下滴当入口；把伤口读成传送门
- 一块平灰当混凝土；主体单一色超过大约一半还不拆材料
- 为练习场另画一套外形或另写一套渲染
- 旋转 45° 和正对 10° 混用还不声明；把已锁三台改相机；把入口 E2 / E3 仍走旧 `iso_*` 当成可以不声明
- 把储藏 C1 的 `edge=INK`（外轮廓深边约 41%）当成规范
- 抄已锁核心 / 净化器 / 玩家的历史 hex 当新对象色板
- 把 PLAN「面分隔线」读成描圈
- 用 AI 图述 / 概念图幻觉当验收（自动图述会稳定幻觉出门、水滴、头盔；以生成器统计 + 实地画面为准）
- 活层青绿画成一串小灯 / 整条霓虹 / 绕满一圈的门圈 / **高处一块整齐的亮矩形**（那是眼睛或屏幕）
- **抽卡时把实现手段当第一轴**：几张卡只在纹理 / 材料 / 开口位置上不同，形体全是同一句话 → 人会评「都是一个方向，只是大小不同」
- 形体类闸门红了就把手上那张拉长拉扁骗阈值，而不是回成立范围里另找一个本来就成立的形体
- 为了凑够卡数把本质放宽，让不成立的形体也算数
- 画完卡才回头调形体类阈值把自己放过；用**众数**当闸门判据（平票会抖，动三颗像素就翻红）
- **为了让闸门变绿去放宽闸门**；闸门误判时要改判据的定义，并写清为什么改
- 新判据抓出旧卡的问题时抬阈值糊过去，而不是修那张旧卡
- 沿垂线逐格打点画 45° 斜梁（会漏成一串点）；用不到 2 格进深的 `iso_prism` 画桩 / 耳 / 栓（会退化成浮空的一颗顶面）；挂件锚点钉死行号
- 磨损 / 指示灯不加"只落在实体上"的守卫就直接 `put`
- 旋转 GameObject 冒充四向；青绿当玩家签名；身体裂开当玩家签名；粗描边圆润四肢
- 薪柴 / 核心用壁炉橙火；把 HUD 薪柴 warm-dim 涂到世界内实体上
- 翻堆外观泄露内容物（未揭晓就画出薪柴晶体或污染物核，或把 teal 画在堆皮上）
