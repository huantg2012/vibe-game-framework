## 1. 净化点交互物（已进关卡）

历史公约：这三台是 45° `iso_prism`。新对象不要默默沿用，先在身份锁里声明相机。

| 对象 | 生产文件 | 生成器 | 学什么 | 不要学 | 像素对照（第一帧，外轮廓去底 3 行去青绿；深边 = 明度 < 体内中位 − 8） |
| ---- | -------- | ------ | ------ | ------ | --- |
| 核心 v6-B | `public/assets/sprites/modules/core-v6-b.png` | `docs/art/review-2026-08-28/gen/core_v6.py` | `iso_prism` **只填面不描边**；顶亮侧暗；青绿碰面色；极小暖灯；光与薪柴同源（teal） | 不要另起描边；不要壁炉橙火；**不要抄 `CORE_*` / `MET_*` 历史 hex 当新色板** | 深边 4.8%；外沿众数是面色 |
| 净化器 B1 | `public/assets/sprites/modules/purifier-b1-sheet.png` | `docs/art/review-2026-08-28/gen/purifier_b1.py` | 同上；外沿可以是最亮顶面金属；结构钉死、只动窗内介质 | 不要物体外一圈深线 | 深边 0%；外沿众数 `MET_L` |
| 储藏 C1 | `public/assets/sprites/modules/storage-c1-sheet.png` | `docs/art/review-2026-08-28/gen/storage_c_cards.py` | 材料不止一块平灰（土座、铜箍、暖灯） | **不要学 `edge=INK`** | 深边约 41%；外沿众数 `INK` |

PLAN 文首「45° + 面分隔线」只约束这三台。分隔线 = 邻面不同色。对照课叠在净化点混凝土上评（生产地板主色 `concrete-dark`），不要只放在纯黑底上评描边。

相关闸门：`npm run check:palette-quantize`（色必须能对上锁定色板）。这三台目前没有独立的「深边占比」npm 脚本；新对象若被人抓回描边，必须补定量闸门，不要只靠肉眼。

## 2. 玩家角色

| 指针 | 学什么 | 不要学 |
| ---- | ------ | ------ |
| `docs/art/actor-pixels.md` | 画布 32×32；混凝土灰略暖；灯是唯一高亮；尘往上飘；四向直立 | 青绿当玩家签名；身体裂开当签名；粗描边圆润四肢 |
| `src/entities/player-sprite-dense.ts`（文件头 **No outline**） | 加厚工业像素；面罩 / 背包 / 分腿 / 灯壳体 | 旋转 `GameObject`；另做一张精灵表当玩家 |

## 5. 裂隙入口（已锁；地面贴花的基线）

**生产默认 = 卡 5 击裂**（DEC-114，2026-09-04；DEC-113 留下卡 4 / 卡 5 两张）。这是本项目第一个**地面平面内**的世界内交互物，地面贴花的锚点 / 层 / 闸门都以它为基线。

**这一支同时是「本质不唯一决定形体」的硬证据：** 本质锁「伤口渗漏，不是门」排除了立着的体积与门框，但**卡 4 地缝与卡 5 击裂都落在成立范围内，人最后两张都留了**。一道中间粗两头细的缝，和一片从受击点向外炸的辐射裂，读的是同一个本质、形体不同。所以本质的活是把不成立的挡在门外，剩下的仍然要抽。

| 项 | 内容 |
| -- | ---- |
| 身份锁 | `docs/design-notes/rift-entrance-identity.md`「伤口渗漏，不是门」 |
| 卡面 | `docs/design-notes/rift-entrance-cards.md`（卡 4 地缝 / 卡 5 击裂；对照另有卡 7 错位 / 8 掀皮 / 9 网裂） |
| 生成器 | `docs/art/review-2026-08-28/gen/rift_entrance_ground.py`（自带闸门，退出码非 0 即不合格） |
| 生产贴图 | `public/assets/sprites/modules/rift-e5-sheet.png`（40×56 × 8 帧、6fps） |
| 接线 | `src/scenes/rift-entrance-visual.ts`；锚点 `ENTRANCE_ORIGIN_Y = 0.5`、层 `ENTRANCE_DEPTH = 1` |
| 对照 | `gym.html?lesson=rift-entrance-card`（五卡两行，底是出击同一份净化点混凝土）；实地 `#purif`，`?entrance=4|7|8|9` 或键 4/5/7/8/9 切对照。生产默认卡 5 |
| 架构 | `architecture.md` DEC-ARCH-019（地面贴花 vs 立着的对象，两类挂法） |

**学什么：** 地面上的缝画在地面平面里，锚点取中心、层在地板之上玩家之下；缝要有三档深度（`#151a1e` / `#0d1114` / `#080a0c`）；断口新鲜面更亮（`metal-grey` / `metal-light`）但必须断续；青绿只在缝里、连着一段、主体压在最暗两档。

**不要学：** 别把它当立着的对象去加顶面带；别把青绿铺满整条；别画出别处的具体材料（那等于承诺目的地，与「去向不可选」冲突）。

相关闸门：生成器内置十条。`npm run check:palette-quantize`。

## 6. 供奉台（抽卡进行中；形体类的基线）

**生产默认 = 卡 I 环（DEC-115）。** 对照课留下。这一支的价值仍在它撞出了因果链里「几张卡必须真的是几个不同的形体，不能是同一个形体换实现手段」这一环。

| 项 | 内容 |
| -- | ---- |
| 身份锁 | `docs/design-notes/offering-stand-identity.md`「一台同时起收容、控制、暴露三种作用的装置」（不是架子、不是祭坛）。第 3 节记了可分维度**换过一次**及原因 |
| 卡面 | `docs/design-notes/offering-stand-cards.md`（九张，三轮） |
| 生成器 | `docs/art/review-2026-08-28/gen/offering_stand_cards.py`（12 条单卡闸门 + 1 条跨卡形体类闸门） |
| 对照 | `gym.html?lesson=offering-card`（九卡三行三列，键 1–9，底是出击同一份净化点混凝土） |

**学什么：一、本质分量主导怎么长出形体。** 本质锁是「收容 + 控制 + 暴露」三件同时成立。第一轮三张全让**收容**主导、只换手段（夹 / 围 / 浇），于是形体塌成一类。第二轮换成让不同分量主导：

| 卡 | 本质里哪个分量主导 | 于是形体是 | 形体类 | aspect | shear |
| -- | ------------------ | ---------- | ------ | ------ | ----- |
| A 压钳 / B 笼斗 / C 浇墩 | 收容（三种做法，本质同一个） | 竖立实心块 + 某面开洞 | 方块 | 0.69 / 0.65 / 0.71 | −0.023 / −0.032 / −0.033 |
| D 举出 | **暴露**——把它递出去挨打 | 长臂把东西送出本体之外 | 横伸 | 0.77 | **−0.311** |
| E 抱箍 | **控制**——箍死在柱子上 | 细柱贯到顶，箍咬中段 | 竖高 | **0.50** | −0.089 |
| F 压槽 | **收容 + 压制** | 压板把它压死在槽里 | 贴地 | **1.16** | −0.022 |
| G 拱 | **暴露**——压力从喉里穿过去 | 两墩 + 压梁，从当中看过去 | 拱 | 1.00 | +0.067（靠 `mid_runs=2` / `arch_open` 与方块、贴地分开） |
| H 钳 | **控制**——两臂夹死 | 顶上两座峰 | 钳 | 0.79 | −0.031（靠 `apex_two=3` 与方块分开） |
| I 环 | **收容**——围成一圈但仍留孔 | 立着的圈 | 环 | 0.83 | +0.003（靠 `enclosed=73` / `mid_runs=2` 与方块分开） |

**二、指标不要只做一个。** 注意 D：`aspect` 0.77 落在方块区间**里面**，光看长宽比它和 A/B/C 没区别；把它和方块分开的只有 `shear`。而 `shear` 也不能换成"整件重心"——长臂被配重配平了，整件重心实测仍居中（+0.022）。

**不要学：** 九张的画法完成度都还没到已锁三台那一档（art 自评仍偏弱的三条写在卡面文档末尾）。**这一支还没人终审，不要当范例去抄画法**，只抄它的轴与闸门。

## 7. 那条走了六张才找到的路（过程教训）

裂隙入口先后废掉六张，两轮都在**同一个病根**上：把「时空的伤」画成「一段墙被弄坏」。

- 第一轮（壁裂幕 / 错层剪 / 膜破回缩）：人评「太像水池」「灾难」「不要真门框」。
- 中间热修两次：第一次把墨黑描边换成深灰描边交差，人评**不诚实**——闸门当时只查 `INK`/`VOID`，所以假绿。第二次才真去掉描边。
- 第二轮（挤入 / 蚀腔 / 层叠）：画法闸门全绿、外沿全是面色，人仍评「都是狗屎」。
- 回到「它是什么 + 为什么」，才发现那个位置**没有墙**：入口压在椭圆北沿，净化点的边界是变暗带 → 力场膜 → 虚空。墙是我凭空造的。
- 人给方向（地面上的裂缝 / 钢化玻璃式辐射 / 被钉住的虫洞）之后，一轮就过。

**沉淀成规矩的三条：**

1. **人否掉方向时，先回到「它在世界里是什么 + 为什么」，不要在旧载体上继续打磨。** 画法闸门全绿 ≠ 载体对。
2. **换色描边 = 不合格。** 把 `INK` 换成 `SHADOW` 交差过一次，闸门因为只查近黑而假绿。判据要写成物理定义（外沿是否比紧邻内部更暗），不要枚举颜色。
3. **闸门误判时改判据的定义，不放宽阈值。** 全局中位数在双材质对象上误报、「主导外沿」在骨架式对象上误报——两次都是判据的适用范围写窄了，不是产出不合格。

上一版的墙上三张与卡 6 囚笼已整支删除（生成器 `rift_e_cards.py` 已删），不留死代码、不留「以后可能有用」的图集。

## 8. 「全绿但不合格」怎么诊断：先定位断在因果链的哪一环

SKILL.md 的因果链是 **本质 → 形体剪影 → 世界观 → 外观**。到目前为止，机器闸门全绿而人仍然否掉，发生过三次，**三次断在不同的环节**。遇到「全绿被否」，第一件事是定位环节，不是继续打磨像素——在错的环节上打磨，磨得再细也不会变对。

| 断在哪一环 | 案例 | 症状 | 沉淀成了什么 |
| ---------- | ---- | ---- | ------------ |
| **形体掉出了本质的成立范围** | 裂隙入口连废六张 | 把地面上的现象画成"一段墙被弄坏"，而那个位置没有墙——墙是凭空造的 | 开工闸门「声明载体平面，再声明相机」+ 载体平面表；本质锁要求当场划出成立范围 |
| **几张卡其实是同一个形体换皮**（没在成立范围里真的换形体） | 供奉台第一轮三张 | 夹 / 围 / 浇是同一个形体的三种实现手段，剪影全是「竖立实心块 + 某面开洞」 | 「形体可以抽，但要落在成立范围内」+ 三个找候选形体的手法 + 跨卡指纹闸门（`aspect` / `shear`） |
| **判据本身不稳**（闸门自己是坏的） | 「整件不读成暗剪影」改三版 | 用相对基准 → 骨架式误报；用众数 → 平票抖动 | 判据必须是绝对的、占比式的物理量；不许落在众数上 |

**还有一环至今没被人当场抓过，但一定会来：世界观 → 外观。** 症状是形体读得出、闸门全绿，但整件看起来可以出现在任何一款游戏里（通用科幻皮）。预防手段是开工闸门的「喂世界观输入」六问，以及写完自检 10b：把图放到别的世界观里想一下，它会不会一样成立。

共同规律：**闸门只能证明"没犯已知的错"，证明不了"链是通的"。** 全绿之后仍要自己缩到 1:1 看第一眼，回答"这几张是不是同一个东西"，以及"它凭什么是这个世界里的东西"。
