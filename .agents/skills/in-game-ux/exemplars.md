# 本游戏 UI 翻车录

来源：合入 `f3d2f93` 的审查（`docs/art/review-2026-08-28/`）。Findings 给 Director 的诊断 ID 为 P5–P7。成品图是方向，不是把旧像素描进已换模型的关卡。

世界内几何体（P1 / P2）已翻生产，**不要**再用本文件指导模块外形——那走 `pixel-models`。

## P5 · HUD 是 debug overlay

**当时：** 右上散列文字，无背景、无边框、无分组，四行视觉权重相同。遇亮背景可读性崩溃。Slice 5.5 曾批准净化点 HUD 不套 `.game-panel`（A 类装置读数）。审查判定：那是 debug 残留。

**要变成：** 真正的面板。容器 + 资源组 / 状态组 + 字号层级。薪柴最大。「下次归来」默认弱。

**成品图：** `docs/art/review-2026-08-28/cards/ui-hud.png`

**迭代 11：** 5.5 那条「可以不套容器」的例外对净化点 HUD **作废**（DEC-118）。裂隙 HUD 不在该例外的翻案范围内，除非另立批次。

## P6 · 底部提示条无容器

**当时：** 裸文字，无动画，视觉优先级低到被忽略。

**要变成：** 世界层与 UI 层的唯一桥梁。容器；无目标半透明、靠近满显；第二行状态预览。走近培养藏应读出「那是能按 E 的东西」，并且不必打开面板就知道值不值得走过去。

**成品图：** `docs/art/review-2026-08-28/cards/ui-hint.png`

## P7 · 面板是网页平铺

**当时：** 信息全展开靠扫描；无主-从、无渐进披露、无明确焦点；约 40% 空白。第一版左侧分类导航 = 网页后台。升级描述只有氛围句。空状态是纯黑。

**要变成：**

- 状态：顶三模块条 + 顶 Tab + 整宽详情 + 底键印。`ui-status.png`
- 分配：一次一个模块；「投入」唯一焦点；底栏出击预估只译已有修正。`ui-alloc.png`
- 空：是什么 / 为什么空 / 现在做什么。`ui-empty.png`

心理模型：操作设备，不是读查询结果。

## AI 味（跨 P5–P7）

纯白字 + 近黑底 + 高饱和强调。扫描线开着仍像生成图。处方精神：压对比、克制后处理。不要再加一层「更 CRT」来掩盖平铺。

## 与已锁装置并排（问 3 的新约束）

审查画 HUD / 面板处方时，场上还是六边形和圆点。现在同框的是 v6-B / B1 / C1 / 卡 5 / 卡 I / 卡 A。新 UI 必须跟这些装置一起看，而不是只跟处方图一起看。
