# 怎样过审美与风格适配

本文件服务 [SKILL.md](SKILL.md) **问 1** 与 **问 3**。hex、字号、组件类以 Kit 为准；本文件给可否决的操作定义。

「好看」= 对得起 `art-direction.md` §6 那句：**净化点设备的监控终端，低保真磨损 CRT，冷峻、功能性、无装饰。** 不是通用扁平好看，也不是把扫描线开满。

agent 不许自称审美过关。

## 显示器感 vs AI 味

审查原话：风格对了，味不对。

| 显示器感（要） | AI 味（否决） |
| -------------- | ------------- |
| 字色在 Kit 的 `ui-text` / `ui-text-bright` 档，正文发灰 | 纯白字 `#ffffff` 砸近黑底，对比拉满 |
| 强调靠字号、位置、条长 | 高饱和强调色当层级 |
| 扫描线是屏的材质，克制 | CRT 后处理当特效，边缘发光、色散、重阴影 |
| 空白被详情填满 | 35–45% 空面积，像网页没填完 |
| 容器 + 分组 + 字号三级 | 散列字贴画布，或卡片投影堆 |

审查处方的精神（落地数值跟 Kit，不要把 2026-08-28 的 hex 当第二套色板）：把最亮值从「接近 255」压到 Kit 已锁的亮字档；次要信息降字号或降不透明度，不要靠再加一色相做层次。

## 与世界同一套（问 3）

2026-08-28 画成品图时，场上还是几何体。现在场上是已锁装置。UI 必须跟**现在的**核心 / 培养藏 / 供奉台同框成立，而不是只跟当年处方图成立。

并排时否决：

- overlay 的边比装置更亮、更饱和，读成另一套 HUD 皮肤
- 暖色出现在非薪柴通道（薪柴是本世界几乎唯一的暖）
- 圆角、投影、外发光（§6 明文工业直角；装饰须有物理原因）
- 新字号档、未映射 hex

## 可否决句

1. 答不出「这是哪台机器打出来的字」→ 否决。元界面允许承认软件，仍守色板与术语。
2. 用新色相做层次 → 否决。
3. 人点名看不清时仍以风格挡 → 否决。
4. 投影 / glow 的物理原因答「好看」→ 删。
5. 常驻独立信息点过多、无标签裸条 → 否决。
6. 打开面板后漏景里的装置看起来像另一款游戏 → 否决。

## 写完最低动作

- 灰度：安全/危险、可用/不可用仍靠位置、条长、计数、符号。只剩色相差 → 不合格。
- 并排已锁装置 + 并排审查成品图。方向对齐成品图，存在对齐装置。
- 朗读可见字符串：能听成复合名词 → 拆开。
