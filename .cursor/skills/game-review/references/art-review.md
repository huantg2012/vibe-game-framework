# 美术设计归类与品质评审

先描述玩家看到的组织规则，再判断它是否成熟。作者给的流派名、引擎、资产来源和旧验收不能代替实际观察。美术有独立的表达与身份价值，不必把每项判断都转成可读性问题。

## 六轴归类

对每轴给出可见依据、把握程度，以及样本是否足够：

1. **空间与投影**：俯视/轴测/透视观感，平面与体积、深度、遮挡、尺度及视口关系。不能从视觉观感断言底层一定是2D或3D。
2. **画法与图像语言**：像素簇、线条、平涂、笔触、拼贴或模型渲染观感；边缘、轮廓、细节尺度、纹理与采样规则。“像素风”不是完整归类。
3. **造型与材质语言**：比例、抽象与夸张、几何/有机倾向、剪影和材料读法；角色、环境、物件各自的规则与联系。
4. **色光与构图**：明度块、色彩关系、冷暖/饱和度组织、光源、焦点、留白与层次。色彩倾向是观察结果，不是固定目标。
5. **视觉母题与情绪**：重复意象如何建立世界身份、兴趣与情感。主题、题材、情绪分开；不要据一张图补写世界设定。
6. **运动与视效**：姿态、节奏、镜头、粒子与效果的形状/时间语言，静态规则在动态中是否保持。无连续材料则未验证。

收束为：**主导语言＋次级语言＋它们分布在哪些对象、如何衔接。** 分别检查实际提供的角色、环境、物件、UI、特效，不要求它们使用同一种制作技术。有多个候选时保留候选，材料不足时不强贴标签；有意粗粝、低保真或异质混合需要组织依据，粗糙本身不是风格解释。

## 四个独立品质结论

- **表达力度与身份**：能否产生兴趣、情绪、地方记忆和自身性格？离开文案后还剩什么？优点要说出成立条件。
- **语言一致性**：形体、材质、色光、细节尺度、UI和动态间是否有可读的联系？有组织的差异与临时拼接分开。
- **完成度与制作成熟度**：轮廓、材料、层次、比例、重复节奏、静区和状态变化是否有选择、有控制？不按面数、纹理清晰度或复杂度直接评分。
- **玩法适配**：常规镜头、运动与压力下，主体、交互对象、危险与反馈能否承担其实际信息职责？艺术价值与操作代价分别呈现，再裁决取舍。

允许“风格明确但执行薄”“画面精细但缺少身份”“表达成立但行动读法冲突”等结论；不要平均成一句好看/不好看。美术整体失效可以是高优先问题，不因没有报错而排到最后。

## 有效取样

看正常游戏尺度的代表视口，再用局部放大定位原因。对空间走一段连续路线；对对象看关键状态转换；对效果看触发前—作用中—恢复后。需要时比较暗/亮背景、不同压力、相邻视角与常见遮挡，但不机械要求每次把所有矩阵跑满。

不要只看最漂亮的定点、调优样例、图标接触表或最终一帧。静帧能够支持材料/构图判断，不能证明运动、手感、转场或所有状态成立。音频若未实际听到，单列未验证。

## 给出可制作的建议

把症状落到可调整的关系：大形与负形、主次明度、材料区别、细节尺度、色彩比例、姿态节奏、效果持续时间、空间锚点等。先说明要改善的观感或理解，再提出实现候选；未经诊断不直接开“换引擎/重做全部贴图”的处方。

共享资产或生成系统的建议需说明适用边界，并拿变化样本及极端状态检验；不能只美化一张演示图。优先保留已成立的视觉个性，不用统一灰暗或统一高饱和抹平世界差异。

使用参考游戏时先声明具体比较维度、观察材料和平台/阶段差异；核实实际资料，不能凭名气和记忆断言制作技术。借鉴可解释的组织方法，不整套套皮。机器检查负责合规/稳定性，专家负责审美判断，用户终审另列。
