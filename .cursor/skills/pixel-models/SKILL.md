# 像素模型：世界内物体怎么画

口号「要像这个游戏」不够。本 skill 是 **HOW**：教 agent 按本游戏已锁像素模型来画世界内实体，而不是靠会话记忆发明描边和色板。

抽卡**决策循环**（机制先锁 → 完整组合 → 对比课 → 人抽 → DEC）住在 [visual-card-draw](../visual-card-draw/SKILL.md)。本文件只管**怎么画**。像素抽卡两份都要 Read：先流程，再画法。

HUD / DOM / 蒙层走 [in-game-ux](../in-game-ux/SKILL.md)。世界内像素实体走本文件。

自定义 agent **不会**自动加载 skill。被派到像素模型 / 像素抽卡时必须显式 Read 本文件；Director 的 Task Brief 必须写明这一步。

已锁范例、学什么 / 不学什么、闸门命令见 [exemplars.md](exemplars.md)。色板 hex、画布表、禁忌全文**不抄进本文件**，按文末指针去读。

## 适用 / 不适用

**适用**：世界内像素实体、精灵图集、程序像素、像素抽卡卡面、对比课里的物体（不是侧栏）。净化点装置、玩家、裂隙内可交互物、薪柴 / 翻堆、入口一类世界物体都在这里。

**不适用**：

- HUD / DOM / overlay / 菜单 → `in-game-ux`（薪柴**计数**的 warm-dim 是 UI，不是世界内实体色）
- 抽卡流程本身（几张卡、何时翻生产、何时删课）→ `visual-card-draw`
- 连续地面大面积烤漆细节 → `docs/art/rift-fragment-surfaces.md`（本 skill 只收物体与地面交接的纪律：物体外沿必须是面色；成片青绿 = 有主占漆，不是装饰）

## 开工闸门（缺一步不许画）

书面写完再动笔。缺任一项 = 停工。

### 1. 身份锁

一句话：**它在世界里是什么**，不是长什么样。对照：储藏锁的是「收容体」；入口锁的是「伤口渗漏，不是门」。禁止从旧卡或 AI 图述反推身份。

### 2. 声明载体平面，再声明相机

**载体平面选错，像素画得再好也不成立。** 这是实测代价最大的一条：裂隙入口连续两轮共六张全废，共同病根就是把「时空的伤」画成「一段墙被弄坏」——而那个位置根本没有墙（净化点边界是变暗带 → 力场膜 → 虚空）。凭空造一段内壁 = 发明场景里不存在的建筑。

先答两问：**它长在什么上面？**（地面 / 已有实体 / 空气）**它是躺着还是立着？** 然后查表：

| 载体平面 | 谁在用 | 像素怎么画 | 锚点 / 层 |
| -------- | ------ | ---------- | --------- |
| **地面平面内**（与地面纹理同一平面，顶视） | 裂隙入口（卡 4 地缝 / 卡 5 击裂，DEC-113）、裂隙占漆 | 缝 / 渍 / 漆直接画在平面里，**不做竖直体积** | 锚点取**中心**；层压在地板之上、玩家之下（`ENTRANCE_DEPTH = 1`） |
| **立着 · 正对 + 向下俯视 10°** | 立在地上的世界物体（人锁的入口相机曾用于此） | 前脸近竖立，顶面只露一条窄带 | 锚点取**脚底**；层与读数桩同层 |
| **立着 · 45° 等距**（顶面旋转 45° + 压缩） | 已锁三台：核心 v6-B、净化器 B1、储藏 C1 | `iso_prism` 只填面 | 同上。**已锁三台不要改相机** |

**地面上的东西必须画在地面平面里。** 按「立着」的相机画会被压没：下俯 10° 时一格进深只换来 0.17 行，一道地缝几乎看不见。反过来，把立着的东西画进地面平面会丢掉体积。

**禁止默默混用。** 一件对象一个平面，写进身份锁。PLAN 文首「45° + 面分隔线」是那三台装置的历史公约，不是全对象默认。分隔线的合法读法 = **邻面不同色**，不是第三色描圈。

架构后果登记在 `architecture.md` DEC-ARCH-019。

### 3. 声明画布尺寸（层级）

写出宽×高，以及它在同场物体里比谁大、比谁小。填充物：`docs/art-direction.md` §3.2、PLAN 统一约束第 2 条、`docs/art/actor-pixels.md` 画布表。不要为练习场另开一套尺寸。

### 4. 锁定色板

只许 `docs/art/palette.json`。列出本对象要用的色板**名**。禁止会话发明 hex，也禁止把已锁生产图上的历史 hex（核心 / 净化器的 `CORE_*` / `MET_*`、玩家身体灰）当成新对象的色板。新格 = art 提案 + 人拍板 + DEC + 全链路传播。本 skill 不授权新增格。已锁三台与已锁玩家不要为「对齐色板」去改生产图。

### 5. 钉 2–3 个具名参考

表：游戏名或已锁生产对象 | 学什么动作 / 体积 / 材质 | 明确不学什么。只写「学核心」而不写「学 `iso_prism` 只填面」= 停工。项目参考入口：`docs/art-direction.md` §1.5。已锁像素锚点见 [exemplars.md](exemplars.md)。

### 6. 若是抽卡：先走 visual-card-draw 步骤 0–1

机制没锁不开画。每张卡是完整组合，不是变量排列。

### 7. 声明落地底

写出对照与验收叠在哪：净化点混凝土，还是某张碎片的烤地。对照课必须用这个底，禁止只在纯黑卡纸上判断描边。

## 画法定律（可执行约束）

1. **硬边、透明底、1:1 真尺寸、可进游戏。** 不是页面示意图，不是抗锯齿概念图。最近邻缩放。产出必须能直接当精灵 / 图集用。
2. **只许锁定色板。** 最终不透明 RGB 必须能在 `palette.json` 找到同一格。禁止会话发明 hex，禁止抄已锁核心 / 净化器 / 玩家身上的历史 hex 当新色。
3. **剪影像素 = 那个面的填色。** 先填可见侧面和顶面，然后停。禁止物体外再描一圈更深的第三色。`INK` / `VOID` / `SHADOW` / 深 clinic 当外沿都算描边。把描边换成另一种深色（换色描边）= 不合格。深色只许落在包围盒最底 3–4 行接地斑，不许爬上墙棱。
4. **体积 = 邻面明度差。** 有明确多面的装置：顶亮、前中、侧暗；侧面不得与顶面同亮。不是渐变、不是 mottle 灰阶量化、不是第三色描圈冒充分隔。玩家是密像素分件（面罩 / 背包 / 分腿），不要套 `iso_prism`。薪柴翻堆是残骸堆（渍缝 + 高光条 + 底影），不是棱柱。
5. **结构钉死，只动活的那一层。** 装置：框 / 罐 / 井逐帧相同；能动的只有窗内介质、口内光幕、灯、被关住的鼓包。玩家：四向换贴图 + 灯尘上飘，允许 1 像素步态形变，不要扭骨架去「呼吸」。翻堆：堆外形不随内容物变；翻找时只许碎屑 / 揭晓粒子动。
6. **暖色稀缺，按侧分工。** 裂隙内世界实体不带暖光源。净化点装置允许极小功能暖灯（面积要能答「指示」，不能答「好看」）。玩家灯是人类侧唯一高亮。薪柴世界内实体属污染侧：teal 余晖，不是壁炉橙火；核心烧薪柴时，光与污染同源（teal）。残骸材质色三格是世界材料、哑不光，口径见 `art-direction.md` §2.3 规则 8 注 2——不要写成光源。
7. **青绿 = 外来模式 / 污染 / 薪柴余晖。** 不是装饰霓虹，不是玩家签名，不是堆皮上的「这里有燃料」。成片青绿在地面上 = 有主占漆。污染侧不要暖色。翻堆主体走残骸材质，teal 只出现在揭晓，不画在堆皮上。
8. **活层青绿有三种画坏法，都是实测撞出来的。** 逐格隔一个点 = 一串小灯；整条 / 整面铺亮 = 霓虹；绕着一个口走满一圈 = 传送门。正确写法：连着一段、段间断开，主体压在最暗两档（`contam-deep` / `contam-mid`），只有几格在走；要么从一个点往外淡出、可达半径随帧呼吸。青绿**只许在缝里 / 口里 / 凹进去的面里**——一贴到透明背景就读成涂上去的荧光线。
9. **不旋转 GameObject。** 四向靠换贴图。四向都是直立（头在画布上方）。45° 与正对 10° 是**画进贴图的投影**，不是运行时去转精灵。无四向的装置也禁止用旋转摆出 45°。
10. **可见像素要在将要落地的场景底上读得出。** 净化点装置叠在净化点混凝土（生产地板主色见 exemplars），裂隙实体叠在该次出击烤地。不要只在纯黑底上判断描边。PLAN「可见像素明度 ≥ 45（对 `#0d1114`）」只适用于那三台装置对着环境暗部看会不会溶掉，**不是**混凝土地面合同，也不是裂隙烤地合同，更不要套到裂隙甲身上。裂隙堆 vs 地面走 `check:loot-pile-contrast`（见 exemplars）。

## 剪影误读清单（实测撞过的，别再撞）

小尺寸下剪影会被自动归类到最近的熟悉物体。这些都是本项目真实被否掉的读法：

| 画了什么 | 被读成 | 怎么破 |
| -------- | ------ | ------ |
| 光滑对称的纺锤 / 椭圆 | 一只眼 | 上下缘不对称，岔出支线 |
| 四根对称的支撑 | 四条腿 → 一只虫子 | 改三根、不对称、不等高 |
| 立柱顶端与主体齐高 + 横向连杆 | 灯笼 / 门框 / 神龛 | 主体要高过立柱顶；连杆只在下半截 |
| 碎成一格一格的顶沿 | 绒毛 / 苔 | 顶沿做平，只在两三处断档 |
| 等角均分的放射线 | 车轮辐条 | 角度与长度都不等分 |
| 一大团深色 | 墨点 / 污渍 | 团压到两三格，其余靠细线 |
| 又多又细的放射线 | 蜘蛛 | 减少条数、拉长、只留一条环向弧 |
| 宽矮的块 + 顶面亮带 | 箱子 / 板条箱 | 加高、破对称、让它长进地里 |
| 填实的深色椭圆压在底部 | 花盆 / 底座 | 换成短放射地裂 + 断口亮棱 |
| 环绕一个洞的连续亮圈 | 传送门 / 舷窗 | 亮只留一段弧；洞形不规则 |

判断办法：把 1:1 的图缩到实际观看尺寸，问「第一眼像什么」，不要问「像不像我想画的」。

## 抽卡场景怎么用本 skill

流程归 `visual-card-draw`：完整组合、真实上下文对比课、打开即播带动效、人没抽不翻生产、落选整支删除、人抓回必须沉淀定量闸门。

本 skill 负责：

- 每一张卡的物体服从上面的画法定律与开工闸门。
- 对比课背景必须是**将要落地的场景底**（净化点混凝土 / 裂隙地面），不是纯黑、不是另一套练习场渲染。
- art 逐卡最短核：身份锁 + 声明相机 + 外沿是面色 + 色在板内（没有抄历史 hex）。人点名「学核心 / 学净化器」时这四件必须书面答。只核不改。不代勾好看。
- 人抓回的描边 / 平色 / 相机混用，修复时必须补或扩一道机器闸门。只修本体不补闸门 = 未完成。
- **闸门要按对象类别分套，判据要写成物理定义。** 实测两次误判：
  - 「外沿深边」用**全局中位数**做基准，在双材质对象上会误报（一半深混凝土 + 一半浅地层 → 误报 25%）。正确定义：**描边 = 外沿比它紧挨的内部更暗**；同色的面碰到背景不是描边。
  - 「主导外沿是面色」是给**整块实体**写的，对骨架式对象（3 像素宽的桩）会误报——那一列背光是形体明暗。骨架式对象改查更硬的一条：**硬件上不许出现近黑**，勾边就无处可藏。
  - 地面贴花另有自己一套：**宽 ≥ 高**（防画成立着的）、**亮断口断续 < 70%**（防勾边）、**缝有三档深度**（防读成一条涂上去的线）。

## 写完自检（必须书面作答；不许自称好看）

1. 载体平面对不对？它长在地面上还是立着？平面选错，后面每一条都白查。
2. 缩到 1:1、叠在声明过的落地底上：第一眼像什么？会不会撞上「剪影误读清单」里的任何一条？
3. 外沿（去接地 3 行、去青绿）众数是不是面色？深边占比是否接近储藏的 41%（在学 `edge=INK`），还是核心 4.8% / 净化器 0% 那一档？
4. 主体是不是一块平色？单一非青绿不透明色是否高到读成整板灰？
5. 动的是不是不该动的框？装置结构帧是否逐像素相同？
6. 每个不透明 RGB 是否都在 `palette.json`？有没有抄核心 / 净化器 / 玩家历史 hex？暖色是否越权到裂隙实体或污染侧？
7. 相机是否与身份锁声明一致？有没有把 45° 菱形和正对 10° 顶带画在同一件未声明的东西上？
8. 对照时的底是不是将要落地的场景底？有朝向的对象 `rotation` 是否恒为 0？
9. 若是薪柴容器：堆皮有没有泄露内容物或画上 teal？

机械层可以扫。**不许**写：好看、审美过关、像这个游戏、PASS。交付写「机械层已扫；审美待人终审」。

## 反模式（出现任一条 = 不合格）

- **给地面上的东西找一个不存在的载体**（例：那个位置没有墙，却画一段墙给它靠）
- **在错的载体平面上反复打磨**：人否掉方向后继续微调旧载体，而不是回到「它是什么 + 为什么」
- 漫画描边；物体外一圈深线；换色描边（把 `INK` 换成 `SHADOW` / `VOID` / 深 clinic 交差）
- 真门框小屋；水池下滴当入口；把伤口读成传送门
- 一块平灰当混凝土；主体单一色超过大约一半还不拆材料
- 为练习场另画一套外形或另写一套渲染
- 旋转 45° 和正对 10° 混用还不声明；把已锁三台改相机；把入口 E2 / E3 仍走旧 `iso_*` 当成可以不声明
- 把储藏 C1 的 `edge=INK`（外轮廓深边约 41%）当成规范
- 抄已锁核心 / 净化器 / 玩家的历史 hex 当新对象色板
- 把 PLAN「面分隔线」读成描圈
- 用 AI 图述 / 概念图幻觉当验收（自动图述会稳定幻觉出门、水滴、头盔；以生成器统计 + 实地画面为准）
- 活层青绿画成一串小灯 / 整条霓虹 / 绕满一圈的门圈
- **为了让闸门变绿去放宽闸门**；闸门误判时要改判据的定义，并写清为什么改
- 旋转 GameObject 冒充四向；青绿当玩家签名；身体裂开当玩家签名；粗描边圆润四肢
- 薪柴 / 核心用壁炉橙火；把 HUD 薪柴 warm-dim 涂到世界内实体上
- 翻堆外观泄露内容物（未揭晓就画出薪柴晶体或污染物核，或把 teal 画在堆皮上）
