# 净化点 R8 建筑源稿

`environment.ts` 是固定 640×400 的完整分层结构源；所有形体均为具名面，不从历史鼠啃墙缘追加补片。`src/art/chamber-authored-architecture.ts` 负责同源像素栅格化、材质内三尺度层积、四块地面及坡道的几何派生。角色与装置不属于本资产。

## 身份与绘制约束

- 本质：被持续外部改写压迫、仍在维护的功能场所。要求实际厚壳、上下支承、可工作的空地；排除城堡装饰、露天祭坛、天空、宗教符号和外部可探索出口。
- 成立形体包括厚肩与内凹维护面、叠放承重板、受压剪切墙段；本轮依已授权 R8 方案组合为不等后肩、整段东剪墙、向下前基础。核心仍在主层，暗支承与上层前缘连接。
- 相机：固定浅透视；世界还原为 `X=x, Y=y+Z, Z=height`。主层0、上层32，两坡高程取实际行走多边形。所有面的法线/高程与填色像素同时落盘。
- 来源：净化点的人用砼、石灰与回收钢件维护；施工并不精密，保留旧料和真实接缝；磨耗属于仍在使用的场地。DEC-180 允许原材色相，暖原料哑不发光，teal只用于异常接触。
- 参考：已锁核心/净化器的面色轮廓与受约束介质；《死亡细胞》的受控背景对比和人工表面信息；《风来之国》的自然结构分层。未复制其城市、信仰或生态。
- 落地底：正式净化点地面与原角色；环境保持640×400原尺寸，设备独立排序。资产稿中的设备叠图只为比例核对，不作为核心动态证据。

## 生成

```sh
node --import tsx tools/art-pipeline/purification-r8.ts docs/qa/artifacts/iteration-30-r8/environment-03
```

输出各层 albedo、baked、normals、height PNG、像素精确分层 `authored-master.svg`、结构面编辑参考 `authored-structure.svg`、表面清单与全景。结构 SVG 不含材质内采样/坡鼻细纹，不能当最终像素。

- color 与 surface 由正式 painter 同步栅格化；不把图片亮度当高度。
- 法线图 `RGB=(normal+1)*127.5`；高度图 `Z=(R*256+G-32768)/32`；alpha 是覆盖。
- `far` 不参与表面重照；`middle` 29,430像素全部有表面；`near` 20,797像素中20,578有表面，219像素是异常接触层。
- 材质各有大块矿物场、中尺度定向层积、低比例骨料簇；静态一次采样，视觉种子不消费玩法随机数。法线仍取形体面，细颜料不假造坡度。
- 导出闸门逐像素比较 floor alpha 与现有四个行走多边形，并检查 surface 不超出其渲染像素。通过只证明几何和资产一致性，不能替人签审美。

## 摄影机与活动

外景 far/middle/near 三层深度 -60/-55/-50；跟随率 .12/.52/1。以基础镜头中心补偿位移，禁止单独自动漂移。近层接触光与沿缝输运同相，中层只在底面缓慢遮蔽，远层无粒子。减少动态时保留低能稳态反射，去掉沿缝运动、尘点与中层变化。
