# 整体工作框架（Overview）

## 核心理念

```
Human = 创意总监 + 质量守门人 + 最终决策者
AI    = 全栈执行团队（策划助理/程序员/美术/QA/文案）
```

你不再是"写代码的人"，而是**导演**。AI 负责生成，你负责方向、判断、取舍。

---

## 六大阶段

| # | 阶段 | 核心目标 | 主要产出 | 人的角色 | AI的角色 |
|---|------|---------|---------|---------|---------|
| 1 | **构思 Ideation** | 从模糊想法到可执行概念 | 概念文档 + 核心循环定义 | 提出愿景、做选择 | 发散创意、结构化整理、竞品分析 |
| 2 | **设计 Design** | 定义玩法细节和技术方向 | GDD精简版 + 技术架构 + 美术方向 | 审批设计决策 | 生成GDD、系统设计、原型UI |
| 3 | **原型 Prototype** | 最小可玩验证 | 可运行的核心玩法原型 | 试玩反馈、方向修正 | 生成代码、快速迭代 |
| 4 | **生产 Production** | 全量内容和系统开发 | 完整游戏各系统 | Code review、优先级排序 | 批量生成代码/资产/内容 |
| 5 | **打磨 Polish** | 体验优化和质量保障 | 可发布版本 | 体验把控、最终裁决 | Bug修复、性能优化、细节补全 |
| 6 | **发布 Launch** | 上线和运营 | 线上版本 + 运营体系 | 市场策略、社区运营 | 部署自动化、数据分析、内容更新 |

---

## 每个阶段的标准工作节奏

```
┌─────────────────────────────────────────┐
│  Human: 定义意图 (Prompt/Brief)          │
│         ↓                               │
│  AI:    生成方案 (Generate)              │
│         ↓                               │
│  Human: 审核 + 反馈 (Review/Feedback)    │
│         ↓                               │
│  AI:    迭代修正 (Iterate)               │
│         ↓                               │
│  Human: 验收 → 进入下一单元 (Accept)     │
└─────────────────────────────────────────┘
```

每个"单元"粒度尽量小（一个系统、一个模块、一个画面），保持快速迭代节奏。

## 技术栈预判（Web 游戏场景）

| 层 | 推荐选项 | 说明 |
|----|---------|------|
| 游戏框架 | Phaser 3 / PixiJS / Three.js / 纯 Canvas | 取决于 2D/3D 和复杂度 |
| UI层 | React/Vue + 游戏Canvas叠加 | 菜单、HUD、对话框等 |
| 构建工具 | Vite | 热更新快，AI生成代码后秒级反馈 |
| 语言 | TypeScript | 类型系统帮助AI生成更准确的代码 |
| 美术资产 | AI生成(Midjourney/SD) + 简单后处理 | 程序员背景，美术交给AI |
| 音频 | Suno/AI音乐 + freesound | 音效和BGM |
| 部署 | Vercel / Netlify / itch.io | 一键部署，快速让人试玩 |
| 版本管理 | Git + GitHub | 标准流程 |

## 质量门禁（Quality Gates）

每个阶段结束前必须通过的检查：

1. **构思 → 设计**：核心循环能用一句话说清楚 + 目标玩家明确
2. **设计 → 原型**：技术方案验证可行 + 范围明确（scope锁定）
3. **原型 → 生产**：核心玩法"有趣" + 技术架构跑通
4. **生产 → 打磨**：全部核心功能可用 + 无阻断性Bug
5. **打磨 → 发布**：性能达标 + 新手体验流畅 + 无严重Bug

---

## Vibe Coding 的关键原则

1. **小步快跑** — 每次对话/prompt 只处理一个明确的小任务
2. **先跑通再优化** — 先要 working code，再谈 clean code
3. **持续可运行** — 任何时候 `npm run dev` 都能启动，看到当前状态
4. **版本快照** — 每完成一个里程碑就 commit，随时可以回滚
5. **人做决策，AI做执行** — 不要让AI替你做产品判断
